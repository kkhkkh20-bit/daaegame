# C2 이벤트 음향·주민 반응 수정

검수 브랜치 `review/c2-event-audio`. 기준 `abbdd493` (이전 검수와 main `2791e791` 병합본). main 병합·배포 없음.

## 최신 사용자 피드백

- 아빠는 플레이어. 아빠 발화는 주민 반응으로 표시하며 아빠 이미지와 아빠가 포함된 분할은 사용하지 않음. 이전 저장의 분할 상태도 로드 시 해제.
- C2 실제 `counter:s3`는 뿔이→아빠→뿔이 공방. 서리의 끼어들기는 단독 제지이며 주민 두 명의 긴 대립이 아니므로 C2 분할을 제거. 새 대사를 만들지 않음.
- 기존 고정 각도 및 짧은 청자 반응 컷 유지. 인물 전환에만 0.18초, 최대 18px 이동 및 최대 10% 투명도의 방향성 잔상. 배경/책상/대화창에 흐림을 넣지 않음. 모션 끄기·스킵·롤백에서는 생략.
- 이번 아트 요청은 부리·서리만 유지. 아빠 제외: [아트 요청](../c2-editorial/ART_BRIEF.md).

## 이벤트 음향

| 상태 | 음악 채널 gain | 환경음 채널 gain | 종료 조건 |
|---|---:|---:|---|
| 기본 | .45 | .65 | 다음 의미 있는 이벤트 |
| 핵심 증거 설명 | 0 | 0 | 주민 반응/대사 전환 |
| 중요한 주인공 연속 발언 | .14 | .18 | 다른 인물 발언 |

읽는 시간을 재는 2.4초 복귀 타이머를 제거. 동일 발언 블록에서 gain을 반복 설정하지 않음. 사용자 mixer volume/mute를 변경하지 않음. 취소·로드·스킵·예외 처리에서 정적을 해제하고 씬 종료 시 기존 채널 상태 복원.

핵심 타격은 현재 **무음**. 1회 큐 실행 제어만 있으며 `R13_C2_TABLE_IMPACT=None`. 거절된 책상 소리, 미선택 총성, 심장음, 휙 소리를 연결하지 않음. 승인된 웅성 OGG는 전달 커밋 `33f5e0a971bc81e5af0201f0d72aa1156cc69248`의 지정 파일과 SOURCE.md만 가져와 C2 환경음에 연결. 다른 회의의 fire/wind는 유지. [출처·CC0 크레딧](../../experiments/renpy-ch1/art/council-murmur-20261018/SOURCE.md). 원본 171520 bytes / SHA256 `895d98976a1cb306b8121d17f2b7f4881662d58512f05499d3a6f46f35298d31` 일치. 기존 환경음 재생 함수의 relative_volume .55와 위 채널 gain, 사용자 효과음 mixer가 함께 적용됨.

영상은 실제 C2 E09 제시·반론 답변 흐름이며 읽기 6초 초과 정적, 동일 설명 다음 페이지 정적, 부리 반응 복귀, 아빠 연속 답변 duck, 뿔이 답변 복귀를 확인. 사용자 음악 .37 / 효과음 .26 설정 보존. 실제 자료 취소·저장 로드·Ctrl 스킵 확인. 예외는 핸들러 호출, 씬 종료는 정리 함수 경로 호출로 검증하며 실제 충돌이나 캠페인 전체 종료 시험은 아님.

기존 일반 PageUp의 이중 체크포인트 UX는 이번 변경 범위에서 수정하지 않음. 휙 소리 비교 및 새 충격음 선택은 보류. main의 이후 변경은 실제 병합 승인 시 재대조 필요.
