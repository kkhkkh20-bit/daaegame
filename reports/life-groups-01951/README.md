# 0.19.51 생활 그룹 검토

최신 main 0.19.50 UI를 보존하여 통합. 승인 원본은 변경하지 않았다. 학교 세 아이 직접 클릭은 자기 첫 응답+기존 4줄로 이어지고 별도 그룹 버튼은 없다. 개인 사건/강제 장면 우선순위와 날짜·생활 조건을 유지했다. 여관 토리 간격과 학교 하단 여백을 조정했다.

실제 SDK 브라우저에서 세 장면 fixture로 7명 얼굴 클릭, 투명부 클릭 제외, 이름표/그룹 버튼 간섭, 데스크톱·터치 대화 취소 후 상태 보존, 세 아이 각각의 5줄 전체 진행 후 상태 보존을 확인했다. runtime.json에 결과가 있다. 자동 검사와 Ren’Py lint 통과. 7개 전송 파트와 조립 ZIP 해시·CRC 확인.
