# 통과 인물만 잔상 — 제한된 비교 후보

최신 사용자 방향에 따라 이 작은 수정만 마무리한다. 다른 레퍼런스/시각 효과 확대, 새 ‘잠깐!’ 문구, 외침, 미선택 금속성 효과음은 추가하지 않았다. 기본 비활성 검토 브랜치에 보존하며 main 배포 없음. 기존 음악만 유지, 새 음성 미적용.

## 실제 인물 및 기존 비교기 정정

현재 그림의 가운데 할아버지는 `resident_ppul` / 뿔이 촌장이다. 최초 중앙 뿔이 화면의 오른쪽 부엉이 인물은 `buri` / 부리, 왼쪽 여우는 `seryeon` / 세련이다. 이전 비교에서 `dad`는 POV라 좌석에 없었고, 존재하지 않는 초점을 요청해 좌석 0인 세련 화면으로 대체됐다. 그래서 이전 영상의 아빠 대사 이름을 화면 속 여우의 실제 ID라고 해석하면 안 된다. `previous-cast.json`은 같은 기존 fixture에서 얻은 런타임 좌석/화면 위치 근거다. 검은 모자의 인물은 `resident_seori` / 서리 검사원이다.

이번 D는 **세련(좌석 0) → 부리(좌석 2) → 세련(좌석 0)** 시점을 명시한다. 양쪽 사이의 좌석 1인 뿔이만 지나가는 인물이다. 대사도 기존 아빠 이름과 잘못 대응시키지 않도록, 승인된 `R13_DIALOGUE_BEATS["lines"]["trial:opening"]`의 세련·부리 도입 대사를 참조한다. 마지막 세련 대사 반복은 반대 방향 비교용이다. 이전 C2 s1/broken 대사와 동일한 텍스트라고 주장하지 않는다. 같은 재판 회의장/승인 그림을 사용하며 실제 이야기·주장·증거 데이터는 수정하지 않았다. 영상 촬영 뒤 동일 대사 문자열을 이 승인 registry 참조로 정리했으며 텍스트 내용과 효과 렌더 코드는 동일하다.

## 변경 범위

`R13MeetingOrbit`의 기존 배경/인물/탁자 합성을 검토용 레이어 선택으로 나눴다. 옵션을 주지 않는 정상 플레이는 기존 세 요소를 모두 그린다. D에서만 배경+일반 인물, 통과 인물, 통과 인물의 두 시간차 잔상, 도착 인물, 탁자 순으로 합성한다. 인물 투명 알파 레이어를 사용하며 사각형 영역을 흐리는 방식이 아니다.

도착 인물은 잔상 소스에서 제외하고 마지막 인물 레이어에 선명하게 한 번 그린다. 두 잔상의 소스 ID는 모두 `resident_ppul`뿐이다. 지연은 .055/.11초, 시작 alpha .26/.15와 blur 3/6px. 시점은 0.34초 보간하고 종료 시 settled 원본 장면만 반환한다. UI/이름/대사는 장면 위에서 한 번만 그린다. 이전 장면 전체 복제와 반복 스트립은 이 후보에서 제거했다.

좌석 순서의 최단 경로에서 양 끝을 제외한 인물을 계산한다. 특정 x좌표나 왼쪽/오른쪽 인물 ID를 하드코딩하지 않는다. 양방향 및 경계 순환의 경로 계산을 확인했다. 각 전환은 독립 객체이고 잔상 합성 결과를 다음 소스로 누적하지 않는다. motion 끔/스킵/롤백에서는 settled 장면으로 바로 간다.

## 검수와 한계

- SDK 8.5.3 실제 Web 녹화: H.264/AAC 48kHz, 10.495초. 평균 -41.8dB / 최대 -22.6dB로 기존 음악 캡처 확인.
- `checks.json`: 첫 도착 `buri`, 반대 방향 도착 `seryeon`; 두 방향 passing은 `resident_ppul` 하나.
- 실제 마우스 클릭 두 번을 약 0.118초 안에 전달, 최종 phase 2 확인. 빠른 클릭 후 정착 화면과 일반 정착 화면의 RGB 픽셀 차이 0.
- 일반 정착 후 클릭 전후 차이 0. 동작 끔 화면과 같은 시점의 효과 종료 화면 차이 0. `verification.json`과 PNG 근거 보존.
- 단위 검사 및 SDK lint 통과(`check.log`). 공식 Web 빌드 part/아카이브 SHA256, ZIP CRC 통과(`build-validation.json`).
- 기존 자동 진행 fixture에 별도 수동 클릭 검수 모드를 추가했으며 기본은 꺼져 있다. 제품 플레이 전체의 클릭/로드 회귀까지 검증한 것은 아니다.
- 렌더 빈도의 병목과 녹화 환경 영향을 분리하지 않았다. 레이어 합성 비용이 늘 수 있으며 성능 개선으로 설명하지 않는다. 레퍼런스 원본이나 외부 음성 파일은 추가하지 않았다.
