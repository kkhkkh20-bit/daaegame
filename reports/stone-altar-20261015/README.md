# 공용 돌 제단 — 맵 아트

주민들이 평소에도 알고 제사 지내는 장소. 고대문명 유적과 가깝고 석조 양식이 이어지지만 비밀 입구나 지하 발견 이벤트를 이 그림으로 확정하지 않는다.

중앙 제의석·제물 놓는 돌상·붉은 천·오른쪽 관리 물품 보관소·왼쪽 진입 계단을 둔다. 큰 색면과 굵은 도트로 첫 시안의 표면 잔무늬를 줄였다.

PNG 원본과 웹용 WebP를 동봉한다. **본편 배경 교체 전 아트 자산**이며 아직 게임에 연결하지 않았다. 기존 altar 장소에는 밸브·관리 장부·장작/통·마을 전망·작업길 등의 조사가 있으므로 이 그림을 그대로 덮어쓰면 조사 좌표와 내용이 어긋난다. 구현 시 해당 조사물의 전경 레이어/배치와 클릭 영역을 함께 맞춰야 한다. 기존 조사 내용·분기·발견 조건은 임의로 지우지 않는다.
