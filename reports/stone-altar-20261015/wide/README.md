# 돌 제단 · 가로 확장본

승인한 색감·제단·석조 아치 디자인을 바탕으로 좌우 공간을 확장했다.

- 원본 2172×724, 가로 3:1.
- 게임 논리 크기 2160×720, 표시 화면 1280×720, 카메라 범위 x=0~880.
- 왼쪽: 진입 계단, 관리 작업대, 장작과 통. 중앙: 제단과 제물. 오른쪽: 관리 물품 보관소, 돌길과 마을 전망.
- 마우스·터치 드래그로 둘러보며, 좌우 이동 버튼은 추가하지 않는다.
- 주민들이 아는 공용 제의 공간이며 가까운 고대 유적과 석조 양식이 이어진다. 숨은 통로 발견이나 새 사건을 이 그림으로 확정하지 않는다.

**본편 연결 전 그림 파일이다.** 기존 altar 장소의 조사 조건을 보존하고 새 위치에 맞게 클릭 영역·인물 서 있는 위치를 조정해야 한다. 기존 관/밸브 조사에 맞는 전경 소품도 필요하므로 배경 파일만 교체하지 않는다. PNG 원본·WebP·배치 기준 JSON을 동봉했다.
