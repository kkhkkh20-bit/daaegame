# UI 통일 시안 — 장면이 먼저, UI는 가볍게

목적: 조작 시연의 큰 탭·아래 설명판을 그대로 본편에 붙이지 않고, 실제 게임 배경·인물·아이콘과 어울리는 화면 규칙을 정한다. **시각/전환 검토용 웹 시안이며 본편의 화면 파일이나 게임 규칙을 수정하지 않았다.**

## 현재 UI에 대한 판단

숲색·크림색·금색과 도트 배경은 게임의 정체성에 맞는다. 그러나 큰 패널과 두꺼운 테두리를 모든 화면에 반복하면 확대 조사에서 관찰 대상보다 UI가 먼저 보인다. 대화·선택·기록이 각각 다른 앱처럼 보이는 것도 줄여야 한다. UI 크기를 일괄 축소하는 대신 화면별 읽을거리 양에 따라 공간을 배분한다.

## 공통 규칙

- 기준 화면 1280×720. 위치는 게임 캔버스에 상대적으로 잡는다. 바깥 시안 전환 탭은 본편 UI가 아니다.
- 기본 문자 Regular. Galmuri11은 별도 Medium/Thin이 없는 픽셀 폰트이므로 가짜 Bold/Light를 만들지 않는다. 픽셀 메뉴는 크기·대비·색으로 위계를 만든다. 여러 실제 굵기가 필요한 장문 설명에는 본편의 한국어 본문 글꼴을 사용한다. 자동 Italic은 사용하지 않는다.
- 기본 패딩 단위 4px. 아이콘 버튼 8px, 도구/일반 버튼 가로12px·세로8px, 관찰문 16px, 대화문 가로32px·세로20px, 카드 본문24px. 모바일은 8/12/16px 단계로 줄인다. 같은 역할을 바꾸면 세 화면에 함께 적용한다.
- 숲색 `#193a35`, 글자 크림 `#f6edd9`, 포인트 금색 `#d1b77b`, 기록 종이 `#efe7d2`. 금색은 선택·이름·주요 상태에 제한한다. 모든 글자를 강조색으로 만들지 않는다.
- 프레임은 전체 외곽 1px 또는 짧은 좌측 포인트만. 크고 밝은 두꺼운 박스를 반복하지 않는다.
- 장소/시각은 좌측 상단 작은 두 줄. 옵션은 우측 상단 아이콘. 조사·제시·기록은 하단의 같은 위치. 대화 기록·자동은 대화 중에만 작은 보조 버튼으로 표시한다.
- 배경은 추가 블러·노이즈 없이 그대로 사용한다. 밝은 배경 위 글자는 각 텍스트 영역에 국소적인 어두운 면을 줘 읽힌다. 화면 전체를 항상 어둡게 하지 않는다.

## 조사

- 확대 그림을 캔버스 전체에 표시한다. 위쪽 큰 모드 탭과 바깥 설명 패널은 제거한다.
- 돌아가기는 우측 상단에 항상 보인다. 확대 화면의 “현장으로”는 장소를 이동하는 버튼과 구분한다.
- 도구는 왼쪽 아래 작은 트레이. 현재 사용 중인 도구에만 얇은 밑줄과 색을 준다. 소지하지 않은 도구나 현재 의미 없는 도구를 모두 늘어놓지 않는다.
- 관찰문은 도구 옆 짧은 반투명 박스. 아빠 이름은 왼쪽. 설명이 길면 기존 대화 표시로 전환하고 관찰문 박스를 계속 키우지 않는다.
- 클릭 가능 위치는 전체 상시 체크 표시 대신 hover/키보드 포커스 때 짧은 테두리와 이름을 표시한다. 실제 클릭 피드백은 본편 기존 이펙트를 연결한다. 중요한 획득과 단순 관찰의 연출은 구분한다.
- 시안에서는 쪽지 클릭 → 기록 카드에서 읽기 → 닫을 때 좌측 상단 획득 표시. 본편은 실제 읽기/증거 등록 완료 이벤트에 연결하고 중복 재생하지 않는다. 이 UI 시안에는 새 효과음 파일을 만들지 않았다.

## 대화 / 질문

- 같은 인물 이미지를 대화·질문 양쪽에서 같은 중앙 좌표와 크기로 유지한다. 질문을 열었다고 왼쪽으로 이동시키지 않는다. 시안은 실제 까로 풀바디를 재사용했다.
- 대화창 좌우 7% 여백, 아래쪽 약20% 높이. 이름표는 창의 왼쪽 위. 본문은 왼쪽 정렬하며 본문 프레임 전체는 가운데 놓는다. 아빠 별도 프로필은 없다.
- 질문은 화면의 가로/세로 중앙에 폭 약38%의 세로 목록. 배경만 잠깐 어둡게 한다. 얼굴을 가리는 것은 허용하되 인물을 재배치하지 않는다.
- 물어본 질문은 2px 취소선 + 흐린 색으로 함께 구분한다. 다시 읽을 수 있으므로 무조건 비활성화하지 않는다.
- 돌아가기/ESC로 질문을 닫는다. 인물 클릭·Enter/Space로 다시 연다. 문장들은 화면 시안용 샘플이며 본편 대사를 일괄 교체하는 지시가 아니다.
- 자동 진행은 대화문 사이에서만 가능. 질문·기록·옵션을 열면 정지한다. 시안은 3.2초 간격의 표시 예제이며 본편에서는 타이핑/음성 완료 뒤의 대기 시간을 기준으로 한다. 선택지를 자동으로 고르지 않는다.

## 기록 / 제시

- 기록 모달은 숲색 제목줄 + 크림색 내용. 왼쪽 큰 물건 그림, 오른쪽 이름·설명·발견 장소. 선택 위치가 바뀌어도 설명 영역이 움직이지 않는다.
- 아래 아이콘은 6열이며 자료가 많아지면 두 줄로 배치한다. 본편은 페이지/스크롤로 자료가 늘어나도 같은 크기와 위치를 유지한다. 실제 보유 자료만 표시하고 빈 슬롯을 잠긴 증거처럼 늘어놓지 않는다.
- 증거·증언·인물을 각각 탭으로 분리한다. 모든 대사를 증언으로 등록하지 않고 본편에서 중요한 발언으로 분류한 기록만 증언에 넣는다. 만난 사람은 본편의 실제 만남 플래그를 사용한다.
- 제시는 기록 카드 구조를 재사용하고 하단에 대상 이름이 있는 “까로에게 제시”를 표시한다. 일반 열람과 제시가 같은 버튼으로 오인되지 않게 한다. 대상 없는 상태의 제시는 비활성화하거나 숨긴다.
- 설명에는 사실과 출처를 먼저 적고 다음 정답·추천 상대·추리 결론을 자동으로 붙이지 않는다. “사건 유무죄와 별개” 같은 공통 면책문을 반복하지 않는다.
- 기존 아이콘 시트를 CSS로 표시했다. M02 및 탁본의 전용 아이콘이 없는 부분은 편지/두루마리 공통 아이콘을 사용한 시안이다. 실제 물건의 외형을 확정하는 새 설정이 아니다.

## 본편 연결과 범위

`ROOM13_GUIDE.md`와 최신 UI/분기 문서를 먼저 읽고 기존 화면 시스템에 스타일을 옮긴다. JS를 Ren'Py에 끼우거나 새 함수 덮어쓰기 층을 추가하는 지시가 아니다. 저장·불러오기·이동 지도·재판/CG에는 각 상태에 맞는 기존 화면을 사용한다. CG나 마차 장면에 조사 도구를 표시하지 않는다.

시안은 과거에 획득한 자료를 함께 표시하는 전시 상태다. 13호실은 5일째 저녁, 까로 대화는 1일째 오후를 각각 보여 주며 이어지는 플레이 순서가 아니다. 자료의 실제 해금·엄마 쪽지의 발견 시점·도구 보유 여부는 본편 조건이 우선이다. 자료의 일부 설명은 레이아웃 확인을 위한 요약/생략이다.

브라우저에서 조사→기록, 자료/인물 전환, 대화→질문 시 인물 좌표 유지, 취소선, 제시 선택, 백로그, 자동 정지, ESC 닫기, 844px 표시, 큰 글자 옵션을 확인했다. 본편 세이브·롤백·14일 진행은 검사하지 않았다.

`previews/`는 실제 브라우저에서 캡처한 시안이다. ZIP은 필요한 기존 그림과 글꼴을 포함하여 독립 실행할 수 있다. 네트워크 없이 검토할 때는 ZIP을 풀고 HTTP 서버로 연다. Galmuri 글꼴 라이선스도 동봉했다.

## 04차 다듬기

- 기록 카드를 화면 높이 74%로 고정하지 않고 내용에 맞게 줄였다. 물건 그림은 늘어지지 않는 정사각형 영역, 본문과 발견 장소는 고정된 위계로 정렬했다.
- 실제 자료 6개만 보여 주고 빈 칸 6개는 제거했다. 자료가 늘면 같은 크기로 다음 줄을 사용한다.
- 자료와 인물 탭에서 마지막으로 본 항목을 각각 기억한다. 단, 쪽지를 클릭했을 때는 그 쪽지를 정확히 연다.
- 자료 클릭 뒤에도 키보드 포커스를 유지한다. 방향키와 Home/End로 항목을 고를 수 있다.
- 첫 열람을 닫은 뒤 획득 표시를 한 번만 보여 준다. 반복 열람에는 획득 표시를 재생하지 않는다.
- 중앙 하단 버튼 위치는 조사·대화에서 동일하다. 아주 좁은 화면에서는 대화 기록/자동을 위쪽 보조 줄로 옮겨 겹치지 않게 한다.
- 기본/선택/호버/물어본 질문의 색과 테두리를 구분했다. 인물을 흔들거나 이동시키는 효과는 넣지 않았다. 패널 전환만 0.12~0.18초로 제한하고 모션 감소 설정에서는 생략한다.
- 844px·560px 화면과 큰 글자 설정을 추가 확인했다. 본편은 여전히 변경하지 않았다.

작은 발견 장소·분류·보조 문구는 종이 바탕 대비를 4.69:1로 맞췄다. 크기를 줄였다고 밝고 흐린 색을 함께 사용하지 않는다.

## 05차 — 실제 정보량을 반영한 숙소 HUD

기본 시작 화면을 확대 조사에서 다람이가 있는 13호실 현장으로 바꿨다. 앞선 UI 시안의 3개 기능만 전시하던 화면에서 날짜·시간·장소·소지금·바로 이동·지도·옵션을 모두 표시한다. 이 화면 역시 본편 적용 전 독립 시안이다.

- 상시: 좌측의 날짜/시간, 장소, 소지금 작은 세 줄. 우측은 연결 장소 버튼, 지도 아이콘, 옵션 아이콘. 아래는 조사·제시·기록. 별도의 일거리/상점 큰 박스를 두지 않는다.
- `복도로`는 지도 없이 즉시 이동하고 복도에서는 `13호실`로 돌아올 수 있다. 다른 장소에서는 연결 장소를 실제 데이터에 맞춰 표시한다.
- 지도는 여관 안에서 열면 여관 장소부터 보여 준다. `여관 밖으로`를 누르면 마을 목록으로 전환한다. 상단 마을 탭으로 먼저 건너뛰지 못하게 했다. 본편은 실제 월드맵을 이 단계에서 연결한다. 시안의 목록은 기존 지도 자체를 삭제하거나 교체하는 지시가 아니다.
- 이동 패널 하단에서 일거리·상점을 연다. 일을 고르면 상세 화면에 `오전 사용 → 오후 · 보수`를 표시하고 선택할 수 있다. 직업 목록에서는 보수만 간단히 보인다.
- 보수 6/7/8냥 및 상점 구운 밤 2냥·그림엽서 3냥·묶음끈 3냥은 확인한 `systems/room13_livelihood_model.rpy`의 현재 값이다. 경제 밸런스 변경 제안이 아니다. 적용 시 최신 런타임 값을 가져온다.
- 시안의 소지금은 0냥으로 고정했다. 상점에는 가격과 부족액을 표시하고 구매를 비활성화한다. 일 선택은 장소 전환만 시연하며 돈 지급·시간 소비·일 완료를 실행하지 않는다.
- 방 설명은 첫 진입 시 짧은 아빠 독백으로 표시하고 약6.5초 뒤 닫는다. 직접 닫을 수도 있다. 같은 시연 세션에서는 다시 강제로 보여 주지 않으며 내용은 대화 기록에 남긴다. 본편은 텍스트 속도/자동 진행 설정에 맞춰 읽기 시간을 조절하고 재열람을 보장한다.
- 다람이는 숙소에 배치했다. 이름표는 hover/포커스 때만 표시하고 클릭하면 중앙 대화 화면으로 이어진다. 아빠가 말할 때도 아빠 프로필을 추가하지 않는다. 짧은 대사는 UI 전환 확인용이며 기존 스토리 대사 교체 지시가 아니다.
- 침대 밑 확대 시안은 상단 바깥의 `확대 조사` 탭으로 따로 확인한다. 현장의 책상은 일반 관찰만 보여 주고, 초반 편지를 눌렀다는 이유로 후반 M02를 지급하지 않는다. 자료창은 기존과 같은 전시 데이터이며 본편 획득 상태를 뜻하지 않는다.
- '시간 소모 없음'은 현장에 상시 쓰지 않는다. 본편에서 실제 비용이 드는 선택, 밤·잠자기·일의 시간 조건은 실행 전에 명확히 표시한다.

추가 확인: 숙소 정보, 다람이 대화, 복도 직접 왕복, 여관 지도 우선, 여관 밖으로 전환, 일 상세 비용, 잔액 부족 구매 비활성화, 방 설명의 대화 기록 보관, 844px·560px 이동 패널 범위. 본편 14일 진행이나 재판 분기는 검사하지 않았다.

## 06차 — 제시한 자료를 보며 이어가는 대화

기록 탭을 `증거 / 증언 / 인물`로 나눴다. 대화 기록은 별도 백로그 버튼을 유지한다. 제시는 기록 선택만 알리는 임시 토스트 대신 **현재 대화에서 참조 중인 자료**를 유지하는 상태로 바꿨다.

1. 대화 중 제시 → 증거 또는 증언 선택 → 대상 이름이 있는 제시 버튼.
2. 기록창이 닫히고 좌측 상단에 자료 카드가 짧게 들어온다. 중앙 대화 상대의 좌표와 크기는 바뀌지 않는다.
3. 증거는 그림+이름, 증언은 발언자 얼굴+제목+핵심 발언을 보여 준다. 아래 대화창에서 아빠와 상대의 말이 이어진다. 대사 한 줄이 끝났다고 자료 카드를 숨기지 않는다.
4. `»` 또는 대사 본문을 눌러 반응을 이어 읽는다. 시안은 3줄 반응 뒤 질문 목록으로 돌아가며 자료 카드를 닫는다. 새 자료를 제시하면 교체하고, 현장/새 주제로 이동하면 해제한다. 카드의 닫기 버튼으로 해당 주제를 마칠 수도 있다.
5. 기록을 잠깐 열었다가 취소해도 진행 중인 제시 주제와 카드는 유지한다. 제시 재선택을 취소했다고 현재 자료를 없애지 않는다.

획득 토스트와 제시 카드는 별개다. 제시 시 획득·인벤토리 등록을 다시 실행하지 않는다. 실물 증거를 소모하거나 증언을 새 증거로 승격하지 않는다. 본편에서는 기존 제시 결과 라벨/대화 분기 시작·종료 지점에 이 카드의 수명을 연결한다. 화면에 자료가 떠 있다는 사실 자체가 옳은 제시나 새로운 단서 획득을 뜻하지 않는다. 재판과 일반 대화의 제시 규칙은 각각 기존대로 유지한다.

증언 샘플 2개는 **현재 UI 시안에서 나온 까로/다람이 대사를 재사용한 전시 자료**다. 새 필수 증언 ID나 증언 연결 퍼즐을 추가하는 지시가 아니다. 시안 반응 역시 ‘같이 읽어 본다’ 수준의 화면 확인용 문장이며 실제 인물의 지식·알리바이·증거 판정을 바꾸지 않는다. 클로드는 실제 제시 분기를 그대로 연결한다.

얼굴은 기존 `room13-avatars.json`의 중립 프로필에 해당하는 원본 시트 첫 칸을 표시했다. 그림 파일을 다시 생성/편집하지 않았다. 제시된 자료 카드에 발언자 얼굴을 표시하는 것이며 아빠 프로필을 기본 대화창에 복원하지 않는다.

제시 순간에만 0.16초 ‘휙’ 소리를 WebAudio로 합성한다. 페이지 로딩이나 다음 대사마다 재생하지 않는다. 옵션에서 효과음을 끌 수 있다. 본편에서는 기존 제시 효과음과 사용자 음량/음소거 설정을 재사용하는 편이 좋다. 새 오디오 파일은 동봉하지 않았다. 모션 감소 설정에서는 카드 이동 효과를 생략한다.

추가 확인: 증거·증언 카드 유지, 대사 진행, 기록 취소 뒤 유지, 다른 자료 교체, 인물 위치 불변, 주제 종료 해제, 조사 복귀, 다람이 대상 반응, 효과음 끄기, 844px·560px에서 대화창과 카드 비중첩. 본편 대결·저장·롤백은 이번에 실행하지 않았다.

## 07차 — 클래식 도트 스킨

동작, 정보 구조, 제시 자료의 수명, NPC 위치는 그대로 유지하고 시각 스타일을 별도 `pixel-theme.css`로 분리했다. HTML에서 `style.css` 다음에 불러온다. 시안 바깥 하단의 **기존 디자인과 비교** 버튼으로 스킨만 켜고 끌 수 있다. 대화와 제시 상태는 초기화되지 않는다.

- 흐린 외곽 그림자 대신 2~4px의 단단한 그림자. 큰 창은 3단 계단 모서리와 황동색 두 겹 테두리를 사용한다.
- 유리 같은 반투명 면을 줄이고 짙은 녹색 창을 사용한다. 지도·기록을 열 때만 배경을 어둡게 한다. 평상시 전체 장면에 어두운 그라데이션을 덮지 않는다.
- 기록은 잡티 없는 양피지색. 종이 질감 노이즈·그레인·랜덤 픽셀을 추가하지 않는다. 도트 배경의 밀도와 UI 글자의 가독성을 유지한다.
- 아이콘 슬롯과 탭은 위/왼쪽 밝음, 아래/오른쪽 어두움의 단순한 픽셀 명암. 선택 상태만 금색으로 강조한다.
- 본문·메뉴·이름·보조 정보에 Galmuri11 Regular를 사용한다. 가짜 굵기·이탤릭·흐림 효과를 넣지 않는다. 한글을 장식용 이미지에 구워 넣지 않는다.
- 하단 조사·제시·기록의 작은 배치와 대화창 범위를 유지한다. 클래식하게 만든다는 이유로 화면 전체를 굵은 프레임으로 둘러싸지 않는다.
- 창의 긴 페이드 효과는 없앴고 제시 카드/획득 표시의 짧은 등장만 3~4단계로 처리한다. 모션 감소 설정에서는 이동을 생략한다.

### 재사용 가능한 프레임

`frames/window.svg` / `frames/paper.svg`는 48×48 정수 좌표의 9분할 프레임이다. `shape-rendering=crispEdges`, slice=12. 배경과 외곽을 같이 담고 있으며 중심은 단색이다. SVG를 코드로 작성하고 브라우저에서 투명 PNG로 동일 크기 렌더링했다. 기존 게임 그림을 필터링하거나 수정한 파일이 아니다.

`frames/window.png`, `frames/paper.png`도 제공한다. Ren'Py에서는 기존 프레임 표시 경로에 `Frame(...,12,12,12,12)` 형태로 옮기고 nearest 표시를 사용한다. 작은 HUD는 본편의 UI 배율/테두리 단위에 맞춰 모서리와 글자 패딩을 함께 맞춘다. 창의 전체 크기에 맞춰 PNG를 통째로 늘려 모서리까지 늘어나게 만들지 않는다.

시안 PNG/SVG는 창 스킨 소재이고 실제 배경·캐릭터는 재생성하지 않았다. `style.css`는 기존 배치, `pixel-theme.css`는 시각 스킨으로 유지해 클로드가 승인된 화면 동작을 다시 만들지 않아도 된다. 본편 적용은 아직 하지 않았다.

확인: 숙소·연결 이동·돈/일거리 UI, 세 기록 탭, 제시 자료 유지/교체/해제, 인물 위치 불변, 효과음 설정, 844px·560px의 카드/대화창 비중첩, 스킨 비교 후 제시 상태 유지.

## 08차 — 배경이 비치는 창과 닳은 황동 마감

모든 창을 같은 불투명도로 만들지 않는다. **글자와 테두리를 흐리는 것이 아니라 창의 안쪽 면만** 반투명하게 한다. 기존 SVG의 불투명한 외곽 면이 중심 아래 남지 않도록 마스크로 중심을 비우고 별도 알파 면을 넣었다.

| 종류 | 안쪽 면 불투명도 | 프레임 파일 |
|---|---:|---|
| 대화창 기본 | 88% | `frames/dialogue.svg/.png` |
| 날짜·장소·이동 버튼·짧은 관찰문 | 86% | `frames/hud.svg/.png` |
| 제시 카드·이동 패널·옵션·진한 대화창 | 96% | `frames/aged-window.svg/.png` |
| 기록의 양피지 카드 | 100% | `frames/aged-paper.svg/.png` |

옵션의 ‘대화창 배경 → 진하게’가 클래식 스킨에서도 작동한다. 자동으로 더 투명해지거나 글자가 함께 흐려지는 기능은 없다. 배경의 형태는 조금 보이되 복잡한 장면에서 읽기 어렵다면 진한 창을 사용한다. 중요한 인물 얼굴·물건·출입구를 가리는 문제는 창의 면적과 위치로도 확인해야 하며 투명도만으로 해결된다고 보지 않는다. 본편에서 실제 카메라/출입구 좌표를 반영한다.

금박은 밝은 흰색 반사선을 줄이고 `#9e8658` 황동색, `#c5ac78` 남은 금박, `#6e5e40` 어두워진 마감으로 나눴다. 모서리의 2~4px 부분에만 닳은 금박과 탁한 녹색 변색을 넣었다. 무작위 잡티·반복되는 녹 텍스처·잔노이즈는 없다. 대부분의 장식은 9분할 모서리 안에 있어 창을 넓혀도 마모 무늬가 긴 줄처럼 늘어나지 않는다.

이전 `window` / `paper` 프레임도 참고용으로 남겼다. 최신 스킨의 기본 파일은 **aged-window / aged-paper / dialogue / hud** 네 종류다. PNG도 동일한 48×48, slice12, 투명 배경으로 내보냈다. 중앙 픽셀 알파는 각각 약245/255/224/219이며 모서리 밖은0, 금박 부분은255다.

Ren'Py에 옮길 때는 반투명 PNG 뒤에 불투명한 Solid를 덧대지 않는다. 전체 프레임의 alpha를 줄이면 금박과 글자까지 흐려지므로 각 소재의 중앙 알파를 유지한다. 버튼 명암과 탭 색도 새 금박 톤에 맞췄다. 종이는 잡티 없는 단색을 유지하고 메타데이터 대비를 확보했다.

확인: 창 종류별 프레임 선택과 PNG 알파, 진한 대화창 옵션, 디자인 비교 뒤 제시 상태 유지, 844px·560px에서 제시 카드/대화창 비중첩, 자바스크립트 오류 없음. 본편은 변경하지 않았다.
