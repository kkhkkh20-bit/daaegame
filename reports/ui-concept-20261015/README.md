# UI 통일 시안 — 장면이 먼저, UI는 가볍게

목적: 조작 시연의 큰 탭·아래 설명판을 그대로 본편에 붙이지 않고, 실제 게임 배경·인물·아이콘과 어울리는 화면 규칙을 정한다. **시각/전환 검토용 웹 시안이며 본편의 화면 파일이나 게임 규칙을 수정하지 않았다.**

## 현재 UI에 대한 판단

숲색·크림색·금색과 도트 배경은 게임의 정체성에 맞는다. 그러나 큰 패널과 두꺼운 테두리를 모든 화면에 반복하면 확대 조사에서 관찰 대상보다 UI가 먼저 보인다. 대화·선택·기록이 각각 다른 앱처럼 보이는 것도 줄여야 한다. UI 크기를 일괄 축소하는 대신 화면별 읽을거리 양에 따라 공간을 배분한다.

## 공통 규칙

- 기준 화면 1280×720. 위치는 게임 캔버스에 상대적으로 잡는다. 바깥 시안 전환 탭은 본편 UI가 아니다.
- 기본 문자 Regular. Galmuri11은 별도 Medium/Thin이 없는 픽셀 폰트이므로 가짜 Bold/Light를 만들지 않는다. 픽셀 메뉴는 크기·대비·색으로 위계를 만든다. 여러 실제 굵기가 필요한 장문 설명에는 본편의 한국어 본문 글꼴을 사용한다. 자동 Italic은 사용하지 않는다.
- 기본 패딩 단위 4px. 아이콘 버튼 8px, 도구/일반 버튼 가로12px·세로8px, 관찰문 16px, 대화문 가로32px·세로20px, 카드 본문24px. 모바일은 8/12/16px 단계로 줄인다. 같은 역할을 바꾸면 세 화면에 함께 적용한다.
- 숲색 `#193a35`, 글자 크림 `#f6edd9`, 포인트 금색 `#d1b77b`, 기록 종이 `#efe7d2`. 금색은 선택·이름·주요 상태에 제한한다. 모든 글자를 강조색으로 만들지 않는다.
- 프레임은 전체 외곽 1px 또는 짧은 좌측 포인트만. 크고 밝은 두꺼운 박스를 반복하지 않는다.
- 장소/시각은 좌측 상단 작은 두 줄. 옵션은 우측 상단 아이콘. 조사·제시·기록은 하단의 같은 위치. 대화 기록·자동은 대화 중에만 작은 보조 버튼으로 표시한다.
- 배경은 추가 블러·노이즈 없이 그대로 사용한다. 밝은 배경 위 글자는 각 텍스트 영역에 국소적인 어두운 면을 줘 읽힌다. 화면 전체를 항상 어둡게 하지 않는다.

## 조사

- 확대 그림을 캔버스 전체에 표시한다. 위쪽 큰 모드 탭과 바깥 설명 패널은 제거한다.
- 돌아가기는 우측 상단에 항상 보인다. 확대 화면의 “현장으로”는 장소를 이동하는 버튼과 구분한다.
- 도구는 왼쪽 아래 작은 트레이. 현재 사용 중인 도구에만 얇은 밑줄과 색을 준다. 소지하지 않은 도구나 현재 의미 없는 도구를 모두 늘어놓지 않는다.
- 관찰문은 도구 옆 짧은 반투명 박스. 아빠 이름은 왼쪽. 설명이 길면 기존 대화 표시로 전환하고 관찰문 박스를 계속 키우지 않는다.
- 클릭 가능 위치는 전체 상시 체크 표시 대신 hover/키보드 포커스 때 짧은 테두리와 이름을 표시한다. 실제 클릭 피드백은 본편 기존 이펙트를 연결한다. 중요한 획득과 단순 관찰의 연출은 구분한다.
- 시안에서는 쪽지 클릭 → 기록 카드에서 읽기 → 닫을 때 좌측 상단 획득 표시. 본편은 실제 읽기/증거 등록 완료 이벤트에 연결하고 중복 재생하지 않는다. 이 UI 시안에는 새 효과음 파일을 만들지 않았다.

## 대화 / 질문

- 같은 인물 이미지를 대화·질문 양쪽에서 같은 중앙 좌표와 크기로 유지한다. 질문을 열었다고 왼쪽으로 이동시키지 않는다. 시안은 실제 까로 풀바디를 재사용했다.
- 대화창 좌우 7% 여백, 아래쪽 약20% 높이. 이름표는 창의 왼쪽 위. 본문은 왼쪽 정렬하며 본문 프레임 전체는 가운데 놓는다. 아빠 별도 프로필은 없다.
- 질문은 화면의 가로/세로 중앙에 폭 약38%의 세로 목록. 배경만 잠깐 어둡게 한다. 얼굴을 가리는 것은 허용하되 인물을 재배치하지 않는다.
- 물어본 질문은 2px 취소선 + 흐린 색으로 함께 구분한다. 다시 읽을 수 있으므로 무조건 비활성화하지 않는다.
- 돌아가기/ESC로 질문을 닫는다. 인물 클릭·Enter/Space로 다시 연다. 문장들은 화면 시안용 샘플이며 본편 대사를 일괄 교체하는 지시가 아니다.
- 자동 진행은 대화문 사이에서만 가능. 질문·기록·옵션을 열면 정지한다. 시안은 3.2초 간격의 표시 예제이며 본편에서는 타이핑/음성 완료 뒤의 대기 시간을 기준으로 한다. 선택지를 자동으로 고르지 않는다.

## 기록 / 제시

- 기록 모달은 숲색 제목줄 + 크림색 내용. 왼쪽 큰 물건 그림, 오른쪽 이름·설명·발견 장소. 선택 위치가 바뀌어도 설명 영역이 움직이지 않는다.
- 아래 아이콘은 6열이며 자료가 많아지면 두 줄로 배치한다. 본편은 페이지/스크롤로 자료가 늘어나도 같은 크기와 위치를 유지한다. 실제 보유 자료만 표시하고 빈 슬롯을 잠긴 증거처럼 늘어놓지 않는다.
- 자료와 인물을 분리한다. 증언이 많은 실제 게임에서는 자료 안에 물증/증언 필터를 기존 분류에 맞춰 추가하되 상단 탭을 과하게 늘리지 않는다. 만난 사람은 본편의 실제 만남 플래그를 사용한다.
- 제시는 기록 카드 구조를 재사용하고 하단에 대상 이름이 있는 “까로에게 제시”를 표시한다. 일반 열람과 제시가 같은 버튼으로 오인되지 않게 한다. 대상 없는 상태의 제시는 비활성화하거나 숨긴다.
- 설명에는 사실과 출처를 먼저 적고 다음 정답·추천 상대·추리 결론을 자동으로 붙이지 않는다. “사건 유무죄와 별개” 같은 공통 면책문을 반복하지 않는다.
- 기존 아이콘 시트를 CSS로 표시했다. M02 및 탁본의 전용 아이콘이 없는 부분은 편지/두루마리 공통 아이콘을 사용한 시안이다. 실제 물건의 외형을 확정하는 새 설정이 아니다.

## 본편 연결과 범위

`ROOM13_GUIDE.md`와 최신 UI/분기 문서를 먼저 읽고 기존 화면 시스템에 스타일을 옮긴다. JS를 Ren'Py에 끼우거나 새 함수 덮어쓰기 층을 추가하는 지시가 아니다. 저장·불러오기·이동 지도·재판/CG에는 각 상태에 맞는 기존 화면을 사용한다. CG나 마차 장면에 조사 도구를 표시하지 않는다.

시안은 과거에 획득한 자료를 함께 표시하는 전시 상태다. 13호실은 5일째 저녁, 까로 대화는 1일째 오후를 각각 보여 주며 이어지는 플레이 순서가 아니다. 자료의 실제 해금·엄마 쪽지의 발견 시점·도구 보유 여부는 본편 조건이 우선이다. 자료의 일부 설명은 레이아웃 확인을 위한 요약/생략이다.

브라우저에서 조사→기록, 자료/인물 전환, 대화→질문 시 인물 좌표 유지, 취소선, 제시 선택, 백로그, 자동 정지, ESC 닫기, 844px 표시, 큰 글자 옵션을 확인했다. 본편 세이브·롤백·14일 진행은 검사하지 않았다.

`previews/`는 실제 브라우저에서 캡처한 시안이다. ZIP은 필요한 기존 그림과 글꼴을 포함하여 독립 실행할 수 있다. 네트워크 없이 검토할 때는 ZIP을 풀고 HTTP 서버로 연다. Galmuri 글꼴 라이선스도 동봉했다.

## 04차 다듬기

- 기록 카드를 화면 높이 74%로 고정하지 않고 내용에 맞게 줄였다. 물건 그림은 늘어지지 않는 정사각형 영역, 본문과 발견 장소는 고정된 위계로 정렬했다.
- 실제 자료 6개만 보여 주고 빈 칸 6개는 제거했다. 자료가 늘면 같은 크기로 다음 줄을 사용한다.
- 자료와 인물 탭에서 마지막으로 본 항목을 각각 기억한다. 단, 쪽지를 클릭했을 때는 그 쪽지를 정확히 연다.
- 자료 클릭 뒤에도 키보드 포커스를 유지한다. 방향키와 Home/End로 항목을 고를 수 있다.
- 첫 열람을 닫은 뒤 획득 표시를 한 번만 보여 준다. 반복 열람에는 획득 표시를 재생하지 않는다.
- 중앙 하단 버튼 위치는 조사·대화에서 동일하다. 아주 좁은 화면에서는 대화 기록/자동을 위쪽 보조 줄로 옮겨 겹치지 않게 한다.
- 기본/선택/호버/물어본 질문의 색과 테두리를 구분했다. 인물을 흔들거나 이동시키는 효과는 넣지 않았다. 패널 전환만 0.12~0.18초로 제한하고 모션 감소 설정에서는 생략한다.
- 844px·560px 화면과 큰 글자 설정을 추가 확인했다. 본편은 여전히 변경하지 않았다.
