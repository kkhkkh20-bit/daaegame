# C2 실제 흐름 — 청자 반응과 지속 대립

검토 브랜치 전용. main 머지/운영 배포 전 보고용입니다.

C2 실제 `r13_lines` 방향 지정과 `r13_meeting_stage`에 연결했습니다. 대본/증거/분기/화자 순서는 바꾸지 않았습니다. 일반 대사는 발언자 고정샷 → 1.1초 후 청자 0.7초 → 발언자 복귀를 사용합니다. 클릭은 즉시 다음 대사로 넘어가며 추가 대기나 동시 텍스트를 만들지 않습니다.

지속 대립은 `debate:counter:C2:s3`의 뿔이↔아빠입니다. 기존 선택지와 올바른 답변(`counter_ok`) 동안 뿔이 왼쪽/아빠 오른쪽을 유지합니다. 말하는 쪽만 테두리·밝기·이름으로 강조하고 기존 대사창 한 개를 사용합니다. 마지막 상대 표정과 압박 수치를 유지합니다. 제3자 개입(서리의 over 오답 지적), 다른 논점/주민 반응으로 넘어가면 해제합니다. weak 오답은 두 인물의 반론이어서 유지합니다.

아빠는 POV라 기존 참석자 명단에는 없습니다. 역방향 인물샷을 구성할 때만 해당 portrait를 포함하며 실제 좌석/참석자/증거 판정에는 추가하지 않습니다. 배경·탁자·인물 전체를 같은 고정 구도로 렌더링한 뒤 패널 전체를 잘라 원근을 유지합니다.

뿔이 v2는 아트 브랜치 전체를 병합하지 않고 전달 ZIP의 두 PNG와 manifest만 가져왔습니다. 원본 commit `79796e7fd1ea8852807f117ba45395861c1dcc4c`, ZIP SHA-256 `3b125544a31c893a92183534854671451594479aa9fb8ed9a51e1324eca8ad77`를 확인했습니다. 개별 PNG도 전달 SHA-256과 일치합니다.

- `shockburst`: 실제 증거 공개 뒤 기존 0.52초 공동 반응에만 사용.
- `ongoingpanic`: C2 뿔이 압박 단계가 1 이상인 중립/불안/당황/놀람 대사 상태에 유지.
- 대본상 분노는 반격 상태이므로 기존 승인 angry 연기를 유지. 반론 성공 때 압박이 줄어드는 기존 규칙을 변경하지 않음.
- 중립 840 profile와 같은 배율 `594/1029`, canvas 611×906. alpha32 발끝 기준 중립1498 대비 쇼크+1px, 패닉+8px를 배율에 맞춰 아래로 보정. 원본 PNG 자체는 변경하지 않음. 런타임은 RGBA 픽셀 일치를 검증한 무손실 WebP로 미리 로딩합니다.

저장/롤백에는 대립 쌍·좌우·표정 상태가 포함됩니다. 불러오기는 짧은 반응을 완료 처리하고 대립 상태를 유지합니다. 스킵/모션끄기는 청자 삽입을 생략하고 고정된 대사 구도를 유지합니다.

## 결과와 검수

- [실제 C2 45초 영상](actual-c2.mp4) — 기존 음향을 포함한 화면 연출 검토용. **새 이벤트 기반 음향은 미반영**이며 [별도 패치 계획·소스 감사](AUDIO_NEXT_PATCH.md)에 구분했습니다.
- [뿔이 패닉·분할 진입](01-confrontation-entry.png), [아빠 답변·좌우 유지](02-dad-answer-fixed-sides.png), [제3자 개입·분할 해제](05-third-party-motion-off.png), [짧은 뿔이 v2 쇼크](06-v2-shock-event.png).
- 실제 C2 증거 제출 경로에서 다자 발언 → 반박 → 기존 선택지 → 정답 → 주민 반응을 진행했습니다. 첫 45초만 발췌했으며 프레임 보간/속도 변경은 없습니다.
- 최신 main `2791e791`(0.19.59)을 검토 브랜치에 통합했습니다. Q1·UI·자료 필터 변경을 보존했고, 충돌은 생성된 배포 파일과 문서 줄 번호였습니다. 문서 위치는 실제 합쳐진 소스에서 재계산했고 배포 파일은 main의 기존 rpyc를 바탕으로 공식 빌더로 다시 생성했습니다.
- 합친 빌드의 `dev/check.sh`(단위검사·lint), 파일 경로/원본 SHA/무손실 RGBA 일치, multipart SHA 및 ZIP CRC 검사 통과.
- 실제 저장/불러오기에서 대사·페이지·좌우 쌍·양쪽 표정·압박·증거·논증 결과 동일. 자료 창 안에서 저장/불러오면 기존 외부 발언으로 복귀하며 연출 상태도 함께 복원됨.
- 실제 엔진 `Rollback(checkpoints=2)`로 대립 답변을 되돌려 쌍/표정 복원 확인. 기존 기본 PageUp/휠/1체크포인트는 같은 대사에 머무르는 이중 체크포인트 제한이 있어 **일반 입력 UX 해결로 간주하지 않습니다**.
- 스킵은 원래 통로 선택지에서 정지하고 증거·논증 결과를 추가로 변경하지 않음. 모션 끄기에서도 분할 유지. 서리의 제3자 반론에서는 분할 해제·청자 삽입 생략 확인.
- 상세 근거: `runtime.json`, `check.log`, `assets-check.json`, `media-check.json`. 새 아빠/부리/서리 과장 아트와 이벤트 기반 음향은 후속 제작/패치이며 완성 처리하지 않았습니다.

main에는 머지/push하지 않았고 외부 배포도 하지 않았습니다.
