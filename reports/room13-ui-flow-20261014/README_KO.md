# 다람탐정 UI 0.17.2-dev 검토

실행 URL: https://kkhkkh20-bit.github.io/daaegame/preview/room13-dev/
루트 Pages는 구 HTML 프로토타입이다. 최초 조사 기준은 `8ac0342e50e5c77026a28e3ddae76e9d49c5dc25`, 최종 통합 기준은 Claude의 `dc15ed23b2901c412c87f3594dafa90f86980c4c`이다. 해당 main의 소스 ZIP을 기준으로 텍스트를 3-way 통합했으며 Claude의 회의 실패·증거·날짜 수정은 유지했다. 자료 브랜치 전체를 병합하지 않았다.

## 적용

- 실제 화자의 기존 프로필을 대사 왼쪽에 배치, 본문 폭·행간과 큰 글씨 기록창 개선.
- 대사 안의 알려진 인물은 금색 `#ebcd8a`, 알려진 장소는 청록색 `#a9ded4`, 소지 증거는 산호색 `#ffb3a3`와 굵기. 가장 긴 명칭부터 단어 경계·한국어 조사를 확인하며 기존 색/굵기/링크·변수 태그와 독백 색을 보존한다. 미발견 증거와 미접촉 인물은 강조하지 않는다. 표시만 변환하며 기록 원문과 스토리 상태를 쓰지 않는다.
- 1일차 안내 필터가 주민의 일반 질문까지 가리던 문제 수정. 질문의 본래 날짜·증거 조건은 유지한다. 읽은 질문은 체크 후 다시 클릭할 수 있다.
- 증거창은 소유한 자료를 직접 선택한 뒤 제시. 취소·복귀와 선택 전 비활성 상태를 구분한다.
- 읽은 대사만 건너뛰기, 선택·제시·회의에서 정지. 기존 자동 진행·백로그·타이핑 음원 채널과 문장부호 CPS 시스템을 재사용한다.
- 상시 인물 흔들림·꼬리 변형 제거. 정지 그림과 표정 교체를 사용하고 교체 시 불투명도가 다시 0으로 떨어지지 않는다. 새 동작 프레임은 만들지 않았다.
- 지도는 현재 이동 가능한 장소만 표시하고 마을→여관 내부 보기·위치 경로를 보강. 이동·시간 규칙은 기존 그대로다. 하단 버튼 대비·크기를 개선했다.
- 회의 발언자의 기존 프로필·선택 표시 추가. 회의 함수·라벨 전체는 최신 main과 동일하다. C2/C4 입증을 여론 표결로 바꾸지 않았다.
- 메인 이어하기/처음부터/불러오기/설정 정리. 호환 저장만 자동 이어하기; 정보 없는 구 저장은 수동 경고 후 열기, 명백히 다른 캠페인/스토리/그림 계약은 차단한다. 저장 정보에 계약 버전·캠페인·스토리·그림 버전 추가.
- 구 저장 또는 진행 저장 정리는 범위/개수 확인과 취소를 제공하며 사용자가 확인해야 실행한다. 설정·읽은 대사·도감·엔딩 등 persistent는 보존한다. 확인 이후 새로 갱신된 슬롯은 삭제하지 않는다. 사용자 실제 저장은 접근하지 않았다.

기존 `ROOM13_UI_RULES.md`의 아바타 금지/보통 굵기보다 이번 사용자의 왼쪽 프로필·색상+굵기 지시를 우선했다. 기본 Ren’Py screen, text tags, ATL, 저장 메타데이터·확인창을 사용하며 새 외부 라이브러리는 추가하지 않았다.

## 검증 구분

동일 배포 파일을 로컬 HTTP 서버에서 Chromium/실제 Ren’Py WebAssembly로 실행했다. 자연 진행과 상태 주입 검증을 구분한다.

- 자연 진행: 마차 대화, 오토 실제 진행, 백로그에서 일시정지, 미독 스킵 정지, 입구 주민 질문/다시 읽기, 자료 선택·취소·제시, 광장·여관·복도·객실 이동, 조사·메모 수집, 수동 저장/불러오기, 페이지 재접속·이어하기.
- 모바일은 실제 기기 대신 Chromium 터치/작은 viewport+큰 글씨로 기록·회의 화면 검증.
- 회의는 격리 브라우저에 7일차와 이미 소지한 E06/E07/E09를 주입한 뒤 실제 화면에서 취소·3개 반박·결론으로 C2 입증. 전체 14일 자연 완주가 아니다.
- 구 저장 정리는 격리 브라우저의 테스트 저장만 사용. 취소, 구 저장만 삭제, 호환 저장 유지, persistent 유지 검증.
- 사건 발생/예방 분기는 기존 규칙 자동 검사로 검증했다. 두 분기 전체를 브라우저로 완주한 것은 아니다.
- SDK 8.5.3 compile/lint 수행. 웹에서 별도로 내려받는 기존 progressive PNG 자산을 lint stage에서 찾지 못하는 기존 경고는 남는다. 구문 오류는 없다.
- 미디어 309개(이미지·음원) 바이트 동일, 게임 JSON 34개 동일, 회의 함수/라벨 동일. `preservation0172.json` 참조.
- 색상은 어두운 대사창 기준 대비 7:1 이상 자동 검사. 알려진 항목만·부분 문자열 방지·한 글자 이름·태그 중복 방지 검사.

공개 github.io를 실행 환경에서 직접 열기는 네트워크 CONNECT 403으로 차단되었다. 로컬 실제 플레이와 GitHub Pages 빌드 API 확인은 별개로 기록하며, 공개 URL 실제 플레이 완료라고 주장하지 않는다.

## 보류·미완료

- 전원 착석 원탁 공간 화면은 아직 구현하지 않았다. 이번 묶음은 기존 회의 화면의 발언자 강조까지다.
- 가로 배경 42장: `dot/room13-ready-assets-20261014` / `ac8760b38a5d75f2a0ef26f914e7ecb4faf7503f` 인계 문서는 모두 제작 후보·게임 적용 전이라고 명시한다. 2048×768 입구 후보는 확인했지만, 장소별 조사 물건·발 위치·출입구·카메라를 새로 검증하기 전 적용하지 않는다. 일괄 가로 늘이기나 좌표 배율 적용을 하지 않았다. 현재 입구 가로 확장은 미적용이다.
- `dot/room13-story-audio-review-20261014`의 bccbb02 및 0170 부록, motion/rescue 지침 검토. 회수 후 객실 3장·일부 구조 CG·동작 초안·NO_AUTO_APPLY는 적용하지 않았다. 구조 순서, 숨은 다람/꼬리, 침대 불, 할머니 공구 시간·증거 위치를 바꾸지 않았다.
- 신규 음원/동작/배경을 청취·승인했다고 주장하지 않는다. Pixabay 공식 라이선스 확인만 했으며 무료=CC0로 취급하지 않았다. 외부 다운로드·원본 재배포·Kenney UI 도입 없음.
- 사용자 제공 Library 스크린샷은 메타데이터만 읽었고 이미지 다운로드 호스트 403으로 픽셀 열람은 미완료. 여기에 포함된 전후 이미지는 직접 실행한 게임 화면이다.
- 이전 배경 회귀 제보는 사용자가 구 Continue 저장 때문이라고 철회했다. 롤백하지 않았고 기존 0.16.2→0.17.0 이미지 293개 동일 검사도 별도로 보존했다.

소스는 `preview/room13-source/ROOM13_SOURCE_HANDOFF.zip`이 정본이다. `source-changes.patch`는 최신 main 대비 검토용 diff이며 ZIP과 동기화했다. 로컬 QA 경로를 쓰는 개발 스크립트는 필요 시 URL/출력 경로를 조정해야 한다.

검증 과정의 게임 실패는 없었다. 이전 before/report.json에 남은 실패는 기준 화면 촬영용 스크립트의 API 호출 오류이며 게임 결함 판정이 아니다. before 폴더는 0.17.0 기준 화면이고 최신 main 대비 코드는 source-changes.patch에 따로 기록했다. 추가 검토에서 런타임 변경은 하지 않았다. followup 스크립트 재실행은 소스 ZIP을 풀어 그 dev 폴더를 PYTHONPATH로 지정하고, 스크립트 상단 URL/OUT을 실행 환경에 맞춰 사용한다.
