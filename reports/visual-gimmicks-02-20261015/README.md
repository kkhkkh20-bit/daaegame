# 클로드 적용 안내 — 조사 시연 02

현재 게임에 있는 `use_knife_under`, `use_rubbing_stone`을 실제 그림과 조작으로 보여 주는 독립 시연이다. 본편 소스·시간·증거·재판 규칙은 수정하지 않았다. 첫 시연의 저울·등불·포장에 이어 사용할 수 있다.

## 파일

- `index.html`, `style.css`, `app.js`: HTTP 서버로 실행하는 독립 웹 시연.
- `assets/`: 신규 배경 6장. 1672×941, 전체 화면, 불투명 WebP. 투명 오브젝트 레이어가 아니다.
- `asset-manifest.json`: 크기·SHA256·파일 경로.
- `interaction-contract.json`: 본편 연결 지점과 클릭 영역.
- `verification.json`: 이번 브라우저 확인 범위.

원본 PNG를 프로젝트 `dev/import_art.py`의 `encode(lossless=True)`로 내보냈다. 리사이즈·필터·손실 재압축을 하지 않았다. 큰 픽셀 면과 단순한 명암을 유지하며 추가 그레인·표면 노이즈를 얹지 않는다. 생성 그림 사이에는 미세한 차이가 있으므로 연속 애니메이션 프레임이 아니라 정지 상태 전환으로 사용한다.

## A. 13호실 침대 밑

**실제 참조:** `room13-pixel-room-before-evening.webp`의 파란 이불·나무 침대·붉은 마루·남색 러그. 새로운 장소를 만드는 것이 아니라 침대 아래 확대 화면이다.

1. 판자를 손으로 살피면 들뜬 끝과 틈을 관찰한다. 증거 지급 없음.
2. 기존 보유 작업칼을 선택하고 틈을 누르면 `floor-closed` → `floor-open`. 칼은 소비하지 않는다.
3. 드러난 작은 쪽지를 누르면 `note-open`. 본편의 기존 M02 내용을 텍스트 레이어로 보여 준다. 그림에는 가짜 한글을 넣지 않았다.
4. 펼쳐 읽을 때만 기존 증거 획득 경로로 연결한다. 판자만 열었을 때는 획득하지 않는다.
5. 다시 접고 돌아와도 조사 상태와 읽은 기록이 남아야 한다. 재열람은 획득 팝업·효과음·보상을 반복하지 않는다.

시연의 다람이 반응 “이 도토리, 엄마가 그려주던 거야.”는 기존 본문의 도토리 표식을 시각적으로 확인하는 짧은 연출 제안이다. 적용할 때는 기존 가족 대화 톤에 맞추고 중요한 단서를 대신 해석하는 긴 대사로 늘리지 않는다.

**공개 시점 주의:** 이건 처음 받는 안내 편지나 첫날 자유 조사 힌트가 아니라 현재 코드의 **엄마의 두 번째 쪽지 M02**다. 현재 활동의 `own:knife`, `lodging`, 날짜 범위 및 중복 조건을 유지한다. 최신 스토리 문서가 발견 시점을 바꿨다면 그 조건이 우선이다. 시연 접근성이 높다고 본편 시작부터 노출하면 안 된다.

## B. 광장 돌 탁본

**실제 참조:** `room13-pixel-panorama-square-morning.webp`의 공공 난방 구조물 석재. 현재 월드 배치의 `square/stone` 영역은 독립 기념비가 아니라 이 석조 구조물이다. 그림은 그 낮은 석재 면을 확대하는 안이다. 설정상 별도 돌을 의도했다면 맵의 조사 위치부터 합의해야 하며, 새 기념비를 임의로 추가하지 않는다.

1. `stone-base`: 긁어 지운 홈을 관찰한다.
2. 기존 탁본 도구를 사용하면 `stone-paper`: 종이가 덮인다.
3. 숯을 든 채 드래그하면 움직인 부분에서만 `stone-rubbed` 레이어가 보인다. SVG 마스크는 구현 예시이며 실제 배경 PNG를 덧그린 파일을 계속 생성하지 않는다.
4. 대략적인 세 줄에 걸쳐 흔적을 확보하면 더 칠할 필요 없이 살펴볼 수 있다. 종이 100% 채우기·정확도 점수·제한 시간·실패 패널티 없음.
5. 드래그 대체 버튼은 한 번에 한 줄을 쓸어 키보드·터치 사용 부담을 줄인다. 결과와 보상은 동일하다.
6. 드러난 자국을 눌러 읽을 때만 기존 R01 결과로 연결한다. 본편에서 완성된 기록은 기록창에서 재열람할 수 있게 한다.

**문양의 의미:** 탁본 그림의 밝은 모양은 드러나는 자국을 보여 주는 추상 시안이다. 실제 인물 이름·새 언어·암호·퍼즐 정답이 아니다. 새 문자 해독 시스템을 만들지 않는다. 현재 R01에는 구체 이름 목록이 확정되어 있지 않으므로 임의의 주민명을 넣지 않았다. 본편에서 실제 이름이 정해지면 그 글자는 가독성 있는 텍스트/확정된 도트 문자 레이어로 별도 표시한다. 지금 그림을 읽어야 정답을 얻는 필수 증거로 쓰면 안 된다.

## 공통 적용 규칙

- 시연 JS/localStorage를 Ren'Py에 복사하지 않는다. 본편 screen·store 상태와 기존 활동/증거 처리 경로를 사용한다.
- 좌표는 이미지 기준 0~1 정규화 `[x,y,width,height]`. 뷰포트가 아니라 확대 이미지 영역에 맞춘다.
- 원래의 획득 조건, 사건 분기, 소유 도구, 중복 방지, 보상 액수, 시간 규칙 유지. 세부 동작마다 한나절 차감하지 않는다. 판자·쪽지·문지르기 단계가 별도 노동이 되면 안 된다.
- 중간에 닫아도 다시 들어갈 수 있고 세이브/로드/롤백이 일관되어야 한다. 탁본 종이는 중간 동작이 아니라 기존 활동 완료 시점에만 기존 규칙대로 한 번 소비한다.
- 완료 여부와 읽은 여부를 분리한다. 획득 연출은 읽고 기록되는 시점 한 번. 좌측 상단 아이콘과 기존 획득 효과음을 재사용한다. 이 시연에는 새 효과음 파일은 포함하지 않았다.
- 회차 초기화 때 도구·증거·확대 장면 상태를 초기화한다. 이전 회차를 안다는 전용 해금은 추가하지 않는다.
- 같은 조작을 매 회차 길게 반복시키지 않는다. 판자는 아는 위치를 바로 검사할 수 있고, 탁본은 몇 번의 넓은 쓸기로 충분하다. 기존 플레이어 지식으로 빠르게 행동할 여지를 남긴다.
- 실제 재미 검증은 “쪽지를 직접 찾았다고 느끼는가 / 탁본에서 홈의 존재를 이해하는가 / 반복하면 지루한가”를 짧게 플레이 관찰한다. 조작 테스트 통과가 재미 검증 완료를 뜻하지 않는다.
