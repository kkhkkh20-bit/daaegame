기준: `15cdf06d` 위의 별도 `review/meeting-effect-abc` 브랜치. Ren’Py 8.5.3 공식 Web 빌드, Chromium 1280×720. main 배포 없음. `r13_effect_review_enabled=False`가 기본이고 정상 플레이에서 이 비교 label을 호출하는 경로는 없다. 기존 인터럽트 1.68초·기존 효과음·새 외부 음성 미적용 상태는 변경하지 않았다.

세 영상은 게임 엔진 안에서 같은 C2 좌석·승인 그림·실제 작성된 s1 및 broken 대사를 사용한 **통제된 비교 fixture**다. 실제 증거 판정을 진행한 영상은 아니다. 뿔 어르신 → 아빠 → 뿔 어르신, 동일 순서로 화면 시작 후 2.0초와 5.5초에 화자를 바꾼다. 이야기·판정 데이터는 수정하지 않는다. 회의 대사창과 이름, 상단 A/B/C 라벨은 효과 밖에서 고정한다. 노란 채움·플래시·보조 속도선·새 외침·인터럽트는 이번 비교 화면에 섞지 않는다.

각 영상은 새 브라우저 문맥에서 같은 장면을 7초 동안 한 차례 미리 표시한 뒤, 비교 label을 다시 시작한다. 첫 그림 로딩이 짧은 효과를 가리는 영향을 줄이기 위한 통제 조건이며 제품 최적화를 뜻하지 않는다. 동일 council 원곡을 다시 처음부터 music channel gain .65로 재생한다. 실제 canvas + WebAudio를 동시 녹화하고 H.264/AAC로 인코딩한다. 후합성 음악·가짜 모션·배속 없음. A의 10% overscan은 제안의 실제 구현 차이이며, 다른 후보와 완전히 같은 크롭이라고 주장하지 않는다. 화면 라벨은 비교용 표시로 제품 UI에 추가되지 않는다.

구현: `game/systems/room13_meeting_effect_review.rpy`. 기존 Orbit에는 비교 시 고정 시점만 허용하는 비활성 기본 분기 하나를 추가했다. 이전·다음 장면이 서로 같은 전역 시점으로 렌더링되는 것을 막기 위한 것으로 정상 플레이 동작은 유지된다. 새 효과는 기존 카메라 설정에 연결하지 않았다.

검사: `check.log` 단위 검사+SDK lint, `build-validation.json` 전송 조각 SHA256/조립 아카이브 SHA256/ZIP CRC. `record.py`와 `capture_game_audio.js`는 녹화 재현 자료다. 브라우저는 `/usr/bin/chromium --no-sandbox`로 실행하며 추가 GPU 우회 옵션을 쓰지 않았다.

한계: 영상에서 관찰되는 프레임 간격을 실제 기기 성능 보증으로 해석하지 않는다. 낮은 렌더 빈도가 게임 병목인지 녹화 환경의 영향인지 아직 분리하지 않았다. 사용자 선택 전에는 어떤 후보도 기본 효과로 적용하지 않는다.

최종 영상 확인: A 10.490초 / B 10.460초 / C 10.509초, 모두 1280×720 실제 캡처의 H.264 영상+AAC 48kHz 오디오. 실제 오디오 평균은 각각 -41.7/-41.8/-41.8dB, 최대 -22.5/-22.3/-22.8dB로 비무음 트랙을 확인했다. 같은 채널 gain을 사용하며 녹화 시작 지연까지 샘플 단위로 동일하다고 주장하지 않는다. 세 후보 모두 두 번의 화자 전환과 안정된 홀드를 포함한다. `*-transition.jpg`는 영상 첫 2.8초의 확인용 프레임 시트이며, 효과를 후합성한 이미지가 아니다. 디졸브는 이전·다음 그림이 겹치는 실제 프레임을 확인했다. 최종 세 녹화에서 런타임 예외 화면이 없음을 확인했다. 청감에 따른 효과 선택은 사용자 검토 대상으로 남긴다.
