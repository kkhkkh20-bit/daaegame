# 0.17.23-dev · 2026-10-14

메인 화면의 명조 타이틀·메뉴가 게임의 도트 글꼴과 맞지 않는다는 사용자 피드백을 반영했다.

- 메인 타이틀, 부제, 메뉴, 보조 문구와 로딩 화면을 실제 게임에서 쓰는 Galmuri11로 통일했다. UI의 명조체 직접 지정을 제거했다.
- 큰 로고는 도트 획이 드러나는 크기로 표시하고, 작은 글씨에는 인위적인 굵기·기울임·외곽선을 적용하지 않는다.
- 메인·옵션 UI의 기본 아이보리(#fff4df), 선택 금색(#ebcd8a), 보조 글씨(#ced9d4), 비활성 색을 공통 역할 값으로 관리한다. 로딩 화면도 같은 색을 사용한다.
- 주 행동은 금색 글씨로 구분하되 마름모·밑줄은 현재 초점 항목에만 표시한다.
- 겨울 숲 배경과 게임의 의미 있는 기록/생각 색 구분은 유지했다. 0.17.22의 다람이 생활·회차 기록 규칙을 그대로 보존한다.

검증: 단위 검사 97개, Ren'Py 8.5.3 compile/lint, PC 및 844×390·640×360 실제 터치, 키보드 초점, 설정/새 게임/자연 저장/이어하기/불러오기, 메인·옵션·로딩 화면 캡처 비교. 로딩 시각 fixture에서는 엔진 요청을 의도적으로 막고 첫 화면만 확인한다.
