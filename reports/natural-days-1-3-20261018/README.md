# 새 게임부터 실제 입력 진행 — 중간 인계

게임 상태를 주입하지 않은 자연 진행이다. 새 게임부터 시작해 대화·몸/얼굴 클릭·조사·지도·자료 제시·저장/불러오기·취침을 실제 UI로 수행했다. 읽기 전용 introspection과 글자 즉시 표시 설정만 사용했다. 이 보고는 1–3일 전체 QA 완료가 아니다.

- 1일: 입구 도착, 다람/경비 대화, 원본 조사 G1, 경비에게 제시하여 입장 정정 E02, 여관 숙박,13호실 M01/E03,취침. 기다리기 확인 취소 후 전체 게임 상태 동일.
- 2일: 0.19.49에서 만든 실제 저장을 통합 후보0.19.51에서 불러오기. 지도→수리점, 협동 대화, 초롱에게 M01 제시→후속 질문→J02, 우체국 세련에게 E01/M01 제시→후속 질문→J03. 우체국 저장을 최종0.19.52에서 다시 불러온 뒤 지도→13호실→취침.
- 3일: 새벽 사건과 피코 사망 분기 자연 발생. 광장 선택지에서 후불 제안을 묻고 거절. 꺼진3번 등 안·틈을 실제 조사해 L03/L04 확보. 지도→우체국→사서 접근/질문 화면까지 진행.

진행 차단은 발견하지 않았다. 아직 3일 주요 사건의 전체 후속 진행과 사서 경고/구조, 1일 저장 재회귀 후 최종 UI 재검증은 미완료다. 위 상태는 실제 저장 1쪽4번에 남긴다. 기존 초기1쪽1번,2일1쪽2·3번도 보존했다.

버전 차이를 구별한다:1일0.19.49;2일 앞부분 로컬 통합 후보0.19.51;J03 뒤 저장부터최종0.19.52. 원격0.19.51 질문 발견 기능은 최종0.19.52에서 포함한다.

관찰: 구 UI에서는 입구 인물 발이 하단 버튼에 가렸으나 main 현장 단순화에서 해당 버튼들이 제거됐다. 여관 일반 토리 앉기 자세의 발/의자 접점은 추가 검토 대상이며, 이번 협동 토리 간격 수정과 다른 포즈다. 잘못된 QA 함수명(r13_world_spots) 조회 실패나 화면 페이드 직후 빈 probe는 게임 진행 오류로 분류하지 않는다.
