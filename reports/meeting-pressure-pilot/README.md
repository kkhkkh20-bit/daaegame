# C2 대표 회의: 지속 감정·집단 반응·카메라·사운드 후보

main 0.19.52를 기준으로 한 검토 브랜치 후보다. 아직 main에 머지하거나 공개 게임에 배포하지 않았다. 대표 범위는 식당 회의 C2 ‘다람이의 방어가 죽음의 원인인가’ 한 곳이다. 대사, 증거 허용, 정답, 판정 결과를 변경하지 않았다.

## 바로 볼 영상

- before.mp4: 약44.1초. 기존 감정/카메라/음악 동작.
- after.mp4: 약45.8초. 지속 압박·집단 반응·카메라·정적 적용 후보.

둘 다 실제 SDK 웹 게임의 화면과 WebAudio 출력을 함께 녹화했다. H.264 Baseline / AAC / yuv420p / faststart MP4이며 ZIP이 아니다. 사후 효과음/BGM 합성, 슬라이드, AI 프레임 보간은 없다. 후보의 AAC 트랙에서 평균 -40.4dB, 최대 -18.9dB와 실제 무음 구간을 확인했다. 사용자의 기본 게임 음량으로 녹화했으며 음량을 억지로 키우지 않았다.

처음에 day10·E35/E09 보유·C1 입증 조건만 설정한 장면 fixture다. 그 뒤 발언 이동, 자료 선택·제시, 반박 선택과 답변은 실제 클릭이다. 자연 캠페인 영상은 아니다. 이전 영상은 같은 빌드에서 이 후보의 압박 기능을 끄고 기존 카메라 함수로 되돌린 비교다. 상세 상태는 before/after-capture.json에 있다.

## 실제로 보이는 흐름

1. E35가 실제 허용된 모순으로 판정되고 설명이 공개되면 뿔이 압박 0→1. 반박 신호 후 핵심 설명 동안 음악·환경음 gain이 0으로 내려간다.
2. 현장 참석자10명이 각자의 승인된 놀람 그림으로 동시에 반응한다. 짧은 집단 화면이 끝난 뒤 뿔이는 평온으로 초기화되지 않고, 동요한 얼굴로 다음 발언을 계속한다. 중립 특수 그림이 그 표정을 덮지 않게 했다.
3. E09의 다른 모순이 공개되면 1→2. 같은 증거/같은 발언 반복은 중복 상승하지 않는다.
4. 기존 ‘겁 많은 아이는 그 길로 못 간다’ 선택은 상대의 역반박이 성립하는 원래 결과다. 그 실제 분기에서 압박 2→1로 완화하고 다음 발언에도 유지한다. 전후 모두 s2만 깨지고 s3은 남는 동일한 판정 결과다.

압박은 run/논점/당사자별 저장 상태이고, 사건 토큰은 발언별로 기록한다. 대사나 카메라 변경으로 지우지 않는다. 현재 에셋으로 확실히 구분되는 ‘평온 / 동요(anxious) / 큰 당황(surprise_talk)’ 세 상태만 사용한다. flustered와 anxious는 같은 원본이므로 다른 단계라고 부풀리지 않았다. 기존에 명시된 화난 몸짓 등은 해당 대사에서 유지한다. 입모양 애니메이션은 추가하지 않았다.

## 카메라와 소리

- 일반 가로 이동은300~360ms, 끝의100ms는 위치를 고정한다. 반박은180ms부터, 큰 반전은80ms 호흡을 둔다. 같은 화자의 연속 발언은 focus revision을 바꾸지 않는다.
- 집단 반응은80ms 호흡 후520ms 화면 타이머다. 첫 표시의 디코딩/렌더 비용까지 포함한 관측 구간은 더 길 수 있다. 실제 렌더 속도를 개선했다고 주장하지 않는다.
- 결정적 설명은 연출용 channel gain만0으로 만든다. 사용자가 멈춰 있어도2.4초 후에는 낮은 음악으로 복귀한다. 집단 반응 뒤에는 상황별 회의 BGM으로 돌아간다. 일반 강조는 기존 덕킹을 유지한다.
- 같은 모순의 반박 신호/압박/집단 반응은 중복 실행하지 않는다. 자료 선택 취소는 신호를 발동시키지 않는다. 불완전하거나 틀린 자료는 기존 판정 분기를 유지하며 성공 집단 반응을 만들지 않는다.
- 저장된 압박/이벤트는 유지하고 로드에서는 일회성 놀람을 정리한다. 침묵 타이머도 로드·장면 종료에서 정리한다. 음악 위치·기존 사용자 mixer volume/mute를 보존한다.

## 검증

추가 단위 검사: 실제 공개된 모순만 상승, 발언별 중복 방지, 유효한 역반박 한 번만 완화, 다른 논점 영향 없음, 사망/부재 인물 제외, 대사/중립 그림 변경 후 유지, 로드 시 일시 반응 정리, 새 run 분리, 정적 타이머 후 음악/환경음 복귀. 전체 자동 검사와 Ren’Py lint 통과 로그는 check.log.

동적 대사 참조의 소스 줄 번호만 갱신했다. 기존119개 바인딩의 텍스트·표정·순서·키·승인 범위는 그대로다. 새 문맥 표정을 추가 활성화하지 않았다. 런타임 저장/로드·스킵·롤백 결과는 별도 state-report.json으로 제공한다.

추가 제작이 필요한 것:
- 뿔이의 현재 anxious/surprise와 구별되는 ‘궁지’ 및 ‘붕괴’ 정지 그림. 승인된 같은 얼굴·뿔·의상 유지가 필요하다.
- 자연스러운 주민 군중 웅성거림과 캐릭터별 짧은 반박 목소리. 현재 라이선스가 확인된 해당 녹음이 없어 임의 음원을 추가하지 않았다. 영상의 주변 반응은 각자의 그림과 기존 대사이며 새 군중 녹음이 아니다.
- 더 큰 몸짓/테이블 반응은 일괄 복제하지 않았다. 현재 승인 그림의 각자 다른 몸짓만 쓴다.

한계: 웹 실행 환경의 실제 이동 렌더 빈도는 여전히 낮다. 기존 별도 측정에서는95~184ms 간격이 관측됐고, 동시 작업 부하가 달라 성능 A/B로 해석할 수 없다. 이번 캡처는 canvas 변화 프레임을 최대30fps로 받는 실제 VFR 녹화다. 출력 FPS 숫자를 올려 문제를 해결한 것이 아니다. GPU 강제 플래그나 보안 설정은 변경하지 않았다. 물리 iPhone 검증은 하지 않았다.

### 런타임 상태 검수 결과

정적 gain0→2.4초 뒤 복귀, 사용자 volume/mute 불변, 자료 창 취소, 실제 저장/로드 후 압박과 대사 복원, Ctrl 스킵 후 선택지 정지와 음악 복귀, 유효한 역반박2→1 유지가 통과했다.

롤백 입력의 제한을 구분한다. 기본 PageUp/휠은 이 회의에서 원하는 이전 사건 경계로 이동하지 않았다. 임시 QA 버튼의 실제 Ren’Py `Rollback(checkpoints=2)` 동작으로 되돌렸을 때 두 번째 증거/회복 토큰이 제거됐고, 첫 증거 이전까지 더 되돌리면 압박0·이벤트 없음·원래 중립·음악복귀가 확인됐다. 다시 실제 E35를 제시하면 압박1이 한 번만 적용됐다. 강제 상태 주입으로 압박을 바꾼 검사가 아니다. 일반 사용자 롤백 입력/이중 체크포인트 UX는 별도 남은 점검 사항이다. state-report.json에 첫 입력 검사 실패와 후속 엔진 검증을 모두 보존했다.
