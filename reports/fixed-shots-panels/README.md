# 겨울 회관 대화 리듬 — 검토 전용 3안

실제 Ren'Py 8.5.3 SDK, 기존 겨울 회관·승인 캐릭터·원탁 좌석을 사용한 코드 시안입니다. main/운영 배포는 하지 않습니다. 새 디자인·음성·효과음은 없습니다.

| 안 | 대표 화면 | 15초 실제 SDK 영상 | 편집 |
|---|---|---|---|
| 1 전체 화면 고정샷 | [PNG](1.png) | [MP4](1.mp4) | 7.2초에 뿔이에서 세련으로 컷 |
| 2 청자 반응 편집 | [PNG](2.png) | [MP4](2.mp4) | 6–7.2초 부리 반응, 9.5–10.4초 뿔이 반응 추가 |
| 3 절제된 2인 분할 | [PNG](3.png) | [MP4](3.mp4) | 7.2–10.4초에만 뿔이·세련 분할, 이후 세련 전체 화면 |

모두 같은 두 대사, 같은 대사 전환 시점(7.2초), 같은 기존 회의 BGM/음량(.65)을 사용합니다. 반응샷에서도 발언자 이름은 실제 대사 주인공을 유지합니다. 대사창은 화면 아래 한 개로 고정합니다. 장면 제목은 비교용 표식입니다.

- 뿔이: “아이가 촛대로 어르신의 머리를 내리쳤다고 했습니다.”
- 세련: “아이의 첫 공격 때문에 어르신이 나중에 쓰러졌을 가능성은요?”

원본 대사는 C2 승인 레지스트리에서 직접 읽습니다. 세련 대사는 반문이며 새 반박 대사를 창작하지 않았습니다. 각 고정샷은 기존 `R13MeetingOrbit`의 실제 좌석 인덱스와 원근을 저장한 구도입니다. 분할도 인물·배경·탁자가 함께 있는 샷 전체를 잘라 확대하므로 요소별 원근을 따로 바꾸지 않습니다. 새 측면 그림이나 3D 카메라를 만든 것은 아닙니다.

초기 A/B 초안도 [A 3컷 PNG](A-three-cuts.png), [B 분할 PNG](B.png)로 보존했습니다. 초기 A/B 영상은 약10.5초이며 최신 3안의 시간 비교에는 위 1/2/3 영상을 사용하세요.

검토 화면은 기본 비활성화이며 운영 스토리에서 호출하지 않습니다. 비교 라벨 `r13_shot_review`를 QA에서만 호출합니다. 녹화는 실제 브라우저 WebAudio와 화면을 기록하고 H.264/AAC로 변환하며 프레임 보간·재타이밍을 하지 않습니다.

검증: `dev/check.sh` 통과(단위검사·Ren'Py lint), 공식 web build 완료, multipart 7개 크기/SHA-256 및 합친 ZIP CRC 검사 통과. 상세는 `check.log`, `archive-check.json`을 참조하세요.

완료된 영상 길이는 1안 14.983초, 2안 14.969초, 3안 15.004초입니다. 1280×720 H.264/AAC, 실제 BGM 비무음 확인. 브라우저 런타임 예외 없이 각 안을 완료했고, 영상에서 2안 청자 반응과 3안 분할→전체 화면 복귀를 직접 확인했습니다. 녹화 시작과 SDK 시계 사이에는 짧은 시작 지연이 있으므로 위 컷 시각은 SDK 장면 기준입니다.

검토 의견: 기본 대화는 1안이 가장 차분하고, 중요한 문답에 2안의 짧은 반응을 제한적으로 넣으면 고전적인 분위기 안에서 리듬이 생깁니다. 3안은 두 사람의 입장이 맞서는 한 번의 순간에만 쓰는 후보입니다. 아직 어느 안도 운영 연출로 확정하지 않았습니다.
