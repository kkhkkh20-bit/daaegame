# 본편 UI 재구성 · 0.18.28

Chef RPG 레퍼런스의 돌판과 화면 구성을 기준으로 실제 Ren’Py UI를 재구성했다. 마지막 사용자 정정에 따라 **대화 초상화 틀은 없다.** 기존 중앙 인물/마차 다람이 연출은 유지한다.

- [메인](01-title.png): 중앙 로고와 작은 세로 메뉴.
- [대화](03-dialogue.png): 캐릭터는 장면에, 이름 띠와 낮은 돌 대화창은 아래에.
- [현장](04-field.png): 오른쪽 위 날짜와 시간대, 별도 장소 라벨.
- [질문](06-resident.png): 가운데 선택지.
- [기록](07-records.png): 왼쪽 분류·가운데 격자·오른쪽 상세.
- [인물](07b-people.png), [대화 기록](07c-history.png).
- [자료 제시](07d-present.png), [제시 후 응답](07e-present-response.png).
- [휴대폰](08-phone.png), [큰 글자](09-large-records.png).

새 주민 그림 변경을 병합한 상태에서 단위 검사 131개, compile/lint와 실제 Chromium 확인을 거쳤다. 자료 선택/제시와 옵션 저장 후 이어하기를 실제 조작으로 확인했다. 지도 그림은 첫 입장 이동 조건을 건드리지 않고 화면을 띄운 시각 확인이다. 전체 14일 회귀는 반복하지 않았다.
