# 대사 수정 적용 인계 · 4차

먼저 [REVIEW.md](REVIEW.md)의 전후 대사를 확인하세요. 다른 개발자의 최신 코드에 수정 파일을 통째로 덮어쓰지 말고, 아래 원문 대조 도구로 적용하세요.

```bash
python reports/dialogue-revision-20261013/apply_revision.py --project experiments/renpy-ch1
python reports/dialogue-revision-20261013/apply_revision.py --project experiments/renpy-ch1 --write
```

첫 명령은 변경하지 않는 dry run입니다. 원래 배포본 또는 1차/2차/3차 수정본의 모든 원문을 먼저 확인하고, 다른 대사로 변경된 부분이 있으면 쓰기 전에 중단합니다. 두 번째 명령은 기존 파일을 dialogue-backup-20261013/에 보존합니다. 수정된 .rpy의 이전 컴파일 파일만 제거합니다. 게임의 조건, 플래그 이름, 비용, 증거 지급, 저장 디렉터리를 바꾸지 않습니다.

최신 전체 개발 소스는 이 검수 작업 공간에 없습니다. revised/game/는 최신 공개 실행 패키지에서 추출한 대사 수정 결과이며, 개발 소스 전체를 대신하지 않습니다.

전체 프로젝트에 dev/build_room13_content.py가 있으면 마지막 JSON 출력 직전에 대사 후처리를 연결하고 모듈/패치 자료를 dev/에 복사합니다. 기존 주민·아트·개정 생성 단계를 모두 실행한 다음 대사를 적용하므로 다음 빌드에서 범용 대사로 돌아가는 것을 막습니다. 이전 기획의 narrative.json을 최신 실행 데이터 위에 덮어쓰지 않습니다. 재생성 결과가 다른 대사이면 원문 대조 오류를 해결한 뒤 진행하세요.

적용 후 필요한 검수:

- 실제 콘텐츠 생성 → RenPy lint → 웹 빌드.
- 부리 소문 대화의 동의/거절/정정과 E06+E08 협조 해금.
- 밤이 익명/기명 제시, 보호 활동 전후, 유출 후 압박 반응.
- 할머니 E05/E09/E10/E13/E14/E35/E36 최초·반복 제시. 준비·유출 플래그 기존 동작 유지 확인.
- 35명의 생활 대사 day 5~7 / 8~13 및 기존 생존·구금 조건 확인.
- E26 수첩과 최종대결 피드백에서 제작용 문구 미노출.
- 저장/불러오기와 읽음 기록. 수정 문장은 기존 텍스트 해시 기반 읽음 처리에 따라 새 문장으로 취급될 수 있습니다. 상태 초기화는 하지 않습니다.

검수 제한: 수정 콘텐츠와 Python 실행 함수는 검증했지만 SDK가 없어 엔진 lint, 수정본 브라우저 플레이, 모든 분기 완주는 하지 못했습니다. 보호·공개에 새 보상이나 새 선택지를 추가한 작업은 아닙니다. 기존 기능에 맞춰 인물의 목적과 감수할 부담을 표현한 대사 수정입니다.

3차 추가 검수: 나비→아빠/다람 전환, 밤이의 경계하는 존댓말, 뭉치·솜이·보리의 아빠/어른 상대 해요체, 나비의 재판과 후반 집단 발언, 기존 등장·문장부호별 대사 속도 유지. VOICE_RULES.md를 참고하세요.

추가한 행동 묘사(None 화자) 전후에 캐릭터가 불필요하게 사라지거나 재등장 연출을 반복하지 않는지도 실제 화면에서 확인하세요. 이번 수정에서 표시 코드는 바꾸지 않았습니다.


4차는 대사 텍스트만 바꾸는 작업에서 대화 진입 흐름 수정까지 확장되었습니다. 두 파일(room13_dialogue_openings_20261013.rpy, room13-dialogue-openings.json)을 game/에 추가하고 r13_talk 진입 및 일반 주제 대사 선택을 연결합니다. 새 파일이 다른 내용으로 존재하면 적용 전에 중단합니다. 주제 조건·증거 지급·시간·대면 기록 방식은 그대로입니다.

- 새 게임의 1일 오후 도토 클릭: 인사 → 작업 관찰 → 질문 목록. 메뉴에 '같은 내용을 두 번 적습니까?'가 없어야 합니다.
- 다람 동행 중 도토 생활 대화: 다람의 질문 → 도토 답 → 아빠 후속 질문. 구금 중에는 아빠 대화가 유지돼야 합니다.
- 35명 초면 인사, 같은 날 재클릭, 다음 날 재방문, 저장/불러오기, 새 회차 초기화 확인.
- 다람 구금·부재 중 콤비 대사에 다람이 등장하지 않고 원래 주제가 사라지지 않아야 합니다.
- 압박받은 밤이, 상실한 부리의 특수 인사 우선 유지. 이미 아는 엄마에게는 초면 인사를 추가하지 않았습니다. 까로/할머니는 도착 때부터 연결된 관계에 맞춰 썼습니다.
- 기존 세이브에 대면 기록이 있으면 이미 만난 사람으로 취급합니다. 새 초면 인사를 보여주려고 세이브나 관계를 초기화하지 마세요. 초면 검수는 별도 새 게임에서 하세요.
- 새 rpy/json의 빌드 포함, init 순서, 행동 묘사 전후 캐릭터 표시, 대사 길이와 화면 넘김을 엔진과 브라우저에서 확인하세요. 함수 검수는 엔진 검수를 대신하지 않습니다.
