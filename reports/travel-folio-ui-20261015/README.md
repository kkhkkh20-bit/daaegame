# 여행 수첩 UI — 0.18.32

## 방향

최신 UI의 구성과 크기를 유지하고 재질을 바꾼다. 눈 덮인 마을에서 가족과 머무는 따뜻함에 맞춰, 기록은 종이 수첩으로, 대화와 행동은 차분한 먹갈색으로 나눈다. 이전 회색의 넓은 경사면과 금속 조작판 느낌을 없앤다. 자글자글한 잡티나 종이 노이즈를 추가하지 않는다.

- 기록: 종이 표지와 안쪽 접힘선, 옅은 갈색 슬롯, 크림색 증거 카드. 증거/증언/인물/대화와 도구 위치는 유지.
- 대화: 불투명한 먹갈색 면, 작게 꺾인 모서리, 얇은 밝은 테두리. 중앙 인물과 별도 이름표 유지.
- 날짜·장소: 밝은 종이 표찰, 진한 갈색 글씨. 시간 원형 표시는 유지.
- 제목·선택·행동: 기존 정렬, 납작한 먹갈색 버튼. 선택은 옅어진 면과 바랜 적갈색 표시로 구분.
- 기존 글자 역할 규칙 유지: 아빠 생각의 파란색 괄호, 증거 지칭과 발화자 이름의 구분.

## 적용 위치 (Claude 인계)

- `game/room13_ui_art.rpy`: 공통 `R13InkPanel`, `R13PaperFrame`, `R13TravelSheet`, `R13PaperPanel`. 실제 실행용 Canvas 도형이며 외부 이미지·9-slice 리소스가 필요 없다. 이전 Stone 이름은 과거 저장 호환 별칭으로만 남긴다.
- `game/room13_notebook.rpy`: 펼친 수첩 바탕과 접힘 여백, 선택 색인, 증거/인물/대화 내용의 종이 위 글자색.
- `game/room13_screens.rpy`: 날짜·장소 종이 표찰과 하단 도구 재질.
- `game/room13_title_art.rpy`: 공통 먹갈색 버튼 사용.
- `game/systems/room13_typography_roles.rpy`: 대화창 기본은 완전 불투명. 연하게는 반투명, 진하게는 불투명한 어두운 면. 글자 역할 색은 변경하지 않는다.
- `game/room13_navigation.rpy`, `room13_reference_composition.rpy`, `systems/room13_playback.rpy`, `systems/room13_reference_ui.rpy`, `systems/room13_ui_refinements.rpy`, `screens.rpy`: 공통 재질 호출과 시간 아이콘 배색. 추가 덮어쓰기 계층 없음.

이번 범위는 화면 재질과 표시다. 이야기, 공개 조건, 증거 획득, 비용, 주민 동선은 바꾸지 않는다. 제단/고대문명 배경 아트에 대한 변경도 포함하지 않는다.

## 확인

실제 웹 빌드 캡처 첨부. 137 단위 검사와 Ren'Py compile/lint 통과. 브라우저에서 제목·대화·날짜/장소·이동창·자연스러운 주민 접근·기록 세부 탭·실제 소유 증거 선택→제시→응답·큰 글자·모바일을 확인했다. 최종 재빌드 후 대화창 연하게/보통/진하게도 별도 확인했다. 전체 14일 플레이 재검사는 범위에 포함하지 않았다.
