# 회의 속도선 카드 비교 후보

최신 상태: [투명 가로선·단계별 템포 후보](../meeting-tempo-review/README.md). 노란 카드는 거절되어 제거됐으며 사운드는 1초 이내 ‘잠깐만요!’ 외침 후보 대기 상태다. 아래는 이전 검토 기록이다.
최신 사용자 피드백에 따라 A/B 군중 웅성거림은 채택하지 않았다. A 파일과 연결 코드는 런타임에서 제거했다. 아래는 후보 검토용이며 main 배포가 아니다.

## 비교 범위

- 이전: [연속 이동 후보의 실제 유음 영상](../meeting-pressure-pilot/after.mp4), 소스 `5921fa0c`.
- 이후: `after.mp4`, 같은 C2 증거 E35→E09→반문 오답 경로. 초기 day10/E35/E09/C1 fixture를 명시적으로 설정한 뒤 실제 UI로 진행한다. 자연 1~3일 플레이 영상과 구별한다.
- 카드는 새 이미지 없이 Render canvas로 노란 바탕과 17개 가로선을 그린다. 화자 변경 revision당 약 0.18초 후 목표 좌석으로 즉시 정착한다. 장면 상단 500px에만 표시되고 대사/도구 UI는 위에 남는다. 같은 화자는 반복하지 않으며 동작 끄기·스킵·롤백에서는 생략한다.
- 연속 회전 보간은 비교용으로 보존하되 후보 기본은 카드다. 이야기/증거/반문 판정은 변경하지 않았다. 실제 압박은 0→1→2, 반문 성공 뒤 1로 회복하며 3/4를 만들기 위해 사건을 추가하지 않았다.

## 새 뿔이 그림

지정 아트 커밋 `ce1da7b23c3a7e20c484fb4e2180bc6179079dbf`에서 ZIP과 manifest만 읽었다. 전체 아트 브랜치는 병합하지 않았다. ZIP SHA256 `a2d75733d6dfe5ee906b23006b09ee688a767d9d5e8dc063d01056f03dbf443c`, manifest SHA256 `ba1608f66ee59349f66cf7e5d02ba7fe59519b20efbc0db3e3d4dab8cd5f6d91` 및 모든 내부 파일 해시를 검증했다.

`experiments/renpy-ch1/art/approved-meeting-pressure-20261018/originals/`에 궁지/collapse 원본을 보관하고 `room13-dialogue-pose-source-art.json`에 cornered/collapse로 등록했다. 원본 1029×1528에 동일한 neutral 배율을 적용하고 y만 각각 +25/+12px 이동했다. 840 프로필은 동일 611×906 canvas, offset (8,47)/(8,40). 몸을 숙여 낮아진 머리를 늘이거나 끌어올리지 않았다. 발 접점 오차는 반올림 이내다.

두 자세는 실제 사건에 연결하지 않은 **진단 전용**이다. 별도 캡처에서 중립/궁지/붕괴를 동일 배율로 비교하며, 진단이 room13 상태를 바꾸지 않았는지 기록한다. 원작 음원·참조 그림은 추가하지 않았다. 인계 manifest와 CC0 라이선스는 수령 증빙으로 남지만 음원 A의 채택을 뜻하지 않는다.

## ‘잠깐만요’ 소리 현황과 교체 요청

현재 유효 경로: `room13_meeting_direction.rpy:r13_meeting_direct_interrupt` → `source_fx("impact")` → `room13_sound.rpy` init150의 `R13_FX` → **`game/assets/sfx-present.wav`** (Kenney Music Jingles HIT00, CC0). 옛 `source-impact.wav`가 이 회의의 유효 큐라는 뜻은 아니다. 현재 영상은 기존 효과음 그대로이며 새 외침 음성이 구현됐다고 표시하지 않는다.

최신 사용자 방향은 **“두두 말고 나팔 소리처럼”**, 즉 짧고 강한 금관악기의 **‘빠밤!’ 반박 스팅거**다. 둔탁한 드럼/이중 타격이나 멜로디 알림으로 확정하지 않는다. 부모가 후보를 준비 중이며 이 브랜치에서는 사운드를 임의 확정/교체하지 않았다. 권장 인계는 WAV 48kHz/24bit 원본과 웹 파생본, 출처/사용권, 명확한 짧은 금관 어택과 짧은 잔향이다. 실제 회의 BGM 아래에서 길이·음량을 비교 승인 후 연결한다. 기존 원작 음원/목소리 복제는 사용하지 않는다. 현재 실제 외침 음성은 없다.

## 성능과 청감의 한계

속도선은 전환 연출 대안이다. 렌더러 성능 문제가 해결됐다는 주장이 아니다. 이전 계측의 프레임 간격 95~184ms는 부하가 있는 headless Chromium 환경의 관찰이며 원인을 확정하는 GPU/CPU 프로파일은 아니다. 여러 인물/배경 합성, 소스 디코드, 브라우저 환경 비용의 기여도를 분리하지 못했다. 이번 카드는 표시 중 무거운 인물 합성 경로를 건너뛰지만 실제 기기의 저프레임 원인 해결/60fps 보장은 별도다.

영상은 canvas와 실제 WebAudio 출력을 동시 녹화한 유음 MP4다. 외부 음원 후합성 없음. 자동 디코딩·오디오 트랙/볼륨 검사와 시각 확인을 청감 평가로 대신하지 않는다. 이 실행 환경에서는 사람의 청감 평가를 완료하지 못했으므로 사용자 검토가 남는다.

## 확인 결과

단위 검사와 Ren’Py lint 통과(`check.log`). 승인 원화/파생 파일 해시와 비례 크기, 발 접점 반올림 오차, 거절된 군중 파일 미포함, 카드의 단발 표시·동작 끄기·롤백 생략을 검사했다. 최종 빌드는 공식 `dev/build_web.py`로 생성했다. 영상은 50.866초 H.264/AAC 48kHz, 실제 오디오 평균 -40.4dB / 최대 -18.8dB. 압박 최종 1, 깨진 진술은 s2만, 음악/환경음 gain=1. 진단 전후 story_unchanged=true. 카드 실제 캡처 구간은 `card-timing.json`에 기록한다. 하드웨어/촬영 환경의 프레임 빈도에 따라 보이는 시간은 코드의 0.18초와 다를 수 있다.

스크린샷: `04-speed-card.png`(제목/대사/하단 UI 보존), `05-explicit-art-diagnostic.png`(중립/궁지/붕괴 같은 배율·발 접점). 머리 크기는 원화 비례 그대로이며 숙인 붕괴 자세의 전체 높이를 늘이지 않았다.
