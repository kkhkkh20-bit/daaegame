# 실제 회의 동작 녹화

meeting-continuous.mp4: 39.16초,1280×720,25fps,H.264/yuv420p,무음. Playwright가 로컬 Ren’Py SDK 웹 게임의 실행 프레임을 연속 녹화한 영상이며 스크린샷 슬라이드나 합성이 아니다. 재생 속도는 원래 속도다.

녹화 전에 10일 회의·E35/E09 보유·C1 입증 조건을 설정했다. 클립 안에서는 실제 클릭으로 화자 전환,자료 제시,반응,반론,같은 화자의 다음 대사,선택지와 답변을 진행한다. 사용자 저장·다른 창·계정 화면은 포함하지 않았다. 공개 cloud 브라우저 실황이나 자연 캠페인 완주 영상은 아니다.

회의 구현은 배포0.19.49와 동일하고 촬영 클라이언트는 생활 그룹 수정을 포함한 로컬0.19.50 후보 빌드다. 정확한 해시와 트림 시각은 meeting-recording.json에 기록했다. 원본 WebM에서 연속 구간만 잘라 MP4로 인코딩했다.
