# 0.19.40 — 조사 배치 후속 수정

학교의 선생님과 뒷줄 학생, 대피소 주민, 우체국 작업자와 방문자의 겹침을 줄였다. 피코는 병상 가장자리의 앉는 지점을 유지하면서 침대에 맞춰 크기를 조정했다. 다람은 침대와 앞쪽 러그에서 머리 크기를 기준으로 자세별 최종 높이를 맞췄다. 아동/좌석 배율을 중복 적용하지 않는다. 기존 일정·사건 제안·사망 조건·대사는 유지한다.

검증: dev/check.sh 단위 검사 및 SDK lint 통과. 마지막 선생님 높이 수정 후 관련 19개 테스트 통과, 공식 SDK 웹 빌드 재생성. 실제 엔진 16개 장면, 인물 클릭 15회, 상태 조합 326개 인물 레코드에서 출현·포즈·사건 배치 보존 확인. 마지막 빌드로 학교 4장면 재확인. 나머지 12장면은 학교 높이만 변경하기 전 빌드이며 각 JSON에 실제 archive SHA를 기록했다. 최종 7개 아카이브 조각 및 1187 preload의 해시와 ZIP CRC 확인.

증거: reports/investigation-balance-01940/index.html, runtime.json, build-verification.json. 기존 reports/place-balance-01936 실패 기록은 보존하고 후속 링크를 추가했다. 전체 캠페인 검증은 아니다.
