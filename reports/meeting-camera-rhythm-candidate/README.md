# 회의 카메라 리듬 비교 후보 (미배포)

현재 main은 0.19.52(d10cabfe)다. 이 변경은 검토 후보이며 main의 표정·논리·판정·아트를 바꾸지 않는다.

## 확인한 원인

- 현재 카메라는 listen 0.22초, reaction/press/recover/reversal 0.12초다. gasp/interrupt/explain은 0초라 코드가 보간을 건너뛰고 목적 좌석으로 즉시 간다. 녹화 FPS 변경으로 이 즉시 이동을 복구할 수 없다.
- round/stone 회의는 `R13MeetingOrbit.render` → `r13_meeting_world_view`가 실제 경로다. 고정 좌석과 탁자가 같은 시점으로 가로 이동하며, 이동 중 `renpy.redraw(self,0)`으로 다음 렌더를 요청한다. 별도의 25fps 게임 제한은 없다.
- Playwright 결과물은 25fps이지만 실제 게임의 서로 다른 이동 프레임은 그보다 적다. 현재 녹화의 이동 렌더 간격 중앙값은 95–129ms, 후보는 151–184ms였다. 두 실행은 같은 장비지만 다른 검증 부하도 있었으므로 성능 A/B 결과로 쓰지 않는다. 후보가 렌더 속도를 높였다는 증거는 없다. 프레임 복제나 AI 보간은 하지 않았다.

## 작은 후보

- 같은 화자: 기존 focus revision을 유지해 움직이지 않는다.
- 일반 화자: 0.32초 + 좌석 거리 보정, 최대 0.48초. 짧게 가속하고 더 길게 감속해 끝에서 정지한다.
- 강한 반박 interrupt: 0.18초부터, 최대 0.30초. 0초 순간 이동을 없앤다.
- 근거 설명/짧은 반응: 0.26초부터, 최대 0.40초.
- 큰 반전 reversal/gasp: 0.08초 호흡 + 0.32초 이동부터. 모든 대사를 일괄 느리게 하지 않는다.
- 한 이동의 속도·호흡은 첫 렌더에서 고정한다. 이동 중 대사 beat가 바뀌어도 곡선이 갑자기 달라지지 않는다. 모션 끄기와 건너뛰기는 목적 위치로 즉시 간다.

## 영상과 검증 범위

before.mp4 약38.7초 / after.mp4 약39.1초, 무음, H.264/yuv420p, 1280×720. 실제 SDK 실행 프레임을 녹화한 원속도 영상이며 슬라이드가 아니다. 초기 day10/E35/E09/C1 조건 설정 후 실제 입력으로 동일한 화자 전환·자료 제시·반응·선택지·답변을 진행했다. 후보는 0.19.52 SDK 웹 클라이언트에 이 브랜치의 카메라 함수 3개만 런타임으로 적용한 비교다. 배포용 ZIP을 새 버전으로 발행한 것은 아니다.

`candidate-functions.py`는 실제 적용한 함수이고 `*-frames.json`은 실제 render 경유 view 샘플이다. `frame-summary.json`은 이동 중 서로 다른 좌표 수와 간격이다. before/after 모두 같은 화자 연속 대사에서 마지막 focus revision 10을 유지했다. 원본 동영상은 시간 구간만 트림했다.

4개 추가 테스트로 곡선의 연속·단조·끝 정지, 전환별 속도 차이와 상한, 모션 비활성화, 도중 beat 변경 안정성을 검사했다. 기존 고정 0.22초 중간값 테스트는 새 완급에서도 지켜야 하는 단조 이동·목적지 도달 조건으로 바꿨다.

## 남은 과제

이 후보만으로 부드러운 렌더 빈도가 확보됐다고 판단하지 않는다. 정상 하드웨어 브라우저에서 녹화 유무를 분리해 프레임 시간을 재측정하고, 느린 경우 회전 중 매 프레임 크기 변환·전경 마스크 비용을 프로파일해야 한다. GPU 강제 플래그나 보안 제한 변경은 하지 않았다.

표정은 별도 기획 대상이다. 현재 각 새 줄에서 방향 표정 사전이 초기화되고 0.35초 반응 토큰이 종료되는 구조를 확인했다. 사용자 요구인 논리 붕괴 단계별 동요 유지, 유리해질 때 회복, 큰 반전에 주변 집단 반응은 별도 상태 설계와 승인된 표정 범위 확인이 필요하다. 이 후보에서 기존 표정이나 판정 로직을 임의 변경하지 않았다.

영상 후 추가된 정밀도 수정: ease 입력 0/1은 정확히 0/1을 반환한다. 종점의 부동소수 오차(0.9999999999999997)를 없애며 영상에서 보이는 이동은 동일하다.
