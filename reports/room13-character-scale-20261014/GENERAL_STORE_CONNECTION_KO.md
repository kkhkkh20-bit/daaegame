# 은호 상점 연결점 — 최신 main 대조, 미구현

최신 `c4a143fc3b6457d297dd1bad58e3d252fcd03ffe` (Claude 0.17.14)에는 **은호 구매 기능이 이미 있다**. 장소 ID는 `store`(공동 물품 창고)이며, 별도의 잡화점 장소 ID는 없다. 낮에 은호에게 ‘물건을 산다’를 선택하거나 ‘일거리·상점’ 상점 탭에서 기존 상품 9개를 구매하는 구조이다. `game/systems/room13_shop.rpy`, `docs/RELEASE_01714.md`를 대조했다.

따라서 신규 노드를 중복 생성하지 않았다. 원래의 `general_store` 제안은 ‘공동 창고와 별도 실내 장소를 만든다’는 방향이 확정될 때만 쓸 수 있는 충돌 없는 **후보 ID**이며 현재 적용하지 않는다. 사용자 요청이 기존 은호 구매 화면에 대응하는 지도 위치·실내 이미지인지, 새 장소로 분리하려는 것인지 최종 디자인 연결에서 구분해야 한다. 기존 `store` 개명·이전·아트 대체도 하지 않았다.

검토 중인 시안: Library `libfile_fc87b3f85e248191903373d0fa95921c`, `general-store-interior-v1.png`. 아직 사용자 검토 중이므로 다운로드·적용·확정하지 않았다.

연결점은 다음과 같다.

- `game/room13_navigation.rpy`: `R13_MAP_NODES['village']`, `R13_MAP_LABELS`. 현재 광장 (336,250), 공동 창고 (553,292), 지도 논리 크기 860×490. 새 지도가 필요한지 먼저 판단하고, 필요하다면 광장 주변 핀·이름·터치 영역 간격을 검토한다.
- `R13_PLACES`와 `game/assets/room13-world-layout.json`: 승인된 배경 키 및 실제 비율·바닥 좌표를 등록하는 곳. `store` 이미지만 교체하면 기존 공동 창고가 바뀌므로 이번 단계에서 교체하지 않는다.
- `game/room13_rules.rpy`의 `r13_places()`가 이동 허용 목록이다. `r13_map_nodes()`가 알려진/허용된 장소만 표시하고, `game/room13.rpy`가 지도 반환값을 다시 허용 목록과 대조한다.
- `game/systems/room13_first_day_flow.rpy:19`가 첫날 목록을 별도로 제한한다(등록 전 gate만, 등록 후 gate/square/inn, 숙박 후 hall/room13 추가). 상점 지도 추가가 첫날 흐름을 자동으로 우회해서는 안 된다.
- 지도 선택은 이동하지 않는다. ‘여기로 이동’ 뒤 `r13_edit(location=...)`만 호출하므로 기존 이동은 **시간 소모 없음**이다. 잡화점 분리가 결정되더라도 이 경로를 유지하고 `r13_tick()`을 붙이지 않는다. 취소는 위치·시간을 보존한다.

이번 캐릭터 수정은 최신 main의 은호 구매/경제/대사를 그대로 보존한다. 신규 판매 경제·상품·주민 일정·사건 증거·새 노드·새 이미지는 추가하지 않았다. 현재 완료 범위는 연결점 확인뿐이다.
