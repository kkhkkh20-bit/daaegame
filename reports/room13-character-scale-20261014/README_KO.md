최종 기준은 main `c4a143fc3b6457d297dd1bad58e3d252fcd03ffe` (0.17.14). 첫 비교 화면은 f903bc8 (0.17.13)에서 촬영했고, 수정 대상 세 파일은 두 main 사이 동일함을 확인했다. Claude의 0.17.14 은호 상점·상품·품삯/외상·이전 빌드 정리는 그대로 보존했다.

## 변경

- 까로 대화: 전신 원화의 머리를 화면 위 48px에 고정하던 분기를 기존 대사/질문 위치 규칙에 맞춤. 머리 여백 대사 약 130px, 질문 약 146px. 확대율은 그대로. 누비 등 기존 흉상 프레이밍은 그대로.
- 공동 창고: 앞쪽 슬롯의 206px 축소를 없애고 깊이에 따른 서 있는 기준 높이 250~368px를 적용. 원래 있던 뭉치245/백 부인271/은호269/실룩260의 상대 키 비율을 유지. 자세별 머리/몸 비율을 적용해 웅크리거나 앉은 인물을 서 있는 키까지 늘리지 않음.
- 발 좌표와 가로세로 비율을 유지한다. 렌더·클릭 영역·이름표는 같은 actor 치수를 사용한다. 입구 및 다른 장소 배율은 변경하지 않음.
- 원화 327개 이미지/음원 바이트 동일. 투명 여백 점검에서 뭉치·백 부인의 실제 crop은 이미 내용에 밀착되어 있었으므로 새 그림이나 임의 crop을 만들지 않음.

수정 런타임 소스는 `room13_rules.rpy`, `room13_acting.rpy`, `assets/room13-world-layout.json` 및 버전 `options.rpy`뿐이다. 전체 ZIP 안의 나머지 기존 파일이 최신 main과 동일함을 검사했다. [소스 변경](source-changes.patch), [보존 검사](preservation.json).

## 실제 실행과 검사

- 최종 배포와 같은 웹 산출물을 로컬 Chromium에서 실제 실행했다. Ren'Py 8.5.3 compile/lint 완료, Python 검사 70개 통과.
- 처음부터 입구에 도착해 까로 질문·대화를 클릭. 대사 도중 실제 저장/불러오기에서 같은 발언자·같은 줄 복귀. 빠른 대사 진행 후 질문·현장 복귀.
- 모바일 844×390 큰 글씨에서 까로 대사·질문 및 8인 창고 화면 확인.
- 명시적 테스트 상태로 1~14일/3시간대/사건 발생·예방의 창고 72개 조합을 검사. 주민 누락 및 화면 바깥 원화 없음. 입구 인물 geometry는 전후 동일.
- 11일 오후 8인 혼잡 상태에서 실제 이름표 클릭·접근 취소 후 상태 보존, 실제 저장/불러오기 후 창고 상태 복원. 첫 fixture는 그날 경고 이벤트를 아직 읽지 않은 상태여서 복귀 시 기존 경고 대사로 진입했다. 이벤트를 이미 읽은 상태로 명시해 다시 검사했으며 제품의 이벤트 규칙은 고치지 않았다.
- 위 후반 장면은 전체 14일 자연 플레이가 아니다. 이번 변경에서 회의/구조 분기 전체를 다시 자연 완주하지 않았다. 관련 엔진은 바이트 보존 및 기존 단위 검사로 확인했다.
