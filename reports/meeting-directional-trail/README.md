# 방향성 잔상 — 우리 게임 구현 제안

정지한 old/new 두 장면의 디졸브와 구별되는 **움직이는 현재 장면 + 뒤따르는 두 겹**, 총 세 위치의 윤곽을 비교한다. 레퍼런스 원본의 알고리즘을 복제했다고 주장하지 않는다. 레퍼런스 영상·프레임은 저장소/게임/비교 영상에 포함하지 않았다. UI 고정은 우리 게임의 가독성 설계이며 레퍼런스 UI의 동작을 단정한 것이 아니다.

- [기존 B · 0.38초 디졸브](B-dissolve.mp4): `5ee50c5f`에서 보존한 비교 영상.
- [D · 방향성 잔상 후보](D-trail.mp4): 동일 C2 대사와 화자 전환 두 번, 실제 SDK Web 녹화.
- [잔상 단일 프레임](trail-frame.png): D 실제 영상에서 추출한 한 프레임. 콜라주·후합성 아님.

## 구현

0.34초 동안 현재 장면이 320px 이동해 정착한다. 첫 전환은 왼쪽 진행/오른쪽 꼬리, 두 번째는 반대 방향. 뒤따르는 두 위치는 진행 반대쪽 180/360px 간격이고 시작 alpha .26/.15다. 0.06초 후 0.28초 동안 alpha 0으로 사라진다. 뒤쪽에 각각 기본 blur 3/6px를 적용해 세 개의 선명한 복제 얼굴처럼 보이는 것을 줄인다. 이 blur는 SDK의 일반 blur이며 레퍼런스의 방향성 motion blur 알고리즘이라고 주장하지 않는다.

원본 회의 장면을 Flatten한 동일 소스에서 세 위치를 그린다. 잔상을 포함한 결과를 다음 잔상의 소스로 재사용하지 않는다. 일반 알파 합성만 사용하고 가산 합성은 사용하지 않는다. 장면은 이동 중에만 가로로 반복해 빈 가장자리를 막는다. 이는 넓은 이동을 위한 비교안의 절충이며 실제 배경 파노라마 재구성과 같지 않다. 정착 후 크롭/크기는 기존 B와 같다.

전환 시간 0.34초가 지나면 settled 장면만 반환해 두 잔상과 이동용 반복 스트립을 렌더 경로에서 제거한다. 첫·두 번째 전환은 별도 객체/지역 시간으로 계산하므로 이전 트레일이 누적되지 않는다. 이름/대사창/비교 라벨은 장면 합성이 끝난 뒤 한 번만 그린다. 비교 fixture에는 별도 조작 버튼이 없으며 정상 제품 UI에 새 효과를 연결하지 않았다.

## 비교 조건과 범위

기존 B와 같은 7초 사전 표시 후 다시 시작하는 1280×720 SDK fixture, 같은 C2 s1/broken 대사, 화자 전환은 2.0초/5.5초. 같은 council 음악·채널 gain .65, 실제 WebAudio+canvas 녹화. 새 음성·새 효과음·후합성 소리 없음. 인터럽트 1.68초는 변경하지 않았고 이번 화면 비교에는 섞지 않는다.

`r13_effect_review_enabled=False` 기본값 유지. 검토 브랜치에만 보존, main 미배포. 정상 플레이의 연속 클릭·스킵·로드 전체 통합 검증은 아직 하지 않았다. 기존 낮은 렌더 빈도가 실제 성능 병목인지 녹화 환경 한계인지 미확인이고, 이 효과는 복수 합성 및 blur 비용을 추가하므로 성능 개선이라고 부르지 않는다.

실측 결과: D 영상 10.460초, H.264 + AAC 48kHz, 실제 오디오 평균 -41.8dB / 최대 -22.6dB. `trail-frame.png`는 영상 timestamp **1.762초**의 실제 단일 프레임이다. 서로 떨어진 윤곽과 뒤쪽의 약한 잔상, 선명한 이름·대사창을 함께 확인할 수 있다. 반대 방향의 두 번째 전환도 확인했으며 정착 후 이전 겹침이 남지 않는다. 전환 종료 후 클릭 전후 PNG의 RGB 픽셀 차이는 0이다. 화면에 지속적인 흰 점멸이나 가산 밝기 폭증 효과는 넣지 않았다. 색/밝기 전체 기기 측정이나 제품 경로 전체 회귀까지 수행한 것은 아니다.
