# 0.17.8-dev · 생활 공간 5곳

기준 main: `13a835003cbc3fd6efacc5f0c27b53f7229fdf1b` (Claude 0.17.7). C3 다음 미입증 발언 선택과 마지막 회의 화면 수정을 보존했다.

진료소·공동 물품 창고·온실·시설·제단의 아침/오후/저녁 15장을 `ac8760b38a5d75f2a0ef26f914e7ecb4faf7503f`에서 개별 선별했다. 2048×768 원본을 1920×720 세계 좌표로 균일 축소하고 기존 조사 대상에 대응하는 클릭 영역·바닥·주민 배치를 작성했다. 서사/대화/증거/일정/판결 엔진은 변경하지 않았다. 상점 8인 모임에서 빈 배치 후보 오류와 얼굴 가림을 수정했다. 기존 좁은 배경용 위치 규칙은 새 5개 장소에서만 건너뛴다.

## 검증

- SDK 8.5.3 compile/lint, 24개 테스트 파일과 규칙 22건(총 25개 명령) 통과.
- 로컬 Chromium 실제 런타임: 5곳 × 3시간대 좌우 이동 및 모든 기존 조사 대상 클릭 확인. 초기 실행은 이 단계 통과 후 혼잡 배치 오류로 종료했으며 원본 실패 보고를 `world0178/initial-object-clicks`에 보존했다.
- 오류 수정 후 날짜 1–14/사건 발생·예방/3시간대 360개 배치 fixture 전체 좌표 검사 통과. 최다 주민 화면 좌우 캡처를 눈으로 검수했다. 온실 재회 상태의 기존 엄마 동작과 5개 조사 클릭도 확인했다.
- C3: 실제 자료책 UI로 E12/E05 반박, 다음 미입증 발언 선택과 올바른 결론 확인. 데스크톱/모바일 큰 글씨 및 취소 복귀 확인. 이는 명시적 상태 fixture이며 자연 14일 완주가 아니다.
- 최종 웹 아카이브 SHA-256: `2b082399068e70b362b84a11e29fdee7b7f559e039e5110b6fd005eab22cb896`. C3 검사는 직전 빌드에서 실행했고 이후 변경은 상점 배치 좌표뿐이다.

기존 정문 3장과 합쳐 승인 배경 18장을 적용했다. 객실 회수 후 3장, 대응 객실 전 3장, 미검증 구조 CG 및 동작 초안은 적용하지 않았다. 나머지 우체국/여관 공간은 별도 검수 묶음으로 진행한다. 원탁 전신 착석 신규 아트는 부족하여 기존 프로필 자리 화면을 유지한다. Library 새 동작/증거 그림은 다운로드 실패로 미검수·미적용이다.

공개 Pages는 API 배포 상태와 커밋을 확인하며, 이 실행 환경의 공개 URL 직접 접속 제한 때문에 원격 브라우저 재생은 미검증이다. 동일 빌드 로컬 브라우저와 모바일 에뮬레이션을 사용했다. 실물 휴대폰은 미검증이다.
