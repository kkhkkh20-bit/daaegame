- 01: 정리한 메인 배경과 회색 선택 프레임
- 03: 중앙 대화창과 이름표
- 04: 날짜판과 현장 버튼
- 05: 지도 화면(첫 입장의 이동 제한을 바꾸지 않는 시각 확인용 화면 호출)

- 07: 종이색 기록창과 석재 테두리
