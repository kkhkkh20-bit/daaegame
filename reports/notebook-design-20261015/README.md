# 기록창 내부 통합 및 디자인 정리 — 0.18.42

## 변경

- 조사 메모·기록 비교를 기록창의 오른쪽 내용 영역으로 통합. 양피지 틀과 왼쪽 색인을 유지하며 증거·증언·인물·대화와 바로 전환한다.
- 별도 메모 열기(focus 지정 포함), 비교 call/Return 진입도 같은 기록창을 사용한다. 기존 진입 이름은 유지한다.
- 비교 카드 두 장, 소유 자료 목록, 비교 결과와 버튼을 내용 영역 안에 재배치. 긴 자료·결과는 각 영역에서 스크롤한다. 비교 판단과 획득 조건은 유지한다.
- 질문 화면: 인물명/역할과 기능 설명의 중복 상단 문구 제거. 선택지 위 이름은 유지. 환경을 먼저 어둡게 그리고 인물을 밝게 표시한다.
- 이동창: 양피지 외곽과 종이 장소 카드, 읽기 쉬운 갈색 정보 글씨. 기존 지도와 이동 조건은 유지.
- 대화 도구: 기록·백로그·자동·더보기로 정리. 읽은 대사 넘기기/모든 대사 빠르게/대화창 숨기기/옵션은 더보기 안에 유지. 더보기 중 자동 진행 정지.
- 아이콘과 도구 글자를 확대. 증언은 깃펜 메모, 대화는 대화 원고로 구분.
- 메인: 저장이 없으면 처음부터가 첫 번째. 음악 출처는 작은 보조 링크.

## 원본과 상태 관리

`game/room13_notebook.rpy`의 `r13_records`가 공통 기록창이다. 오른쪽에 `r13_learning_notes_content`와 `r13_compare_content`를 포함한다. 기존 `r13_learning_notes`/`r13_record_compare` 진입은 공통 기록창을 사용하며 닫기 및 호출 반환 동작을 전달한다.

포함된 화면은 각자의 scope에 메모 탭/펼침 상태와 비교 선택/결과를 보관한다. `r13_record_select`는 기존 화면 이름과 명시적으로 전달한 scope를 모두 지원한다. 따라서 메모의 '자세히 본 것'을 누른 것이 상위 기록창의 분류를 덮어쓰지 않는다. 새 덮어쓰기 계층 없음.

관련 원본: `room13_notebook.rpy`, `room13_record_compare.rpy`, `systems/room13_learning.rpy`, `room13_screens.rpy`, `room13_navigation.rpy`, `room13_antique_icons.rpy`, `systems/room13_playback.rpy`, `screens.rpy`.
