# 0.17.21-dev · 2026-10-14

첫 화면을 눈에 갇힌 마을의 미스터리에 맞춰 새로 디자인했다. 어두운 겨울 숲과 따뜻한 여관을 오른쪽에 배치한 전용 배경을 만들고, 왼쪽에는 큰 한글 타이틀과 간결한 메뉴를 올렸다.

- 새 배경: 달빛, 눈 덮인 숲, 불 켜진 여관과 발자국. 원본 PNG와 런타임의 무손실 WebP를 보관한다.
- 타이틀: 종이색 명조 로고, 첫 번째 이야기 표기, 기존 부제. 메뉴를 둘러싼 큰 사각 패널을 없애고 여백·금빛 마름모·밑줄로 선택 상태를 표시한다.
- 기능: 이어하기·처음부터·불러오기·설정의 실제 동작과 저장 호환성 판정을 유지한다. 저장이 없는 경우 이어하기/불러오기는 비활성이고 처음부터가 기본 초점이다.
- 눈 효과는 화면 움직임 설정과 연결한다. 끄면 눈이 그려지지 않고 재그리기도 요청하지 않는다.
- 로딩 화면도 같은 이미지와 명조체로 맞췄다. 브라우저 보조 메뉴의 보이지 않는 영역이 작은 화면의 게임 설정 버튼을 가로채지 않도록 포인터 영역을 줄였다.
- 추리 도움 옵션이나 사건 규칙은 추가·변경하지 않았다. 0.17.19의 소리·미리보기·옵션 초기화와 0.17.20의 회차 이월 제거 규칙을 보존한다.

원본 이미지: design/room13-title-20261014/title-winter.png. 같은 픽셀을 무손실 WebP로 변환해 사용한다. 기존 Room13Title 폰트를 웹 로딩용 WOFF2로 변환했고 기존 OFL을 유지했다.

재포장: 기존 dev/package_web_webp.py가 dev/update_title_loader.py를 호출한다. 웹 이미지와 폰트는 동일한 패키징 단계에서 카탈로그와 파일 해시를 갱신한다. 환경에 Pillow와 fontTools[woff] (Brotli 포함)가 필요하다.

검증 범위: 단위 검사, Ren'Py 8.5.3 compile/lint, 실제 Chromium 키보드/클릭/터치, 1280×720·844×390·640×360 배치, 화면 움직임의 재접속 유지, 실제 새 게임에서 만든 저장으로 이어하기와 불러오기, 로딩 화면 첫 표시. 로딩 시각 검사는 엔진 요청을 의도적으로 막은 별도 fixture이며 실제 게임 검증과 구분한다.
