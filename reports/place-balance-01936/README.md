# 0.19.36 장소별 실제 화면

[장소별 갤러리](index.html). 66장의 실제 Chromium/WASM 캡처를 육안 확인했다. 화면 합성이나 새 원화 생성은 하지 않았다. 2일·12일의 오전/오후/저녁과 12일 대피 fixture의 서로 다른 인물/동작/장소를 대상으로 한다. 다른 날짜 및 사건 분기, 목록에 없는 원화는 미검수다. 자동 캡처 성공을 전체 디자인 통과로 바꾸지 않는다.

다람의 문자 그대로 “두 침대 사이 끼임”은 재현하지 못했다. 재현된 이불 앞쪽 좌석과 하단 안내에 가려진 바닥 동작을 수정했다. 나비 주방 5동작은 별도 검수 묶음도 보존한다. 토실 승인 겨울 모자/목도리 변형은 유지했다.
