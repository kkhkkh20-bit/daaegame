# B 디졸브 잔상 길이 비교

사용자 선택: “b를 좀 더 잔상이 남게”. 변경 전 실제 코드값은 **0.24초**, 변경 후는 **0.38초**(+0.14초, 약 58% 증가). SDK native Dissolve의 부드러운 교차 소멸을 유지하고 정지 잔상이나 별도 잔상 레이어를 더하지 않았다. fixture의 연속 redraw 구간도 .32→.42초로 맞췄다. SDK `renpy/display/transition.py`의 Dissolve.render는 st >= time이면 new_widget만 반환한다.

- [변경 전 B](before-B.mp4): `710f0e2d`의 실제 SDK 녹화, 0.24초.
- [수정 B](after-B.mp4): 같은 C2 s1/broken 대사와 뿔→아빠→뿔 전환 두 번, 0.38초.

기존과 같은 7초 사전 표시 후 fixture를 다시 열어 녹화했다. 같은 council 원곡, music channel gain .65, 실제 WebAudio+canvas 동시 캡처. 새 음성·음향 교체·후합성 소리 없음. 기존 인터럽트 1.68초는 변경하지 않았으며 비교 장면에는 인터럽트를 섞지 않는다. 상단 라벨·이름·대사 패널은 디졸브 밖에서 선명하게 고정한다. 버튼을 움직이는 효과는 없으며 비교 fixture에 별도 조작 버튼은 없다.

정상 플레이에 연결하지 않은 기본 비활성 비교 fixture다. 사용자 선택 방향에 맞춘 수정 후보를 검토 브랜치에 보존하며 main 배포는 하지 않는다. 이는 실제 증거 판정 플레이 영상이 아니다.

검수 범위: SDK lint/단위 검사, 공식 Web 빌드 조각/아카이브 SHA256와 ZIP CRC, 실제 영상의 두 화자 전환 및 이후 홀드, 비교 화면에서 마지막 전환이 끝난 뒤 클릭 전후 화면을 확인한다. 생산 플레이의 다음 대사 클릭 경로 전체를 검증했다고 주장하지 않는다. 낮은 렌더 빈도의 원인이 실제 성능 병목인지 녹화 환경 영향인지는 미확인이다.

완료 결과: 수정 영상 10.510초(H.264/AAC 48kHz). 평균 -41.7dB, 최대 -22.6dB의 실제 오디오 트랙 확인. 전환 중에만 이전·다음 얼굴이 겹치고 정착 후에는 이전 장면이 남지 않는다. 마지막 정착 후 클릭 전후 PNG의 RGB 픽셀 차이는 0으로, 이 비교 화면에서 잔상이 재등장하거나 고착되지 않음을 확인했다. 이름·대사창은 전환 프레임에서도 선명하게 유지된다. 단위 검사/SDK lint 및 빌드 무결성 검증 통과.
