최신 직접 적용 요청 / 2026-10-14
사용자는 Claude와 병렬 개발하면서 dot도 준비된 자료의 선별 적용, UI 통일, 메인화면 개선을 수행하기를 요청했다. 작업 전 최신 커밋과 인계 문서를 확인한다. Claude의 화면이나 아직 푸시하지 않은 변경은 확인하지 못했다.

1. 공통 UI: 색상, 폰트, 간격, 버튼, 선택/비활성, 뒤로가기 규칙을 메인/옵션/인물/증거/지도에 통일. 좁은 중앙 배치 대사창, 본문 왼쪽 정렬, 왼쪽 프로필. 두 줄 표시와 깜빡임 방지. 이동 버튼은 더보기에 숨기지 않음.
2. 고유명사: 인물 이름/장소/증거 이름의 해당 단어만 강조. 제안 색상은 인물 금색, 장소 청록, 증거 산호색+굵게. 명암 대비 검증 후 확정. 기존 강조 규칙과 중복되지 않게 통합. 미공개 정체/미획득 증거를 색상으로 스포일러하지 않음. 부분 문자열 오탐, 중첩 태그, 타이핑 중 글자 잘림, 저장 후 복귀 검사.
3. 독백과 타이핑: 독백의 파란 표현, 문장부호 쉼, 증거 등장 효과음은 공통 작성 규칙에 연결. 매 대본마다 임의 구현하지 않음.
4. 에셋 적용: 이 폴더는 검토용. NO_AUTO_APPLY/보류/미승인은 자동채택 금지. 전체 브랜치 통째 병합 금지. 실제 판결/스토리 조건 임의변경 금지.
5. 검증: 저장/불러오기, 스킵, 연타, 닫기/복귀, 큰 글씨, 모바일, 예방/발생 및 구금 분기. 변경 스크린샷과 적용/보류/미실행 목록 보고.

상태: 저장된 개발 환경에서 작업 생성은 접수됐으나 사용 한도로 실행 실패. 코드 수정/게임 적용/실행 테스트는 시작되지 않았다. 자료 업로드와 읽기 검토만 완료 범위다.
