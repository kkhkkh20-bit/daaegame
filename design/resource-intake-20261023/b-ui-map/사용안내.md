# 다람탐정 마을 지도 에셋

승인된 B 스타일에 맞춘 지도 화면용 분리 에셋 납품본입니다. 게임 구현이나 신규 기능 추가가 아니며, 게임 소스·저장 데이터는 변경하지 않았습니다.

## 구성
- assets/map_background_1136x570.png: 글자 없는 지도 배경, 불투명 PNG. 원본 1774×887을 1136×570으로 단순 리사이즈한 파생본입니다. 비율 변화는 약 0.35%입니다.
- assets/notebook_frame_1280x720.png: 실제 알파 채널을 가진 노트 프레임. 중앙 x88, y58, 너비1136, 높이570은 완전 투명합니다.
- assets/b_*.png: 기존 승인 B 에셋을 그대로 재사용한 패널·버튼·아이콘·테이프·제목 탭입니다. PNG 안에 한국어 문구를 합치지 않았습니다.
- assets/sticker_daram_stubborn.png: 기존 다람 스티커를 그대로 재사용했습니다.
- originals/: 지도 생성 원본과 프레임 원본. 새 생성 원본은 별도로 보존하고, 재사용 UI는 assets에 원래 파일을 보존했습니다.
- layout_1280x720.json: 배치 좌표, 화면 크기, 장소 이름, UI 문구, 제안 클릭 영역입니다.
- previews/: 실제 배포 PNG들을 조립한 1280×720 및 640×360 미리보기입니다. 시스템 Noto Sans CJK Bold 폰트로 문구만 별도 렌더링했습니다.
- manifest.json: 각 파일의 바이트 크기, SHA-256, PNG 치수와 알파 범위, 알파 기준 가시 영역을 기록했습니다.

## 분리 범위와 제약
노트 프레임, 지도 배경, UI판, 아이콘, 테이프, 스티커, 문구/좌표는 분리되어 있습니다. 건물·눈·강·나무는 배경 그림에 포함되어 있고 개별 오브젝트나 타일로 분리되어 있지 않습니다. 캐릭터나 물 흐름 애니메이션도 포함하지 않습니다. 픽셀 단위 수작업 픽셀아트로 검증한 파일은 아닙니다.

## 조립 순서와 글자
1280×720 기준으로 지도 배경을 (88,58)에 1136×570으로 놓고, 프레임을 (0,0)에 1280×720으로 올립니다. 그 위에 제목, 장소 라벨, 하단 UI와 스티커를 놓습니다. 모든 좌표는 전체 화면 좌상단 기준이며 [x,y,너비,높이]입니다.
제목은 상단 밴드 안에 두어 건물을 가리지 않습니다. 장소 라벨은 120×34, 글자는 굵은 20px이고, 하단 컨트롤 글자는 굵은 19px입니다. 제목은 배경판 없이 크림색 상단 띠에 굵은 20px로 표시합니다. 실제 게임에서는 해당 한국어 문구를 텍스트 컴포넌트로 렌더링하세요. 폰트 파일은 패키지에 포함하지 않았습니다.
하단은 선택 장소 / 마을 / 여관 안 / 숲·산길 / 이곳으로 이동 / 현장으로이며, 선택 예시는 광장입니다. 구역 버튼 사이 간격은 10px, 구역과 이동 버튼 사이에는 26px를 두었습니다. 우측 상단 닫기는 별도 이미지가 아닌 기본 텍스트 ×로, 중심 (1230,40)에 배치합니다. 이 버튼들의 동작은 구현하지 않았습니다.

## 실제 크기와 투명 여백 주의
PNG 캔버스 크기와 눈에 보이는 그림 크기는 다릅니다. manifest.json의 visible_alpha_bounds_px가 원본 PNG에서 알파가 0보다 큰 픽셀의 바운딩 박스입니다. visible_bounds_at_layout_px에는 배치 크기로 환산한 실제 그림 영역을 기록했습니다. 예컨대 버튼을 160×52로 배치해도 내부의 버튼 그림은 투명 여백 때문에 더 작게 보일 수 있습니다. 레이아웃의 크기는 PNG 전체를 기준으로 하므로, 임의로 trim하면 좌표와 크기가 달라집니다.
미리보기 레이아웃은 버튼과 라벨의 가시 크기를 확보하기 위해 _trimmed 파생본을 사용합니다. 기존 파일의 투명 여백만 ImageMagick으로 잘라냈고, 원본은 b_panel_small.png / b_button.png / b_button_primary.png로 함께 보존했습니다. 라벨 가시 높이는 약 34px, 하단 버튼 가시 높이는 약 40px입니다. 파생본도 전체 PNG 크기를 기준으로 배치합니다. 런타임에서 시각 크기를 바꾸려면 가시 영역과 클릭 영역을 별도로 맞추고, 실제 게임 화면에서 확인해야 합니다.

## 검수 범위
이 미리보기는 실제 게임 실행 화면이 아닌 에셋 조립 검수용 시안입니다.
프리뷰를 실제 파일로 합성하여 육안 확인했고, 프레임 투명창 알파값과 파일 치수·해시를 검사했습니다. 제안 클릭 영역은 그림을 보고 잡은 사각형이며 실제 게임 런타임에서 클릭 테스트한 값이 아닙니다. 구현·상호작용·모바일 터치 검증은 하지 않았습니다. 640px 미리보기는 축소 확인용이며 휴대폰에서 글자·터치 영역의 가독성이 보장된다는 뜻이 아닙니다. 작은 화면은 확대/스크롤 등 기존 게임 방식에 맞춰 별도 검증이 필요합니다.
