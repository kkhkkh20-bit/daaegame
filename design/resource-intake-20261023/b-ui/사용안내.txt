다람탐정 B안 수첩 UI 부품 26종

assets 폴더의 PNG가 실제 납품 부품입니다. 26종 모두 요청한 캔버스 크기, RGBA 및 바깥 투명도를 확인했습니다. 제목 로고만 글자가 있고 나머지는 게임에서 글자를 올려 씁니다. 전체보기 이미지는 검수용이며 게임용 배경이 아닙니다.

주의할 부분만:
1. 스프링이 붙은 대사창·큰 수첩·메인 판은 높이를 고정하고 가로로 늘리는 용도로 제작했습니다. 세로까지 자유롭게 늘리면 고리가 늘어납니다. 세로 변경은 별도 b_spiral_ring.png를 올리는 방식 등으로 개발 담당이 처리해야 합니다.
2. 작은 버튼/테이프/고리는 16px 여백을 그대로 적용하면 그림을 쓸 수 없어 작은 비례 여백을 썼습니다. 캔버스 규격은 유지했습니다. 정확한 여백은 metadata에 있습니다.
3. 카드 기본/강조/완료는 생성 편집본이라 테두리가 픽셀 단위로 완전히 동일하지는 않습니다. 호버 전환 시 형태 흔들림은 개발 화면에서 확인해야 합니다.
4. 9-slice 경계는 제안값이며 Ren'Py 실제 실행 검증은 아직 하지 않았습니다. alpha가 약간 남는 종이 질감은 생성 원화의 일부입니다.
5. 실제 기존 텍스트·동작·저장과 분기는 그대로 유지하십시오. 이 파일에 새 게임 기능이나 정답 표시는 없습니다.
6. 손그림 B안의 원화 부품입니다. 엄밀한 2×2 픽셀 격자 인증본은 아닙니다.

전체 파일의 크기와 SHA256은 manifest.json에 있습니다. 고해상 생성 원본은 별도로 보존했습니다. 이 납품은 그림 제작 완료이며 게임 코드 적용·빌드·배포 완료를 뜻하지 않습니다.
