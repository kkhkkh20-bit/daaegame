layout_1280x720.json은 납품 에셋을 실제로 배치한 좌표입니다. 조립_미리보기.png는 이 좌표와 납품 파일을 사용한 합성 검수 이미지로, 생성 모델이 별도로 예쁘게 다시 그린 화면이 아닙니다. 실제 Ren'Py 실행 스크린샷도 아닙니다. 미리보기 문구는 게임에 넣지 마세요.

레이어는 배경 → 로고 → 다람이 → 메뉴 판 → 버튼 → 글자 순서입니다. 저장 존재 여부에 따른 이어하기/불러오기 활성화, 음악 출처, 기존 메뉴 동작은 현행 코드를 유지해야 합니다. 색/미리보기의 활성 상태는 예시입니다.

PNG 전체를 게임 화면으로 붙이지 말고 assets의 부품을 별도 배치하세요. 전체 레이아웃을 기준 1280x720에서 균등 확대/축소하고, 버튼만 따로 작게 만들지 마세요. 화면비가 다르면 안전 영역을 확인하세요. 파일의 투명 여백과 실제 그림 영역은 다릅니다.

생성 이미지 기반이므로 미세 가장자리와 작은 크기의 가독성은 실제 배경에서 추가 확인이 필요합니다. 엄밀한2x2픽셀격자본이 아니며 게임 코드 적용/빌드/배포는 수행하지 않았습니다.
