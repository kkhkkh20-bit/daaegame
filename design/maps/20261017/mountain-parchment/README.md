# 숲·산길 지도 양피지 통일

2026-10-17 소유자 요청: 외부 지도 중 양피지 그림에서 벗어난 화면을 확인하고, 맞추거나 제거할지 결정.

마을은 갈색 잉크 지도인데 숲·산길만 파란 설경 일러스트였다. 산 지도에는 깊은 숲·시설·온실·제단의 독립된 이동 역할이 있으므로 유지하고 양피지 선화로 통일했다. 작은 반복 무늬·종이 알갱이는 넣지 않았다.

- `discovered.png`: 기존 `design/maps/20261017/mountain-discovered.webp`의 장소 배치와 현재 `game/assets/room13-map-village.webp`의 갈색 잉크 스타일을 참조한 생성 원본.
- `hidden.png`: 위 원본에서 온실·제단만 평범한 숲으로 바꾼 편집 원본. 다른 영역의 구도는 유지.
- 런타임 기본 지도는 `dev/import_art.py`로 WebP 변환. 발견 이미지·선택 마스크는 `dev/make_cartography_layers.py`로 생성한다. 그림을 코드로 다시 그리지 않는다.
- 선택 마스크의 시설·온실·제단 외곽은 새 그림에서 측정했다. 위치별 대표 클릭점과 발견 조건은 유지했다.
- 숨겨진 장소 두 개는 기존 발견 조건이 충족된 경우에만 원본 패치로 나타난다. 일반 선택 레이어는 숨김 지도에서 잘라 기존 그림이 다시 드러나지 않게 한다.
