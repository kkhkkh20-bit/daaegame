5. 사용자 검토 후 승인된 자산만 별도 구현 작업에서 연결하고 저장/불러오기·증거 분기·모바일 음량을 회귀 검사합니다.

## 검토 상태와 자동 적용 금지
- 신규 이미지 15장은 모두 검토 후보입니다. 이미지 생성·디지털 QA가 게임 적용 승인을 뜻하지 않습니다.
- 증거 회수 후 객실 3장: NO_AUTO_APPLY. 금속 제거는 확인했지만 촛농과 갈색 흔적의 연속성이 달라졌으므로 보류합니다. floor_preserved 분기에 자동 채택하지 마세요.
- 책장 확대 2장과 통로 열림 객실 3장: 공간 연결의 사용자 승인이 필요합니다.
- E09 바닥 증거 2장은 tight 수정본으로 QA 완료입니다. 실제 게임 배치·분기 연결은 미검증입니다.
- 합성 효과음 19종(WAV+OGG)과 CC0 외부 후보 20종: 디지털 파일 검사 결과만 제공하며 실제 청음·게임 믹스·모바일 청취·런타임 연결은 미실시입니다.
- 현재 제작 중인 43명 캐릭터 모션, 신규 구조 CG와 구금 장면은 이 묶음에 없습니다.

## 기준 버전 주의
이 브랜치는 업로드 직전 확인한 main `8ac0342e50e5c77026a28e3ddae76e9d49c5dc25` (0.17.0-dev)에서 분기했습니다. 포함된 스토리·음원 감사의 기준 소스는 이전 `5e6c2c53ae067b7fc2eb9d10075320587a342f0e` (0.16.2)입니다. 0.17.0-dev에는 토론 엔진과 433개 표시 문자열 변경이 있으므로 이벤트 키와 화면 연결을 현행 코드에서 다시 확인해야 합니다. 함께 포함한 최신0170_변경대조_부록.txt에서 커밋 고정 ZIP과 0.16.2의 정적 대조를 완료했습니다. 실제 런타임 실행 검증은 하지 않았습니다.

## 출처·구성
- 스토리 패키지: 전달용 ZIP의 51개 파일만 선별했습니다. source/raw/production 및 원본 ZIP은 제외했습니다.
- 합성음: 외부 샘플 없는 신규 19종, 표현 규칙, 이벤트 규격, 수치 QA, 3개 청음 비교를 포함합니다. 대형 참조 원음·재구성 원음·생성 도구는 제외했습니다. 원본 문서의 해당 경로는 제작 감사 이력이며 이 묶음의 실행 의존성이 아닙니다.
- 무료 CC0: 선별 목록의 82개 파일만 포함합니다. 선택된 원음/게임용 변환본, 원본 합성음 비교, 라이선스, 출처 증빙, 해시를 보존했습니다. 대형 원본 팩은 제외했습니다.
- 합성음 비교 믹스의 기존 프로젝트 음악은 관련 크레딧과 악기 라이선스를 보존했습니다. 외부 CC0 후보와 프로젝트 기존 음원의 권리 구분을 유지하세요.
- 전체 파일 무결성은 `SHA256SUMS.txt`에서 확인합니다. 기존 각 패키지의 manifest와 감사표는 기준 버전의 기록을 보존합니다.
