# Claude 인수인계: 무료 효과음 20개 비교안

## 이번 변경의 범위

사용자는 무료 효과음을 조사해서 듣고 넣어도 좋다고 했다. 이 결과물은 상업용으로 쓸 수 있는 CC0 자료 20개를 확보해 기존 합성 19종과 비교하도록 준비한 자산 검토 묶음이다. 실제 청음 수단이 없어 후보를 최종 승인하지 않았으며 게임 코드나 배포를 바꾸지 않았다. 구현 담당은 Claude다.

## 제일 먼저 할 일

1. `preview/index.html`에서 낮은 볼륨부터 A/B 청음한다. 사용자가 고른 결과 JSON이 있으면 함께 확인한다.
2. `event_mapping.json`의 기존 이벤트 계약을 읽고 새 증거/제시/선택/물리 상태 의미를 보존한다.
3. 무료 후보와 합성안 중 이벤트마다 하나를 선택한다. 여러 후보 전부를 겹쳐 넣지 않는다. 물리 레이어가 필요하면 별도 렌더와 출처 기록을 남긴다.
4. 채택한 `selected/game_wav/` 파일만 게임의 새 SFX 하위 폴더에 복사한다. 원본을 덮어쓰지 않는다.
5. 채택한 파일의 SHA-256, 수정 사항, 크레딧을 최종 빌드에 보존한다.

## 우선 검토할 매핑

- 선택 확인: `kenney_click1` 또는 `kenney_select_001` ↔ `choice_confirm`
- 취소: `kenney_back_001` ↔ `choice_cancel`
- 증거 획득: `kenney_confirmation_001` ↔ `evidence_acquire`
- 자료 제시: `kenney_pluck_001` ↔ `evidence_present`
- 수첩 열기/페이지: `luckius_paper_1/2` ↔ `notebook_open/page`
- 레버 올림/내림: `bmaczero_mechanical1/2` ↔ `mechanism_lever_on/off`
- 안쪽 손잡이: `bmaczero_lightclunk1` ↔ `passage_exit_release`
- 잠긴 손잡이: `coughe_locked_jiggle` ↔ `book_latch_locked`
- 걸쇠 해제: `coughe_unlock_door` ↔ `book_latch_unlock`
- 걸쇠 복귀의 접촉층: `coughe_door_lock`
- 일반 문 열기: `coughe_door_open`; 강제 개방에는 쓰지 않는다.
- 나무 발걸음 A/B: `kenney_footstep_wood_000/001`; 실제 이동 장면이 있을 때만 별도 이벤트 등록
- 목재 충격 3개: 선택적으로 소도구/문/책장 접촉층에 사용. 전체 기계 동작을 표현하는 완성음으로 단정하지 않는다.

이 목록은 파일명/제작자 설명/수치에 근거한 제안이다. 직접 듣고 채택을 결정한다. 긴장/추론/모순/타이핑은 기존 합성안부터 검토하며 억지로 무료 파일로 바꾸지 않는다.

## 기술상 주의

일부 원본 OGG와 부동소수점 WAV는 디코딩 피크가 0 dBFS를 넘는다. 정수 PCM으로 먼저 바꾼 뒤 볼륨을 낮추면 이미 잘린 피크를 복구할 수 없다. 이 패키지는 float 디코딩 → 감쇠 → PCM16 순서로 처리했고 변환본 20개에서 클리핑 샘플은 0이다. 원본 녹음의 기존 왜곡까지 제거했다고 주장하지 않는다.

가공본의 목표 피크는 이벤트별 -12~-21 dBFS이며, 기존 `sound_events.json` 채널 게인은 시작값이다. 피크 정렬은 체감 음량 정렬이 아니므로 BGM과 함께 다시 조절한다. 기존 사용자 음량/음소거 설정을 덮어쓰지 않는다.

메모: `bmaczero_mechanical1`은 약 917ms, `kenney_plank_medium_000`은 약 779ms다. 장면 전환으로 소리가 중간에 잘리는지 검증한다. 필요하면 사용자가 승인한 음원의 비파괴 파생본을 따로 만들고 변형 기록을 남긴다.

## 중복/스포일러 방지

- `r13_grant()`에 획득 신호가 이미 있다. 새 호출을 중복 추가하지 말고 중앙 파일 매핑을 교체한다.
- 자료 카드 표시에도 기존 page 호출이 있다. 제시 확정 후 한 번만.
- 선택 확인 직후 증거/추론 신호가 있으면 확인음을 생략한다.
- 로드/롤백/기록/hover/redraw/카드 순환은 새 사건이 아니다.
- 증거 제시 시 정답/실패를 미리 소리로 누설하지 않는다.
- 레버 올림/내림, 잠긴 책장, 해제, 안쪽 출구, 구조용 강제 개방의 상태가 다름을 보존한다.
- 기존에 비활성화한 마차·말발굽·까마귀 등의 불만족 효과를 되살리지 않는다.

## 완료 보고 기준

자산 있음 / 라이선스 확인 / 수치 검사 / 실제 청음 / 게임 연결 / 회귀 / 배포 확인을 각각 보고한다. 청음은 PC·휴대폰·헤드폰, 기본/낮은 음량, 여러 BGM, 빠른 연속 입력을 포함한다.

빌드 설정에 `**.txt` 제외가 있으면 라이선스가 소스에만 남을 수 있다. 최종 ZIP/웹 크레딧에서 실제 보존을 확인한다. CC0는 표기 의무가 없어도 프로젝트 출처 기록은 유지하는 편이 좋다.
