GitHub 커넥터로 커밋/변경 파일을 확인했다. 이 저장소는 .rpy가 직접 체크인된 구조가 아니라 소스 전달 ZIP을 제공하므로 이전 .rpy 직접 조회 404는 소스 부재를 뜻하지 않았다. 이번에는 커밋 고정 ZIP을 실제로 내려받아 풀고 0.16.2 전달본과 비교했다. 실행 SDK/대부분 원화가 없는 소스여서 여전히 정적검토이며 실행하지 않았다. 런타임 코드 변경 없음.
이하 경로는 ZIP 내부 experiments/renpy-ch1/game/ 기준이다.

1. 원탁/공개 회의 판정 갱신
신규 systems/room13_debate.rpy가 현재 본편에 연결되어 있다.
- room13.rpy:551 r13_argument_menu는 r13_debate_run을 호출한다.
- 7일째 C1–C4와 14일째 F1–F4를 공통 엔진으로 처리한다.
- 발언의 강조 문구를 자료로 반박, 사실인 말 구별, 무료 되묻기, 숨은 발언 공개, 힌트, 정답/지나침/약함의 결론 3지선다가 구현됐다.
- 신뢰는 5칸. 틀린 자료/결론에 감점, 0칸이면 해당 논점만 초기화한다. 수집 자료/다른 논점은 유지한다.
- systems/room13_debate.rpy:371–388에서 좌석별 입장과 집계를 계산한다. :487–498 화면은 상단 이름표 색상과 인원수로 이를 표시한다.
- 중요한 구분: 현재 '좌석'은 데이터와 이름표이다. 캐릭터가 원탁에 실제로 앉은 공간형 화면은 아니다. :463 이후는 어두운 덮개 + 좌측 발언 카드 + 우측 행동 패널이다.
- 여론은 여전히 연출이다. r13_prove/propositions를 통해 기존 C2/C4 판정과 연결되며 과반 표결이 결말을 바꾸는 규칙은 없다. docs/DESIGN_MEETING_0170.md도 이를 명시한다.

따라서 앞선 보고서의 '종이 패널 심문만 존재'는 0.17 기준으로 갱신해야 한다. 구현 계획도 옛 r13_debate 패널을 확장하기보다 새 r13_debate_run/board의 판정과 상태를 유지한 채 표시층을 공간형으로 교체하는 것이 적합하다. 이미 생긴 신뢰·발언 반박·좌석별 입장 표시를 중복 구현하지 않는다.

2. 변화 없는 표현 기반

3. 구조/문 잠금/심박 차이
- room13.rpy:475–484의 핵심 흐름은 동일하다. 문 아래 연기 CG → 안쪽 빗장 대사 → 할머니가 공구를 가져옴 → 도토가 지렛대를 받아 너울과 문을 받침 → impact → 상태 변경 → 구조 CG → 발견 대사.
- 0.17에는 주변 법정/행정 용어를 쉽게 고친 대사 변화가 있지만 잠긴 문 조사, 도구 선택, 침대 아래 클릭은 추가되지 않았다.
- 심박 source_pulse 및 scene_fx 채널은 변경 없음. source_pause_effects의 source_mode 조건, r13_scene 전환에서 심박 정지되는 주의사항도 그대로다.
- 현재 rescue CG와 '침대 아래에서 다람이가 손을 뻗었다' 대사는 방 진입 직후 나온다. 새 발견 순서를 만들려면 이 CG/대사를 침대 아래 클릭 뒤로 옮겨야 한다. 방 전체 샷에서 다람이를 먼저 노출하면 새 연출 의도가 깨진다.

4. 최신 사용자 순서를 반영한 신규 작업 범위
원거리에서 연기 나는 여관 → 입구 군중 → 복도의 잠긴 문 → 짧은 주변 조사 및 도구로 파괴 → 방 전체(작은 불, 피 흘리는 부엉이, 다람이는 보이지 않음) → 침대 아래 클릭 → 발견/구출.
- 원거리 여관 및 입구 군중 샷, 복도 잠금 상호작용, 방 전체 발견 전 화면, 침대 아래 선택 영역이 신규다.
- 구조는 외부 영상이 아닌 게임 내 CG/레이어 애니메이션으로 구현한다. 기존 구조 CG는 클릭 이후의 발견/구출에 재활용할 수 있는지 실제 원화를 확인해야 한다.
- 문은 안쪽 빗장이므로 열쇠로 여는 정답을 만들지 않는다. 문 파손 방향은 기존 왼쪽 고정부 파손/오른쪽 경첩 유지/실내 방향 개방과 일치시킨다.
- 할머니가 처음부터 공구를 든 채 군중에 서 있게 그리지 않는다. 현재 대사의 '공구 가져왔어'와 새 회의 C3(:85–107)의 '첫 비명 때 식당, 공구 가지러 주방에 간 뒤 행적 공백'을 함께 유지해야 한다. 등장 시간을 당기면 추리 증언의 근거가 달라진다.
- 새 방 전체 샷의 작은 불은 기존 '작은 깔개를 젖은 천으로 덮음, 침대는 타지 않음'과 맞춘다. 불 위치/피 위치/시신/촛대 위치는 이후 E07/E08/E14/E33 등 현장 기록과 모순되지 않도록 고정한다.
- 짧은 연출 상태와 필수 사건 상태를 분리한다. 침대 클릭 이전에 구조 후 기록/후속 메뉴가 열리지 않게 하되, 스킵할 때도 동일한 구출 완료·후속 선택으로 연결한다. 저장/로드·롤백에서 중복 증거 지급이나 심박 잔류가 없어야 한다.

5. 검증 구분
0.17 릴리스 노트는 회의 엔진 단위 테스트, SDK compile/lint, C1/C2 일부 흐름과 신뢰 초기화, 기존 공개 브라우저 QA 통과를 기록한다. 이는 게시본 작성자의 검증 기록이며 이번 검토자가 다시 실행한 결과가 아니다. 릴리스 노트도 14일 자연 완주와 실물 휴대폰은 미검증이라고 명시한다. 새 공간형 원탁/새 구조 연출은 아직 구현 전이므로 어떤 기존 QA도 이 신규 화면의 합격 근거가 될 수 없다.
