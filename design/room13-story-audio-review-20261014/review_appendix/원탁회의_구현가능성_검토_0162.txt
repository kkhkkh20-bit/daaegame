원탁회의 공간형 UI 구현 가능성 검토
검토일: 2026-10-14 / 대상: 전달받은 0.16.2 소스 및 원탁회의 공간형 UI 시안 v2

결론
현재 Ren’Py 구조로 구현 가능하다. 엔진 교체는 필요 없다. 전용 원탁 화면, 착석 에셋, 기존 심문 흐름과의 연결이 필요하다. 가장 작은 구현 범위는 전체 원탁 + 발언자 강조 + 기존 대사창 + 증거 제시다.

검증 한계
시안 이미지는 직접 확인했다. 소스 정적검토만 수행했고 실행 SDK 및 대부분의 이미지/음악 원본이 없는 전달본이라 실행하지 못했다. 지정 main SHA의 직접 파일 조회는 404였으므로 해당 커밋과 전달본의 완전한 동일성은 독립 검증하지 못했다. 기존 QA 보고서의 통과 내역을 이번 실행 결과로 간주하지 않는다. 런타임 코드 변경 없음.
이하 코드 경로는 experiments/renpy-ch1/game/ 기준이다.

1. 기존 기능과 새 작업
- 좌석 배치: screens.rpy:344 round_table에 7인 고정 좌표, 별도 밤이, 전경 table.png가 존재한다. 그러나 winter.rpy:130 start→room13_start 본편에서는 이 화면을 부르지 않는다. 본편 r13_trial은 배경+대사+종이 패널 심문이다. 회의 참석자를 고정한 전용 좌석 화면을 연결해야 한다.
- 착석: room13_acting.rpy는 머리/손/발/좌석 접점과 자세 메타데이터를 지원한다. 토리 벤치, 서연 의자 자세 등 일부 착석 원화가 있지만 전 참석자의 원탁 착석 세트는 확인되지 않았다. 식당은 나비 외 주민을 neutral로 강제한다(:306). 단순 서 있는 그림 가림은 시안과 같은 자연스러운 팔/어깨를 만들지 못한다.
- 테이블 가림: 옛 round_table의 테이블 전경 및 room13_acting.rpy:103,457의 R13FurnitureMask/AlphaMask 재사용 가능. 테이블 전체를 위에 올리면 손까지 가려지므로 몸체→테이블 전경→탁상 위 손/소품 등 레이어 설계 필요.
- 발언자: room13_rules.rpy:274 r13_speaker의 표정/큰 이미지/동일 화자 등장 중복 방지 재사용 가능. 현재는 단일 r13_visitor 교체 방식이므로 참석자를 유지하며 한 명을 강조하는 처리는 신규. 최소판은 좌석 밝기 강조, 확대는 별도 화면 전환 권장.
- 증거 제시: room13.rpy:535–579 r13_argument, r13_book(hearing=True), r13_submit, r13_material_corner 이미 연결됨. 새 하단 버튼과 연결 가능. 끼어들기는 기존 되묻기로 연결할지 별도 발언 선택을 만들지 정해야 한다. 실시간 타이밍 입력 기능은 아니다.
- 투표: 옛 source_screens.rpy:228 및 timeline.rpy에 표시/계산이 있지만 현 본편 r13_verdict(:621)는 C2/C4 입증 여부로 판정한다. 실제 주민 표결은 현재 본편에 신규 규칙이다. 단순 찬반 연출과 표수가 결말을 바꾸는 시스템을 구분해야 한다.
- 대사/발언 기록: screens.rpy:84 say, room13.rpy:32 r13_lines, 기록/백로그 재사용 가능. 머리 위 말풍선은 신규 좌표/폭/겹침 처리. 문자와 이름은 그림에 굽지 말고 실시간 텍스트로 표시해야 한다. 복수 말풍선은 읽기 순서도 정해야 한다.
- 모바일: 1280×720 기준(options.rpy), 작은 화면 큰 글씨 자동 적용(room13_readability.rpy). 큰 글씨 대사창은 y=454부터여서 테이블/손/버튼과 충돌할 수 있다(screens.rpy:90). 주 발언 하나를 크게 표시하고 증거/기록은 덮개 화면으로 여는 구성이 안전하다.

2. 추가 에셋
인물/문자 없는 원탁 배경, 투명 테이블 전경과 필요한 의자 전경, 좌석 방향별 착석 기본 그림, 주요 발언 표정/자세, 탁상 위 손과 소품 또는 동등한 마스크 설계, 머리/손/좌석 접점 좌표.
현재 시안은 합쳐진 한 장이다. 인물/버튼/테이블의 독립 조작용 에셋으로 그대로 사용할 수 없다.

3. 최소 구현 단계
1) 1280×720 원탁 전용 화면과 참석자/좌석 데이터
2) 배경·인물·테이블·손 레이어 정지 화면 검증
3) r13_lines에 발언자 상태 연결, 기존 대사창·백로그 유지
4) 기존 증거 제시·되묻기·논리 연결 버튼 연결
5) 선택적으로 클로즈업·말풍선·표결 추가
6) 저장/로드·취소 복귀·연타·자동 읽기·큰 글씨·모바일 가로 검증

4. 위험
- 시안 1672×941과 게임 1280×720의 좌표 변환을 통일하고 그림/클릭영역/말풍선에 동일 적용.
- 가려진 몸을 누르지 않게 렌더와 같은 마스크로 클릭 판정.
- 모든 참석자의 큰 텍스처/미세움직임/마스크를 매 프레임 갱신하지 말고 발언자 중심으로 제한.
- 신규 모달은 room13_dialogue_rhythm.rpy:78의 자동 음향 차단 등 관련 차단 조건에도 연결.
- 새 상태는 기본값/업그레이드를 마련하고 기존 저장 호환 검증.
