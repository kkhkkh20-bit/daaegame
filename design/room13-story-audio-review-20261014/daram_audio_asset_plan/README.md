# 다람탐정 소리와 대사 연출 검토 묶음

19개 효과음 후보와 이후 모든 대사 작성자가 사용할 공통 표현 규칙입니다. 게임 대사·런타임·저장소·배포는 수정하지 않았습니다.

## 먼저 보기

1. `preview/index.html`을 열어 소리와 타이핑 비교 3종을 들어보세요. 자동 재생은 없고 전체 음량·정지 버튼이 있습니다.
2. `docs/AUTHORING_RULES.md`는 중요어 빨강/굵게, 독백의 파란 대화창, 타이핑, 사건별 효과음의 지속 규칙입니다.
3. `docs/CLAUDE_HANDOFF.md`는 실제 연결 순서와 회귀 테스트입니다.
4. `docs/AUDIO_AUDIT.md`는 기존 자산, 없는 자산, 현재 확인된 문제와 출처입니다.

## 파일

- `audio/wav`, `audio/ogg`: 새 19종. 17개 이벤트에서 사용하며 타이핑은 3변형입니다.
- `sound_manifest.json`: 길이·피크·해시·출처
- `sound_events.json`, `audio_event_inventory.csv`: 연결 시점·레벨·우선순위·중복 억제
- `provenance_license_manifest.json`: 신규·기존 참조의 권리 구분
- `existing_runtime_audio.json`: 빌드 메타데이터의 기존 40개 음원
- `reference/repository_audio_inventory.json`: 저장소 독립 음원 49개
- `qa`: 디지털 검사와 12초 청음 비교
- `tools`: 재현 가능한 자산 생성·감사·미리보기 도구

## 검증 상태

신규 WAV/OGG 파일 존재와 신호 검사는 통과했습니다. 실제 사람 청음, 실제 브라우저 게임의 믹스, 모바일 기기 청취, 런타임 연결은 아직 수행하지 않았습니다. `preview/index.html`은 검토 페이지이고 실제 게임 화면이 아닙니다.
