# 다람탐정 지도 적용 준비용 인계

이 패키지는 배경·분리 라벨·배치 데이터·독립 HTML 참고 예제입니다. 기존 게임에 적용하거나 배포한 결과물이 아닙니다.

## 구성
- assets/village_clean.png: 글자와 이름표를 뺀 전체 지도 배경. 건물과 지형은 배경에 합쳐져 있습니다. 건물별 분리 스티커가 아닙니다.
- assets/notebook_frame_1280x720.png: 기존 v2의 고정 노트 프레임 원본.
- assets/label_plate.svg: 이번 참고 예제용으로 코드로 만든 크림색 라벨판. 배경에서 추출한 그림이 아닙니다.
- layout.json / layout.js / labels.csv: 기존 13개 장소 ID, 별도 한글 이름, 라벨 중심, 잠정 선택 영역. JS는 HTML을 서버 없이 열기 위한 동일 데이터 복사본입니다.
- reference.html: 고정 프레임 안에서 지도 내용을 균일 확대·축소하고 양축 드래그하는 독립 참고 예제. 장소를 누르면 선택 이름만 바뀝니다. 게임 이동·저장·사건 기능이 없습니다.
- approved_style_preview.png: 앞서 확인한 전체 지도 스타일 시안. 글자가 합쳐진 참고 그림이며 실제 배경에는 쓰지 않습니다.
- original_source_cartography_reference.json: 이전 원본 지도 좌표를 비교하기 위한 읽기 전용 참고. 새 배경의 클릭 다각형으로 그대로 사용하면 안 됩니다.
- verification.json / bitmap-sha256.json: 수행한 정적 검사와 파일 해시.

## 열기
ZIP을 전체 해제한 뒤 reference.html을 엽니다. 기본은 확대 보기이며 지도 안을 드래그하거나 방향키로 둘러볼 수 있습니다. ‘전체 보기’는 전체 지도를 균일 축소하고, ‘확대 보기’는 자세히 볼 크기로 돌립니다. 고정 프레임·하단 안내는 지도와 함께 움직이지 않습니다. 이 두 보기 버튼은 참고 예제의 검수 보조이며 게임에 새 기능을 추가하자는 제안이 아닙니다.

## 기존 게임 연결 시
1. 기존 13개 목적지 ID를 유지합니다. 이름표 텍스트는 예제의 고정 문자열 대신 r13_map_label(id) 등 현재 게임의 라벨 함수를 사용합니다. 숲의 교환함 보조명과 현재 위치 등 기존 동적 문구를 보존합니다.
2. r13_map_nodes, r13_map_locked_nodes, r13_map_discovered 및 실제 이동 허용 판정을 유지합니다. 이 HTML은 전체 13곳을 보여 주는 디자인 참고일 뿐, 모든 장소를 즉시 공개하는 게임 규칙이 아닙니다.
3. 미발견 통로·지하·온실·제단을 공개하지 않습니다. 학교 장작 창고 등 기존 사건 장소 별칭, 여관 안·숲과 산길 탭을 유지합니다.
4. 클릭은 장소 선택만 하고 이동은 기존 확정 버튼으로 처리합니다. 취소·드래그가 시간·현재 위치·사건 상태를 바꾸지 않도록 합니다.
5. 예제의 드래그 임계값은 실제 화면 CSS 픽셀 기준 8px입니다. 임계값을 넘은 제스처는 마지막에 장소를 선택하지 않으며 pointercancel도 선택하지 않습니다. 실제 PC·터치 환경에서 임계값을 다시 검수해야 합니다.
6. 지도는 원본 비율을 유지해 균일 배율로 그리고 뷰포트에서 잘라 봅니다. 가로를 두 배로 늘리거나 건물을 한 화면에 맞추려고 압축하지 않습니다.
7. 라벨과 건물은 같은 지도 좌표계를 사용합니다. 좌표·라벨판 크기·잠정 hit rect는 최종 런타임 배율에서 조정해야 합니다.

## 원본과 차이·검증 범위
원본 기준은 main 08aa1a0a5ee6d8b5dd6c06f1de7bcee134b8397e의 2304×1344 마을 그림입니다. 북서쪽 숲, 북쪽 학교, 서쪽 진료실·큰 여관, 중앙 장터·광장, 동쪽 수리점·창고, 남중앙 입구와 목교, 남쪽 강변 빨래터·솜이네의 큰 배치를 참고했습니다. 새 그림은 스타일을 다시 그린 것이므로 건물 윤곽과 세부 지형이 픽셀 단위로 일치하지 않습니다.

잠정 선택 영역은 별도 배경을 눈으로 확인해 제안한 사각형입니다. 기존 런타임 다각형이나 알파 클릭 영역의 검증 완료본이 아닙니다. 배경의 건물은 합쳐져 있어 건물만 떠오르는 효과를 그대로 제공하지 않습니다. 그 효과가 필요하면 승인 범위 안에서 개별 그림·마스크를 별도로 제작·검수해야 합니다.

정적 데이터·소스 문법·파일 무결성 및 이미지 육안 검수만 기록합니다. 실제 게임 적용, 브라우저 포인터 조작, 모바일 실기기, 저장 복원, 사건 조건 회귀 검사를 수행했다고 주장하지 않습니다. 배경·라벨·예제를 기존 게임에 통합한 뒤 이 검사를 마쳐야 적용 완료로 볼 수 있습니다.
