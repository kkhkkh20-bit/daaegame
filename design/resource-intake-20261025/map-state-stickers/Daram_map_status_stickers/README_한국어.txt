다람탐정 지도 상태 스티커 4종

이 묶음은 이미지 에셋과 크기·대비 확인 시안입니다. 실제 게임에 적용하거나 배포하지 않았습니다. 새 게임 상태·장소·대화 조건을 추가하지 않습니다.

표시 의미
- current_location: 기존 현재 위치를 표시하는 빨간 핀과 발자국.
- map_selected: 기존 선택 중인 장소를 표시하는 남색 체크 배지. 선택과 실제 이동은 다릅니다. 조사 완료를 의미하지 않습니다.
- locked: 이미 공개된 장소가 기존 규칙상 잠겨 있을 때 쓰는 황동 자물쇠. 미발견·비공개 장소의 위치를 자물쇠로 드러내면 안 됩니다.
- new_dialogue: 기존 게임 엔진의 새 대화 표시 조건이 실제 충족될 때만 쓰는 말풍선. 새 알림 시스템이나 조건의 구현을 뜻하지 않습니다.

파일
- originals/: 생성된 투명 PNG 원본 4개. 바이트 단위로 보존했습니다.
- runtime/48, 64, 96, 128/: 알파 8/255 이상인 시각적 윤곽 기준으로 바깥 여백을 제외하고 그림 전체를 균일 축소하고 정사각 캔버스 중앙에 배치한 파생 PNG. 그림의 긴 변은 캔버스의 약 84%입니다. 형태·색·비율을 다시 그리거나 변형하지 않았습니다.
- manifest.json: 원본과 파생 파일의 크기, 실제 알파 픽셀 수, 비투명 영역, SHA-256 및 바이트 수.
- preview/contact_sheet.png 및 HTML: 크림·남색 배경에서 4가지 실제 픽셀 크기를 확인하는 이미지.
- preview/placement_mockup.png 및 HTML: 승인된 재작화 지도 위의 예시 배치 시안. 실제 게임 상태나 최종 좌표가 아닙니다.

적용 시 유의
아이콘 표시 여부·장소 공개 여부·잠금·이동·대화 가능 여부는 기존 게임 판정을 그대로 사용해야 합니다. 이 묶음에는 실행 코드 통합, 상태 판정, 저장 데이터 변경, 클릭 영역 변경, 새 시스템이 포함되어 있지 않습니다. 지도 확대율과 화면 밀도를 고려하여 필요한 PNG 크기를 선택하세요. 생성 그림은 크기별 가독성을 검토한 뒤 적용해야 합니다.
