# 다람탐정 UI 버튼 상태 세트 v1

기존 승인 자산을 그대로 사용한 시각 상태 내보내기입니다. 새 화면이나 기능을 추가하지 않았고, 게임 코드·동작·진행 로직은 변경하지 않았습니다.

## 구성
- primary: 기존 빨간 주 버튼, 160 × 52 px.
- standard: 기존 크림색 일반 버튼, 160 × 52 px.
- wide_choice: 기존 작은 패널을 사용하는 가로형 선택 버튼용 자산, 240 × 60 px. 새로운 질문 카드 디자인이 아닙니다.
- 각 계열에 basic / pressed / selected / disabled PNG 4개, 총 12개.
- PNG에는 텍스트가 없으며 배경은 투명합니다.
- source 폴더에는 사용한 원본 3개를 수정 없이 포함했습니다.

## 상태 조건과 표시
- basic: 기본 상태. 원본 PNG와 바이트 단위로 같습니다.
- pressed: 누르는 동안 원본 전체를 아래로 2 px 이동. 캔버스와 클릭 영역은 고정합니다.
- selected: 선택이 유지되는 상태에 원본 바깥쪽으로 빨간 2 px 테두리만 추가했습니다.
- disabled: 사용 불가 상태. RGB 색상은 유지하고 원본 알파값만 45%로 줄였습니다.
- 동시에 해당하면 disabled → pressed → selected → basic 순서로 표시하는 것을 권장합니다. 기존 게임에 이 상태가 이미 있는 경우에만 매핑하십시오.

## 캔버스·클릭 영역
모든 좌표는 각 PNG의 왼쪽 위를 원점으로 하며 같은 계열의 모든 상태에서 동일합니다.
- primary / standard: 캔버스 160 × 52, 클릭 영역 x=16, y=10, width=128, height=32.
- wide_choice: 캔버스 240 × 60, 클릭 영역 x=8, y=8, width=224, height=44.
- 이 클릭 영역은 자산 기준 권장 값이며, 기존 런타임 클릭 영역을 자동 변경하지 않습니다.
- 실제 버튼 문구는 런타임 텍스트로 별도 렌더링합니다. pressed일 때 텍스트도 아래로 2 px 이동하고, 클릭 영역은 움직이지 마십시오.
- 자산을 전체로 늘리거나 9-slice 하지 않았습니다. 화면 배율 변경 시 원본 비율을 유지하십시오. 긴 문구 때문에 더 큰 카드가 필요하면 별도 승인된 원본을 사용해야 합니다.

## 재생성·검증
- build.cjs: Node.js + Sharp 기반의 상태 합성 스크립트. 원본 그림을 다시 그리지 않습니다.
- manifest.json: 파일 목록, 캔버스 크기, 클릭 영역, 텍스트 이동값.
- preview.png: 상태 비교용 미리보기. 미리보기의 제목·라벨·배경은 실제 PNG 자산에 포함되지 않습니다.
- 이 패키지는 자산 전달 전용입니다. 저장소 또는 게임에 통합하지 않았습니다.
