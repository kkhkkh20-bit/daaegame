다람탐정 추가 UI 에셋 요청서
기준: 2026-10-25 개발본 / 1280×720 논리 화면

제작 방향
귀엽고 화려한 다람이의 스티커 수첩. 크림 종이, 진한 갈색 윤곽, 남색·빨강 포인트를 유지한다. 이야기의 잔혹함을 장식이나 정답 표시로 드러내지 않는다. 새 디자인 제안보다 현재 부품의 비율·여백·상태를 보완하는 작업이다. 예전 2026-10-24 선택창 원본 요청서는 이번 제작 목록으로 사용하지 않는다.

1. 먼저 필요한 것: 정사각 아이콘 버튼 4장
파일: square_standard_basic / pressed / selected / disabled.png
화면에서 보이는 종이 크기: 64×64. 공통 PNG 캔버스: 80×80, 종이는 (8,8)부터 64×64 안에 배치한다.
상태 장식까지 포함한 그림은 네 상태 모두 같은 캔버스 안에 들어가야 한다. 선택 테두리를 위한 여백도 미리 확보한다.
용도: 조사 화면의 더보기/설정처럼 글자 없이 아이콘만 들어가는 버튼. 현재 새 상태 세트에는 가로형만 있어 이 버튼은 이전 배경을 유지 중이다.
중앙 내용 안전영역: 40×40. 실제 아이콘은 게임에서 30×30으로 올리므로 배경에 기호나 글자를 그리지 않는다.
원본 크림 버튼과 같은 종이·선·모서리로 만든다. 가로형 버튼을 정사각형으로 눌러 만들지 않는다.
기존 클릭영역은 PC 64×64이며, 터치영역 크기는 코드가 별도로 처리한다. 투명 여백이 클릭영역을 결정하지 않는다.

2. 다음 보완: 굵은 글씨가 들어갈 버튼의 표시 비율 16장
현재 받은 160×52 원본은 그대로 보관·사용 중이다. 강제로 늘리지 않고 맞추다 보니, 일부 버튼의 보이는 높이와 글자가 작아진다. 아래 두 규격은 기존 버튼의 재질과 윤곽을 유지한 크기별 파생본으로 제작한다.

A. 메인 메뉴: main_primary / main_standard × basic, pressed, selected, disabled = 8장
보이는 종이: 184×60 / 공통 캔버스: 200×76 / 종이 시작점 (8,8).
중앙 안전영역: 164×42. 문구 Pretendard Bold 28px + 아이콘30px + 간격10px를 넣을 수 있어야 한다.
이어하기·처음부터·불러오기·설정 네 버튼은 같은 표시 폭을 쓴다. 빨강과 크림도 같은 캔버스·배치·외곽 규격을 사용한다.
현재 버튼의 화면 슬롯: x44 / 242 / 440 / 638, y616, 각각184×76. 납품 PNG의 바깥 여백은 구현 시 공통 기준으로 처리하며 슬롯은 유지한다.

B. 질문창 하단: topic_primary / topic_standard × 같은 4상태 = 8장
보이는 종이: 146×52 / 공통 캔버스: 162×68 / 종이 시작점 (8,8).
중앙 안전영역: 130×36. 문구 Bold22~24px + 아이콘24px + 간격6px가 들어가는 공간을 확보한다. 긴 글자는 게임에서 처리하며 이미지에 합치지 않는다.
자료 제시·기록·더보기·돌아가기 모두 같은 표시 폭을 쓴다.
현재 슬롯: x572 / 726 / 880 / 1034, y574(PC) 또는550(터치), 폭146, 높이64(PC)/88(터치).
이 규격은 질문 하단 도구 버튼용이다. 질문 목록이나 편지 선택 카드의 디자인은 교체하지 않는다.

3. 상태 공통 규칙
basic: 기존 기본 재질.
pressed: 캔버스·외곽 규격·중심 정렬은 유지하고, 종이의 시각적 눌림만 최대2px. 글자·아이콘의2px 이동은 게임에서 처리하므로 이미지에 글자를 넣지 않는다.
selected: 기존 선택 표시 방식 유지. 같은 위치에 강조하고, 선이 겹겹이 중복되지 않도록 기본 윤곽과 구분한다. 정답이나 조사 완료를 의미하지 않는다.
disabled: 기존 비활성처럼 알파를 낮추되 작은 크기에서도 형태가 읽히도록 한다. 클릭 가능 여부는 게임이 결정한다.
동시 상태 우선순위는 비활성→누름→선택→기본. 게임에 없는 상태나 새 해금 조건을 제작자가 추가하지 않는다.
네 상태는 같은 PNG 크기·배치 좌표를 사용한다. 원본의 가로·세로를 따로 늘리거나 9-slice로 길게 늘리는 납품은 이번 요청에 포함하지 않는다. 확대 원본을 제공한다면 전체를 정확히2배로 만들어 배율을 적는다.

4. 이미 있어서 다시 제작하지 않을 것
13곳 전체 마을 지도/좌표, 수첩 프레임, 지도 상태4종, 빨강·크림·넓은 버튼 상태12종, 다이어리 장식6종, 현재 메인 포스터·제목, 기존 질문·편지 선택 카드, 캐릭터 얼굴 스티커.
지도 새 대화 스티커도 이미 있다. 지도에서의 표시 조건 연결은 개발 작업이며, 에셋을 다시 만들 필요가 없다.
건물별 분리 스티커와 새 지도 배경은 이번 제작 범위가 아니다. 숨은 장소용 표시나 새 상태 아이콘도 요청하지 않는다.

5. 전달물과 확인 기준
1차는 정사각4장, 2차는 크기 보완16장. 총20장이고 각 파일 규격은 asset_specs.csv에 적었다.
투명 RGBA PNG, 원본과 표시용을 구분한다. manifest.json에 파일명/캔버스/실제 알파 경계/내용 안전영역/기준 표시 크기/상태/눌림 이동량/SHA-256을 기록한다.
원본 편집 파일이 있으면 함께 제공한다. PNG에는 텍스트·아이콘·게임 UI를 합성하지 않는다.
각 계열4상태를 같은 크기로 나란히 보여주는 미리보기와, 첨부한 현재 화면 위에 얹은1280×720 시안을 제공한다. 합성 시안과 실제 게임 캡처는 구분한다.
검수는 선 두께·외곽 중심·상태 전환 시 흔들림·안전영역·진한 고딕 글자 가독성·기존 부품과의 재질 일치를 본다. 테두리와 본문이 겹치거나 캔버스 끝에서 잘리면 납품 전 수정한다.
