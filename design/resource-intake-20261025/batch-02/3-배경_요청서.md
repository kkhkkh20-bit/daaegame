# 불타는 밤 — 배경 요청서 (2026-10-25)

소유자: "마을이 불타면 불탄 마을 배경 필요한 거 아니야?" — 맞다. 지금 있는 불 그림은 6~7일 장작 창고(`room13-pixel-panorama-woodshed-fire.webp`, `-woodshed-ruin.webp`)와 여관 난로 효과(`room13-fx-inn-fire-*`)뿐이고, 불타는 마을·광장·학교 그림은 없다. 불 소리(`amb-fire.mp3`)와 밤 음악은 있다.

장면 흐름(설계 `docs/design/WILD_NIGHT_DESIGN.md` 6장, 지시서 `지시서.md` 5~6장): 학교 교실에서 깨어남 → 복도 → 광장 → 산길 어귀 → 첫 굽이 폐온실 → 결말(다음 날 아침).

## 꼭 필요한 것 (기존 장소의 같은 구도로, 이 판 전용 변형)
| 파일 이름(안) | 장소·때 | 그림 내용 |
|---|---|---|
| `wild-school-classroom-night` | 학교 교실·밤 | 창밖이 붉게 물듦, 아이들 침상, 난로는 꺼짐 |
| `wild-school-hall-night` | 학교 복도·밤 | 연기가 낮게 깔림, 끝의 문이 열려 붉은 빛 |
| `wild-square-burning` | 광장·밤 | 언덕 위 큰 집들이 불탐, 3번 등은 푸르게, 사람들이 뒤엉킨 실루엣(얼굴 없이) |
| `wild-road-mouth-night` | 산길 어귀·밤 | 뒤로 불타는 마을이 내려다보임, 초소 난로의 푸른 불 |
| `wild-greenhouse-night` | 폐온실 낮은 문 안·밤 | 문틈으로 붉은 빛, 셋(또는 둘·혼자)이 숨는 자리 |
| `wild-village-dawn-ash` | 다음 날 아침·산길에서 본 마을 | 연기만 남은 마을, 타 버린 광장 이름판 |

## 있으면 좋은 것
- 광장 이름판 아래 재 속 물건 그림(엄마의 장갑 한 짝 / 도토리 두 알) — 결말 갈래별 한 장씩.
- 불길이 일렁이는 겹(효과용 투명 그림) — 기존 배경 위에 얹어 쓸 수 있게.

## 지킬 것
- 같은 장소의 기존 배경과 구도·크기를 맞춘다(기존 장소 파일을 바탕으로).
- 인물은 그리지 않는다(인물은 게임이 따로 세운다). 군중은 얼굴 없는 실루엣만.
- 지나치게 잔혹한 묘사는 피하고 불빛·연기·실루엣으로 무서움을 낸다(최악 결말 허용은 이야기로, 그림은 암시로).
- 그림이 오기 전에는 기존 밤 배경 + 불 소리로 대신하고, 받으면 바꾼다.
