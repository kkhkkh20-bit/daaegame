# 회의 선택·갈림길 화면 시안 v1

2026-10-25. 검토용 합성 시안이며 실제 플레이 캡처가 아닙니다. 게임 코드·화면·스토리·저장 기록은 변경하지 않았습니다. 명시적인 「적용」 승인 전에는 구현하지 않습니다.

## 6. 회의 기회를 다 쓴 뒤

파일: previews/06_회의선택_PC_1280x720.png, previews/06_회의선택_휴대폰가로_960x540.png

- 기능: 아빠 속말 「다 있었다. 그런데 이어 붙이지 못했다.」 뒤에 두 행동을 고릅니다. 「결과를 받아들인다」가 왼쪽 빨강 기본 강조, 「회의를 처음부터 다시」가 오른쪽 크림 보조 행동입니다.
- 필요한 이유: 패배를 이야기로 이어 가는 기본 흐름을 유지하면서 같은 회의를 다시 풀 기회를 명시적으로 선택하게 합니다.
- 기존과의 차이: 속말 뒤 곧바로 진 결과로 넘어가던 자리에 선택 한 번을 둡니다. 게임 오버·자동 재시작·새 회차 버튼이 아닙니다.
- 승인된 B 수첩/옵션 재질, 기존 빨강·크림 버튼 원본, Pretendard Regular를 재사용했습니다. 버튼 원본은 같은 가로세로 비율로 확대했으며 새 버튼 그림은 만들지 않았습니다. 이 시안의 그림 확대는 런타임 부품 규격 변경 승인을 뜻하지 않습니다. 160px 원본 버튼을 확대해 가장자리가 부드럽게 보이므로 최종 픽셀 자산이 아닙니다. 제작 때 적절한 해상도의 승인 원본 또는 검증·승인된 분할 방식을 확보해야 하며, 기존 버튼 상태 세트의 임의 확대/분할 금지 규칙을 이 시안으로 해제하지 않습니다. 확대된 시안 버튼을 그대로 런타임에 넣지 마십시오.
- PC 1280×720. 휴대폰은 같은 16:9 배치를 960×540으로 비례 축소하되 버튼 문구의 원본 글자 크기는 28px로 보강했습니다. 휴대폰 시안에서 보이는 버튼 높이는 약61px입니다. 실제 기기·터치·Ren'Py 시험은 아직 하지 않았습니다.
- 광장 배경은 저장소의 실제 장소 그림을 참고 합성한 것입니다. 실제 회의 장면의 인물·상태·배경을 재현했다고 주장하지 않습니다. 머리글, 하단 검토 문구는 시안 설명이며 게임 문구 추가 제안이 아닙니다.
- 재시작 때 되돌릴 값/보존할 값과 진입 라벨은 이야기 담당이 승인 뒤 구현합니다. 이 전달물에는 해당 로직이 없습니다.

## 7. 갈림길의 대승리 표시

먼저 previews/07_갈림길_두안_비교.png를 봅니다. 7일 불·12일 수프 각각 A/B 원본 PNG가 들어 있습니다.

### 가: 개수만 추가 (추천)
- 안 본 대승리를 다른 안 본 결과와 함께 숫자로만 셉니다. 대승리를 본 뒤에도 다른 본 결과와 같은 카드로 표시하며 별도 표식은 없습니다.
- 이유: 기존 「숨겨진 결과는 개수로만」 원칙을 가장 적게 바꿉니다.
- 차이: 실제 결과 목록에 하나가 추가되고, 아직 안 봤을 때 숫자만 그만큼 늘어납니다. 결과를 본 뒤에는 더 이상 미확인 개수에 포함하지 않습니다.

### 나: 본 대승리에만 작은 표식
- 가와 같은 개수 처리에 더해, 이미 본 대승리 카드 우상단에 24px 빨간 작은 마름모 배지를 둡니다.
- 이유: 이미 발견한 특별한 결과를 다시 찾아보기 쉽게 합니다.
- 차이: 본 결과를 구분하는 시각 표식 하나가 추가됩니다. 미확인 대승리 카드·이름·실루엣·조건·달성 방법을 따로 드러내지 않습니다. 기존 운명 「?」 표식과는 다른 모양입니다.

### 시안 데이터와 기존 화면 보존
- 숫자와 결과는 비교를 위한 명시적 샘플이며 실제 플레이어 저장 기록을 읽거나 변경하지 않았습니다.
- 기존 회의 결과 3종(이김·부분·짐)에 제안된 대승리 1종을 더한 경우를 예로 들었습니다. 「짐」만 본 샘플이면 안 본 결과 3, 「짐」과 「대승리」를 본 샘플이면 안 본 결과 2입니다. 이 숫자를 고정 UI 값으로 구현해서는 안 됩니다.
- 안 본 상태 파일은 이름·이미지·특별 표식이 없는 숫자칸만 보여 줍니다. 나 안에서도 발견 전 화면은 이와 동일합니다.
- 실제 room13_fork_screen.rpy의 날짜 순서, 한 화면 6열, 결과 카드175×116, 미확인 칸175×56, 세로 간격16을 참고했습니다. 승인 B 재질의 안쪽 여백을 피하려고 열 시작점110·열 간격182로 시안에서만 조정했습니다. 이것은 별도 레이아웃 구현을 승인받은 것이 아닙니다.
- 검토 대상 밖의 실제 기록을 임의로 만들지 않도록 나머지 칸은 「기존 기록 영역 / 시안에서 생략」으로 표시했습니다. 실제 구현에서 기존 칸·페이지 이동·결말 기록·닫기를 삭제한다는 뜻이 아닙니다.
- 기존 운명 ?의 공개 조건은 그대로 유지합니다. 누구의 생사인지, 조건·방법·안 본 결과 이름은 표시하지 않습니다. 배경 썸네일은 저장소의 해당 장소 그림을 이용한 샘플이지 특정 플레이 결과 캡처가 아닙니다.
