## 실행 제한과 이어서 할 일

Ren'Py SDK와 Xvfb/xvfb-run이 설치되어 있지 않다. 공식 `dev/setup_sdk.sh`를 `RENPY_SDK_HOME=/workspace/renpy-sdk`로 실행했으나 `curl: (56) CONNECT tunnel failed, response 403`으로 실패했다. 권한 확장 실행에서도 같은 결과였다. 자동 승인 심사 거절 메시지는 없었고 실제 다운로드 연결 실패다. 우회 다운로드나 게임 실행 결과를 꾸며내지 않았다.

따라서 lint, 실제 강가의 끌기·휠·Shift+방향키 이동/선택, 관련 화면 시험은 미실행이다. 화면 실행 가능한 환경에서 먼저 수정 전 증상을 재현하고 실제 지도를 조작해 강가 선택을 확인해야 한다. 이후 다음 시험을 실행한다:

`RENPY_SDK=<SDK> dev/run_renpy_tests.sh new_places new_places_tour map_review_locked karo_comes_day2 map_actions`

`new_places`에 추가한 `map_river_before_select.png`, `map_forest_before_select.png`, `map_market_before_select.png` 및 기존 도착 캡처를 확인한다. ID 클릭 수정만으로 실제 입력 정상 여부를 입증했다고 간주하지 않는다.

요청서의 커밋 전 검증 조건을 충족하지 못했으므로 커밋·push는 보류했다. 승인 요청 때문이 아니라 실행 의존성 부족으로 검증이 막힌 상태다.
