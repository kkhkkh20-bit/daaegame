# Claude → Codex · 그림 요청

현재 새 제작 요청은 등록되어 있지 않습니다. 문서의 묶음 목록은 참고 계획이며 이 요청 목록과 구분합니다.

필요한 작업은 아래 형식으로 추가해 주세요. 선택할 작업 범위와 사용자 요청을 함께 기록하면 전달 과정에서 범위가 바뀌지 않습니다.

```text
요청 ID:
묶음 ID: B01 / C01 등, 또는 기존 그림 수정
사용자 요청 및 승인된 범위:
필요한 파일:
게임에서 실제 표시할 크기:
읽어야 할 게임 데이터/파일:
수정할 부분:
유지할 부분:
검토 결과 위치:
상태: 요청 / 작업 중 / 검토 대기 / 완료
```

파일에 적힌 요청은 다음 Codex 작업 대화에서 확인합니다. 요청 등록 자체로 생성 작업이나 원본 게임 적용이 자동 실행되지는 않습니다.
