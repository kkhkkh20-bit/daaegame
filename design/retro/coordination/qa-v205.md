# v205 (2026-10-08) 1장 공간·시간·인물 연출

이미 있는 장면, 플래그, 음악, 포즈로만 만들었다. 새 엔진·새 배경·새 조사 장소는 없다.

이번에는 구현과 짧은 확인만 했다. 전체 검수는 따로 한다.

## 실제 적용

| 항목 | 적용 내용 |
| --- | --- |
| 1. 마을 어귀 | BOOK.envelope.pre[1](festival-road, 기존 낮 보정 day 그대로)의 시각 표기를 '이른 봄 · 마을 어귀 정류장'으로 바꿨다. '문맥도 안 보인다.' 다음에 왕구 등장·대사 2줄, 다람 1줄, 퇴장을 넣었다. 사무소로 이어지는 흐름은 그대로이고, 조사 장소는 3곳 그대로다 |
| 2. 첫 만남 | MEETX.envelope 5명을 3줄 이내로 바꿨다. shortMeet는 3줄 이하면 자르지 않는다. 이름·하는 일·관계는 아래 표에 따로 정리했다. 질문 해금은 바꾸지 않았다 |
| 3. 장소 첫 진입 | 띠로 장소명과 이야기 속 방문 시각을 보여 준다. 아래 '장소별 시각' 표 참고 |
| 4. 좌우 보기 | 좌우 화살표 아래에 '보기' 글자를 넣었다(aria '왼쪽 보기/오른쪽 보기'). 이동 메뉴 '이동한다'와 구분된다 |
| 5. 배경음 | invKey에 1장만 명시했다. 우체국 inv_room(실내 작업), 창고 inv_snow(차분한 종소리), 기록실 inv_night(조용한 칼림바). 모두 기존 합성곡이다 |
| 6. 생활 디테일 | 나비 수다 첫 줄을 우편 칸 이야기로 바꿨다. 다람 "철새는 아직 안 왔는데, 칸은 비워 두네?" / 나비 "주소가 있잖아. 돌아오면 써야지." 증거·시각·정답·중요 진술은 그대로이고, 새 클릭 과제도 없다 |
| 이야기책 | 퇴장한 인물이 무대 상대로 남지 않게 정리했다 |

### 2. 첫 만남 인물별 내용

| 인물 | 이름·하는 일·관계 | 성격이 드러나는 부분 |
| --- | --- | --- |
| 왕구 | 정류장에서 이미 인사했으므로 자기소개는 반복하지 않는다 | 결론('봉투가 없어졌어요')부터, 근거는 탐정에게 |
| 나비 | 창구 도우미 | 줄 세우기 + "빠지는 사람 없이" |
| 도토 | 도서관 조수, 10시 1분 12초 기록(시각 그대로) | '잠깐'을 3초로 고침 |
| 부리 | 할아버지 손자 | 순찰일지 정리를 '임무'라고 부름 |
| 까로 | 장사꾼, 이번 봉투 심부름 | 서명을 두 번 강조하는 이유가 '다들 저부터 의심해서' |

### 3. 장소 첫 진입: 동작

- 띠를 누르면 바로 걷히고, 그 탭은 아래로 가지 않는다(v201 보호).
- 같은 이동에서는 '장소 이동' 카드를 생략한다.
- 본 소개는 G.beats["place204:<장소>"]에 저장된다. 이어하기를 해도 다시 나오지 않는다.
- 지도 이동(moveTo)과 힌트·지도 바로가기(goTab({loc})) 둘 다 같은 소개를 쓴다.
- 재방문 때는 기존의 짧은 '장소 이동' 카드(장소명 + 수상한 곳 N군데/증거 수집 완료)만 나온다.

## 장소별 시각

| 장소 | 표시 | 근거 |
| --- | --- | --- |
| 사무소 | 다음 날 오전 9시(기존 이야기책) | 바꾸지 않음 |
| 우체국 | 오전 9:20 | 기존 현장 소개(SCENEX)가 이미 보여 줌. 새 띠는 없음 |
| 창고 | 도토와 아직 인사하지 않았으면 '오전 10:01', 이미 만났으면 '같은 날 오전' | 도토의 실제 인사 10시 1분 12초와 맞출 때만 분까지 표시 |
| 기록실 | '같은 날 오전' | 정확한 분 근거 없음 |

- 증언 속 과거 시각(TIMELINE)은 쓰지 않았다.
- 시각이 거꾸로 표시되는 경우는 없다. 창고와 기록실은 우체국 다음에만 열리고, 기록실은 범위로만 표시한다.

## 보류

- 같은 장소 재방문 때 새 목적 한 줄: 기존 단서 대사(BEATS)와 장소 카드 범위에서만 남겼다. 겨울 기록과 부리 답변으로 지급 기준을 확인하는 흐름이 그 예다. 새 안내 문장은 추가하지 않았다.
- 오프닝 음식/글씨 농담 압축은 이번 범위가 아니다.
- 마을 어귀 전용 바깥 생활 곡: 마을 어귀는 이야기책이라 기존 'story' 곡이 나온다. 새 곡은 없다.
