# v210 가로 시험본(비교용) · 1장 우체국

전체 전환이 아니라 비교용 실험이다. 기본 게임(index.html, game.html, dot.html), sw.js, manifest(방향)는 바꾸지 않았다.

- 시험 주소: https://kkhkkh20-bit.github.io/daaegame/wide.html
- 기본 주소(그대로): https://kkhkkh20-bit.github.io/daaegame/

## 구성

| 항목 | 내용 |
| --- | --- |
| 파일 | wide.html 한 개 추가. 기본 게임과 같은 빌드(v209)에 시험 전용 스크립트 두 개(앞: 저장 격리, 뒤: 가로 배치·범위 제한)를 붙인 것 |
| 시작 | 격리 저장에 1장 진행이 없으면 오프닝 없이 1장 우체국 첫 조사 상태로 시작. 있으면 이어서(항상 우체국) |
| 저장 격리 | 이 페이지의 저장은 모두 'daae-wide209:' 접두어 키. 기본 저장(daae-detective-v3, 음량 등)은 읽지도 쓰지도 않음. 도트 그림 캐시(dc1:)만 공유. 클라우드 동기화 끔. 격리가 안 되는 브라우저면 저장 함수를 막고 시험을 시작하지 않음 |
| 화면 | 조사 장면은 360×200 비율 그대로 화면 높이에 맞추고 오른쪽에 보조 줄(도트 아이콘+짧은 글자). 넘치는 너비는 기존 좌우 보기로 이동. 위아래 두꺼운 막대는 숨기고 장소 이름은 반투명 작은 칩 |
| 대화 | 상대 전신 원화를 크게 가운데(화면 높이의 82%, 위 6%부터), 아래쪽은 반투명 대사창 뒤로. 발끝을 보이려고 줄이지 않음. 아빠는 얼굴 없음(기존 시점 그대로) |
| 질문 | 같은 구도에 반투명 질문판(2열). 대답 중에는 질문판을 감춤. '조사로' 버튼과 오른쪽 '조사'로 복귀, 사용자가 옮겨 둔 좌우 위치 그대로 |
| 기존 기능 | 증거 기록(가로에서는 왼쪽 상세·오른쪽 목록), 증거 발견 창(그림 왼쪽, 확인 버튼 항상 보임), 힌트, 기록, 줄기, 설정, 메모 사용 가능 |
| 범위 밖 | 지도 이동·원탁회의·다른 장소: 누르면 '가로 시험 범위 밖' 안내만. 사건 목록 등으로 나가면 세로 화면이 그대로 보이고 아래에 '가로 시험(우체국)으로 돌아가기' 버튼 |
| 세로로 열면 | 강제 회전 없이 '가로로 돌려 주세요' 안내와 기본 게임 링크 |
| 입력 보호 | 기존 v204 대화 종료 보호, v209 지도 전환 보호 모두 같은 빌드에 그대로 |

| 페이지 오류 | 0 | 0 | 0 |

- 조사 지점 3곳(창밖 풍경 관찰·저울 관찰·빨간 소인 잉크)은 중심이 이웃 지점과 겹친다. 기존과 같고, 가장 가까운 대상 고르기로 실제 탭에서 모두 조사됐다.
- 기본 game.html: 시험 스크립트가 없고 제목 화면이 열리며 오류 0. game.html은 v209 그대로다.

## 확인하지 못한 점

- 실기기(iOS Safari, 안드로이드 크롬) 미확인. 특히 iOS에서 localStorage 대체(격리) 동작, 주소창·노치 안전 영역.
- 640×360에서 증거 발견 창은 '다람 메모'가 확인 버튼 뒤로 들어가 스크롤해야 보인다.
- 데스크톱 큰 화면에서는 질문판이 낮아 발 근처만 가려진다.
- 첫 만남 '새 인물' 띠, 이야기책(오프닝)·결판 연출의 가로 배치는 범위 밖이라 보지 않았다.
- 시험 중 1장 진행이 우체국 밖으로 넘어가는 경우(창고·기록실 해금)는 안내로만 막았다.
