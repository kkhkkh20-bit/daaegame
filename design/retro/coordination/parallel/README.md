# 병행 작업 담당

같은 그림을 중복 제작하지 않도록 이 채팅은 B01 배경, 다른 채팅은 C01 캐릭터로 범위를 나눕니다. 현재 상태는 담당 예약이며 실제 생성·완료를 의미하지 않습니다.

- B01: 현재 채팅. `design/retro/bg/fall-steps.png`, `fall-square.png`, `fall-pond.png`.
- C01: 사용자가 시작 문구를 전달하는 다른 채팅. `design/retro/chars/papa.png`, `rei.png`, `karo.png`.

각 채팅은 자기 묶음의 JSON과 결과 파일만 갱신합니다. 공통 `status.json`, `document-batches.json`, `requests.md`, `review.md`, 공통 안내 파일은 병행 중 덮어쓰지 않습니다. 묶음별 전달 문서는 `HANDOFF-B01.txt`, `HANDOFF-C01.txt`로 구분합니다. 담당 예약이 있는 동안 일반 문서 순서로 자동 선택해 상대 묶음을 가져가지 않습니다.

같은 Git 작업 폴더의 체크아웃·인덱스 충돌을 피하려면 채팅별 작업 폴더나 worktree를 사용합니다. 저장소에 반영할 때 최신 원격 변경을 확인하고 자기 파일만 커밋합니다. 원본 게임, 승인된 그림, 상대 채팅의 변경을 유지하며 강제 푸시는 하지 않습니다.

다른 채팅용 시작 문구는 `C01-start.txt`에 있습니다. 같은 저장소를 사용할 수 있어야 자료를 읽을 수 있으며, 이 파일을 만들었다는 것만으로 다른 채팅이 시작되거나 읽은 것으로 표시하지 않습니다.
