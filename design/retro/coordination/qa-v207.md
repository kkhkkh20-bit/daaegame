# v207 (2026-10-08) 1장 이동 지도 주민 · 증거 아이콘 · 재방문 안내

기존 상태(locOpen, c.ppl, 만남 목록, visibleTalk, G.asked, G.visited)만 읽는다. 새 날짜·행동력·생활 엔진, 새 저장 항목, 화면 방향·큰 레이아웃·대화창 배치, 원탁회의 투표는 바꾸지 않았다. 모듈: ui207.js(1장 한정).

## 실제 적용

| 항목 | 내용 |
| --- | --- |
| 1. 이동 지도 주민 | 열린 장소 이름표 아래에 그 장소 장면에 서 있는 주민(c.ppl)의 작은 얼굴+이름. 장면이 인물을 세우는 조건과 같다. 잠긴 장소('???')에는 표시 없음. 노란 '?'는 장면 인물의 '?'와 같은 계산(보이는 질문 중 안 물은 것). 누르면 그 장소로 이동만 한다(만남·질문 처리 없음) |
| 2. 증거 아이콘 | 이름·선택한 증거만 펼치는 상세는 이미 되어 있어 유지. 같은 그림을 쓰던 증거를 기존 픽셀 아이콘으로 구분: 잠긴 꽥순네 칸 → 자물쇠, 겨울 굴뚝 기록 → 난로, 눈 피해 기록 → 눈송이. 설명·사실 문장은 그대로 |
| 3. 재방문 안내 | 이미 와 본 장소로 지도 이동하면 기존 '장소 이동' 카드에 줄을 더한다: '처음 만날 주민', '새로 물어볼 말'(떠날 때 없던 질문이 새로 열림), '남은 질문'. 해당 없으면 줄 없음. 다 들으면 사라짐. 카드는 입력을 막지 않음(줄이 있을 때만 2.3초) |

필수 단서는 시간으로 사라지지 않는다. 카드는 짧게 보였다 사라지지만, 같은 정보는 지도 얼굴의 '?'와 장면 인물의 '?'에 계속 남고 질문은 대화 목록에 그대로 있다.

## 보류

- 빈 등기 받침(e1_tray)과 02번 보관함(e1_box)은 같은 상자 그림이다. 맞는 기존 아이콘이 없어 새 그림을 요청한다(아래).
- 힌트·바로가기(goTab) 경로의 재방문에는 카드가 원래 없어 안내도 없다.
- 2~15장에는 적용하지 않았다(1장만 확인).
- 기존 차이: 장소 카드 '수상한 곳 N군데'(증거만)와 아래 띠 '살펴볼 곳 N군데'(증거+관찰)의 숫자 기준이 다르다. 이번에는 바꾸지 않았다.
