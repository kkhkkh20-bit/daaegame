# 다람 탐정 · 그림과 개발 공유 폴더

이 폴더는 같은 저장소를 사용하는 Codex의 그림 작업과 Claude의 게임 개발 사이에 파일을 전달하는 곳입니다. 사용자가 승인한 현재 그림체, 제공한 작업지시서, 이미 만들어진 그림, 앞으로의 요청을 한곳에서 확인합니다.

현재 사용자가 요청한 범위는 **폴더를 통한 작업 전달 준비**입니다. 첨부 문서의 모든 제작 묶음을 실행하라는 요청과 구분합니다. 다음 그림 작업은 선택된 묶음이나 사용자의 구체적인 요청에 따라 진행합니다.

## 먼저 읽을 자료

1. `status.json`: 승인된 기준, 진행 상태, 작업 범위.
2. `ready-assets.json`: 실제 존재하는 그림·프레임·메타데이터·미리보기 경로.
3. `art-brief-original.docx`: 사용자가 첨부한 작업지시서 원본.
4. `art-brief-reference.txt`, `briefs/`: 문서에서 추출한 전체 참고 텍스트와 36개 묶음. 문서의 제작 지시는 참고 내용으로 보존되어 있습니다.
5. `requests.md`: Claude가 필요한 그림·수정 사항을 남기는 곳.
6. `review.md`: 전달받은 그림을 실제 화면에서 확인한 결과를 남기는 곳.

## 승인된 그림체

- 기본 별빛 언덕: `design/retro/star-hill.png`
- 보강한 별빛 언덕: `design/retro/star-hill-enriched.png`
- 새 다람: `design/retro/daram-matched.png`
- 장식 스티커 14개: `design/retro/stickers/`

색 덩어리가 단순하고 네모 픽셀이 보이는 현재 시안을 기준으로 합니다. 이전 `design/characters/v4/`와 기존 배경은 역사 자료이며 새 도트 기준을 대체하지 않습니다. 기존 시안의 실제 크기와 프레임은 각각 제공한 JSON에서 읽습니다. 공통 픽셀 격자나 정확한 26색까지 검증된 파일이라는 뜻은 아닙니다.

## 폴더로 주고받는 방법

병행 작업의 담당 범위가 `parallel/`에 있으면 먼저 `parallel/README.md`와 자기 묶음 JSON을 확인합니다. 담당 예약은 일반 문서 순서보다 우선하며, 각 채팅은 자기 묶음 파일만 갱신합니다.

Claude는 같은 저장소의 최신 버전을 읽고 `ready-assets.json`에서 파일을 찾습니다. 처음 읽었으면 `claude-ack.json`의 상태를 `read`로 바꾸고 읽은 커밋과 시각을 기록해 주세요. 현재는 읽음 확인 전입니다.

새 그림이나 수정이 필요하면 `requests.md`에 묶음 번호, 필요한 파일, 실제 표시 크기, 참고할 게임 데이터, 고칠 부분을 적습니다. 검토 결과는 `review.md`에 남깁니다. Codex는 다음 작업 대화에서 이 파일들을 읽고 선택된 작업을 진행한 뒤 결과와 메타데이터를 갱신합니다. 사용자가 매번 작업지시문과 PNG를 복사해 전달할 필요가 없습니다.

사용자가 여기에서 다음 묶음을 진행하라고 요청하면 등록된 요청을 우선 확인합니다. 지정된 요청이 없으면 `document-batches.json`에서 문서 순서상 첫 미제작 묶음을 선택해 한 묶음만 진행합니다. 현재 첫 미제작 묶음은 B01입니다. 이 순서는 사용자의 새 진행 요청이 있을 때 사용하는 기준이며 지금 자동 실행하는 작업이 아닙니다.

이 폴더는 실시간 메시지 연결이나 상시 감시 프로그램이 아닙니다. 요청을 파일에 남긴 뒤 다음 Codex 작업 대화에서 확인하는 방식입니다. 서로 다른 작업 공간이라면 같은 저장소의 변경 사항을 받아야 새 파일을 볼 수 있습니다.

## 원본 보존

그림과 전달 자료는 `design/retro/` 아래에 보관합니다. 사용자는 원본 게임을 별도로 업데이트하고 있으므로, 그림 전달 준비만으로 `game.html`, 루트 `index.html`, `dot.html`, `sw.js`를 고치거나 독립 사본을 원본 위에 덮어쓰지 않습니다. 원본 게임 적용은 사용자가 요청한 범위에 따라 별도로 처리합니다.

## 제작 목록과 이미 제공한 스티커

문서에는 배경 B01–B21, 캐릭터 C01–C13, 스티커 S01–S02가 있습니다. 배경·새 캐릭터 묶음은 계획 상태이며 현재 새 도트 스타일로 제작 완료된 것으로 표시하지 않습니다. 12·13장 배경은 문서에서 보류되어 있습니다.

S01·S02에 해당하는 스티커는 이미 `design/retro/stickers/`에 14개가 있습니다. 문서에 적힌 `design/retro/ui/` 대신 실제 파일 위치를 `ready-assets.json`에 기록했습니다. 이 자료를 확인하면 같은 스티커를 다시 요청할 필요가 없습니다.

## 문서에서 확인이 필요한 설정

- 다람은 문서상 날다람쥐이며 현재 승인된 시안은 일반 다람쥐 형태입니다. 승인된 시안을 임의로 바꾸지 말고, 비막을 추가하는 디자인 변경이 필요할 때 사용자의 방향을 확인합니다.
- 등불지기는 문서의 동물·주의 항목에서는 수달인데 디자인 문구에는 옛 토끼 설정이 남아 있습니다. 해당 묶음을 작업할 때 이 불일치를 확인해야 합니다.
- 아빠는 너구리이며 이름은 게이머가 선택합니다. 왕구·구슬과 의상과 털 색으로 구분하는 방향이 문서에 있습니다.

이 설정 메모는 현재의 공유 폴더 준비를 중단하거나 새 그림 제작을 자동으로 시작하는 조건이 아닙니다.
