적용 방법
1. 이 브랜치의 B03 신규 파일만 가져옴. main 병합 여부와 실제 적용은 게임 담당이 결정.
2. 배경/전경을 같은 가운데 9:5로 crop하고 nearest-neighbor로 360×200 표시. 게임용 축소·팔레트 사본은 art/에 따로 만들고 원본 PNG 보존.
3. HOTS는 위 spots 중심점, 각 장소 obs는 위 관찰 중심점으로 옮김. 좌표는 수동 시각 확인한 대략 좌표이며 실제 버튼 크기는 화면에서 검토.
4. PPL은 발 중심으로 배치. 기존 인물 너비·높이에 맞춰 실제 대사 화면에서 가림 확인. 오른쪽 아래 (320~360,185~200)에는 발을 배치하지 않음.
5. 미리보기는 이 폴더를 HTTP 서버로 열어 B03-preview.html 확인. 좌표/기존 인물 비교/창구 전경 토글 제공. 원래 게임 UI를 변경하지 않음.
