네 파일은 128×128 RGBA 투명 PNG이며 따뜻한 기존 픽셀풍에 맞춘 시각 후보다.
권장 표시 크기는 28–36px. 22px에서는 내부 디테일이 줄어드므로 짧은 UI 라벨을 유지한다.
가로세로 비율을 유지하고 기존 픽셀 렌더링 정책을 사용한 뒤 실제 기기에서 확인한다.
preview.png에는 밝고 어두운 배경에서 22/28/32/36px 비교가 포함되어 있다.

Claude 적용 안내
현재 B03 작업을 마친 뒤 하나의 UI 패치로 검토한다. 해당 기능이 존재하는 위치에만 연결하고,
기존 이벤트, 저장/이어하기 흐름, 접근성 이름과 짧은 라벨을 보존한다.
이 브랜치는 후보 전달만 수행하며 게임 코드 및 기존 32개 아이콘은 변경하지 않는다.
최종 적용 시 모바일 작은 크기, 대비, 터치 영역 및 기능 동작을 별도로 확인한다.

제작과 한계
내장 이미지 생성 도구로 생성·수정한 원본을 투명 여백 기준으로 크롭하고 최근접 샘플링해 정규화했다.
엄격한 32×32 원화 격자 또는 모든 외곽선의 정확한 단색/1px 규격을 보증하지 않는다.
continue: 버건디 사건 수첩+금색 책갈피; combine: 대각선으로 연결된 두 퍼즐 조각;
talk: 크림색 말풍선+점 세 개; examine: 기존 investigate 계열 돋보기+확대 표시.
