1280 기준 배치 확인
실제 게임의 논리 화면 폭이1280인지 먼저 코드에서 확인하세요. 확인됐다면 위 원본 캔버스 크기를 1:1 시작점으로 삼되, 이는 최종 배치 승인값이 아닙니다. 실제 논리 폭이 다르면 기존 화면 좌표계와 UI 배율을 우선 따르세요.
1280 기준 화면 전체를 표시 폭W로 균등 확대/축소하는 경우 배율은 W/1280입니다. 이미지와 글자와 입력영역에 같은 화면 변환을 적용하고, 이미 변환된 캔버스에 개별 배율을 다시 곱하지 마세요.
카드는 원본672×116 전체를640×84로 압축하지 마세요. 그림영역과 바깥 투명여백을 구분하여 배치·입력영역을 확인하세요.
대사창1200×160을 사용하는 경우 높이를 고정하는 편이 안전합니다. 원본 전체를 세로 확대하면 스프링과 모서리가 늘어납니다. 이 묶음은 새로운 9-slice 값을 지정하지 않습니다.

- 부모 패널과 자식 카드의 배경/외곽선이 모두 보이는지 확인.

위 항목은 화면 비교에 따른 점검 제안입니다. 소스 확인 전 원인을 확정하지 않습니다.
