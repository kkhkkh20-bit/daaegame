# 숲·산길 지도 B 추가 자산

시안·미적용. 기존 마을 B의 크림·네이비·코랄과 갈색 외곽선, 흰 스티커 테두리를 따른 제안입니다. 실제 지리/연결 관계는 검증하지 않았습니다. 저장소나 게임 구현은 변경하지 않았습니다.

## 구성
- 불투명 빈 배경: assets/map_forest_base_1136x570.png
- 투명 장소 스티커: forest_path, protection_facility, abandoned_greenhouse, mountain_altar
- 별도 눈·안개 가림판: cover_greenhouse, cover_altar
- 기존 마을 notebook_frame_1280x720.png 재사용
- manifest.proposed.json: 지도 내부 좌표, 크기, 이름표 중심, 제안 hitgroup과 공개/비공개 처리 계약
- previews/forest_DEFAULT_1280x720.png: 기본 비공개 상태
- previews/forest_REVEALED_SPOILER_designer_only_1280x720.png: 스포일러, 디자이너 전용 공개 비교

스티커와 배경에는 글자/UI가 없습니다. 미리보기의 글자는 조립 시 별도로 올렸습니다. 모든 장소와 가림판은 실제 RGBA 투명 PNG입니다. 원본은 originals/에 그대로 보존했습니다. 배경은 정확히 1136×570으로 납품했고, 스티커는 비율 유지한 640px 이내 런타임 파생본입니다.

## 스포일러 처리 필수
기본 상태에서 폐온실·제단의 스티커 자체를 그리지 않습니다. 이름표, 클릭/키보드 포커스 영역, 툴팁과 접근성 이름도 제외하고 눈 가림판만 그립니다. 이렇게 하면 가림판 가장자리 투명도와 무관하게 어떤 실루엣도 노출되지 않습니다. 가림판을 반투명 효과로 대체하거나 숨은 장소 위에만 덮는 방식은 사용하지 마세요. 실제 이야기 조건/플래그 이름은 추정해서 넣지 않았습니다. 기존 코드의 검증된 조건에 연결하는 것은 별도 구현 작업입니다.

## 검수
배경 건물 없음, 4개 장소 각각 분리, 2개 가림판 각각 분리, 기본 미리보기에서 비공개 이름/그림 없음, 1280×720 합성에서 틀 밖 잘림 없음 확인. 보호시설의 구체적 건축 외형과 장소들의 위치는 미적 제안이지 설정 확정이 아닙니다. 제단은 무문양 석조물이며 새 종교/조직 상징을 넣지 않았습니다.

## 생성 방식
Built-in image_gen 사용, 장소와 가림판별 개별 호출. 스티커는 transparent_background=true. assemble_preview.py는 생성 원본 보존 후 크기 조정/배치/별도 텍스트 합성만 수행합니다. 원본에는 의도하지 않은 설정으로 해석될 수 있는 미적 소품이 있을 수 있으므로 확정 설정으로 취급하지 않습니다.
