다람 마을 · 캐릭터 전신 검토 후보 43종

1. 전달 상태
이 묶음은 캐릭터 43명의 전신 이미지 검토용입니다. 최종 승인이나 게임 반영 완료를 뜻하지 않습니다.
이번 전달로 새로 게임에 적용한 항목은 0건입니다. 저장소와 런타임 파일은 변경하지 않았습니다.
까로는 기존 전신 PNG를 변경 없이 포함했습니다. 나머지 42종은 기존 캐릭터 자료를 참고해 제작한 전신 후보입니다.

2. 구성
characters/ : 캐릭터마다 선택한 전신 RGBA PNG 1개씩, 총 43개
character-overview-ko.png : 한국어 이름과 ID를 붙인 전체 검토 이미지
manifest.json : 상대 경로, 이름, 버전, 크기, 해시, 투명도 측정값, 간단한 출처와 개별 유의사항
QA_CAVEATS_KO.txt : 검토 범위와 알려진 차이
manifest.json의 repository_asset은 기준 저장소의 참고 자료 경로이며 ZIP 내부 경로가 아닙니다.

3. 사용 구도
원본 PNG는 발끝까지 포함한 전신을 위한 자료입니다. 대화 장면의 의도된 구도는 무릎 위입니다.
이 묶음에 대화용 크롭, 실제 월드 크기 보정, 애니메이션이나 게임 코드 적용은 포함하지 않았습니다.
정면 얼굴과 관객을 향한 양쪽 눈을 목표로 제작했으며, 최종 인상은 원본 및 실제 대화 화면과 비교해 확인해 주세요.

4. 전체 검토 이미지 읽는 법
캐릭터가 잘 보이도록 썸네일의 투명 여백을 줄이고 각 칸에 맞춰 nearest-neighbor로 축소했습니다.
각 칸의 키나 크기는 실제 캐릭터 간 키, 월드 스케일, 런타임 표시 크기를 뜻하지 않습니다.
썸네일의 배경색·레이아웃은 검토용입니다. 개별 PNG에는 합성하지 않았습니다.
characters/의 PNG는 선택된 파일을 픽셀 수정, 팔레트 변환, 알파 정리 또는 리사이즈 없이 바이트 단위로 그대로 복사했습니다.

5. 주의
생성 후보의 얼굴과 세부 형태는 기존 흉상과 픽셀 단위로 동일하지 않습니다.
픽셀 밀도, 완전한 이진 알파, 정확한 색상 팔레트, 게임 런타임 일치는 보증하지 않습니다.
특히 엄마의 윤곽과 부리·도토·할머니·세련·너울의 얼굴 차이는 QA_CAVEATS_KO.txt를 확인해 주세요.
