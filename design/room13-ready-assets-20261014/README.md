## 포함한 자료

| 자료 | 수량 | 상태 |
|---|---:|---|
| 캐릭터 전신 RGBA PNG | 43명 × 1장 | 까로는 기존 전신 원본, 나머지 42명은 생성 검토 후보 |
| 가로 확장 배경 PNG | 14개 장면 상태 × 오전·오후·저녁 = 42장 | 13개 장소, 2048×768, 8:3 |
| 마차 손 교정 PNG | 1개 이미지, 소스/런타임 경로용 동일 복사본 2개 | 원본 해시 검사를 포함한 소스 적용 스크립트 제공 |
| 전체 검토 이미지 | 2장 | 캐릭터 PNG와 배경 JPG |
| 설명·검토 유의사항·원본 목록 | 각 하위 폴더 | 기존 검증과 현재 전달 상태를 구분 |

`MANIFEST.json`에 검증 목록 파일(`MANIFEST.json`, `SHA256SUMS`)을 제외한 모든 전달 파일의 상대 경로, 바이트 수, SHA-256, Git blob SHA를 기록했습니다. `SHA256SUMS`는 같은 파일들의 SHA-256 목록입니다. 큰 ZIP과 52MB 런타임 패치 바이너리는 중복으로 올리지 않았습니다.

## Claude에게 줄 작업 지시

이 브랜치의 `design/room13-ready-assets-20261014/README.md`부터 읽고 원본 PNG, 각 manifest와 QA 유의사항을 확인해 주세요. 준비된 에셋을 최신 Room13 소스와 비교하고 실제 적용 계획과 검토 화면을 마련해 주세요. 검토 후보를 최종 승인된 그림으로 간주하지 마세요. 이번 에셋 전달 자체는 게임 적용·배포 지시가 아닙니다. 별도의 적용 요청이 있으면 아래 조건을 지키며 작업해 주세요.

1. 현재 Room13의 기준 소스는 저장소 `CLAUDE.md`가 가리키는 `preview/room13-source/ROOM13_SOURCE_HANDOFF.zip`입니다. 오래된 `experiments/renpy-ch1` 스냅샷을 최신 소스로 혼동하지 마세요. 그림 제작 기준은 `a53d8c2b9894a9ff907df9aaa81d934ee8dcc5c1`이며 이후 소스와 달라졌을 수 있습니다.
2. 캐릭터 원본은 발끝까지 포함한 전신 자료이며 대화 화면의 의도된 구도는 무릎 위입니다. 대화용 크롭·월드 스케일·캐릭터별 키·발 위치는 아직 적용하지 않았습니다. 검토 이미지의 칸별 크기를 실제 키로 쓰지 마세요.
3. 생성 후보에는 얼굴·표정·몸 비율·픽셀 밀도 차이와 부분 투명 가장자리가 있습니다. `characters/QA_CAVEATS_KO.txt`를 확인하고 기존 얼굴과 실제 엔진 화면을 비교해 주세요. 기존 얼굴 픽셀 보존이나 완성된 애니메이션으로 주장하지 마세요.
4. 배경의 조사 물건과 공간 위치가 일부 바뀌었습니다. 단순한 가로 배율 확대 대신 클릭 영역, 출입구, 이동 범위, 발 위치와 가림 순서를 다시 맞추고 장면·시간대별로 검증해 주세요. 일반 객실과 사건 전 13호 객실은 그림을 공유합니다. 복도와 13호 객실은 사건 전후를 구분합니다. 기존 넓은 광장·여관·학교·공방 배경은 유지하는 구성이었습니다.
5. 마차 손 교정은 `carriage/INTEGRATION_KO.md`를 읽고 최신 소스에서 dry-run을 먼저 실행해 주세요. 기존 이미지 또는 provenance 해시가 달라졌으면 중단하고 비교해야 합니다. 과거 공개본용 런타임 패치를 최신 공개본에 덮어쓰지 마세요.
6. 실제 적용 후에는 관련 검사, Ren'Py lint, 데스크톱·모바일 플레이, 대화 크롭·조사 클릭·장면 전환·저장/불러오기를 검증하고 결과를 보고해 주세요. 현재 전달본은 이 런타임 검증을 완료했다는 뜻이 아닙니다.
