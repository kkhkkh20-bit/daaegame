다람 탐정 사무소 — 캐릭터·배경 디자인 연결 안내

대상은 원작 game.html이다. chapter-one 확장판의 시나리오나 게임 로직을 옮기는 작업이 아니다.

캐릭터
원작 CAST/BIO/PERSONA를 기준으로 다람이를 제외한 본캐릭터 35명을 제작했다.
CAST에는 37개 ID가 있다. luka와 shadow는 nero의 변장/정체 표시이며, 별도 인물로 세지 않았다.
이 두 외형은 별도 표정 시트로 제공한다. 다람이 이미지는 기존 것을 그대로 사용한다.
뭉치(mungchi)는 원작 설정인 판다이며, 백 부인(madam)의 아들이다.

PNG는 캐릭터별 표정 시트 또는 여러 인물의 표정 시트다.
한 인물마다 0=기본, 1=생각/의심, 2=감정 표정이 있다.
각 인물의 정확한 PNG 경로와 표정 좌표는 manifest.json의 characters[id]를 사용한다.
파일 크기나 등분 좌표를 추정하지 말 것. 투명 영역이 달라 표정별 좌표를 측정했다.
frames는 원본 이미지 픽셀 단위 [x, y, width, height]다.
alpha를 유지해 장면 배경 위에 표시한다. PNG를 다시 바탕색으로 합성하지 않는다.

연결 코드
<script src="design/art-kit.js"></script>
<div id="actor-art"></div>
<script>
DaramArtKit.ready.then(() => {
  DaramArtKit.character(document.getElementById('actor-art'), 'mungchi', 0);
});
</script>

생각 표정으로 변경:
DaramArtKit.character(document.getElementById('actor-art'), 'mungchi', 1);

변장 표시:
DaramArtKit.character(document.getElementById('actor-art'), 'luka', 0);
DaramArtKit.character(document.getElementById('actor-art'), 'shadow', 0);

이 렌더러는 PNG를 수정하지 않고 SVG의 클립 영역으로 표정을 보여 준다.
정해진 크기의 부모 요소를 두고 .daram-art { width:100%; height:100%; display:block; } 적용.
원작의 다람이 표시 ID(det1 등)는 게임 구현 단계에서 'daram'으로 매핑한다.

배경
main = 메인 화면 배경
cake, window, crown, star, bell, dark, museum, cart, glove, festival,
snow, clapper, bureau, lining, kitchen = 원작 15개 사건의 대표 배경
forest-path = 마을을 잇는 이동 연출용 숲길

DaramArtKit.background(document.getElementById('scene-art'), 'snow');

배경은 사건의 대표 장소를 위한 디자인이다. 원작의 개별 조사 장소마다 다른
핫스폿/증거 위치를 새 그림에 맞춰 연결하는 일은 구현 단계에서 진행해야 한다.

메인 화면 시안
index.html을 열면 새 메인 화면 구도와 인물/배경 미리보기를 볼 수 있다.
35명 인물을 검색하고 표정을 바꾸며, 배경에 기존 다람이를 세워 볼 수 있다.
메인 화면의 제목·메뉴는 이미지에 구워 넣지 않고 HTML로 얹었다.
원작 game.html과 그 시나리오/게임 로직은 이 디자인 작업에서 수정하지 않았다.

파일

character-specs.json   인물별 원작 설정과 디자인 명세
canon.json             작업 시작 시 원작에서 확인한 등장인물·장소 정보
art-kit.js             PNG 아틀라스 표시 코드
characters/            투명 캐릭터 PNG 시트
backgrounds/           불투명 배경 PNG 시트
reference/             기존 다람이 원본 복사본과 폰트·OFL 라이선스
studio.css / studio.js / index.html  디자인 미리보기
