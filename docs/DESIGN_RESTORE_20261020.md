## 산출물 제한과 비용

캡처 제한은 native 단계 뒤에 실행하며 PNG만 최대8MiB로 선별한다. `native-qa-summary.log`, 테스트별 텍스트/JSON, check/lint/build 로그와 결과 판정은 삭제하거나 재작성하지 않는다. 실패한 테스트의 종료 코드는 기존 `pipefail` 및 테스트 스크립트의 실패 반환값으로 작업을 실패시킨다. 전체 캡처의 경로·크기·SHA256·보관 여부를 별도 목록에 남긴다. 따라서 캡처 보관량을 줄인 것으로 테스트 통과를 만들지 않는다.

저장소는 공개이며 표준 ubuntu-24.04 runner를 사용한다. 이 작업은 실행당100MiB/1일 산출물 상한을 유지하며 유료 runner/API를 사용하지 않았다. 다른 작업의 기존 산출물은 삭제하지 않았다. 전체 계정의 청구액은 조회하지 않았으므로 실제 계정 청구액을 확정하지 않는다.
