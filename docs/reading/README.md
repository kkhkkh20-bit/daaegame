# 다람탐정 주민 별편 읽기 안내

14일 공통 시간표를 기준으로 피코 사건에서 마지막날까지 선택한 주민의 같은 시간을 나눠 쓴 별편이다. 경로별 파일은 해당 판에서 함께 일어날 수 있는 장면을 담는다. 서로 다른 판의 생존·사망·이송·회의 결과를 한 사건처럼 합치지 않는다.

기본 PDF는 각 구간의 대표 경로다. 앞 파일과 다음 파일의 머리말에서 생사·회의 결과를 맞춰 읽는다. 마지막 구간의 14일 세 장면은 아침 줄기이며 일반 아침은 무사망·진엔딩·완전 해결과 같지 않다.

원고 전문은 읽기 문서이고 게임에는 같은 시점의 짧은 행동·대사가 연결돼 있다. 피코 편에는 제안으로 남은 시점도 있어 해당 적용 문서에서 구별한다. 이 모음은 주민 전원의 매일 일과나 모든 결말을 빠짐없이 소설화한 문서는 아니다.
