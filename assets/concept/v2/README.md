# Daram UI Concept V2

이 폴더의 이미지는 Codex가 실제 게임 UI를 구현할 때 참고하는 디자인 시안입니다.

## Files
- daram-ui-dialogue-vertical-v2.jpg: 기본 대화 화면
- daram-ui-investigation-vertical-v2.jpg: 조사 / 클릭 포인트 화면
- daram-ui-evidence-vertical-v2.jpg: 단서 제시 화면

## Implementation rules
1. 시안 전체를 한 장의 배경 이미지로 사용하지 않는다.
2. 배경, 캐릭터, 대화창, 상단 메뉴, 조사 핫스팟, 단서 패널을 실제 HTML/CSS/React UI 레이어로 분리한다.
3. 모바일 9:16 화면을 우선 기준으로 한다.
4. 조사 화면의 창문, 서류/받침, 잠긴 보관함 등은 실제 클릭 가능한 요소로 구현한다.
5. 다람 캐릭터는 별도의 투명 PNG 에셋으로 교체 가능한 구조로 만든다.
6. 대사와 단서 텍스트는 이미지에 박아 넣지 말고 데이터/UI 텍스트로 관리한다.
7. 시안의 따뜻한 목재색, 크림색, 버건디, 브론즈 계열과 추리 비주얼노벨 분위기는 유지하되 특정 기존 게임 UI를 그대로 복제하지 않는다.
8. 이미지에 보이는 글자나 세부 장식은 참고용이며 실제 구현에서는 가독성과 모바일 터치 영역을 우선한다.

## Codex task
현재 게임 구조를 먼저 확인한 뒤 이 세 시안을 공통 디자인 시스템으로 해석해 기존 UI를 개선한다. 기능을 깨지 않도록 단계적으로 적용하고, 모바일 화면에서 대화 / 조사 / 단서 제시 세 상태를 직접 테스트한다.
