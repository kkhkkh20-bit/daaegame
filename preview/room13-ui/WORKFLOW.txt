다람탐정 UI 수정 작업 순서 — 0.12.2

1. 비교 화면 고정
비교 대상을 정확히 일곱 화면으로 정한다: title, hub, interaction, topics, evidence, notebook, settings.
동일한 저장/날짜/장소/인물/자료 보유 상태로 이전판과 수정판을 캡처한다. 수리점 부리 대화를 기준으로 삼으면 사용자 신고 화면과 직접 비교할 수 있다. 예쁜 한 화면만 캡처해서 나머지를 합격 처리하지 않는다.

2. 참고자료에서 실제 적용할 원칙 선택
직접 본 사용자 역전재판 스크린샷: 얼굴/표정 보호, 대화 하단 고정, 대화/조사/제시/이동의 분명한 동사, 제시 물건의 독립 미리보기.
직접 본 현재판: 큰 반투명 베이지 판이 그림과 경쟁하고, '해 볼 일'과 '읽은 대사 빠르게'가 플레이 동작의 우선순위를 흐린다.
추가 게임 공식 링크는 REFERENCES.txt에 별도 기록한다. 접근하지 못한 이미지의 색/배치를 직접 본 것처럼 근거로 사용하지 않는다.

3. 타입/색/인터랙션 체계 고정
제목: 명조 한 종류. 플레이 본문/버튼/시간: 고딕 한 종류. 증거 설명은 장식 서체 금지.
행동: 불투명 잉크색 면 + 밝은 글씨. 기록: 밝은 종이 + 어두운 글씨. 활성 선택: 금색 선과 명확한 글자 변화. 모든 패널에 금색 장식 반복 금지.
버튼의 기본/호버/포커스/비활성 상태를 같은 역할끼리 통일한다. 선택이 곧 증거 공개가 되지 않도록 상세 확인과 확정을 유지한다. 취소는 세계 시간/비밀 공개/증거 상태를 바꾸지 않는다.

4. 일곱 화면 합격 조건
[title] 제목이 버튼 상자처럼 보이지 않는다. 시작/이어하기/설정의 위계가 명확하다. 감상 가능한 배경 여백이 남는다. 사용자 시작 입력 이후 BGM이 재생된다. 브라우저 자동재생 제한은 무음 게임으로 방치하지 않는다.
[hub] 하단 주요 동작이 불투명하고 읽힌다. '읽은 대사 빠르게'가 없다. 이동/조사/활동의 동작 의미가 중복되지 않는다. 날짜/시간/장소는 상단 우측에서 한눈에 읽힌다.
[interaction] 대화/조사/제시/이동의 명칭과 아이콘이 일관된다. 부리의 얼굴과 귀가 버튼에 가려지지 않는다. 귀여운 거대 머리를 단순 확대해서 화면 중심에 채우지 않는다.
[topics] 새 질문/이미 들은 질문이 구분된다. 질문이 얼굴을 가리지 않는다. 긴 한국어 제목이 잘리거나 두 버튼에 겹치지 않는다. 되돌아가기가 같은 위치에 있다.
[evidence] 누구에게 보여주는지 이름/얼굴로 확인된다. 자료 선택, 설명 읽기, 보여주기 확정이 분리된다. 취소 후 상대에게 자료가 공개되지 않는다. 증언은 발언자가 있는 자료로 읽힌다.
[notebook] 물증과 증언을 쉽게 구분한다. 선택 자료 아이콘과 본문이 충분히 크다. 실제 확보하지 않은 과거 회차 기록을 현재 물증처럼 제출할 수 없다. 기록 종이 위 텍스트 대비가 안정적이다.
[settings] 읽은 대사 빠르게, 음악/효과음, 움직임 설정을 여기서 찾는다. 주 화면으로 복귀가 명확하다. 옵션 변경 뒤 실제 반영과 저장을 확인한다.

5. 실제 브라우저 검증
1280x720에서 일곱 화면을 캡처하고 844x390 모바일 가로 화면에서 다시 실제 터치한다. CSS 표시 크기 기준으로 가능한 주요 터치면 44px 이상을 목표로 한다. 1280게임픽셀 버튼 높이를 44로 지정했다고 모바일44px를 만족했다고 주장하지 않는다. 축소 비율을 계산하여 실제 표시 크기를 확인한다. 한 화면에서 충족하기 어렵다면 버튼 수/간격/행 배열을 바꾸고 긴 목록은 스크롤로 분리한다.
이동→부리 선택→질문→되돌아가기→자료 선택→취소→수첩→설정→저장→로드의 짧은 실제 조작 경로를 실행한다. 첫 접속 캐릭터 로딩, 아이콘 잘림, 하단 버튼과 브라우저 여백, 소리 재생을 확인한다.

6. 결과 공개와 남은 문제 분리
일곱 화면의 전/후를 웹 비교 갤러리에 모은다. UI 수정이 완료돼도 캐릭터 원화의 성인 비율/종 구별/배경 일치가 해결됐다고 표현하지 않는다. 캐릭터는 기존 도트와 새 성인 시안의 동일 장소 비교를 따로 진행한다. 확인한 사항/실패한 사항/다음 작업을 기록하고 실제 테스트한 빌드만 배포한다.
