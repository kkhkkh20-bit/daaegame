게임 열기 ↗

행동은 짙은 하단 메뉴, 질문은 얼굴 옆, 기록은 밝은 수첩에 배치했습니다. 아래 이미지는 시안 합성이 아닌 실행 화면입니다.

이미지를 누르면 원본 크기로 볼 수 있습니다. 캐릭터 원화의 비율과 그림체는 이번 UI 수정과 별도로 검토 중입니다.

이번에 바꾼 것

겨울 마을을 살린 명조체 타이틀과 13호 표식. 배경이 비치지 않는 행동 버튼. 인물 왼쪽·질문 오른쪽 배치. 설정으로 옮긴 읽기 옵션. 출발 화면으로 돌아오는 제시 취소.

확인한 범위

PC와 844×390 모바일 가로 화면의 실제 클릭·터치, 질문 선택과 제시 취소, 설정 변경을 확인했습니다. Chromium에서 타이틀 음악의 실제 오디오 출력도 확인했습니다. Safari 음성 자동재생과 모든 휴대폰 기종을 검증한 것은 아닙니다.

레퍼런스와 작업 순서
  1. 사용자가 제공한 역전재판의 조사·대화·제시 화면 비교
  2. 인물의 얼굴 영역과 조작 영역을 분리하는 화면 설계
  3. 제목용 명조와 본문용 고딕, 잉크색·종이색·황동색 기준 정리
  4. Ren’Py의 실제 버튼과 화면으로 구현
  5. 독립 에이전트가 PC·모바일 화면과 상태 변화를 검수
  6. 발견한 이름 잘림·알림 겹침·취소 동선을 수정한 뒤 재검수
  • 사용자가 제공한 역전재판 레퍼런스
  • Tangle Tower 공식 자료
  • Strange Horticulture 공식 사이트

외부 공식 자료의 출처와 작품 설명은 확인했지만, 일부 원본 이미지는 접근 제한으로 직접 확대 검토하지 못했습니다. 화면 배치의 직접 비교 기준은 사용자가 제공한 이미지와 실제 게임 실행 화면입니다. 다른 게임의 원화를 가져다 사용하지 않았습니다.
