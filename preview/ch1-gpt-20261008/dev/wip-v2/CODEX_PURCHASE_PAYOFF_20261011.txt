무료 1장 → 다음 장을 보고 싶은 결말 (2026-10-11)

사용자 목표
- 추리게임을 좋아하는 플레이어가 자기 관찰로 불공평한 상황을 뒤집는다.
- 1장 안의 돈 사건은 해결한다. 엄마의 행적은 구체적인 흔적과 질문을 남긴다.
- 조사 → 회의 → 대결과 간단한 기존 아이콘 조작을 유지한다.
- v2만 수정한다. 원래 공개 게임·미승인 PNG·엄마 실종의 진상은 바꾸지 않는다.

- 제안 문서의 새로운 행적·우편 번호·목걸이의 기능을 확정 사실로 추가하지 않는다.

핵심 구현
1. 플레이어가 답을 만들어 내는 F3
   까로의 「세련 손님에 대해」 질문 또는 숙박부(C09) 제시를 끝내면 C14를 받는다.
   까로는 세련이 주막 노름판을 떠나지 않아 마차를 놓친 것만 보았다.
   얼마를 잃었는지는 모른다고 대사·증거 원문·다람 메모에 명시한다.
   F3는 발견 기록 C10 → 도장은 품에 있었다는 진술 C12 → 사전 목격 C14 순서다.
   봉인 모순만으로 최초 금액을 단정하지 않는다. 이백 냥은 세련의 자백으로 확인된다.
   까로가 갑자기 떠올려 자동으로 답을 알려주던 대사는 제거했다.
   C14가 없으면 실제 조사로 돌아간다. 이미 질문을 들은 구 저장은 C09를 보여주면 된다.

2. 승리의 결과
   답을 미리 알려주던 M3/M4 제목을 중립적인 제목으로 바꿨다.
   M4 까로의 부녀 표 철회 뒤 다람에게 공개 사과한다.
   F4 너울의 혐의·배상·양도 취소 뒤 다람의 관찰을 정식 증언으로 기록한다.
   나비의 반죽 자리도 유지된다는 짧은 대사로 여관의 일상을 회수한다.
   기존 주민별 표 변화와 마지막 투표 결과는 보존했다.

3. 엄마 단서와 다음 장
   E4: 할머니가 다른 손님 기록을 가리고 장부 한 줄의 글씨만 허락한다.
   이름표와 장부의 「다」 긴 꼬리를 겹쳐 관찰하는 종이 UI를 넣었다.
   실제 비교 클릭 때만 inn_mother_lead를 저장한다. 닫기·Escape도 진행 가능하다.
   현재 생존·이동 시각·실종 원인·편지 발신자 등 새로운 사실은 확정하지 않는다.
   E5 가족 일상과 할머니의 마지막 대사를 유지한다.
   정적과 창가 별 소실 예고 뒤 제목과 짧은 질문을 보여준다. 완료 저장에서 재생 가능하다.
   이 작업은 2장 본편·결제·구매 전환 측정을 구현하는 작업이 아니다.

저장과 입력
- 최종 대결의 기존 5개 phase 번호는 유지한다.
- innfinal의 phase·sus·done·휴회를 정제해 보존하고, 재개 시 설득력을 초기화하지 않는다.
- 설득력 소진으로 명시 재시작할 때만 F1부터 다시 시작한다.
- 구 저장 F3에 C14가 없으면 증언 조사로 보내며 증거를 자동 지급하지 않는다.
- 증거 창의 기존 footer를 「대결 이어가기」로 연결했다. 증언을 얻으면 원래 phase와
  설득력을 유지한 채 직접 재개한다. 배경 패널 버튼과 record 버튼은 별도 id를 쓴다.
- 결말/예고 지연 콜백과 신규 UI는 G 교체·메뉴·장면 이탈 때 취소한다.
- 최종 대결 기록 정제는 등록된 window.EP1INN을 참조한다. 잘못된 EP 지역변수
  참조로 applyClean이 후반 저장을 빈 상태로 처리하던 검증 중 오류를 수정했다.
- 새 관찰/예고 창을 기존 대화 입력 보호에 등록했다. 엄마 글씨 창은 실제 누름이
  그 창 안에서 시작한 경우만 클릭을 받으므로 이전 대사의 누름이 넘어오지 않는다.
- PNG 교체 없이 종이·마차 기록·창문/별을 작은 SVG UI로 표현했다.

확인한 검증
- 빌드의 모든 script 문법, 기존 저장 이관, 실제 native 회의의 지연 입력 처리 통과.
- 대사 연타/누른 채 장면 전환/조사 전 입력은 시계 조사로 새지 않는다.
  844×390·390×844에서 새 클릭과 실제 pan으로 시계를 수집했다.
- 배포용 wrapper c6633238bfa1의 두 화면 크기에서 실제 메뉴→시작 CG→Enter 통과.
  JS·HTTP 오류 0, QA 평가 hook 없음. 실제 pre-Karo 저장 Continue도 정상 복귀.
- 엄마 글씨 비교는 native 새 pointer와 Enter로 진행했다. 종이 이동이 끝난 뒤
  두 종이와 SVG 좌표가 일치한다(중간 프레임이 아닌 470ms 정착 후 확인).
- 실제 조사로 만든 pre-Karo 저장부터 까로 질문→C14 획득→증거 창 대결 재개→
  F3 자백/전원 표/배상 철회→가족 후일담→엄마 글씨 비교→2장 예고 완료 통과.
  선택 장부 C11 없이도 막히지 않았고 오답 0·JS 오류 0·HTTP 오류 0이었다.
- 구 저장(T_ka2 기질문, C14 없음, F3, 설득력 3)은 재로드 뒤 조사를 안내한다.
  실제 까로에게 C09를 제시해 C14를 얻은 뒤 같은 F3·설득력 3으로 이어졌다.
- 완료 저장 Continue는 완료 beat를 유지하며 예고를 강제로 반복하지 않는다.
  예고 재생/Escape 종료, 예고 준비 전 Enter 차단, 은박 별 소실도 통과했다.
- 이 자동 검증은 클라우드 Chromium 기준이며 실기기 청취 평가를 뜻하지 않는다.

구매 의향은 실제 사용자에게 확인해야 한다. 자동 검증은 조작·논리·기록·진행을 검증한다.
