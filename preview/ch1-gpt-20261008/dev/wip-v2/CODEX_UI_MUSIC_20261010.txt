UI
- inn_polish.js: 메인 제목/장 이름, 메뉴 묶음, 음악 시작 안내, 세로 구도.
- 조사 메뉴, 대화 주제, 이동 창, 증거 탭, 설정 창의 색상/대비 통일.
- 증거 탭의 기존 border-image fill이 새 배경을 덮던 문제 제거.
- 메뉴/닫기 버튼 터치 영역, 키보드 포커스, 메인 위/아래 이동 지원.
- 대사/캐릭터 크기와 게임 진행 핸들러는 기존 시스템 사용.

음악
- title-v1: 70 BPM, 피아노·클라리넷·첼로로 따뜻함과 작은 의문을 함께 표현.
- travel-v1: 84 BPM, 기타를 더해 부녀의 숲길 장면과 연결.
- investigation-v1: 96 BPM, 짧은 저음 현악 리듬으로 조사 긴장을 유지.
- 세 곡은 동일한 짧은 선율을 변주한 24마디 자체 작곡. MP3 실악기 샘플 렌더.
- 메인 화면에서 음악 큐가 없던 경로를 수정. 실제 사용자 입력 후 재생.
- 기존 음악 버스/페이드/음소거/볼륨 설정/대사 시 감쇠를 공유.
- 과한 추가 증폭 제거. 인물 곡 볼륨 상한 조정.
- 솜솜 발견의 정적·심장 소리, 회의의 대사별 긴박한 큐는 유지.
- 모든 인물/회의 곡을 새로 작곡한 것은 아니다.
- 악기 출처/라이선스는 audio/v2/CREDITS.txt, GPL-2.txt 참고.

검증
- build.py: JavaScript 구문 검사 및 배포본의 시험 평가 함수 제외.
- qa_polish.py: 844×390/390×844 메뉴 영역, 실제 음악 시작 클릭,
  음소거/복귀, 버퍼 재사용, 설정 볼륨 변경, 실제 증거 창 열기/닫기.
  세 곡 8초 렌더의 유한 신호/음량/클리핑 확인. 화면 캡처 육안 검수.
- qa_audio.py: 기존 대사/회의 오디오 큐 및 신호 검사.
- qa_somsom.py: 두 화면 방향에서 발견 전 정적/긴장 유지/음악 복귀.
- qa_input.py: 두 화면 방향에서 대사 연타/누른 채 이동/조사 전 시계 차단.
- 테스트는 실제 사람의 청취 평가나 실기기 검사를 대신하지 않는다.
