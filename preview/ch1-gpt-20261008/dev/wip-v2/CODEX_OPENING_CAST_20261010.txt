사용자 지시/범위
- 앞으로 바로 머지: 검수된 v2만 main 반영 후 Pages 확인.
- 이번 요청은 필요한 표정 제작과 Drive의 다른 너울 적용을 명시했다.
  이 범위의 새 표현을 연결했으며 다른 보류 아트는 자동 교체하지 않았다.
- 공개 play.html/루트 게임/기존 dev 공개 소스는 유지.

초반 이해
- 이유 없는 노인 시선은 P2와 조사 중 광장의 회상 이벤트 모두 제거.
- 할머니 인사→아빠 방문 목적→엄마 사진→닮음 반응으로 첫 만남 정리.
- 사진을 보고 닮았다는 말이 실제 과거 만남의 증거가 되지 않도록 장부 대사도 변경.
  장부 둘째 권의 엄마 글씨를 짚으면 할머니가 권한을 막고 장부를 회수한다.
- 소리에 깨어 아빠를 부른 뒤 문틈을 확인하고 복도에 나감.
  밤이와의 다음날 대화에서도 소리 때문에 나왔고 다음엔 아빠를 깨우겠다고 한다.
- prologue 글 있는 행 102→88, 문자열 2389→1837(-23.1%). 화면 페이지 수는 아님.
- 가족/탐정/서점/엄마 옛 편지, 관찰에 참여하는 딸, 시간표/봉인/금액 차이는 유지.
- gen/conv.py는 원본 JSON이 없고 옛 문구가 남아 있으므로 실행하지 않았다.

너울/다람/밤이
- Drive 새 도트/너울의 기본/제지/분노/머쓱 4표정과 standing PNG를 neoul-v3로 연결.
  원본 PNG 바이트 보존. 원본명/Drive ID/SHA256/렌더 좌표는 manifest.json.
- 대화·화자 초상·작은 얼굴·인물 카드·원탁은 같은 감정 source로 렌더 crop.
  느낌표만으로 분노 표정을 요청하지 않는다.
- 전신은 접수대 마루에만 발선 정렬. 상반신은 대사창 뒤로 이어지게 함.
  직접 세로에서 실제 .vtxt top을 사용하여 몸 하단의 빈틈/공중에 뜨는 현상 제거.
- image_gen으로 채택 다람 v4 중립 그림을 편집해 걱정 표정 제작.
  같은 모자/복장/수첩/비율 유지. sad/worried/cower에만 사용하며 꼬리/장난 동작은 정적.
  다람 몸·화자 초상·작은 얼굴·원탁도 같은 새 PNG source.
- 밤이는 프롤로그/대화/원탁 모두 기존 action-poses/bami 거꾸로 그림.
  직접 세로도 천장에 발 부착, 원탁은 주변 인물 크기에 맞춰 말풍선 위에 얼굴 표시.
  천장 배우를 서 있는 그림에 180도 회전시켜 대체하지 않는다.

장면/시간 UI
- native banner Promise/타이밍/입력 보호는 그대로, 종이색 작은 장소+달/해 패널.
- P10b: 부녀방의 걱정 다람→방문을 열면 어두운 복도→문밑빛 소멸→밤이→귀환 뒤 침실.
- 원본 배경과 새 worry PNG를 SVG로 렌더. 배경의 밝기만 낮추고 대사/장소/초상은 유지.
- 기존 정적·심장 박동 오디오는 유지. 귀환 뒤 native 900ms 정적+fade.
- 미획득 증거/숨은 솜솜 위치 노출 없음. overlays는 장면 종료 때 정리, pointer-events:none.
- motion-reduce에는 이동/입장/밝기 전환 정지.
