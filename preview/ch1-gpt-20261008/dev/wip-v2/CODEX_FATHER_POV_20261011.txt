오프닝과 밤 장면의 아빠 시점 (2026-10-11)

최신 사용자 방향
- 토끼 할머니의 환영 다음에는 아빠가 답한다. 어색한 설명 독백 대신 대화로 상황을 이해하게 한다.
- 아빠가 현장에 없는 다람 단독 행동과 전지적 작가 설명을 없앤다.
- 이번 지시가 이전의 자정 콜드오픈/다람 단독 밤 장면보다 우선한다.

수정
- P1: 부녀의 마차 대화부터 시작한다. 서점, 엄마의 실종, 전직 탐정, 옛 편지와 마을 도장은 두 사람의 질문·답으로 전달한다.
  EP.OPENING_POV=father. 패치 74는 실제 새 게임의 내부 cold 호출과 관리자 진입 모두에서 기존 범인 시점 콜드오픈을 건너뛴다.
  과거 연출 데이터는 기록으로 보존하며 일반 플레이에는 나오지 않는다.
- P3: 할머니 “어서 와요. 추웠지?” → 아빠 숙박 질문 → 아빠가 사진을 보이며 질문 → 할머니 반응.
- P5/P12/P13: 설명 지문을 현장에서 하는 경고·수색 보고·봉인 개봉 대화로 바꾼다.
  남은 짧은 생각은 아빠가 직접 본 할머니의 빈 베개를 더듬는 손이다.
- P10b: 부녀가 함께 복도 소리를 듣는다. 다람은 엄마 사진을 보여 주자고 제안한다.
  아빠는 사진 질문은 아침으로 미루고, 소리 확인은 문 앞까지만 함께 하기로 한다.
  나간 뒤 문 밑의 빛을 발견 → 노크 → 불이 꺼지고 답이 없음 → 돌아가려다 천장의 밤이를 봄.
  밤이를 깨운 데 사과하고 손을 잡고 함께 방으로 돌아온다. 아빠가 자거나 다람 혼자 나오는 설정은 제거했다.
  이 장면에는 설명 나레이션이 없다. 아빠는 플레이어 시점으로 다람 곁에 있고 별도 전신을 추가하지 않았다.
- C07: 다음 날 “혼자 나왔어?”라는 꾸중을 지우고, 밤이가 둘을 놀라게 했던 일을 말한다.
  아빠가 밤이의 밤중 위치를 직접 묻는다. 취침 시각/천장 위치/시계 단서와 C13 목격 증언은 유지한다.
- 문 빛/소등/귀환 화면과 심박 시작·종료 큐를 새 대사에 연결했다.
  봉인 그림도 새 개봉 대사에서 닫혀 수색 화면으로 정상 전환한다.
- 그림·음원 파일 변경 없이 승인된 현장 전신, 대화 표정, 컷과 소리를 사용했다.

- qa_presentation_timing.py --mode fast --viewport portrait --expect-stable --check-menu:
  실제 새 게임 340회 입력, 8,922 프레임. 마차/마부/마을/봉인 CG 각 1회, 화면 공백·중첩·음악 선행 없음.
  현장 전신/대화 표정 소스 연결 일치. 실제 메인 복귀 → 이어하기에도 과거 CG/심박 잔류 없음. JS/HTTP 오류 0.
- qa_audio_timing.py: P1/P2 음악, P10 종소리 → P10b 정적/심박, 아빠 시점 오프닝의 즉시 완료, 회의 긴장/완화 검사 통과.

  실제 질문 전부와 증언 획득 창 확인을 통과했다. 오프닝 컷 잔류 및 JS/HTTP 오류 0.
