모바일 잔여 연출·다람 전신·장소 카드 정리 (2026-10-11)

요청과 재현
- 사용자가 보낸 화면의 빈 아빠 초상, 밤 침실의 잘린 다람 하체,
  커다란 갈색 장소/시간 띠를 실제 새 게임과 관리자 장면에서 확인했다.
- 현재 v2의 새 게임에서는 최신 가족/마을 CG와 아빠 얼굴이 정상이다.
  스크린샷의 일부 옛 대사는 현재 대본에 없다. 모든 옛 자산을 지우는
  방식 대신, 실제로 남은 잘못된 이미지 연결과 로딩 경로를 수정했다.
- 원래 공개판은 별도로 보존하며, 수정 확인 주소는 아래 v2 주소다.

수정
- 밤 침실과 복도는 모두 승인된 dialogue-v2 현장 전신을 사용한다.
  상반신 대화 그림을 방 안의 작은 인물로 쓰던 연결을 제거했다.
- 아틀라스가 아직 로딩 중이어도 새 전신의 계획된 소스를 유지한다.
  로딩 여부 때문에 옛 상반신 그림이 그 장면에 고정되던 경로를 제거했다.
- 실제 대화창의 상단과 전신 자산의 발 좌표를 이용해 침실 다람을 배치한다.
  작은 가로 화면과 세로 브라우저의 회전 래퍼에서도 발이 대화창 위에 남는다.
- 초상 이미지와 새 아틀라스 디코딩이 끝나기 전에는 초상 타일을 숨긴다.
  빈 금색 테두리나 이전 얼굴이 잠깐 나오는 것을 막고, 로드 이벤트와
  기존 갱신 루프로 준비된 얼굴을 표시한다. 대사 영역의 자리는 유지한다.
- 장소/시간은 지도 핀과 시계가 있는 작은 종이 카드로 직접 만든다.
  옛 배너의 글자별 효과음·충격·흔들림을 장소 전환에 호출하지 않는다.
  본래 장 제목/회의/판정 연출은 기존 배너를 유지한다.
- 장소 카드의 Promise 완료, 유지 시간, __t0/__skip 입력 규약,
  중복 종료 방지와 전환 시 대사창 정리를 유지한다.
- 배너를 띄우는 같은 작업에서 기존 오디오 tick을 실행한다.
  같은 P5 장면의 장 제목에서 음악 차단이 다음 220ms 폴링까지
  늦던 구간을 수정했다. 새 타이머나 별도 음악 상태를 만들지 않았다.
