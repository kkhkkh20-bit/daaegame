1장 v2 — 컷·음악 타이밍과 대화용 그림 분리 (2026-10-11)

사용자 요청
- 부녀 전체 그림과 인게임이 왔다갔다 하는 현상, 음악·배경 전환 순서를 수정한다.
- 현장에 선 모습과 대화할 때 가까이 다가온 모습은 별도 그림으로 제작한다.
- 에이전트로 디자인 기획·타이밍·실제 플레이를 나눠 검사한다. 검증 후 main 바로 반영.
- 이번 신규 대화 그림/마부 컷 제작·연결은 명시 요청 범위다. 기존 보류 아트를 자동 채택하지 않는다.

화면 기준
1. 현장: 기존 전신·작업 자세와 실제 알파 클릭 영역 유지.
2. 대화/질문: 새 투명 상반신 atlas. 같은 상대를 유지하며 부녀가 말해도 상대 표정을 초기화하지 않는다.
3. 회의: 기존 별도 좌석 그림/얼굴 경로 유지. 대화용 상반신을 회의 좌석에 덮지 않는다.
4. 전체 컷: 위 대화 인물을 숨긴다. 같은 장면의 @dir 대기 중에도 컷을 유지한다.
5. 아빠: 1인칭 플레이어 유지. 신규 그림은 화자 초상에만 사용하며 대화 무대에 아빠 전신을 추가하지 않는다.

확인한 원인과 수정
- 기준 c6633238bfa1을 실제 새 게임으로 빠르게/천천히 진행했다. P2 마을 컷은 2개 생성되고
  대사 배치 사이 362~366ms 원래 무대로 돌아갔다. P13 봉인은 2개 생성, 약250ms 공백이었다.
- inn_story_cinematics: DL 유무 대신 G·phase·sid 소유권으로 컷을 유지한다.
  대사 배치 사이 DL=null이어도 같은 장면이면 유지. 봉인 개봉/마부 등 명시 cue에서만 전환한다.
  다음 CG는 별도로 decode 후 교체해 원래 작은 좌석이 비치지 않는다. 늦게 끝난 이전 onload는 버린다.
- P1: 부녀 마차 컷 → 까로가 돌아보는 새 마부 컷을 한 번 전환. 이후 아빠 답변도 마부 컷 유지.
- inn_opening_direction: 밤 레이어에 G/실제 장면 소유권을 추가하고 즉시 정리한다.
- inn_audio: __innPresentationState와 같은 시점을 사용한다. 장소 카드/첫 이미지 준비 중 정적,
  같은 장면에서 이미 준비된 CG를 유지하며 다음 CG를 읽을 때는 같은 음악을 끊지 않는다.
  새 대사 큐는 새 컷 commit 뒤 처리. 종·심박·출발 마차 예약은 G/sid/phase 변경 시 취소한다.
- patch65/inn_stage.split: native banner/dir/대사 continuation을 G·screen·pro/end phase/sid로 검사.
  메인 진입·저장 교체·다른 장면 진입 뒤 과거 callback이 대사나 장면을 다시 넣지 않는다.
  P5 뒤 chapter title은 존재하지 않는 window.banner 대신 엔진 내 banner를 사용한다.
- native talkFig: 신규 bust를 동기 처리 후 return한다. 옛 전신을 넣고 다음 RAF에 다시 bust로
  덮던 왕복을 제거했다. on(k)=false였던 할머니/밤이도 신규 경로에 포함한다.
- atlas 준비 중에는 대화 자리를 비워 예약한다. 기존 전신을 먼저 표시하지 않는다.
  오류 시 기존 승인 그림 fallback을 복원하며, 상태 API에 failed를 표시한다.
- 작은 화자 얼굴도 해당 대화 atlas의 같은 표정에서 source 좌표로 표시한다.
