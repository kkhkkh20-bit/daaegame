2026-10-11 로딩부터 마을 여행까지: UI 톤과 공간 연속성

사용자 지시
- 로딩 UI부터 제각각인 톤을 통일한다.
- 마을로 가는 장면이 있어야 한다. 우체국이 닫혔다는 말에는 우체국 입구를 보여 준다.
- 기존 아빠 시점, 짧은 부녀 대화, 음악 선행, 공개/v2 구분과 직접 main 반영 정책을 유지한다.

UI
- boot_theme.css/html을 wrapper와 게임의 최초 #bootld가 공유한다.
- 남색 첫 paint·노랑 진행 막대·sans 로딩 글꼴을 월넛/황동/종이색과 Galmuri, 편지/돋보기 문양으로 바꾼다.
- iframe을 받기 전에도 같은 로딩 화면을 보여 준다. wrapper의 가로/세로 transform을 함께 사용한다.
- iframe이 자체 loader를 그리면 같은 origin/source postMessage로 외부 loader가 넘겨준다.
- 게임 준비/로딩 제거는 기존 native 계약을 유지한다. v2의 외부 Google Fonts 연결은 제거한다. 게임은 기존 embedded Galmuri, wrapper는 같은 저장소의 OFL Galmuri를 로컬로 쓴다.
- main/설정 바탕도 월넛으로 맞췄다. 장소/time 카드는 기존 종이 카드 문양을 공유한다.
- 여행 장소 배지는 기록 버튼 아래 top74에 두고 native 장소 카드 동안 숨긴다.

실제 화면과 대본
- P1: 부녀 마차 대화 → 엄마 편지/우체국 목적 → 창밖 고갯길과 다가오는 마을 → 정차 → 까로 → 귀환 시간 질문.
- P2: 손잡고 걷는 마을 전경 → 닫힌 우체국 출입문/셔터와 '닫음' 표찰 → 언덕 위 불 켜진 집 → 계단을 올라 여관 문 앞.
- P2의 노크는 외부 컷에서, P3의 문열기 역시 외부 컷에서 재생한다. P3의 명시 stage 방향과 암전에서 실내로 들어온 뒤 문닫기/할머니 환영으로 이어진다.
- 이름을 읽기 전 wide 컷에서 여관 이름을 먼저 말하지 않는다. 언덕의 불 켜진 집을 본 뒤 입구 간판에서 이름을 읽는다.
- 새 camera D만 추가하고 P1/P2/P3와 다른 scene ID·순서는 유지했다. 구저장/관리자 entry cursor를 밀지 않는다.
- camera는 주석/대사 regex가 아니라 명시 direction으로 소유한다. 같은 scene owner의 암전도 decode와 실제 음악 .28초 선행을 기다린다. 같은 음악은 이어 재생한다.
- native endDlg callback 뒤 옛 freeze 창을 다시 붙이는 wrapper가 있다. 동기 정리뿐 아니라 owner/game/camera 확인 microtask에서 첫 paint 전에 그 tail을 지운다. 새 live DL은 clear 함수의 기존 guard로 보호한다.
- 신규 고해상도 배경은 main 첫 로딩과 경쟁하지 않고 P1/P2 진입부터 다음 몇 컷을 준비한다.
