1장 v2 — 현악 음악·행동 효과음·대사 압축 (2026-10-10)

사용자 요청
- 피아노의 박자·불협이 계속 어색함. 긴 설명 대사와 관찰 능력을 평가하는 지문 제거.
- 말발굽·문 열고 닫는 소리 교체. 에이전트로 필요한 순간과 적용 오류 검수.
- 검증 후 main에 바로 반영하고, 공개 원본과 v2를 계속 분리.

음악
- CODEX_PIANO_MUSIC_20261010.txt의 피아노 버전은 과거 기록이다.
- 현재 빌드는 inn_music_tracks.js + audio/v3/*-strings-v3.mp3를 사용한다.
  피아노를 빼고 첼로·현악·피치카토의 9곡으로 교체했다. 이전 자산은 보관만 한다.
- Dm/Bb/F/C의 기본 3화음, 4/4 정박. 악기 lane 1/2/5만 발음한다.
  메인 72, 조사 80, 회의 88→104, 최종 대결 96→112 BPM.
- 인물 대화 때 조사곡을 갈아 끼우지 않는다. 다른 템포끼리 1.1초 겹치던
  전환은 80ms 종료→60ms 여백→400ms 진입으로 바꿨다(패치 56).
- 대사 중 배경음은 낮게. 엄마의 글씨·생존 확인·핵심 증언은 정적.
  솜솜 발견은 어둠→털→등잔→작은 몸 순서와 정적·심박을 유지한다.
  구조 준비부터 심박을 끝내며, 생존은 원탁회의에서 확인한다.

효과음
- inn_recorded_sfx.js: 녹음 나무문 열기 0.435초, 닫기 0.586초.
  P3의 550ms 간격에서 겹치지 않으며, 후일담 E4도 문 여는 cue를 연결했다.
- 마차: 실제 발굽 두 번을 1.2초 루프로 편집. 기존 합성 발굽·마구 방울·
  덜컹 소리는 함께 재생하지 않는다. 정차는 300ms 종료, 출발은 기존 멀어짐 유지.
- 작은 클릭/메뉴 선택은 낮고 짧게, 자세히 보기는 종이음 하나,
  증거 지급은 두 음 한 번, 솜솜 생존은 작은 반짝임.
- 놀람 표정·감탄·중요 대사에 자동으로 붙던 충격음은 제거했다.
  대본의 명시적 impact와 실제 반박·최종 인정은 타격을 유지한다.
- C03 획득음 중복 제거: 공용 획득 카드가 한 번 재생한다(패치 57).
  질문/지급/솜솜 구조 모두 같은 책임으로 묶어 질문의 획득음도 유지한다.
- F3의 백 냥 인정과 F4의 누명 자백을 구분한다. F3의 '…네.'가 최종 자백 음악을
  먼저 실행하던 오류를 마지막 FINAL phase 조건으로 수정했다.
- native 회의 대사의 표/음악 큐는 대사가 시작할 때 동기 적용한다(패치 58).
  말풍선 글자를 나중에 매칭하던 방식에서 첫 짧은 지목 대사의 표 이동이
  누락되던 문제를 고쳤다. overlay 대기열과 중복 적용 보호는 유지한다.
- 지목 화면 재진입의 버튼은 클릭 당시 현재 회의 화면을 찾는다(패치 59).
  이전 회의 DOM을 캐시한 핸들러로 새 화면의 지목이 막히는 경우를 막았다.
- 비동기 디코딩은 옛 상태·음소거·지연된 단발음·종료된 루프를 재생하지 않는다.
- 출처·변형·라이선스: audio/v3/CREDITS.txt, audio/v3/sfx/SFX_CREDITS.txt.
  음악은 독자 작곡/FluidR3 MIT, 문 CC BY 3.0, 말발굽 CC BY-SA 3.0.
  개별 원본·해시·라이선스 문서도 저장했다.

대사
- 프롤로그/조사/회의·대결/후일담의 설명·복창·정답 요약을 짧게 줄였다.
  불필요한 줄은 삭제했다. '다람이만 알아봤다' 식 능력 평가도 제거했다.
- 전직 탐정·서점·엄마 실종·편지 출처·딸의 동행·아빠의 제한 조사 동기,
  비공개 침대 밑 위치·장부 열람 허락·도토 방문 힌트는 유지한다.
- 증거 원문, 대결 단계, 증거 순서, 표 이동, 제한 조건, 저장 키는 유지한다.
  엄마의 실제 장부 단서 '지난겨울, 열세 번째 침대'도 유지한다.

검증 방법과 범위
- qa_music_assets.py: 9곡의 정박/3화음/피아노 미사용, 실제 MP3/WAV의
  클리핑·루프 경계·SHA256·HTTP 경로·라이선스. 직접 청취 평가는 아니다.
- qa_audio.py: 실제 브라우저 음악 선택/정적/압박/실패/최종 인정,
  Web Audio 디코딩·오프라인 루프, 미디어 캐시 3개 한도.
- qa_sfx_cues.py: 준비 상태에서 효과음 호출 횟수/실제 녹음 소스/중지 검증.
- qa_intro.py, qa_story.py: 새 게임 도입과 가족 동기·증거 논리.
- qa_scene_guidance.py: 실제 클릭으로 C01/C02/솜솜/C04/도토 단서·저장 복구.
- qa_flow.py --without-ledger: 준비한 증거로 회의→8개 반박→후일담.
  조사의 실제 클릭 검증과 준비 상태의 회의 검증 범위를 구분한다.
- qa_saved_notebook.py: QA hook 없는 배포 빌드에서 실제 수집 저장 이어하기.
- 실기기·스피커 청취를 완료했다고 주장하지 않는다.
