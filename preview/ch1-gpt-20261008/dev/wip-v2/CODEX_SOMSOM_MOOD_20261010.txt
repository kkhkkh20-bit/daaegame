2026-10-10 · 장소·시간 UI / 솜솜 발견 / 감정별 음악

승인 범위
- 사용자가 장소·시간 UI 재디자인, 솜솜 자리 노란 박스 삭제, 희미한 배경 모습,
  손에 든 발견 그림 제작을 요청했다. 사람 손 대신 털 많은 다람쥐 앞발,
  풍성하고 예쁜 쥐 털, 그림과 연출 모두 신비한 분위기를 추가로 지정했다.
- 조사·심각·코믹·친구 만남에 서로 다른 배경음을 요구했다.
- 기존의 즉시 main 반영·배포 승인 유지. 작업은 preview v2에 한정한다.

UI
- 초반 장소·시간 banner와 실제 방 이동 placeCard(.arr10)를 같은 작은
  종이 카드로 통일. 왼쪽 위치 핀, 장소명, 시계 아이콘과 시각을 배치한다.
- 초반의 실제 title/sub를 보존한다. 이동 중에는 확정되지 않은 분 단위
  시각을 만들지 않고 다음 날 오전/후일담 오후로 표시한다.
- 회의·투표·대결 판정 배너를 장소 카드로 오인해 꾸미던 범위를 줄였다.
- 원래 배너 Promise·1400ms·입력 차단, 이동 도착 1700ms를 유지한다.
- SVG 아이콘에는 fill/stroke를 직접 명시하여 기존 도트 래스터 변환에서도
  검은 실루엣으로 변하지 않도록 했다.

솜솜
- o_under의 border/background/pseudo/icon과 자동 힌트 테두리를 없앴다.
  누르는 영역은 유지하며 키보드 focus-visible만 희미한 흰 점선으로 남긴다.
- 기존 C04 바구니 그림의 잠든 쥐를 SVG로 프레이밍하여 상자 옆 어둠 속에
  작은 희미한 형상으로 배치한다. 새로운 위치 증거나 생존 신호는 만들지 않는다.
- 발견 완료/기존 C04 저장/관찰 완료/바구니 이송 뒤에는 숨은 모습을 제거한다.
- 어둠→털→등잔빛→몸→앞발에 받쳐 든 그림→바구니의 한 번의 흐름이다.
  단서 C04 지급은 기존 대화·부리 소개가 끝난 뒤 한 번만 유지한다.
- 새 그림 art/ch1/discovery/somsom-held.png는 image_gen으로 생성한 뒤
  사용자 요청에 따라 털 앞발·작은 발톱·풍성한 솜솜 털로 수정했다.
  이미지 후처리 없이 원본을 복사했다. 참조와 SHA256은 같은 폴더 manifest.json.
- 그림은 .8초 동안 등잔빛에 드러난다. 음악과 글자 효과음은 쉬고, 손에 든
  동안 저음 두 박 소리는 1.16초 간격으로 작게 유지한다. 숨/맥박에 맞춘
  몸 움직임·피·마킹·새 단서는 넣지 않는다. reduced motion에서는 정지한다.

음악
- 기존 주요 9곡은 있으나 인물 대화 대부분이 조사곡을 공유했다.
- 새 원곡 4개: 조사 D단조 88BPM 피치카토·목관, 심각 D단조 56BPM 첼로·하프,
  코믹 G장조 100BPM 목관 응답·쉼, 만남 F장조 76BPM 플루트·현·하프.
  단순히 같은 곡의 템포를 바꾼 것이 아니다. 악보·음원·크레딧은 audio/v4/.
- 타이틀·여행·회의·압박·대결·후일담의 기존 v3 핵심 곡은 보존했다.
- 소스 gen/music_context_v4.py, 배포에서는 생성기를 실행하지 않고 MP3 사용.
  FluidR3_GM 악기 샘플, MIT 원문은 audio/v2/FLUIDR3-LICENSE.txt에 유지.
  피아노 악기와 타 게임 음원·채보 선율을 사용하지 않는다.
- 표정이나 감탄부호만으로 음악을 전환하지 않는다. 실제 대사의 의도에
  맞는 큐를 대화/장면 동안 유지하고 같은 상황의 곡은 재시작하지 않는다.
  예: 여관 인사 friend→엄마 사진 serious→입장 friend,
  괴물 목소리 comic→함께 탐정 약속 friend, 나비의 온기 friend,
  부리의 차갑다는 진술 serious, 밤이의 목격 진술 investigation.
- 솜솜·밤 복도 정적과 회의/대결의 명시 silence/pulse/press 큐가 우선한다.
