추리 UI 단순화 — 조사 → 회의 → 대결 (2026-10-10)

사용자 방향
- 방탈출처럼 현장에서 증거를 찾는다.
- 회의에서 주민들의 발언을 듣고, 모순을 반박해 의심과 표를 바꾼다.
- 마지막 대결에서 상대의 변명을 증거로 무너뜨린다.
- 조작은 아이콘 중심으로 간단하게 한다.

현재 구현
1. 조사
- 장면의 물건을 직접 조사하고 주민에게 질문해 실제 증거/증언을 모은다.
- 별도 '추리' 수첩과 두 카드+결론 고르기 퀴즈를 제거했다.
- 필수 관찰/증거 자세히 보기, 상자 허락/잠금장치, 솜솜의 직접 발견은 유지한다.
2. 회의
- 기본 조작은 증거 / 질문 / 다음 세 아이콘이다.
- 증거를 열면 현재 발언을 함께 표시하고, 기존 증거 그림과 짧은 이름으로 고른다.
- 선택 후 제시를 직접 눌러 판단한다. 취소하면 선택을 해제한다.
- 관련 증거를 너무 일찍 제시한 경우 감점 없이 안내한다. 선택만으로는 감점하지 않는다.
- 손자국→나비의 증언, 시계→잠자리→첫눈 일지 등 기존 단계별 증거 반박을 유지한다.
- 발견 위치 비교도 솜솜→발견 기록을 직접 제시한다. 비공개 위치는 세련의 실언 전에 공개하지 않는다.
- 주민들의 실제 표 변화는 기존 votes/rtVotes 데이터로 유지한다. 대상 얼굴과 짧은 이름을 함께 표시한다.
3. 대결
- 같은 증거 선택→제시 조작으로 상대의 주장을 반박한다.
- F1은 기존 0번 phase 안에서 도입 대사 후 토론을 연다. 붉은 털→주머니를 플레이어가 직접 제시해야 한다.
- 정답 증거 자동 선택/자동 완료를 제거했다. 봉인과 액수, 목격담 반박도 직접 진행한다.

소스

- inn_evidence.js: 이미 배운 첫눈 관찰만 증언에 추가한다. 배우지 않은 관찰은 제공하지 않는다.
- 53_logic_gate.py: 기존 정답 연출의 재시도 보호, 이전 reason 저장 기록 호환. 추가 퀴즈 게이트 제거.
- 54_direct_proof.py: 토론 도입 대사 지원, 오디오 메타 연결, 비동기 오답/투표의 중복 및 오래된 콜백 보호.
- inn_ui9.js: 세로에서 넘치는 원래 장면의 반복 중앙 복귀 제거, 기존 좌우 이동 복원.
- 제거된 inn_reasoning.js와 CODEX_DEDUCTION_DESIGN_20261010.txt의 별도 퀴즈 설계는 이전 이력이다.
