1장 v2 — 표정 연결과 캐릭터별 작은 동작 (2026-10-10)

요청과 범위
- 상황에 맞는 얼굴/표정, 도트 선명도와 외형 통일, 캐릭터 특징을 살린 가벼운 움직임.
- 현재 게임에 연결된 승인 PNG만 사용한다. 원본 이미지 파일은 변경하지 않는다.
  design/retro의 미승인 얼굴/전신은 자동으로 교체하지 않는다.
- 기존 조사/회의/대결, 증거 지급, 대사 본문, 음악/효과음과 클릭 판정은 유지한다.
  대사의 감정 표시 3곳만 보강했다. 본문 변경은 없다.

표정 오류 수정
- FL의 무대 표정(배열[6])과 L/W의 발화 표정([2]/m)을 __innMood로 같이 읽는다.
  큰 배우가 L 표정을 놓치고 작은 초상은 FL 표정을 놓치던 불일치를 수정했다.
- 할머니의 sad/worried/nervous/shock는 기존 걱정 그림, smile은 기존 안도 그림.
  식당의 고정 수건 자세가 이 감정을 가리지 않으며, 초상도 같은 원본 얼굴을 크롭한다.
  크롭은 최대 너비 제한으로 가로가 압축되지 않게 원본 비율을 유지한다.
- 너울: 명시적 angry/mad/confront만 분노. 느낌표/놀람만으로 분노하지 않는다.
  머쓱/규정 강조/기본은 기존 4상태 안에서 구분한다.
- 원탁의 다람이 옛 갈색 모자 외형을 현재 채택된 v4 프로필로 맞췄다.
  할머니의 걱정 그림도 회의에서 동일하게 연결한다.
- 회의는 정규화된 얼굴 SVG id(happy/neutral 등)에서 감정을 역추정하지 않는다.
  실제 native/반박 대기열의 원본 줄 m을 읽는다. smile/sad 의미가 사라지던 오류를 수정했다.
- 다람 resolve는 코믹 분노 대신 차분한 메모 그림.
- 걱정/감탄에 자동으로 땀을 붙이지 않는다. 명시적 nervous/panic/sweat/oops만 땀,
  명시적 shock/surprise만 작은 움찔을 사용한다.
- 감정 표시 보강: 장치 취급을 막는 다람 sad, 생존 확인 뒤 할머니 smile,
  이송 여부를 확인하는 다람 worried. 생존 전에는 축하하지 않는다.

동작 구현: inn_character_motion.js
- 기존 전원 idle9의 연속 회전±0.5도/세로늘이기1.012를 제거했다.
  도트의 경계를 흐리게 바꾸지 않는 1px 이동/계단식 타이밍으로 바꿨다.
- 나비 귀끝, 까로 머리깃, 밤이 매달린 귀끝, 도토 연필끝,
  부리 머리깃, 세련 종이끝은 기존 그림의 작은 부분만 SVG 레이어로 나눠 움직인다.
  새 도트를 그리거나 기존 PNG의 색/얼굴/복장을 변경하는 방식이 아니다.
- 정적인 연결부는 4 source px 겹친다. 마스크와 레이어는 장식이며 클릭을 받지 않는다.
  세련의 종이 영역에 섞인 재킷 픽셀은 검수 후 제외했다.
- 아빠/할머니는 차분한 호흡, 도토는 기록하는 짧은 끄덕임,
  부리는 작은 경청 동작, 너울은 규정 강조의 한 번 끄덕임.
  밤이를 바닥 발 기준으로 흔드는 효과는 사용하지 않는다.
- 다람 기존 t0/t1/t2 꼬리는 단일 160ms 스케줄러로 관리한다.
  기존 별도 꼬리 타이머는 제거했다. 배우별 타이머를 계속 추가하지 않는다.
- sad/worried 등 걱정·불안·분노, 솜솜 수색, pulse/silence, 엄마 글씨의 정적에서
  장난스러운 idle/꼬리를 멈춘다. 슬픔은 자세를 2px 낮추고 유지한다.
- 설정 창/기록/증거 창과 페이지 비활성에서는 멈춘다.
  prefers-reduced-motion에서는 CSS 동작과 꼬리 PNG 프레임 변경 모두 멈춘다.

화면 통일
- 큰 배우와 화자 초상 모두 image-rendering:pixelated.
- 얼굴/몸은 원본 비율 유지. 세로 화면은 너비에 맞춰 상한을 두고 몸 끝을 대사창 쪽에 정렬한다.
- 픽셀 표시 방식과 외형을 맞춘 작업이다. 원본 자산의 색수/논리 도트 격자까지
  새로 통일한 작업이나 상용 게임 수준의 전체 표정 세트 제작 완료로 보지 않는다.
- 현재 승인된 다람 v4에는 정확한 슬픔/공포 얼굴이 없다. 기존 다른 복장 얼굴을
  섞지 않고 조용한 기본 자세를 유지했다. 해당 감정의 새 도트는 후속 승인 대상이다.
- 아빠도 채택된 단일 프로필을 유지한다. 이전 다른 얼굴의 v5 손가락 포즈는 연결하지 않는다.
