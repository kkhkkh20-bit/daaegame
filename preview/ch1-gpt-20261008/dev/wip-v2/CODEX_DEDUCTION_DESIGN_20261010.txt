1장 v2 — 조사 → 회의 → 대결의 직접 추리 개선 (2026-10-10)

문제와 목표
기존 순서 지정 증거 제시와 선행 해설 뒤 결론 고르기는 답을 따라 누르는 느낌이 강했다.
장면/인물/투표/휴회/실패 연출은 유지하면서 플레이어가 근거와 결론을 먼저 연결한다.
돈을 받을 수준의 재미가 보장됐다는 뜻은 아니다. 실제 구매자 플레이테스트는 별도다.

조사
- 현장의 물증과 주민의 진술을 구분해 읽는다.
- 주머니와 이불을 조사한 뒤 침대 밑을 자동 클릭하지 않는다. 직접 조사 안내만 한다.
- 새 '추리' 버튼에서 조사 수첩을 연다. 두 기록과 결론을 선택하고 명시적으로 검증한다.
- 수첩의 오답/도움은 감점하지 않는다. 가설과 공식 판정을 구분한다.
- 정보가 부족하면 질문을 잠그고 실제로 더 확인할 곳/사람을 안내한다.
- 밤이에게 날씨 일지를 보여줘야 목격 당시 첫눈이 시작됐다는 관찰이 C13에 추가된다.
  조사에서 놓친 경우 회의 M3 도입에서 같은 관찰을 말하고 기록한다.

회의
- 기존 증언 선택/되묻기/증거창을 유지한다.
- 핵심 발언의 제시를 누르면 추리 수첩으로 그 주장을 검증한다.
- 카드 순서는 자유. 같은 카드 두 번은 불가. 두 카드+결론+제출이 모두 필요하다.
- 카드 읽기/선택 변경은 감점하지 않고, 틀린 공식 제시에만 설득력 한 칸을 쓴다.
- 도움 세 단계는 방향 → 살펴볼 사실 → 구체적 근거. 자동 정답 선택과 감점 없음.
- 완료 뒤 '이 근거로 제시하기'를 눌러야 기존 반응/표 변화/다음 안건이 진행된다.
- M2 생사 확인, 증거 부족 휴회, 표결은 기존 구조를 유지한다.

대결
- 세련의 새 설명을 접촉 흔적, 목격담, 봉인 상태로 차례로 검증한다.
- 동일 시스템을 사용하되 질문의 증명 범위가 좁아진다.
- 접촉 → 운반/은닉 → 도난 주장 → 자백과 계약 동기 순서를 유지한다.
- 접촉 자국만으로 살해, 시각 착오만으로 목격 전체 거짓, 장소 지식만으로 절도를
  확정하는 결론은 오답이며 이유를 설명한다.

직접 추리 기준표 (검사 기대값은 런타임 정답 데이터에서 자동 추출하지 않음)
linen / M1: C02 손자국 + C03 반죽 진술 → 나비에게 이불을 만졌는지 물을 이유.
time / M3: C06 숫자 없는 시계 + C07 거꾸로 매달린 자세 → 시각 착오 가능성.
           시계를 직접 돌려 보는 조작 제공.
           C13 첫눈 목격 조건 + C08 자정 첫눈 일지 → 실제 목격은 자정.
location / M4: C04 직접 발견 위치 + C10 공개 기록 → 세련의 비공개 위치 지식 확인.
contact / F1: C05 뒤집힌 글씨/별 + C01 덜 마른 같은 도장 → 봉인띠와 털의 접촉.
seal / F3: C10 온전한 봉인/백 냥 + C12 혼자 봉함/도장 품에 → 재봉인 설명 불성립.
노름/이백 냥 손실은 이후 까로의 목격과 세련의 인정으로 밝힌다.

구현과 저장
- inn_reasoning.js: 질문, 실제 카드 원문, 근거 칸, 결론, 무료 도움, 제한된 피드백.
- patches/53_logic_gate.py: 기존 정오판정 앞에서 필수 추리 게이트 처리.
- G.reason={version:1,solved:[알려진 문제 ID]}만 정제해서 저장.
  중간 선택/임의 필드는 버리고, 공식 판정을 완료 목록으로 건너뛰지 않는다.
- 다음 줄/Enter/자동 진행으로 필수 검증을 넘길 수 없다.
- 새 게임, 로드, 재시도에서는 시도 내 완료/대기 콜백을 초기화한다.
- 기존 __hush/flash의 비동기 성공도 원탁 세대/진행 상태가 같은지 확인한다.
- 대화의 효과 스킵/구형 연타 보호는 추리 모달 입력을 삼키지 않게 좁은 예외를 둔다.
  실제 장면/시계 입력 보호는 유지한다.
