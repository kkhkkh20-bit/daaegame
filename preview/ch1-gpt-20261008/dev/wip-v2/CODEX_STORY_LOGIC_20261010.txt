1장 v2 스토리 논리 개선 — 2026-10-10

범위: 별도 v2만 수정. 기존 공개본과 미승인 아트는 유지.

아빠의 동기
- 엄마의 편지가 발송된 곳과 날짜를 우체국에서 확인하려고 마을에 방문.
- 우체국이 닫혀 아이와 하룻밤 묵음. 할머니에게 사진을 보여 물어볼 계획.
- 할머니가 조사를 받게 되자 엄마 이야기를 물을 기회를 잃을까 걱정하며 주머니가 발견된 경위부터 확인.
- 솜솜을 발견한 뒤 살아 있을 가능성 때문에 구조하고, 자신의 행동을 알리고 책임지기로 함.

증거와 정보 순서
- 방에서 돈 주머니가 발견되었다는 사실과 절도 판정을 구분.
- 침대 밑이라는 발견 위치는 회의에서 세련이 말하기 전까지 공개 대사에서 삭제.
- 위치를 알고 있다는 사실은 의심의 근거로 제시하고, 실제 행위는 후속 진술로 확인.
- 표결은 최종 판정 전의 의견이며 새 증거에 따라 바뀔 수 있다고 설명.

인물 행동과 결말
- 세련의 자정 방문, 솜솜 이동, 돈 주머니 은닉을 자백으로 연결.
- 노름으로 잃은 돈의 책임을 할머니에게 돌리고, 서명을 받아 여관 인수 실패까지 덮으려 했다는 동기 보강.
- 할머니는 손님과 한 약속 때문에 기록을 보호함. 첫 장부 열람은 실제 잠금 입력 전에 허락을 받음.
- 선택 장부를 읽지 않아도 결말 대사가 읽었다고 가정하지 않음.
- 아빠가 우체국과 엄마 사진 확인을 위해 남기로 선택하고, 아이의 숙식도 확인.
- 첫눈, 다음 날 마지막 마차, 겨울 동안 막히는 고갯길의 순서를 명확히 함.

검증
- 새 게임 도입부터 조사 진입: 실제 입력 진행, 실행/HTTP 오류 0.
- 회의부터 결말: 정상 경로 및 선택 장부 없는 경로 통과, 실행/HTTP 오류 0.
- 회의의 비공개 위치 정보 누출 검사 통과.
- 장부 잠금 전에 허락 대화가 나오고 완료 후 입력창이 열리는 동작 통과.
- 솜솜 발견 연출: 가로/세로 화면에서 정적, 심박, 발견, 음악 복귀 검사 통과.
- 회의 정적/심박/압박 및 자백 소리 연결 검사 통과.

제한
- 회의/결말 검사는 준비된 조사 상태로 진입하는 자동 검사임.
- 전체 조사 과정을 새 게임부터 직접 모두 걷는 수동 플레이와 실제 기기 청취 평가는 별도 필요.
- GitHub Pages 원격 HTTP 접근은 실행 환경 프록시가 차단하므로 배포 성공은 Pages 빌드 상태와 커밋으로 확인.
