사용자 요청
- 방탈출 추리 기믹을 더하고, 비밀번호를 푸는 순간을 실제 조작으로 만든다.
- 추리 UI는 글보다 아이콘을 중심으로 단순하게 유지한다.

기존 구조

  연출은 변경하지 않는다.
- 머리판 원문 「첫 손님, 열한 번째 달 둘째 날」을 읽고 1102로 옮겨
  상자를 여는 기존 퍼즐을 유지한다. 새 사건 사실이나 임의 암호는 만들지 않는다.
- 할머니에게 작은 손님을 돌본 기록을 볼 허락을 받는다. 첫째 권만 본다는
  약속, 장부의 증거 ID C11, 이후 회의·대결의 판정은 그대로다.

숫자 자물쇠
- 새 inn_room_puzzles.js는 실제 장면의 o_inn_lock 입력을 받는다.
  inn_input의 window capture 보호를 통과한 입력만 처리하며 대사 중에는 열리지 않는다.
- 달/날 달력 아이콘 두 묶음과 네 숫자로 구성한다. 숫자를 누르면 올라가고
  아래 화살표로 내린다. 키보드는 숫자 입력, 좌우 이동, 위아래 증감,
  Backspace, Enter, Escape, Tab/Shift+Tab을 지원한다.
- 날짜는 o_inn_head2를 직접 관찰 완료한 저장 상태에서만 재표시한다.
  자물쇠를 먼저 눌렀다면 허락을 받은 뒤 머리판 자국을 살피라는 안내만 보인다.
- 도움은 관찰 방향→달/날 두 칸→한 자리도 두 칸이라는 형식 힌트이다.
  힌트가 정답 숫자를 그대로 읽어 주지 않는다. 오답은 체력/회의 오답 수를 바꾸지 않는다.
- 입력 초안 네 자리와 힌트 단계는 inn_pin_d0~d3/inn_pin_hint에 저장한다.
  sanitizer는 0~9/0~2 정수만 보존한다. 오래된 저장에는 이 값이 없어도 된다.
- 맞히면 원래 inn_lock 상태만 켜고 원래 열리는 효과음을 재생한다.
  C11을 자동 지급하지 않고, 열린 상자를 실제 조사해서 기존 대본을 진행한다.

선택 붉은 자국 비교
- 기존 C01과 C05를 모두 수집한 뒤 사건 기록의 해당 증거 상세에
  겹쳐 보기 아이콘을 보여 준다. 첫 조사 중 근접 그림을 강제로 미니게임으로 바꾸지 않는다.
- 기존 I1-seal-strip-complete-512.png와 dormouse-flank-exact-overlay-512.png를
  직접 확인했다. 털 자국은 좌우 거울상이며 180도 회전은 잘못된 글씨가 된다.
- 조작 대상은 털 자국을 옮긴 기록 종이이다. 작은 손님의 몸을 뒤집거나
  털 자국 방향을 바꾼 것으로 설명하지 않는다. 좌우 반전과 겹치기 두 동작만 있다.
- 두 원본 PNG는 그대로 사용하고, 화면에서 글씨/별 부분을 확대해 보여 준다.
  원본의 두 그림은 형태를 비교하는 기록이며 픽셀 단위 감정/일치 판정으로 취급하지 않는다.
- 겹친 뒤 문구는 글씨와 별이 같은 방향이 되었다고만 말한다.
  어떻게 묻었는지의 최종 추론과 제시는 원래 회의에서 한다.
- inn_ink_compared는 선택 조사 완료 표시일 뿐이다. 새 증거를 지급하거나
  기존 회의/대결을 잠그거나 사건 정답을 대신 제출하지 않는다.

수명/호환
- 모달 뒤의 기록/근접 보기는 보존하며 Escape/닫기/바깥 누르기로 돌아간다.
- 650ms 새 모달 보호, 키보드 repeat 차단, 포커스 순환을 적용한다.
- 게임 객체 교체·대화 시작·장면 이탈·모달 제거 때 임시 퍼즐을 정리한다.
  허락 뒤 늦은 콜백도 처음 게임 객체·방·조사 탭이 그대로인지 확인한다.
- 허락 대사가 끝난 뒤 기존 700ms 입력 보호가 풀릴 때까지 기다린다.
  그동안 Escape/메뉴 진입/새 대사/상태 교체가 발생하면 예약을 취소한다.
- 기록의 기존 자세히 보기·다람 메모에 position:relative를 복구했다.
  all:unset이 지운 기준점 때문에 ::after가 상세 패널 전체를 덮던 입력 오류를 고친다.
  기존 버튼의 확대 클릭 영역은 각 버튼을 기준으로 유지한다.
- 원래 inn_lock/C11을 가진 저장은 열린 상자를 그대로 유지한다.
- 테스트 eval 훅을 운영 모듈에 추가하지 않는다. build.py가 inn_scene_guidance
  다음에 새 모듈을 주입하고, 기존 publish 경로를 root가 실행한다.

  허락→미관찰 정보 경계→오답/도움→머리판 직접 관찰→초안 실제 저장/reload→

  다람 메모의 실제 클릭/팝업 제목, 반전·겹치기, 원래 기록으로 복귀도 확인한다.

  필요하지 않은지도 검사한다. 자산/JavaScript 오류를 수집한다.
