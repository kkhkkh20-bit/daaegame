관리자 장면 테스트 (2026-10-11)

요청
- 우측 설정에서 일반 기능과 구분된 관리자 테스트로 바로 들어가기.
- 기존 사용자 지시에 따라 검증한 v2 변경을 main에 즉시 반영/배포.

사용 방법
- 우측 메뉴 → 플레이테스트 → 관리자 테스트.
- 메인/게임 설정에도 동일한 관리자 테스트 항목을 추가했다.
- 스토리/조사/회의 · 대결/후일담 탭에서 장면을 고른다.
- 테스트 화면 상단의 '장면 선택'으로 다른 장면을 고른다.
- '일반 플레이로'로 돌아간 뒤 이어하기를 누르면 기존 저장을 재개한다.

장면
- 스토리: 오프닝, 마차 · 마을, 여관 첫 만남, 밤 복도, 도난 신고 · 수색.
- 조사: 조사 시작(증거 전), 솜솜 발견(돈 조사 뒤 실제 발견 연출),
  숫자 자물쇠(머리판 날짜/상자 조사를 할 수 있는 상태).
- 회의 · 대결: 원탁 회의, 최종 대결(필요한 증거/증언 준비).
- 후일담: 사건 뒤 일상, 엄마의 글씨(책/장부 비교부터).

구현과 저장
- inn_admin_test.js를 엔진 클로저에 주입한다. 기존 __innMain을 감싸며,
  일반 실행에서는 그대로 기존 함수를 호출한다.
- 이름이 정해진 12개 프리셋만 허용한다. 평가 함수/콘솔 명령은 제공하지 않는다.
- '관리자 테스트'는 v2 플레이테스트 메뉴다. 계정 인증/서버 관리 기능은 없다.
- 기존 저장 shim의 slot=admin-test와 testScene 쿼리를 iframe 내부에서 사용한다.
- 일반 저장 접두사: daae-preview-ch1-gpt-20261008:
- 테스트 저장 접두사: daae-preview-ch1-gpt-20261008-admin-test:
- 테스트 진입 전 일반 진행을 저장하고, 마지막으로 저장된 설정만 복사한다.
  장면 변경마다 테스트 접두사의 키만 초기화한다. 일반 진행은 복사하지 않는다.
- sessionStorage의 조사 확인 표시도 inn9seen-admin-test로 분리했다.
- 기존 'QA 저장칸' 표시는 관리자 모드에서 숨기고 장면 이름/복귀 버튼을 표시한다.
- 실제 iframe 재탐색으로 이전 장면의 타이머/음악을 종료한다.
  기본 로딩 화면 bootld가 사라진 다음에 장면을 시작하여 첫 연출이 가려지지 않는다.
- 관리자 버튼 클릭/키보드 입력은 대사 넘기기와 분리한다.
  Escape 닫기, Enter/Space 선택, 보이는 버튼만 Tab 순환.
- 설정 목록을 스크롤할 수 있게 하여 작은 화면의 음량/글씨 설정을 유지한다.
