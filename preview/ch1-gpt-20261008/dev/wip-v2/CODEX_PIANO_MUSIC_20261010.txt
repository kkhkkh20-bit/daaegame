1장 v2 — 피아노를 중심에 둔 웅장하고 기묘한 음악 (2026-10-10)

사용자 방향
“배경음은 피아노 기반 좀 웅장하고 기묘한 노래가 좋을까? 고퀄리티로.”
부녀의 기억에는 온기가 있고, 마을과 사건에는 불안이 있다.
타이틀과 반격에서 편성이 커지고, 조사와 중요한 발견에서는 여백과 정적을 둔다.

실제 제작
- 작은 범용 TimGM6mb 음원으로 만든 기존 세 곡 대신 실제 Yamaha C5 피아노 녹음 사용.
- Alexander Holm의 Salamander Grand Piano V3 soft/medium/firm 녹음층을 섞어 타건 세기를 표현.
  SFZ의 키별 보정값으로 튜닝, 고품질 샘플레이트·음높이 변환, 작은 타이밍·세기 변화 적용.
- FluidR3의 녹음 기반 첼로·현악·프렌치 호른·첼레스타·피치카토·팀파니를 받침으로 사용.
  멜로디와 주요 리듬은 피아노가 맡으며 지속적인 저음 드론·메트로놈 타악을 넣지 않는다.
- 독자 선율 D–A–Bb–E의 질문과 F–E–D의 답이 장면을 연결한다.
  D단조, Bb/F의 따뜻한 화성, Ebmaj7(#11)와 A(b9)의 불안한 화성을 쓴다.
- 메인: 76 BPM, 32마디, 약 101초. 피아노 도입 → 첼로 → 중간 관현악 확대 → 피아노 복귀.
  단순 짧은 음형을 계속 반복하는 대신 A/A'/B/A로 전개한다.
- 이동: 84 BPM. 가족이 책을 읽던 기억과 숲길을 위한 부드러운 편곡.
- 조사: 92 BPM. 말과 생각을 위한 여백, 중저음 피아노·피치카토 리듬.
- 사건: 68 BPM. 음 수를 줄이고 낮은 첼로와 긴 잔향으로 불안을 준다.
- 회의: 96 BPM → 압박 112 BPM. 대결: 112 BPM → 압박 126 BPM.
  단순 재생 속도 변경으로 음높이를 올리지 않고 각각 새 템포로 연주·렌더링한다.
- 후일담: 72 BPM. 낮아진 선율과 피아노가 가족의 목표로 돌아온다.
- 할머니·세련·나비·밤이·도토·부리·너울의 기존 테마 키를 유지하고 각각 피아노 편곡.
  낮은 집의 온기 / 정중한 불안 / 돌봄 / 높은 천장 / 기록 리듬 / 문과 장치 / 단정한 규칙.
  조사 대화 2.5초 뒤 인물 테마가 들어오는 기존 규칙도 유지한다.

믹스와 파일
- 녹음의 스테레오 위치, 저음 정리, 방의 초기 반사·확산 잔향, 피아노와 현악의 음량 균형.
- 루프의 앞부분에 이전 연주의 릴리즈를 접고 필터·잔향도 반복 경계를 고려해 처리한다.
- 강제로 모든 음을 키우기보다 정적인 음량 보정과 최대 음량 여유로 연주 강약을 유지한다.
- 44.1 kHz 스테레오, 224 kbps MP3 16곡. 게임은 장면에 필요한 곡을 읽는다.
- 기존 효과음·마차 환경음·솜솜 발견 정적/심박·반박 순간의 정적·자백 뒤 여운은 유지.
  콜드오픈의 짧은 합성 음향은 유지한다. 이 음악 수정으로 이야기·증거·그림을 바꾸지 않는다.

연결과 성능
- inn_piano_tracks.js는 렌더러가 생성하는 음원 키·템포·실제 반복 길이 목록이다.
- 기존 곡 정의 전체를 교체하여 이전 합성 반주가 새 파일과 겹쳐 재생되지 않게 한다.
- 52_sampled_music.py는 기존 음악 버스·음소거·페이드·덕킹을 사용한다.
- 디코딩한 음원의 캐시는 최근 3곡으로 제한하며, 지울 때 완료된 Promise 참조도 지운다.
  현재 재생 중인 소스의 버퍼는 재생 종료까지 유지한다. 모든 곡을 동시에 디코딩하지 않는다.
- 회의 진입 시 압박/추궁곡, 대결 진입 시 압박/할머니곡을 미리 읽어 전환 지연을 줄인다.
  준비가 늦게 끝난 옛 장면의 소스가 뒤늦게 재생되지 않도록 기존 취소 보호를 유지한다.
- 실제 작곡 길이를 Web Audio loopEnd로 사용해 파일 인코딩 여분에 따른 틈을 피한다.

검증 결과
- qa_piano_assets.py: MP3 16곡(23.74 MiB)의 SHA256, 실제 디코딩 길이, 스테레오,
  유한 파형, 최대 레벨 여유, 통합 음량, 반복 경계 검사 모두 통과.
- qa_audio.py: 모든 16곡을 Web Audio로 디코딩·8초 오프라인 재생, 클리핑 0.
  압박 템포 증가, 자백·실패·정적·심박 큐, 캐시 3곡 제한 모두 통과.
  메인 101초 전체를 넘어 반복시킨 구간의 상대 파형 차이 약 0.00036으로 연결 확인.
- qa_polish.py: 844×390, 390×844 모두 메인 음악 해제/재생, 음소거/복귀 시 재요청 없음,
  설정 음량 변경 중 곡 재시작 없음, 세 기본 음악 재생과 기존 화면 검사 통과.
- qa_somsom.py: 두 방향 모두 발견 전 정적 → 발견 순간 → 긴장 유지 → 조사곡 복귀 통과.
- 위 브라우저 검사 JS 오류·자산 HTTP 실패 0.
- 깨끗한 배포용 v2 래퍼에서도 실제 입력으로 새 메인 음악 재생을 확인했다.
  16곡 연결, QA 평가 함수 없음, JS 오류·HTTP 실패 0. 배포 파일 지문 84e4cad3da82.
