# Smooth originals and uniform pixel manufacturing references

Original master sheets are preserved unchanged. Manufacturing packages contain transformation scripts, source/output manifests, review caveats and comparison overviews. These are delivery artifacts for separate integration review, not runtime game assets or a deployment.

Extract each ZIP into a separate batch folder. See delivery-manifest.json for source ZIP byte sizes and SHA256. Scripts retain production-workspace paths and require path adaptation. Preserve REVIEW.md caveats, source identities, proportions and foot anchors when integrating.
