# 다람 탐정 — 사라진 봉투

사용자가 승인한 겨울 접수대 일러스트 시안을 바탕으로 만든 독립 실행형 1장입니다. 기존 게임과 이전 `prototype-vn/`은 변경하지 않습니다. 이번 아트는 사용자가 최근 승인한 **일러스트풍**이며 도트 완성본이라고 표시하지 않습니다.

## 실행

- `python chapter-one/build.py`: 이미지·CSS·대사를 포함하는 `chapter-one/play.html` 생성.
- `play.html`은 데스크톱 다운로드용입니다. 모바일 앱의 첨부파일 미리보기에서는 HTML/자바스크립트 실행이 차단될 수 있어 모바일 실행 링크로 안내하지 않습니다.
- 모바일은 **HTTPS로 게시한 `chapter-one/index.html`**을 Safari/Chrome에서 엽니다. 현재 공개 사이트에 새 1장이 게시됐다고 간주하지 마세요.
- 웹 진입 HTML은 약 2KB이고 배경·캐릭터는 별도 파일로 로드합니다. 그림을 불러오기 전 시작 버튼을 잠그며 실패 시 다시 불러오기 버튼을 표시합니다.
- 개발: 저장소 루트에서 `python -m http.server 8066 --directory .`, 내부 검증 주소 `/chapter-one/`.
- 검증: `NODE_PATH=/opt/codex/cua_node/lib/node_modules node chapter-one/check.cjs` (Chromium `/usr/bin/chromium`). `CHAPTER_URL`로 번들 파일도 검증할 수 있습니다.

## 플레이 범위

도착과 탐정이 되고 싶은 이유 → 까로와 대화 → 접수대 물건 4곳 조사 → 접수와 지급을 구분하는 증거 제시 → 뭉치의 열쇠에 대한 증언 검증 → 봉투 회수와 동기 확인 → 지급 명단/엄마의 보고서 비교 → 주민 앞 금액 확인 → 부녀 후일담과 다음 목적지.

두 번의 증언 검증은 정확한 문장에 관련 증거를 제시해야 통과합니다. 오답은 상황별 피드백 후 같은 증언으로 복귀합니다. 보고서 비교는 두 문서를 읽어야 답할 수 있습니다. ‘메모 보기’는 선택형 힌트입니다. 명단 누락 자체의 행정적 정당성과 엄마 이름을 옮겨 적은 사람은 이번 장에서 단정하지 않습니다.

## 자산과 구조

- `assets/reception.png`: UI와 인물이 없는 독립 배경.
- `assets/daram.png`, `karo.png`, `mungchi.png`: 세 표정/포즈가 나란히 있는 캐릭터 아틀라스. CSS로 프레임 선택.
- 모든 자산은 이번 세션의 이미지 생성 도구로 제작. Higgsfield 호출 아님.
- 글자·이름표·메뉴·조사 지점·수첩은 실제 HTML이며 그림에 붙은 가짜 버튼이 아닙니다.
- `story.js`: 시나리오/증거 데이터. `game.js`: 상태 전환과 저장. `style.css`: 반응형 화면.
- 브라우저 저장 키 `daram-illustrated-chapter1-v1`. 기존 게임 저장을 읽거나 변경하지 않습니다.
- 대화 중 카메라 흔들림/줌 없음. 표정은 정적인 3종 교체이며 세밀한 립싱크·눈 깜빡임·음성·BGM은 아직 없습니다.
- 아빠는 화면 밖의 동행자로 이름표에 표시됩니다. 엄마 회상 삽화나 별도 아빠 스프라이트를 완성했다고 표시하지 않습니다.

## 제작 판단

첫 장은 사라진 봉투 사건을 해결하는 짧은 플레이 가능한 버전입니다. 1부 전체나 상업 출시 완료가 아닙니다. 접수대 원경을 먼저 보여주고, 인물 없이 현장을 조사하며, 대화와 증거 열람을 별도 화면 상태로 처리합니다. 다람/상대 인물을 한꺼번에 띄우지 않습니다. 세로 화면이 우선이며 데스크톱은 같은 장면 비율을 유지합니다.

## 이번 검증 결과

2026-10-06 Chromium/Playwright에서 개발 진입과 단일 HTML의 전체 1장 진행을 각각 완료했습니다. 올바른 증거를 잘못된 증언에 제시, 잘못된 증거, 대화 재진입, 2차 증언, 두 문서 열람 전 정답 선택 방지, 오답 복귀, 진행/엔딩 새로고침을 확인했습니다. 360×640, 390×844, 430×932, 844×390, 1280×720에서 이름표·얼굴·조사 버튼의 가림 및 화면 넘침을 검사했고 브라우저 오류/실패 요청은 없었습니다. 단일 파일은 HTML 외 요청 없이 오프라인 전환 후 배경·캐릭터·대화가 작동하는 것을 별도 확인했습니다. 실제 모바일 Safari나 모든 기기의 터치 감각까지 검증한 것은 아닙니다.
