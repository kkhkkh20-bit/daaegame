# 다람 탐정 — 사라진 봉투

겨울 접수대를 배경으로 하는 세로형 추리 비주얼 노벨 1장입니다. 공개 경로는 `https://kkhkkh20-bit.github.io/daaegame/chapter-one/`입니다. 루트의 기존 게임과 저장 데이터는 별개로 유지합니다.

## 실행과 검증

저장소 루트에서 `python -m http.server 8070 --bind 127.0.0.1`로 개발 서버를 시작합니다.

```sh
node chapter-one/check-core.cjs
NODE_PATH=/opt/codex/cua_node/lib/node_modules node chapter-one/check.cjs
NODE_PATH=/opt/codex/cua_node/lib/node_modules node chapter-one/check-mobile.cjs
```

브라우저 검사는 Chromium `/usr/bin/chromium`을 사용합니다. `CHAPTER_URL`로 검사 주소를 바꿀 수 있습니다. `python chapter-one/build.py`는 선택적인 데스크톱 다운로드용 `play.html`을 생성합니다. 모바일에는 큰 단일 파일 대신 공개 웹 주소를 사용합니다.

## 화면과 조작

- 조사는 가로 배경을 손가락으로 밀거나 좌우 버튼으로 이동합니다. 물건을 직접 누르며 돋보기 표시는 없습니다. 키보드 초점은 접근성을 위해 표시합니다.
- 대화 중에는 카메라가 고정됩니다. 아빠 대사에서는 다람의 반응을 보여주고 이름표로 화자를 구분합니다. 생각은 괄호와 파란 글씨로 구분합니다.
- 다람은 여섯 표정·포즈, 까로와 뭉치는 각각 세 가지를 사용합니다. 까로의 화면 점유 크기를 줄였습니다.
- 얇은 메뉴와 반투명 대화창, 단순한 수첩을 사용합니다. 객관적인 증거 설명과 다람의 장난스러운 낙서는 분리합니다.

## 원작 시스템 연결

`tools/extract_core.py`가 기존 `game.html`에서 `fresh`, `gated`, `comboFor`, `haveItem`, **전체 `judgeBattle`** 등을 포함한 15개 함수를 그대로 추출합니다. `legacy-provenance.json`에 원본 위치와 SHA256을 기록합니다. `legacy-core.js`는 원작의 화면·효과 호출을 새 화면 어댑터로 연결합니다. `case-data.js`는 이번 사건을 원작 데이터 형식으로 제공합니다.

이번 장에서 사용하는 기능:

- 현장 조사, 조건부 장소 이동, 인물별 질문·잡담·증거 제시
- 증거의 구체적인 부분 검사, 증언 수집, 증거/증언 결합 세 가지
- 정확한 증언 문장에 증거 제시, 신뢰도 다섯 칸, 재도전
- 인물·증언·증거·시간순 기록 수첩, 증거 고정, 힌트 세 번
- 범인·위치·동기를 따로 고르는 최종 추리, 후일담
- 자동 저장, 수동 슬롯 세 개, 저장 파일 내보내기/가져오기

첫 장은 접수증의 서명이 무엇을 증명하는지, 잠긴 보관함의 다른 열쇠, 지급 명단과 엄마의 보고서가 확인한 범위의 차이를 추리합니다. 문서를 단순히 열기만 해서는 검사를 끝낸 것으로 처리하지 않습니다.

원작 15개 사건과 후반 전용 미니게임 전체를 이식한 버전은 아닙니다. 해당 원작은 루트 게임에 남아 있습니다. 이번 새 사건에 필요한 원작 판정과 시스템을 연결한 것입니다.

## 자산·저장

- `assets/reception.png`: 대화 배경. `panorama.png`: 가로 조사 배경.
- `daram.png`, `daram-extra.png`, `karo.png`, `mungchi.png`: 투명 배경 3열 캐릭터 아틀라스.
- 그림은 이미지 생성 도구로 제작한 일러스트입니다. Higgsfield 생성물 또는 완성된 도트 아트로 표시하지 않습니다.
- 실제 UI와 대사는 HTML/CSS입니다. 그림 속 글자를 버튼으로 사용하지 않습니다.
- 저장 키는 `daram-illustrated-chapter1-v1`, 수동 슬롯은 같은 키에 `:slots`를 붙입니다. 이전 1장 저장을 이어받습니다.
- 표정은 정적인 포즈 교체입니다. 립싱크·음성·BGM은 아직 구현하지 않았습니다.
