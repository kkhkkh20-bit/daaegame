# 다람 탐정 — 사라진 봉투

겨울 접수대를 배경으로 하는 세로형 추리 비주얼 노벨 1장입니다. 공개 경로는 `https://kkhkkh20-bit.github.io/daaegame/chapter-one/`입니다. 루트의 기존 게임과 저장 데이터는 별개로 유지합니다.

## 실행과 검증

저장소 루트에서 `python -m http.server 8070 --bind 127.0.0.1`로 개발 서버를 시작합니다.

```sh
node chapter-one/check-core.cjs
NODE_PATH=/opt/codex/cua_node/lib/node_modules node chapter-one/check.cjs
NODE_PATH=/opt/codex/cua_node/lib/node_modules node chapter-one/check-mobile.cjs
```

브라우저 검사는 Chromium `/usr/bin/chromium`을 사용합니다. `CHAPTER_URL`로 검사 주소를 바꿀 수 있습니다. `python chapter-one/build.py`는 선택적인 데스크톱 다운로드용 `play.html`을 생성합니다. 모바일에는 큰 단일 파일 대신 공개 웹 주소를 사용합니다.

## 화면과 조작

- 조사는 가로 배경을 손가락으로 밀거나 좌우 버튼으로 이동합니다. 물건을 직접 누르며 돋보기 표시는 없습니다. 키보드 초점은 접근성을 위해 표시합니다.
- 대화 중에는 카메라가 고정됩니다. 아빠 대사에서는 다람의 반응을 보여주고 이름표로 화자를 구분합니다. 생각은 괄호와 파란 글씨로 구분합니다.
- 다람은 여섯 표정·포즈, 까로와 뭉치는 각각 세 가지를 사용합니다. 까로의 화면 점유 크기를 줄였습니다.
- 얇은 메뉴와 반투명 대화창, 단순한 수첩을 사용합니다. 객관적인 증거 설명과 다람의 장난스러운 낙서는 분리합니다.

## 제작 원칙 — 원작 시스템 유지

기존 다람탐정 게임을 시스템의 기준으로 삼습니다. 새 버전의 변경 범위는 화면 디자인, 캐릭터 연출, 시나리오와 사건 데이터입니다. 조사·이동·질문·수첩·검사·결합·증언·추궁·제시·판정·힌트·저장·음악·효과를 별도 축약 규칙으로 대체하지 않습니다. 미연결 기능은 원작 구현을 확인해 연결하며, 원작 판정 코드와 새 화면 어댑터를 구분합니다. 현재 연결된 1장 기능과 아직 이식되지 않은 후반 전용 기능은 아래에 명시합니다.

아빠의 이름은 **다온**입니다. 대사 이름표, 서술과 대화 기록, 인물 수첩에 사용합니다. 다람이 부르는 호칭은 자연스럽게 ‘아빠’를 유지합니다. 아빠 관점의 서술과 상대 인물을 보여주는 연출도 유지합니다.

## 원작 시스템 연결

`tools/extract_core.py`가 기존 `game.html`에서 `fresh`, `gated`, `comboFor`, `haveItem`, **전체 `judgeBattle`** 등을 포함한 16개 함수를 그대로 추출합니다. `legacy-provenance.json`에 원본 위치와 SHA256을 기록합니다. `legacy-core.js`는 원작의 화면·효과 호출을 새 화면 어댑터로 연결합니다. `case-data.js`는 이번 사건을 원작 데이터 형식으로 제공합니다.

이번 장에서 사용하는 기능:

- 현장 조사, 조건부 장소 이동, 인물별 질문·잡담·증거 제시
- 증거의 구체적인 부분 검사, 증언 수집, 증거/증언 결합 세 가지
- 정확한 증언 문장에 증거 제시, 신뢰도 다섯 칸, 재도전
- 인물·증언·증거·시간순 기록 수첩, 증거 고정, 힌트 세 번
- 범인·위치·동기를 따로 고르는 최종 추리, 후일담
- 자동 저장, 수동 슬롯 세 개, 저장 파일 내보내기/가져오기

첫 장은 접수증의 서명이 무엇을 증명하는지, 잠긴 보관함의 다른 열쇠, 지급 명단과 엄마의 보고서가 확인한 범위의 차이를 추리합니다. 문서를 단순히 열기만 해서는 검사를 끝낸 것으로 처리하지 않습니다.

원작 15개 사건과 후반 전용 미니게임 전체를 이식한 버전은 아닙니다. 해당 원작은 루트 게임에 남아 있습니다. 이번 새 사건에 필요한 원작 판정과 시스템을 연결한 것입니다.

## 원작 소리 복원

`tools/extract_audio.py`로 원작의 여섯 가지 합성 배경음(calm, sneak, talk, battle, pursuit, win)과 기본 효과음 코드를 추출했습니다. `audio-provenance.json`에 원본 해시를 기록합니다. `tools/audio-adapter.js`는 재생 시작, 모바일 백그라운드 정지/복귀, 배경음·효과음 개별 음량과 설정 보존을 담당합니다. 조사·대화·공방·후일담에 맞춰 곡을 바꾸고, 글자 출력·페이지 넘김·발견·검사·결합·이동·추궁·제시·오답에 소리를 연결합니다.

설정에서 각 음량을 0으로 내리면 해당 소리만 끕니다. 브라우저 자동 재생 제한에 맞춰 사용자가 게임 버튼을 처음 누른 뒤 소리가 시작됩니다. 녹음 파일이나 새 외부 음악을 추가한 것은 아닙니다. `check-audio.cjs`는 터치 시작, 실제 오실레이터 생성, 개별 음소거, 설정 보존, 배경 전환 시 정지와 복귀를 Chromium에서 검사합니다.

## 최신 UI 테마

`ui.css`에서 붉은 이름표와 사건 수첩, 흰 증거 서류, 다람 초상이 붙은 개인 메모를 구분합니다. 제목과 이름표는 원작의 Galmuri11 글꼴을 사용하며 OFL 라이선스 사본을 함께 배포합니다. 확인한 공식 스크린샷과 적용 원칙은 [UI_REFERENCES.md](UI_REFERENCES.md)에 기록했습니다. 배경·캐릭터 이미지, 원작 판정과 소리는 그대로 유지합니다.

### 사용자 첨부 예시를 반영한 최신 창 구성

현재 `ui.css`는 아이보리·청록의 둥근 모바일 게임 UI입니다. 이전 붉은 직각 테마를 대체했습니다. 질문은 번호가 붙은 카드, 대사는 밝은 창과 화자 표찰, 수첩은 중앙 제목과 원형 닫기 버튼으로 구성합니다. 까로 반신 이미지의 하단은 세로 대사창 안쪽에 맞춰 절단면이 떠 보이지 않게 했습니다. `check.cjs`에서 얼굴 가림뿐 아니라 원본 이미지 하단이 창 뒤에 있는지도 검사합니다.

## 증거 선택 흐름 복구

원작 `recItems` 함수를 추가로 그대로 추출해 증거·증언 목록을 구성합니다. `selectRecord` 어댑터는 원작처럼 선택과 열람 여부(`G.seen`)를 기록합니다. 상세창 안에서 현재 선택한 증거의 이름, 검사 상태, 다른 수집 기록을 함께 확인하고 바로 바꿀 수 있습니다. 목록으로 돌아가도 선택 표시를 유지합니다. 공방에서는 제시 대상 인물과 정확한 증언 문장을 표시하고, 확인 버튼에도 제시할 증거 이름을 씁니다. 제시 뒤 대사/기록에도 사용한 증거 이름을 남깁니다. 결합 결과를 제시하는 경우에도 제시 모드를 유지합니다.

이는 현재 1장에 사용 중인 원작 수첩·공방 흐름의 복구입니다. 후반 사건 전용 시스템까지 모두 이식했다는 의미는 아닙니다.

## 장면 연출 연결

원작 `flash`, `panicFx`, `stampFx`, `cutin`, `banner`의 역할을 확인하고 새 세로 화면에 맞는 `effects.js`로 연결했습니다. 원본의 전체 화면 흔들림·긴 입력 잠금은 그대로 복제하지 않았습니다. 중요한 대사의 놀람·당황·깨달음·장난스러움, 추궁·반박·오답·증거 발견·결합·사건 해결을 구분합니다. 캐릭터의 짧은 움직임과 표식은 장면당 한 번만 표시하며 다음 대사에서 정리됩니다. 일반 대화의 카메라와 대사창은 움직이지 않습니다.

설정의 ‘화면 연출’은 기본/움직임 줄이기/끄기를 지원하며 저장됩니다. OS의 reduced-motion 설정도 존중합니다. 효과 레이어는 입력을 가로채지 않습니다. 원작 소리와 현재 캐릭터 표정을 사용하며 새 표정 그림을 추가한 것은 아닙니다. 기존 저장 대사에도 동일한 대사 텍스트에 해당하는 연출을 적용합니다. `check-effects.cjs`에서 실제 도입 대사의 놀람, 다음 대사 정리, 입력 통과, 저동작·끄기, 중복·타이머 정리를 검사합니다.

## 캐릭터 비율과 아빠 시점

`portraits.js`가 캐릭터별 프레임 종횡비, 얼굴 폭, 눈 위치를 기준으로 화면상의 얼굴 크기를 통일합니다. 다람은 눈높이를 12px 낮게 두고, 성인 인물은 공통 눈높이를 사용합니다. 반신 그림의 아래 절단선은 대사창 뒤에서 잘라 표시합니다. 화면 크기가 바뀌면 다시 계산하며 대사마다 줌을 하지 않습니다. 질문창의 간격도 줄였습니다.

아빠 이름표의 ‘곁에서’는 삭제했습니다. 아빠가 현재 인물과 대화할 때 상대를 그대로 보여줍니다. 서술 이름표와 가족 관계 표현은 아빠의 관점으로 맞췄으며, 다람 자신의 생각·수첩 메모는 다람의 것으로 유지합니다. 기존 저장의 해당 서술과 아빠 대화 대상도 보정합니다. `check-portraits.cjs`가 인물별 얼굴 크기·눈높이·절단 위치·아빠 대화 대상을 검사합니다.

## 원작 도트 UI 복원 — 현재 테마

`pixel.css`가 앞선 둥근 아이보리·청록 테마를 대체합니다. 기존 `game.html` 도트 모드의 Galmuri11/Galmuri11B 폰트 파일을 그대로 사용하고, 같은 짙은 남색·크림 선·노란 선택색, 직각 이중 테두리와 눌림 버튼 원칙을 적용했습니다. 대사와 질문은 원작 굵은 도트 글꼴, 설명과 보조 조작은 일반 도트 글꼴입니다. 폰트 로딩은 게임 시작 전에 기다립니다. OFL 라이선스는 기존 사본에 포함합니다.

증거 제목은 고정된 창 제목에 한 번만 표시하며 선택 번호/목록과 실제 문서를 구분합니다. ‘선택한 기록’ 박스를 줄이고, 다람의 낙서는 선택적으로 펼치게 했습니다. 검사 결과와 하단 조작은 유지합니다. 캐릭터·배경 일러스트를 도트로 바꾼 버전은 아니며, UI와 글꼴을 원작 기준으로 복원한 것입니다. 아빠 시점, 캐릭터 비율, 효과·소리, 원작 판정은 유지합니다.

## 조사 위치와 증거 그림

원작 `game.html`의 `bindScene → lensAt → evIcon` 발견 흐름과 수첩의 그림 표시를 참고했습니다. 평소 돋보기는 숨기고, 누른 조사 영역에 테두리와 물건 이름을 표시한 다음 340ms 뒤 증거창을 엽니다. 닫으면 표시도 정리됩니다. 드래그는 조사로 처리하지 않습니다.

접수증·받침·시계·보관함은 기존 파노라마에서 해당 부분을 CSS로 확대합니다. 열쇠는 뭉치 그림의 열쇠 부분, 봉투·명부·보고서는 원작 `evIcon`의 해당 도형을 사용합니다. 결합 결과에는 실제 결합한 자료들의 그림을 함께 표시합니다. 이미지 파일을 새로 생성한 것은 아닙니다. `tools/extract_evidence_art.py`가 원본 함수를 그대로 추출하고 출처 해시를 저장합니다.

`check.cjs`는 클릭 표시, 증거 이미지 로딩, 드래그 오수집 방지, 전체 사건 진행 및 5종 화면 크기를 검증합니다.
