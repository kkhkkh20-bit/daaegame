# UI 재구성 · 2026-10-06

공식 Steam 상점 API가 제공하는 스크린샷을 다운로드해 실제 화면을 확인했습니다. 아래 작품은 가로 화면 레퍼런스입니다. 세로 모바일용이라고 오인하지 않으며, 구분·대비·화자 표시 원칙만 이 게임의 세로 레이아웃에 적용했습니다.

- [역전재판 123](https://store.steampowered.com/app/787480/): 장면 위에 놓는 일정한 대화 영역, 별도 이름표, 명확한 다음 조작 표시. 파란색이나 원작 프레임을 복제하지 않고 화면 정보의 위계를 참고했습니다.
- [Tangle Tower](https://store.steampowered.com/app/359510/): 배경과 인물 중심의 조사 장면, 윤곽이 분명한 창과 소수의 기능 버튼. 문양을 늘리기보다 조작부의 경계를 분명히 했습니다.
- [Murder by Numbers](https://store.steampowered.com/app/1140290/): 화자 탭과 본문 분리, 소수 포인트색, 강한 글자 대비. 해당 작품의 밝은 청록색을 가져오지 않고 다람의 리본에서 붉은색을 정했습니다.

## 적용

1. 풀폭 베이지 바텀시트를 작은 사건 수첩 창으로 교체. 외곽과 제목띠를 구분하고 배경 장면을 가장자리에 남깁니다.
2. 제목은 원작에 포함된 Galmuri11 픽셀 글꼴, 본문은 모바일에서 읽기 쉬운 고딕으로 구분합니다.
3. 증거 본문은 흰 서류, 검사는 붉은 조작 버튼, 검사가 끝난 기록은 초록 표시로 구분합니다. 문서에 없는 사실을 도장이나 장식으로 덧붙이지 않습니다. ‘보관 자료’는 수첩 UI 표시입니다.
4. 다람의 장난스러운 메모는 기존 캐릭터 아틀라스를 이용한 작은 초상과 별도 메모지로 구분합니다.
5. 대화창·이름표·수첩 탭·하단 도구를 같은 리본색과 잉크 테두리로 통일합니다. 현장 돋보기는 표시하지 않습니다.
6. 단서를 숨기거나 판정을 바꾸지 않습니다. 그림 배경/배우 아트는 이번 UI 수정에서 재생성하지 않았습니다.

`style.css`는 반응형 배치와 기능을, `ui.css`는 이번 화면 테마를 담당합니다. 생성 이미지에 UI를 합성하지 않았습니다. 새로운 원작 스크린샷이나 타 게임의 자산을 게임에 포함하지 않았습니다.

폰트: 기존 game.html에서 Galmuri11 WOFF2를 그대로 추출. [Galmuri](https://github.com/quiple/galmuri)의 SIL OFL 1.1 사본은 `assets/Galmuri-OFL.txt`에 포함합니다.

검증: 1장 전체 진행, 다섯 크기 화면, 작은 화면의 까로 얼굴 가림 수정, 증거 검사·결합·공방, 수첩 스크롤과 터치 로딩 복구. 실제 Safari 실기 검증은 아닙니다.

## 사용자 첨부 레퍼런스 반영 · 최신 수정

앞선 붉은 각진 창보다 사용자가 새로 첨부한 모바일 게임의 밝은 정보창을 우선합니다. 앞쪽 예시들의 아이보리 패널, 둥근 조작부, 중앙 제목, 원형 닫기, 부드러운 청록색을 일관된 방향으로 적용했습니다. 뒤쪽 예시의 네온색·랭킹·재화 바는 추리게임 흐름에 필요한 요소가 아니므로 추가하지 않습니다.

- 대사창: 밝은 바탕과 읽기 쉬운 어두운 글씨, 위로 걸친 화자 표찰, 우측 아래 ‘다음’ 표시. 생각은 파란색 괄호 대사 유지.
- 질문 선택: 번호·질문·재청취 상태를 나눈 둥근 카드. 작은 화면에서는 얼굴을 가리지 않도록 목록만 내부 스크롤.
- 수첩/증거/설정: 중앙 제목, 원형 닫기, 밝은 패널, 청록색 주요 버튼. 글꼴은 본문과 조작부 모두 모바일 고딕으로 맞춤. 원작 픽셀 글꼴은 이 테마에서 강제하지 않음.
- 까로 원본은 허벅지에서 끝나는 반신 이미지. 다리를 새로 생성한 것이 아니라, 세로 화면의 이미지 하단을 대사창 안쪽에 배치해 절단면이 밖으로 뜨지 않도록 수정. 작은 화면과 일반 화면에서 얼굴과 이미지 하단의 위치를 각각 검증.
- 새로운 과금·재화·랭킹 기능이나 상시 조사 돋보기는 추가하지 않음. 기존 소리·저장·증거 검사와 결합·공방 유지.

## 수첩의 증거 기록 구성

역전재판의 증거 기록에서 참고할 요소를 ‘증거 그림을 중심으로 한 선택’, ‘선택 상태의 명확한 테두리’, ‘이름과 설명을 묶은 상세 영역’, ‘증거와 인물의 탭 구분’으로 정했습니다. 세로 화면에는 상단 요약과 3열 증거 썸네일로 재구성했습니다. 게임 고유 이미지·폰트·판정은 유지합니다. 공개 스크린샷의 조사/대화 연출과 기존 원작 수첩 코드를 함께 참고했으며, 역전재판의 화면이나 자산을 그대로 복제하지 않습니다.

질문 항목은 터치 후 남는 hover 배경을 제거해 동일한 기본색으로 표시합니다. 주요 메뉴와 수첩 탭에는 이름과 함께 기능 아이콘을 붙입니다. 증거 선택 강조는 수첩 안에서만 유지합니다.
