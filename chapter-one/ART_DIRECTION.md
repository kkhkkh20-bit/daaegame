# 눈길 거처 — 따뜻한 인디 추리극

## 제작 기준

시스템 기준은 기존 다람탐정이다. 조사·증거·검사·결합·증언·반박 판정과 저장 흐름은 유지하며, 화면과 사건 데이터가 이를 표현한다. 시각 기준은 사용자가 제공한 동물 탐정단 4화면 보드와 `assets/concept/v2`의 대화·조사·증거 시안이다. 시안 이미지를 통째로 게임 화면으로 사용하지 않는다.

다람은 11살 여자 다람쥐다. 예쁜 원본 일러스트의 의상, 주황색 털과 꼬리, 갈색 눈, 도토리 장식, 버건디 리본을 유지한다. 장난스러움과 성급함이 있고 두려움을 숨기기도 한다. 어린이를 아기처럼 표현하지 않고, 성인 체형이나 연애 강조로 매력을 만들지 않는다. 대표 아트는 기존 원본을 보존하고 인게임은 픽셀 스타일 atlas를 사용한다. 까로는 부리·깃털·날개 모양 손, 뭉치는 가시·둥근 귀·주둥이로 종을 구별한다. 다온은 시점 인물로 유지한다.

## 이번 적용

- 다람 6표정, 까로·뭉치 각 3표정의 픽셀 재해석 아트. 원본 atlas는 보존.
- 증거 8종과 도토리 배지 1종을 포함한 픽셀 아이콘 atlas. 목록에는 도형 대신 아이콘, 상세에는 현장 이미지 유지.
- 남색 외곽 / 크림색 정보창 / 금색 선택 / 버건디 화자 / 브라운 선. 현재 기능에 없는 숫자나 기능은 시안에서 가져오지 않음.
- 대사 본문은 일반 도트 글꼴, 이름·증거 제목만 굵은 글꼴. 비활성 메뉴와 힌트까지 금색으로 강조하지 않음.
- 조사 선택은 자동으로 설명창을 열지 않음. 대상 테두리·이름·체크와 하단 발견 카드가 남고, 사용자가 자세히 보기를 선택. 상세를 닫아도 표시 유지. 다른 대상 선택/장소 모드 전환 때 정리.
- 조사에는 대형 인물을 배치하지 않음. 큰 인물은 대화·증언에서 사용. 현재 조사 대상은 물건이며 NPC 현장 배치는 아직 추가하지 않음.
- 반박 수첩은 대상 인물·정확한 증언 문장 → 선택 증거 → 명시적 확인/제시 흐름. 오답과 검사 조건은 원작 판정 유지.

## 원작 1스테이지 비교 플레이

`game.html`의 현재 첫 사건 `returnenvelope`에서 실제 UI로 단서 6개를 수집하고 질문, 결합, 제시, 3라운드 공방, 수동 결론과 결말을 완료했다. 개발용 훅은 장소 이동·애니메이션 종료·검증용으로만 사용했다. 저장 다시 읽기와 클래식판 15사건 분리도 확인했다. 실제 모바일 Safari가 아닌 Chromium 검사다.

이 비교에서 반영한 것은 발견 후 확인 단계, 선택을 보존하는 수첩, 증언과 증거를 함께 읽는 화면, 명확한 제시 확인이다. 새 사건의 단서 수와 공방 수는 현재 시나리오 기준으로 남겼다. 원작 전체 15사건, 인물 현장 배치와 후반 특수 도구를 모두 이식했다고 간주하지 않는다.

## 에셋·구현

`art-provenance.json`: 생성 출처. `art.js`: 픽셀 이미지 준비와 실패 시 원본 fallback. `portraits.js`: 새 atlas의 눈높이/얼굴 폭 맞춤. `indie.css`: 현재 시각 기준. 배경은 이번에 원본 일러스트를 유지했다. 픽셀 이미지를 정밀한 수작업 픽셀 아트라고 주장하지 않는다.

## 검증

`check-indie.cjs`: 터치 선택 표시와 카드 유지, 상세 닫기/재선택, 조사 인물 숨김, 픽셀 아이콘·캐릭터, 증언 비교, 픽셀 로딩 실패 fallback.
기존 `check.cjs`, `check-portraits.cjs`, `check-mobile.cjs`로 전체 사건·5종 화면 크기·캐릭터 비율·모바일 로딩 복구를 확인한다.

## v16 접수대와 타이틀
기존 배경 유지 방침을 갱신: 접수대도 `reception-pixel.png`로 교체한다. 일러스트 원본은 홍보용 기준 자료로 보존하고, 타이틀과 실제 조사 화면은 픽셀 배경을 공유한다.
