# 장소 기반 조사와 UI 정리

## 참고 자료 확인

사용자 설명의 01 산장 대화 / 02 소품실 조사 / 03 모순 반박 역할을 설계 기준으로 반영했다. 실제 이미지로 확인한 것은 기존 첨부 레퍼런스와 `assets/concept/v2`다. 작업 시점의 로컬 파일과 원격 main에는 `assets/concept/v3` 및 지정된 세 파일 이름이 없었다. 별도 위치를 사용자에게 요청했으며, 미확인 이미지를 직접 분석했다고 주장하지 않는다. 연극단 사건을 임의로 추가하지 않고 현재 산장 사건의 기능에 맞춰 구조를 적용했다.

## 진단과 수정

| 기존 문제 | 적용 |
| --- | --- |
| 화면 가로 이동값이 장소 번호도 바꿈 | room과 roomPans를 분리, 좌우 이동은 방 안 탐색만 수행 |
| 장소 메뉴가 같은 사진의 일부로 이동 | 접수대/휴게실/관리실/문서 보관실의 독립 이미지·조사 대상·메모 |
| 증거 선택 때 모달 전체 교체 | veil/sheet 노드를 유지하고 내용만 갱신, 재등장 애니메이션 제거 |
| 발견 효과가 숨겨져 선택 반응이 약함 | 대상 테두리·체크·이름과 발견 카드 유지, 클릭 부위에만 윤곽 효과, 재선택 소리 |
| 현장에 목표와 조사 상태 없음 | 현재 목표, 현재 방 조사 수, 장소별 조사 수와 잠금 상태 |
| 증언의 의심 지점을 기억하기 어려움 | 플레이어가 문장별 표시/해제, 자동 정답 강조 없음 |
| 단서 외 공간이 무반응 | 창밖/벽난로/업무 책상에 현장 관찰과 다람 메모 |

## 파일과 공통 구성

- `locations.js`: 방별 배경·물건 좌표·관찰 좌표·대화 가능한 인물.
- `case-data.js`: 원작 스키마의 장소별 증거 배치와 기존 잠금 조건.
- `game.js`: 방 이동, 방별 가로 위치 저장, 진행 목표, 현장 관찰, 창 노드 유지, 문장 표시.
- `indie.css`: 공통 색상/버튼/대화·증거창 기준.
- `casebook.css`: 장소 카드/목표/관찰/문장 표시. UI는 실제 HTML 버튼과 텍스트로 구성.
- `assets/room-lounge.png`, `room-office.png`, `room-archive.png`: 새 픽셀 스타일 배경. 기존 접수대와 캐릭터 유지.
- `tools/evidence-art-adapter.js`: 바뀐 발견 장소의 실제 물건 이미지와 상세 연결.

남색 `#20273d`, 크림 `#faf2df`, 골드 `#e8bd5c`, 버건디 `#824339`, 브론즈 `#b99661`을 유지한다. 도트 제목/일반 도트 본문 구분. 주요 인물은 방별 ‘이야기 듣기’로 연결하며 조사 배경을 가리는 대형 캐릭터는 쓰지 않는다.

## 저장과 플레이 보존

기존 저장은 원래 장소 번호를 새 방으로 보정한다. 원작 발견/검사/결합/추궁/제시/오답/힌트/저장/최종 추리 규칙은 유지했다. 두 번째 공방 뒤 문서 보관실이 열린다. 기존 시나리오가 회수한 봉투와 두 문서는 자동 기록 동작을 유지하며 새 보관실에서 다시 조사할 수 있다. 새 이미지 로딩 실패 시 조사 입력을 막고 재시도 버튼을 표시한다.

## 검증

`check.cjs`: 여러 장소를 실제로 이동해 증거 수집 후 전체 사건 완료, 기존 공방·오답·검사·결합, 5종 화면 크기.
`check-rooms.cjs`: 다른 배경/대상, 보관실 잠금, 방 안 가로 탐색과 방 이동 분리, 선택 유지, 모달 노드 재사용, 관찰, 저장 복원. 390×844 / 360×640 터치 에뮬레이션.
`check-indie.cjs`, `check-core.cjs`, `check-mobile.cjs`: 기존 흐름/아트 fallback/판정/로딩 복구.
실제 iPhone Safari 기기 검증을 대신한다고 주장하지 않는다.
