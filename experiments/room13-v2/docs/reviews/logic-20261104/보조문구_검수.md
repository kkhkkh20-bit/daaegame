## 조사 목표·제출 화면 안내

| 문구·장치 | 검토 |
|---|---|
| 돌목 씨에게 우리 방문 신청 기록을 확인받자. | 초기 목적과 일치한다. 누구에게 왜 말하는지 알 수 있다. |
| 서류의 날짜·이름·방문 목적과 초소 규칙을 직접 확인하자. | 원본·명단의 정체를 확인하는 목표다. 규칙은 실제 필수 자료가 아니므로 모든 항목을 반드시 모아야 한다는 뜻으로 읽힐 여지가 있다(L02). |
| 다람의 이름까지 등록하고 함께 들어갈 근거를 고른다 | 해결 목표는 맞지만 무엇이 수정 전 기록이고 무엇이 원래 신청인지 구분하는 질문이 앞에 필요하다(L01·L16). |
| 고른 근거가 맞으면 「근거 제시」. | 복수 선택의 체크와 고른 자료 수는 있지만, 개별 제시와 함께 제출의 차이를 직접 설명하지 않는다(L16). |
| 맞는 근거는 남겨 두었다. / 맞지 않는다. | 부분 정답을 남기는 실행과 일치한다. 이 알림 뒤 충분한 증거가 있는데 더 찾으라는 속말이 나오면 서로 다른 지시가 된다(L02). |
| 두 편지를 나란히 본다 / 두 장을 골라 견준다 | 두 장 선택이라는 조작은 명확하다. 대상은 초대 편지와 방의 메모로 이름을 맞춘다(L07). |
| 나란히 놓기 / 견주어 본다 | 두 장이 맞으면 관찰을 건너뛰고 견주어 본다로 성공할 수 있다. 관찰·엄마 습관을 알기 전에 성공하는 과제와 설명의 순서가 어긋난다(L09). |
| 자료 %d개 · 4개씩 쪽 넘김 | 세 개 제한이 아니다. 소지 E01·E02·E03 세 개 상태는 정상적으로 도달한다. E04 규칙을 별도로 읽으면 네 개가 된다. |
| 함께 볼 자료 / 보여 준다 / 근거 제시 | 수첩 열람·상대에게 한 장 보여 주기·회의에 여러 장 제출이 서로 다른 동작이다. 첫 진입 때 이 차이를 한 번 설명하면 돌목이 같은 자료를 거절하는 이유를 이해하기 쉽다(L16). |
| 출처 펼치기 | 별도 원본 문구를 읽는 동작이다. 펼친 원문에 없는 날짜·수신인 이름을 관찰 답변으로 추가해서는 안 된다(L08). |
| 목적지 잠금 안내와 이동 목표 서식 | 현재 갈 수 있는 목적지를 표시하는 기능이다. 초롱이 내일 광장에 있다는 대화 후 1일차에 광장 이동이 막힌 것은 진행 오류가 아니다. |
| 물건 이름 + 어떻게 할까? | 한 물건에 여러 진행 행동이 붙을 때 생성되는 선택 안내다. 줄거리 지식을 더하지 않는다. |

## 판정하지 않은 것

실제 신규 플레이어의 정답률·소요 시간, 현재 기기의 글자 가독성, 음향·프레임 속도, 2일차 이후 사건, 실제 공개 서버의 응답 상태는 이번 의미 검수의 검증 범위가 아니다. 새 자료·진상·정답 조건을 제안 없이 추가하지 않았다.
