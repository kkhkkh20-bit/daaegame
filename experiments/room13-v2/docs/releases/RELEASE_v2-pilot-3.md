# v2-pilot-3 · 캐릭터 중복과 다람 원본 복구

2026-11-04. 소유자가 보고한 중복 표시와 다람 근접 그림의 품질 저하를 재현하고 수정했다.

- 대화·자료 제시 뒤 질문 화면에 큰 캐릭터가 남던 것을 정리했다. 이전 판의 중복 상태로 저장한 화면도 불러올 때 정리한다. 후속 대화의 인물은 정상 재표시된다.
- 기존 본편에서 이미 사용하던 다람 승인 원본 여섯 표정의 연결을 복구했다. 원본 파일과 본편의 크기 대응표를 그대로 사용한다.
- 대사·정답·판정은 변경하지 않았다. v2는 1일 검토용으로 두고 다음 날짜 확장은 보류한다.

단위시험 27개, 화면시험 11개와 웹의 두 중복 경로·저장 복원·후속 대화를 확인했다. PC와 모바일 가로 크기의 실제 화면, 수정 전후 비교와 검증 범위는 [캐릭터 표시 검수](../reviews/visual-20261104/검수.md)에 있다. 실제 휴대폰과 공개 주소의 직접 접속은 작업 환경에서 확인하지 못했다.
