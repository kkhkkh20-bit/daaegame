# v2-pilot-2 · 1일 시범 안정화

2026-11-04. 소유자가 1일 시범을 먼저 안정화하고 다음 날짜를 옮기는 순서에 동의했다.

## 고친 것

- 메인화면의 「이어하기」가 실제 저장 파일을 찾지 못했다. 가장 최근 저장의 전체 슬롯 이름에 페이지 이름을 다시 붙이던 것을 고쳤다. 다른 쪽에 저장한 경우도 그대로 이어진다.
- 대사 도중 글자 크기를 바꾸면 다음 쪽에서 문장 일부가 빠질 수 있었다. 한 원문 줄의 쪽 구성과 본문 크기를 저장에 함께 보관한다. 새 크기는 다음 원문 줄부터 적용하며, 설정과 다른 화면은 즉시 반영된다. 이 정보가 없는 이전 저장은 현재 원문 줄의 첫 쪽부터 다시 보여 누락을 막는다.
- 회의에서 자료를 골라 저장하면 불러올 때 선택만 지워졌다. 저장 파일에는 선택이 있었지만, 화면이 끝나기 전 변경이라 불러오기 때 되감겼다. 선택·해제 직후 보존 표시를 남겨 고른 자료를 그대로 불러온다.

대사 원문, 정답·결과 판정, 이야기 데이터와 UI 배치는 바꾸지 않았다. 기존 본편 0.20.89의 실행 코드와 공개본도 바꾸지 않았다.

## 확인

- 단위시험 26개 통과. 글자 크기 양방향 변경, 쪽 구성의 저장 복원, 이전 저장, 다음 줄의 새 크기 적용 등 회귀시험 8개를 포함한다.
- Ren'Py 8.5.3 lint 통과.
- 화면시험 7개 통과: 시작, 건너뛰기, 다른 쪽 저장의 이어하기, 회의 선택 저장·복원 후 제출, 1일 정답 길, 일부 정답 후 재시도, 우회 길.
- Chromium 웹: 새 게임부터 입구 회의, 여관, 13호실, 편지 대조, 1일 밤을 거쳐 시범 종료까지 실제 입력으로 완주했다. 현장·회의 도중 저장 후 브라우저 새로고침과 이어하기를 확인했다. 편지 대조와 밤은 844×390 터치로 확인했다. 자바스크립트 예외·HTTP 오류 없음.
- 웹에서 큰 글씨 대사 둘째 쪽을 저장하고 새로고침한 뒤 같은 문장·쪽·크기로 돌아왔다. 다음 원문 줄부터 작은 글씨가 적용됐다.
- 원본과 공개 묶음의 판 번호 일치, 전송 목록의 파일 크기·해시 일치, 시험 코드의 공개 묶음 제외 확인.
