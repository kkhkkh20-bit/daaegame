다람탐정 1편 · 13호 밀실 사건 / 전체 스토리 집필 패키지
집필일: 2026-10-12

상태: 신규 본편의 집필·분기 설계 데이터. 현재 Ren'Py 실행본에 연결되지 않았음.
공개 게임/기존 저장/기존 소스의 동작을 변경하지 않는다.
사용자가 요청하기 전 플레이 검사를 반복하지 않는 기존 지시를 유지한다.

읽는 순서
1. MAIN_STORY.txt — 확정 설정, 14일 본편, 경로별 결과, 엔딩, 후속편
2. CASE13_TRUTH.txt — 방 구조, 범행/증언 시간표, 증거 연쇄, 알리바이 반박
3. SCENES.txt — 본편 및 주요 분기의 실제 대사, 연출, 선택과 결과
4. narrative.json — 인물/일정/증거/행동/논점/엔딩의 구조화된 집필 데이터
5. IMPLEMENTATION.txt — 기존 게임과의 차이, 상태/시간/저장/재플레이 연결 규칙

초창기 캐릭터의 외형과 인연을 활용하되, 당시 가벼운 사건의 전력은 이번 겨울 본편에 자동 이식하지 않는다.
등불지기 초롱은 할머니의 아들인 원래 관계를 유지한다. 살인 피해자는 은퇴 탐정 부엉이 할아버지이며 부리의 할아버지다.
현재 실행본의 나비=여관 주방, 부리=수리점 등 직무 변경은 해당 주민 소개에서 명시한다.
신규 본편의 인물 ID는 원작 ID를 기준으로 하고, 실행본 ID 연결표는 narrative.json에 보관한다.

이 문서의 사건 진실과 증거 관계는 집필 기준이다. 실제 화면의 크기, 이동 시간, 흔적의 가시성은 장면을 구현하면서 이 기준을 충족해야 한다.
특히 사건 방 배치와 증거 보존, 할머니의 이동 동선이 다르게 구현되면 문서의 결론을 그대로 사용할 수 없다.
현실 법의학의 정밀한 사망 시각 계산이나 혈액 DNA 분석에 기대지 않는다. 한 개의 발자국/상처/증언만으로 범인을 확정하지 않는다.
