마을과 생활 공간 구조 / 2026-10-12

이번에 실제 적용한 구조
마을 지도 → 여관 앞 → 접수대 ↔ 손님 홀 → 여관 앞 / 마을 지도.
마을의 기존 5개 외부 목적지는 유지한다. 여관 안의 공개 공간 2곳을 하위 장소로 추가했다.
접수대의 오른쪽 문을 직접 눌러 손님 홀로 갈 수도 있다. 왼쪽 문은 여관 밖으로 이어진다.
접수대와 손님 홀은 하단 공간 탭으로도 이동한다. 현재 탭은 다시 암전하지 않는다.

생활과 대화의 구분
- 할머니: 접수대 뒤에서 잔을 닦는 별도 그림. 기존 배경에서 정확히 같은 카운터
  영역을 전경으로 잘라 덮어 하반신을 가린다. 방문만으로 대사는 시작하지 않는다.
- 할머니를 누르면 기존 질문/인터뷰 그림으로 전환하고, 대화가 끝나면 일하던 자리로 돌아온다.
- 누비: 여관에 있는 시간에는 손님 홀 의자에서 이불을 꿰맨다. 대화용 그림은 별도 유지한다.
- 모모: 여관으로 오는 시간대에는 손님 홀에서 쿠키를 나눈다. 여관 앞에는 중복 배치하지 않는다.
- 주변 주민 목록에서 홀 안의 손님을 고르면 실제 홀 배경으로 이동한 뒤 대화한다.
- 손님 홀은 새 저녁 배경을 사용한다. 낮 배경을 밤 장소에 재사용하지 않는다.

데이터와 실행 책임
- village-interiors.json: 건물별 공개 공간 이름/배경/관찰 대사/실내 인물 배치.
- village_interiors.rpy: 공간 정보 조회, 기존 주민 시간표와 실내 배치 연결, 하단 이동 UI.
- arrival_inn: 선택한 공간 진입 → 사람/물건/문 선택 → 기존 대화 → 같은 공간 복귀.
- scene_present: 암전/음악/화면 정리의 공통 실행 규칙을 여관 진입에도 적용한다.
- arrival_inn_room / village_interiors_seen: 현재 내부 공간과 방문 기록. 저장/불러오기 대상.
- village-residents의 기존 시간표가 사람의 출근/이동을 결정한다. 실내 배치는 시간을 바꾸지 않는다.

시간과 사건
동일 건물 안의 짧은 이동은 시간을 소비하지 않는다. 기존 바깥 이동과 첫 질문 완료의 시간 규칙은 유지.
숙박은 기존 우체국 확인 조건을 유지한다. 객실/사건 현장/회의를 자유 탐색 공간으로 미리 열지 않는다.
주민의 진실, 증언 동의, 관계 점수, 증거 획득 조건은 기존 시스템이 맡는다.

향후 다른 건물에 적용할 방향
지도는 전체 방향을 잡는 곳, 거리 화면은 생활을 관찰하는 곳, 건물 안은 목적 있는 만남을 만드는 곳.
새 장소는 최소 하나의 생활 행동, 만날 사람 또는 관찰 가능한 물건, 돌아가는 길을 갖게 한다.
장소 수부터 늘리지 않고 같은 장소의 시간대/사건 전후 변화를 우선한다.
우체국 창구와 작업 공간, 광장의 가게 등은 다음 적용 대상이며 이번 빌드에는 아직 추가하지 않았다.
화산의 딸의 화면이나 규칙을 복제한 것이 아니라, 지도에서 장소와 활동을 고르는 방향을 참고했다.
