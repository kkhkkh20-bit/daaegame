다람탐정 Ren’Py 1장 시험판 0.6.1 (2026-10-11)

기본 플레이
익명의 범죄자 훅 → 부녀의 마차 → 마을 입구에서 바로 조작한다.
외지인을 경계하는 주민과의 만남은 선택이다. 주민 클릭 → 질문 선택 → 대화.
광장/골목/여관 앞 주민을 만나지 않아도 사건에 도달한다.
우체국 문이 닫혔음을 확인하고 여관에 들어간다. 입장 자체로 대사하지 않는다.
할머니 클릭 → '방이 있나요?' → 숙박 → 아침의 사건 → 조사/회의/최종 대결.
사진 질문은 숙박 대화에서 이어진다. 마차에서는 여행 목적을 설명하지 않는다.

원본과 변경 자료
chapter-source.json은 기존 v2 HTML의 읽기 전용 캡처다. 원본 파일을 수정하지 않는다.
chapter-dialogue.json은 회의/대결/주민 질문/후일담의 새 대본이며 초기화 때 별도로 적용한다.
증거 ID/획득/질문 조건/증거 비교/선택지/주요 사건 이벤트는 원본 계약을 유지한다.
사용자 요청으로 바뀐 도입/마을/관찰/밤이 첫 만남은 village-story.json에 별도로 작성했다.
arrival.rpy는 주민 질문과 입구/여관 동선을, source.rpy는 본 사건의 재생을 맡는다.
공개 루트와 기존 HTML/v2 및 그 원본 그림 파일은 수정하지 않는다.
prepare_assets.py는 원본 HTML 캡처의 해시가 바뀌면 빌드를 중지한다.

그림과 연출
열 명의 인터뷰 전신을 네 표정씩 제작했다. 모두 중앙에서 플레이어를 바라본다.
밤이는 거꾸로 매달린 자세를 유지한다. 이동 화면의 작은 인물과 인터뷰 전신은 별개다.
대사 왼쪽의 큰 얼굴은 기존 승인 자료의 얼굴 영역을 사용하며, 몸 전체를 축소하지 않는다.
질문창을 열 때 대화 인물을 지워 중복 표시를 막는다. 질문은 푸른 띠 형태로 표시한다.
질문 선택에서는 전신을 오른쪽에, 실제 대사에서는 중앙에 배치하여 얼굴을 가리지 않는다.
원탁 뒤의 작은 배우와 앞의 발언자가 같은 사람일 때에는 뒤 배우만 숨긴다.
원탁 대결 전면도 인터뷰 전신을 써서 구형 상반신 이미지와 구별한다.
읽은 질문은 취소선/그림 체크로 표시한다. 글꼴에 없는 체크 기호는 사용하지 않는다.
발견이나 회의 결과로 답변이 바뀌면 새 이야기로 표시하며, 읽으면 다시 완료 처리한다.
까로 마차 컷은 첫눈 전 저녁의 낙엽 마을과 같은 계절이다. 첫눈은 사건 당일 자정이다.
입구/광장/골목/우체국/여관 앞뜰을 서로 다른 야외 배경으로 제작했다.
건축 재료/원근/저녁 색감을 맞추고, 다음 날 입구는 첫눈 뒤 아침 모습으로 전환한다.
마을 지도의 미리보기는 해당 장소와 동일한 PNG를 사용한다. 별도 건물 아이콘은 쓰지 않는다.
마을 지도는 크림색 여행 지도, 여관 내부는 평면 안내도로 구분한다.
로딩과 제목 화면도 새 입구 배경을 쓴다. 지도 전환에 예전 부녀 컷이 끼어들지 않는다.
크리스털 등/잠긴 상자/침대 밑 작은 손님/여관 안내도를 별도 그림으로 제작했다.
주머니의 손 제거와 귀여운 다람쥐 앞발로 솜솜을 받치는 발견 컷도 유지한다.
새 PNG는 art/에 원본 그대로 보존하고, 게임이 실행 중 필요한 영역만 잘라 보여 준다.

조사와 UI
책상/빈 상자/창문/주변을 눌러 짧은 반응을 볼 수 있다. 확인 표시는 재방문/저장 후에도 남는다.
주머니/이불/상자/침대 밑 클릭 영역은 실제 소품 위치와 맞췄다. 노란 박스는 없다.
침대 머리판의 흐릿한 글씨는 화면에도 남긴다. 가까이 조사하면 날짜를 읽을 수 있다.
이동하기/회의로는 독립된 글자 버튼이다. 이동 지도에도 저장과 설정을 계속 쓸 수 있다.
원탁은 발언 선택/되묻기/증거 비교, 마지막 대결은 모순을 연결한다.
지도 선택 방식이며 자유 보행/온라인 마피아 구현은 아니다.
솜솜 발견 자리를 다시 누르면 짧게 관찰하고, 발견 군중 장면을 반복하지 않는다.
이미 연 상자는 자물쇠 없이 장부를 다시 본다. 확인된 솜솜 생존 정보는 증거 카드에 반영한다.
대안 증거 접근의 선행 조건과 비교 단계를 처리한다. 발언을 바꿔도 받아들인 비교를 유지한다.
비교 개수를 정답 개수처럼 표시하는 대신 현재 비교 중인 기록을 보여 준다.
HUD의 터치 범위를 확대하고 질문·대결 진입 직후 입력을 잠깐 막는다.
음량 막대와 손잡이를 표시하고 주민 수첩은 문장 높이에 맞춰 스크롤한다.
엄마의 흔적은 실제 두 기록의 필적을 비교한다. 시계 비교는 정방향과 밤이의 거꾸로 본 방향을 함께 보여 준다.

대화
상황 설명 다음에 상황 설명을 붙이는 대신, 질문에 답하고 반박하거나 말을 피하는 대화로 썼다.
회의에서는 같은 자리의 주민이 끼어들어 의심/변명/편들기를 주고받는다.
마피아게임 채팅의 빠른 반응을 참고한 말투이며 대화창을 카톡 UI로 바꾼 것은 아니다.
다람의 질문과 반응을 늘리고, 아빠는 딸을 지키거나 확인한 모순을 짚는 순간에 말한다.
조사에서 알게 된 사실을 그대로 다시 설명하지 않고, 그 사실을 두고 의견이 충돌하게 한다.
범인의 가족사 추측을 없애고, 솜솜을 옮긴 시각은 인트로의 자정과 일치시켰다.
이백 냥을 노름으로 잃은 금액은 자백 전 단정하지 않는다. 할머니의 배상 근거부터 부정한다.
발견 전후 대사/까로에게 들은 말/관계가 부족한 주민의 망설임도 같은 대화 수준으로 맞췄다.

기억·시간·관계
발견/대화 여부가 질문의 공개 조건과 다른 주민의 반응에 반영된다.
솜솜을 발견하기 전 돌보는 법 질문을 숨긴다. 까로의 이야기를 듣기 전 세련을 추궁할 수 없다.
이동과 처음 선택한 주제, 사건의 중요한 단계에서만 시간이 흐른다. 반복 대화로 신뢰를 얻지 않는다.
저녁 주민은 각자 자리를 비우며, 발견/시간 기록/추궁 후 아침의 위치도 달라진다.
증거 수첩의 주민 수첩에는 직접 만난 날짜/시각/장소가 기록된다.
관찰만으로 알 수 있는 역할을 보여 주며, 아직 듣지 않은 비밀이나 알리바이를 먼저 공개하지 않는다.
회의에서 정정한 밤이의 목격담과 세련의 증언은 재질문에서도 정정 상태를 유지한다.
사건 전 자유 탐색의 시각은 저녁 9시까지로 제한해 숙박 전 다음 날로 넘어가지 않게 한다.
사건 뒤 정오→오후→밤의 시간도 실제로 흐르며, 후일담에서 만난 시각을 수첩에 맞춰 기록한다.
외지인에 대한 경계에서 시작한다. 만남과 확인된 추리로 신뢰를 얻는다.
여섯 주민 중 네 명의 지지가 필요하다. 부족하면 각 주민의 걱정을 듣고 관련 증거로 설득한다.
타당한 여러 증거를 허용하고 엉뚱한 증거는 왜 부족한지 설명한다. 설득 실패로 진행을 막지 않는다.
사건의 진실/본 결말은 유지하며 선택적 교류에 따라 필요한 설득 수가 달라진다.
시간/관찰/신뢰는 저장에 포함된다. 다음 에피소드의 실제 분기는 아직 구현하지 않았다.
규칙/반응/공개 일과는 village-state.json, 구현은 timeline.rpy에 분리했다.

소리
마을 신규 음악 '길가에 켜진 등': 116 BPM, C 장조, 32마디 약 66초.
플루트/기타/현악/피치카토/하프/첼레스타/베이스의 밝은 애니메이션풍 자체 작곡이다.
외부 애니메이션 곡을 복제하지 않았다. FluidR3 녹음 악기 샘플의 MIT 라이선스를 동봉한다.
audio/에 MP3/악보/크레딧을 보존한다. 선택적 재생성 도구는 compose_town.py다.
여행/조사/회의/긴박한 장면/후일담의 기존 곡은 유지한다. 암전 중에 다음 음악을 먼저 시작한다.
범죄자 훅은 55~130 BPM 심박이 빨라진다. 마차 전환 전에 완전히 종료한다.
타이핑은 글자가 나오는 동안만 재생하며, 대사 완료/메뉴/중요한 정적에는 멈춘다.
연속 심박 지시는 소리를 처음부터 다시 시작하지 않는다. 대결의 정적 후에는 대결곡으로 복귀한다.
보호 장면 이후 회의가 재개되면 음악도 돌아오고, 사건 해결 뒤에는 후일담 곡으로 풀어 준다.
말발굽은 재생하지 않는다. 실제 캐릭터 더빙은 아직 없다.
출처와 승인 범위는 game/assets/provenance.json에 동봉한다.

검사/빌드
공식 Ren’Py 8.5.3 SDK 및 web/, Chromium, FontTools/Pillow를 사용한다.
python3 -m pip install -r experiments/renpy-ch1/requirements.txt
저장소 루트: python3 -m http.server 8093
python3 experiments/renpy-ch1/build_web.py --sdk /absolute/path/to/renpy-8.5.3-sdk
python3 experiments/renpy-ch1/qa_source.py --output /tmp/daram-village-qa
python3 experiments/renpy-ch1/qa_audio.py --output /tmp/daram-village-audio
python3 experiments/renpy-ch1/qa_memory.py --output /tmp/daram-village-memory
python3 experiments/renpy-ch1/qa_dialogue.py
python3 experiments/renpy-ch1/qa_logic.py
python3 experiments/renpy-ch1/qa_audio_flow.py --desktop-only --output /tmp/daram-village-audio-flow
QA는 실제 WASM 게임에서 마우스/터치로 조작한다. 상태 조회는 읽기 전용이다.
보고서의 game.zip 해시와 배포 빌드 해시가 일치하는지 확인한다.
PC는 선택 주민/돌/재방문/저장 복귀, 터치는 선택 주민 없는 경로를 진행한다.
발견 전후 질문 공개, 까로→세련의 정보 연결, 추궁 후 위치 변경, 관련 없는 증거의 설득 실패를 검사한다.
주민 수첩 열기/닫기, 아직 안 만난 주민의 비공개, 시간/기억/관계 저장, 순찰 종료 뒤 빈 입구도 확인한다.
조사/오답/회의 네 단계/투표/대결 세 단계/후일담/심박 종료까지 검사한다.
소리는 브라우저의 실제 출력 신호/음소거/타이핑을 검사한다.
추가 경로는 대안 증거→발언 교대→저장 복원→회의 휴정→정정 증인 재방문을 실제 조작한다.
빈 발견 자리/열린 상자 재방문, 생존 카드 갱신, 배우 중복과 얼굴 위치, 음량 막대, 수첩 스크롤도 검사한다.
필적 비교의 두 기록과 시계 비교의 회전 방향이 실제 화면에 표시되는지도 검사한다.
실제 iPhone/Safari 기기나 사람이 곡을 청취해 평가한 검사는 아니다.
웹 배포 약 130 MiB, 그중 game.zip 약 91 MiB. 처음 내려받은 뒤 장면마다 추가 다운로드하지 않는다.

저장
저장 경로 daaegame-renpy-village-ch1-06은 0.6.0과 동일하다. 이전 0.1~0.5와 HTML 저장은 호환되지 않는다.
이 버전은 처음부터 시작한다. 같은 브라우저/사이트의 IndexedDB에 저장한다.
사이트 데이터 삭제 시 저장도 사라진다. 저장 가져오기/내보내기를 지원한다.
