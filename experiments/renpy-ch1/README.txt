다람탐정 — 원본 1장 Ren’Py 이식 비교판 0.3
=========================================

목적
이전 0.2는 기능 확인을 위해 별도 각색한 시험판이었다. 사용자 피드백대로 이를
기존 1장을 옮긴 버전으로 취급하지 않는다. 0.3의 기본 시작은 기존 v2의 대사와
장면 순서를 직접 재생한다. 대본을 새로 쓰거나 짧게 바꾸지 않는다.
공개 원본·v2·승인 이미지/음악 원본은 그대로 유지한다.

주소
https://kkhkkh20-bit.github.io/daaegame/preview/renpy-ch1-test/

이식한 내용
- 원본 도입 P1/P2/P3/P5/P10/P10b/P11/P12/P13의 대사와 명시적인 연출 큐.
- 마차 부녀 → 마을 접근 → 마부 → 닫힌 우체국 → 여관 → 밤 동행 → 도난 수색.
- 조사 질문, 증거 관찰, 열세 번째 침대/장부 자물쇠, 솜솜 발견과 주민 소집.
- 생사 확인·이불·목격 시각·부녀에게 향한 의심의 네 원탁 라운드.
- 투표, 털 자국·주머니 이동·이백 냥의 세 최종 대결 라운드와 원본 후일담.
- 증거 비교·되묻기·관련 증거 반응·생사 판단 선택·부족한 증거를 위한 휴회.
- 기존 발견 조건 C01/C02/C03/C09/C12. 첫 방 한 번 클릭으로 발견하지 않는다.

원문 관리
capture_source.py는 로컬로 서비스한 기존 play_v2.html의 EP1INN와 음악 정의를
읽기만 한다. 결과는 game/chapter-source.json. 출처 HTML의 SHA256도 기록한다.
prepare_assets.py는 출처 해시가 달라지면 빌드를 중지한다.
source.rpy는 이 데이터의 대사를 재생한다. 원본 무대 지문은 기존 DIR 분류대로
처리하며 말 대사는 원문을 유지한다. 기존 0.2 story.rpy의 각색은 기본 시작에서
호출하지 않는다. 게임으로 보여 주지 않는 비교 기록으로 남아 있다.

화면과 소리
승인된 기존 PNG/MP3를 바이트 그대로 복사하며 provenance.json에 해시를 기록한다.
중복 자산은 재사용한다. 인물 현장 전신과 대화 그림은 기존 atlas의 별도 영역을
실행 중 Crop한다. 마차/마부/마을/닫힌 우체국/여관/봉인/솜솜 컷을 연결한다.
밤의 부녀와 거꾸로 매달린 밤이는 명시적인 night 큐에 따라 나타나고 사라진다.
명시적인 음악 큐는 암전 중 시작한다. 원본 음악의 장면별 정의를 사용한다.
문 여닫기는 기존 CC BY 3.0 녹음. 타이핑음도 이전에 명시한 녹음 파생 파일이다.
노크·발소리·종 열 번·심박·자물쇠·증거/추궁 효과를 원래 위치에 연결한다.
source_sounds.py의 PCM은 기존 inn_audio.js의 합성음 종류와 레시피를 참고해
오프라인으로 재구성한 근사 효과음이다. 원래 WebAudio 출력과 바이트 동일한
녹음이라고 주장하지 않는다. 말발굽과 마차 드럼롤은 사용자 지시대로 사용하지 않는다.
배경음·타이핑·심박은 별도 채널이며 중요한 정적에는 타이핑도 멈춘다.
메뉴에서는 심박을 일시 정지한다. 발견/밤의 심박이 다음 장소로 남지 않게 종료한다.
실제 캐릭터 더빙은 없다. 기존 음악을 새 고급 음악으로 제작했다는 뜻도 아니다.
라이선스/출처는 game.zip에 동봉한다.

비교판의 경계
장소 이동은 지도 선택 방식이다. 직접 캐릭터를 조종하는 자유 보행은 아니다.
원탁은 고정된 사건의 주장과 증거를 다루며 온라인 랜덤 마피아는 아니다.
Ren’Py 화면 배치는 자체 구현이다. 기존 HTML UI/모든 동작을 픽셀 단위로
복제한 것이 아니다. 원문 데이터는 가져왔지만 모든 장식 애니메이션을 옮겼다고
주장하지 않는다. 실패 HP/원본 실패 엔딩 대신 오답을 재시도할 수 있다.
스토리의 논리/매력 개선은 원본 이식과 별도 작업이다. 이번에 임의로 재작성하지 않는다.

조작
가로 화면을 권장한다. 대사를 누르면 글자가 완성되고 다시 누르면 다음 줄이다.
이동 아이콘으로 일곱 장소를 선택한다. 배경 조사 위치에 노란 박스는 없다.
주민을 누르고 질문을 고른다. 원탁에서는 발언 선택 → 되묻기 → 증거 비교.
원문에 있는 단계별 증거 연결을 사용한다. 관련 증거의 soft 경로도 처리한다.

빌드/검사
Ren’Py 공식 8.5.3 SDK와 같은 버전의 web/, ffmpeg, chromium이 필요하다.
python3 -m pip install -r experiments/renpy-ch1/requirements.txt
저장소 루트에서 python3 -m http.server 8093
원본 데이터 갱신: python3 experiments/renpy-ch1/capture_source.py
python3 experiments/renpy-ch1/build_web.py --sdk /absolute/path/to/renpy-8.5.3-sdk
python3 experiments/renpy-ch1/qa_source.py --output /tmp/daram-source-qa
python3 experiments/renpy-ch1/qa_audio.py --output /tmp/daram-audio-qa
qa_source는 실제 WASM에서 마우스/터치 입력으로 플레이한다. renpy_exec는
상태 조회에만 쓴다. 도입 말 대사의 순서와 문장, 모든 실행한 말 대사의 원문 포함,
효과음 큐, 발견/회의/대결/엔딩 및 저장 복귀를 검사한다.
qa_web.py의 기존 0.2 경로는 이전 각색의 기록이며 현재판 검사는 qa_source.py다.
마지막 CG 전환만 점검하려면 --discovery-only와 --desktop-only 또는 --mobile-only를
사용한다. 전체 경로 검사 뒤 CG 진입 암전만 수정했고, 마지막 배포 파일의
도입→발견/CG는 두 화면에서 별도로 검사한다. 해시는 QA_REPORT.json에 구분한다.
현재 웹 배포 합계는 약 98.1 MiB(103 MB)다. 처음 받는 패키지가 크다.
자산은 처음 받으므로 장면마다 추가 다운로드하지 않는다.
실제 iPhone/Safari나 사람의 청취 평가를 했다고 주장하지 않는다.

저장
새 저장 경로 daaegame-renpy-source-ch1-20261011을 사용한다. 0.1/0.2 및 HTML/v2
저장은 호환되지 않는다. 같은 브라우저/사이트의 IndexedDB에 유지된다.
