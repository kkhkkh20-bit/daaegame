다람탐정 — Ren’Py 마을 탐색 시험판 0.4
=======================================

주소
https://kkhkkh20-bit.github.io/daaegame/preview/renpy-ch1-test/

이번 변경
사용자 요청에 따라 Ren’Py를 계속 사용한다. 새 프롤로그는 이미 여행을 약속한
부녀의 친근한 마차 대화다. 마차에서 엄마/탐정/편지의 사정을 설명하지 않는다.
도착하면 먼저 마을 지도에서 장소를 고른다. 마을 입구, 광장, 골목, 우체국,
여관 앞뜰을 방문할 수 있다. 너울·부리·밤이·세련과의 만남과 돌 관찰은 선택이다.
아무도 만나지 않고 사건으로 가도 된다. 재방문 대사와 만남 이력은 저장된다.
밤이의 사건 전 강제 만남은 제거했다. 먼저 만난 세련·너울은 다음 날 다시
자기소개하지 않는다. 조사 중에도 먼저 만난 주민은 짧게 이전 일을 기억한다. 밤이의 첫 질문은
낮에 만난 경우/처음 만난 경우를 나누며, 삭제한 밤 만남을 언급하지 않는다.

우체국의 닫힌 출입문을 직접 확인하고, 다음 날 개장 시간을 읽은 뒤 여관에
묵는다. 여관부터 찾아가도 주민을 만날 수 있고, 방을 잡기 전에 우체국으로
돌아간다. 숙박→다음 날 도난 신고→조사로 이어진다. 사건이 아직 발생하지 않은
마을 탐색에서 사건 증거를 획득하거나 회의를 시작할 수는 없다.
외지인을 경계하는 주민의 태도는 통행 제한, 공동 물건의 도난 기억, 자기 일에
대한 경계로 드러난다. 유일하게 따뜻하게 맞는 할머니는 엄마 사진에서 말을 피한다.
돌은 빛을 담아 등으로 쓰는 생활 도구다. 선택해서 실제 빛 변화를 볼 수 있다.
이번 사건의 증거/정답에 새 판타지 규칙을 추가하지 않는다.

보존한 사건
원본 v2의 열세 번째 침대, 돈/봉인, 늦은 솜솜 발견, 장부 자물쇠, 조사 질문,
네 원탁 라운드, 투표와 세 최종 대결, 후일담은 같은 데이터로 이어진다.
도난 수색 P11~P13은 앞선 만남과 참여 동기에 필요한 줄만 별도 각색했다.
전체 사건의 대사/논리를 새로 쓴 판은 아니다.

데이터 관리
- game/chapter-source.json: 기존 v2를 읽기만 해서 캡처한 기준 자료. 그대로 보존.
- game/village-story.json: 새 프롤로그/마을/숙박 대사와 첫인사 연속성.
- game/arrival.rpy: 선택 탐색, 재방문, 저장 가능한 만남, 숙박으로의 연결.
- game/source.rpy: 공통 조사/회의/대결 재생기.
- game/story.rpy: 이전 0.2 각색 기록. 기본 시작에서는 호출하지 않는다.
prepare_assets.py는 원본 HTML의 캡처 해시가 바뀌면 빌드를 중지한다.
0.4의 도입은 기존 v2 대사의 정확한 복제가 아니라 사용자 요청의 새 구성이다.
공개 루트와 기존 HTML/v2 파일은 수정하지 않는다.

그림과 소리
명시 요청한 두 그림만 experiments/renpy-ch1/art/에 별도 생성했다.
pouch-no-hand.png는 돈 주머니에서 손을 제거한 증거 컷이다.
somsom-gentle.png는 작은 겨울잠쥐를 귀여운 다람쥐 앞발로 받치는 컷이다.
사람 손/손톱과 상처처럼 보이는 붉은 얼룩은 피했다. 희미한 도장 흔적을 남겼다.
원본 그림 파일은 그대로다. 털 증거는 새 솜솜 그림의 회색 털 확대와 승인된 정확한 도장
오버레이를 함께 사용한다. 발견 CG와 배경의 희미한 솜솜은 서로 다른 자산이다.
검은 화면에서 이전 인물을 지우고 발견 CG를 열어 잔상을 막는다.

기존 승인 음악을 장면별로 사용하며, 암전에서 음악을 먼저 재생한다.
마차는 밝은 부녀 음악, 마을은 만남 음악, 경계/사진은 심각한 음악이다.
노크·문·종·발견·심박·자물쇠·추궁 효과도 이어진다. 말발굽은 재생하지 않는다.
타이핑음은 새로 합성한 짧고 부드러운 네 가지 탭을 반복한다. 외부 샘플은 없다.
문 녹음은 기존 CC BY 3.0이며 크레딧을 동봉한다.
타이핑은 글자가 나오는 동안만 재생하고, 완료/메뉴/중요한 정적에는 멈춘다.
배경음·타이핑·심박은 별도 채널이다. 실제 캐릭터 더빙이나 새 BGM 제작은 없다.
provenance.json에 원본/두 수정 그림/합성 효과음의 출처를 구분한다.

조작과 범위
가로 화면 권장. 대사 첫 클릭은 글자 완성, 다음 클릭은 다음 줄이다.
마을 건물로 이동하고 주민을 눌러 대화한다. 광장의 작은 등은 선택적으로 조사.
여관 앞뜰의 '방을 묻는다'로 숙박한다. 사건 이후에는 이동 아이콘으로 일곱
조사 장소를 선택하고 증거를 수집한다. 노란 조사 박스는 없다.
원탁은 발언 선택→되묻기→증거 비교, 최종 대결은 모순을 연결한다.
지도 선택 이동이며 직접 캐릭터를 조종하는 자유 보행/온라인 마피아는 아니다.
Ren’Py의 자체 UI이므로 기존 HTML 화면을 픽셀 단위로 복제하지 않는다.
원본 실패 HP/실패 엔딩 대신 오답 재시도를 허용한다.

빌드와 실제 실행 검사
공식 Ren’Py 8.5.3 SDK와 같은 버전 web/, chromium, FontTools가 필요하다.
python3 -m pip install -r experiments/renpy-ch1/requirements.txt
저장소 루트: python3 -m http.server 8093
python3 experiments/renpy-ch1/build_web.py --sdk /absolute/path/to/renpy-8.5.3-sdk
python3 experiments/renpy-ch1/qa_source.py --output /tmp/daram-village-qa
python3 experiments/renpy-ch1/qa_audio.py --output /tmp/daram-village-audio
qa_source는 실제 WASM에서 마우스/터치로 플레이한다. 상태 조회는 읽기 전용이다.
PC는 모든 선택 만남/돌/재방문/마을 저장 복귀, 터치는 선택 만남 없는 경로를
진행한다. 조사→회의→대결→후일담과 증거/저장/오답/발견 CG도 검사한다.
qa_audio는 배경음 음소거와 복귀, 메뉴 종료, BGM 없이 타이핑 실출력을 검사한다.
전체 완주 뒤 마을 배경/회색 털 그림/밤이 첫 만남 대사를 정리했다. 최종 파일은
두 화면에서 도입→발견→밤이 질문과 소리를 다시 검사한다. 전체 완주 파일과
최종 변경부 검사 파일의 해시는 QA_REPORT.json에 구분한다.
소리 검사는 AUDIO_QA_REPORT.json에도 기록한다.
실제 iPhone/Safari 검사나 사람이 소리를 듣고 평가한 결과는 아니다.
웹 실행 패키지는 약 100 MiB. 처음 내려받은 뒤 장면마다 추가 다운로드하지 않는다.
