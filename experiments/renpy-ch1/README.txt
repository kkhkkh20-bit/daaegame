다람탐정 — 작은 1장 Ren'Py 웹 시험판 0.2
=======================================

목적과 범위
기존 1장 「열세 번째 침대」를 압축해, 마을 이동·조사·원탁 회의·대결·후일담까지
실제로 연결한다. 기존 공개 게임, v2 및 승인 원본 이미지는 변경하지 않는다.
원본 대본의 전면 이식이나 최종 확정 시나리오가 아니라 엔진/플레이 경험 검증용
별도 각색이다. 약 20분 안팎이며 모든 원본 대화와 방을 옮긴 것은 아니다.

주소
https://kkhkkh20-bit.github.io/daaegame/preview/renpy-ch1-test/

플레이 흐름
1. 부녀의 마차 대화 → 닫힌 우체국 → 여관. 아내의 옛 편지 도장을 따라온 이유.
2. 지도에서 접수대·부엌·입구 선택. 주민을 누르거나 말풍선으로 대화.
3. 밤 복도의 거꾸로 매달린 밤이 → 아침의 도난 신고와 할머니에 대한 압박.
4. 여섯 장소를 오가며 조사. 표식 없는 배경 물건, 주민의 목격담, 날짜 자물쇠.
5. 작은 손님의 장부와 등잔을 확보한 뒤 침대 아래 재조사 → 솜솜 발견.
6. 여덟 주민을 선택하는 원탁. 먼저 생사 확인, 시계의 시선 반전, 두 자국 비교.
7. 마지막 반격: 알려지지 않은 발견 위치 → 목격 이동과 접촉 → 봉인의 의미.
8. 자백 전에 할머니에게 도난 책임을 물을 근거가 없다는 판정.
9. 사건 이후 같은 주민의 달라진 대화. 엄마의 지난겨울 방문과 다음 행선지.

조작
가로 화면을 권장한다. 대사를 누르면 글자 완성, 다시 누르면 다음 줄로 진행한다.
이동 아이콘으로 지도를 열고 장소를 고른다. 배경 조사에는 사각형 하이라이트나
단서 위치 목록이 없다. 주민 그림/말풍선으로 대화한다. 수첩에는 사실만 기록한다.
자물쇠는 네 자릿수를 각각 올리거나 내린다. 원탁에서는 주민을 선택하고 되묻기/
증거를 사용한다. 증거가 많아지면 수첩의 아이콘 카드 페이지를 넘긴다. 관련 증거를 비교할 때
서로 다른 제시 순서도 허용한다. 오답은 반응 후 재시도하며 증거를 잃지 않는다.

제작 구조
세 개의 .rpy 파일: options(저장 상태/자료), story(장면과 사건), screens(UI).
이동은 제한된 장소 선택 방식이며 캐릭터를 직접 조종하는 자유 보행은 아니다.
원탁은 각 주민의 주장에 답하는 서사형 회의이며 랜덤 역할 배정 온라인 마피아는
아니다. 투표 숫자만으로 범인을 확정하지 않는다. 무관한 증거에는 이유를 답한다.

서사 각색의 경계
솜솜의 겨울잠·할머니의 이름 없는 손님 보호·세련의 허위 신고·봉인된 백 냥과
여관 계약 압박은 기존 사건 소재다. 조사 순서, 대사, 장부 자물쇠의 연결과 짧은
후일담은 이 시험판용으로 다시 연결했다. 엄마 단서도 전체 기획 확정본이 아니다.
까로는 노름판을 본 것만 말하며 이백 냥의 정확한 손실을 증명하지 않는다.
봉인 이후 돈이 빠졌다는 주장은 증거로 반박하고, 정확한 지출은 별도 조사한다.
세련의 고백이 할머니의 도난 책임을 반박하는 빠진 증거를 대신하지 않는다.

자산과 사운드
기존 승인 PNG/MP3를 그대로 복사하고 assets/provenance.json으로 출처/해시를 기록.
현장 전신과 대화 상반신은 기존 atlas의 서로 다른 영역을 엔진 실행 중 Crop한다.
상자 투명 여백도 런타임 Crop으로 처리한다. 이미지 원본은 편집하지 않는다.
털 확대는 실제 솜솜 CG의 회색 털 영역 + 기존 붉은 자국 overlay를 엔진에서 합성.
여행·밤·조사·회의·추궁·후일담에 기존 곡을 각각 연결한다. 암전 중 곡이 선행한다.
문 효과음은 기존 CC BY 기록을 사용한다. 작은 타이핑음은 bennstir의 기존 나무 문
닫기 음원 일부에 필터/페이드/음량/간격을 적용한 CC BY 3.0 파생 파일이다.
글자 완성/넘김/메뉴에서 타이핑음을 중지한다. 발견과 마지막 침묵에는 쉬게 한다.
음악/효과음 각각 음량과 음소거를 설정할 수 있다. 말발굽은 사용하지 않는다.
credits 및 FluidR3_GM의 MIT 라이선스, Galmuri OFL을 game.zip에 동봉한다.
실제 캐릭터 더빙은 포함하지 않았다. 음성 생성 서비스 호출/녹음을 했다고 표시하지
않는다. 연출별 새 곡 제작/청취 평가까지 끝낸 제품 버전도 아니다.

빌드와 검사
Ren'Py 공식 8.5.3 SDK + 같은 버전 web/ 필요:
https://github.com/renpy/renpy/releases/tag/8.5.3.26051504
python3 -m pip install -r experiments/renpy-ch1/requirements.txt
시스템 ffmpeg 및 chromium도 필요하다.
python3 experiments/renpy-ch1/build_web.py --sdk /absolute/path/to/renpy-8.5.3-sdk
저장소 루트: python3 -m http.server 8093
python3 experiments/renpy-ch1/qa_web.py --output /tmp/daram-small-qa
python3 experiments/renpy-ch1/qa_audio.py --output /tmp/daram-audio-qa
SDK 린트 및 마우스 1280×720/터치 844×390 실제 WASM 플레이를 확인한다.
QA는 SDK의 renpy_exec로 상태를 읽기만 하며 진행이나 증거를 주입하지 않는다.
웹 배포 크기는 약 86 MiB(90 MB). 첫 다운로드가 무거운 대신 작은 시험판의
자산은 초기 패키지에 포함한다. 첫 5분 시험판의 약 60 MB보다 커졌다.
브라우저 오디오 출력 신호 검사와 실제 iPhone/Safari 청취 검사는 구분한다.
오류가 영원히 없다는 보장은 없다. 전체 에피소드 규모와 실기기 검증은 남아 있다.

저장
새 저장 경로 daaegame-renpy-small-ch1-20261011을 literal define으로 지정한다.
이전 5분 Ren'Py 시험판과 기존 HTML/v2 저장은 호환되지 않는다. 웹 저장은 같은
브라우저/사이트의 IndexedDB에 유지되며 사이트 데이터를 지우면 사라진다.
브라우저 확장 메뉴에서 저장 파일을 가져오거나 내보낼 수 있다.
