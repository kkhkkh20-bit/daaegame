다람탐정 첫 연출 시범 제작 명세 01
대상: 1일 마차 A01 / 3일 등 절도 B02
기준: DT_STORY_1.1_PRODUCTION_BASIS_01_20261020
범위: 대사·분기·증거를 바꾸지 않는 연출 설계. 본편 코드·기존 원화 변경 없음. 실행 검증 전.

1. 먼저 알아둘 실제 리소스 상태
숲은 합쳐진 한 장이다. 원경·중경·전경이 완성된 레이어처럼 표시하지 않는다. 현재 제작 가능한 대안은 정지 원화의 수평 팬이다.
마차 내부 원화에는 창밖 마을이 이미 그려져 있다. 초기부터 전체를 보여 주면 마을 첫 등장 연출을 앞당긴다. 처음에는 오른쪽 좌석 부분, 까로의 지붕 대사 이후 전체 창으로 전환한다.
기존 과자 봉지 CG는 나무 탁자 위다. 무릎 위 손 동작인 것처럼 사용하지 않는다. 신규 손 컷이 없을 때는 원문 서술과 기존 표정으로 진행한다.
3일 final03 칼/등/파편은 후보이며 무조건 적용 승인 목록은 비어 있다. 파일이 있다는 것과 그림체·현장 구조 승인 완료를 구별한다.

3. 조작과 표정
아빠 1인칭이 기본이다. 대결 연출 때문에 아빠·다람을 화면 반대편에서 바라보는 새 객관시점 범행 컷을 만들지 않는다.
D03S05 시작에는 원문에서 도착한 너울·초롱·톡·우박·실룩·백 부인과 아빠 곁 다람만. 실룩 자녀는 부리와 공방. 바둑이는 L0030에 맞춰 등장. 모든 얼굴을 동시에 늘어놓지 말고 말하는 사람과 실제 반응 대상만 1~2명.
칼만 닮았다는 오답: B021 L0068~L0070. 근거 없는 조합: B022 L0071~L0072. 힌트는 요청 시 B023 L0073만. 정답 성공음/접합 결과를 오답에서 재사용하지 않는다.
칼 접합 뒤 실룩 반박이 남고, 걸쇠 반박 뒤 같은 돌의 반출 연결이 남는다. 접합 한번으로 lamp_theft_supported를 만들지 않는다.

4. 저장·스킵·모바일
컷신은 표현 계층이며 원문 상태의 별도 생산자가 아니다. 읽기/관찰/정답 입력 완료를 스킵이 대신하지 않는다.
저장은 원문 기록 커서·선택 콜백·미완료 입력·기존 효과 적용 여부와 함께 복구해야 한다. 효과 직전/직후를 저장해 각각 재개하고 acquire, 반환, 구금이 한번만 처리되는지 확인한다.
이미 본 연출 다시보기는 읽기 전용. 정적·팬은 즉시 끝낼 수 있고, 필수 입력에서 멈춘다. 같은 조각에 다른 배율/회전을 적용해 억지 접합하지 않는다.
모바일은 작은 파편을 정확히 찍어야만 풀리는 조작 대신 해당 부분 선택+두 물건 비교를 허용한다. 정답 표시/자동 접합은 제출 뒤만.
2×2 이동 격자를 지켜도 기존 원화 전체가 자동으로 격자 통일되는 것은 아니다. 실제 합성·렌더링 검수가 별도로 필요하다.

5. 제작 승인 전 검사
A01: 편지 펼치기 전 스킵→E01 자동획득 없음. 선택 전 스킵→선택 대기. 도토리 관찰 안 한 경로→K01a 없음. 두 관찰 재열람→중복 보상 없음. 마을 첫 노출은 지붕 대사 뒤.
B02: 피코 생존/사망 둘 다 조사 진입; 사망 경로만 애도 대사. 우박 가설 수정 입력 전 정답 대사 없음. E15+E16만 제출→주웠다 반박, 성공 아님. 칼 비교→걸쇠 주장→위치 비교→동일 돌 연결 순서.
B02: 반환/보류 × 즉시인계반대/인계 네 조합을 테스트. 수레 처분을 자동 선취하지 않는다. 돌 복구는 D03S06에서만, 나머지 두 돌은 미확인.
실제 실행·그림체 최종 승인·모바일 리딩·사용자 재미 검증은 아직 수행하지 않았다. 명세 및 소스 ID·파일 존재 검증만 완료.

6. 1일 오프닝에서 입구 추리까지 끊기지 않는 연결
S01 필수 편지 조사/선택을 끝내고 원래 다음 입력 → S02 정차 조건 확인 → L0008 초소 이동 → L0019 E02 실제 획득 → L0022 초대장 제시 또는 원본 요청 → L0028 같은 날짜 원본 → S03 조사.
S03 세 자료는 기존 수첩 UI를 유지한다. E02는 처리 명단, E03은 가족 방문 신청 원본, E04는 벽 규정이다. 숙소 확대는 E03의 일부이지 새 네 번째 증거가 아니다.
정답: 목적 불일치부터 확인했다면 B004 L0014~19. 이미 세 근거를 찾아 바로 제출하면 B005 L0020~23으로 곧바로 성공. 이유 질문을 강요하지 않는다.
오답: B006 L0024 인원만 제시, B007 L0025 승객 확인만 제시, B008 L0026 다른 집 신청서. 힌트 B009 L0027은 요청할 때만. B010 이유 질문은 선택 사항이다.
중요: source S03_B001은 always이지만 저작 계약은 종이를 클릭해야 E03/E04를 얻도록 되어 있다. 엔진 연결자가 이를 자동 대사 순회로 해석해 입장 즉시 획득시키면 안 된다. 해당 evidence 기록을 기존 조사 입력 완료와 연결해 검증하고, 원본을 조용히 수정하지 않는다.
통합02 방문 신청서는 사용자 거절 상태이며 final03은 별도 교정 후보로 전달됐다. final03을 사용자 승인 완료로 간주하지 않는다. 읽기와 선택의 명세만 먼저 연결하고 최종 그림 검수를 별도로 받는다.

7. 실제 조작 검수
타이핑 중 첫 클릭은 현재 줄 전체 표시, 다음 독립 클릭은 다음 줄. 같은 터치의 pointer-up이 다음 선택지 클릭으로 이어지지 않도록 한다. 빠른 연타로 정답·획득·장면 이동이 중복되지 않아야 한다.
저장 위치: E01/E03/E04 획득 전후, 오답 직후, 정답 제출 직후, 돌 반환과 실룩 처분 사이. 불러오기 뒤 원래 입력과 상태가 같아야 한다.
현재 클라우드 실행 재시도는 코드 실행 전 사용량 제한으로 차단됨. 이 묶음은 문서와 소스/파일 정적 검증 산출물이며 게임 작동 검증이 아니다.
