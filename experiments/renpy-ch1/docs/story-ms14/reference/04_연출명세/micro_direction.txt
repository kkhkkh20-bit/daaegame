다람탐정 일상 행동·카메라·음향 보완 01
기준: DT_STORY_1.1_PRODUCTION_BASIS_01_20261020
성격: 대사를 고치지 않는 연출 부속 명세. 게임 적용·실행·청취·플레이 재미 검증 완료본이 아님.

1. 이번에 만드는 것은 무엇인가
중요한 컷신 사이에도 사람이 실제로 살고 일하는 느낌을 만든다. 매 문장마다 흔들거나 표정을 바꾸지 않는다. 원문에 있는 행동의 시작, 작업을 방해받는 순간, 회피하는 순간, 다시 일을 시작하는 순간만 골라 쓴다. 부속 JSON의 29개 이벤트는 기존 대사/행동 ID를 그대로 참조하며, 각 원문 조건과 내용도 함께 보존했다. JSON 자체는 엔진 코드가 아니다.

2. 우선 제작할 실제 흐름: 4일 솜이네 골목
출석과 시간 순서가 핵심이다. 실룩 하역과 네로의 침구 작업은 같은 카메라 안에 몰아넣지 않는다. 같은 D04_S01 내부에서도 장소와 블록 진입 조건을 따라야 한다.

가. 선택에 따른 실룩의 아침
MS14_D04_S01_B002만: 3일 인계 경로에서 아침 하역장. L0001의 실룩 짐 내리기, 너울의 작업표로 시작한다.
L0008에서 아빠가 요청한 작업표를 보여 준다. 문서 전체를 먼저 보여 주며 ‘종료일 공란’을 빨간 원으로 알려주지 않는다.
L0011 “그만해요. 당신은 적고 가면 되잖아요. ……다람아, 저쪽으로 가 있어.”는 일을 시키는 리듬과 아이 앞의 체면이 충돌하는 순간이다. 새 독백이나 영웅 음악을 붙이지 않는다.
L0012 손 잡기는 원문대로. 전용 손 포즈가 없으면 서술을 읽게 하고 인물 기본 자세를 유지한다. 여기서 아이들을 하역장에 새로 등장시키지 않는다.
실룩 보호·출석만 요구한 경로에는 이 연출 전체가 없다.

나. 네로는 대답보다 일을 먼저 한다
L0016: 젖은 침구를 짜는 네로와 초상을 든 다람의 전체 구도. 아직 솜이는 없다. 초상은 피코/초상 상태와 일치해야 한다.
2일에 이미 네로를 만난 경로: B004의 기존 인사→공통 질문. 침구 돕기나 보상을 새로 요구하지 않는다.
처음 만나는 경로: B005 “손 좀 비켜요. 물 떨어져요.”로 몸의 자리를 보여 준다. 반복 흔들림이나 익살 효과음은 쓰지 않는다.
B006/L0023: 실제 기존 조작 완료 후 빈 통 교체, 젖은 침구 끝 받치기, 처마 안 이동을 2~3개의 정지 상태로 확인한다. 이 연출을 봤다고 입력 완료를 대신 쓰지 않는다. 가족 담요 두 장 지급으로 바꾸지 않는다.
전용 짜는 포즈가 없으면 승인 네로 정지 이미지와 침구/물통 배치, 천 소리 후보, 원문 서술로 구현한다. 몸을 일그러뜨려 짜는 척하는 임시 애니메이션은 금지한다.

다. 문이 대화를 가로막는다
B007/L0040에서만 솜이 등장: 문 열림, 빈 그릇, 무쇠의 손. 손바닥 글씨는 이 거리에서 못 읽는다. 확대·보정으로 글씨를 보여주지 않는다.
L0049: 기침 뒤 솜이가 등으로 문을 닫는다. 동작 컷이 없으면 문 열린 정지 이미지→닫힌 이미지와 기존 서술. 문 사이로 새로운 방이나 인물을 보여주지 않는다.
L0050: 그림을 보고 잠깐 멈추지만 사용자의 진행을 막지 않는다.
L0056: 문손잡이로 가던 아빠 손을 거둔다. 없던 아빠 전신을 억지로 만들 필요 없다.
L0059에서 네로는 물을 들고 들어간다. 골목으로 나온 뒤 “아빠도 못 기다렸네.”가 남는다. 실패음이나 도덕 판정은 없다.

라. 이 장면의 합격 기준
실룩 경로 유무, 네로 첫 만남/재회, 실제 초상 상태 세 축을 확인한다. 솜이의 출현/퇴장 전후가 원문과 맞아야 한다. 침구 동작이 추가 클릭 숙제가 되면 줄인다. 행동을 다 보여도 엄마에 관한 새 사실이나 증거를 만들어서는 안 된다. 처음 보는 사람이 대사보다 동작을 기다려야 하면 실패다.

3. 5일 편지: 음악이 멎는 정확한 문장
앵커 MS14_D05_S04_L0006의 실제 문구:
“당신과 다람이를 부른 적 없어.”
이 문장의 마침표까지 출력됐을 때 BGM만 짧게 내려 멈춘다. 편지 전체 원문은 바꾸지 않으며 엄마가 현장에 나타나거나 엄마 성우가 자동으로 읽는 장면을 추가하지 않는다.
- 첫 클릭은 현재 대사를 전부 출력한다. 문장 끝을 한꺼번에 통과했다면 음악 이벤트는 1회 실행한다.
- 두 번째 클릭이 다음 대사로 간다. 첫 클릭이 음악 이벤트와 함께 다음 대사까지 넘기지 않게 입력을 잠근다.
- 자동 진행도 선택과 증거 입력 앞에서는 정지한다. 읽은 내용 스킵이 직접 조사/반박 입력을 대신하지 않는다.
- 긴 강제 정적은 없다. 종이·낮은 바람만 남기며 사용자는 바로 읽을 수 있다.
- L0008의 엄지 숨기기, L0022의 답장 뒤집기에는 같은 무음 상태가 이어진다.
- 이후 MS14_D05_S05_L0033은 첫날과 같은 복도다. 빈 대야를 든 종업원의 발소리가 멈출 뿐, 새 감시자/미확인 그림자를 추가하지 않는다.
- 음악에서 악기 하나를 빼려면 원래 stems와 사용 권한이 있어야 한다. 없으면 기존 곡 음량을 낮추거나 환경음만 쓴다. 단순 EQ를 ‘악기 제거’로 설명하지 않는다.

4. 다른 절정은 서로 다르게 들려야 한다
10일 MS14_D10_S03_L0028: 나비의 “그 말은 지금 하지 마세요.”는 음악을 연속 유지하되 대사를 조금 더 앞에 둔다.
10일 L0054: 실제 정답 연결 후에만 물증 확대. 물리/시각 검수 미완료 상태에서는 연출로 입증을 완료했다고 선언하지 않는다.
10일 L0066: 할머니의 말막힘은 낮은 음악 위에서 타이핑 소리만 사라진다. 5일의 완전 음악 정지를 반복하지 않는다.
13일 MS14_D13_S03_L0017: 촌장 주장 때 중립 구도를 유지하고 원하면 약한 음악 감쇄만 쓴다. 새 무늬 자동 확대·아침 회상은 없다.
13일 L0022: 정답 제출 후에만 수선 기억 컷. 수레 이동음은 실제 이동 상태에만 켠다. 촌장이 말한다고 수레가 출발한 것으로 만들지 않는다.
14일 MS14_D14_S02_L0043 “학교도 식소.” 뒤에는 이미 멈춘 실제 작업자의 손을 본다. 새로 작업이 멈춘 상태를 만들지 않는다. 음악보다 공구 소리가 없는 것이 핵심이다.
14일 L0048의 두려움을 인정하는 부리는 기존 B017 조건에서만. L0049 공구를 다시 잡는 행동을 대사 앞에 당기지 않는다.
14일 L0059: 실제 부리 작업 또는 까로 받침이 갖춰진 대체 작업에만 쇠 마찰음이 돌아온다. 둘 다 준비되지 않았다면 성공 소리도 없다.
14일 과자는 원래 엔딩 분기를 따른다. 가족 철수·부분 구조·폭력 경로를 모두 성공 제단 컷으로 합치지 않는다.

5. 14일 전체의 리듬 규칙
1일: 풍경은 넓게, 가족 소품은 짧게. 튜토리얼은 조작 가능한 순간을 기다리게 하지 않는다.
2~3일: 생활의 자리와 초상이 달라지는 것을 먼저 보고 결과 대사를 듣는다. 사망을 화려한 컷신 보상처럼 취급하지 않는다.
4~5일: 물통·문·수첩으로 대화를 움직인다. 음악 전체 정지는 5일 경고의 결정문에 집중한다.
6~7일: 화재/잠긴 문에 소리의 밀도를 사용하되 생존/예방 경로에는 피해음을 먼저 재생하지 않는다.
8~9일: 조사 전체 물건→사용자 세부 선택. 단서 하나마다 큰 정답음을 반복하지 않는다.
10일: 공방 입력→물증 컷→사람의 반응. 음악은 긴장을 이어 주고 나비의 말/할머니의 침묵이 리듬을 바꾼다.
11일: 가족 생활 소리, 양말·단추의 손. 포옹과 화해를 강제하지 않는다.
12일: 실제 예방/배식/피해 상태를 먼저 분기한 뒤 소리·시선 선택. 조리음을 곧바로 독약 암시로 바꾸지 않는다.
13일: 기억의 승리와 사람을 실제 내리는 행동을 분리. 전자는 반박, 후자는 움직임과 협력이다.
14일: 음악보다 멎었다 돌아오는 작업 소리. 이후 가족 과자에는 명령·행정 설명을 다시 끼워 넣지 않는다.

6. 이미지와 자산 버전
통합02의 원본 재사용 자산은 위치·상태·역할을 확인해 사용한다. 03 후보의 replacements/manifest가 특정 파일을 교체한다고 명시한 경우에만 해당 대상에 우선 적용한다. 같은 이름이나 ‘최종’이라는 폴더명만으로 검수를 통과한 것으로 보지 않는다. 최신 사용자 반려 대상 방문 신청서 및 그림체는 부모 작업의 검수 결과를 따라 보류한다.
일반 캐릭터의 눈코입만 다른 그림체로 합성하지 않는다. 가족이 그린 극중 그림은 의도적인 크레파스/서툰 낙서 예외다. 그 그림까지 일반 스프라이트처럼 기계적인 2×2 도트로 바꾸지 않는다. 이 예외를 모든 캐릭터에 확대하지 않는다.
DEV 비교 그림·전체 증거 정답 조립도는 플레이어용 자산이 아니다. 관찰 전 단계에서 대신 쓰지 않는다.

7. 음원 권리와 실제 재생 상태
reuse/audio/licenses의 로컬 출처 명세를 읽고 세 OGG의 SHA-256을 대조했다. 모두 파일 해시가 일치한다.
- Council_Desk_OneHit.ogg: p1llowt4lk, Freesound 443289, 명세상 CC0 1.0 Universal.
- Council_SmallRoom_Murmur_Loop.ogg: Breviceps, Freesound 457043, 명세상 CC0 1.0 Universal.
- Council_Soft-Air_Transition.ogg: WizardOZ, Freesound 419341, 명세상 CC0 1.0. 원 소스도 합성음이라고 기록됨.
이는 보관된 출처/변환/해시 확인이다. 이번 작업에서 원 사이트 조건을 다시 검증하거나 직접 청취하지 않았다. 출시 전 담당자가 출처 조건과 실제 파일을 확인해야 한다. 세 파일을 평범한 대화마다 모두 사용하지 않는다.
phase2/audio의 10개 WAV는 외부 샘플·멜로디 없는 결정적 절차 합성 후보라고 기록돼 있다. 기술적 포맷 확인과 상업권 인증/청취 승인은 다르다. 녹음 효과음으로 소개하지 않는다. 낮은 타이핑음·종이·물·기침은 이 10개에 포함돼 있다고 가정하지 말고 실제 기존 자산 확인 또는 신규 필요 항목으로 남긴다.

8. 저장·입력·스킵·재감상
micro_events.json의 save_fields 및 event_contract를 공통 재생 계약에 매핑한다. 스토리 효과를 이 부속 파일에서 중복 실행하지 않는다.
스킵 종료도 같은 finalize를 지나도록 하되 필수 선택과 조사 입력은 넘지 않는다. 완료된 입력/효과는 ID로 1회만 커밋한다. 빠른 두 번 터치가 두 분기 콜백을 동시에 실행하지 않게 처리한다.
음악이 꺼진 편지 중간에 저장한 뒤 불러오면 꺼진 상태를 복원한다. 음량·루프 위치·fade 목표와 경과·소리 1회 재생 이력·현재 대사 글자 위치를 함께 저장한다. restore 중 예전 루프가 겹쳐 재생되면 실패다.
재감상은 새 연출 인스턴스로 소리는 다시 들려줄 수 있지만 증거·물자·시간·관계 상태는 바꾸지 않는다. 생존자와 소품은 재감상 시점의 기록된 장면 상태를 사용한다.
모바일 저사양에서는 정지 이미지와 원문이 동일 정보를 전달해야 한다. 큰 줌/움직임 줄이기 옵션은 입력이나 증거를 숨기는 옵션이 아니다.

9. 이번 파일의 검증 범위
29개 연출 앵커가 실제 기준본의 ID와 원문에 존재한다. 세 문장 중간 앵커가 실제 문자열에 일치한다. 원본 파일, 대사, 조건, 효과는 변경하지 않았다. 엔진 실행·스킵/저장·iOS 화면·음량·인물 포즈·추리 물리 구조·재미는 아직 검증하지 않았다.
실제 테스트의 우선순위는 1일 마차→입구, 3일 물증 대조, 4일 솜이네다. 5일·10일·13일은 정답 노출 및 오디오 저장 경계 검증으로 이어간다. 이 문서를 만든 것만으로 플레이 가능한 완성품이라 보고하지 않는다.
