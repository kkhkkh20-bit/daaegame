다람탐정 연출 실행 계약 01
기준: DT_STORY_1.1_PRODUCTION_BASIS_01_20261020
이 문서는 구현 명세다. 엔진 코드가 아니며 실행 검증 완료를 의미하지 않는다.

1. 구현 순서
첫 시범: 1일 마차에서 입구 추리까지 → 3일 등 조사와 반박 → 4일 솜이네 일반 대화.
10일 살인 대결은 대표 대결 기준이지만 물증/문틈 재연 검증 전에는 관찰 자료와 대사 입력 흐름만 테스트한다. 확정 범행 재현 영상을 먼저 완성했다고 처리하지 않는다.
기존 엔진·수첩·대사 UI·저장 구조에 얇은 연출 연결층을 추가한다. 엔진 교체, 일반 UI 전면 교체, 신규 보상·캐릭터·사건 추가는 범위 밖이다.

2. 하나의 이벤트 흐름
scene_id와 record_id를 유지한다. 연출 cue_id는 해당 record_id와 연결되는 별도 식별자이며 원 대사 ID를 대체하지 않는다.
각 이벤트는 다음을 구분한다:
- source_scene / source_record / source_block: 기준 대본의 실제 위치
- phase: 대사 직전 / 타이핑 도중 실제 문구 도달 / 문장 전체 표시 완료 / 원래 입력 결과 직후 / 원래 상태 확정 직후
- guard_ref: 원래 분기 조건의 참조. 사람이 읽는 조건 문자열을 eval하지 않는다.
- assets: 파일별 역할, 사용 상태, viewport, 실제 참석 인물
- presentation: 카메라·표정·소품·음향·정적
- input_gate: 진행 / 증거 제시 / 명시적 힌트 / 선택 / 연출 스킵
- effect_ref: 기존 스토리가 소유하는 상태 변경 참조. 카메라/음향 이벤트가 사건 결과를 새로 결정하지 않는다.
- resume / skip / replay: 재개·건너뛰기·재감상 정책

순서: 원래 주장 대사 → 선택 가능 상태 → 플레이어 입력 → 원래 판정 → 정답 후 연출 → 원래 반박 대사/다음 단계.
오답이면 오답 반응으로만 돌아간다. 정답 연출 예약이 남아 뒤늦게 재생되면 안 된다. 힌트는 별도 입력으로만 연다.
13일의 회상과 수레 정지는 별도 이벤트다. 시간 모순 정답이 수레 정지·전원 구조·모과 생사를 자동 확정하지 않는다.

3. 클릭·터치·자동 진행
타이핑 중 첫 클릭은 현재 문장을 모두 보이게 하고 그 입력을 소비한다. 같은 클릭이 새 선택지 제출이나 다음 대사로 재사용되면 안 된다.
문장 표시 완료 뒤 다음 클릭으로 진행한다. 선택지가 나타난 직후 이전 더블탭이 선택지에 관통하지 않도록 화면/입력 토큰을 바꾼다.
선택 결과 처리 중 입력 잠금은 같은 결과의 중복 실행만 막고 장시간 읽기 대기를 강제하지 않는다.
자동 진행과 읽은 대사 스킵은 조사·추리·선택 입력 앞에서 반드시 멈춘다. 회차별 미독 대사는 기존 정책에 맞춰 보존한다.
재열람·증거 비교·연출 스킵 시간이 이야기 속 이동/조사 시간으로 추가 차감되면 안 된다.
마이크로 정적은 짧고 넘길 수 있어야 한다. 접근성 설정에서 글자 즉시 표시·움직임 감소를 사용해도 정보와 상태 결과는 같아야 한다.

4. 저장·불러오기·스킵·재감상
컷신 상태는 scene_id, record_id, cue_id, 현재 단계, 글자 표시 상태, 이미 처리한 effect ID, 해당 분기 선택 결과, 실제 표시 인물/소품, 음향 상태를 재개 가능하게 저장한다. 엔진이 이미 제공하는 기능을 우선 재사용한다.
상태 변경의 기준은 원래 대본이다. 이미 의료/구조 결과가 확정된 뒤 결과 컷을 보여주는 장면에서는 결과를 컷신 끝까지 미루거나 다시 계산하지 않는다.
컷신 내부에서 꼭 확정해야 하는 기존 효과는 원자적 커밋과 처리 ID를 사용한다. 저장 직후 재개, 스킵, 다시 클릭해도 아이템·시간·물자·일회성 플래그가 한 번만 처리되어야 한다.
건너뛰기: 승인된 현재 분기의 남은 표현만 생략하고, 원래 순서에서 필수인 효과를 한 번만 처리한 뒤 다음 입력 지점에서 멈춘다. 미제출 정답이나 미선택 구조 행동까지 건너뛰어 성공시키지 않는다.
재감상: 현재 회차 저장을 바꾸지 않는 읽기 전용 재생. 과거의 생존·소품 상태로 표시하되 증거/물자/관계 점수를 다시 지급하지 않는다.
로드: 한 번 끝난 충격음·비명·획득음을 매번 처음부터 재생하지 않는다. 긴 배경음 위치 복원이 불가능하면 짧은 페이드로 복원하되 결과음이 중복되지 않게 한다. 실제 지원 수준을 테스트 후 보고한다.

5. 그림과 카메라
일반 캐릭터는 같은 인물의 기본·표정 사이에서 실높이, 발 앵커, 얼굴 중심과 의상 디테일을 유지한다. 같은 zoom값을 다른 크기의 캔버스에 그대로 적용하지 않는다.
17개 기존 표정은 화풍·배율 검수 보류다. 임시로 쓰면서 최종이라고 보고하지 않는다. 기본 그림 유지+동작 서술/짧은 멈춤으로 임시 흐름을 시험할 수 있으나 감정 연출 완료로 계산하지 않는다.
게임 속 크레파스 가족 그림과 연필 초상은 의도된 다른 매체다. 일반 캐릭터 도트 규칙으로 전체를 픽셀 캐릭터처럼 바꾸지 않는다.
배경 시트는 해당 영역만 선택한다. 3:1 전경을16:9로 찌그러뜨리지 않는다. 좌우 반전으로 문·손잡이·증거 위치를 바꾸지 않는다.
소품 전체 관찰 → 플레이어가 조사 선택 → 세부 확대 순서. 정답 전 카메라가 핀이나 새 무늬만 자동 강조하지 않는다. 확대 자체는 조작 가능한 관찰이지 정답 판정이 아니다.
정답 후 재구성은 확인된 사실만 표현한다. DEV 도식, 추정된 손동작, 아직 검증하지 않은 타격·시야를 실제 기억처럼 재연하지 않는다.

6. 음향
대사 타이핑은 낮고 부드럽게, UI 클릭과 말소리를 분리한다. 음소거/볼륨 설정을 존중한다. 새로운 주파수나 음색이 실제 기기에서 거슬리지 않는지 청취가 필요하다.
음악은 장면마다 새 곡보다 유지/감소/복귀를 먼저 사용한다. 5일 경고의 끊김, 7일 문밖의 공간음, 10일 마지막 말막힘, 13일 입력 대기 감쇠, 14일 공구 소리의 재개는 서로 다르게 처리한다.
곡의 일부 악기 제거는 실제 stem이 있는 경우에만 한다. 단일 음원을 가진 채 악기 분리 편곡을 완료했다고 하지 않는다. 대안은 볼륨/페이드/무음이다.
실제 라이선스 근거를 가진 파일만 플레이 빌드에 포함한다. 출처·조건·표기문·파일 해시를 함께 남긴다. 출처 확인 전에는 논리 음향 ID만 연결하며 자동 다운로드나 임의 상업사용 승인을 하지 않는다.

7. 플랫폼·완료 기준
현재 저장 구조가 웹 빌드와 네이티브 빌드에서 같다고 가정하지 않는다. 실제 대상 브라우저·휴대폰·화면 방향·빌드 버전을 테스트 결과에 쓴다.
필수: 대사창/선택지/확대 소품 가림 없음, 작은 터치가 이동으로 오인되지 않음, 안전영역 유지, 텍스트 가독성, 최초 오디오 입력 제약, 절전/백그라운드 복귀 후 중복 재생 없음.
기술 테스트와 재미 테스트를 분리한다. AI 문서 검토나 스크립트 검사로 '재미있다/모바일 통과/실제 플레이 완료'를 판정하지 않는다.
완료 보고: 변경 파일·브랜치/커밋, 실행 환경, 테스트한 scene/record/cue, 각 결과, 실패 재현 절차, 스크린샷, 미검증 항목. 본편 배포나 main 병합은 별도 승인 없이 하지 않는다.

현재 실행 상태
2026-10-20 새 클라우드 개발 시도를 시작했으나 사용량 한도 오류로 코드 조사/적용 전에 실패했다. 따라서 본 명세의 저장·로드·스킵·모바일·재미 테스트는 모두 실행 미검증이다. 이 제한을 다른 환경에서 본편 코드를 몰래 구현하는 방식으로 우회하지 않았다.

다람탐정 첫 연출 시범 제작 명세 01

1. 먼저 알아둘 실제 리소스 상태
숲은 합쳐진 한 장이다. 원경·중경·전경이 완성된 레이어처럼 표시하지 않는다. 현재 제작 가능한 대안은 정지 원화의 수평 팬이다.
마차 내부 원화에는 창밖 마을이 이미 그려져 있다. 초기부터 전체를 보여 주면 마을 첫 등장 연출을 앞당긴다. 처음에는 오른쪽 좌석 부분, 까로의 지붕 대사 이후 전체 창으로 전환한다.
기존 과자 봉지 CG는 나무 탁자 위다. 무릎 위 손 동작인 것처럼 사용하지 않는다. 신규 손 컷이 없을 때는 원문 서술과 기존 표정으로 진행한다.
3일 final03 칼/등/파편은 후보이며 무조건 적용 승인 목록은 비어 있다. 파일이 있다는 것과 그림체·현장 구조 승인 완료를 구별한다.

6. 이미지와 자산 버전
통합02의 원본 재사용 자산은 위치·상태·역할을 확인해 사용한다. 03 후보의 replacements/manifest가 특정 파일을 교체한다고 명시한 경우에만 해당 대상에 우선 적용한다. 같은 이름이나 ‘최종’이라는 폴더명만으로 검수를 통과한 것으로 보지 않는다. 최신 사용자 반려 대상 방문 신청서 및 그림체는 부모 작업의 검수 결과를 따라 보류한다.
일반 캐릭터의 눈코입만 다른 그림체로 합성하지 않는다. 가족이 그린 극중 그림은 의도적인 크레파스/서툰 낙서 예외다. 그 그림까지 일반 스프라이트처럼 기계적인 2×2 도트로 바꾸지 않는다. 이 예외를 모든 캐릭터에 확대하지 않는다.
DEV 비교 그림·전체 증거 정답 조립도는 플레이어용 자산이 아니다. 관찰 전 단계에서 대신 쓰지 않는다.

7. 음원 권리와 실제 재생 상태
reuse/audio/licenses의 로컬 출처 명세를 읽고 세 OGG의 SHA-256을 대조했다. 모두 파일 해시가 일치한다.
- Council_Desk_OneHit.ogg: p1llowt4lk, Freesound 443289, 명세상 CC0 1.0 Universal.
- Council_SmallRoom_Murmur_Loop.ogg: Breviceps, Freesound 457043, 명세상 CC0 1.0 Universal.
- Council_Soft-Air_Transition.ogg: WizardOZ, Freesound 419341, 명세상 CC0 1.0. 원 소스도 합성음이라고 기록됨.
이는 보관된 출처/변환/해시 확인이다. 이번 작업에서 원 사이트 조건을 다시 검증하거나 직접 청취하지 않았다. 출시 전 담당자가 출처 조건과 실제 파일을 확인해야 한다. 세 파일을 평범한 대화마다 모두 사용하지 않는다.
phase2/audio의 10개 WAV는 외부 샘플·멜로디 없는 결정적 절차 합성 후보라고 기록돼 있다. 기술적 포맷 확인과 상업권 인증/청취 승인은 다르다. 녹음 효과음으로 소개하지 않는다. 낮은 타이핑음·종이·물·기침은 이 10개에 포함돼 있다고 가정하지 말고 실제 기존 자산 확인 또는 신규 필요 항목으로 남긴다.

8. 저장·입력·스킵·재감상
micro_events.json의 save_fields 및 event_contract를 공통 재생 계약에 매핑한다. 스토리 효과를 이 부속 파일에서 중복 실행하지 않는다.
스킵 종료도 같은 finalize를 지나도록 하되 필수 선택과 조사 입력은 넘지 않는다. 완료된 입력/효과는 ID로 1회만 커밋한다. 빠른 두 번 터치가 두 분기 콜백을 동시에 실행하지 않게 처리한다.
음악이 꺼진 편지 중간에 저장한 뒤 불러오면 꺼진 상태를 복원한다. 음량·루프 위치·fade 목표와 경과·소리 1회 재생 이력·현재 대사 글자 위치를 함께 저장한다. restore 중 예전 루프가 겹쳐 재생되면 실패다.
재감상은 새 연출 인스턴스로 소리는 다시 들려줄 수 있지만 증거·물자·시간·관계 상태는 바꾸지 않는다. 생존자와 소품은 재감상 시점의 기록된 장면 상태를 사용한다.
모바일 저사양에서는 정지 이미지와 원문이 동일 정보를 전달해야 한다. 큰 줌/움직임 줄이기 옵션은 입력이나 증거를 숨기는 옵션이 아니다.

9. 이번 파일의 검증 범위
29개 연출 앵커가 실제 기준본의 ID와 원문에 존재한다. 세 문장 중간 앵커가 실제 문자열에 일치한다. 원본 파일, 대사, 조건, 효과는 변경하지 않았다. 엔진 실행·스킵/저장·iOS 화면·음량·인물 포즈·추리 물리 구조·재미는 아직 검증하지 않았다.
실제 테스트의 우선순위는 1일 마차→입구, 3일 물증 대조, 4일 솜이네다. 5일·10일·13일은 정답 노출 및 오디오 저장 경계 검증으로 이어간다. 이 문서를 만든 것만으로 플레이 가능한 완성품이라 보고하지 않는다.
