다람탐정 연출 제작 명세01
스토리 기준 DT_STORY_1.1_PRODUCTION_BASIS_01_20261020. 원본 대사/분기 수정 없음.

읽는 순서
1. 공통이벤트_품질기준.txt: 입력·상태·저장·스킵의 실행 계약.
2. pilots/시범_A01_B02_스토리보드.txt와 연출이벤트.json: 첫날 오프닝→입구,3일 조사·대결의 상세 앵커.
3. micro_direction.txt와 micro_events.json: 4일 일반 대화,5일 경고 등 대화 속 행동·소리.
4. scene_map.json: 14일82장면에 대한 A6/B7/C 배치와 원문 조건 참조 색인.
5. storyboards_rest.txt: 나머지 컷의 화면·음향 제안.
6. actual_resource_gaplist.json: 실제 파일 존재와 미술/물리/실행 보류 구분.
7. 실행검수_체크리스트.json:40개 실행/사람 관찰 항목. 현재 모두 NOT_RUN.

중복 연결 방지
scene_map은 배치 색인이며 별도 재생 배열이 아니다. 상세 pilots와 scene_map을 같은 대사에서 각각 실행하지 않는다. A01/B02는 pilots 상세를 실행 설계 기준으로 사용한다. micro_events와 해당 상세 컷이 같은 record를 쓰면 같은 표현 제어기에 묶고 중복 camera/audio 이벤트를 자동 합치지 않는다. 나머지 storyboards는 설명 자료다. 개발자가 출처별 배열을 모두 순서대로 재생하는 방식 금지.
source_text/source_effects/source_guard는 원문 근거이지 새 대사/상태 명령이 아니다. 원문 상태는 원래 엔진이 정확히 한 번 소유한다.

구현 범위
먼저1일오프닝→입구,3일물증조사·반박,4일솜이네대화를 시범으로 만든다.10일은 물증/현장 검증 전 확정 범행 재연을 하지 않는다. 5일과13일은 정답 전 강조/회상 금지와 음향 변화를 별도 테스트한다.
본편과 모든 UI를 다시 만들지 않는다. 기존 승인 가로형 수첩 UI와 시스템에 연결한다. 새로운 추리 전용 화면 구성이 필요하면 기존 UI 틀 안의 검토 시안을 먼저 만든다.

가족 그림 예외
일반 인게임 배경·캐릭터의 도트 규칙과, 아이가 그린 극중 크레파스 그림은 구분한다. 가족 그림 전체를 반듯한 도트 캐릭터로 바꾸지 않는다. 최근 요청은 원래 크레파스 몸/종이를 살리고 눈코입만 같은 서툰 질감으로 고치는 것이다.

현재 검증 수준
기준본에 존재하는 ID 참조 검사 통과. 파일 존재 확인과 원문 조건 추출은 실제로 수행했다.
실행 환경에서 컷신·대사·분기가 통합됐다는 뜻이 아니다. 2026-10-20 새 개발 작업이 사용량 한도 오류로 코드 접근 전에 실패했다. main 적용/배포/실제 플레이/모바일 검증은 수행하지 않았다.

마차 창밖 마을을 초반부터 보여주면 첫 등장이 약해지므로 기존 좌석 구도/원문 까로 대사에 맞춰 노출한다. 실제3레이어는 미확보라 정지 팬 대안을 제공한다.

13일 다람 위치,14일 과자 대체/촌장 장소/구조·폭력 결말 조합의 기존 보류 항목을 임의 성공 처리하지 않는다.
