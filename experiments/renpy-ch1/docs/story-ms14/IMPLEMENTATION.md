## 실제 연결 범위

첫 검토 구간은 `MS14_D01_S01`부터 `MS14_D03_S06`까지와 `MS14_D04_S01`이다. 17장면의 712레코드 중 player_visible이고 dialogue/narration/evidence인 587개를 원문 그대로 표시한다. 내부 action/system/choice 레코드를 개발 지시문으로 대사창에 출력하지 않는다. 선택과 조사는 별도 입력으로 연결한다.

원문 자연어 when/requires/effects는 엔진 코드가 아니다. 명시적인 진행 그래프와 비교 연산만 실행하며, 알 수 없는 guard/operation은 오류로 중단한다. 원본 82장면과 분기표 전체는 source/에 보존하지만 후반까지 실행 연결했다고 주장하지 않는다. `dev/import_ms14.py <병합된 전달 폴더>`로 실행 데이터와 선택 자산을 재생성할 수 있다.

## 상태와 입력

`state-map.csv`는 65개 상태·증거의 원문 이름, 엔진 필드, 초기값, 변경 이벤트, 참조 분기, 저장 여부를 연결한다. 상태는 `ms14.values`, 증거는 `ms14.evidence`, 현재 입력과 커서는 `ms14.node/cursor/selected`, 적용 효과 ID는 `ms14.applied`에 저장한다. 모든 갱신은 새 상태를 반환한 뒤 단일 Ren'Py 문장에서 교체한다.

기존 수첩에는 `MS14:E01` 같은 별도 ID만 투영한다. 기존 E01 등은 이전 저장의 의미를 유지한다. 수첩 열람·선택은 증거 획득이나 시간 경과가 아니다. 정답 조합은 플레이어가 수첩에서 한 장씩 고른 뒤 직접 제시한다. 힌트는 요청한 경우만 원문 힌트 블록을 재생한다.

원문 충돌 처리: D01S03 B001의 E03/E04 자동 획득은 author_contract의 자료 클릭 계약을 우선해 각 조사 입력 뒤로 분리했다. 원문 레코드와 효과 자체는 수정하지 않았다. E06은 방 메모이며 전달 지시서의 M01 표기 대신 정본 ID를 사용했다. E01/E06 비교는 위조범 확정 상태를 만들지 않는다.

## 자산

`game/ms14/art.json`에 실제 파일·역할·크기·원본 경로·해시·검토 상태가 있다. PNG는 재인코딩하지 않아 알파와 원래 형상을 보존했다.

- 기존 배경 12개. 마차 초반은 오른쪽 좌석만 사용하고 지붕 대사 뒤 전체 창을 보여 준다.
- D01 열린 보따리와 원래 크레파스 가족 그림은 별도 레이어로 표시한다. 세 팔을 유지한다.
- D02 교환함은 원래 천주머니가 있는 상태를 유지하며 쪽지 투입 전에만 보여 준다.
- D03 초상은 완성/미완성/다람의 첫 선을 실제 상태와 연결한다. 두 담요는 실제 수령 후 수첩에서 수량에 맞게 표시한다.
- 솜이네 골목은 전용 외부 원화가 없어 remaining_resource_actions의 gate-morning 후보를 임시 사용한다. 내부 집 원화를 골목으로 쓰지 않는다. 하역장도 광장 후보 재사용이며 정확한 현장 검증 전이다.
- 수정03 문서의 미확정 날짜·금액·서명·측정값을 임의로 채우지 않았다. DEV 물증 도식과 보류 표정은 포함하지 않는다. 칼 대조는 원문 관찰·진술과 수첩 입력으로 연결했으며, 최종 물증 그림/드래그 접합 퍼즐이 완성된 것은 아니다.
- 새 음원은 출처·청취 확인 전이라 추가하지 않았다. 풍부한 미세 동작, 숲 팬, 전용 손 포즈와 최종 음향 연출은 미완이다.

## 검증

로그는 납품 ZIP의 validation/에 포함한다.

- 8개 새 단위 검사: 2일 선택 × 돌 반환 × 인계 × 입구 두 경로 총 16경로, 획득 전 조사, 오답 무효과, 미확인 조건 거부, 효과 중복, 칼 대조만으로 절도 확정 금지, 원문/해시 보존.
- 실제 엔진 5개 테스트: 오프닝 조사 입력과 지붕 노출, E03/E04 개별 조사, 실제 게임 수첩 표시, 솜이네 대화 시작, 대화 스킵 후 입력 정지와 저장→진행→불러오기로 편지 획득 전 상태 복원.
- 수첩 검사는 기존 QA용 간이 수첩을 실제 게임 화면으로 복구한 상태에서 별도로 수행했다. 간이 QA 화면 캡처를 실제 UI 검수로 세지 않는다.
- native setup으로 D03/D04 위치까지 도달한 검사는 전체 연속 수동 플레이를 대체하지 않는다. 전체 대사를 새 게임부터 끝까지 사람이 플레이한 것은 아니다.
- 환경: Linux x86_64, Ren'Py 8.5.3, Mesa llvmpipe, 가상 1280×720 / 창 1099×618. 실제 휴대폰·브라우저 검증 아님.

## 미완료

5~14일 실행 연결, D01~D03 전체 연속 실기 플레이, 모든 독립 선택 조합의 엔진 저장/로드·연타·롤백·재진입, 4일 전체 장면, 최종 물증 확대 미술과 물리/시야, 음원 출처·청취, 웹/모바일 빌드, 접근성 전 조합, 사람 재미 테스트는 미완료다.

후반은 원문에 명시된 D13 광장/학교 조건 충돌, D14 봉투 밀기 대체, 구조와 폭력의 중첩, 촌장 위치·1회 대결 조건을 해결한 뒤 연결해야 한다. 원문의 release hold와 40개 실행검수 원본은 수정하지 않았다. 초기 단위 검사 또는 일부 native 통과를 전체 검수 완료로 바꾸지 않는다.

공개본은 빌드·병합·push·배포하지 않았다. 전달물은 기존 저장소에 적용된 개발 브랜치의 검토본이다.
