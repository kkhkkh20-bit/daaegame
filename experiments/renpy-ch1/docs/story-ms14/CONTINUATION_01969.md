## 리소스와 상태

추가 파일은 솜이네 실내, 여관 복도, 초소 책상 쪽 재구성용 기존 배경과 `D05_warning_private` 교정 문서다. 총 24개 파일의 원본 경로·해시·역할은 `game/ms14/art.json`에 있다. 초소 후보의 구금실 문은 크롭에서 제외했다. 현장 구조·밤 조명·최종 미술 승인은 별도다. 소매 접합 기술 도식이나 새 인물 그림·음원을 자동 적용하지 않았다. 진료 담당자와 종업원은 원문에 있는 이름의 대사만 표시하며 다른 인물 그림을 빌려 쓰지 않는다.

99개 상태/증거 항목과 음악의 표현 상태 1개를 `state-map.csv`로 갱신했다. 새 필드는 명시된 초기값만 추가하며 이전 회차의 담요·피코·실룩·증거·처리 효과는 다시 계산하지 않는다. 저장 스키마는 저작 버전과 별개인 runtime_schema=2다. 기존 v1형 종료 상태는 새 4일 시작 입력으로 이어진다.

음악 정지는 `MS14_D05_S04_L0006:first_sentence_done` 표현 cue에 한정한다. 실제 표시되는 첫 문장이 완성될 때 Ren'Py의 slow_done 콜백으로 멈추며, 나머지 표시 문자열과 합치면 원문과 정확히 같다. 상태/증거 효과를 이 콜백에서 실행하지 않는다. 이미 실행된 cue는 중복하지 않고 after_load에서 무음 상태만 복원한다. 현재 새 본편에는 추가 BGM을 도입하지 않았으므로 native 검사에서는 기존 게임의 타이틀 곡으로 정지·복원을 확인했다.

E27/E28은 `private=true`로 표시하고 공개 제시 목록에서 제외한다. 가족끼리의 E01/E27 비교에서만 E27을 선택할 수 있다. 개인 수첩에서 읽는 행위는 별개이며 자료를 소모하거나 공개·인계 상태를 바꾸지 않는다.

원문 보류: D04S04의 author_contract는 E21을 언급하지만 해당 장면의 실제 records에는 acquire(E21)이 없다. 원문이 명시한 목격 대사는 그대로 재생하고 E21 카드를 임의로 만들지 않았다. 5일 필수 제시 계약은 E20/E22/E23/E24이므로 이 연결에는 가상의 E21을 요구하지 않는다. 후반 연결 시 다시 검토해야 한다.

## 실행 결과

- 전체 단위 검사: 742개 통과. 새 구간의 선택 유지·증거 선행 조건·오답·가족 편지 비공개·v1 상태 보완·표현 cue의 일회성 등을 포함한다.
- 초반 native 회귀: `ms14_opening`, `ms14_gate`, `ms14_present`(실제 수첩), `ms14_somi`, `ms14_skip_save` 통과.
- 새 native: `ms14_45_continue`, `ms14_45_warning`, `ms14_45_privacy`, `ms14_45_rebuttal`, `ms14_45_night` 통과.
- 이어하기 검사는 v1 형태의 상태를 만들어 이전 종료 라벨에서 실제 새 입력으로 이동했다. 모든 실제 사용자 저장 파일을 변환·검수했다는 뜻은 아니다. 최초 실행은 테스트 실행기의 시간 제한에 걸렸고, 제한을 늘린 단독 재실행에서 통과했다.
- 경고 검사에서는 타이핑 중 첫 클릭이 첫 문장을 완성하고 같은 클릭으로 다음 패킷에 넘어가지 않는 것, cue 한 번, BGM 정지, 저장→곡 재생→불러오기 후 무음 복원을 확인했다.
- 공개 제시 목록에 편지 두 장이 빠지지만 이번 회차 소유 자료는 유지되는 것을 실제 게임 수첩으로 확인했다.
- 밤이 검사는 소매 천 하나만 낸 오답 뒤 혐의가 남고, 네 근거를 제출한 뒤에만 E25/E26과 보호 교대가 확정되는 것을 실제 엔진에서 확인했다.
- 환경은 Linux x86_64, Ren'Py 8.5.3.26051504, Mesa llvmpipe, 가상 1280×720/창 1099×618이다. native 위치 준비와 스크립트 검사가 전체 연속 수동 플레이·실제 휴대폰·웹 빌드·재미 검수의 대체물은 아니다.

검사 로그와 화면은 `validation/01969/`에 보존한다. 6~14일 실행 연결, 모든 지점의 저장/롤백·연타, 최종 물증 원화와 시야·물리, 오디오 청취, 모바일, 사람 테스트는 남아 있다.
