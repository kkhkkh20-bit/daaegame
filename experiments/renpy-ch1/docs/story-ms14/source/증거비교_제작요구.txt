다람탐정 8–9일 증거 비교 제작 요구
기준: DT_STORY_1.1_CANDIDATE_20261020, DIALOGUE_06_10.json.
범위: 기존 수첩 픽셀 UI의 살펴보기·확대·대조. 추가 대사, 단서, 상태값, 별도 UI 시스템 없이 제작한다. 제작 요구이며 구현·자산 승인 보고가 아니다. 아래 같은 문단에서 생략한 레코드 접두사는 직전 전체 ID와 같다.

1. 촛대 윗조각 / 아랫조각 / 결합부
근거: MS14_D08_S03_L0001, L0007, L0010, L0023–L0025.
아랫조각은 손잡이·잡았던 자리·넘어지며 찍힌 흔적, 윗조각은 작은 촛농 받침·짧은 부러진 목·얼룩 있는 파단면으로 구분한다. 뒤쪽 접힌 천, 천과 기존 장식 고리를 함께 통과하는 닫힌 핀, 앞쪽 깨진 면과 돌출 구리 끝을 동일 원본·방향에서 보여 준다. 우연히 핀만 고리에 걸린 모양으로 그리지 않는다.
플레이어 입력: 손잡이·파단면·고리를 각각 확대. 천/핀을 풀거나 맨손으로 조각을 맞추지 않는다. 최초 현장 스케치와 현재 보관 상태를 구분하며, 확대도에 새 흠집을 추가하지 않는다.
확인 범위: 수거 당시 결합 상태까지. 감싼 사람·타격자·고의는 표시하지 않는다. 실제 관찰 뒤 E08_CONTACT_ASSEMBLY의 기존 재열람 MS14_D08_S03_B005/L0036으로 연결한다.

2. 구리선 조각 / 핀 결손부 / 수선 자료
근거: MS14_D08_S03_L0016–L0022; MS14_D09_S02_L0005–L0017 또는 L0019–L0025.
별도 보관된 조각과 핀에 남은 끝을 같은 축척으로 나란히 보여 준다. 끊긴 굴곡과 두 번 꺾인 선의 연속이 식별되어야 한다. 수선 전후 그림은 기존 장부/영수증 등본이며 제작용 복원도를 새 증거로 바꾸지 않는다.
플레이어 입력: D8 두 끝 확대 대조 → D9 핀 뒤 확대·상자째 방향 확인·수선 그림/날짜/수령인 대조. 색이 같다는 것만으로 완료시키지 않는다. 새 드래그 퍼즐/제출 상태는 만들지 않는다.
확인 범위: D8 E08_WOUND_WIRE, D9 해당 대조 뒤 E09_PIN_OWNER. 톡 부재는 기존 세련 등본 분기 B002를 사용하며 세련을 수선 목격자로 그리지 않는다. 소유 확인은 범행 확인이 아니다.

3. 목도리 귀퉁이 / 보존된 천
근거: MS14_D09_S03_B006/L0042–L0049, B008/L0052.
보존 천의 사진과 목도리 끝을 동일 원본에서 분리해 끊긴 짜임선·모서리 윤곽이 이어지도록 만든다. 색만 맞추거나 독립 생성 그림의 비슷한 찢김으로 대체하지 않는다.
플레이어 입력: 기존 E09_PIN_TIME_confirmed 뒤 player_requests=목도리_끝_대조로 나란히 비교. 현물 핀·상처 조각을 목도리에 붙이지 않고, 목도리를 가져가지 않는다.
확인 범위: 기존 E09_SCARF와 감쌌다는 할머니의 진술. 그것만으로 치명 접촉의 시각·책임·고의를 확정하지 않는다.

4. 방 배치 / 두 손 / 목도리 핀의 시간
근거: MS14_D08_S02_L0024–L0034, L0043; MS14_D09_S03_L0025–L0033, L0050. 보호 인계 원본: MS14_D07_S04_L0018.
문 아래 틈·문 가까운 침대 끝·책상 옆 상처 발생 위치를 같은 평면과 일관된 축척으로 제시한다. 도토가 잡은 다람의 왼손, 아랫조각을 든 오른손, 문 쪽 웅크린 자세, 문을 받치는 나비가 성립해야 한다. 도토의 관찰 범위는 아이와 두 손이며 방 안 타격자는 보이지 않는다. 아빠가 먼저 아이 손을 이어 잡은 뒤 도토가 놓는 기존 인계도 유지한다.
플레이어 입력: 기존 방 살펴보기에서 세 위치와 관찰 범위 확인. 수첩에서 ‘첫 비명 때 동행’과 ‘첫 비명 후 핀 재착용’을 별도 줄로 기록해 나비에게 읽어 준다. 손을 잡기 시작했을 때 계단참 목도리에 핀이 있었다는 증언과 획득한 방 기록을 대조한다.
확인 범위: E08_ROOM_REACH는 위치 확인, E08_CHILD_POSITION은 연속 양손 관찰, E09_PIN_TIME/E09_PIN_HANDOVER_TIME은 나비 증언으로 출처를 유지한다. 증언 재구성을 객관적 촬영 장면으로 제시하지 않는다. 나비가 주방 이후 행동까지 본 것으로 그리지 않으며 손가락 상처로 시각을 확정하지 않는다.
실제 맵/거리는 미확인이다. 실제 배경·스프라이트로 도토의 시야, 아이 손의 책상 도달 불가, 나비의 문 지지, 보호 손 인계가 동시에 성립하는지 검수한다. 임의 거리 수치나 새 사각지대를 확정하지 않는다.

5. 오답·힌트·재열람과 정답 노출 제한
기존 힌트 연결: MS14_D08_S02_B002/L0038(문·책장·도토 위치), MS14_D08_S03_B002/L0029(손잡이·깨진 면·고리), MS14_D09_S02_B003/L0027(수리 부분), MS14_D09_S03_B004/L0037(목격 범위).
‘첫 비명 동행도 거짓’ 입력은 MS14_D09_S03_B003/L0035–L0036으로 정정하고 미해결 관찰로 복귀한다. D8–9에 없는 실패 대사·판정 상태는 추가하지 않는다. 비교 입력 전에 관찰 결과 대사를 자동 재생하지 않는다.
오답/힌트/재열람은 0분, 획득 완료한 증거만 열람한다. 과거 기록을 보며 현재 인물을 새로 현장에 출현시키지 않는다. source/assembled/접촉면 기술도는 제작용이고 정답 전에 공개하지 않는다. 자동 결합·정답 화살표·범인명·치명 접촉 결론으로 답을 주지 않으며 D10 제출·논박을 앞당기지 않는다. 살인 전용 파손·상처 구리선·핀 단서는 예방 경로에 생성하지 않는다.

6. 현재 후보의 부족분과 승인 조건
D10_candlestick_pin_concept.png는 v1.0 기반 미술 후보다. 천/핀/고리의 정확한 관통과 구리 끝/파단면의 동일 접촉면이 미완이며 최종 증거 그림으로 승인할 수 없다. 현재 묶음에는 위 요구를 충족하는 윗·아랫조각 비교, 목도리 결손 쌍, 방/양손 시야 최종 화면이 없다.
geometry/D10_wire_main·fragment·comparison은 공유 원형의 2D 구리선 연결 기준일 뿐이다. 최종 픽셀 미술에서 동일 경계·선을 보존하고 두 조각을 독립 변형하지 않는다. 도형의 일치는 천/핀 결합이나 현실 상처 발생의 물리 검증이 아니다.
