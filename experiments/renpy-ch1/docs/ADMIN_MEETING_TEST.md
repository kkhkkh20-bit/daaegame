# 관리자 회의 바로 테스트

## 사용하는 방법

1. 기존 방법으로 관리자 도구를 켜고, 마을 화면 위쪽의 `관리자`를 누릅니다.
2. `다음 진행 조건`에서 `회의 바로 테스트 (진행 보존)`를 누릅니다.
3. 이번 수정은 맨 위 `C2 · 아이가 친 촛대 때문에 죽었다`에서 확인합니다. C1/C3/C4도 선택할 수 있습니다.
4. 실제 회의의 발언 듣기, 자료 제시, 반론, 결론 선택을 그대로 사용합니다.
5. 오른쪽 위 `테스트 종료 · 다시 선택` 또는 Esc/뒤로가기로 회의 선택창에 돌아갑니다. 같은 회의를 다시 누르면 초기 테스트 상태에서 시작합니다. 선택창과 관리자 창을 닫으면 원래 진행으로 돌아갑니다.

## 테스트 조건

- 본편 날짜를 넘기는 이동 기능이 아니라 Ren'Py Replay를 사용합니다.
- 기존 회의 QA의 7일 저녁 식당 사건 발생 상태에 기반합니다.
- 모든 자료와 밤이의 증언 동의를 테스트용으로 제공합니다. 선택한 논점보다 앞선 C 논점은 완료 상태입니다. C2의 경우 C1이 완료되어 있어 통로에 관한 되받아치기도 나옵니다.
- 선택한 논점의 발언은 아직 반박되지 않았으며 정답을 자동 선택하지 않습니다.
- 선택한 논점만 실행합니다. 판결, 후속 사건, 엔딩, 영화 장면으로 넘어가지 않습니다.
- 본편 상태와 저장은 Replay가 보존합니다. 테스트 중 자동저장 요청 및 게임의 읽은 대사 기록 추가를 차단합니다. 테스트 결과/자료는 본편으로 가져오지 않습니다.
- 폰트, 기존 회의 화면과 자료/반론 규칙, 관리자 접근 방식은 바꾸지 않습니다.

## 검증

`python3 -m unittest discover -s dev -p 'test_admin_meeting.py'`

8개 순수 Python 검사: 선택 목록, 독립된 초기 상태, 모든 C 논점 진입 가능, 재시작 상태, C2 새 E08 대사와 C1 기반 반격 조건, 자동저장 차단/일반 동작 유지, 읽은 대사 기록 보호, Replay/종료 연결.

이 검사는 Ren'Py 실행 결과가 아닙니다. 배포 전 전체 `dev/check.sh`, Ren'Py lint 및 실제 화면 검증이 필요합니다.

### 실제 실행 확인 목록

- 기존 저장이 있는 게임에서 현재 날짜/장소/자료/논점과 저장 슬롯 메타데이터, 읽은 대사 기록을 기록한다.
- C2를 선택하여 E08 반박, E35 반박, E09 또는 E10 반박 후 반격의 오답/정답을 확인한다.
- 자료 선택창을 취소하고 다시 연다. 대화 중 및 자료 선택 중 테스트 종료로 돌아간다.
- C2를 다시 선택하여 이전 테스트의 반박/결론이 남지 않았는지 확인한다.
- C1/C3/C4도 선택하고 결론/포기 후 선택창으로 돌아오는지 확인한다.
- Esc/휴대폰 뒤로가기, 완료 화면 종료, 반복 클릭 후 관리자 창과 본편 복귀를 확인한다.
- 본편 상태, 저장 슬롯, 게임의 읽은 대사 기록이 진입 전과 같은지 확인한다. 일반 회의에서는 기존 자동저장이 계속 동작해야 한다.
- 화면 크기/큰 글씨 두 설정에서 종료 버튼과 기존 회의 조작이 겹치거나 가려지지 않는지 확인한다.
