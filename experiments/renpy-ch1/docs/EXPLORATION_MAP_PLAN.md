# 조사 맵 확장 기준

첫날은 입구에서 자동 이동하지 않는다. 입구·광장·여관만 열고, 플레이어가 이동을 선택한다. 여관에서 할머니에게 말을 걸어 방을 받은 뒤 복도와 13호실을 연다. 이동과 일반 조사는 시간을 쓰지 않는다. 다른 장소는 다음날 열린다.

맵 길이는 인원수보다 조사 구역 수로 정한다. 빈 공간이나 같은 배경을 늘려 숨길 곳을 만들지 않는다. 주민은 일정에 맞춰 배치하며 넓어진 맵에 맞춰 추가하지 않는다. 좌우 이동은 드래그만 사용한다.

| 장소 | 목표 너비 | 조사 구역 | 우선순위 |
| --- | --- | --- | --- |
| 13호실 | 1800 | 책상·서랍 / 침대·엄마의 생활 흔적 / 창가·짐 | 1 |
| 공동 창고 | 1920 | 접수 장부 / 작업대 / 보관 선반 | 2 |
| 우체국 | 1800 | 접수대 / 분류 작업대 / 반송품 보관 | 3 |
| 광장·여관 | 기존 1920 유지 | 배경과 조사 지점의 시각적 일치 점검 | 유지 |
| 학교·수리점 | 기존 1800 유지 | 일거리와 정보 획득 구역 연결 | 유지 |
| 복도·통로 | 기존 크기 유지 | 이동 공간에는 불필요한 조사거리를 늘리지 않음 | 유지 |

확장은 원화를 새로 구성한 뒤 배경·사물 클릭 영역·인물 발 위치·이름표·확대 조사 화면을 함께 맞춘다. 첫 화면에서 다음 조사 구역의 일부가 보여야 드래그할 이유를 알 수 있다. 방 전체 지도나 발견 전 단서 표시는 두지 않는다.

각 주요 장소는 핵심 단서 1~2개, 의미 있는 생활 관찰 2~3개, 작업/증언과 연결되는 재조사 지점 1개를 목표로 한다. 단순 클릭 수가 아니라 읽기 → 기록 → 다른 사람에게 제시하거나 기록끼리 비교하는 연결을 검증한다. 초회차에는 숨은 출입구를 노출하지 않는다.

이 문서는 확장 설계이며 신규 배경 제작 완료를 뜻하지 않는다.
