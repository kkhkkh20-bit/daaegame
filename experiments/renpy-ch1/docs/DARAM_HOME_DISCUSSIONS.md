# 13호실의 다람이 · 0.17.22-dev

다람이는 숙소에서 부녀가 알고 있는 사실과 각자의 생각을 나누는 동료다. 정답 조합이나 다음 목적지를 안내하지 않는다.

- 방을 얻었고 다람이가 아빠와 함께 있거나 구출된 상태면, 오전·오후·저녁 모두 숙소에 표시한다. 구금된 다람이를 방에 복제하지 않는다. 기존 사건 이후 임시 객실과 숙박 규칙도 보존한다.
- 13호실 오전은 침대에서 책 읽기, 오후는 책상 옆 바닥에서 수첩에 그림 그리기, 저녁은 침대 곁 살펴보기. 이미 있는 깊은 갈색 그림을 사용한다. 실제 의자에 앉는 전용 그림이 없는 자세를 의자 위에 붙이지 않는다. 마을 NPC의 이동 애니메이션은 추가하지 않는다.
- 다람이를 직접 클릭하면 기존 대화 화면에서 질문한다. 일상 질문은 항상 가능하고, 엄마의 메모/흔적, 봉투 목격담, 두 편지를 실제로 얻은 경우 관련 질문이 열린다.
- 사건 당시 기억은 사건 발생 후, 재판 뒤 마음은 재판 후, 난방 문제는 둘째 주 위기 시작 후에만 이야기한다. 엄마와의 재회 대화는 둘째 주이면서 실제 합류 상태일 때만 나온다. 날짜 도달만으로 재회를 가정하지 않는다.
- 다람이는 보지 못한 범행이나 읽지 않은 봉투 내용을 말하지 않는다. 일과 주민 도움을 증언 구매처럼 설명하지 않는다.
- 질문을 읽어도 돈·시간·증거가 바뀌지 않는다. 상태에 맞는 질문의 읽음 표시는 저장된다. 시간대·날짜·소유 자료·사건·판결·엄마 합류 상태가 달라지면 다시 대화할 수 있으며, 옛 대사를 오늘의 상황으로 오인하는 날짜 기록 재생을 사용하지 않는다.
- 기존 `오늘 찾은 걸 같이 볼까?` 기록 비교는 유지한다. `어디부터 살펴볼까?`의 목적지 안내는 상황별 대화로 대체한다. 방에서 초반 자료를 비교할 때 기존 진행 조건은 보존하고, 결과 문구에서는 다음 목적지/제시 명령을 제거한다. 첫 주 사건 전의 방 안 안내는 행선지 명령 대신 현재의 의문을 표시한다. 실제 날짜/이동/도구/소지품 규칙은 최신 0.17.18-dev를 보존한다.

검증: `dev/test_daram_home.py`의 정보·분기·읽음·저장·조회 불변성 검사. `dev/qa_daram_home.py`는 실제 플레이에서 획득한 첫날 후 방 상태와 명시적인 시간/분기 테스트 상태를 구분한다. 실제 클릭·질문·저장/불러오기·모바일을 확인한다. 전체 14일 재미 검증으로 취급하지 않는다.
