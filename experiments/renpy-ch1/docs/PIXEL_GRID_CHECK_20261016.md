## 고친 것 (0.18.93)

- 3px·2px 격자 인물은 원래 저해상도 텍스처(`폭 // 격자`)를 원래 폭으로 다시 늘렸다.
  - 예: 133칸을 400px에 그리면 약 130칸마다 한 줄이 4px가 됐다.
- 이제 정확히 '칸 수 × 격자' 크기로 그린다. 그림 상자는 최대 격자−1 픽셀 작아지고, 발이 닿는 아래쪽 끝은 그대로다.
- 고친 뒤 3px 인물은 1.00, 2px 인물은 0.98~1.00이다.

## 확인됐지만 해결되지 않은 것 (완료 아님)

1. **인물마다 화면 격자 크기가 다르다.**
   - 대화에서 묶음 인물은 한 칸이 4px 또는 5px이다. 다람·밤이·나비·초롱은 5, 나머지는 4다.
   - 그 밖의 인물은 3px 격자다. 질문 화면처럼 같은 장면에 두 종류가 나오면 픽셀 크기가 섞여 보인다.
   - 원인: 인물마다 화면 키를 맞추면서 가장 가까운 정수배를 고르기 때문이다.
   - 맞추려면 전원을 같은 k로 고정해야 한다. 그러면 화면 키가 인물마다 최대 ±20% 달라지므로 결정이 필요하다.
2. **3px 격자 인물의 원본 셀은 정수배로 옮겨지지 않는다.**
   - 화면 블록은 고른 3px이지만, 블록 하나가 원본 그림의 셀 몇 개를 nearest로 집어 온다.
   - 사자 선생님 새 표정 5장
     - 1/2로 줄여 셀 하나 = 파일 1px이다. 그다음 1.095배 보정과 화면 배율이 곱해져 셀 하나가 약 1.24 화면 px가 된다.
     - 3px 블록 하나에 셀 약 2.4개가 들어가서, 일부 원본 셀은 합쳐지거나 빠진다.
   - 너울(1/2, 보정 없음)과 512×768 원본 인물들(셀 크기가 고르지 않은 원본)도 같다.
   - 묶음 인물처럼 정수배로 그리려면 그림 자체가 2×2 셀 원본이어야 한다. 너울과 사자 선생님 표정은 원래 2×2 원본이 있으므로 바꿀 수 있다. 다만 너울 보통 표정(0.18.89 그림)은 2×2가 아니다.
3. **마을 인물 원본은 들여올 때 매끄럽게 줄였다.**
   - `dev/apply_npc_redesign.py`와 `dev/apply_map_actions.py`가 1024 원본을 LANCZOS 0.5배로 줄인다.
   - 화면 블록은 고른 2px이지만, 원본 셀 가장자리에 섞인 색이 남을 수 있다.
4. **배경은 2×2 셀 그림이 아니다.**
   - 2048 원본 자체에 고른 셀이 없고, 0.9375배 nearest로 16열마다 1열이 빠진다.
5. **창과 브라우저 크기**
   - 1280×720이 아닌 창(자동 시험 기본 1098×617, 모바일 844×390, 1920×1080 전체 화면 등)에서는 화면 전체가 정수가 아닌 배율로 한 번 더 늘거나 줄어서, 모든 인물의 블록이 고르지 않다.
   - 정수배 확대와 레터박스를 켜는 설정이 필요하다. 아직 하지 않았다.

## 인물 몸 비율

- 가로세로를 따로 늘리는 곳은 없다.
- 묶음 인물은 `size=(w,h)`가 같은 배율 `s·u`에서 나오고, 2px·3px 격자 인물도 상자 비율을 원본 자르기 크기에서 가져온다.
- 격자 인물은 저해상도 텍스처를 만들 때 폭과 높이를 따로 내림한다(`폭 // 격자`, `높이 // 격자`). 그래서 가로세로 비율 차이가 텍스처 한 칸 이하로 생긴다. 예: 133칸 폭이면 0.75% 이하다. 이것은 원래 있던 성질이다.
- 0.18.93 수정 뒤에는 그림이 최대 격자−1 픽셀(2px 격자는 1px, 3px 격자는 2px) 작게 그려진다.
  - 아래쪽 끝(발)은 그대로 두고 위쪽이 그만큼 내려온다(`yoffset`).
