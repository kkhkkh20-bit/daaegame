## 한눈에 — 무슨 일이 있었나 (정답)

1. 7일 저녁, 13호에서 부엉이 할아버지가 갑자기 정신을 놓고(발작) 다람의 **팔을 붙잡았다.** 다람은 무서워서 촛대로 할아버지 **손을 쳤다.** 촛대는 바닥에 떨어져 두 동강 났고, 다람은 **침대 밑에 숨었다.**
2. 그때 **할머니**가 주방의 쇠 손잡이(레버)를 올리고, **13호 책장 뒤 통로**로 들어왔다. 할아버지가 지키던 **엄마의 기록**을 가져가려고. 할아버지가 막아서자, 할머니는 부러진 촛대 윗동강으로 **할아버지 머리를 쳤다.** 그때 할머니 목도리 **핀**이 촛대 고리에 박혔다.
3. 가족을 이 마을로 부른 **초대 편지**는 엄마가 아니라 **할머니가 엄마 이름으로 쓴 것**이다. 우체국 슬링이 할머니 부탁으로 엄마('부인')의 옛 편지를 따라 써 주었다. 할머니는 엄마를 숨은 곳에서 끌어내려고 가족을 불렀다.
4. 8일 밤, 엄마의 편지를 아빠에게 가져오던 등불지기 **초롱**이 종탑 계단 아래에서 죽는다. 할머니 부탁을 받은 **너울의 사람들**이 편지를 빼앗으려 했고, 초롱은 끝까지 품을 놓지 않았다.
5. 9일 새벽, 통로 길이를 재러 들어간 목수 **따닥**이 통로 안에서 얼어 죽는다. 누군가 주방 레버를 **내려** 통로 문을 닫았다. 따닥이 새벽에 들어간다는 걸 미리 들은 사람은 **할머니**다.
6. 할머니는 끝까지 다정하다. 할머니에게도 이유가 있다(아직 다 밝혀지지 않는다). 그리고 할머니 손녀 **토실**이 그 회의를 보고 있다.

| 2 | 할머니 "손잡이야 누가 지나가다 건드렸겠지. 새벽 주방엔 【늘 토실이가 불을 넣는단다】. 그 어린 게 안에 사람이 있는 줄 알았겠니." | 따닥의 말 | 아빠 "따닥 씨가 그 전날 제게 말했습니다. '내일 새벽에 통로를 잰다. 할머니께도 말씀드렸다.' 안에 사람이 있다는 걸 아는 분은 할머니였습니다." |

**2번 — 토실**
```
(지문) 할머니의 말이 끝나기도 전에, 맨 뒷줄에서 의자가 넘어지는 소리가 났다.
토실: 나 아니야!
토실: 할머니가 그날은 새벽에 주방 오지 말라고 했잖아. 그래서 나 안 갔어. 이불 속에 있었어. 나 아니야……!
(지문) 다람이 아빠 다리를 놓고, 토실 쪽을 보았다. 사흘 전 자기가 한 말과 같은 말이었다.
(침묵)
할머니: ……그래. 토실이는 아니란다. 우리 토실이는 그날 이불 속에 있었지.
```
- 따닥이 살았다면 1·2번이 더 쉽다: 따닥 "두 번이나 세게 당겼어요. 쐐기가 아니었으면…… 저는 할머니께만 말씀드렸어요."
- 「따닥의 말」 없이 「내려진 레버」만 있으면: 할머니 "누가 내렸는지는 아무도 모르지 않니." (1번까지만)

**정리 고르기**
- ✔ "손잡이를 내린 사람은 안에 따닥이 있는 걸 알았다. 그걸 아는 사람은 할머니뿐이다."
  ```
  서리: 문은 저절로 닫히지 않았습니다. 안에 사람이 있는 걸 아는 사람이 닫았습니다. 그것을 들은 사람은 할머니 한 분입니다.
  ```
- ✗ "토실이 실수로 내렸다." → 서리 "아이는 그날 주방에 없었습니다. 아이에게 또 짐을 지우지 마십시오." (토실이 운다. 깃발 「토실이 상처받았다」)
- ✗ "따닥은 통로를 너무 많이 알았다." → 서리 "그건 까닭입니다. 누가 했는지가 아닙니다."

### 처절한 순간

```
(지문) 할머니가 천천히 일어섰다. 아무도 할머니를 붙잡지 않았다.
(지문) 할머니는 맨 뒷줄로 걸어가, 넘어진 의자를 세우고, 토실의 목도리를 다시 여며 주었다.
할머니: 토실아. 할머니 없어도 밥 거르지 말렴. 나비 말 잘 듣고. 밤에 무서우면 나비 방에 가렴.
토실: 할머니 늑대 아니지? 그치?
(침묵)
할머니: ……그럼. 할머니는 할머니지.
할머니: (아빠를 돌아본다) 다람이 참 착한 아이란다. 그 애 엄마를 꼭 닮았지.
할머니: 내가 왜 그랬는지는 묻지 말렴. 아이 아버지는 아직 그걸 들을 수 없단다.
다람: (작게) ……아빠. 할머니가 나 그림책 넣어 줬어.
```

### 결정

**(끝까지 갔고, 「촌장의 약속」이 있다)**
```
촌장: 증거대로 하겠다 했소. ……너울, 할머니를 모시오.
너울: ……. (오래 서 있다가) 할머니, 가시지요.
(지문) 할머니는 너울의 팔을 짚고 걸어 나갔다. 문 앞에서 한 번도 돌아보지 않았다.
```
→ **할머니 입증 + 집행.** 할머니는 회관 아래 방에 갇힌다.

**(끝까지 갔고, 약속이 없다)**
```
촌장: 말은 다 들었소. ……그러나 여관 어른을 외지 사람 말로 가둘 수는 없소.
촌장: 아이는 풀어 주겠소. 나머지 일은 마을이 알아서 하오.
아빠(생각): 증거는 섰다. 그런데 판결을 집행할 사람이 듣지 않는다. 촌장이 왜 이렇게까지 버티는지, 먼저 알았어야 했다.
(지문) 할머니는 토실의 손을 잡고 회관을 나갔다. 토실은 할머니 손을 잡은 채, 할머니를 올려다보지 못했다.
```
→ **입증은 됐지만 집행되지 않는다.** 마을 사람들은 다 들었다. 할머니는 자유다. 토실은 모든 걸 안 채 할머니 곁에 남는다(가장 찝찝한 길).

**결정 — 멈춘 경우** (C2 뒤에 멈췄거나, 증인이 모자라 막혔다)
```
서리: 아이는 풀려납니다. 어르신을 죽게 한 사람은 아직 밝혀지지 않았습니다.
할머니: 다행이구나. 다행이야. (다람의 볼을 쓰다듬는다) 밤죽 식기 전에 오렴.
아빠(생각): 저 손이다. 그런데 오늘 나는 그 말을 하지 못했다.
```
→ **다람 석방까지만.** 할머니 자유. 토실은 아무것도 모른다.

조건: 회의에서 「할아버지의 탐정 수첩」을 썼다.

```
(지문) 회관 계단. 부리가 낡은 탐정 모자를 들고 다람 앞에 섰다. 모자 끝이 해져 있었다.
부리: 할아버지 거야. 너 가져.
다람: 나 할아버지 때렸는데……?
부리: 할아버지가 그랬어. 탐정은 듣는 사람이라고.
부리: (모자를 다람 머리에 씌워 준다. 너무 커서 눈까지 내려온다) 너는 들었잖아. 할아버지 손이 무서워서 잡은 거라는 거. 나는 그거 몰랐어.
다람: (모자를 밀어 올리며) ……할아버지 손, 아팠겠다.
부리: 응. 근데 이제 안 아파.
(침묵)
다람: 부리 오빠. 나 이거 잘 쓸게. 엄마 찾으면 엄마한테도 보여 줄게.
```
- 수첩을 안 썼다면: 부리는 계단 끝에 서 있다가 아무 말 없이 수리점으로 간다. 모자는 부리가 쓴다.

## 10일 저녁 — 광장, 초롱의 등

조건: 8일 밤 초롱 대신 등을 켰다.

```
(지문) 광장 이름 판에 새 이름 둘이 새겨져 있었다. 초롱. 따닥.
(지문) 판 앞에 등이 하나 놓여 있었다. 그 곁에 늙은 토끼 한 분이 서 있었다. 초롱을 닮은 귀였다.
초롱의 어머니: 그 애가 밤마다 들고 다니던 등이에요.
초롱의 어머니: 그저께 밤에 그 애 대신 켜 주셨다지요. 동쪽 등 셋. 우리 집 창에서 보였어요. 그 애가 돌아온 줄 알았어요.
초롱의 어머니: (등을 아빠 손에 쥐여 준다) 그 애가 늘 말했어요. 남의 소식을 전하는 건 그 사람 하루를 지켜 주는 일이라고.
다람: (등을 받아 든다. 두 손으로) ……따뜻해.
다람: 할머니. 초롱 언니가 우리 엄마 편지 지켜 줬어. 끝까지.
초롱의 어머니: 그래. 그 애는 그런 애였단다.
```
- 등을 켜지 않았다면: 이름 판 앞에 꺼진 등잔 조각만 있다. 초롱의 어머니는 아빠를 보지 않고 지나간다.
- 초롱이 살았다면: 초롱이 다람에게 등을 쥐여 준다. "오늘은 다람이가 켜 볼래?" 다람이 등을 하나 켠다. 따닥의 이름만 판에 있다(따닥도 살았다면 이름 판에 새 이름이 없다. 다람 "오늘은 안 읽어도 돼?").
- 따닥이 죽고 톡이 풀려났다면: 판 앞에 톡이 따닥의 줄자를 놓고 간다. "도면은 내가 마저 그려요."

## 결과 정리

| 결과 | 다음에 |
|---|---|
| 다람 석방 | ⑤에 다람이 함께 간다. 다람은 탐정 모자를 쓴다(수첩을 썼다면) |
| 할머니 입증 + 집행 (촌장의 약속 있음) | 할머니 구금 → ⑥에서 명령서의 손을 밝힐 때, 할머니가 갇힌 방에서 쓴 글씨가 대조 증거가 된다. ⑤에서 토실은 심부름을 하지 않는다. 토실은 나비가 맡는다 |
| 할머니 입증, 집행 안 됨 (약속 없음) | 할머니 자유. 마을은 다 들었다. ⑤에서 할머니가 토실을 시켜 엄마를 쫓고, 토실은 알면서 간다(가장 아픈 길) |
| 다람 석방까지만 (멈춤·증인 부족) | 할머니 자유 → ⑤에서 토실을 시켜 엄마를 쫓는다. 토실은 아무것도 모른다 |
| 초롱이 산다 (너울의 말 + 바둑이) | 엄마의 온전한 편지. ⑤에서 엄마를 찾는 길이 하루 빨라진다. 초롱이 결말에서 이름 판 앞 등을 켠다 |
| 초롱이 반쯤 산다 (바둑이 없이) | 초롱은 진료소. 편지는 할머니 손에 → ⑤에서 엄마의 은신처가 먼저 들킨다 |
| 초롱이 죽고, 아빠가 등을 켰다 | 초롱의 어머니가 초롱의 등을 준다. 결말에서 다람이 그 등을 이름 판 앞에 놓는다 |
| 초롱이 죽고, 등을 켜지 않았다 | 젖은 편지 한 줄만 남는다. 광장 동쪽 등 셋이 끝까지 어둡다 |
| 따닥이 산다 (수첩+레버 + 톡의 쐐기) | 따닥이 C5에서 직접 말한다. 따닥이 통로 도면을 끝내 ⑤의 옛 시설 길이 하루 빨리 열린다 |
| 따닥이 반쯤 산다 (톡 없이) | 따닥은 살지만 두 손을 못 쓴다. 도면은 끝나지 않는다 |
| 따닥이 죽고 톡이 풀려났다 | 톡이 따닥의 도면을 마저 그려 옛 시설 길을 연다(⑤를 하루 앞당김) |
| 부리의 수첩을 썼다 | 부리가 할아버지 탐정 모자를 다람에게 씌워 준다 |
| 밤이가 말했다 | 밤이가 처음으로 어른들 앞에서 자기 이름으로 말했다. ⑥에서 밤이가 밤눈으로 길을 본다 |
| 나비가 말했다 | 나비가 할머니 품을 떠난다. 할머니가 갇히면 나비가 여관 부엌과 토실을 맡는다 |
| 토실이 핀을 말했다 / 토실을 몰아세웠다 | 토실이 다람을 피한다. ⑤ 토실의 고백이 늦어진다. 제단 뒤 이름 판 장면에서 토실이 먼저 다람 손을 잡지 않는다(다람이 잡는다) |
| 탐정단이 없었다(②를 안 했다) | 다람은 사흘을 혼자 보냈다. 석방 뒤 다람이 아빠 손을 한동안 놓지 않는다. 밤 대화 "아빠, 나 혼자 있었어" |
| 회의에서 C2까지 못 갔다 | 다람은 보호실에 남는다 → 11일 긴 밤을 보호실에서 보낸다(⑤ 시작이 막힌다. 다시 하기를 권하는 결과) |
