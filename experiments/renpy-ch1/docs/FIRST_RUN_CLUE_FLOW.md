# 초회차: 엄마를 찾는 첫 조사

## 플레이 흐름

첫날은 입구의 원본·명부 조사부터 진행한다. 다람이에게 물어보고 두 기록을 함께 비교한 뒤 경비에게 예약 원본을 제시해 동행 등록을 바로잡는다. 등록이 끝나도 입구에 머물며, 광장 → 여관 → 13호실은 직접 이동한다.

처음 만나는 인물은 현재 하는 일과 다람이의 반응을 먼저 읽고, 말을 걸지 선택한다. 거절하면 만남 기록이나 방 배정은 생기지 않는다. 말을 걸면 기존 첫 인사와 맥락에 맞는 질문 목록으로 이어진다. 할머니도 이 흐름을 거쳐 방을 부탁하는 질문을 직접 선택해야 방을 받는다. 첫날 질문을 일괄 숨기지 않고 기존 날짜·단서 조건을 따른다.

방을 받은 뒤 책상 확대 화면의 종이를 눌러 메모를 읽고, 이불의 바느질 흔적을 조사한다. 메모는 대사가 끝난 뒤 기록된다. 같은 종이를 다시 읽어도 중복 획득하거나 시간이 흐르지 않는다.

다람이의 ‘오늘 찾은 걸 같이 볼까?’는 기록 비교를 연다. 초대 편지와 엄마의 메모를 직접 골라 비교하면 엄마도 가족이 도착할 것을 알고 있었다는 추론을 정리한다. 이 비교는 선택 사항이고, 직접 하지 않았다면 밤 대화에서 완료한 추론처럼 말하지 않는다.

메모를 할머니에게 제시하면 ‘등불을 돌보는 사람’이 초롱이라는 것을 알아낸다. 첫날 밤은 이름을 알아냈는지에 따라 대사가 달라진다. 13호실의 ‘자기’를 직접 선택해야 다음 날이 된다.

둘째 날은 까로에게 마차를 물어보고 생활 일거리를 연다. 엄마의 메모를 초롱에게 제시하면 ‘아내를 마지막으로 어디에서 보셨습니까?’가 열린다. 이 후속 대화를 끝까지 읽으면 J02 ‘초롱이 마지막으로 본 엄마’를 얻는다. 초롱이 본 것은 우체국 쪽으로 걸어간 방향이지 우체국 안에 들어가는 장면이 아니다.

우체국에서 J02를 제시하면 세련이 가족을 확인할 자료를 요청한다. 초대 편지와 엄마의 메모를 각각 제시하면 ‘아내가 여기서 무엇을 찾았습니까?’가 열린다. 후속 대화를 읽으면 J03 ‘세련이 확인한 엄마의 방문’을 얻는다. 엄마는 반송품을 물었으나 당시에는 도착하지 않았다. 그 이후 행선지는 확인되지 않는다.

J02와 J03을 기록에서 비교하면 실제 방문으로 확인된 구간과 아직 모르는 구간을 구분할 수 있다. 이후 주민들의 일을 도우며 다음 목격자를 찾는 기존 캠페인으로 이어진다.

## 제약

- 이동, 일반 조사, 제시, 기록 비교는 오전·오후 일할 시간을 쓰지 않는다.
- 초롱·세련의 증언은 제시만으로 자동 획득하지 않는다. 열린 후속 질문을 직접 읽어야 기록된다.
- 현재 위치와 획득한 단서에 따라 기존의 짧은 현장 안내 문구만 갱신한다. 별도의 강제 안내 화면은 추가하지 않는다.
- 다람이에게 어디부터 살펴볼지 물으면 현재 조사 진행에 맞춰 답한다.
- J01 ‘나비의 등불지기 이야기’는 일을 돕고 나비에게 질문하는 별도 정보 경로로 유지한다.
- 3일째의 기존 미전달 봉투 분기, 사건 이후와 2주차 분기는 덮어쓰지 않는다.
- 새 초회차 표시가 없는 옛 캠페인 저장에는 새로운 조사 분기를 열지 않는다.

## 검증 범위

순수 상태 테스트로 미소유 기록 제시/비교, 두 가족 자료 제시 조건, 증언 획득 경계, 기존 3일째 봉투 해금과 이전 캠페인 분리 조건을 확인한다. 브라우저 검증은 새 게임부터 직접 이동·확대 조사·비교·제시·잠자기·둘째 날 증언 확인·저장/불러오기·모바일 기록 화면을 대상으로 한다. 전체 14일 캠페인의 모든 분기를 완주한 검증은 아니다.
