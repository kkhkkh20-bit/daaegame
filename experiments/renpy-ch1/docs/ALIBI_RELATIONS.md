# 관계도와 알리바이 대조 (0.18.79)

- 소유자 요청: "이벤트와 로직이 치밀해야 해. 사람들이 정신없으면서 퍼즐을 맞춰 가는 느낌, 관계성."
- 구현: `game/systems/room13_alibi.rpy`. 장소별 이유는 `game/systems/room13_place_reasons.rpy`, 일과표는 `docs/SCHEDULE_14D.md`.
- 회의·재판 코드와 기록·증거는 바꾸지 않았다. 아래 진술을 회의에서 쓸지는 회의 담당 채팅이 정한다(7절).

## 1. 원칙

1. 사람은 이유가 있어서 그 자리에 있다(장소별 이유 113개).
2. 대본이 이미 묘사한 시각에는 일정이 대본을 따른다(사건 시각 고정표).
3. 그 시각 같은 장소에 있던 사람은 서로의 증인이 된다.
4. 관계(가족, 빚, 고용, 감싸 주기) 때문에 거짓말하거나 말을 아끼는 사람이 있다.
5. 맞지 않는 말 두 개를 모으면 모순이 되고, 수첩에 남는다.

## 2. 사건 시각 고정표

| 시각 | 인물 | 주간 일정상 위치 → 고정 위치 | 이유 |
|---|---|---|---|
| 1일 저녁 | 토실 | 여관 → 숲 | 할머니가 차를 들려 엄마 발자국을 따라가게 했다 |
| 1일 저녁 | 칼바람 | 집 → 숲 | 덫을 보고 오다 우는 토실을 여관에 데려다줬다 |
| 4일 저녁 | 부엉이 할아버지 | 식당 → 13호(복도) | 할머니와 약속한 물건 전달. 사건 당사자 |
| 4일 저녁 | 은호·구슬 | 여관 → 창고 | 납품 장부 마감. 서로 알리바이 |
| 4일 저녁 | 백 부인 | 여관 → 자기 창고 | 매일 오던 여관에 이날만 오지 않았다 |
| 4일 저녁 | 우박 | 여관 → 진료소 | 서리만 먼저 뛰어가고 진료소를 지켰다 |
| 4일 저녁 | 토실 | 여관(식당 쪽) → 여관 뒷방 | 할머니가 일찍 자라고 했다 |

- 주간 일정을 그대로 두면 사건 장면에 나오지 않는 사람 다섯 명이 사건 시각 여관에 있게 된다. 그래서 고정했다.

## 3. 알리바이 질문

물어볼 수 있는 때: 첫날 밤은 2일째부터, 사건 저녁은 5일째부터(사건이 난 경로).

| 시각 | 인물 | 말 | 관계 때문에 |
|---|---|---|---|
| 첫날 밤 | 할머니 | 접수대를 지켰다. 토실은 일찍 재웠다 | **거짓**. 손녀를 숲에 보낸 것을 숨긴다 |
| 첫날 밤 | 토실 | "자고 있었어요" → 두 번째 심부름을 들킨 뒤 "숲에 갔어요" | 할머니를 감싼다 |
| 첫날 밤 | 칼바람 | 숲에서 우는 토실을 여관까지 데려다줬다 | 묻는 사람이 없어 말하지 않았을 뿐 |
| 첫날 밤 | 현이 | 할머니가 부엌에서 보온병에 차를 담아 갔다 | 소문을 노래로 파는 사람 |
| 사건 저녁 | 할머니 | 식당에서 손님들과 내내 같이 있었다 | **거짓**(재판 C3 주장과 같음) |
| 사건 저녁 | 현이 | 국만 뜨고 부엌으로 가서 안 돌아왔다 | |
| 사건 저녁 | 달그락 | 초저녁에 한 번 지나갔다. 비명 뒤 "공구 가지러" 부엌 뒷문으로 나갔다 | 할머니에게 숙박비를 깎아 받는 처지라 처음엔 조심스럽다 |
| 사건 저녁 | 톡 | 식당엔 할머니가 거의 없었다. 낮에 핀을 달아 드렸다 | 누명을 썼던 사람 |
| 사건 저녁 | 토실 | 뒷방에서, 비명 조금 뒤 빨래방 쪽 벽 안 발소리를 들었다 | 아이라서 본 대로 말한다 |
| 사건 저녁 | 은호 | 창고에서 구슬과 재고를 셌다 | |
| 사건 저녁 | 구슬 | 같이 셌다. 다만 사장은 다른 장부를 따로 들고 있었다 | 고용주를 감싸면서도 흘린다(불법 외상 장부) |
| 사건 저녁 | 우박 | 진료소를 지켰다 | 스승 서리를 감싼다(톡 누명의 원인) |
| 사건 저녁 | 백 부인 | 자기 창고에서 뭉치와 보관함을 셌다. 그날은 여관에 가기 싫었다 | 할머니와 오래 알았다. 하필 그날만 없었다 |

## 4. 대조 (모순이 생기는 짝)

| 짝 | 아빠가 알아차리는 것 | 플래그 |
|---|---|---|
| 할머니(첫날 밤) × 칼바람 | 재웠다는 아이가 그 밤 숲에 있었다 | `alibi_x_night1` |
| 현이(첫날 밤) × 칼바람 | 할머니가 담아 간 보온병 = 숲의 아이가 안은 보온병 | `alibi_x_thermos` |
| 할머니(사건) × 현이 | 내내 식당에 있었다는 말이 맞지 않는다 | `alibi_x_dining` |
| 할머니(사건) × 톡 | 두 번째 증인 | `alibi_x_dining2` |
| 달그락 × 토실 | 부엌 뒷문으로 나간 할머니, 빨래방 벽 안의 발소리 → 벽 안 길 | `alibi_x_wall` |
| 은호 × 구슬 | 서로 알리바이. 그날도 따로 든 장부 | `alibi_x_store` |

- 수첩(조사 메모)에 "첫날 밤, 누가 어디 있었나" "13호 사건이 난 저녁, 누가 어디 있었나"가 생긴다. 물어본 사람과 찾은 모순이 쌓인다.

## 6. 대본에서 찾은 정리할 점

- **너울 이름**: 주민 데이터에는 '왕구', 대사에서는 '너울'이다. 게임 화면은 '너울'로 나온다.
- **실룩의 빚**: 대본은 백 부인에게 진 빚이다. 장소별 이유에 '은호에게 빚'이라고 잘못 쓴 것을 고쳤다.
- **초롱의 어머니**: 주민 데이터에 '자기 어머니를 지킨다'고 되어 있지만 대본에 나오지 않는다. 나중에 이벤트로 쓸 수 있다.

## 7. 회의 담당 채팅에 넘기는 것

- 사건 저녁 할머니의 "내내 식당" 주장(재판 C3)과 맞지 않는 증인 셋이 생겼다: 현이, 달그락, 톡.
- 토실이 들은 "빨래방 쪽 벽 안 발소리"는 기존 증거 E05(통로)·H14(빨래방 문턱 밀랍)와 같은 방향이다.
- 지금은 플래그만 남는다(`alibi_x_dining`, `alibi_x_wall`). 회의에서 증언으로 쓸지는 회의 담당이 정한다.
