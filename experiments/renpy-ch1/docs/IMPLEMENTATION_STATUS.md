# 추천 조합 로컬 구현 현황

기준 main .66: `24ce3b6037093a562f0bd9b1c35c64a9b690a13d`.

## 실제 연결한 범위
현재 시작일은 1일이다. 마차 도착 → 돌목의 인원 오해 → 초소 선반/인물 조사 → 원본과 목록의 실제 제시 → 여관 진입을 독립 구현했다. 구캠페인 자동 이벤트나 위조 편지 사실은 가져오지 않는다. 1일 입장 뒤에도 엄마 연락·재회가 가능하다. native 실행 검증은 아직이다.

제목 화면의 ‘추천 스토리 검증판 · 엄마 B / 피코 C’에서 독립 캠페인으로 시작한다. 엄마 B/피코 C → 밤이 C → 화재 A → 13호 A → 수프 B → 최종 C가 별도 상태로 연결되어 있다. 제목 문구는 첫 진입을 식별하는 문구이며, 후속은 각 사건 완료 후 ‘다음 사건’으로 열린다.

- 실제 장소 지도 → 인물/현장 대상 클릭 → 알고 있는 사실에 따른 질문 → 획득 카드 → 회의 제시/반론/결론을 구현했다.
- 기존 인물·배경·대사/질문 UI·월드 캐릭터 표시·저장 화면을 재사용한다. 기존 사건의 지식/범인/이벤트 로직에는 합류하지 않는다.
- 엄마는 첫 접촉 → 전달 중 장화 말리기 → 현재 답 → 공개 자리 재회로 만난다. 답을 받은 날이 지나면 실제 전달지점 재확인을 해야 한다. 밤 거처 확인은 별도다.
- 피코는 실제 여관 이동으로만 생존한다. 생존/사망 모두 같은 엄마 초상 단서를 받으며, 생존 시 피코가 직접 말한다.
- 학교 실제 인계, 레버 봉쇄, 약 사전 차단 등 예방 성공은 후속에서 되돌리지 않는다. 마지막은 오늘의 보호 인계와 첫밤까지만 판정하고, 확인하지 않은 외부 출발을 완료 처리하지 않는다.

## 세이브 격리
`r13_recommended` 및 `room13_recommended_v1` 캠페인 ID를 사용한다. 기존 저장을 조용히 변환하지 않는다. 추천판 revision이 달라도 자동 변환하지 않는다. 공용 대사 읽음 기록의 키는 `recommended:`로 구분한다.

## 아직 완료라고 할 수 없는 범위
- 공개 main 배포/별도 PR 생성은 하지 않았다. 새 PR 승인은 parent가 확인 중이다.
- 로컬 RenPy SDK 실행 불가. 공식 8.5.3 엔진 CI는 아직 실행하지 않았다. 모든 native testcase는 미실행이다.
- Python 단위/상태/소스 검사는 native 플레이나 화면 검수의 대체물이 아니다. 최신 결과는 `integrated-source-tests.log`를 참고한다.
- 피코 등/천 접촉 및 화재 L/M/W의 exact 원화 정적 검수는 통과했다. 실행 화면·클릭 검증은 별도 False라 최종 합성 gate도 False다. 따라서 현재 두 사건은 부분판정에 머문다.
- 피코 등은 기존 광장 배경의 테이퍼형 매달린 황동 등이다. 갈고리에서 내려 벤치 받침에 놓고 뚜껑을 여는 새 클로즈업은 exact-source 정적 검수를 통과했다. 초기 넓은 받침 도식은 production 제외다.
- 새 R/P/G/K와 냄비 현장 도식의 실제 배경 결합, 변경 사인의 전문·서사 검수, 게임 해상도별 UI 검수는 미완이다.
- 현장 사물은 조사 표식으로 클릭 가능하지만 기존 배경 속 개별 물체 위치와 정밀 결합한 완성 아트는 아니다.

## 관리자/테스트 진입
일반 사용자: 제목 추천 버튼 → 안내 → 새 추천 이야기 시작. 현장 하단 지도/수첩, 인물과 사물 표식으로 진행한다.
관리자: 현장 오른쪽 위 ‘상태검증 허브’는 전역 액션 하네스다. 여기에서 진행한 결과를 일반 현장 플레이 검증이라고 부르지 않는다. ep2~6 admin label과 native fixture의 직접 state setup도 동일하게 구분한다.

## 첫 단면 플레이
지도 → 광장 피코/초롱 낮점검 → 주방/여관 실제 피코 이동 → 수리점 부리 → 기록실 → 광장 초롱 첫접촉 → 여관 장화 말리기 → 광장 현재 답 → 수리점 엄마 → 저녁 → 장부 방 → 여관 가족 자리. 다음날 현장/인계 조사 후 약속한 회의로 진행한다. 엄마 길과 피코 길의 순서는 일부 교환 가능하다.

## 메인 루트의 플레이 깊이 한계
재회는 방문 행적, 최초 연락, 짧은 실제 전달 왕복, 현재 답과 대면 확인을 거치는 짧은 조사다. 지식 순서와 시간 조건은 구현했지만, 여러 경쟁 가설을 플레이어가 비교하는 긴 추론 사건 수준은 아니다. 문답 몇 차례만으로 빨리 재회할 수 있다는 플레이 깊이 한계는 아침 리뷰에 남긴다. 재회 뒤 메인 폴더는 함께 잘 자리·식사와 실제 출발 조건으로 갱신된다. 까로에게 묻는 행동이 마차 축 균열/고갯길 폭설을 알려 주지만 수리와 개통을 실제 완료하는 후속 플레이는 아직 구현하지 않았다. 이 미완료를 후속 사건 일정 때문에 머물러야 한다는 서사로 숨기지 않는다.

- 피코의 엄마 초상(P01)은 승인된 엄마 원본의 실제 얼굴을 판자 프레임에 재사용했다. 그림에 없는 흉터 주장은 제거했다.16개 물건 정체성 묶음은 기존 문서 resolver2개+export14개로 모두 연결했으며, 부품수는 최소23개다. 아이콘 연결 완료는 native 표시 검증 완료와 다르다.

## 피코 회의의 새 판단과 사전 동의 경로
꼬미 조사로는 돌의 이동과 나비의 운반을 알지만, 현재 나비가 쓰는 실제 천을 자동 획득하지 않는다. 정상 회의에서는 나비가 용기·천을 직접 가져와 ‘등 밖에서 주웠고 혼자 운반했다’고 해명하며, 플레이어가 실제 물건을 대조한다. 등 뚜껑을 닫으면 가려지는 내부 금속부의 흔적은 앞선 등 조사에 제시한다. 미리 출처를 질문하고 물건 검사에 동의받는 경로도 열려 있으며, 이미 비교했다면 그 기억을 유지하고 회의의 반복 제시를 생략할 수 있다. 실제 접촉 형상 검수 전에는 직접 반출 판정이 여전히 잠긴다.

천 조각은 동일 원본의 상보 마스크로 구성한다. RenPy AlphaMask가 실제 알파 채널을 사용하므로 RGBA 파생 마스크를 연결했고, 알파 0/255·원본 L 값 일치·두 알파의 상보성은 소스 회귀검사로 확인했다. 엔진에서 두 조각을 실제 렌더한 검증은 아직 하지 않았다.

피코의 천 접촉 시점은 새 명시적 생활 관찰로 연결했다. 꼬미가 2일 저녁 같은 천을 직접 펴서 온전함을 보고 빈 통에 접어 넣어 빌려준다. 돌만 내려놓은 뒤 통과 천은 나비가 계속 대여 중이며 실제 대조 때까지 단독 사용했다고 답한다. 꼬미의 첫 질문과 기록에서 동일 canonical 원본의 온전한 모습을 재구성으로 보여 준다. 이 변경은 기존 소스의 기정사실이 아니라 추천판에 새로 평가·추가한 장면이다. 자백으로 부족한 추론을 완료하는 중간안은 제거했다. 온전한 대여 상태 관찰이 없으면 승인 그림이 있어도 직접 반출 판단을 할 수 없다.

추천 회의의6회차별 진입·실제 발화·질문·정오답·이탈에 연출 어댑터를 연결했다. 그러나 native 미검증이므로 기본 꺼짐이며, 현재 일반 플레이는 단순 배경·대사 경로다. 관리자 시연과 전체 연출 검수행렬은 `MEETING_STAGING_ADAPTER.md`에 설명했다.

천 시점의 최종 세부: 같은 저녁 나비가 천을 풀어 돌을 내려놓는 순간 꼬미는 동일 모서리가 이미 찢어진 것을 보았다. 따라서 이후 배식 중 추가 접촉 가능성과 무관하게 해당 찢김은 대여 전 온전함과 돌 인계 사이에 발생했다. 첫 질문에 전후 관찰을 모두 제공하고, 같은 원본의 온전한 모습/실제 마스크의 찢긴 모습을 두 장면으로 보여 준다. 어느 한쪽의 관찰이 없으면 최종 제시를 거부한다.


격리 QA 새 캠페인은 상태 안에서만 두 미검증 최종 단계 시험을 허용한다. 일반 flags는 바꾸지 않으며 기존 저장을 변환하지 않는다. 정확한 진입과 승격 조건은 `NATIVE_QA_PROMOTION_CHECKLIST.md`에 있다.
