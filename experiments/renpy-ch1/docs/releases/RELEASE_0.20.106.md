# Room13 0.20.106 — 피코와 주민 반응을 본편에 연결

2026-11-06. 소유자가 종합 리뷰 뒤 본편 적용과 3일차 연결 검증을 승인하고, 실제 피코 현장 시안에 「응 시안 적용」이라고 답했다.

## 바뀐 행동

- 2일 피코의 기존 초상 약속을 살리며 아빠·다람·피코의 짧은 감독 놀이와 담요 나눠 들기를 추가했다.
- 3일 사망 확인·미완 초상 인수 뒤, 승인한 공통 수첩 안에서 발견 당시 모습·받은 초상·다람 반응을 원하는 순서로 살핀다. 그림을 접어 설명만 듣거나 바로 떠날 수 있다. 질문을 완료하지 않아도 기존 등 조사로 진행한다.
- 다람이 초상 인수 때 아빠를 붙잡고, 보호생존판에서는 나비가 정리 역할을 배정한다. 톡은 공구를 넣고 다음 질문을 받으며, 부리는 자기 기록을 확인한 뒤 집게 반환을 부탁한다.
- 나비·부리에게는 실제 대면에서 아빠가 사망 확인만 전한다. 전달 완료 후 해당 주민의 청취 표시를 남기며 당일·다음 날에는 짧은 잔향을 보인다. 현재 업무·필수 문답·더 큰 사건이 먼저다.
- 사망 시각처럼 읽히던 질문을 등 소등 시점 질문으로 바꾸고, 점검장 확인보다 먼저 공방으로 가라고 권하던 말을 위치 설명으로 줄였다.

## 보존

생사·사인·범인·정답 조합·승패·초상 상태와 획득 순서·기존 경량화는 유지했다. 별편 전문이나 주민 속마음을 게임에 삽입하지 않았다. 선택 화면에서 새 증거·시간·기회를 얻거나 잃지 않는다.
