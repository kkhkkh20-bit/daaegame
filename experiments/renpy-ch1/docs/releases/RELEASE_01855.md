# 0.18.55 — 자료·보여주기 통합, 이동과 공개 회의 UI

## 플레이어에게 바뀌는 것

- 기록은 자료 / 인물 / 대화로 정리했다. 자료에 증거·증언·조사 도구·상점 물건·빌린 물건이 함께 나온다. 분류와 정렬 버튼, 상시 기록 비교와 별도 아이템 페이지는 제거했다. 조사 메모와 달력은 기록 안에 남는다.
- 물건도 같은 보여주기로 고른다. 상대가 받은 뒤가 아니라, 대화에서 건네기·반납·함께 쓰기를 선택하고 반응을 읽은 뒤 기존 완료 처리가 실행된다. 보여주기만 하면 소모·보증금 반환·도움 기록·보상이 생기지 않는다. 기존 보유·수령인·시간·진행 조건도 유지한다.
- 별도 물건 전달·반납·간식 질문을 숨겼다. 도구와 물건은 UI에서만 통합하고 실제 증거 저장소에 넣지 않는다. 공개 회의에서 근거로 낼 수 있는 것은 기존 증거·증언뿐이다.
- 가까운 이동은 우측 상단의 연결 장소 목록 한곳에 모았다. 문 위·바닥의 중복 이동 버튼을 제거하고 지도는 유지했다. 실제 이동 가능 여부는 기존 조건으로 다시 확인한다.
- 7일째 회의의 주장 선택을 양피지 화면으로 바꿨다. 현재 가능한 주장만 표시하며, 자료가 없는 논점 처리와 판결 순서는 유지한다.
- 7일째·14일째 공통 대결판도 불투명한 양피지와 갈색으로 통일했다. 왼쪽 참석자·발언 목록, 오른쪽 선택한 발언·되묻기·보여주기, 아래 결론·중단 순서다. 집계는 하단 보조 정보로 옮겼다. 자동 안내 대신 선택한 원문을 읽는다. 되묻기 대사·숨은 발언·반박·반론·판정 조건은 그대로다.
- 새 회의 선택 화면에서는 자동 넘기기·건너뛰기가 멈춘다. 회의 중단 확인도 유지했다.

## 개발 계약

`systems/room13_materials.rpy`는 UI 키만 `tool:` / `bag:` 접두어로 구분한다. 실제 소유권은 기존 inventory에서 확인한다. 기존 선물/반납 질문 조건을 전달 가능 조건으로 재사용하고, 동의 뒤에 `r13_finish_topic`을 다시 검증하여 호출한다. 숨긴 예전 화면·비교 모델은 예전 저장의 참조 호환을 위해 남겼다.

0.18.53의 주민 행동 클릭 이벤트와 0.18.54의 빛·그림자 조명 변경을 병합하여 보존했다. 상점 팀은 `SHOP_RESIDENT_HELP_CONTRACT.md`의 갱신된 전달 경로를 기준으로 확장한다.
