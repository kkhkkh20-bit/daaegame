# 0.19.77 — 인물·배경 조사 반응 복구

0.19.76의 검증이 정해진 단서 경로에 치우쳐, 첫 입구의 돌목 클릭과 일반 배경 조사 반응이 빠진 것을 놓쳤다. 4~5일 확대를 중단하고 첫 3일의 기존 조작 연결을 복구한다.

- 첫 입구에서 돌목을 누르면 명단 확인으로 바로 이어진다. 질문이 없는 인물도 기존 대화 화면과 돌아가기로 반응한다.
- 새 대본의 필수 조사 대상만 보이게 했던 필터를 풀어 기존 일반 사물 설명을 복구한다. 이전 대본의 증거/사건 처리는 실행하지 않으며, V1.1.1 기록은 해당 진행 조건에서만 획득한다.
- 편지 펼치기·마차 하차·기록 재열람과 작업 중간의 의미 없는 진행/취소 확인창을 제거한다. 실제 분기와 현장 행동 입력은 유지한다. 기록 재열람은 원래 기록 내용을 일반 대화 클릭으로 읽는다.
- 관계없는 자료 제시 후에도 아무 반응 없이 돌아가지 않고 기존 알림으로 더 확인할 내용이 없음을 표시한다.
- 초기 미디어는 마차와 승인된 시작 인물 자료를 유지하고, 입구의 다른 옛 인물/수첩 그림은 필요할 때 받는다. 이미지·음원 화질을 변경하거나 새 자산을 만들지 않는다. 게임 자료의 첫 다운로드는 약56.3MB → 약35.6MB(약37% 감소), 필수 개별 파일112개 →47개다. 엔진 파일과 기기별 초기화 시간은 별도이므로 모든 기기의 1분 이내 시작을 보장하는 수치는 아니다.

## 확인 범위

- 실제 시작→일반 클릭으로 하차→돌목 클릭→명단 확인→다람의 대화 열기/복귀: 네이티브 통과.
- 새 브라우저의 입구 인물, 일반 배경 두 대상, 서류 조사·제시, 지도 이동과 13호 도착: 통과.
- 변경 관련 단위12건, 로더 복구3건과 단위/lint 묶음 통과.
- 첫 3일 핵심 진행 두 경로 통과. 실제 저장에서 이어 보호/네로 작업, 돌 반환/보관 유지, 출석 의무/구금 인계와 피코·초상·침구 결과를 확인했다. 화면과 실제 재개 지점은 `docs/story-v111/PLAY_REPORT.md` 및 `verification77/`에 있다.

4~14일, 추가 동작 리소스 및 주요 엔딩은 이번 복구의 완료 범위에 포함하지 않는다.

## 기존 자료 그림 연결

새 V111 증거 ID에 전용 그림이 없어 공통 두루마리가 보이던 연결을 복구했다. 초대 편지→기존 초대 편지, 신청 원본→기존 신청서, 규칙→기존 규칙, 처리 명단→기존 명단, 정정 기록→기존 정정 기록을 사용한다. 메모·공구 쪽지·측정지·침구·동의받은 칼도 의미가 맞는 기존 그림을 재사용한다. 초상과 보따리의 기존 연결은 유지한다. 번호가 같은 다른 사건 그림은 자동 복사하지 않는다. 맞는 원본이 없는 파편·돌의 세부 상태 등은 리소스 요청에 남긴다.

## 기존 인물 배치 보존 (추가 요청)

대본에 현재 질문이 없는 기존 주민도 기존 일정·위치대로 표시하고 클릭할 수 있도록 복구했다. 새 대본의 현장 인물을 더하며 기존 배치 순서를 우선한다. 단, 피코의 사망·진료소 이동과 실룩의 구금 같은 이미 확정된 결과는 우선 적용한다. 질문이 없는 주민에게 옛 사건 대사를 실행하지 않으며 기존 대화 화면에서 자료 보기·복귀가 가능하다. 나머지 주민의 새 등장 위치는 사용자 전달을 기다린다.

## 미완료

2일차 광장의 남겨 둔 물건은 주민과 겹쳐 표본 클릭으로 접근하지 못했다(3일차 같은 대상 설명은 확인). 기존 인물 우선 클릭 규칙·배치는 유지한다. 구작 사건 전용 대상 일부는 효과를 실행하지 않고 이름만 표시한다. 나머지 주민의 새 위치는 사용자 전달 대기이며, 4~14일·주요 엔딩·추가 동작 자산은 미완료다. 전체 사물의 모든 픽셀과 선택 조합을 검증했다고 주장하지 않는다.
