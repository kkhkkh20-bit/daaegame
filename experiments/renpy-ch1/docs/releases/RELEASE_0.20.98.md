# 다람탐정 0.20.98 — 마차 중앙 구도와 초소 출발 연결

소유자가 첫 마차 장면에서 대사와 오른쪽 다람의 표정을 함께 보기 어렵다고 지적해, 중앙 좌석을 정면에서 보는 새 배경을 만들고 다람의 얼굴을 화면 중앙에 배치했다.

- 마차 배경을 새로 제작했다. 승인된 착석 표정 8종은 한 번만 축소해 그대로 쓰며 대화·복원·선택지의 좌석 위치를 맞춘다. 창밖 눈 마스크도 새 창틀에 맞춰 재생성했다.
- 하차 대사의 jolt 효과음과 직전 주행음 잔향을 제거했다. 일반 대사의 타이핑·배경음·다른 장면의 효과음은 유지한다.
- 돌목에게 자료를 낸 뒤 여관으로 떠날 때, 너울이 다가와 소개와 인사를 하고 아빠의 방문 목적을 듣는 문답을 넣었다. 돌목을 향한 지시는 몸의 방향을 밝힌다. 지도에서 여관을 먼저 고른 판도 실제 초소 배우 위치를 맞춘다.

생사·증거 정답·입구 등록 결과·엄마의 정보 시점과 기존 저장의 진행은 유지한다. 세부 기록은 `docs/reviews/opening-20261105/`다.
