## B. 부팅 오류 안전 처리

자세한 재현은 `reports/boot-guard-20261015/README.md`에 있다.

- 원인(재현으로 확인)
  - WebGL 렌더러를 만들지 못하면(`Could not set video mode.`) Ren'Py가 오류를 기록만 하고 다음 문장으로 넘어간다.
  - 그래서 이야기가 저절로 입구 화면까지 넘어간 뒤 같은 오류를 끝없이 반복한다. 오류마다 파일을 써서 `FS.syncfs`가 쌓인다.
  - 신고된 탭에서 WebGL이 실패한 이유는 첫 기록이 남지 않아 확정하지 못했다.
- `game/systems/room13_boot_guard.rpy`
  - 렌더러가 없을 때 첫 오류에서 게임을 세운다. 이야기·기록·시간·저장이 그대로 남는다.
  - 화면에 이유를 보여 주고 버튼 두 개를 둔다: '다시 시도'(새로 고침), '실행 기록 받기'.
  - 첫 오류는 `window.r13BootFailure`와 콘솔에 남는다.
- `game/room13.rpy`
  - 입구 화면, 입구 질문 목록, 현장 화면의 결과가 `(종류, 값)` 짝이 아니면 같은 화면을 다시 띄운다.
  - 세 번 연속이면 보이는 오류를 낸다.
  - 정상 결과와 '돌아가기'(`("entry","back")`)는 예전과 같다.
- 건드리지 않은 것: 계정 데이터, 브라우저 보안 설정, GPU 설정, 자동 재시도.

  - 모바일 844×390 터치: 타이틀 → 처음부터 → 도입 → 입구. 콘솔 16줄, 오류 없음.

    - 0.18.68 공개본에서 저장한 1번 칸을 같은 브라우저 프로필에서 이 판으로 불러왔다.
