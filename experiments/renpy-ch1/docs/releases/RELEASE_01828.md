# 0.18.28 · 2026-10-15 — Chef RPG 레퍼런스에 맞춘 UI 구조 재구성

소유자 지시: 기존 스킨을 다듬는 수준이 아니라 화면 구성을 재구성한다. 이어서 **대화 초상화는 제외**하고 회색 돌판의 색면·모서리·겹친 테두리를 레퍼런스에 가깝게 맞추라고 정정했다. 최종 구현은 그 정정을 따른다.

## 최종 구성

- 메인: 중앙 로고 아래 작은 돌판 버튼 5개를 세로로 쌓는다. 이어하기/처음부터/불러오기/설정/기존 음악 출처 기능을 연결했다. 웹 브라우저를 닫는 가짜 종료 버튼을 만들지 않았다.
- 현장: 오른쪽 위에 일차·요일·오전/오후/저녁과 작은 시간대 표식을 놓고, 장소는 왼쪽 위 별도 라벨로 분리했다. 실제 시각/계절/날씨를 새로 만들어 표시하지 않는다. 마차·CG에서는 해당 날짜판을 노출하지 않는다.
- 대화: 별도 초상화 틀 없이, 아래 중앙의 928px 돌판과 작은 이름 띠를 사용한다. 기존 중앙 인물 연출과 마차의 다람이를 유지한다. 아빠는 화면에 그리지 않는다.
- 질문: 인물 초상화를 빼고 선택지 묶음을 가운데 정렬했다. 질문 내용, 읽은 표시와 선택 동작은 보존했다.
- 기록/제시: 왼쪽 분류·도구, 가운데 자료 격자, 오른쪽 그림과 스크롤 상세 정보로 재구성했다. 같은 격자·상세 컴포넌트를 공유한다. 인물·대화 기록, 관심 표시, 발견 순서/최근 순서, 조사 메모·비교·달력·아이템, 이전 여정 자료 열람을 유지했다.
- 자료 제시는 이번 여정에 가진 자료를 직접 선택한 뒤 기존 확인 절차를 거친다. 처음 자동으로 보이는 상세 자료가 곧바로 제시되지 않게 기존 선택 조건을 유지한다.
- 공통 돌판: 녹색/금박보다 중성 회색 면을 쓰고, 큰 판의 깎인 모서리와 두꺼운 명암 테두리를 코드로 그린다. 잡티/노이즈 이미지는 추가하지 않았다.

## 구현 위치

- `room13_reference_composition.rpy`: 시간대 표식.
- `screens.rpy`: 메인/대화. 기존 Room13 외 캠페인의 대화 렌더러는 유지했다.
- `room13_screens.rpy`: 날짜·이동·질문·제시 연결.
- `room13_notebook.rpy`: 3열 기록·제시 공유 컴포넌트.
- `room13_ui_art.rpy`, `room13_title_art.rpy`: 돌판과 버튼 마감.
- `systems/room13_typography_roles.rpy`: 기존 역할별 색은 그대로 두고 회색 판의 불투명도만 조정했다.
- 로딩 화면도 중앙 로고 배치에 맞췄다.

## 검증

- 새 주민 변경과 병합 후 단위 검사 131개 통과. 아빠가 그려지지 않음, 대상/표정 유지, 마차의 대화 대상 제한 검사를 그대로 유지한다.
- Ren'Py compile/lint 및 웹 빌드 통과.
- 실제 Chromium 캡처/결과는 `reports/reference-ui-20261015/`에 둔다. 데스크톱/휴대폰, 기록의 인물·대화 탭, 실제 자료 선택·제시·응답, 옵션 저장 후 이어하기, 큰 글자 기록창을 확인한다.
- 지도는 첫 입장의 이동 제한을 바꾸지 않는 시각 확인용 화면 호출로 점검한다. 전체 14일 회귀는 반복하지 않는다.

이 변경은 스토리 분기, 돈·시간, 증거 판정이나 마을 스케줄을 개편하지 않는다. 이름과 객실번호도 확정 변경하지 않았다.
