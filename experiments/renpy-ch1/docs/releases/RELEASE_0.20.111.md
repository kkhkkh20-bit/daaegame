# Room13 0.20.111 — 화재 사건의 설명 검증과 마지막 별편 압축

2026-11-06. 7일 화재 사건은 누비의 방어 진술을 듣고 가설을 고른 뒤 E06_FIRE로 발화 위치를 대조하는 순서로 바꿨다. 통의 소유나 문 앞 목격만으로 방화를 단정하면 반박을 듣고 다시 고르며 기회는 소모하지 않는다. 기존 정답 자료·자료 오답 기회·자백 이후 책임 구분·승패·생사·결말을 유지한다.

이전에는 자료 제출 이후의 세 질문이 모두 같은 자백으로 이어졌다. 그 메뉴를 없애고 자료 대조의 인용도 실제로 먼저 들은 ‘등잔에서 번졌을 수 있다’는 말로 맞췄다. 발화 위치를 확인해도 누비의 범행·살의를 자동으로 확정하지 않으며, 방화 사실은 기존 자백과 기존 E07_NUBI 획득 시점으로 남긴다. 재조사는 선택을 유지하며 구성공 진입점에는 방어 문답만 보완한다.

13~14일 별편 여섯 편은 반복되는 의미 해설과 운반 문답을 덜었다. 나비의 게임 반응은 추가 세 행을 삭제하고 기존 인수 약속 한 줄을 남겼다. 압축 원고와 분기 매칭, PDF·Word·경로별 묶음을 함께 갱신했다.

변경 범위·검증·화면은 [검수 기록](../reviews/fire-deduction-edit-20261106/검수.md), 읽기는 [마지막 별편](../../../../docs/reading/resident-days1314-20261106/README.md)을 따른다. 자료 대조 UI 개편과 다른 사건 재설계는 이번 범위에 포함하지 않는다.

전체 단위 1,319개·최종 관련 80개·lint·대사 A/B/C·관련 화면 8개와 새 Chromium 첫 로딩을 통과했다. 실제 7일 웹 저장에서 8일 아침까지 화면으로 이어갔고 오류는 없었다. 마지막 기본 PDF는 7쪽이다. 초기 로딩은 전판보다 836바이트 증가한 36,370,350바이트이며 새 에셋은 없다. 14일 전체 재주행·새 모바일 검사는 미실행이다.
