## 보류와 추가 아트

회수 후 room-after 세 장은 흔적 연속성 보류를 유지한다. 나머지 장소는 별도 위치 대조/클릭 검증 후 순차 적용한다. 새 방향 에셋 ZIP과 E01/E07/E06 시안은 Library 경로를 받았지만 다운로드 호스트 CONNECT 403 때문에 아직 픽셀 검수하지 못했다. 적용하지 않았다. `POSE_REQUEST_KO.md`의 기존 ID/제안 ID 구분을 따른다.

원탁의 실제 전신 착석에는 뿔이·부리·나비·보리·토리·콩이의 의자 자세, 도토의 의자 자세, 세련·너울의 방향 맞춘 자세가 필요하다. 현재 각 인물의 중립/바닥 앉기/휴대용 의자를 원탁 의자 자산으로 임의 확정하지 않는다. 표시층은 기존 프로필을 이용한 참석자 자리 배치부터 진행한다.

통합 실검증에서 저장 쪽 버튼이 재사용 화면의 지역 변수를 바꾸지 못하는 문제를 발견했다. file_slots의 쪽 선택을 SetLocalVariable로 고쳐 3쪽×6칸에 실제 접근할 수 있게 한다. 저장·호환 규칙은 유지한다.
