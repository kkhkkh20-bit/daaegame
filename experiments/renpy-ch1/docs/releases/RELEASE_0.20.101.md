# 다람탐정 0.20.101 — 메인·로딩의 마을 그림 제거

소유자 요청으로 메인 화면과 웹 로딩 화면에서 왼쪽 마을 엽서를 제거했다. 남색 바탕에 기존 로고와 오른쪽 캐릭터 스티커를 표시하며, 로고·스티커·메뉴의 배치와 기능은 유지한다.

- 메인 배경의 마을 엽서층을 남색 단색으로 바꿨다.
- 로딩 이미지 생성기도 같은 바탕·로고·스티커로 맞추고 실제 합성 파일을 재생성했다.
- 로딩 그림 주소에 내용 해시를 붙여 예전 지도 표지가 캐시에 남는 것을 막는다.
- 기존 엽서 원본은 이전 참조와 자료 보존을 위해 남겼다. 이야기와 게임 진행은 바꾸지 않았다.
