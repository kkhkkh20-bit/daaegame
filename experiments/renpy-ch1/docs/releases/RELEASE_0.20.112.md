# Room13 0.20.112 — 피코 사건의 관찰·추론·처리 반응 연결

2026-11-06. 소유자 승인으로 3일차 피코 사건을 편집했다. 다람은 시신 곁에서 아빠도 밖에서 자지 않기를 바라고, 미완성 초상에는 그린 사람 이름을 기억한다. 사망 확인은 아침 발견 사실로 한정하며 정확한 사망 시각을 단정하지 않는다.

진료소의 같은 결론으로 가는 중간 질문은 없앴다. 현장에서는 파편 위치와 공구를 들어 올리는 방향을 그림에 남기고, 회의에서 걸쇠만 닫았다는 설명을 플레이어가 먼저 검증한다. 단면·점검 시각만으로 수단을 입증하려 하면 기회 소모 없이 범위를 짚고 다시 고른다. 기존 자료 오답은 기존대로 기회를 소모한다. 수리 미완료와 절도 책임을 구분하며 실룩의 안쪽 흠집 발언은 보조 질문으로 둔다.

실룩을 오늘 돌려보내거나 작업 대기소로 보낼 때 안쪽의 부리에게 직접 알리고 아이들 곁을 확인한다. 대화가 실제 끝난 뒤에만 부리의 청취 상태를 남긴다. 재대면 반응도 들은 결정만 기억하며 아이들의 귀가·식사·인계 완료는 만들어 내지 않는다.

원본 기록·기존 정답 일곱 조합·51개 상태 반영 순서·명단 처리·승패·생사·결말·생존 예방 경로를 유지했다. 새 증거나 그림은 없다. 증거 읽기 UI는 [PC·휴대폰 시안](../../../../docs/reading/piko-case-20261106/README.md)으로 분리해 실제 UI에 적용하지 않았다.

단위 1,324개·관련 43개·lint·대사 A/B/C 0·엔진 화면 시험 11개를 통과했다. 상세 변경·원본 보존·캡처와 웹 확인 범위는 [검수 기록](../reviews/piko-case-20261106/검수.md)을 따른다. 14일 전체 재주행과 인간 초면 재미 검증은 이번 검증에 포함하지 않는다.

웹 첫 로딩은 36,373,426바이트로 전판보다 3,076바이트 늘었다. 선로딩 33개·원격 4,626개·예열 107개는 동일하며 새 그림은 없다.
