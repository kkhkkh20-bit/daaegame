# 0.19.41 — 회의 발언별 원화와 바둑이 저녁 순찰

승인된 회의 원화 여섯 장을 정확한 발언 단위에 연결한다. 앞 발언의 감정/청자 강조는 다음 발언에서 정리하고, 원래 지정된 감정과 동작을 우선한다. 도토의 회의 전체 구도는 정본 smooth 원화를 사용한다. 광장/학교의 전체 구도는 바닥에 발을 맞추고 이름표를 실제 머리 위에 놓는다. 학교 왼쪽 침대와 인물이 겹치지 않도록 전체 구도의 열을 바닥 공간 안에 배치했다.

실제 검수에서 발견한 두 연결 문제를 고쳤다. 새 회의 원화의 offset을 정수 픽셀로 전달하여 RenPy가 상대 좌표로 해석해 발언자가 사라지는 것을 막았다. 나비 E12의 authored anxious 감정은 legacy avatar 표현 distressed로 변환돼도 승인된 witness_hesitate 원화를 선택한다. 대사·증거·결론·일정은 변경하지 않는다.

바둑이의 승인된 등불 순찰 원본만 공통 2px map export로 변환했다. 실제 광장 저녁에 이미 출현한 바둑이의 living_bootlace만 교체한다. 낮 시간, 미출현, 사건 제안, block_cart 등 별도 사건 동작은 유지한다. 어린아이/앉기 배율을 추가 적용하지 않는다. 피코·보리·종종이·도토 새 원화는 최신 직업 소품 보완본을 기다리며 미연결이다.

검증 기록은 docs/reviews/meeting-direction-01941 및 reports/meeting-direction-01941, reports/badook-lantern-01941에 둔다. 패킷 간 rollback은 실제 PageUp 요청 후 현재 패킷에 머물러 여전히 미검증이다. 전체 캠페인 QA를 했다고 주장하지 않는다.
