# 0.20.56

다람이 보호실에 갇힌 8~9일, 부리가 아빠의 임시 짝이 된다(소유자 선택). 이 구간은 아빠 혼자 조사해 웃음이 비어 있었다(8일 기쁨 줄 2/75, 9일 1/57).

- 부리는 할아버지의 죽음을 밝히려는 당사자이고 다람을 의심한다. 아빠가 딸에게 유리한 쪽으로 기울면 짚는다("……아저씨 얼굴이 펴졌어요. 다람이 편 말이라서요?" → 아빠는 걸음으로 잰다).
- 할아버지의 가르침을 잇는다("'믿었다'는 적지 마세요. 본 건 왼쪽, 들은 건 오른쪽").
- 곧이곧대로의 웃음("반의 반이면 몇 명인데요?", "적었어요.", "적어 둘까요? 키 178.").
- 9일 아침 주방 장면에 부리를 세웠다. 9일 식당은 나비가 혼자 털어놓는 장면이라 넣지 않았다.
- 갇힌 다람은 면회 때마다 탐정단 대장으로 보고를 받는다("대장 명령이야. 밥 먹고 다녀").
- 인물 사고방식 카드 기준으로 초롱·네로·세련·까로·나비·할머니의 무색무취한 줄 10개를 고치고, 조연 16명의 카드를 적었다.
