# 0.18.2-dev · 2026-10-14 — 마을 사건 묶음 1 (소유자 지시)

`docs/EVENT_CATALOG.md`의 "3일째 밤 묶음"을 구현했다. 코드는 `game/systems/room13_town_events.rpy` 한 파일이다. 기존 흐름에는 두 군데만 연결했다.
- 장소에 도착할 때: `r13_roam`에서 `r13_town_events`를 호출한다.
- 대화 주제를 고를 때: `R13_TOPIC_LABELS`에 있는 주제는 선택지가 있는 장면으로 보낸다.

## 사건

| 사건 | 언제·어디 | 선택지 | 첫 회차에 흔한 결과 | 아는 사람이 할 수 있는 것 |
|---|---|---|---|---|
| B 솜이의 약 도둑 | 3일 오후·저녁 공동 창고. 오후에 수리점 골목에서 매복도 가능 | 쫓기 4개(지붕 / 수리점 골목 / 왕구 / 모른 척)와, 잡은 뒤 처리 6개 | 지붕을 쫓다 놓침 | 골목 매복. 무쇠 할아버지에게 약을 주면 폐광 지도(H5) |
| C 백 부인의 고액 일자리 | 3일 저녁 여관 접수대 | 거절 / 수락 / 다람이가 방 지킴 / 쐐기 / 검사원 동행 / 숨어서 뭉치 잡기 / 지붕 길(조건부). 모두 7개 | 갇혀서 4일 오전을 잃고, 7냥만 받고, 방이 뒤져짐. 엄마의 경고 봉투(E18)를 가졌으면 할머니에게 샘(`warning_exposed`) | 쐐기로 비축 장부(H1)와 15냥. 검사원 동행으로 감금 기록(H4). 숨어 있다 뭉치의 말(H3) |

- 솜이에게 2일 오후 광장에서 걱정을 물어도 사는 곳(수리점 뒤 골목)과 할아버지 병을 알 수 있다.
- 결과에 따라 이후 대사가 바뀐다.
  - 솜이: 신뢰 / 지붕 길 거래 / 적대
  - 무쇠 할아버지: 회복 / 악화
  - 백 부인: 신뢰 / 적대
- 새 상품: 나무 쐐기 2냥(2~13일). 아이콘을 추가했다.
- 새 기록 H1~H5는 모두 이번 회차 것이고, 1주차 재판의 입증 자료로 쓰지 않는다(정황·2주차용).
  - H1 비축 장부
  - H2 창고 약초 수
  - H3 뭉치의 말
  - H4 감금 확인
  - H5 폐광 지도
- 소문 깃발: `rumor:sold_stolen`, `rumor:strongarm`. 지금은 기록만 하고, 효과는 다음 묶음에서 붙인다.
