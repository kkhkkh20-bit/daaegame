# 0.18.14-dev · 2026-10-15 — 주민은 자기가 겪은 일을 기억한다 (소유자 지시)

코드: `systems/room13_memory.rpy`, 소문 규칙은 `systems/room13_bundle3.rpy`·`systems/room13_carryover.rpy`.

## 바뀐 것
- **좋은 소문 하나가 나쁜 소문을 모두 지우던 규칙을 없앴다.** 예전에는 `rumor:fair`가 있으면 나쁜 소문 목록이 비었다.
- 소문만 들은 사람은 판단을 미룬다.
  - 은호 물건값: 나쁜 소문이 있으면 +1냥, 좋은 소문도 있으면 오르지 않는다(판단 유보).
  - 곰 선생님(2주차 대피소): 나쁜 소문 2개 이상이면 좋은 소문이 있어도 보증인을 요구한다. 대사가 "좋은 이야기도, 나쁜 이야기도 들었어요…"로 바뀐다.
- 직접 손해 본 주민은 좋은 소문이 있어도 차갑다. 지금까지 깃발만 서고 아무 데서도 쓰이지 않던 주민이 많았다.

| 주민 | 그 일 | 바로잡는 행동 |
|---|---|---|
| 피코 | 가짜 그림을 모모에게 알림 | 받은 사례금을 나눠 준다 (3냥) |
| 슬링 | 너울에게 알려 일자리를 잃음 | 너울에게 사정을 전한다 (너울 언짢음) |
| 따닥 | 증축 신고 | 신고 사례금을 돌려준다 (5냥) |
| 여니 | 교환대 물건을 그냥 가져감·장물 신고 | 목도리와 장갑 값을 치른다 (3냥) |
| 나비 | 뒷문 일을 할머니에게 알림 | 아이들 밥값을 낸다 (4냥) |
| 뿔이 | 장부로 압박 | 사과한다 |
| 누비 | 서리에게 알려 장작이 끊김 | 장작 값을 대신 낸다 (4냥) |
| 실룩 | 입막음 값을 받음 | 여덟 냥을 돌려준다 → 실룩이 소문을 바로잡는다 |
| 솜이 | 붙잡히거나 약초를 팔림 | 할아버지 약값을 보탠다 (5냥) |
| 은호 | 저울 일을 광장에 알림 (값 +1냥) | 백 부인 장부(H1)를 보여 사실을 맞춘다 → 남들과 같은 값 |

- 차가운 주민에게 "말을 걸어 본다"를 고르면, 좋은 소문을 들었을 경우 "…는 들었어요. 그래도 …"로 시작한다. 숫자 대신 대사로만 보인다.
- 바로잡아도 도움을 약속하지는 않는다(예: 따닥은 여전히 증언을 거절할 수 있다).

## 검증
- 새 화면 테스트 `memory_grudge`: 여니(좋은 소문 + 피해) → 차가운 대사 → 값 규칙 4가지 → 3냥으로 바로잡기 → 주제 닫힘.
