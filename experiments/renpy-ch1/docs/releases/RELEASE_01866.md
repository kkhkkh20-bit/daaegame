# 0.18.66 · 원탁 깊이와 양옆 시선

모두 정면을 보며 일렬로 서 있던 인상을 줄이기 위해 양옆 참가자는 기존 현장용 옆모습/사선 포즈로, 가운데를 바라보도록 방향을 맞췄다. 가까운 좌우 자리는 조금 낮게 배치하고, 가운데 발언자는 정면 인터뷰 크기를 유지한다. 제단에서도 시선 배치는 적용하지만 원래대로 서 있는 장소다.

여관의 근접 화면은 원탁 뒤쪽 가장자리의 곡선이 대사창 위로 보이는 배경을 사용하고 전경 가림 곡선도 맞췄다. 전체 안건·투표 화면은 기존 배치, 자료 제시와 판단 로직은 유지한다.

검증: 단위 검사·Ren’Py lint·웹 빌드와 실제 Chromium 여관/제단·모바일·전환 후 중앙 정착. 화면은 `reports/meeting-depth-20261016/`.
