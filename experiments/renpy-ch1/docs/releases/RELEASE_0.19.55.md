# 0.19.55 — 배경 직접 조사

물건을 눌러도 선택만 되고 별도 ‘살펴보기’를 눌러야 했던 현장 조작을 수정했다. ‘주변 살피기’에서 배경의 물건을 직접 누르면 기존 조사 장면과 단서 획득이 실행된다. 일반 사각 영역과 인물 앞 소품의 마스크 영역 모두 같은 조사 경로를 쓴다.

배경의 돋보기 표식과 툴팁 돋보기, 중복된 하단 ‘살펴보기’ 버튼을 제거했다. 인물 기본 화면, 지도 이동, 조사 조건과 자료 소유·제시 조건은 기존 규칙을 사용한다.

검증: dev/check.sh와 공식 웹 빌드. 실제 브라우저의 PC/터치로 초소 서류 발견→G1 획득→돌목에게 제시 경로를 확인한다. 상세 결과와 실제 화면은 docs/reviews/direct-investigation-20261018/ 참고.
