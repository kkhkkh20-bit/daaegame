# 0.19.78 — 숲길 마차 컷과 조사 하단 배치

기존 게임의 새 게임 진입 앞에 6.4초짜리 외부 전경을 붙인다. 높은 곳에서 본 마차가 왼쪽 아래에서 오른쪽 위의 작은 산골 마을로 멀어진다. 성벽·도시·탑은 사용하지 않고 기존 입구의 낮은 목조/회벽 집과 나무 문에 맞춘다. 그림 두 장과 Ren'Py 위치·크기 보간만 사용하며 영상 파일이나 엔진을 추가하지 않는다.

- 컷의 건너뛰기/일반 탭은 외부 전경만 닫고 기존 마차 대화로 이어진다. 대사·증거·선택 조건은 유지한다.
- 기존 travel BGM 한 채널과 carriage_ride 주행음을 사용한다. 주행음은 내부로 이어지고 기존 하차 처리에서 멈춘다. 내부의 지속 흔들림은 없으며 대본의 한 번 덜컹임은 유지한다.
- 조사 화면의 지도·기록은 오른쪽 하단에 나란히 둔다. 안내 문장은 왼쪽 최하단으로 내린다.
- 일반 배경 사물의 짧은 관찰문은 하단704까지 내려 표시하며 읽는 동안 도구 모음을 숨긴다. 일반 인물 대화·질문·기록/제시 화면은 기존 배치를 유지한다.
- 캐릭터 원화·등장 일정·대본 분기는 바꾸지 않는다. 기존 인물 우선 클릭 규칙도 유지한다.

## 검증

- 네이티브 `coach_exterior`: 실제 새 게임에서 전경→내부 자동 전환, travel BGM·주행음, pulse 꺼짐 확인.
- 단위 묶음772건 중 기존 대사창 테스트의 store 모형 누락 및 변경한 안내문 기대값을 수정하고 해당8건 재검사 통과. 나머지 묶음에서 다른 실패 없음.
- 공식 웹 빌드 compile/lint 통과. 기존 구작 진입의 도달 불가 경고만 남음.
- 최종 웹 빌드에서 건너뛰기 버튼→기존 내부 대화, 첫 입구까지 일반 클릭 진행, 장작 직접 클릭→하단 관찰문→현장 복귀 통과.1280×720과844×390 터치 화면에서 확인. BGM·주행음의 재생 경로와 pulse 미재생은 엔진 채널 조회로 확인했으며 실제 기기 스피커 청취는 별도다.

## 용량·범위

새 미디어 약1.03MB. 게임 자료 첫 로딩 약36.6MB(이전35.6MB); 약37MB 엔진은 별도다. 웹 core는 기존8MB 분할 전달을 유지한다. 초기 로딩 전체가 일정 시간 이내라는 주장은 하지 않는다.

이번 검증은 시작 컷과 조사 배치 변경 범위다. 첫3일 분기 결과는0.19.77 검증을 유지하며 반복 검사하지 않는다. 4~14일·엔딩·추가 주민의 새 등장 위치와 2일차 광장 사물 겹침은 이번 변경으로 해결하지 않는다.
