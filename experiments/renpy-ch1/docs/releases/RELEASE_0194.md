# 0.19.4 · 2026-10-17 — 지도 반복 질감 정리

소유자 피드백 ‘자글자글 반복된 패턴 빼줘’에 따라 마을·숲/산길 그림을 같은 배치에서 다시 정리했다.

- 눈 덮인 지붕의 촘촘한 평행선, 규칙적인 바닥 돌무늬, 강물의 반복 잔물결을 덜었다.
- 눈과 그림자는 큰 색면으로, 나무의 눈 덩어리와 바위는 더 큰 형태로 정리했다. 건물의 위치·크기와 온도감은 유지했다.
- 발견 전 숲 지도에도 같은 마감을 적용했다. 폐온실·제단은 여전히 그림과 장소 이름 모두 기존 조건에 따라 나타난다.
- 건물 선택 하이라이트를 새 그림에서 다시 잘랐다. 발견 패치의 여백도 넓혀 지붕과 돌계단이 자연스럽게 이어지게 했다.
- 장소 좌표·클릭 영역·이동 확정 방식·사건·자료·진행 조건은 그대로다.
