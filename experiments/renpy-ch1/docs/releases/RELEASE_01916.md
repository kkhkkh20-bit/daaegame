# 0.19.16 — 플레이 리뷰의 기억·약속·증거 반응 수정

인계 브랜치 `6bd5d023`의 대사·분기 수정과 검수 기록 12개를 이어받아 웹 빌드에 반영한다. 이번 추가 수정은 `docs/HANDOFF_20261017.md`의 남은 일 1~3과 숙박비 흔적을 대상으로 한다.

## 변경
- 초롱에게 M01을 바로 보여줘도 엄마를 알아본 사실과 3일 봉투 약속을 기억한다. J04·J05 제시 경로도 같은 약속을 남긴다.
- 다람의 후속 질문·초반 목표·첫날과 2~3일 밤·수첩·달력이 `r13_mother_knowledge`의 같은 사실 판정을 쓴다. 약속 당일 재방문 첫마디가 이어지고, 봉투 위치를 들은 뒤에는 수첩의 질문도 바뀐다. 편지(E18)는 기존 현장 수령을 유지한다.
- 기존 저장 파일의 제시 기록·기존 깃발도 읽는다. 조회만으로 새 깃발을 쓰지 않는다. 사건 뒤나 초롱 사망 뒤에는 지난 약속을 달력에 계속 표시하지 않는다.
- 초롱에게 초대 편지를 제시하면 실제로 확인할 수 있는 범위만 답한다. 초대 편지의 진짜 작성자는 미리 드러내지 않는다.
- 톡은 등 사건이 난 뒤 처음 질문을 받으면 사건 이후 시점으로 답한다. 이미 읽은 대화를 다시 읽는 기록은 유지한다.
- 서리는 온도계·측정 쪽지·노끈·우박 증언·초롱 증언에 서로 다른 반응을 보인다. 제시만으로 새 증거를 주거나 사건을 해결하지 않는다.
- 노끈 발견만으로 '등을 연 사람은 둘'이라고 단정하던 생각·자료 설명·회의 반응을 고쳤다. 목격한 사실과 확인할 추측을 구분한다.
- 여관 체크인·등록의 숙박비 문장을 없앴다. 누비의 별채 제안은 난방·식사로 유인하며, 폐지된 방값 차액을 매일 지급하지 않는다.
- 바뀐 밤 대사에 다람의 표정 연출 위치를 다시 맞췄다.
- 재검사에서 찾은 실제 자동 건너뛰기 오류도 고쳤다. 새 환경에서는 엔진의 `skip_unseen=False`가 전부 빠르게 모드를 막았다. 모드가 켜진 동안만 이 설정을 허용하고 선택지·메뉴·읽은 것만 모드에서 원래 설정을 복구한다. 복구용 값은 이야기 되감기로 사라지지 않는 실행 세션에 둔다.
- 기존 `new_places` 화면 검사는 옛 지도 좌표 대신 현재 이름 위치를 읽어 클릭한다. 이동 결과 단언은 유지한다.
- 초상화 제안 검사 3개의 2일 상태에 미래 사건(`lt_dawn`)을 미리 넣던 준비를 고쳤다. 대사 검사도 옛 10줄 이상 기준 대신 짧아진 대사의 실제 단서와 기존 강조 표시를 확인한다.

- `dev/test_review_knowledge01916.py`: 메모·봉투 목격·보관함 목격 기록의 1~3일 제시 9개 경로, 기존 저장의 기억, 미소유 자료, 조회 순수성, 약속 종료, 서리의 5개 반응, 톡의 재독 기록을 검사한다.
- `dev/qa_review_knowledge.py`: 새 브라우저에서 실제 시작 후 17개 격리 상태 검사를 실행한다. 별도로 소유 메모가 있는 현장 상태를 설정하고, 일반 제시 화면을 실제 클릭해 대사·수첩·달력을 확인한다. 이 후반부는 상태를 준비한 화면 검사이며 자연 플레이 전체를 뜻하지 않는다.
- `review_knowledge01916`, `review_poc_promise01916` 화면 검사: 첫날 및 2~3일 밤에 봉투 약속을 기억한다. `shortcuts`도 자동 건너뛰기 수정 뒤 다시 통과했다.
- `dev/check.sh`: 단위 검사 전체 통과, Ren’Py lint 통과.
- 표준 화면 회귀 128개: 재검사까지 모두 통과. 처음 실행은 121개 통과였고, 아래 항목을 수정·재검사했다.

  - `dialogue_expand`: 대사를 짧게 고친 요구에 맞춰 단서와 기존 강조 표시를 검사.
  - `skip_modes`: 읽지 않은 대사 건너뛰기의 실제 오류 수정 후 통과.
  - `ep_art_tour`: 임시 160초 제한을 넘겼으나 저장소의 400초 기준으로 다시 실행하여 통과(약 162초, 71장면).

- `dev/test_skip_unseen01916.py`: 사용자 설정이 참/거짓인 양쪽에서 전부 모드, 읽은 것만 모드, 메뉴 10종 및 외부 중단 후 설정 복구를 검사한다.
