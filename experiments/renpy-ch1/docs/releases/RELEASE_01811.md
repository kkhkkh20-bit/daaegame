# 0.18.11-dev · 2026-10-14 — 1주차 새 사건 3개: 엄마의 흔적, 벽 속의 길, 재판 전의 유혹 (소유자 지시)

코드는 `game/systems/room13_week1_cases.rpy`다. 사건 목록 6절의 결정은 다음과 같이 했다.
- L 가짜 편지: 할머니의 4일 저녁 계획을 바꿀 수 있다. 새 결말은 만들지 않고, 사건이 일어나지 않는 기존 흐름으로 이어진다.
- T 거짓 증언: 재판에 나오면 반드시 깨진다. 촌장이 판결 집행을 거부한다.
- 소문은 결말에 넣지 않는다.

## ① 엄마의 흔적

| 사건 | 언제·어디 | 선택지 | 이어지는 것 |
|---|---|---|---|
| G 피코의 초상 | 2~3일 낮, 광장 | 모모에게 알림(사례 6냥) / 모른 척 / 엄마 초상 의뢰(5냥) / 구운 밤 / 그만 | 엄마 초상을 슬링·초롱에게 보여 주면 엄마를 본 사람이 나온다. 2주차 답장이 이틀 빨라진다 |
| L 슬링의 편지 | 2~4일 낮, 우체국 | 모른 척 / 현장에서 잡기(H9) / 너울에게 알림 / 달래기(3냥, 초상을 보여 줬으면 무료) | 모른 척하면 경고가 할머니에게 샌다(2주차 추적). 잡거나 달래면 편지가 안전해지고 2주차 추적을 떼어 준다. 이어서 **가짜 편지**를 흘릴 수 있다 |
| 가짜 편지의 밤 | 4일 저녁 | 할머니를 따라감 / 다람이와 방에 남음 | 할머니가 여관을 비워 그날 사건이 일어나지 않는다. 따라가면 초롱과 함께 할머니의 계획을 보고, 2주차 계획 입증의 증인 조건(`prevention_witness`)이 생긴다 |

- 4일에 잠을 자서 저녁으로 넘어가도 가짜 편지의 밤이 먼저 나온다.
