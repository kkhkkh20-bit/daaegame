# 0.18.73 · 제단 회의 내용·판정 점검

제단의 F1~F4 발언, 자료가 입증하는 범위, 실제 대피 준비, 결론 선택과 엔딩 조건을 정본 및 실행 코드와 대조했다.

## 발견과 수정

- F2는 낮의 첫 실험(E23)만으로 ‘오늘 밤 버틴다’는 결론까지 갈 수 있었다. 다른 방법의 존재(E23)와 저녁 부하에서의 재실험(E24)을 별도 발언으로 나눴다. E24는 낮→저녁의 서로 다른 부하와 시각, 기술자·기록자가 남은 실제 관찰 상태도 확인한다. 연구 해석(E30)은 실험을 대신하지 않는다. 에너지가 새로 생기거나 영구 운전한다는 결론은 계속 오답이다.
- F3의 대피소(E25)·물자(E26)는 기록과 함께 실제 shelter_ready/supplies_ready를 요구한다. 인력 확인을 준비 전에 되물었을 때는 pressed를 남기지 않는다. 실제 교대 인력과 환자 운반 준비 후에 다시 확인해야 완료된다.
- F4의 만남 기록(E17)은 엄마가 가족에게 경고했다는 것을 입증하지 못한다. ‘연락하려 하지 않았다’는 발언으로 모순을 분명히 하고, 경고 봉투(E18)를 근거로 받는다. E17은 만남까지만 확인하는 보조 응답으로 제한한다. C4가 이미 입증된 경우 사전 분리 논점을 인용하는 기존 경로는 유지한다.
- 결론 라벨에서도 모든 필수 발언의 입증을 확인한다. 실제 관찰 검사를 좋은 결말의 추가 조건과 공유하고, 없거나 불완전한 관찰 자료는 오류 대신 미충족으로 처리한다. 일반 사전과 Ren’Py 저장용 사전을 모두 처리한다.
- 자료 묶음 메타데이터를 실제 발언의 범위와 맞췄다. F2는 추출 기록(E21 또는 E22)+낮 관찰(E23)+저녁 관찰(E24), F4는 편지(E01)+사전 분리 요청(E16)+경고 봉투(E18)다.

## 정상 확인

F1의 일부 회복은 전원 완치가 아니다. F2의 잔량 집약은 새 에너지 충전이 아니다. F3는 학교·식량·장작·교대 인력·환자 운반을 실제로 준비해야 한다. 공개 의견은 입증과 준비를 대체하지 않는다. 진범 판결/예방 입증, 연구 원본 보관, 증인 보호 등 좋은 결말의 추가 조건을 유지한다.

## 검증

단위 테스트 187개, 회의 대상 테스트 26개, Ren’Py lint 및 웹 빌드. 실제 Chromium에서 F2의 낮 실험만 가진 경우, E24 종이만 있는 경우, 정상 재실험, 과도한 결론 거부, F3의 기록만 있는 경우/인력 미확인/실제 준비 후 확인, F4의 만남 기록 거부/경고·사전 요청에 의한 입증을 검사했다. 엔딩은 단위 테스트로 E1/E3/E4/E5/E6의 관문을 대조했다. 브라우저는 명시적 14일 상태를 사용했으며 전체 14일 플레이 검사는 아니다.
