# 0.19.52 — 학교 직접 대화와 협동 장면 배치

- 학교 세 아이의 별도 함께 놀기 버튼을 없애고, 아이 직접 클릭 → 해당 아이 첫 응답 → 기존 함께 노는 대사로 연결한다. 개인 사건/강제 장면 우선순위와 날짜·생활 조건, 시간 비소모를 보존한다.
- 학교 세 아이를 하단·우측 버튼에서 떨어뜨리고 여관 토리를 예니와 더 떨어뜨린다. 작업실 접점과 승인 이미지 원본은 유지한다.
- main 0.19.50 현장 단순화(기본 사람 보기, 지도 이동, 주변 살피기 토글)를 함께 반영한다. 삭제된 여관 이동 버튼을 위한 이름표 회피 예외도 제거한다.
- 회의 실제 영상은 reports/game-motion-20261018에 별도 기록했다. 초기 회의 상태만 fixture이며 영상 구간은 실제 입력, 무음이다.

검증과 자연 진행 범위는 최종 검토 보고서에 기록한다. 자연 진행과 장면 fixture 검증은 구별한다.

최신 main 0.19.51 질문 발견/빈 대화 안내 기능도 보존하여 통합했다.
