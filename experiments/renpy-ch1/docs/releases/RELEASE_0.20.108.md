# Room13 0.20.108 — 7~9일 주민 별편과 반응

2026-11-06. 소유자의 이어가기 요청에 따라 4~6일 다음 7~9일을 다룬다. 주민 9명의 별편 9장면을 쓰고 본편의 같은 시점에 추가 27행·기존 인수 지문 1행 개정을 연결했다.

- 선생님은 막내의 직접 대답을 기다리고, 누비는 자백이 어떻게 적혔는지 따지며, 보리는 생존 꼬미에게 빈 그릇부터 맡긴다.
- 서리는 아이가 소매를 정리할 시간을 확보하고, 치료받아 살아난 부엉이는 종이를 직접 들고 다람과 함께 본다. 초롱은 비밀 내용 대신 봉투의 인수만 확인한다.
- 부리는 유족으로서의 질문을 지키고, 톡은 수리품을 보게 하며, 세련은 맡긴 사람과 작성자의 구분을 고집한다.
