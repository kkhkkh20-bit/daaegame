# 0.18.22 · 2026-10-15 — 입구 서류는 대화로, 펼치는 궁금증, 생활·손 조사 화면 8종, 소유자 화면 피드백

0.18.21(PR #9: 전신 표정·지도 v5·여관 이동 칩) 위에 쌓았다.

## 1. 마을 입구

- **서류 팝업 제거.** 두 서류를 화면에서 한꺼번에 받던 방식을 없앴다.
  - 돌목에게 "이름 목록이 다른 이유"를 물으면, 그가 직접 명단을 보여 준다. 이때 옮겨 쓴 이름 목록(G3)을 얻는다.
  - 초소 선반을 누르면 짧은 장면이 나온다. 아빠가 월요일 묶음에서 우리 예약 원본(G1)을 찾는다.
  - 까로의 증언에 "예약 서류는 초소 선반 월요일 묶음에 끼워 두더라"는 한 줄을 더했다.
- **다람이 위치.** 초소 창 안에서 잘려 보이던 그림을 없앴다. 다람이는 이제 마당 가운데에 전신으로 서 있다.
  - 이전처럼 눌러서 대화할 수 있다.
  - 관련 파일: `room13_entry_window.rpy`, `room13-world-layout.json`의 gate.

## 2. 13호와 침대

- **다람이 위치.** 오후에 책상 옆 가방 위에 앉아 있었는데, 이제 침대 앞 깔개에 앉아 그림을 그린다. '자기' 버튼과 겹치지 않는다.
- **첫날 침대.** 아직 잘 수 없는 상태에서 침대를 누르면 이전에는 아무 안내가 없었다.
  - 이제 "침대에서 잠자기 · 아직은 아니다. 책상 위를 먼저 살펴보자"가 비활성 버튼으로 보인다.
  - 이불을 아직 보지 않았다면 "이불부터 살펴보자"가 보인다.
- **물건 메뉴 패널.** 선택지 수만큼만 커진다. 버튼 하나 아래에 빈칸이 남지 않는다. 선택지가 4개 이상일 때만 스크롤이 생긴다.
- **침대 밑 설명.** "작은 아이가 웅크릴 공간이 있다"는 문장을 지웠다. 사건보다 먼저 결과를 암시했기 때문이다. 이제 "어둡고 먼지가 얇게 앉아 있다"로 보인다.

## 3. 대화

- **다람 질문 정리.** "오늘 찾은 것을 같이 보자고 한다"를 없앴다. 기록 버튼과 역할이 겹쳤다.
- **질문 번호 고정.** 질문은 여러 층에서 앞이나 가운데에 끼워 들어가서, 같은 질문의 번호가 바뀌곤 했다.
  - 이제 처음 나타난 순서를 회차 상태(`topic_order`)에 기억한다.
  - 새 질문만 맨 아래에 붙는다. 관련 파일: `systems/room13_topic_order.rpy`.

## 4. 조사 메모 펼치기

- 필드 왼쪽의 궁금증 한 줄 옆에 ▼과 개수를 붙였다.
  - 누르면 열린 의문 목록이 펼쳐진다.
  - 항목을 누르면 조사 메모가 그 카드를 펼친 상태로 열린다.
- 조사 메모 카드는 처음에 제목과 '모르는 것' 한 줄만 보인다. 누르면 펼쳐진다.
- 목록에는 조사 메모의 '지금 궁금한 것'에 있는 행만 나온다. 일반 사건 표시(!)를 목록에 합치는 작업은 하지 않았다.

## 5. 책상 서랍 퍼즐 표시

- **탁본.** 아스키 화살표를 쓰던 크림색 사각형을 바꿨다.
  - 이제 반투명 종이 위에 연필 결이 보인다.
  - 눌린 자리만 밝은 선으로 남는다. 판 윤곽, 아래 반원 홈, ①↓, ②→이다.
- **홈을 누른 상태.** 자가 홈에 걸려 있고, 판 가장자리에 금색 모서리 표시가 생긴다.
- **도구칸이 열린 상태.** 판의 왼쪽 띠가 오른쪽에 남고, 안쪽은 어두운 칸으로 바뀐다. 돋보기가 그 안에 보인다.
- 누를 수 있는 물건에 마우스를 올리면 금색 모서리가 보인다.
- 아이템 버튼에 아이콘을 붙였다.
- 정식 그림 요청서: `docs/ART_REQUEST_01822.md`.

## 6. 여관 접수대

- 토리는 자기 의자에 앉아 천을 꿰맨다. 기존 activity 포즈다.
- 따닥은 출입문 옆 벽 앞에서 판자를 망치질한다. 기존 living_repair 포즈다.
  - 대기 구역에 서 있으면 모두 서 있는 자세로 바뀌던 규칙에서 둘을 뺐다(`pinned`).
- 따닥의 판자가 문틀에 실제로 붙어 보이지는 않는다. 전용 포즈와 배경 레이어를 요청서에 넣었다.

## 7. 생활 조사 화면 3종 (소유자 제공 `room13-map-assets.zip`)

- **그림.** 원본 무손실 WebP 6장을 그대로 복사했다(1672×941, 합계 7.7MB).
- **공통 화면.** `screen r13_life_closeup` 하나를 쓴다. 물건을 살펴보거나, 쓸 물건을 고른 뒤 대상을 누른다.
  - 전후 그림은 실제 상태가 바뀐 순간에만 교체한다.
- **배달**
  - `r13_delivery_inspect` 메뉴를 그림 화면으로 바꿨다.
  - 그대로 둔 것: 짐표 문구, 얹어 보기 반응, 가진 물건 시험, 까로 끈 허락, 일당·1회 보너스·시간.
  - 묶으면 배경이 '묶인 짐' 그림으로 바뀐다.
- **여관 현관 문틈**
  - 조건: 2일째부터, 낮, 할머니가 접수대에 있을 때. 여관 현관(door)을 누르면 열린다.
  - 진행: 천을 누르면 할머니에게 짧게 허락을 받는다. 천을 고른 뒤 문 아래 틈을 누르면 천이 놓인다.
  - 결과 상태(`inn_draft_sealed`)는 이번 회차 동안 유지된다.
  - 돈, 증거, 시간 보상은 없다.
- **식당 배식**
  - 회차에서 첫 주방 일을 할 때 한 번만 나온다.
  - 비어 있는 파란 잎 무늬 자리를 누르면 국과 빵이 채워지고, 쟁반의 빵이 2개에서 1개로 줄어든다.
  - 그 뒤에는 기존처럼 "맡은 일만 마친다"와 질문 중에서 고른다.
  - 다음 주방 일부터는 기존 메뉴만 나온다.
- **하지 않은 것**
  - 국과 빵을 따로 옮기는 중간 상태는 없다. 받은 그림에 중간 상태가 없기 때문이다.
  - 문틈 장면에 난로는 넣지 않았다.

## 8. 손으로 확인하는 조사 3종 (소유자 제공 `visual-gimmicks.zip`)

- **그림.** 원본 무손실 WebP 7장을 그대로 복사했다(`assets/r13-gimmick-*.webp`).
- **유지한 것.** 기존 아이템 사용 활동 세 개의 장소, 필요 물건, 날짜, 시간 비용, 보상을 그대로 둔다.
  - 그림을 여는 것만으로는 끝나지 않는다. "내용을 읽는" 단계에서만 활동이 끝나고, 시간 비용과 보상이 적용된다.
  - 중간에 닫으면 시간이 들지 않는다. 진행 상태(`room13["gimmicks"]`)는 이번 회차 동안 남는다.
- **포장천 자루** (`use_knife_burlap`)
  - 아래쪽을 누르면 단단한 판이 손에 닿는다(보상 없음).
  - 작업칼로 실밥을 끊으면 나무 덮개가 보인다.
  - 덮개를 손으로 들면 내용물이 보인다.
  - 내용물을 누르면 기존 대사가 나오고 `hidden_stock`이 켜진다.
- **손등불** (`use_lantern_rear`)
  - 등불을 들기 전에는 화면이 어둡다.
  - 등불을 들면 포인터 주변만 둥글게 밝아지고, 문턱·벽 밑·계단 밑을 볼 수 있다.
  - 문턱을 본 뒤 "본 것을 적는다"를 누르면 기존 대사, R02, `soot_trail`이 적용된다.
  - 세 곳을 모두 볼 필요는 없다.
- **양팔저울** (`use_weight_scale`)
  - 표준 추를 왼쪽 접시에 올리면 기운 그림으로 바뀐다. 추를 다시 내릴 수도 있다.
  - 가운데 조정부에서 나사의 긁힌 자국을 본다.
  - 두 가지를 모두 본 뒤에만 "본 것을 적는다"가 나온다. 기울기만으로는 끝나지 않는다.
  - 기존 문장의 '바늘'은 그림과 맞지 않았다. 활동 대사와 은호에게 말하는 대사를 '접시가 기울었다'와 '나사 둘레 긁힘'으로 바꿨다.
  - 결과 대사에는 "가게 추의 실제 무게와 누가 돌렸는지는 모른다"는 한계를 적었다.
- **남은 불일치.** 포장 내용물 그림의 고기는 생고기처럼 보인다. 본문은 '말린 고기'다. 본문은 그대로 두었다.

## 9. 손으로 확인하는 조사 2종 (소유자 제공 `visual-gimmicks-02.zip`)

- **그림.** 원본 무손실 WebP 6장을 그대로 복사했다.
- **유지한 것.** 기존 활동의 조건, 시간 비용, 보상, 중복 방지를 그대로 둔다.
- **침대 밑 판자** (`use_knife_under`)
  - 판자를 손으로 누르면 들뜬 끝만 관찰한다.
  - 작업칼로 판자를 들면 접힌 종이가 보인다. 이 단계에서는 M02를 주지 않는다. 칼은 소모하지 않는다.
  - 종이를 누르면 펼친 그림 위에 기존 M02 대사가 나오고, 이때 활동이 끝난다.
  - 다람이와 함께 있으면 "이 도토리, 엄마가 그려 주던 거야." 한 줄을 더한다.
- **광장 돌 탁본** (`use_rubbing_stone`)
  - 탁본 종이를 돌에 대면 종이 그림으로 바뀐다.
  - 종이 위를 누른 채 끌면 지나간 칸(6×4)만 탁본 그림이 드러난다. "한 줄 문지르기" 버튼으로 한 줄씩 채워도 된다.
  - 10칸 이상이 세 줄 이상에 걸쳐 드러나면 "드러난 자국을 살펴본다"가 나온다. 기존 R01 대사가 나오고, 탁본 종이는 이때 한 번만 소모된다.
  - 드러나는 무늬는 추상 그림이다. 해독할 문자가 아니다.
- **웹 로딩.** 확대 조사 배경 19장은 처음 열 때 받는다(`REMOTE_CLOSEUP`). 첫 로딩은 약 89MB로, 이번 그림 추가 전과 같다.
- **검사 범위.** 드래그 문지르기는 자동 테스트로 확인하지 못했다. 버튼으로 문지르는 경로만 테스트했다.
