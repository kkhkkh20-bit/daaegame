# 0.19.89 — 새 세계관 1단계: 회의·명단·돈·엔딩 판정 규칙

기획 문서 「다람탐정 전체 재구성(새 세계관), 2026-10-21」 7장(회의 규칙), 8장(위기와 생활경제), 11장(엔딩 7종)의 규칙만 코드로 옮겼다. 기존 대사, 선택지, 증거, 일정은 바꾸지 않았다. 새 회의 대사와 쟁점 연결은 사건마다 소유자 확인을 받은 뒤 다음 단계에서 붙인다.

## 적용

- 새 파일 `game/room13_v111_newworld.rpy`(init 318). 모든 값은 기존 `r13_v111_set`으로 `room13["v111"]["values"]`에 저장한다. 별도 저장 상태나 화면을 만들지 않았다.
- 회의 11개와 쟁점 47개 표(`R13_NW_MEETINGS`). 관문 쟁점 표시, 제단 회의의 '나머지 둘 이상' 부분 조건.
  - `r13_nw_judge`: 증거 제시 한 번으로 쟁점이 정해진다. 맞으면 won, 틀리면 lost(확정). 사건별로 정한 반쪽 제시는 한 번만 hardened로 다시 연다. 아무것도 안 보여 주고 누르면 잃지 않는다.
  - 관문에서 지면 회의가 바로 끝나고 결과는 lose. 남은 쟁점은 locked.
  - `r13_nw_meeting_close`: win/partial/lose를 `meeting:<회의>`에 한 번만 기록한다. 다시 열 수 없다.
  - `r13_nw_choose`: 가설 고르기, '까닭' 고르기처럼 증거 없이 고르는 쟁점.
- `r13_v111_proof`에 선택 인자 `issue`, `partial`, `hardened`를 더했다. 인자를 넘기지 않는 기존 22곳의 호출은 예전과 같이 동작한다. `issue`를 넘기면 오답 라벨이 반드시 있어야 한다.
- 이송 예정 명단: `r13_nw_list`/`r13_nw_unlist`/`r13_nw_listed`. 다람이 오르면 `daram_wristband`. 13일 수레 출발 `r13_nw_cart_departs`는 내리지 못한 사람을 `departed:<이름>`으로 한 번만 기록한다. 죽은 사람은 타지 않는다.
- 돈(냥): `r13_nw_earn`/`r13_nw_spend`. 같은 일로 두 번 벌거나 두 번 내지 않는다. 모자라면 내지 않는다.
- 황금률: `r13_nw_steal`. 표시는 최대 2, 2가 되면 아빠가 명단에 오른다.
- `r13_nw_loss_count`: 피코, 꼬미, 부엉이, 네로, 도담(늦은 섭취 경로 포함) 가운데 죽은 수.
- 엔딩 판정 순서(생성기 `dev/build_v111_days1114.py`에서 다시 만듦): 남겨진 이름(다람/아빠) → 얼어붙은 마을(사망 넷 이상) → 가족 철수 → 부분 구조(`outcome13=departed` 포함) → 군중 폭력 → 14일 장면. 결과는 `ending14`에 남긴다.
- 진 엔딩 판정은 14일 과자 장면 끝, 저장 안내 앞. 생존 다섯, 기록 인계·가설 문답·담요·제단 회의 승리, 너울 장부 확보(`neoul_ledger_secured`)가 모두 있어야 한다. 지금 이야기에는 이 회의들이 아직 없으므로 열리지 않는다.
- 새 엔딩 3종(남겨진 이름 다람/아빠 변형, 얼어붙은 마을, 진 엔딩 에필로그)의 서술 초안. 아빠 시점 서술만 쓰고 인물 대사창은 쓰지 않는다. 배경은 기존 학교, 광장, 입구 배경을 임시로 쓴다. 전용 그림은 디자인 리소스 요청서(2026-10-21) E01~E04로 요청했다.

## 지금 이야기에 생기는 차이

- 피코, 꼬미, 부엉이, 네로, 도담 가운데 넷 이상 죽은 저장은 14일 아침 기존 엔딩 대신 「얼어붙은 마을」로 간다. 기획 11-1에 따른 의도된 변경이다.
- 그 밖의 경로는 같은 엔딩으로 간다. 명단, 돈, 도둑 표시는 아직 어느 장면도 부르지 않는다.

## 하지 않은 것

- 회의별 쟁점 연결과 '상대 주장 확정' 대사: 사건마다 대사를 쓰고 소유자 확인 뒤 붙인다.
