# 0.20.47 — 3번 등 절도 미수판

2일 저녁 남은 끈을 빌리고 걸쇠를 살펴 고정하면 3번 돌을 빼내지 못한다. 피코는 식당 숙박으로 처리하지 않고 광장에서 살아남는다. 3일은 돌이 남은 현장과 실제 칼 대조, 지급 전 약속을 조사하는 별도 경로로 진행한다.

미수판의 회의와 13일 질문은 실제 얻은 자료로 해결한다. 도난판의 돌 인수·매입 증거를 허위로 주지 않는다. 기존 도난판은 유지한다.

관련 자동 검사 40개·lint·미수판 화면 3개·웹 빌드·브라우저 확인을 통과했다. 상세 범위는 `../reviews/prevention-puzzles-20261025/3번등_구현.md`.
