# 0.20.149 — 시장 물품과 다른 현장 조사 연결

2026-11-10. 기존 포가튼 시티형 탐색 기획의 인물·물건·미래 지식 연결 36개를 현행 코드와 대조했다. 현재 실행되는 연결, 현재 이야기와 충돌하는 옛 제안, 1부 이후에 남은 연결을 [대조표](../design/기존기획_복원대조_20261110.md)에 구분했다.

1부 자유 방문에 장터를 다시 연결하고, 실제 은호에게 남은 끈을 받고 표준추를 빌려 현장에 사용하는 경로를 추가했다. 까로의 두 짐을 살펴 싣는 방법을 정하고 직접 묶은 뒤, 까로와 확인한 방법을 2일 저녁의 등 걸쇠에 응용한다. 기존 무료 끈 조달과 본편의 등 고정·미수 판정은 유지한다. 표준추로 가게 저울을 확인한 뒤 은호에게 재계량을 요구하면 눈금 정정과 영점 확인 경험이 남는다.

물품은 기존 물품 소유권에 저장한다. 가격·노잣돈·수고비를 없앴으며, 같은 물품을 중복 받거나 취소만으로 사용하지 않는다. 표준추는 회수해 재사용하고, 걸쇠를 고정한 끈은 소모한다. 본편 필수 조사와 대화는 물품 선택 때문에 막히지 않는다. 기존 에셋과 공통 수첩 UI를 사용했다.

검증 결과와 한계, 실제 화면은 [149 검수](../reviews/review149/검수.md)에 남긴다. 전체 원안의 구현 완료나 1~7일 자연 완주로 보고하지 않는다. 복원 순서는 [탐색 연계 설계](../design/탐색연계_복원149.md)에 기록했다.

1부 1~7일 메인 대사 466개를 수정해 가족의 불안과 행동 이유, 주민의 질문과 대답을 연결했다. 피코 사망 직후의 조사 질문은 아이의 죽음 확인·위로 뒤로 옮겼고, 학교 인수 뒤의 청취 시점과 구금 장면 표정도 바로잡았다. 대사 조건·증거·회의 정답·생사와 7일 낮 경계는 유지했다. slop-rewrite 가이드 없음 절차와 독립 검수를 적용했으며, 자동 문장 검사에 남은 의도적 중단 대사 경고는 검수 문서에 적었다.
