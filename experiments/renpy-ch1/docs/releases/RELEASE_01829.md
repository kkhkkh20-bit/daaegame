# 0.18.29 · 2026-10-15 — 도트 연출: 벽난로 불꽃, 저녁 눈, 다람이 눈 깜빡임

0.18.28(돌 패널 UI) 위에 쌓았다. 작업은 0.18.22에서 시작해 main을 병합했다. 소유자가 시안(벽난로·광장 눈·다람이 깜빡임)을 보고 적용을 요청했다.
화면 연출만 바꾼다. 시간·증거·관계·일정·대사는 바꾸지 않는다.

## 1. 원칙

- 원본 배경·인물 그림은 한 픽셀도 바꾸지 않는다. 원본 위에 프레임만 얹는다.
- 설정의 '움직임'을 끄거나 건너뛰기 중이면 모든 효과가 멈추고 원본 그림만 보인다.
- 현장 인물은 그대로 정지 포즈다. 입 모양 자동 움직임은 넣지 않았다.
- 함수 덮어쓰기 층을 더하지 않았다. 연결은 두 줄이다.
  - `room13_world_camera.rpy`의 `r13_world_background`: 배경을 키우기 전에 `r13_dot_fx_scene`으로 효과를 얹는다.
  - `room13_fullbody_dialogue.rpy`의 `r13_fullbody_close_art`: 전신 그림을 `r13_blink_art`로 감싼다.
- 코드: `systems/room13_dot_fx.rpy`. 프레임과 좌표: `assets/room13-dot-fx.json`.
- 프레임은 `dev/make_dot_fx.py`가 만든다(시드 고정, 다시 돌려도 같다).

## 2. 여관 로비 벽난로 (아침·오후·저녁)

- 시간대별 12프레임, 초당 9장.
- 원래 그려진 불꽃을 지우지 않는다. 불꽃 픽셀의 밝기만 4px 칸 단위로 위로 흐르게 바꾼다.
- 불꽃 끝 칸은 들어가고 나오며, 불티 세 개가 올라간다.
- 쇠살대·장작(어두운 픽셀)은 항상 원본 그대로 불꽃 앞에 남는다.
- 저녁에만 방 전체에 주황 빛이 불꽃 세기에 맞춰 약하게 일렁인다. 밝기는 4단계로 끊었다(최대 10%).

## 3. 실외 저녁 눈

- 광장·마을 입구·제단 길의 저녁 장면에만 내린다. 아침·오후, 실내는 그대로다.
  - 이야기에서 눈이 언제 오는지(첫눈 자정, 발자국 단서)와 부딪히지 않도록 저녁으로 좁혔다. 넓히려면 json의 `snow.periods`를 바꾼다.
- 먼 눈(4px) 140개, 가까운 눈(8px 십자) 28개가 다른 속도로 내린다.
- 위치는 시간으로만 정해지고(저장할 상태 없음), 매번 4px 칸에 맞춰 원화의 도트 크기와 어긋나지 않는다.
- 광장 저녁 가로등 빛은 두세 번에 한 번 짧게 흔들린다.

## 4. 다람이 눈 깜빡임 (대화 전신)

- neutral·flustered·angry·anxious·surprise 5표정. joy는 원래 눈을 감고 있어 제외했다.
- 반쯤 감음 50ms → 감음 90ms → 반쯤 감음 50ms. 간격은 2.6~5.2초, 표정마다 정해진 순서다.
- 등장 후 1.6초 동안은 깜빡이지 않는다. 등장 직후 화면과 테스트 캡처는 원본과 같다.
- 시안에서 감은 오른쪽 눈 아래로 갈색 털이 크림색 얼굴을 덮던 문제를 고쳤다.
  - 눈꺼풀 위는 눈 위쪽 털색, 아래는 가장 가까운 바깥 색(크림색 얼굴 또는 털)으로 칠한다.
  - 눈썹·속눈썹 같은 검은 선은 색의 출처에서 빼고, 눈 밖에 있는 굵은 선(화난 눈썹)은 그대로 둔다.
- 다른 인물의 깜빡임은 아직 없다. 같은 도구로 만들 수 있지만 표정마다 눈 위치를 사람이 확인해야 한다.

## 5. 검사

- 단위 테스트: `dev/test_dot_fx.py`(프레임 크기·좌표·연결 두 줄·움직임 설정 확인).
- 화면 테스트: `dot_fx`(기본 묶음 밖). 여관·광장·입구·제단 장면과 다람이 깜빡임을 엔진에서 캡처하고, 움직임을 끈 화면도 남긴다.
  - 결과: `$ROOM13_QA_OUT/dot_fx/`.
- 웹판 허브는 화면을 자주 다시 그린다. 장면별 효과 묶음을 한 번만 만들어 다시 쓴다(처음 시안처럼 매번 그림 크기를 읽으면 웹판 입력이 35초 넘게 멈췄다. `qa_carriage`로 잡았다).
- 브라우저 확인: `qa_carriage`, `qa_navigation`, `qa_save_slots` 통과. 웹판에서 여관·광장·입구 저녁 효과가 움직이는 것과 입력 지연(0.1초 안팎)을 확인했다.
- 0.18.28 병합 뒤의 전체 회귀는 소유자 지시로 생략했다(다른 작업에서 다룬다). 병합 전 0.18.22 기준 전체 화면 테스트 73개, 병합 뒤 단위 테스트·lint는 통과했다.
- 추가 용량: 약 270KB(불꽃 시트 3장 약 200KB, 나머지 작은 조각).
