# 0.19.23 — 원화 로딩 실패 처리와 승인 연결

종종이의 `jongjong:work` 아빠 질문과 현이 질문 목록은 승인된 일반 neutral을 사용한다. 정상 경로는 대화용 3px 격자를 통과하지 않는다. 사용자 스크린샷의 실제 브라우저 상태는 확보하지 못했으므로 원인을 캐시 또는 특정 다운로드 실패로 확정하지 않는다.

확인한 두 결함을 보완했다. 웹 로더가 다운로드 예외 뒤에도 실행 의존성을 해제하던 문제를 고쳐, 실패 파일은 최대 두 번 재시도하고 파일 길이도 검사한다. 실패가 계속되면 저장 기록을 삭제하지 않는 다시 불러오기 버튼을 제공한다. 부분 파일시스템으로 게임을 시작하지 않는다. 승인된 대화 원화가 누락되면 같은 승인 neutral의 다른 크기를 사용하고, 모두 없으면 명시적 로딩 실패 안내를 표시한다. 옛 도트 디자인으로 조용히 내려가지 않는다. 회의와 별도 승인 행동은 이 일반 대화 경로와 분리되어 유지된다.

일반 대화 59명·354슬롯·1062개 표시 파일은 그대로다. 최종 transport/ZIP에서 모든 파일의 등록과 실제 바이트를 검사한다. 이미지가 작은 550개는 ZIP 안, 나머지 512개는 preload다. 파일을 새로 만들거나 사용자에게 캐시 삭제를 요구하지 않는다.

식당은 중복된 세 자리를 여섯 바닥 자리로 늘리고 공통 충돌 회피 배치를 사용한다. 실제 2일 저녁 6명 화면을 확인했다. 나비 쟁반과 부엉이 할아버지 수첩을 유지하며, 서 있는 그림을 의자에 억지로 앉히지 않는다. 기존 알파/가구 클릭 마스크를 사용한다. 도토 광장의 없는 행동키는 준비된 수첩 행동에 연결하고, 보호된 밤이는 낮에도 기존 바닥 앉기 동작을 사용한다. 슬링의 웅크린 자세는 접점 분류를 맞췄다.

추가 원화 커밋 `d7a55faa91ca85b4a0665d204187ffdc76367daf`의 6개를 검증했다. 밤이 작은 안도, 초롱의 조심스러운 안도, 꼬미의 자부심, 토실의 혼란 4개만 정확한 대사·화자·행 번호에 연결했다. 일반 6표정 슬롯은 변경하지 않는다. 나머지 2개는 `chorong_mother` 원본으로, 요청된 `mom`과 역할이 달라 보류했다. 새로운 솔방울 현장 행동은 재승인 대기이며 기존 솔방울·실룩 이미지는 보존했다. 돌목의 미제작 입 수정 행동, 피코 침대 휴식·선생님 젖은 코트 및 기타 미제작 현장 동작은 완료로 표시하지 않는다.

검증: 304개 단위 검사와 Ren’Py lint 통과 후 로더 오류/재시도 테스트 1개를 추가하여 통과. 다운로드 단절·잘린 응답·최종 실패 시 실행 차단을 검사한다. 실제 Chromium의 좁은 대화/질문 목록/저장복원 및 식당 화면 검증을 사용하며 전체 게임 재플레이는 하지 않는다. 추가 4표정은 실제 렌더러 fixture로 선택·표시를 확인했고, 배경은 fixture 배경이며 해당 에피소드 전체 플레이 결과가 아니다.

공개 게임 URL의 기존 프록시 403을 재시도하지 않았다. 배포 확인은 GitHub Pages 실행 결과로 한다. 사용자 브라우저에서 발생한 원인이 확정된 것과, 코드상 실패 경로를 재현·차단한 것은 구분한다.

최종 실제 실행 결과: 종종이 질문 목록→아빠 질문→저장복원, 현이 광장 질문 목록이 모두 승인 원화였다. 59명 모든 1062프레임의 runtime loadable이 참이었다. 식당 6명 각각의 실제 얼굴 지점에서 hit target이 그 인물과 일치했다. 질문 목록의 얼굴 가림 배치는 이번 범위에서 변경하지 않았다.
