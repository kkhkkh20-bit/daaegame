# 0.19.71 — 기존 여관·13호실 대사와 증거 업데이트

기존 조사·클릭 게임에 전달 원문의 여관 첫 방문, 마지막 귀가 날짜 재질문, 방의 메모, 책상 아래 보따리, 첫날 밤 대사를 연결했다. 처음 방문과 재질문의 실제 대사 제공자가 서로 덮어쓰지 않도록 기존 두 제공자의 내용도 맞췄다. 날짜를 답하지 않은 원문에서 임의의 날짜나 초대 편지 작성자를 확정하지 않는다.

- 원문 `E06`은 기존 `M01` 메모에 연결했다. 메모를 직접 읽고 기존 획득 함수가 처리한 후에만 기록과 초롱 이름 표시가 남는다.
- 원문 `E30`은 기존 사건 증거 `E30`을 덮어쓰지 않고 `FAMILY_BUNDLE`로 등록했다. 기존 사물의 `need/give/flags/call_label` 처리로만 조사하며 수첩에도 기존 기록·제시 화면을 쓴다.
- 전달 PNG `assets/ms14/bundle.png`는 다시 그리거나 재인코딩하지 않았다. 기존 장소의 소품 목록에 원본 비율로 놓고 사물 클릭 영역과 맞췄다. 원본 alpha 최댓값 254도 보존한다.
- 보따리를 반복 조사해도 기록은 하나만 남는다. 다람에게 보여 줄 때의 반응은 원문의 가족 그림 대사를 사용한다. 주소·숨은 봉투·추가 수신 사실은 만들지 않는다.

음악, 캐릭터, 카메라, 이동, 현장 조사, 수첩·제시 화면의 시스템은 0.19.70과 같다. 별도 MS14 진행기는 새 시작에서 실행하지 않는다. 증거·대사에 붙는 표정 참조와 원문 검수 목록만 새 문장에 맞췄다.

검증 기록은 `docs/story-ms14/validation/01971/`에 보관한다. 단위 테스트 742개와 SDK 직접 lint를 수행했고, 브라우저에서는 처음 시작부터 입구·여관·13호실까지 실제 클릭으로 확인한다. 이번 연결 범위 이후의 신규 대본 전체가 완료됐다는 의미는 아니다. 기존 이불 조사·취침 조건과 이후 사건 구조를 변경하지 않았다.

진행 입력 원칙: 단순 대사 진행은 일반 클릭, 현장 행동은 기존 조사 대상, 장소 변경은 기존 이동, 실제 결정은 선택지에 연결한다. 선택지 수가 하나라는 이유로 일괄 자동 실행하지 않는다. 특히 결과를 바꾸는 행동은 플레이어 입력을 남긴다. 별도 작업 중인 6일차 파일은 이 변경에 포함하지 않는다.
