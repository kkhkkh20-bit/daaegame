# 0.18.39 · 2026-10-15 — 오프닝 컷씬

0.18.38 위에 쌓았다. 소유자 요청: 모션그래픽 컷씬, 오프닝부터.

## 1. 흐름 (약 14초, 새 게임에서 마차 대화 앞)

1. **검은 화면 · 4.2초:** 눈이 내리고 아빠의 독백 두 줄이 타자 치듯 나온다. "여관에서 온 편지 한 통." / "아내가 머물던 산마을로 간다."
2. **마을 입구 · 5.6초:** 입구 오후 파노라마를 마을 안쪽에서 입구 문과 마차 쪽으로 훑는다. 위쪽이 계단식으로 어두워지고 제목 로고와 "눈에 갇힌 마을"이 나타난다.
3. **빈 마차 안 · 4.2초:** 아빠 시점. 마차가 3px씩 덜컹거리고 창밖으로 눈이 스쳐 지나간다. 끝에 크게 한 번 덜컹(삐걱 소리)하면 기존 마차 대화의 "덜컹."으로 이어진다.

- 클릭하면 다음 컷으로 넘어간다. '건너뛰기'는 컷씬만 건너뛰고 마차 대화로 간다(마차 대화의 '건너뛰기'는 예전처럼 입구까지 간다).
- 독백은 기존 대사에 있는 사실만 썼다(여관에서 온 편지, 아내를 찾으러 감). 아빠는 그리지 않았다.
- 그림은 기존 원화만 썼다: 입구 파노라마(오후), 빈 마차 안, 제목 로고. 창밖 눈 영역은 `dev/make_dot_fx.py`가 만든 `room13-fx-carriage-window-mask.webp`.
- 음악은 마차 장면과 같은 여행 곡과 바람 소리를 컷씬부터 튼다(마차 장면에서 다시 시작하지 않는다).

## 2. 설정

- '움직임'이 꺼져 있으면 카메라 이동·흔들림·눈 없이 같은 컷을 정지 화면으로 보여 준다.
- 건너뛰기 중이거나 화면 테스트(`renpy test`) 중에는 나오지 않는다. 기존 테스트는 마차 대화부터 시작한다. 컷씬 확인은 `opening_cut` 테스트(`r13_opening_force`)로 한다.
