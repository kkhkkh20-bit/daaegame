# 0.19.79 — 마차 덜컹임과 과자 농담의 인과 복구

사용자가 마차가 흔들리자 아빠가 바로 '안 잡아 줘?'라고 말하는 흐름을 정리해 달라고 요청했다. 새 대본 실행에서 L0001 행동문이 생략된 채 L0002 아빠 대사에 흔들림만 붙어 있었다.

- 첫 행동문을 실제 진행에 포함한다. 다람을 기존 원화로 먼저 표시하고 이 행동 시점에 한 번 덜컹인다. 아빠 대사에는 흔들림을 붙이지 않는다.
- 순서: 마차 덜컹임/다람이 과자를 두 손으로 감쌈 → '과자는 꼭 잡고, 아빠는?' → '아빠는 안 부서지잖아.' → '넘어지면 아프거든.' → 다람이 다른 손으로 소매를 잡음 → 남은 과자와 엄마 몫 대화.
- '많이 남았어?'를 '과자는 몇 개 남았어?'로 구체화한다. 엄마 몫 하나, 이후 편지·입구·증거·분기 결과는 유지한다.
- 업로드 원문 `v111/records.json`은 보존한다. 승인된 수정6줄만 `R13_V111_CARRIAGE_TEXT`에 명시하며 신규 엔진이나 대본 해석기를 추가하지 않는다.

## 확인

- 단위/lint 묶음 통과.
- 실제 새 게임의 수정 구간만 네이티브 검사: 행동문/다람 표시/행동문에만 덜컹임 큐/아빠·다람 응답/소매 행동/엄마 몫까지8개 확인 통과.
- 공식 웹 빌드 compile/lint 통과. 웹 core8MB 분할 유지. 신규 미디어 없음.
- 최종 웹 빌드0.19.79에서 실제 클릭으로 행동문부터 엄마 몫까지 순서 확인 통과.844×390 터치 화면 캡처: [행동문](../reviews/carriage79/action.png), [아빠 응답](../reviews/carriage79/dad.png), [엄마 몫](../reviews/carriage79/mom.png). 기록은 같은 폴더 report.json.

## 남은 표현 리소스·별도 작업

현재 연결한 다람 원화에는 과자를 감싸거나 아빠 소매를 잡는 전용 동작이 없다. 행동은 지문으로 전달하고 기존 동일 인물 초상을 유지한다. 토리 제작과 겹치는 신규 인물 그림은 생성하지 않았다. 필요한 동작: 앉아서 과자 봉지를 품에 감쌈, 한 손에 과자를 안고 다른 손을 화면 밖 아빠에게 뻗음. 표정은 기존 원화를 사용한다.

외부 마차의 더 낮은 채도·먼 마을 풍경은 별도 연출 조정이다. 이번 판은 대사와 행동의 실행 순서를 수정하며, 그 배경 재설계까지 완료했다고 보고하지 않는다. 첫3일 전체 분기·저장/로드·엔딩을 반복 검사하지 않았다.
