# 0.19.1 — 확정 캐릭터 기본 연결 일치

확정 48명 시트와 승인 rev47을 기준으로 너울·사자 선생님·토실·모모·보리·설이의 기본 대화, 조사 기본 자세, 프로필, 대체 그림을 정본 원본으로 맞췄다. 수정 원본은 재생성하지 않았으며 저장소 원본의 SHA-256을 확인했다. 너울은 흰 코트, 사자 선생님은 도포, 모모는 발굽, 설이는 종을 든 정본이다.

돌목은 승인된 입 수정본을 기본 조사 자세와 프로필에도 연결했다. 다른 5표정과 별도 행동은 그대로 남겼고 입 수정이 끝났다고 표시하지 않았다. 부리 v7, 네로의 회색 털·남색 망토·금색 브로치, 솔방울·굴돌, 백 부인·뭉치 연결은 보존했다. 은색 늑대는 미배정 후보로 유지한다.

토실의 겨울 보온병 및 책을 든 행동, 모모의 등잔 확인, 보리의 장작 묶기, 설이의 종끈 행동은 승인된 별도 그림으로 유지한다. 해당 행동은 직접 그림을 열어 정본의 얼굴·종·의상을 대조했다. 사자 선생님의 이전 조끼 행동 3종은 도포 행동 제작 대기로 기록했다.

구슬·백 부인·도토의 삭제된 행동을 요구하던 장소 설정 6건(일부 시간대별 설정 포함)을 제거했다. 평상시 현재 정본으로 표시하며, 삭제된 행동명을 중립 그림에 붙이지 않는다. 미제작 목록과 원래 요청은 `art/canonical-channel-alignment-20261017/report.json`에 남겼다.

기존 21명과 이번에 정본으로 복원한 너울·사자 선생님을 합한 23명은 5개 감정이 아직 중립 fallback이다. 모든 해당 키에 `fallback: neutral`, `production_status: pending`을 명시했다. 새 표정이나 동작을 생성하거나 완료로 처리하지 않았다. 돌목의 추가 입 수정도 별도 제작 과제다.

표정 파일을 읽을 수 없을 때 현재 정본 중립을 먼저 사용하고, 저장 불러오기 때 대화 이미지 캐시를 비운다. init 58/59와 이후 init 999 등록을 확인했다. 미사용 resident-art/room13-avatars 잔재는 수정하지 않았다.

검증: 48명 모두 4개 주요 채널 등록 확인, 채널 파일 존재 검사, 원본 SHA-256, 승인 행동 보존, 미제작 표시, 없는 표정→현재 중립 fallback 단위 검사. `dev/check.sh` 통과(단위 검사 및 Ren'Py lint). 공개본은 `dev/build_web.py`로 생성한다. 장시간 브라우저/전체 화면 회귀는 이번 범위에서 실행하지 않았다.

재현: `python3 dev/align_canonical_channels.py` 후 `python3 dev/fullbody_centre.py`. 이전 아트 적용 스크립트를 재실행한 경우 이 정렬을 마지막에 실행한다. 원래 연결은 같은 art 디렉터리에 보관했다.
