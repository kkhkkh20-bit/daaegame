# 0.19.45 — 회의 확대 화면의 탁자 높이

사용자 검토에 따라 확대 발언 화면의 원탁 중앙선을 y396에서476, 제단 돌판을432에서476으로 내렸다. 확대 탁자의 가장자리를 y494로 맞추고 부리 제지 원화의 앵커를24px 내려 이동 중 하체 노출을 막았다. 좌석 간 거리·이동 계산은 유지하며, 가슴과 팔·손짓이 더 보이도록 전경 가림을 낮췄다. 배경은 같은 원화를 비율대로 확대해 중앙을 잘랐다(원탁1.2배, 돌판1.1배). 탁자 텍스처에는 위치 이동만 추가했으며 원화 파일·가로세로 비율을 수정하지 않았다. 전체 좌석 화면은 기존 접점과 구성을 유지한다.

실제 C2 대화에서 부리 손바닥/상체, 촌장 stern 문장, 뒤 서리 줄, 저장/불러오기, 자료 열기/취소, 844×390 터치를 확인했다. 별도 renderer fixture로 10발언 구도와 4전체 좌석 화면을 비교했다. 실제 반박의 선택지는 얼굴 아래에 유지되며, 선택 단계의 허리·손 일부 가림은 기존 UI 구성이다. 인물의 다리가 드러나거나 좌석 접점이 바뀌지 않는다. 원화에 없는 옆시선은 이번에 제작하지 않았다.

전체397 단위 검사·SDK lint 통과 후 마지막 가장자리/앵커 조정에 회의66검사·공식 재빌드·실제 화면 재검수를 수행했다. 배포 파일 hash/CRC 확인. 함수 줄 이동으로 OVERRIDE_MAP을 재생성했다. 검토 자료 reports/meeting-framing-01945는 이전/이후 비교와 실제 PNG를 보존한다. 물리 휴대폰·전체 캠페인·회의 packet 간 rollback은 미검증이다.
