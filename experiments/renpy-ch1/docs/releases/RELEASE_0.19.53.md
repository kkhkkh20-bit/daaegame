# 0.19.53 — 첫 사건의 조사와 회의 돌아보기

첫 사건에서 조사 부족과 추리·결론의 미완료를 구별할 수 있도록 했다. 실패 경로, 톡 증언과 진엔딩 조건, 인물 생사와 후속 사건의 손실은 유지한다.

- 획득한 사실에 따라 추리 메모에 미해결 질문을 남긴다. 회의 입장 전 계속 조사할 수 있으며, 완전 조사 조건은 추가하지 않았다.
- 노끈을 제시한 대상에 맞춰 연결이 부족한 이유를 설명한다. 확보하지 않은 대여 사실이나 아이의 증언을 아빠가 인용하지 않는다. 탁본의 기존 반박 경로는 유지한다.
- 톡 구금, 석방·조각 미반환, 석방·조각 반환의 후일담을 구분한다.
- 실제 반박 결과를 돌아보고 선택적으로 사고 방향과 구체적 조사 방향을 볼 수 있다. 전부 반박한 뒤 결론을 내지 않은 경우와 회의 기한을 놓친 경우도 구분한다.
- 회의 직전·조사 시점·완료 결과를 별도 저장한다. 재시도는 당시 시간·돈·자료·인물 상태 전체를 복원한다. 수동 저장을 덮지 않으며 새 회차에 증거나 보상을 넘기지 않는다. 기존 저장에 없는 재시도 지점은 제공하지 않는다.
- 옛 추리 메모의 별도 어두운 화면을 없애고 현재 ‘기록 → 메모’ 화면으로 통합했다. 기존 양피지·글자색·탭·메모 펼치기·닫기를 그대로 재사용한다.
- 회고 선택지에 직전 대사창·인물이 겹치지 않게 장면 상태를 정리한다. 기존 공통 선택지 부품을 사용한다.
- 0.19.50의 현장 조작 개선과 0.19.51의 질문 발견 개선을 병합했다. 제거된 버튼 이름을 참조하던 회의 QA도 현재 이름에 맞췄다.

정본 대조와 판단 근거: [Q1_CANON_REVIEW.md](../Q1_CANON_REVIEW.md). 구현 계약: [Q1_REVIEW_DESIGN.md](../Q1_REVIEW_DESIGN.md). 실제 화면·검증 기록은 [개선판 점검](../reviews/q1-investigation-review-20261018/README.md)에 남겼다.

검증: `dev/check.sh` 통과. 표준 화면 검사 128개는 현재 UI에 맞춘 재검사를 포함해 모두 통과했고, 추가 덮어쓰기 순서 검사도 통과했다. 0.19.51 병합 후 0.19.52에서 첫 회의와 덮어쓰기 순서를 다시 확인했다. 전체 이야기를 수작업으로 재플레이한 검수는 아니다.

브라우저에서 ‘기록 → 메모’와 옛 진입점의 동일 화면, 큰 글씨·작은 화면, 부분 실패 → 선택 힌트 → 회의 복원 → 보관 결과 복원 → 조사 복원 → 실제 추가 조사 → 다섯 논점과 결론 → 조각 반환 → 현장 복귀를 통과했다. 7냥의 재시도 원상 복원과 성공 후 15냥으로 한 번만 지급되는 보상도 확인했다. 0.19.52 학교 대화 변경은 보존했다.
