# 0.19.53 — 질문 영역을 아래로 조정

소유자 지시에 따라 인물 이름·‘묻고 싶은 이야기’ 제목·질문 목록을 함께80px 내렸다. 이름과 제목은 같은150px 기준선이다. 질문1~2개의 칼바람 대화가 화면 상단에 붙는 느낌을 줄였다.

많은 질문은 새 시작점에서 가용 높이를 다시 측정해 명시적으로 페이지를 나눈다. 자료 보여주기·기록·이전/다음 질문과 겹치지 않도록 했다. 질문 해금과 대사·증거·시간 로직은 바꾸지 않았다.

검증: `dev/check.sh`, `dev/qa_lowered_questions.py`. PC/터치에서1·2·8·12개 목록의 높이·페이지, 실제 칼바람 대화의1개→2개 질문을 확인한다. 캡처는 `docs/reviews/lowered-questions-20261018/`.
