# 0.20.140 — 3일차, 발언을 골라 검증하는 회의

3일차 등 사건에서 실제 들은 발언을 골라 되묻고 자료를 제시한다. 도난 네 쟁점과 미수 두 쟁점은 각 분기의 자료·발언을 사용한다. 칼과 파편은 기존 그림의 접점을 직접 짚어 대조하고, 바깥 걸쇠와 안쪽 파편의 위치도 눌러 확인한다.

읽기·관찰·되묻기와 이미 확인한 다른 발언의 검토는 무료다. 현재 발언에 제시하면 기존 정답·대체 조합·기회·결과로 이어진다. 현재 발언을 건너뛰거나 옛 저장에 청취 캐시가 없을 때도 기존 자료 제시로 진행할 수 있다. 진상·생사·결말·새 그림·증거 ID는 바꾸거나 추가하지 않았다.

이번은3일차 두 분기 시범이며 전 사건 개편 완료가 아니다. 검증 범위와 실제 화면은 [설계와 검수](../reviews/case-hearing-20261109/설계와검수.md)를 따른다.
