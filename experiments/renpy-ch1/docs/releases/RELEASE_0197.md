# 0.19.7 — 입구 배치·건너뛰기 명칭

입구에서 다람의 고정 발 위치만 x880에서760으로 옮겨 꽥순의 몸과 이름표를 가리던 겹침을 줄였다. y668·높이205·동작·그림 및 다른 주민 배치는 유지한다.

상단 버튼은 ‘씬 건너뛰기’, 하단은 ‘대사 건너뛰기’로 구분한다. 기존 이동/현재 대화 종료 동작은 유지하며, 긴 문구에 맞춰 해당 버튼 폭만 조정했다. 선택 모드와 대화 인물 위치는 변경하지 않았다.

검수: 단위 검사·Ren’Py lint·웹 빌드, 실제 엔진의 입구 수정 전후 화면, 보통/큰 글씨 버튼, 상단 마차→입구 이동 및 하단 대화 종료→동일 장소 질문 목록 복귀 확인. 모든 장소/일정·모바일 실기기 전수 검수는 아님.
