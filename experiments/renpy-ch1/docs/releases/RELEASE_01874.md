# 0.18.74 · 네 장면으로 이어지는 엔딩 후일담

일곱 엔딩 모두 한 장의 그림에서 네 장면으로 이어지는 후일담으로 바꿨다. 가족의 상태와 함께 마을의 불빛, 남겨진 자리, 대피소와 배식, 주민의 공동 작업, 남겨진 기록을 보여준다. 엔딩의 조건이나 입증 판정은 바꾸지 않았다.

## 그림과 연출

- 엔딩별 네 장면, 총 28개 그림. 기존 다람이·엄마 디자인을 참고한 겨울 픽셀 그림이며 아빠는 플레이어의 시점으로 남긴다.
- 장면마다 짧은 제목과 두 문장의 후일담. 10초 동안 천천히 움직이는 카메라와 전환, 기존 라이선스의 엔딩 음악. 연출 끄기 설정에서는 정지 화면과 즉시 전환을 사용한다.
- 이전/다음, 방향키·Enter·Space로 넘기기. 그림 위를 누르면 다음으로 가지만, 아래 버튼은 개별 동작만 수행한다. 처음 .45초는 입력을 막아 직전 대사를 넘긴 클릭이 연달아 적용되지 않게 했다.
- 마지막 그림 위에 제목과 실제 여정 기록을 양피지 카드로 정리한다. 후일담 다시 보기, 새 여정, 진행 불러오기, 확인 후 메인화면 이동을 제공한다. 기존의 전지적 해금 지식 목록은 결과 화면에서 제외했다.

## 결말과 실제 상태

- E0: 엄마를 만나지 못한 채 이어지는 길. E1: 한 짝의 장갑과 확인하지 못한 행방. E2: 재회한 가족과 불이 꺼진 마을. E3: 잠깐의 온기와 계속되는 추출.
- E4: 대피가 완성되지 않은 마을. 물자·환자 운반 준비 여부와 F1 입증 상태에 따라 문장을 달리한다. 준비가 된 경우에도 식량이 없다고 단정하던 기존의 공통 문장도 바로잡았다.
- E5: 나비의 장부, 배식과 공동생활, 책임의 기록, 가족의 일상. 어르신의 생존 여부에 맞춰 문장을 바꾼다. 겨울이 끝나거나 모든 집의 불이 켜지는 장면은 없다.
- E6: 공동 보관하는 사본, 계속되는 마을 일, 나중에 더해진 도면의 선, 창의 천을 걷는 다람이. 마을 밖의 사건은 확인되지 않은 가능성으로 남긴다.
- 그림과 문장은 시간·물건·자료·입증 상태를 변경하지 않는다. 다시 보기는 엔딩 보상이나 결말 대사를 재실행하지 않는다. 기존 컷씬과 과거 그림 경로는 이전 저장 호환을 위해 유지한다.

## 검증

단위 테스트 192개, Ren’Py lint, 웹 빌드. 실제 Chromium에서 명시적인 엔딩 상태를 설정해 일곱 엔딩의 대사→네 장면→결과 화면을 재생했다. 이는 전체 14일 플레이 검사가 아니다. 이전 장면 이동, 중간 저장·불러오기, 후일담 재생 후 전체 여정 상태 보존, 연출 끄기, 모바일 큰 글씨 화면도 확인한다.
