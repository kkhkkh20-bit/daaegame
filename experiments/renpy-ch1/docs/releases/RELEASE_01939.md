# 0.19.39 — 승인 원화의 공간 접점·표정 연결 및 리소스 인덱스

최신 main 61665fc2 (0.19.38)의 인물 왼쪽 질문지, 하단 기록/자료 버튼, 제목 기준선 변경을 그대로 보존했다. 이 릴리스는 새 회의 UI 개편이나 신규 원화 생성이 아니다.

- 나비 주방 5동작의 몸 크기를 원화별 머리 비율로 보정했다. 조리대/화덕과 손·그릇 접점, 마스크는 유지했다.
- 다람의 침대 좌석/바닥 동작, 사건 대기 중 앉아 쉬기, 광장 슬링/설이의 단차를 기존 승인 그림으로 수정했다.
- 승인된 서리 앞쪽 3/4 시선 원화를 진료실의 실제 존재하는 서류 동작에 연결했다. 다른 장소·작업 원화는 보존했다.
- 명시적 narration show/표정 연결과 같은 논리 pose에서 남는 이전 표정 잔상을 수정했다. 새 표정 추론은 하지 않는다.
- 읽기 전용 리소스 대시보드에 63명·음향 50개·조건부 호출과 실제 캡처를 연결했다. 정적 등록과 실제 등장 증거를 구분하며 실행 조건 미해결은 그대로 표시한다.

검증: unit/lint, 공식 SDK 웹 빌드, 전송/선로딩 SHA 및 ZIP CRC, 공간 클릭 8회와 449 인물 레코드, 나비 8상태 및 2 저장/복원, 장소 66장(118 인물·동작·장소 조합) 육안 확인. 대시보드 팝업/뒤로가기/390px/필터/WAV·MP3 실제 재생/누락 파일 피드백을 로컬 Chromium에서 확인했다.

남은 항목: 학교/우체국의 기존 밀집 배치, 나비 식당 원화 컵 비율, 피코 침대 동작 크기 추가 검토. 다른 날짜와 사건 분기는 미검수다. 자세한 분류와 인물·동작·날짜·시간은 [장소 갤러리](../../../../reports/place-balance-01936/index.html)에 있다. 회의 도토 좌석 원화 누락과 모달 뒤 일반 식당 노출은 읽기 결과만 기록했고 회의 개편은 별도 작업이다. 전체 게임 QA나 모든 원화 완성을 주장하지 않는다.
