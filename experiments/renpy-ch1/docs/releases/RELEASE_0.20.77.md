# 0.20.77

2026-10-27. 생활 배치 보강(실무 의견 적용).

- 우체국 낮·저녁(옛 1280 배경) 자리: 세련 도장·촌장 공지 고정·모모는 접수대 안(가슴 아래 가림), 구슬·콩이는 앞 전신.
- 매대 안/앞 규칙(소유자): 그 자리의 주인만 매대 안(가림 폴리곤), 손님·지나가는 사람은 매대 앞 전신. 반쯤 걸치는 자리 없앰.
  장터 은호·구슬·누비·여니 앞 전신, 상점 저울 탁자는 안 없음, 여관 접수대 구슬 앞.

- 2차 요청서: 까로 바퀴 점검 재요청 1장(여백). 1~3일 보강 6장은 1차 납품에 모두 포함.
- 시험 대상 조절 중 발견: 밤 대사창 글자가 커지며 「건너뛰기·더보기」 버튼이 대사창 아래 오른쪽에 걸침(다음 판에서 손본다).
