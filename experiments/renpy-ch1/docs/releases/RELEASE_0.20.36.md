# Room13 0.20.36 — 초소 대화의 전제와 조사 연결 보완

- 이름을 묻고 명부에서 찾은 뒤 일꾼 등록 사실을 말하도록 초소 대화 순서를 보완했다. 아빠의 질문과 돌목의 답변이 직전 정보를 이어받도록 고쳤다.
- 4일 필수 조사 대상을 새 초소 서류 영역으로 연결했다. 옛 선반 영역이 새 서류 영역에 겹쳐 다른 반응을 여는 문제를 자연 진행 검증에서 확인했다.
- 자연 진행 도구의 현재 수첩·지도·현장 조작 대응을 갱신했다. 보고서는 실제 통과 구간과 미확인 구간을 구분한다.

검증
- 대사27개·후반 연결16개 단위 통과, 대사 논리 A/B/C0건. 웹 빌드 lint 오류 없음.
- 새 게임에서 수정한 초소 대화가 끝나고 조사 진입하는 것 확인. 실제 4일 저장에서 서류 조사·물림 장면·밤이 질문·현장 조사·귀가를 거쳐 5일 진입 확인.
- 네로·피코 보호 경로는 실제 UI로 3일까지 각각 통과. 이후 5~14일 자연 진행과 전체 대사 재검토는 남았다.
