# 0.20.143 — 1부 연속 완주에서 발견한 대사 연결과 발언 제목 수정

5일차 발언 검증에서 키에 관한 추정과 울타리 목격담에 서로 다른 제목을 붙였다. 실제로 끝까지 들은 발언만 표시하고, 원래 대사·선택 대상·되묻기·판정은 유지한다. 이전 저장의 발언 기록도 새 제목으로 표시한다.

2일차 초상 의뢰는 엄마를 찾으려고 사람들에게 보여 주는 목적을 유지하고, 찾은 뒤 엄마에게 주고 싶다는 다람의 바람으로 연결했다. 3일차 수령 직후의 자동 묘사는 코가 빠졌다는 관찰을 반복하지 않는다. 첫 관찰과 다시 살펴보는 기능은 남겼다. 5일차 답장 장면에는 초롱을 부르고 그가 돌아오는 과정을 넣었다.

바둑이·무쇠의 근접 대화 그림은 이번에 교체하지 않았다. 보유 후보는 화풍 외에도 표정·소품·무쇠 손바닥의 ‘솜이’ 글씨 조건이 달라 그대로 대체할 수 없었다. 두 인물의 같은 역할 납품본 확인 요청을 등록했다. 새 이미지나 리샘플링 그림은 만들지 않았다.
