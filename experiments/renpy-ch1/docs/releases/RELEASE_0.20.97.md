# 다람탐정 0.20.97 — 소설 개정안 본편 적용

소유자가 승인한 『기다린다던 방』 14장 퇴고 원고를 기존 본편의 대사와 행동 연결에 반영한다. 소설의 한 경로와 게임의 생존·예방·실패 경로를 구별하며, 플레이어의 자료 제시와 실제 인수·이송 상태를 유지한다.

## 변경

- 엄마를 기다리는 다람의 반응, 피코의 약속과 상실, 아빠의 성급한 판단을 다람이 되짚는 주고받기를 보강한다.
- 2일 도착 쪽지, 5일 첫 답장, 8일 경고, 10일 초롱의 전언, 11일 재회의 정보 시점을 맞춘다. 새 정보의 실제 청취 여부를 별도로 저장한다.
- 6일 학교 담요 조달과 운반, 7일 아이의 복도 인계와 이후 귀환, 9일 책장과 별도 판자문의 구분을 연결한다.
- 후반의 설명과 반복 확인을 줄이되 배식 중단, 자료 제출, 이송 인수와 장치 보관은 실제 행동으로 남긴다.
- 새 게임의 미완성 초상은 엄마를 만난 뒤 코를 완성한다. 이미 완성한 초상이 있는 옛 저장은 그 상태를 유지한다.

날짜별 근거와 적용 범위: `docs/reviews/novel-game-20261105/`.
