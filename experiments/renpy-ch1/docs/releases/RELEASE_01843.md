# 0.18.43 · 2026-10-15 — 1:1 대화 몸동작(부드러운 스쿼시·스트레치)

0.18.42 위에 쌓았다. 소유자 피드백: "눈만 바뀌는 게 아니라 놀라면 '확' 하는 동작이 있어야 한다. 지금은 프레임도 낮다." "조사 화면은 배경 위에 있을 때를 말한다. 1:1 화면은 움직여도 된다."

## 1. 바뀐 것

- 1:1 대화 전신 그림이 매 프레임 부드럽게 움직인다(이전: 3px 단위로 끊긴 오프셋).
- 표정 그림 한 장을 허리 높이(그림 위에서 62%) 가운데를 축으로 늘이고 누르고 띄운다(스쿼시·스트레치, 가감속).
  - 놀람: 앞 얼굴로 움츠림 → 놀란 얼굴로 바뀌며 위로 늘어나 42px 솟구침 → 공중에서 잠깐 → 착지하며 눌림 → 제자리
  - 기쁨: 웅크렸다 통통 두 번 / 화남: 앞 얼굴로 움찔 → 들썩이며 부르르 / 불안: 움츠려 잔떨림 → 천천히 펴짐
  - 당황: 좌우로 허둥지둥 / 생각: 한쪽으로 기울어 1초 머묾
- 동작이 끝나면 숨쉬기(1.7초마다 0.7% 늘었다 줄기)와 눈 깜빡임만 남는다. 대화 그림이 있는 모든 인물이 숨쉬고, 감정 동작은 `R13_REACT_PEOPLE` 인물만.
- 조사(배경 위 현장) 화면의 인물은 0.18.41대로 움직이지 않는다.
- 설정의 '움직임'을 끄면 예전처럼 멈춘 그림이다.

## 2. 한계

- 그림 자체의 자세(팔을 드는 등)는 바뀌지 않는다. 표정 그림이 한 장씩이라 몸 전체를 늘이고 누르는 방식이다. 팔·몸 자세가 바뀌는 동작은 원화에 동작 프레임(예: 놀람 2~3장)을 그려 받아야 한다.
- 늘이고 누르는 동안은 도트가 살짝 부드럽게 보간된다(부드러운 움직임을 위해 선택).

## 3. 파일

- `systems/room13_dot_fx.rpy`: `r13_react`가 대화 그림을 `Fixed(크기 고정)` 안의 움직임 변환으로 감싼다. 변환은 `r13_body_*`.
- 화면 테스트 `motion_reel`(기본 묶음 밖): 여관 저녁에서 다람이가 여섯 감정을 차례로 보여 준다. 화면 녹화로 검수할 때 쓴다.

## 4. 검사

- 단위 테스트·lint 통과. 화면 테스트 `dot_fx`(감정별 0.04~0.7초 캡처 7장), `fullbody_line_emotions`, `carriage_view` 통과.
- 엔진 화면을 녹화해 여섯 동작을 확인했다.
- 전체 회귀는 소유자 지시로 생략했다.
