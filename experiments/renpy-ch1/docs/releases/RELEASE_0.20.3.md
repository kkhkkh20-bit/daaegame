# 0.20.3 — 마을 입구 D안(75% 축소·아래 띠), 역할별 자리, 설정창 저장

## 마을 입구 화면(소유자 승인 시안 D)
- 현장을 75%로 줄여 한 화면에 약 1707px 폭이 보인다. 조사 대상 8개가 모두 화면에 들어온다.
- 화면 아래 띠(180px): 조사할 때는 지도·생각·기록 버튼, 대화할 때는 대사창이 쓴다. 대화 중 배경도 같은 구도를 쓴다.
- 이름표는 축소와 상관없이 원래 글자 크기로 보인다.
- 역할별 자리: 돌목은 문 오른쪽 기둥 옆, 실룩은 돌목 곁에서 귓속말, 까로는 자기 마차 바퀴 손질, 다람은 까로 곁에서 생각하는 자세, 보리는 장작더미 옆에서 장작 나르기. 출입문 통로와 초소 서류는 비워 둔다.
- 장면에 필요 없는 주민은 생활 장소로: 네로는 잡화점, 바둑이는 광장. 그 장면 이야기에 필요하면 입구에 남는다.
- 다른 장소는 아직 그대로다. 입구에서 확인한 뒤 넓힌다.

## 저장
- 설정창 아래 줄에 「저장 · 불러오기」를 넣었다. 조사 중에도 저장할 수 있다.
