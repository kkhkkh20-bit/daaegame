# 0.20.72

소유자 캡처 지적(2026-10-27) 반영. 「버튼이 수첩 안에 있으면 안에 있어야 하고, 애매하게 뒷배경을 초과하면 안 돼」.

- 수첩 공통 틀의 안쪽 아래를 종이 안(636)으로 내려, 기록 5탭·갈림길·자료 대조의 하단 버튼 줄이 종이 가장자리를 넘지 않는다.
  갈림길의 지난 결말 띠는 버튼 왼쪽에서 끝난다. 지도 오른쪽 아래의 다람 스티커(수첩 모서리 밖)와 왼쪽 위 테이프 조각을 뺐다.
- 기록 탭 줄의 목표 칸이 좁은 폭에서 「목표」 글자만 찌그러지던 것을, 제목 띠 아래 가는 줄에 「목표 · 점 · 지금 단계」로 전부 보인다.
- 질문 화면 네 버튼(자료 제시·기록·더보기·돌아가기)을 같은 바탕·같은 크기·글자만으로 통일. 「질문 N개」를 제목 띠 안으로.
- 아빠 생각(괄호) 줄에서 뒤에 말할 다람이 미리 서 있던 것을 없앴다.
- 1일 입구 돌목에게 근거를 대는 것은 회의가 아니므로 횟수 제한을 없앴다(「남은 기회」 표시·차감 없음).
- 획득 알림 카드가 현장 상단 지도·기록 버튼을 덮지 않게 아래로.
