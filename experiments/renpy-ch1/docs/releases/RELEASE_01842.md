# 0.18.42 — 기록창 내부 메모·비교, 디자인 일관성

조사 메모와 기록 비교를 기존 기록창 틀 안의 내용으로 통합하고 왼쪽 색인 전환을 유지했다. 별도 메모/비교 진입도 같은 틀을 사용한다. 내부 메모 탭과 비교 선택은 각각의 화면 scope에 보관해 상위 기록 분류와 충돌하지 않도록 했다.

질문 화면 중복 안내 제거 및 배경만 암전, 양피지 이동창과 종이 장소 카드, 대화 도구 축약 및 더보기, 증언 깃펜 아이콘과 도구 확대, 첫 실행 메인 메뉴 우선순위 및 작은 음악 출처 링크를 반영했다. 기존 이야기·이동·획득 조건 유지.

검증: 140 단위 검사, compile/lint, 실제 브라우저에서 기록 색인·메모 세부 탭·비교 선택 및 결과·별도 진입·제시 응답·더보기 옵션 복귀·모바일/큰 글자. 전체 14일 재검사 없음. 캡처와 인계는 `reports/notebook-design-20261015/`.
