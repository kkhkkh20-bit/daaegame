# 0.17.12-dev · 2026-10-14

## 옵션 화면 다시 만들기 (소유자 지시)
- 한 화면에 모두 들어가고 스크롤하지 않는다. 버튼 높이 56, 슬라이더 높이 40으로 휴대폰에서 누르기 쉽게 했다.
- **소리:** 배경음 / 효과음·대사 소리 볼륨, 각각 켜짐·꺼짐, 인물 전환 효과.
- **읽기:** 대사가 나오는 속도(느리게·보통·빠르게·즉시), 자동 진행 속도(빠르게↔느리게 표시), 큰 글씨, 읽은 대사 빠르게(게임 중에만).
- **게임 중 아래 줄:** 저장 · 불러오기 · 처음 화면. 처음 화면은 "저장하지 않은 진행은 사라진다"를 한 번 묻는다.
- 뺀 것: 스크롤 영역, 항목마다 붙던 긴 설명, '배경음: 켜짐'처럼 글자로만 상태를 알리던 버튼(이제 켜짐은 금색).
- 색은 진녹색 바탕 · 금색 강조 두 가지로 맞췄다.

## 검증
- Ren'Py 화면(타이틀·게임 중), lint, 단위 테스트, 브라우저 QA(0.17.10 이동, 저장).
