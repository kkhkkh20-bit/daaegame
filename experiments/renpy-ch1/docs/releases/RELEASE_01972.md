# 0.19.72 — 마차 도입과 대사 맥락 연출

첫 대사가 ‘아빠는 안 잡아 줘?’로 바로 시작해 무엇과 대비하는 말인지 알 수 없던 문제를 보완했다. 전달 제작기준본 D01S01 L0001과 연출구현명세 A01을 읽고, 효과음 지시는 실제 음향으로, 전용 손 그림이 없는 동작은 명세가 허용한 원문 서술로 연결했다.

- 과자 봉지를 챙기는 상황을 먼저 전달한 후 아빠 대사로 이어진다. ‘나무 바퀴 소리’라는 제작 지시를 자막으로 표시하지 않는다.
- 전달된 원본 출발·바퀴·옷감·정차 WAV를 그대로 사용한다. 배경과 인물만 작게 흔들리고 대화창·버튼은 고정된다. 기존 인물 전환 효과 정지 설정과 건너뛰기를 존중한다.
- 마차 원화의 오른쪽 좌석 영역을 명세 좌표로 보여 준다. 창밖 마을은 까로의 지붕 안내에서 공개한다. 좌석 그림을 가로로 늘이거나 서 있는 전신을 착석 포즈처럼 합성하지 않는다.
- ‘또 읽어?’부터 ‘십삼 호’까지 기존 자료 카드에 초대 편지를 표시해 읽는 대상을 알린다. 카드는 새 메뉴나 선택지를 만들지 않고, 증거 지급·시간·조건을 바꾸지 않는다.
- 기존 페이지 분할 대사에서 씬 건너뛰기를 눌러도 다음 페이지가 남던 문제를 고쳤다. 페이지 반복에서도 기존 마차 스킵 플래그를 확인한다.
- 일반 진행과 씬 건너뛰기 모두 입구에 도착하면 마차 효과음·흔들림·자료 카드를 해제한다.

새 손 컷을 제작했다고 주장하지 않는다. 탁자 위 과자 CG를 무릎/외투 동작으로 재해석하지 않는다. 이번 변경은 마차 도입의 연출이며, 전체 신규 대본이나 모든 원문 조작 연결이 완료됐다는 의미는 아니다. 편지 상세 조작과 이후 장면 연결은 기존 시스템을 기준으로 별도 검토가 필요하다.

플레이 이해 검토는 소스와 실제 플레이 순서에 대한 개발자 점검이다. 외부 게이머 대상 사용성 시험 결과가 아니다. 과자 선행 상황, 편지 지시 대상, 마을 공개 시점, 정차의 시청각 구분을 확인하고 실행 검증 결과는 `docs/story-ms14/validation/01972/`에 보관한다.
