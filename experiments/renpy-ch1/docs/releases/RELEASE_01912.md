# 0.19.12 — 지도 그림에 직접 쓴 지명

승인된 손글씨 지명 원화로 마을 지도를 교체했다. 여관·학교 등 보통 장소 이름 11개는 그림과 같은 갈색 잉크로 종이에 직접 적혀 있다. 별도 이름표 패널과 겹쳐 그리던 게임 글씨는 제거했다. 제목·지역 탭·이동/복귀 버튼은 기존 UI를 유지한다.

건물과 지명의 투명 클릭 영역은 같은 목적지를 선택한다. 선택·마우스오버·키보드 포커스는 얇은 잉크 밑줄로 표시한다. 마우스오버는 선택한 목적지를 바꾸지 않으며 실제 이동은 기존 확인 버튼으로만 실행한다. 현재 위치는 별도 작은 문구로 표시한다. 모든 지명과 입구·강이 하단 UI 위에 들어오도록 마을 그림만 위로33px 옮기고 남은 배경 여백을 종이색으로 맞췄다.

보통 지명은 인쇄된 지도처럼 항상 읽을 수 있지만, 이동 대상과 클릭 활성화는 기존 r13_map_nodes/r13_places를 따른다. 미발견 통로·지하·온실·제단은 이 그림에 추가하지 않았다. 숲·산길 지도, 여관의 층별 글 안내, 실제 장소 개방·시간·회의·대사·자료 판정은 유지했다. 0.19.11까지의 캐릭터 표정 작업과 저장 호환 수정도 보존했다.

검수: 전체 dev/check.sh(단위·lint), 실제 엔진 cartography, 웹의 11개 건물·11개 지명 선택, 마우스오버와 선택 분리, 상태·시간 보존, 844×390 터치 반복 입력·취소, 여관 안내와 지하 복귀, 기존 온실/제단 발견 조건, 확인 버튼으로 실제 우체국 이동. 웹 검수는 상태 fixture이며 전체 캠페인 자연 진행이나 모바일 실기기 전수 검수를 뜻하지 않는다.
