# 0.20.123 — 조사·주장 분리와 화재의 실제 문답

3일차에 칼날과 자국을 살펴보려던 선택이 특정 칼이라는 주장으로 처리되던 흐름을 나눴다. 관찰은 무료로 돌아오고, “이 자국은 실룩 씨 칼이 냈습니다”라는 명시적 주장만 기존 반박과 기회 차감으로 보낸다. 칼끝 대조와 걸쇠·파편 위치의 기존 증명은 유지한다.

화재 첫 논증에서는 관찰과 질문을 UI가 의미상 정답/오답으로 거르지 않는다. 아빠가 선택한 관찰을 말하고 누비·보리가 답한다. 장작·등잔 확인이나 아직 행동을 입증하지 못하는 연결은 기회 차감 없이 돌아온다. 유효한 논증의 자료 제출은 기존 판정과 차감을 따른다.

누비가 아이들을 내보내려 했다고 말한 뒤에는 이미 확인한 문 앞 흔적이나 실제로 들은 솥 이야기를 다시 펴고, 플레이어가 직접 되묻는다. 해 지기 전 차가운 솥과 저녁에 물을 데웠다는 진술을 곧바로 모순으로 처리하지 않는다. 재확인 화면은 건너뛰기·자동 읽기가 멈추며 저장할 수 있다.

원본 records·정답 자료 묶음·회의 기회 총수·부분 성공·생사·결말은 유지한다. 검증 범위와 화면은 [검수 기록](../reviews/deduction-play-20261108/검수.md)을 따른다.

전체 단위1,448개·lint와 관련 엔진 화면7개, 최종 웹의 PC·휴대폰·실제 저장 복원 검수를 통과했다. 검수는 상태를 준비한 변경 장면을 대상으로 했으며 1~7일 전체 무중단 재완주로 계산하지 않는다.
