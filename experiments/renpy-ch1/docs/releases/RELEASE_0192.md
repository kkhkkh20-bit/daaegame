# 0.19.2 · 2026-10-17 — 빼기 정리 (기능 수보다 직관성)

소유자 피드백 "기능이 너무 늘어나면 직관성이 떨어진다"에 따라, 승인된 시안대로 화면 요소를 줄였다.
근거: Notion 「Room13 레퍼런스 2차 정리」의 「기능 수보다 직관성」 절.

## 기록 화면
- 탭 6개 → 4개: 자료 / 사람 / 대화 / 메모.
  - 「인물」은 「사람」(관계도)에 합쳤다. 관계도 오른쪽 상세 아래에 그 사람에게서 들은 이야기와 보여 준 자료가 붙는다.
  - 「달력」은 「메모」 안 오른쪽 위 「달력 ›」로 들어간다. 날짜판을 누르면 예전처럼 달력이 바로 열린다.
- 자료 거름 두 줄(최대 7개) → 한 줄: 전체 / 증언 / 전달 가능 / ● 안 읽음 N / 지난 사건 N.
  - "오늘 얻음"은 뺐다. 최근 얻은 순서 정렬과 ● 표시로 충분하다.
  - "이 사람 관련"은 단추를 없앴다. 보여주기를 열면 지금 상대(회의에서는 발언자)와 이어진 자료가 자동으로 앞에 온다.

## 「더보기」
- 9개 → 4개: 저장 · 불러오기 / 다시 시작할 아침 / 설정 / 메인화면.
  - 대사 중에만 「빠르게」(읽은 것만 · 전부)와 「대화창 숨기기」가 위에 붙는다. 대화창 숨기기는 휴대폰에서 그림 전체를 볼 유일한 방법이라 남겼다(시안과 다른 점).
  - 회의 중의 「자동」·「토론 멈추기」는 그대로.
- 「닫기」를 없애고 바깥을 누르면 닫힌다.
- **「생활 장부」를 없앴다.** 일거리·숙박비를 없앨 때(0.18.94) 남은 흔적이었다.
- 저장 화면 위에 「불러오기로 ›」, 불러오기 화면에 「저장으로 ›」를 두어 한 입구로 오간다.
- 단축키 안내는 설정 화면 아래 「단축키 (PC)」로 옮겼다.
