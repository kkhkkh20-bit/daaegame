# 0.18.81 · 게임에 맞춘 단순한 48px 자료 아이콘

자료·물건 82종을 48×48 도트 기준으로 다시 정리했다. 단순히 이전 그림을 축소하는 대신, imagegen으로 불필요한 금속광·금장·장식·잔선과 내부 명암을 덜어내고 큰 픽셀 덩어리와 평평한 색면으로 다시 그렸다. 황동은 차분한 황토색, 종이는 크림색, 가죽은 낮은 채도의 버건디·청록·갈색으로 맞춘다.

봉투의 솔잎 봉인과 엄마 메모의 도토리, 붉은 바느질 매듭, 촛대 두 부분과 고리 속 핀, 자료에 적힌 중요한 도형은 유지한다. 인물 초상화와 P01은 계속 제외한다. 정보의 의미나 소유·획득·보여주기·입증 조건은 바꾸지 않는다.

실행에서는 64×64였던 논리 크기를 48×48로 바꾸고 목록·상세·상점·보여주기에 nearest 샘플링을 유지한다. WebP는 UI 도트용 무손실 가져오기를 사용한다. 새 시트의 각 그림 범위를 다시 확인하여 옆 칸 조각이 같이 나타나지 않게 한다.

검증은 `dev/check.sh`의 단위 테스트 195개+lint, 그림 매핑·투명도·자르기 검사, 웹 빌드와 실제 Chromium 자료창·상점·보여주기·모바일 화면이다. 모든 자료를 가진 명시적 검수 상태를 사용하며, 모든 획득 경로를 플레이한 검사는 아니다.
