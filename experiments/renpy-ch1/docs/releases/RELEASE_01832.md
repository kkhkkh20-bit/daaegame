# 0.18.32 · 2026-10-15 — 다람이 표정 반응 동작

0.18.31 위에 쌓았다. 소유자 요청: 눈 깜빡임 말고 동작의 역동성, "놀란 표정이 나오기 전에 먼저 놀라는" 반응. 우선 다람이만.

## 1. 동작

대화 중 다람이 표정이 바뀌는 순간 몸이 한 번 반응한다. 같은 표정이 이어지면 반응하지 않는다.

| 표정 | 동작 |
|---|---|
| 놀람 | 앞 표정 그대로 0.1초 움찔(아래로 9px) → 놀란 얼굴로 바뀌며 30px 튀어오름 → 단계적으로 내려앉음 |
| 화남 | 앞 표정 그대로 0.07초 움찔 → 화난 얼굴로 바뀌며 좌우 9px 부르르 |
| 기쁨 | 깡총 두 번(18px, 12px) |
| 불안 | 12px 움츠러들며 잔떨림, 0.6초 뒤 제자리 |
| 당황 | 좌우 9px 갸웃 세 번 |

- 등장하자마자 놀라거나 기뻐하는 대사는 그 자리에서 바로 반응한다.
- 움직임은 대화 그림 도트 크기(3px)의 배수로만 움직이고, 확대·회전은 쓰지 않아 픽셀이 뭉개지지 않는다.
- 반응이 있는 표정 전환은 0.22초 페이드 대신 바로 바뀐다(움찔한 뒤 바뀌는 맛을 살리려고).
- 설정의 '움직임'을 끄거나 건너뛰기 중이면 예전처럼 반응 없이 바뀐다.

## 2. 연결

- `room13_rules.rpy`의 `r13_speaker` 안 한 곳: `r13_react_kind`로 반응을 고르고 `r13_react`로 그림과 변환을 얹는다. 덮어쓰기 층은 없다.
- 코드: `systems/room13_dot_fx.rpy`(`R13_REACT_PEOPLE`에 이름을 더하면 다른 인물도 같은 동작을 쓴다).
- `dev/test_room13_pov.py`의 대역 환경에 반응 함수 두 개를 '반응 없음'으로 더했다.

## 3. 검사

- 단위 테스트·lint 통과. 화면 테스트 `dot_fx`에 다섯 표정 반응 캡처(0.04~0.7초)를 더했고 통과.
- 전체 회귀는 소유자 지시로 생략했다.
