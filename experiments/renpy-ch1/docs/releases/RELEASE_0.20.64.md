# 0.20.64

소유자: "해줘" (조사 반응 대사를 4일 이후 장소로).

## 조사 반응 2차 (4일 이후 장소)

- 진료소(침대·대야·가림막), 학교(난로·공책), 창고(저울·포장천), 온실(화분·물뿌리개) 9곳에 다람·아빠 주고받기.
  다람이 엉뚱하게 말하고 아빠가 받아친다. 단서의 뜻은 말하지 않는다.
- 넣지 않은 곳: 사건과 닿는 물건(약병·진료 기록·장부·자루·담요·장작·등 표식·기계), 시설(사람을 넘겨주는 곳), 제단(마지막 회의).
- 막은 날: 12일 학교·진료소(수프 사건), 13일 광장(군중·수레). 3일 광장, 사건 뒤 13호·복도는 그대로 막는다.
- 1차(28곳)와 합쳐 37곳. 같은 때 4번까지, 다람이 곁에 있을 때만(갇힌 8~9일은 나오지 않는다).

검사: lint, 단위 1110개, 대사 논리 검사 0건, 화면 시험 9개(12일 수프·13일 수레·진엔딩 포함) 통과.
사실·증거·생사·회의 정답·진행 조건은 바꾸지 않았다.
