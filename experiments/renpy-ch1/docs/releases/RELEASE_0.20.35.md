# 0.20.35 · 수첩 에셋 도구함과 규격 버튼 통합

에셋 태그·역할 매칭을 한곳에서 관리하고 회의 화면 캡처·전후 비교·제작 요청 ZIP·연결 되돌리기를 제공한다. 규격별 버튼20종을 제작해 메인·질문·조사에 적용하고 회의 제목/이름/본문 겹침을 정리했다.

0.20.34 이야기와 0.20.33 회의 재시도를 통합했다. 재시도는 기존 정본의 회의 시작 스냅샷 복원 방식이다. 회의 전에 얻은 자료와 시작 상태를 보존하고 회의 중 변화는 다시 진행한다.
