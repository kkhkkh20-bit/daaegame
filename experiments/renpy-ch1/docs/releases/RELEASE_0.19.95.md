# 0.19.95 — 오류 단계: 게임 버그 2건, 예전 화면 테스트 정리

## 게임 버그
- 새 세계관 대화에서 말한 인물(또는 장면에 나온 인물)이 만난 사람으로 기록된다. 이전에는 질문 화면을 거치지 않는 새 세계관 대화라 관계도에 나오지 않았다(1일 입구의 돌목 등).
- 새 세계관 현장(`r13_v111_wait_again`)도 예전 현장처럼 화면이 잘못된 값을 돌려주면 현장을 다시 보여 준다. 이전에는 `None`을 그대로 읽어 멈출 수 있었다(Codex가 테스트를 고치다 발견).

## 예전 화면 테스트(Codex 작성 → Claude가 Ren'Py로 실행·재수정)
- 표준 묶음의 예전 테스트를 새 세계관 흐름에 맞게 다시 썼다: 현장 반환 주입, 실제 버튼 문구('단축키 PC', '지도'), 지도·선택지 준비 대기, 숲에서 연 지도는 '마을' 탭을 눌러 시장 선택.
- 새 세계관에 없는 예전 C1~C4 재판 테스트 등 13개는 LEGACY 묶음(`ROOM13_LEGACY=1`)으로 분리했다. 테스트별 이유: `reports/legacy-tests-v111-20261022/results.txt`.
