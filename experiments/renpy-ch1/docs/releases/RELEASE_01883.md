# 0.18.83 · 겨울 동화책 표지 같은 메인화면

밝고 귀여운 중앙 금빛 로고와 돌 버튼 대신, 왼쪽에 제목·소개 문장·메뉴를 묶고 오른쪽 여관과 마을 길이 보이게 했다. 배경의 채도를 줄이고 차가운 저녁빛을 입힌다. 왼쪽과 위아래에 조용한 그림자를 두고 화면 가장자리에 가느다란 옛 책 표지 선을 더했다. 피나 새로운 등장인물, 사건을 암시하는 그림은 추가하지 않았다.

로고는 기존 이름 ‘다람탐정’을 유지하되 도토리와 아래 장식을 없애고, 아이보리 도트 글자로 다시 그렸다. 메뉴는 넓은 어두운 책갈피 형태이며 선택 표시의 따뜻한 빛은 버튼 아래에만 놓인다. 저장이 없으면 처음부터가 첫 항목이고, 저장이 있을 때는 이어하기가 위에 붙는다. 새 게임·저장·불러오기·설정·출처 기능은 기존 동작이다.

배경 원본과 기존 눈·조명 모션, 움직임 끄기 설정은 유지한다. 웹 첫 로딩의 로고·배치·그림자도 메인화면과 맞춘다. 게임 안 대사창·자료·회의 화면의 스타일은 바꾸지 않는다.

검사: `dev/check.sh`(단위 테스트와 Ren'Py lint), 웹 빌드, `dev/qa_title.py`의 실제 Chromium 화면·마우스·키보드·844×390 터치·움직임 끄기·설정/출처 복귀·새 게임·저장 후 메인화면 확인·이어하기. 문구는 ‘겨울의 미스터리 동화’, ‘눈은 모든 발자국을 덮는다.’이며 사건의 사실이나 해결책을 밝히지 않는다.
