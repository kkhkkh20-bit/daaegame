# 0.19.88 — 시작 다운로드·시간대 배경·현장 가독성

스토리 재구성은 다른 채팅에서 진행한다. 이번 변경은 기존 대사/선택/생존/증거/일정을 유지하고 표시와 다운로드만 수정한다.

## 적용

- 시작 화이트리스트를 실제 타이틀/마차와 현재 승인 다람 대화 그림으로 좁혔다. 폐기된 다람 아틀라스, 돌목/까로 전체 표정, 입구 이후 음악 및 다른 시간대 배경은 기존 progressive 다운로드로 유지한다. 첫 입구 음악/바람은 실행 후 기존 저우선순위 캐시 예열에 포함한다. 원본 해상도/음질을 낮추지 않았다.
- 첫 로딩 게임 자료 38338284 → 29136834바이트: 9201450바이트(약24%) 감소. 엔진 wasm/data 합계 36643938바이트는 별도이며 그대로다. 이 수치는 다운로드 자료량이며 실제 휴대폰 로딩 시간을 보장하는 값이 아니다.
- 대화 배경이 시작 시점의 오전 값을 계속 사용하던 연결을 현재 장소의 실제 시각을 따라 읽도록 수정했다. 기존 저녁 원화/조명 사용. 시계/사건 상태는 변경하지 않는다. 별도 시간대 원화가 없는 공간은 요청서에 남긴다.
- 기존 공통 버튼의 실제 크기와 위치를 인물 자유 배치 후보 및 이름표 충돌 계산에 반영했다. 가구에 고정된 인물/일정/장소는 보존한다. 화면 가장자리의 일부 보이는 얼굴에 딸린 이름표를 현재 뷰포트 안으로 제한했다.
- 이전 저장 화면을 열 때 표시 캐시를 비우고 다시 그려 현재 표시 규칙을 적용한다.
- 검사 실패 로그를 보존하여 원인 확인 때문에 같은 전체 검사를 다시 돌릴 필요를 줄였다. 줄 이동에 따른 기존 대사 바인딩 위치 메타데이터만 갱신했다.

## 검증

802개 검사 및 Ren'Py lint 통과, 공식 웹 빌드 완료. 새 게임의 마차·편지 → 첫 입구 조사 화면을 실제 입력으로 확인했다. 실제 14일 제단 저장에서 좌우 이동과 데스크톱/휴대폰 화면을 검수했다. 실제 13일 저녁 입구 저장에서도 밤 배경과 기존 이동을 확인했다. 기록/선택/생존 상태가 표시 검수 중 변하지 않는지 대조했다. 기본 저장/로드/스킵의 별도 중복 행렬은 수행하지 않았다.

캡처와 범위는 docs/reviews/presentation-20261021/에 보존한다. 로컬 공식 빌드 캡처이며 공개 서버 직접 접속 캡처로 주장하지 않는다. 모든 장소/인원/가구 조합을 검수한 것은 아니다.

## 리소스 요청 및 미완료

다른 디자인 채팅 전달 문서: docs/design/RESOURCE_REQUEST_20261021.md.

정밀 단서 비교 C01(겉옷/울타리 천), C02(구리선/핀), C03(병/파편/봉인)은 같은 원본에서 분리한 형상과 공통 배율/좌표를 요청했다. 원화는 아직 없다. 따라서 이 세 비교 그림의 게임 적용은 미완료다. 기존 일반 아이콘을 정확한 접합 그림으로 대신하지 않았고 새 비교 엔진/임시 정답 그림은 만들지 않았다. 인물 동작은 토리와 중복 제작하지 않는다. 원문 ID와 표시 전제는 요청서에 명시했다.
