# 0.20.66

소유자: "감정선이랑 선생님 장면도 해줘".

## 감정선 보강 일곱 (`docs/reviews/bonds-20261024/감정선_검수.md` 11장)

위기 전 아빠·다람과 주고받은 일 + 위기 장면에서 그 일을 비추는 줄. 모두 다람이 곁에 있을 때만 나온다.
- 판돌: 6일 아침 식당 「모과 자리」 → 13일 「이번엔 내가 가서 앉을 거요」.
- 굴돌: 11일 시설 벽 앞 다람 「그럼 내가 기억할게요」 → 13일 내릴 때 다람이 받친다.
- 너울: 5일 초소 회의 끝 주판알을 주워 줌 → 13일 알이 굴러갈 때 줍지 않음, 군중 판 뒤 눈 속에서 주움.
- 톡: 2일 밤 다람 「고리를 받았다」 → 3일 누명 때 「나쁜 사람 아니야」, 13일 고리를 들어 보임.
- 밤이: 3일 저녁 처마 아이에게 도토리(「거기 둬요」) → 4·5·13일 도토리.
- 보리: 6일 가시와 「그 장작 명단에 원래는 제 이름도」 → 6일 불 뒤 아빠 생각, 13일 「가시 뺐어요?」.
- 나비: 12일 짐 판 「나비 누나가 나 맡아 줬어요」, 13일 「누나, 국 식어요」/「……그건 내 말이잖아」.
이름 소개 전 인물(6일 판돌, 3일 밤이)의 말은 지문 속 인용으로 썼다.

## 예방판 13일 선생님 (맞물림 10번 마지막)

12일 국을 막은 판이고 이송 칸이 무효가 아니면, 수레에서 내릴 때 선생님이 새미를 등 뒤로 감춘다. 국을 막아도 목적은 남는다.

검사: 대사 논리 0건, lint, 단위 1110개, 전체 화면 시험 167개 통과.
회의 정답·생사·진행 조건은 바꾸지 않았다.
