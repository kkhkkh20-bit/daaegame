# 0.19.26 — 회의 확대 정본과 대화 전용 동작 연결

0.19.24 프로필 58명 적용에 이어, 승인 대화 원본 59명의 사용 범위를 회의 발언 확대 화면으로 넓혔다. 회의의 740/776/840/876 높이와 가까운 이웃 인물도 같은 원본을 비율 유지해 표시한다. 회의 중에는 직전 일반 대화의 반응 계획이 회의 표정을 덮지 않는다. 먼 좌석 군중과 조사 지도는 이번 변경 대상이 아니다.

우체국 오후 세련의 `chair_listen` / `chair_read` 대화 경로에는 승인 neutral 원화의 얼굴·편지 bust를 연결했다. 지도용 앉은 픽셀 그림은 유지한다. 이 임시 정본 bust는 새 앉은 동작 두 장을 제작 완료했다는 뜻이 아니다. 두 전용 그림은 별도 제작 대기이며 기존 동작 키를 보존했다.

뿔 `kneel_stone`은 기존 원본 파일·crop·자세를 유지하고 대화 확대의 추가 3px 격자만 제거했다. 선생님 `write_attendance` / `collapse_attendance`는 fullbody에 그림이 있는데 지도용 acting에 없어서 중립으로 바뀌던 연결을 수정했다. 존재하는 대화 전용 동작만 통과하고 없는 동작은 중립으로 남는다. 선생님 두 그림은 여전히 기존 픽셀 원본이며 새 매끄러운 그림 완료로 표시하지 않는다.

활성 전용 동작 16개 중 뿔은 기존 원본 격자 제거 검토, 나머지 15개는 별도 제작 대기다. 잠재 키 `hold_skirt`는 자동 제작 대상이 아니다. 요청 명세는 `docs/reviews/dialogue-exceptions/pose-production-requests.json`에 기록했다. 문틀·어른 다리·수레·상처 등 원본과 장면에 없는 요소를 새로 요구하지 않는다.

프로필 58명은 앞선 0.19.24에서 완료됐다. 새 솔방울 친칠라 패키지 다운로드는 실행 프록시의 `Tunnel connection failed: 403 Forbidden`으로 파일 0개 수신 상태다. 우회·재시도하지 않았고 해당 그림이나 59번째 프로필은 이번에 적용하지 않았다. 승인 지도 동작 9개도 이번 범위에서 적용하지 않았다.

최신 main의 0.19.25 사건 이후 장면 변경을 모두 보존해 병합했다. 충돌은 options.rpy의 버전 두 곳뿐이며 0.19.26으로 구분했다.

검증: 통합 main 기준 `dev/check.sh` 단위 검사 및 Ren’Py lint 통과. 웹 배포 조각 7개와 ZIP CRC, 사전 로딩 파일 전체 SHA256 일치. 실제 WASM에서 회의 발언 확대와 저장 복원, 우체국 오후 질문→세련 답변→저장 복원을 확인했다. 강제 자세 렌더 fixture는 실제 서사 진행 검증과 구분했다. 처음 검사에서 아빠 대사 중 강제 지정한 읽는 자세는 불러오기 시 실제 줄의 듣기 자세로 복원되는 것이 정상임을 확인하고, 실제 세련 답변 상태 저장으로 검사 절차를 수정했다.

최종 0.19.26 실제 WASM 검사 통과. 뿔 무릎 꿇기와 선생님 출석부 두 동작은 요청 키·선택 키·표시 키가 일치하며 화면에서 동작 원본이 확인됐다. 해당 세 장의 우체국 배경은 렌더 검증 fixture이며 그 장소에 서사적으로 등장한다는 뜻이 아니다. 근거: `docs/reviews/meeting-source/runtime.json`, `transport.json`, 복원 화면 및 `authored-fixtures.jpg`.
