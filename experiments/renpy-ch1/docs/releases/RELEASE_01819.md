# 0.18.19-dev · 2026-10-15 — 남은 개선 요청 전부 (소유자 지시 "다 하라")

## 1. 시간을 쓰는 선택에만 표시
- 일·잠은 기존대로 표시한다(일자리 판 "마치면 …", 잠 확인창).
- 종을 직접 치는 선택(1주차 광장 종, 2주차 종탑)에 " · 늦은 저녁까지"를 붙였다.
  - 고르기 전에 너울이 경고한다: "외지 사람이 종을 마음대로 치면 초소에서 경위를 설명해야 하오."
- 1주차 종은 대사로는 "초소에서 밤을 보냈다"인데 실제 시간이 흐르지 않았다. 늦은 저녁·입구로 맞췄다.
- 함정인 사건은 결과를 다 공개하지 않고, 짐작할 대사만 넣었다.
  - 백 부인 밤일: "늦게 끝나도 품삯은 드릴게요."
  - 누비 별채: 열쇠를 자기가 갖겠다는 말, 자꾸 초소 쪽을 돌아본다.

## 2. 재판·회의 뒤 3줄 기록 (`systems/room13_trial_notes.rpy`)
- 첫 재판이 끝나면 C1~C4 논점마다, 예방 회의가 끝나면 그 결과를 조사 메모 "지금 궁금한 것"에 남긴다.
  - **확인한 것**
  - **모르는 것**(입증하지 못한 부분)
  - **그 결과**
- 예: "첫 비명 때 할머니는 나비와 함께 있었다. / 그 이후에도 함께 있었다는 것은 확인하지 못했다. / 할머니의 이동에 관한 주장은 남았다."
- 증거 이름·얻는 곳·다음 목적지는 쓰지 않는다(테스트로 기록 ID가 섞이지 않았는지 확인).

## 3. 재조사의 의미와 수상함·범행 분리 (`systems/room13_reinspect.rpy`)
- **촛대 재조사:** 서리에게 "봉해 둔 촛대를 다시 볼 수 있겠습니까?"를 언제든 다시 물을 수 있다.
  - 전체 / 갈라진 면 / 장식 고리를 첫 회차부터 볼 수 있다.
  - 4일에 톡이 핀을 고치는 장면을 봤으면, 장식 고리를 볼 때 "톡의 작업대에서 본 핀의 연결 부위와 닮았다"가 붙는다.
  - 관찰 기록 H15를 얻는다. 이전 회차로 열리는 것은 없다.
- **은호의 숨긴 장부:** 5~6일 은호가 장부를 급히 덮는다. 물어보면 배급표 없는 집에 이자를 붙인 불법 외상 장부다(J16).
  - J16 한계: "13호 사건과 이어지는 내용은 이 장부에 없다."
  - 2주차에 은호가 물자를 거절하면, 이 사실로 대피소 몫을 받는 길이 열린다.

## 4. 알고도 이용하기 (`systems/room13_use_knowledge.rpy`)
- **모르는 척하기:** 할머니가 손님 편지를 읽게 한 것을 안 뒤에 할머니가 "엄마에게서 소식은 없었나요?"라고 묻는다.
  - "아직 기다리고 있습니다"로 답하면, 할머니가 접수대 아래 서랍을 여닫는 것을 본다(H16).
  - 따지는 것은 별도의 선택("손님 편지를 열어 보게 하셨지요.")이다. 한 번 따지면 슬링을 통한 가짜 편지가 더는 통하지 않는다.
- **부탁으로 증언 확인:** 도토가 "복도 끝까지 다 보였다"고 하면, 그 자리에 다시 서 달라고 부탁할 수 있다. 모퉁이에 가려 계단 첫 칸부터는 안 보인다(J17). 증언 범위를 좁힐 뿐 범인 증거는 아니다.
- **봉인 보존과 개봉:** 점검함의 경고 봉투를 그 자리에서 뜯거나(예전대로), 봉한 채 챙길 수 있다.
  - 봉한 채 챙기면 초롱과 함께 열거나(E18 + J18: 초롱이 맡아 둔 봉투, 봉인 온전), 13호에서 다람이와 열 수 있다.
  - 초롱 확인 없이 할머니에게 보이면 할머니가 "뜯어진 봉투면 누구든 바꿔 넣을 수 있잖아요"라고 받아친다.
  - 기록이 사라지거나 진행이 막히지는 않는다. 달라지는 것은 무엇을 보여 줄 수 있느냐다.

## 5. 일반 사건은 다가갈지 고른다 (`systems/room13_event_offers.rpy`)
- 장소에 들어가면 바로 시작하던 일반 사건 13개는 화면 왼쪽에 "! 창고 앞에서 백 부인이 누군가를 몰아세우고 있다" 같은 표시로 바뀐다. 누르면 들어간다.
  - 해당 사건: 피코 초상, 슬링 편지, 따닥 증축, 뭉치 봉인, 실룩 거짓 증언, 배급대, 사서 장부, 2주차 종, 계측 장부, 부리 공구, 1주차 종, 톡 고발, 솜이 도둑.
- 지나치면 그 시간 칸이 끝날 때 사건이 그대로 진행된다. 결과는 그 사건의 기존 "모른 척" 선택과 같다. 다음 도착 때 전해 들은 말이 나온다.
- 그대로 자동으로 시작하는 것
  - 다람이 신변·눈앞의 일: 경비 순찰, 처마의 밤이, 가짜 편지의 밤, 사건 당일.
  - 상대가 아빠에게 직접 다가오는 제안: 백 부인 밤일, 까로의 일 제안.
  - 저녁 미션으로 직접 고른 장소의 일.
  - 부엉이 할아버지의 짧은 장면.
- 이전 화면 테스트는 테스트 전용 깃발(`qa_auto_offer`)로 예전처럼 자동으로 들어간다. 새 테스트 `event_offer`가 표시 누르기와 지나친 결과를 확인한다.

## 6. 일자리 관찰
- 일자리 판은 하는 일만 보인다(0.18.16). 증언은 일을 마친 보상이 아니라, 일하며 본 것을 나중에 물어야 얻는다(식사 준비 → 나비, 부품 정리 → 부리, 배달 → 짐표와 끈). 이번에 더 바꾼 것은 없다.
