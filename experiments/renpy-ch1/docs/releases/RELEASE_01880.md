# 0.18.80 · 증거와 물건 아이콘

자료 기록의 범용 봉투·문서 그림과 단순 16×16 도구 그림을 자료별로 구분되는 앤틱 도트 아이콘으로 바꿨다. 물증·관찰 기록·메모·장부 62종, 상점·대여 물건 16종, 필기함 도구 4종으로 총 82종이다. 인물 재구성 중이라는 사용자 요청에 따라 증언의 기존 인물 그림과 P01 엄마 초상은 이번 교체 대상에서 제외했다.

투명 배경, 크림색 종이·목재·황동·버건디·청록 팔레트를 사용한다. 편지의 봉인과 끈, 기록에 붙은 소품, 도구의 실루엣으로 구분한다. 초대 편지에는 솔잎 봉인, 엄마 메모에는 도토리 표시를 둔다. 두 부분의 촛대·고리 안의 핀·수리 부품 등은 자료가 설명하는 범위에 맞춰 대조했다. 확대할 때 거칠게 보이는 종이결과 잔점도 한 번 더 정리했다.

`assets/room13-material-icons079.json`의 좌표를 한 함수로 읽는다. 같은 그림이 자료 60px 격자, 상세 132px 그림, 보여주기·획득 카드, 상점 및 도구 아이콘에 적용된다. 알려지지 않은 새 키는 기존 그림으로 돌아간다. 소지 여부, 건네기·대여·소비, 획득 보상과 입증 조건은 바꾸지 않는다. 현장 단서의 실제 확대 그림을 고르는 함수도 그대로 둔다.

검증: 자료 종류별 매핑, 자르기 범위와 투명도·셀 중복, 읽기 전용 조회를 검사하는 테스트 및 전체 단위+lint, 웹 빌드. 단위 테스트 195개를 포함한 `dev/check.sh`를 통과했다. 실제 Chromium에서 명시적으로 모든 자료와 물건을 가진 검수 상태를 사용하여 목록의 모든 페이지, 상세 그림, 모바일 큰 글씨, 상점, 보여주기 카드와 선택창을 확인했다. 이는 실제 획득 경로를 모두 플레이한 검사는 아니다.

[실제 화면 및 검수](../../reports/material-icons-20261016/README.md). 아이콘 목록·출처는 `art/material-icons-20261016/`.

도트 표현은 필수다. 최종 그림은 기존 픽셀 아이콘을 스타일 참고로 다시 제작하며, 윤곽·명암을 분명한 픽셀 덩어리로 구성한다. 실행 시 64×64 논리 크기와 nearest 샘플링을 사용해 목록과 상세에서 도트 크기를 일관되게 유지한다.
