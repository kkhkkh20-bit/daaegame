# 0.18.86 — 승인된 달빛 광장 메인화면 적용

소유자가 선택한 은백색·청보라빛 클래식 명조 로고와 겨울 광장 시안을 적용했다. 글자 양끝의 별 모양 반짝임은 없다. 시안의 글자 형태와 은은한 빛 번짐을 유지하기 위해 로고는 표지 그림에 포함하고, 메뉴는 그림에서 제거한 뒤 실제 엔진 버튼으로 구성했다.

- 왼쪽 위 달빛 로고, 하단 왼쪽 동일 크기의 가로 메뉴(이어하기 / 처음부터 / 불러오기 / 설정).
- 메뉴는 명조 서체와 얇은 구분선, 선택 항목 아래의 따뜻한 강조선. 메뉴 전용 Noto Serif CJK KR 서브셋은 Room13 Title Serif로 이름을 바꾸고 OFL을 함께 제공한다.
- 저장이 없으면 이어하기·불러오기는 흐리게 비활성화하고 처음부터에 기본 초점을 둔다. 저장이 있으면 기존 이어하기와 불러오기 동작을 사용한다.
- 음악 출처는 작은 하단 링크로 유지. 로딩 표지도 같은 그림으로 맞춰 중복 로고를 없앴다.
- 눈과 등불 연출은 유지하고, 불빛 좌표를 새 광장 그림의 등불·창 위치로 재생성했다. 움직임 끄기도 지원한다.
- 게임 대사·사건·진행 조건과 오프닝 컷씬은 변경하지 않았다.

검증:
- `dev/check.sh`: 단위 검사 및 Ren'Py lint 통과. 별도 직접 실행한 unittest 195개 통과.
- `dev/build_web.py --sdk /workspace/tools/renpy/renpy-8.5.3-sdk --work /tmp/room13-build-moonlit`로 공개본 생성.
- `dev/qa_title.py`: PC/키보드/모바일 터치, 설정·출처 복귀, 움직임 끄기, 새 게임, 저장 후 메인화면 복귀·불러오기·이어하기 검증.
- 전용 네이티브 `dot_fx` 화면 검사는 실행 환경에 `xvfb-run`이 없어 실행하지 못했다. 실제 브라우저에서 새 타이틀 조명·눈 및 움직임 끄기 화면을 확인했다.

검수 출력: `/tmp/title086-browser/`, 단위 검사 로그 `/tmp/title086-unit.log`.
