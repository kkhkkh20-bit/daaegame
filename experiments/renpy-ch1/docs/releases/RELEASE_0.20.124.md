# 0.20.124 — 일반 유저 검토에서 막힌 조사와 대화 연결 개선

다친 돌목을 눌렀는데 인사 차단만 나오던 4일차, 보급판·인계 자료와 클릭할 물건 이름이 달랐던 6~7일차를 고쳤다. 돌목·나비·선생님에게 현재 용건을 말하면 기존 조사·인계가 이어지며, 물건을 직접 누르는 경로도 유지한다. 발자국·보급판·명부·잠금은 현 단계의 이름으로 표시한다.

학교 자리와 함께 이동할 뜻을 확인한 뒤에는 깡통 한 번 클릭으로 관찰과 회수를 잇는다. 이전 저장에서 이미 관찰했다면 풀어 챙길 행동과 안내가 보인다. 보리 목격 질문·누비 아이 인수 질문·식당 출발 질문은 하나뿐일 때 인물 클릭 뒤 바로 이어진다. 복수 질문과 자료 제시는 그대로다.

체크한 자료가 정확히 두 장이면 ‘나란히 읽기’가 그 두 장을 바로 펼친다. 읽기만으로 제출·기회 차감·보유 자료 변경은 하지 않는다. 편지 비교를 처음 열 때는 지난 자료가 함께 있는 전체 목록으로 시작한다. 저장된 탭·읽기 기억은 유지한다.

초상화의 손·바늘 묘사를 실제 얼굴·목도리 그림에 맞춰 2일 주문부터 3일 인수, 자료 본문, 10일 선택 덧붙임까지 수정했다. 화재의 앞뒤 맞지 않는 질문과 흔적 설명 반복을 정리하고, 대피 경로에서 불을 발견하는 전환을 보탰다. 주민의 감정 반응은 보존하고 출석·인계의 중복 설명만 소폭 줄였다.

당면 조사·인계 중에는 뒤늦은 피코 사망 알림이 끼어들지 않는다. 3일차 첫 보고와 자유 탐색 반응은 유지한다. 진상·정답 묶음·기회 총수·생사·결말은 바꾸지 않았다.
