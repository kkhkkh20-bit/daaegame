# 0.20.95

2026-11-05. 기존 본편 1~3일차의 이해와 반복 조작을 점검하고, 소유자가 확인한 자료 대조·저장칸 시안을 적용했다.

- 3일 진료소·등 회의의 다섯 자료 제출 쟁점에 기존 통합 자료 대조 화면을 연결했다. 실제 들은 발언과 보유 자료를 같은 화면에서 읽고 고르며, 정답 조합·기회·기존 대체 조합은 유지한다.
- 2일 우체국에서 질문이 비고 자료 제시만 남은 경우 세련을 누르면 기존 자료함으로 이어진다. 취소·오답·자료 수신자 검증은 유지한다.
- 피코에게 초상을 부탁하는 질문이 실제로 하나뿐인 경우 인물 클릭 뒤 바로 주고받기를 이어 간다. 첫 대화·질문 읽음·10분 처리는 유지하며 후속 질문이 있으면 기존 질문 화면을 쓴다.
- 우박의 측정지에 반환 사실이 적혀 있다는 오답 반응을 고쳤다. 반환은 우박의 증언, 측정 종료 시각은 기록으로 구분한다.
- 기존 저장 화면의 슬롯·그림 크기는 유지하고 긴 설명을 칸 안에 맞췄다. 저장 원문과 호환 판정·복원 방식은 변경하지 않았다.
- 기존 브라우저 주행 도구를 현재 통합 화면·명시적 쪽 넘김·우체국 진입 흐름에 맞췄다.

검사 방법·실행 결과·실제 화면은 [초반 경험 개선 기록](../reviews/early-experience-20261105/검수.md)에 보관한다. 초면 인간 사용자가 재미있게 완주했다는 검증으로 세지 않는다.


검사: 전체 단위 1,176개·관련 28개·최종 lint·A/B/C 0·관련 화면 5개 통과. 새 게임부터 3일차 취침 전까지 진행하고 오답 재시도·대체 조합을 확인했다. 실제 이전 저장에서 PC·휴대폰 저장 복원을 통과했고 일반·설정 저장, 자료 대조를 보통·큰 글씨로 확인했다. 마지막 모바일 표시 조정은 해당 화면과 관련 검사로 재검증했다. 경계·미실행 범위는 검수 기록을 따른다.

이전 질문 화면 저장에 새 임시 UI 값이 없어도 이어갈 수 있도록 기본값을 추가했고, 관련 단위 28개와 우체국 취소·오답·수신 화면을 재검증했다.
