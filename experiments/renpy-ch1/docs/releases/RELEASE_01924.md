# 0.19.24 · 여섯 에피소드의 분기별 후일담

각 사건이 끝난 뒤 선택과 피해가 남은 모습을 보여 주는 컷신을 추가했다. 피코가 살아남았는지, 보리가 아이들을 돌보게 되었는지, 수레를 멈췄더라도 바둑이가 다쳤는지 등을 별도로 읽어 실제 결과에 맞는 장면만 이어진다. 회의에 가지 않은 경우와 무쇠의 진료소 이후도 포함한다.

- 신규 그림 24컷과 승인된 원화·장면을 조합한 후일담 프레임 46개.
- 여섯 에피소드의 정상 마무리·기한 초과·불참·진료소 후속 장면 등 10개 진입점 연결.
- 기존 어두운 대사창 재질 유지. 이전/다음, 키보드·터치, 모션 끄기, 큰 글씨와 중간 저장·불러오기 지원.
- 사망·부상·구금·동행 조건을 구분한다. 아빠는 그리지 않는다. 생사, 대사, 증거, 시간, 회의 결과는 유지한다.
- E0–E6 게임 전체 엔딩의 기존 컷신은 유지한다. main의 0.19.22 승인 장면 추가도 병합했다.
- 웹용 그림은 WebP q95로 변환하고 초기 다운로드에 넣지 않았다. 기존 8 MiB 분할 전송을 유지한다.
