# 0.19.68 · 새 본편 초반 연결 검토본

새 게임에서 제작기준본01의 1~3일과 4일 솜이네 대화 시범으로 진입한다. 기존 Ren'Py 대사창·선택지·수첩·저장을 재사용하며, 기존 본편 라벨과 증거 데이터는 유지한다. 새 증거는 `MS14:` 이름공간을 사용하므로 기존 저장의 E01~E35 의미와 충돌하지 않는다.

정본 82장면 원본은 `docs/story-ms14/source/`에 바이트 그대로 보존했다. 이번 실행 연결은 17장면, 712레코드(표시 대상 587개), 명시적으로 작성한 178개 진행 노드다. 자연어 조건을 실행하지 않으며 오답·선택 대안을 배열 순서대로 재생하지 않는다. 2일 피코/네로 선택, 3일 칼 접합 이후 추가 반박, 돌 반환과 인계의 독립 선택, 4일 첫 만남/재회 및 인계 후속을 연결했다.

입구 E03/E04는 각각 자료를 읽은 뒤에만 획득한다. 효과는 원문 record ID별로 한 번 처리하며, 기본 저장·불러오기와 롤백이 전체 커서·선택·처리 ID를 함께 보존한다. 많은 조사 항목은 기존 선택지 화면 안에서 명시적인 다음 페이지로 나눴다. 현재 대화 건너뛰기는 현재 블록을 마치고 다음 입력 앞에서 멈춘다.

원본 보존형 소품·분기 초상과 기존 배경 20개를 선택적으로 연결했다. 문서 미확정 수치, DEV 접합도, 보류 표정, 미확인 음원은 적용하지 않았다. 솜이네 골목과 하역장의 전용 배경은 없으므로 전달 자료가 지정한 외부 배경 후보를 임시로 재사용한다. 이를 현장 구조 검증 또는 최종 미술 승인으로 간주하지 않는다.

검증과 남은 범위는 `docs/story-ms14/IMPLEMENTATION.md`에 기록한다. 5~14일 실행 연결, 전체 연속 플레이와 분기별 저장/연타/롤백, 모바일·웹 빌드, 사람의 재미 검수는 완료되지 않았다. 공개본 생성·main 병합·push·배포는 하지 않았다.
