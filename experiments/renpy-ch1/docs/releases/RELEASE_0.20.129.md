# 0.20.129 — 숨은 회의 인물과 중복 예열 제거

진행 중 지연을 줄이기 위해 단독 회의에서 보이지 않는 주민 전원의 원화까지 생성·예측하던 경로를 현재 화자 한 명으로 제한한다. 회의 좌석·발언 순서·대사·판정은 유지한다. 끝난 놀람 연출도 현재 표정만 준비한다.

그날 인물의 옛 원화·모든 표정·특수 자세를 합쳐 받던 예열 목록은 현재 중립 대화 그림과 현재 현장 그림으로 줄였다. 예열에서 빠진 파일과 나중 장소의 음악은 실제 사용 때 기존 점진 로더로 제공한다. 타이틀·마차의 필수 음악과 효과음은 유지한다. 현행 정면·크기·현장 원화의 인물 분류 누락도 고쳐, 원화가 도착하기 전에 흐린 축소 인물이 잠깐 나타나는 것을 막는다. 원화의 품질·표현·표시 크기는 변경하지 않는다.

[측정·화면·검증 범위](../reviews/performance-20261108/검수.md)에 기록한다. 대사·자료·정답·생사·결말·공개 1부 경계는 변경하지 않는다.
