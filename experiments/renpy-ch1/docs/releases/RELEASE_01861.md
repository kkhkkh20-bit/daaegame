# 0.18.61 · 회의 정면 인터뷰 샷

회의 발언 중 현장용 옆모습과 양옆 참가자를 함께 보이던 구도를, 기존 정면 대화 이미지 한 명의 얼굴·상반신이 크게 보이는 구도로 변경했다. 일반 대화와 같은 표정별 이미지 및 중심 보정을 재사용한다. 배경도 1.25배 당겨 원탁/석판의 전경 가림을 같은 좌표로 맞췄다.

발언 선택·회의 안건·의견 공개에서는 전체 참가자 구도를 유지한다. 화자 변경 시 짧은 좌우 이동, 움직임 끄기 설정, 대사 중 자료 제시와 취소/저장 복귀는 기존 동작을 유지한다.

검증: 단위 검사와 Ren’Py lint, 웹 빌드. 실제 Chromium에서 7일 회의·정면 대화·자료 제시·취소/저장 복귀·반론 선택·의견 공개·모바일/큰 글씨·14일 제단 회의를 확인했다. 회의 시점의 명시적 검토 상태로 확인했으며 전체 14일 경로를 플레이한 검사는 아니다.
