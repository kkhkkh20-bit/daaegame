# Room13 0.20.18 — 피코 시범: 2일 오후를 행동으로 판정, 살린 피코가 5일 회의를 돕는다

### 2일 오후 (열쇠표 K1)

- 「피코가 오늘 안에서 잘 자리를 마련한다 / 네로를 만나 물자 일을 돕는다」 메뉴와, 선택 전에 결과를 알려 주던 지문 두 줄을 뺐다.
- 현장에서 움직여 실제로 한 일이 결과를 정한다. 식당 나비에게 포대를 옮기고, 여관 할머니에게 마른 천을 빌린 뒤에야 광장 피코에게 자리를 전할 수 있고, 그 길로 함께 식당에 들어가면 피코가 산다. 식당 나비에게 「네로를 만나러 간다」를 고르면 오후가 끝나고 피코는 밖에 남는다. 반쯤 하다 떠나면 한 일은 남지 않는다.
- 나비의 경고("등이 꺼지면…… 못 견딜 수도")를 사실만 말하는 문장으로 바꿨다. 할 수 있는 일은 아빠의 생각 한 줄로 알려 주되, 무엇을 잃는지는 말하지 않는다.
- 맞바꿈(네로 쪽 담요 두 장 / 피코 생존)은 그대로다. 옛 저장을 위해 이전 라벨(`shelter_choice`, `shelter_work`)은 남겼다.

### 연쇄 P1 — 피코의 처마 옆 그림

- 피코가 살아 있으면 4일 밤 식당에서 아빠에게 숯 그림을 건넨다(새 자료 「피코의 처마 옆 그림」). 허리를 숙인 사람·찢어진 소매·맨발·처마 기둥 절반을 넘는 키. 얼굴은 없다.
- 5일 초소 회의에서 「돌목의 최초 진술 + 울타리 천 + 피코의 그림」으로도 밤이를 풀 수 있다(겉옷 대조·귀가 진술을 대신). 그림으로 이기면 아빠·돌목·너울의 대사가 그림을 짚는다. 회의 결론은 바뀌지 않는다.
- 자료 그림은 임시판이다(`dev/make_piko_sketch4.py`, 1일 가족 그림 종이에 숯 선).
