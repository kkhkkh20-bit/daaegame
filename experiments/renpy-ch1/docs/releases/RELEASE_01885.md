# 0.18.85 · 기존 겨울 마을 배경 복구

사용자가 요청한 배경 롤백이다. 인물이 있는 숲 표지 원화를 제거하고 기존 겨울 마을·여관·마차 배경을 원래 파일 그대로 복구한다. 웹 로딩 배경도 같은 그림을 사용한다. 조명 생성기 좌표를 기존 등불·창 위치로 돌리고 빛 판을 다시 생성한다.

로고·버튼·메뉴 위치는 이번 복구에서 바꾸지 않는다. 새 디자인은 이미지 시안으로만 제시하며, 사용자 적용·배포 요청 전에는 게임에 반영하지 않는다. 이 작업 원칙을 저장소 지침에도 기록한다.

검증: 원래 배경 파일과 SHA-256 일치, `dev/check.sh`(단위 테스트·Ren'Py lint), 웹 빌드와 실제 Chromium 타이틀 화면 확인. 이야기와 게임 진행 로직은 변경하지 않는다.
