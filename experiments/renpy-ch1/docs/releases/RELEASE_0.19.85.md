# 0.19.85 — V1.1.1 4~14일 기존 시스템 연결

3일차 종료 지점에서 막히던 V1.1.1을 14일까지 기존 Room13 조사·대화·지도·수첩/제시로 잇는다. 새 엔진이나 새 게임 메뉴를 만들지 않았고 최신 마차/UI/승인 자산을 보존했다.

원문 82씬·3162레코드·113개 개별 조건은 보존한다. 목격/부분 증언 지급, 대피/피해 자료, 실제 아이 인수, 안전 통로·심리 증거, 석방·재회·물자 수령/사용, 실제 탑승/인수 및 신병·감독 역할을 명시적인 native 분기로 연결했다. 전원 구조·가족 우선·부분 구조·폭행 결과는 다른 상태와 실제 장소로 끝난다. 부분 인수 한 번이 전원 구조가 되거나, 없는 인물이 말하거나, 폭행 직후 즉시 화해하는 결과를 방지한다.

기존 지도 표면/장소 별칭, 수첩 자료 분류, 붐비는 현장 배치와 주민 동행 범위의 연결 오류도 고쳤다. 새 이미지·음원은 만들지 않았다. 일반 인물은 기존 위치에 유지하고 대본의 사망·신병·이동 결과만 우선한다.

검증: 원문/변경 조건 검사, `dev/check.sh`, 공식 SDK 웹 빌드, 실제 저장에서 이어 진행한 Chromium 클릭 검수. 주요 네 결말 및 A/B/C, 12일 세 경로, 추가 교사 탑승·분리 감독과 부리 협력을 확인한다. 정확한 분기·실제 화면·미실행 조합은 [검수 보고](../story-v111/verification414/PLAY_REPORT.md), 감사 21건은 `../story-v111/AUDIT_21_STATUS.csv`에 기록한다. 저장/로드/스킵 기본 행렬은 별도 반복하지 않았다.

최종 검사 결과와 공식 게임 빌드 해시는 검수 보고의 RESULTS.json에 남긴다. 공개 커밋은 GitHub Pages 빌드 메타데이터와 push한 HEAD를 대조한다. 그림의 존재와 공간/동작 일치는 구분하며, 미확정 확대/동작/CG는 기존 자산·토리 작업 대조 목록으로 유지한다.
