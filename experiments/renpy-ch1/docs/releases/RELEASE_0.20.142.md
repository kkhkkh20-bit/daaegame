# 0.20.142 — 병렬 리뷰에서 확인한 대사·추리·자료 UI 수정

작성자를 확인하기 전에 편지를 아내가 보냈다고 단정하던 쪽지를 고쳤다. 첫 방의 다람 응답은 아빠의 비교 제안을 받도록 바꿨다. 3일차 칼 일치 설명은 직접 접점을 확인한 뒤로 옮기고, 마지막 돌 쟁점은 이미 인정한 판매 사실과 다투는 취득 경위를 구별했다.

화재에서는 아빠의 근거별 질문 다음에 보리의 같은 등유 질문이 반복되지 않고 누비의 기존 답이 이어진다. 보리 목격 발화와 두 재인용을 같은 해요체로 맞췄다. 11일차의 자료 제시 전 해설은 비교 질문으로 바꾸고 결론은 성공 뒤에 남겼다.

단일 발언은 인용을 펼친 자료 목록부터 시작한다. 되묻기·재독과 저장한 화면은 유지한다. 선택 자료 모아보기에서 페이지 밖의 선택물 이름을 확인하고 읽거나 해제할 수 있다. PC의 긴 발언 행 여백을 늘리고, 화재 복귀 버튼 중복과 획득 알림의 관찰문 가림을 정리했다. 새 이미지·음향은 추가하지 않았다.

기존 정답·대체 조합·기회·자료 획득·생사·결말·공개 1부 7일 경계는 유지한다. 5일의 후속 반론에 새로운 판정을 추가하거나 11일의 기존 이유 선택을 없애지는 않았다.
