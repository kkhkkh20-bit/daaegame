# 0.19.10 — 꽥순 실제 5표정 연결

꽥순의 joy/flustered/angry/anxious/surprise가 모두 승인 중립 한 장으로 표시되던 상태를 각각 다른 표정·상체 동작 원본으로 연결했다. 분홍 깃털·청록 코트·크림 목도리·치마·부츠의 같은 배역 디자인을 직접 대조했다. 중립 원본과 조사 행동·프로필·회의 그림은 유지한다.

- 원본5 PNG와 전달 manifest는 `art/incoming/kkwak-expressions-20261017/`. ZIP/내부 파일 해시 검증, 실제 RGBA와 불투명 신체 경계의 프레임 여백 확인.
- 원본 크기의 lossless WebP, 중간3px 축소 없는 native_detail. 좌표 map은 1:1 원본 크기를 유지하고 발 기준의 수직 위치만 정렬한다. mapped 그림도 native_detail을 사용할 수 있게 기존 분기를 확장했다. 눈 깜빡임의 옛 조각은 추가하지 않는다.
- [전후 이미지](../reviews/01910/comparison.png): 같은 엔진/배경에서 이전 neutral fallback과 이후 표정을 비교. 전신 검수 높이560으로 날개·꼬리·발을 확인했다. 실제 대화 높이840도 별도 로컬 캡처에서 날개/얼굴 잘림 없이 확인했으며, 하체는 기존 대화 확대 범위대로 화면 아래로 이어진다. 공개 사이트 전후를 촬영한 자료가 아니라 빌드된 게임의 로컬 엔진 검수다.
- 단위 검사 전체 + Ren’Py lint 통과, 원본/런타임 픽셀 동일성 및6개 서로 다른 파일 검사, 웹 빌드, 실제 Chromium/Ren’Py 6표정 전후 출력 확인.
- 동시 진행된 main 0.19.9의 양피지 지도 변경을 병합하여 보존. 생성된 웹 파일 충돌은 소스 병합 후 build_web.py로 재생성. 선택지/대사창 시안은 적용하지 않음.

별도 수신된 선생님·돌목·도토·구슬·너울·누비·보리·초롱 후보는 이 릴리스의 완료 수량에 포함하지 않는다.
