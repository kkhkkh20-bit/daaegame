# 0.20.59

2026-10-26 납품 그림 중 대기하던 것을 연결하고, 오래 실패하던 화면 시험 16건의 원인을 정리했다.
소유자: "응 해"(남은 순서대로 진행).

## 그림 연결

- **아랫길 노인**: 흰 테두리 입석 한 장 대신 테두리 없는 6감정(39번 묶음 후보). 받은 그대로는 가장자리가
  반투명이고 감정마다 발 높이가 최대 45px 달라, 알파를 0/255로 정리하고 발 밑줄을 맞췄다.
  얼굴 아이콘은 새 평온 그림에서 잘라 냈다.
- **13호 난로**: 13호 배경에 난로가 없어 빈 벽에 조사 자리만 있었다. v2 세 장에서 난로 부분만 떼어
  여섯 배경(사건 전후 x 아침·오후·저녁) 조명에 맞춰 겹친다. 날짜별 상태는 대본을 따른다.
  - 7일 전: 보통 불빛(도토가 갈아 넣은 배급 돌)
  - 7·8일: 그날 한 일(그대로면 검푸른 안쪽 돌, 바꿔 넣었으면 배급 돌, 꺼냈으면 빈 난로)
  - 9일부터: 서리가 8일에 꺼낸 뒤의 빈 난로
  - 재받이 돌 조각은 주머니에 넣거나 난로에 바꿔 넣기 전까지만 보인다.
  - 조사 자리(난로·재받이)는 그려진 자리로 옮겼다.
- **판돌 집**: 7일 문간(쟁반·문), 11일 실내(안쪽 돌), 돌을 바꾼 뒤 장작불. 숟가락·핀·고친 손잡이는 대사 줄 위 그림으로.
- **옛 시설 정비실**: 닫힌 문 → 연 문 → 실내. 종이·표시한 종이·판 앞뒤·단면판·점검표·엄마 수첩은 대사 줄 위 그림으로.
  문이 열리는 줄에서 그림도 열려 있게 `opened` 를 대사 앞에서 세운다(이 값은 도착 때 바로 실내로 가는 데만 쓴다).
- 정비실은 옛 시설과 장면 키가 같아, 대사 장면에서 옛 배경이 나오지 않게 지금 장소를 먼저 찾는다.

연결하지 않은 것:
- **회의 입석 5명**(할머니·나비·부리·도토·보리): 화면이 바뀌므로 시안 먼저(`art/meeting-stand-20261026/preview-now-vs-stand.png`).
  원래 10명 요청 중 5명만 와서, 적용하면 세련·서리 등은 앉은 그림 그대로 섞인다.
- **판돌 누나**(3표정): 이름이 정해진 뒤 연결한다. 지금은 지문 속 목소리.
