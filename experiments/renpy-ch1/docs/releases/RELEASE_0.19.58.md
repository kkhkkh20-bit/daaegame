# 0.19.58 첫 사건의 여러 승리 논증

첫 사건에서 현장 끈을 놓쳐도 거래 자료나 두 사람의 목격을 연결해 같은 승리를 얻는다. 기존 다섯 발언 전체 반박 조건을 새 회의에서 없애고, 반출한 사람·행동·허락 여부가 실제 제출한 근거로 연결됐는지 판단한다.

- 초롱의 첫 순찰과 반출 관찰, 부리의 목격, 백 부인의 매입 원장, 실룩의 정산 쪽지와 회의 중 설명을 L15~L20으로 추가했다. 질문·제시 계기와 관찰의 한계를 구분한다.
- 상대의 재반박에 답해야 입증이 확정된다. 서로 다른 방법의 근거를 섞을 수 있으며, 무관한 자료 반복이나 과장으로 빈틈을 메울 수 없다.
- 결론 정리는 조사 완료 표시 없이 열려 있다. 최종 확정 전에 회의로 돌아갈 수 있고, 확정 후에는 그 논증으로 승패를 판단한다. 두 번 오답 뒤의 자동 힌트는 새 회의에서 제거했다.
- 어떤 경로로 이겨도 톡 석방과 같은 처분 선택으로 이어진다. 창고 미조사 경로는 승리 뒤 공개 확인을 거친다. 빚 조건도 실제 진술로 확인하며, 사망·후속 증언 부탁·조각 반환·수레 선택의 인과는 유지한다.
- 이미 진행 중이거나 끝난 구형 회의 저장은 기존 규칙을 유지한다. 새 논증과 증거는 현재 회차의 전체 저장에 포함되고 재시도로 누적되지 않는다.
