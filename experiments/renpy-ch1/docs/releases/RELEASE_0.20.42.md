# 0.20.42 — 숨겨진 가족과 고대 기지

판돌의 생활 식기를 고치며 숨겨진 가족을 발견한다. 가설 회의에서 이긴 뒤 학교에 실제 도착한 장작의 남는 몫을 허락받아 난방을 바꾸고, 13일에 나비가 돌봄을 맡는 것까지 확인한다. 돌봄을 맡을 사람이 없으면 완료되지 않는다. 먼저 만난 판돌은 11일에 다시 자기소개하지 않는다.

1·7·11일에 모은 조각으로 진엔딩 판의 14일 저녁에 고대 정비실을 선택 방문한다. 문을 맞추고 장치·사고 기록·엄마의 수첩을 살핀 뒤 돌아온다. 기존 진엔딩 조건과 회의 판정은 유지한다.

전용 그림은 미납품으로 기존 배경을 임시 사용한다. 판돌의 누나는 별도 인물 그림 없이 지문과 목소리로 표현한다. 전체 대사 개작은 후속 작업이다.
