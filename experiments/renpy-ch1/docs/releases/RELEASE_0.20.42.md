# 0.20.42 — 수첩 UI 공통화

소유자가 전체 화면 비교 후 승인한 UI 통일 작업이다.

- 메인·설정·질문·선택·지도·기록·회의 조작에 공통 크림/빨강 스티커 버튼을 연결했다. 폰트는 굵은 Pretendard를 유지한다.
- 상태별 크기 계산과 렌더 캐시를 고쳐 버튼 그림이 지정 영역 밖으로 커지는 현상을 막았다. 원래 가족별 클릭 영역과 글자 안전 영역을 보존했다.
- 설정 미리보기와 행 간격, 회의 자료 대조의 안쪽 여백을 정리했다.
- 기록·자료 대조에는 공통 수첩 패널, 여관·숲 지도에는 마을 지도와 같은 외곽/하단 조작을 적용했다.
- 선택지마다 반복되는 테이프를 제거했다. 선택·회의 인물에 스티커 외곽을 적용했다.
- 에셋 스캔 때 공통 버튼이 옛 이미지로 되돌아가지 않도록 도구함 레시피도 수정했다.

대사·판정·분기·이동 가능 조건은 변경하지 않았다. 상위 0.20.41 이야기 변경 및 이후 설계 문서를 보존했다.
