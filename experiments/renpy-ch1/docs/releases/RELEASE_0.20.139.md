# 0.20.139 — 자료를 보여 준 뒤 이어서 묻는 조사

입구에서 방문 신청 원본을 돌목에게 직접 보여 줄 수 있다. 답을 들은 뒤에만 신청서 기재를 인정한 상태를 기록하고, 근거 대조 화면에도 방금 들은 발언을 펼쳐 보인다. 인정은 등록 완료가 아니며 기존 명단·신청서의 근거 제시로 등록을 마친다. 이미 확인한 신청서를 다시 보여 주면 짧게 되말한다.

2일차 초롱에게 두 글을 확인한 뒤에는 ‘왜 여기서 펴면 안 되죠?’와 ‘두 글 모두 아내 글씨입니까?’를 선택해 물을 수 있다. 초롱은 방 메모의 필체만 인정하고, 여기서 편지를 펴면 안 되는 이유에는 답하지 않는다. 플레이어는 답을 듣고 질문이 사라지는 것을 볼 수 있다. 두 질문을 반드시 골라야 이동하는 구조는 아니다.

다른 자료나 이미 확인한 자료를 보여 주면 해당 주민이 그 자료로 확인할 수 있는 범위에서 답한다. 자료 제시의 취소·반복만으로 정답, 등록 결과, 회의 기회가 바뀌지 않는다. 새 증거·새 진상·그림·생사·결말은 추가하거나 바꾸지 않았다.

검증 결과와 화면은 [검수 기록](../reviews/inquiry-20261109/검수.md)에 남긴다.

관련 단위113개·생성 메타데이터24개·SDK5개 통과. 최종 로컬 웹에서 새 게임부터 입구 원본 제시와 발언 반영을 확인했고, PC 저장·새로고침·불러오기와 두 화면 크기를 확인했다. 초롱 후속 질문은 준비 상태의 SDK 시험이며1~7일 전체 재완주는 하지 않았다.
