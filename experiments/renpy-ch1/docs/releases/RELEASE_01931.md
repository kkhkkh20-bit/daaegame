# 0.19.31 — 조사 지도 P0 동작 8종

승인 아트 커밋 `9371f483d2c3e6026cfa3784c90507c91f8e6376`에서 ZIP3개와 manifest만 읽었다. ZIP SHA256·bytes·CRC, 내부/외부 manifest 배열 일치, PNG8개 SHA256·bytes·1024×1536 헤더를 확인했다. 원본 PNG는 `art/approved-action27-p0/originals`에 바이트 그대로 보존한다. 아트 브랜치 전체를 병합하지 않았다.

적용 범위는 장터 은호 장부(MK-2), 구슬 저울(MK-3), 누비 천(MK-4), 여니 장갑 수선(MK-5), 달그락 항아리(MK-6), 우체국 슬링 소포(PO-1), 광장 피코 액자(SQ-2), 수리점 톡 랜턴(WS-1)이다. 기존 실제 등장 일정·사망·구금·우선 사건을 유지하고, 기존 인물이 그 장소에 있을 때만 새 자세를 쓴다. P0 장터용 동작의 창고 재사용은 이번 범위에 포함하지 않는다.

지도 전용 파생 출력은512×768 RGBA, 2px 격자, lossless WebP(exact alpha/RGB)다. 런타임에서도 기존2px 조사 렌더러를 사용한다. 팔레트를 감축하지 않았고 은호의 녹색 크라바트가 남는지 검사했다. `actual-size-pixel-comparison.png`에 실제 지도 높이의 원본 축소/최종 도트와 얼굴4배 확대를 나란히 남겼다. 원본의 투명 영역 RGB만 정규화하며 유효 색·알파는 보존한다. 대화 smooth·프로필·회의 그림은 변경하지 않았다.

init178에서 기존 perspective126, map9 176, 솔방울177 이후 최종 접점 배치를 수행한다. 인물별 가림과 손·소품 전경 영역을 함께 계산하며 클릭 mask도 같은 표시 함수를 쓴다. 완성된 배치 높이에 원근을 다시 적용하지 않는다. 우체국은 오전2160폭과 오후/저녁1280폭에 별도 좌표·가림을 사용한다. 이벤트 offer가 있으면 새 자세로 덮지 않는다. 달그락만 장터의 기존 map9 항아리 동작을 새 승인 변형으로 대체한다. 나머지 map9와 숲 솔방울 약초는 유지한다.

실제 배경·게임 검수 보정:

- 피코: 도토와 겹치지 않게 벤치 안 발 기준을(1020,585)로 조정.
- 톡: 시안(1380,426)은 실제 배경의 작업대가 아닌 통/판자 앞이었다. 실제 오른쪽 작업대 위(1585,383)에 랜턴 바닥을 맞추고 가림 다각형을 새로 측정했다. 다른 주민 위치를 옮기지 않고 소품 겹침을 해결했다.

검증: 단위 검사·Ren’Py lint, 원본/파생 파일·2px/알파·의상 색 검사, 배포 조각과 사전 로딩 파일 SHA256·ZIP CRC. 실제 Chromium/WASM에서8동작과 슬링3시간대, 얼굴 클릭과 가려진 발의 클릭 제외를 확인했다. 은호·슬링 오후·톡 저장/불러오기와 지도 이동 후 복원을 검수했다. 전체 캠페인 반복 실행이 아닌 실제 일정 상태 fixture다. 최종 실행 결과와 초기 QA 도우미 오류의 구분은 `docs/reviews/action27-p0/runtime.json`에 기록한다.
