# 0.20.131 — 실제 클릭과 첫 방의 발견 단계 교정

0.20.130 실 플레이에서 확인한 다섯 항목을 고친다.

- 입구 장부를 큰 서류보다 우선 처리해, 실제 장부를 눌러 명단을 건네받고 읽는다. 같은 시간 마커를 사용해 조사 비용을 중복 소모하지 않는다.
- 가족 그림의 왼쪽 아빠에게 세 팔, 작은 아이에게 두 팔이 보이도록 교정한다. 발견 컷과 E30 상세가 같은 교정 파일을 사용한다.
- 첫 방은 두 편지를 함께 펼치되, 글의 다른 부분을 직접 짚어야 비교를 완료한다. 미관찰 제시는 기회를 쓰지 않고 관찰 화면으로 이어진다. 이미 완료한 저장은 다시 관찰하지 않는다.
- 자료·화재 연결의 보조 버튼을 질문창의 부드러운 갈색 종이 표현과 맞추고, 주요 제출의 빨강은 유지한다.
- 너울의 일반 여섯 표정을 기존 다람의 도트 기준에 맞춘다. 의상·정면 시선·표시 키·발선과 표정 대응은 보존한다.

기존 증거·정답 문서 조합·생사·결말·공개 1부 경계는 유지한다. 관찰 UI는 문서 비교를 완료하기 전 단계이며 새 사건이나 자료를 추가하지 않는다.

검증: 관련 단위165개·SDK 화면10개 통과, lint·웹 버전 확인 완료. 후속 검수에서 3일차 걸쇠 설명의 구조 그림 부재를 새 개선 항목으로 기록했다. 전체 7일 연속 완주 결과는 아니다.
