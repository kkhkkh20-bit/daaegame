# 0.19.49 — 회의 대사창에 맞춘 테이블과 연속 조작 검수

근접 회의 테이블 상단을 16px 내려 대사창 윗변(기본 y492)에 맞췄다. 원탁 중심492·가장자리496이며 제단 중심도492다. 배경은 비율을 유지한 확대·중앙 크롭으로 맞추고, 인물 원화·크기·의상·전체 좌석 배치는 유지한다. 공통 UI와 생활 그룹 0.19.48을 포함한다.

검수 범위는 로컬 SDK 실제 실행이다. 회의 최초 조건을 설정한 후 실제 입력으로 진행하는 연속 흐름과 별도 제단/전체 좌석 렌더러 조건 설정을 분리해 기록한다. 공개 cloud 브라우저의 WebGL 실패를 플레이 검수 불가능으로 해석하지 않는다. 전체 캠페인·실기 휴대폰·다른 대사 묶음으로의 롤백은 검수 범위가 아니다.

검증 완료:410 단위 검사·SDK lint·공식 빌드와7개 분할/1210개 사전 로딩 파일의 SHA·CRC. 실제 저장/불러오기 메뉴, 자료 취소와 되묻기 복귀, E35 제시 반응, E09 반론·동일 화자 다음 대사의 카메라 유지, 모바일 건너뛰기의 선택지 정지와 답변 후 회의 복귀를38개 입력 전환으로 기록했다. 처음에 전체 자료와 C1 입증 조건을 설정한 구간 검사이며 자연 캠페인으로 표시하지 않는다. 보고서: reports/meeting-continuity-01949.
