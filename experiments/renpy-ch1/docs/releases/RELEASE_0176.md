# 0.17.6-dev · 회의 자리와 발언자

0.17.5 main(57ed9c5)을 기준으로 기존 회의 표시층만 고쳤다. 회의 판단 함수와 label 전체는 바이트 동일하다. C2/C4의 자료 반박·결론·입증, 여론 표시의 계산과 판결 규칙은 바꾸지 않았다.

- 식당 회의 8명과 제단 회의 6명을 기존 프로필로 탁자 둘레에 배치했다. 새로운 전신 착석 그림을 확정하거나 기존 바닥 앉기·휴대 의자를 임의 변형하지 않았다.
- 선택한 발언자의 자리 테두리·이름·중앙 발언 표시를 강조한다. 참석자 명단 밖의 발언자도 중앙과 오른쪽 프로필에 표시된다.
- 참석자의 자리를 누르면 그 사람이 현재 공개한 첫 발언을 선택한다. 발언이 없는 참석자는 새 주장이나 숨은 자료를 노출하지 않는다.
- 기존 여론 합계는 오른쪽에 줄별로 표시해 긴 이름과 겹치지 않게 했다. 입증 규칙은 그대로다.
- 발언 목록 스크롤 위치는 논점별로 기억하고 자료 제시 취소 후 유지한다. 긴 힌트는 별도 viewport, 되묻기·자료로 반박 버튼은 고정해 큰 글씨에서도 접근한다.

Ren’Py screen, viewport, Displayable canvas와 기존 프로필만 사용한다. 새 외부 라이브러리나 상시 동작을 넣지 않았다. 자세한 실제 실행 결과와 전후 스크린샷은 저장소 reports/room13-spatial-20261014/MEETING_0176_KO.md 참조.
