# 0.18.48 · 2026-10-15 — 저장·기록 신뢰성, 조사 화면 정지, 대화 건너뛰기, 증거 카드

0.18.46(타이틀 로고)과 0.18.47(그림책 톤, 이상 다른 세션) 위에 쌓았다. 새 기록 카드 뒤의 빛(0.18.47)은 새 카드 위치에 맞췄다. 소유자 검토(저장과 기록의 신뢰성) 5건과 화면 요청을 반영했다.

## 저장·기록

1. 자동저장 불러오기: '최근 자동저장'도 일반 칸과 같은 확인("저장하지 않은 진행은 사라진다. 불러올까?")을 거친다. 두 버튼이 `r13_load_confirm` 하나를 쓴다.
2. 저장 칸: 큰 글씨 설정을 따른다. 칸마다 다음 순서로 보인다.
   - 이야기 속 시점(날짜·시간대·장소)
   - 진행 상태(예: "식당 회의까지 2일 · 촛대 논점에 쓸 자료 1/3")
   - 저장 직전 마지막 대사 한 줄
   - 칸 번호·실제 시각·버전
   진행 상태와 마지막 대사는 이번 판 이후 저장부터 보인다.
3. 과거 대화 기록: 주제를 처음 읽을 때 실제로 나온 대사를 그대로 보관한다. 다시 열 때는 보관한 원문을 보여 주고, 지금 상태(다람이 동행 여부, 사건 조건)로 대사를 다시 만들지 않는다. 이전 판의 저장에는 원문이 없어서 예전 방식으로 보인다.
4. 다시 읽기: 날짜와 상대의 발언(원문 인용, 최대 세 줄)을 먼저 보여 주고, "전체 대화 다시 보기"를 고르면 전체를 보여 준다. 요약이나 해석은 붙이지 않는다.
5. 옵션 초기화가 자동 진행도 끈다.
