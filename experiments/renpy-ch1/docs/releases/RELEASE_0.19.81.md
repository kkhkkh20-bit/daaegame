# 0.19.81 — 풍경의 잔무늬·반복 패턴 정리

사용자가 마차 풍경의 자글거림, 얼룩 같은 눈 표현과 반복 나무 패턴을 지적했다. 같은 마차·먼 마을 구도를 유지하면서 그림을 다시 정리했다.

- 눈은 넓고 깨끗한 면과 큰 그림자로, 산은 큰 명암 면으로 정리한다.
- 먼 숲은 낮은 대비의 겹친 실루엣으로 묶고 가까운 나무·돌·잔가지의 밀도를 줄인다.
- 마차는 작고 어두운 상태로 유지한다. 정지 컷3.5초와 기존 내부 대화·주행음 연결은0.19.80 그대로다.
- 공식 import_art.py로 동일 자산을 교체하며, 웹 asset_versions의 내용 해시로 이전 그림 캐시와 구분한다.

## 확인 범위

0.19.80에서 통과한 단위/lint·자동 전환·건너뛰기 검증은 유지한다. 이번에는 그림과 버전만 바꾸므로 첫3일 분기·저장/로드·기존 UI 검사를 반복하지 않는다. 공식 웹 compile/lint 및 최종 그림의 PC·휴대폰 크기 확인 결과를 아래에 기록한다.

- 공식 웹 compile/lint 통과. 기존 구작 도달 불가 경고만 유지된다.
- 최종0.19.81 웹 클릭 검증 통과: [PC 풍경](../reviews/carriage81/landscape.png), [844×390 풍경](../reviews/carriage81/landscape-mobile.png), 자동 전환 뒤 기존 내부 첫 행동문까지 확인. 신규 그림352,896bytes, 초기 게임 자료 약35.93MB.
