# 0.20.122 — 1부 UI와 대화 연결 검수

첫 마차부터 7일차까지의 대화 연결과 실제 화면을 검수했다. 질문에 답하지 않고 다른 정보로 넘어가거나, 물건·주제가 갑자기 바뀌는 기존 12문장을 고치고 장작을 가리키는 지문 1행을 보탰다. 마차·여관·13호실의 이미 연결된 대화는 유지했다.

- 질문: 호버가 없어도 누르는 행의 범위를 알 수 있도록 기존 종이 면과 가는 경계를 표시한다. 읽음·질문 동작·페이지·입력 지연은 유지한다.
- 더보기: 명시적 닫기 버튼과 자동 읽기의 켜짐/꺼짐 표시를 넣었다.
- 자료 대조·화재 연결: 실제 조사 현장으로 복귀하는 버튼 이름을 ‘현장으로’로 통일한다. 선택·초안·시간·기회·판정은 유지한다. 인물의 발언이 없는 비교 화면의 ‘발언 보기’도 ‘비교 안내’로 바로잡았다.
- 대사: 모모의 직접 응답, 피코의 걱정에 대한 답, 너울과 아빠의 관련성 문답, 공방 방문 목적, 엄마의 비밀 요청 이유, 수건/장작의 화제 구분, 편지 작성자 미상의 답, 상실 이후 보리의 식사 반응을 다듬었다.

원본 records·정답·자료·생사·결말은 변경하지 않았다. 플레이 검수의 실제 범위와 전후 화면·검사 결과는 [검수 기록](../reviews/ui-dialogue-20261108/검수.md)에 남긴다.


전체 단위1,444개·lint, 변경 UI의 엔진 화면 시험과 최종 웹 검증을 통과했다. 같은 새 게임에서 이어 온 저장으로 7일차 1부 완료와 PC/휴대폰 결과 기록까지 실제 입력했다. 1~3일은0.20.121, 4~7일은0.20.122 검수 빌드이며 최종 변경 지점은 별도 준비 시험으로 다시 확인했다. 모든 분기를 한 버전으로 무중단 완주했다고 계산하지 않는다. 검수 보고서에 전후 화면·실제 진행·대사 전후 전문을 보관했다.
