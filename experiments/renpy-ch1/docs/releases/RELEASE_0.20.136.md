# 0.20.136 — 첫 만남·첫 방의 안내와 주민 말투 수정

입구에서 처음 만난 주민에게 아직 여관에 묵고 있다고 소개하던 성인·아동 공통 인사를 고쳤다. 첫 방의 침대가 낱말만 속말로 출력하던 경로는 현재 읽을 메모를 안내한다. 두 글의 차이를 찾은 뒤에는 '발견한 차이 확인'을 누르면 다람과 이야기를 잇는다고 안내한다. 같은 내용의 대체 납품이 없는 임시 과자 봉투의 큰 확대는 제거했다.

하오체가 지나치게 많다는 요청에 따라 1부 1~7일과 공통 인사·반응 247줄을 인물별 현대 말투로 바꿨다. 회의 재인용도 현재 본문과 일치시켰다. 원본 기록·정답·기회·등록 결과·증거·생사·결말은 바꾸지 않았다. 8~14일의 개별 본문 전체 현대화는 이번 범위가 아니다.

[수정 내용·실제 화면·검증 범위](../reviews/arrival-room-20261109/검수.md)를 따른다.

관련 단위198개, 메타데이터 확인21개, SDK6개를 통과했다. 최종 로컬 웹에서 새 게임부터 실제 입력으로 첫날을 마치고2일 아침까지 진행했으며 PC·휴대폰 캡처를 확인했다. 브라우저 pageerror는 없었다.
