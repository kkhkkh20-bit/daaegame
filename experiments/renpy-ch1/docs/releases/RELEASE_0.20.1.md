# 0.20.1 — 저장 오류 수정, 주민 반응(알아낸 만큼 말이 달라짐)

## 저장 오류(소유자 실제 플레이 검수 0.19.99, P1)
- 퍽·흔들림 연출이 나온 뒤 저장하면 "Can't get local object r13_impact_shake.<locals>.shake" 예외가 났다.
- 원인: 흔들림 효과를 함수 안 함수로 만들어, 저장 파일에 넣을 수 없었다.
- 저장 가능한 구조(클래스)로 바꿨다. 같은 경로(흔들림 대사 → 다음 줄 → 저장 → 불러오기) 화면 테스트를 추가했다. 고치기 전 코드는 실패, 고친 뒤 통과한다.

## 주민 반응(승인한 개선안 3번)
- 자료를 얻은 뒤 관련 주민에게 새 질문이 생긴다(질문 앞 「새」). 1~14일차 31개.
- 관련 자료를 보여 주면 그 인물이 멈칫하거나 말을 바꾸는 반응이 나온다. 64개.
- 관련 없는 자료를 보여 주면 시스템 문장 대신 그 인물 말투로 짧게 답한다. 50명.
- 사실·회의 논리는 바꾸지 않는다. 엄마 편지의 도토리처럼 플레이어가 찾을 단서를 짚는 줄은 넣지 않고, 테스트로 막는다.
- 초안은 Codex, 검수는 Claude. 데이터: game/v111/newworld/reactions.json

## 검증
- 단위 테스트와 lint 통과. 저장·새 질문·연출 화면 테스트 통과.
