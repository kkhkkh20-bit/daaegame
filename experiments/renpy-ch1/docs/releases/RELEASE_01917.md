승인된 `8c80550`의 독립 ZIP 8개에서 20명 × 6개 원화 120개의 SHA를 검증했다. 별도 대화 원화 경로에 560/760/840 표시 프로필 360개를 연결했다. 기존 지도 픽셀 그림과 회의·조사 전용 동작은 보존한다. 직전 대화 표정이 남아 있어도 회의·별도 행동 그림을 덮지 못하도록 진입 조건을 검사한다. 미검토 일반 대사는 승인된 중립 원화를 사용하며 옛 디자인으로 돌아가지 않는다.

표정은 장면·화자·실제 문장과 일치한 검토 결과로만 선택한다. 놀람은 0.35초 반응 뒤 대화 자세로 정착하고, 화면 재구성·불러오기·스킵 때 재연하지 않는다. 긴 화면 시간 때문에 반응이 즉시 끝나던 렌더 시계 문제를 실제 화면 검사에서 찾아 수정했다.

최신 main 0.19.16의 엄마 정보 공유, 증거 답변, 미독 대사 스킵을 보존했다. 변경 의심 11건 중 10건의 문맥을 다시 검토했고 굴돌 1건은 이스케이프 따옴표 오탐이었다. 따닥 생존/사망을 구분한 호출도 추가해 총 119개 동적 호출을 연결했다. 선생님의 “고맙습니다. 걱정 마세요.”는 두 문맥 모두 표면상 침착한 중립이다.
