# 0.19.17 — 회의 공방 연출

정확한 발언에 근거를 내면 ‘잠깐만요!’로 공방을 끊고, 카메라와 현재 주장을 고정한 채 자료를 설명한다. 상대의 재정비·역공·최종 항변과 주민의 짧은 반응에 조명·구도·배경음을 함께 연결했다. 식당 원탁, 제단 돌판, 광장·학교의 모든 기존 C/F/Q 회의에 적용한다.

맞는 자료만으로 승리를 먼저 선언하지 않는다. 기존 역질문을 통과해야 성공음·반박 완료가 나오며, 자료 부족·부분 입증·포기·집행 실패 결과는 그대로다. 새 판결·의심 수치·랜덤 패배를 추가하지 않았다. 기존 표정과 음악을 재사용했고 새 고해상도 이미지 자산은 없다.

구체적인 구성과 검증 범위: [회의 연출 검토](../reviews/01917/MEETING_DIRECTION.md).

최종 검증 결과는 완료 후 기록한다.
