## 옵션: 소리 / 화면 / 게임 세 탭 (소유자 지시)
- **소리:** 배경음, 효과음·대사 소리(볼륨과 켜짐/꺼짐).
- **화면:** 글자 크기 3단계(작게·보통·크게), 대사창 진하기 3단계(연하게·보통·진하게), 인물 전환 효과, 전체 화면 전환(안드로이드 브라우저. 아이폰 사파리는 웹 전체 화면을 지원하지 않음).
- **게임:** 대사가 나오는 속도, 자동 진행 속도, 읽은 대사 빠르게(게임 중), 저장 정리(0.17.2의 정리 창을 옵션에서 바로 열기).
- 마지막에 고른 탭을 기억한다. 버튼은 게임의 기본 패널(진녹색 바탕, 금색 테두리, 계단 모서리)을 쓴다.
- '작게'는 지정 크기의 약 90%다. '크게'는 기존 큰 글씨와 같다.
