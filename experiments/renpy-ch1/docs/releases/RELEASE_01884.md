# 0.18.84 · 전용 원화로 구성한 겨울 동화 메인화면

기존 골목 배경 대신, 다람이·봉인된 편지·나무의 붉은 실·숲 너머 마을을 하나의 구도로 그린 타이틀 원화를 넣었다. 왼쪽의 인물과 편지에서 다리와 마을로 시선이 이어지고, 오른쪽 안개 공간이 제목과 메뉴를 받친다. 색 필터로 분위기를 바꾸는 대신 원화에 달빛과 눈·숲의 명암을 담았다.

다람이는 기존 전신 원화를 참조했다. 새 인물 초상화나 아빠를 추가하지 않는다. 장소 배치는 실제 이동 지도가 아닌 상징적인 표지 구도이며 새 사건의 사실·해답을 추가하지 않는다.

제목은 ‘다람탐정’을 유지하며, 눈과 마른 가지·작은 붉은 봉인이 달린 아이보리 책 글씨로 다시 그렸다. 주 행동은 붉은 봉인색의 큰 버튼, 나머지는 양피지 탭으로 만든다. 저장이 없는 첫 실행에서는 이어하기와 불러오기를 숨겨 처음부터·설정만 남긴다. 저장이 있으면 이어하기·처음부터·불러오기·설정의 네 줄이 된다. 음악 출처는 하단의 작은 링크다.

새 원화에 맞춰 생성기의 타이틀 조명 좌표를 바꾸고 `dev/make_dot_fx.py --title-only`로 빛 판을 다시 만들었다. 눈은 더 적고 느리게 내린다. 움직임 끄기는 기존 설정을 따른다. 웹 로딩 화면도 같은 원화·로고를 사용하며, 오프닝의 공유 로고는 비율을 유지해 넣는다. 쓰지 않는 이전 타이틀 배경은 제거했다.

검증: `dev/check.sh`의 단위 테스트와 Ren'Py lint, 웹 빌드, 실제 Chromium에서 `dev/qa_title.py`(키보드·마우스·844×390 터치·설정·출처·움직임 끄기·새 게임·저장·메인 복귀 확인·불러오기·이어하기). 게임 안의 자료·회의 로직과 대사는 바꾸지 않는다.
