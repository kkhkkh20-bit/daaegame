# 0.19.73 — 건너뛰기 버튼 문구·정렬 정리

긴 ‘현재 대화 건너뛰기’를 ‘건너뛰기’로 줄이고 기존 하단 도크의 ‘더보기’와 같은 폭 160, 높이, 간격 16을 사용한다. 기록 버튼이 없는 대화에서는 비어 있던 기록 칸을 예약하지 않아 두 버튼이 오른쪽에서 나란히 놓인다. 기록이 있는 화면은 건너뛰기·기록·더보기 순서다.

마차에서는 상단 중복 버튼을 없애고 하단 건너뛰기가 기존 씬 건너뛰기 동작을 그대로 수행한다. 다른 대화의 기존 확인창과 건너뛰기 동작은 유지한다. 화면·조사·증거 처리나 신규 대본은 변경하지 않는다.
