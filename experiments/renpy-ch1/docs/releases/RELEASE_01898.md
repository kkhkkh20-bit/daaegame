# 0.18.98 — 지도가 보이는 표식, 자료와 관계도 왕복

긴 지도 이름표를 장소 픽토그램으로 줄이고, 선택한 장소 이름만 표시한다. 44px 표식에 64px 터치 영역을 적용하고 건물 윤곽 선택은 유지한다.

자료는 하나의 창에서 전체/증언/전달 가능으로 좁혀 본다. 명시된 출처와 실제 획득 자료만으로 증언↔관계도를 연결한다. 필터와 선택 위치를 기억하고, 빈 슬롯과 한 페이지의 이전/다음 버튼은 숨긴다. 긴 자료명은 읽기 영역 안에서 스크롤되어 큰 글씨에서도 겹치지 않는다. 옛 시설은 기존 발견 조건을 확인해 여관 지하 구역에 표시하고, 현재 위치에서도 올바른 지도를 연다. 이야기·정답·소유권·발견 조건은 바꾸지 않는다.

넓은 시점의 새 월드맵 그림은 `docs/reviews/01898/worldmap-wide-draft.png`에 비교용으로만 저장했다. 현재 게임 지도 그림과 클릭 영역은 유지한다.

레퍼런스, 화면과 검증: [조사·적용 기록](../reviews/01898/RESEARCH.md).

검증 완료: `dev/check.sh`(단위 테스트·Ren’Py lint), 실제 Ren’Py `relations_tab`, PC/844×390 터치·큰 글씨 관계도/자료/지도 검수, 자료별 스크롤과 창 복귀 검수. 지도 표식 11곳의 선택 결과·터치 영역 분리·시간 불변, 미발견 장소/출처 숨김, 회의 자료 필터를 확인했다. 실제 결과는 검수 폴더 `verification.json`에 보관했다.
