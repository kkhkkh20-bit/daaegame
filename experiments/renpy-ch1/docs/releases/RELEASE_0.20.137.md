# 0.20.137 — 첫날의 조사 순서와 기다리는 이유 연결

메모에서 초롱의 단서를 얻으면 편지 비교를 끝내기 전에도 지도에서 접수대로 내려가 행방을 물을 수 있다. 초롱의 현재 위치를 아는지 되묻고, 할머니가 아는 범위를 확인한다. 먼저 물은 경로는 비교 뒤 같은 위치 문답을 반복하지 않는다. 비교를 먼저 마친 경로도 접수대에 직접 가서 질문한다.

문서 비교 버튼에서 오전을 저녁으로 바꾸던 처리를 제거했다. 접수대를 오가며 엄마와 초롱의 귀환을 확인하는 낮의 행동을 보여 준 뒤 저녁으로 잇는다. 비교에서 발견한 차이는 작성자에 관한 의문으로 남기고, 2일차 초롱의 기존 문답으로 이어진다. 입구의 반복 설명과 도토리 습관 재설명을 줄였다.

가족 그림·메모의 첫 확대 중 획득 알림과 만료 시계를 기다리게 해 그림을 가리지 않는다. 과자 봉지를 접는 지문에서는 수첩을 든 다람을 잠시 숨기고 다음 대사에 다시 표시한다. 자료 대조는 문서 원문을 먼저 읽고 중복 요약은 출처에서 펼친다. 상단 안내 중복을 줄여 읽기 공간을 확보했다.

보유 에셋만 재사용했다. 원본 기록·정답·기회·증거 획득 효과·등록 결과·생사·결말은 유지한다. 첫날 조사 동선과 대사 순서가 이번 변경 범위다. 검증 결과와 화면은 [검수 기록](../reviews/first-day-flow-20261109/검수.md)에 적는다.

관련 단위194개·생성 메타데이터36개·SDK5개 통과. 대사 A/B/C0건, lint 및 공개 묶음 확인 통과. 최종 로컬 웹에서 비교 전 접수대 문의 경로로 첫날을 마치고2일 아침에 진입했으며 PC·휴대폰 화면을 확인했다. 1~7일 전체 재완주는 이번 범위가 아니다.
