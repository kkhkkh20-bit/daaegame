# Room13 0.20.14 — 자료별 그림과 실제 플레이 검토 반영

## 바뀐 동작

- 자료 80종의 기존 원화를 대조해 목록·상세·제시 화면에 연결했다. 전용 원화 68종, 상태별 그림 3종, 증언자 얼굴 9종이다. 기존 그림이 모두 있어 중복 생성하지 않았다.
- 좁은 3열 목록을 그림과 전체 이름을 나란히 표시하는 5행 목록으로 바꿨다. 한글 어절을 보존하고 마지막 한 글자가 홀로 남는 줄바꿈을 피한다. 새 자료는 뒤에 추가하며, 이전 저장의 선택 자료를 기준으로 페이지를 복구한다.
- 지도 제목·상태·하단·여관 목록을 기존 갈색·금색 UI 부품으로 통일했다. 잠긴 일반 장소를 누르면 짧은 안내가 나온다. 드래그 후 첫 터치를 놓치던 마우스 호버 처리는 터치에서만 해제했다. 이동 조건과 숨은 장소 공개 조건은 그대로다.
- 자료 선택의 ‘그만두기’를 ‘선택 마치기 · N개’로 바꾸고, 근거 선택·자기 비교·인물 제시의 제목과 안내를 나눴다. 제출 버튼은 ‘선택한 근거 제출’이며 무료 편집과 오답 제출의 기회 차감을 설명한다.
- 입구 첫 조사 안내와 실패 힌트를 보완했다. 정답 자료명·클릭 위치를 자동으로 알려주지 않는다. 자료 출처의 내부 ID는 획득 장소·자료명·화자 설명으로 표시한다.
- 질문·설정·자료·지도·공통 하단 터치 영역을 작은 가로 화면에서도 누르기 쉽게 정리했다. 대사 하단 조작의 화면 밖 잘림, 현장 이름표의 배율 계산, 마차 선택지의 얼굴 가림을 수정했다.
- 반복 확인한 편지·입구 조사에 읽음 표시를 붙이고 유사 질문의 문구를 구별했다. 첫 13호실 입실에 맥락 한 줄을 추가하고 메모의 터치 영역을 넓혔다.

## 검토 근거와 범위

실제 플레이 보고서 U01~U13 원문과 항목별 대조는 `docs/reviews/play-review-20261023/`에 보관했다. 보고서 실행 버전은 0.20.11이며, 이 변경은 0.20.13 소스를 기준으로 구현했다. 기존 0.20.13의 자료 본문 스크롤과 글씨 개선은 유지한다.

자료 획득 시점·정답 조합·기회 수·이동 해금·시간·생사·결말은 바꾸지 않았다. 입실의 기존 침대 감정 장면과 메모→보따리 선행 조건도 유지한다. 실물 휴대폰 사용자 시험과 전체 14일 수동 플레이는 별도 범위다.
