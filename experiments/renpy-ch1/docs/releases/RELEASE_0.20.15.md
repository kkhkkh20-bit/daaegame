# Room13 0.20.15 — 2일차 동선과 추가 QA 반영

## 바뀐 동작

- 2일차 광장에서 초롱에게 다시 말을 걸면 등불의 덮개 지지 끈을 잡아 달라고 안내한다. 같은 단계에서 등불 이름도 조작 대상을 드러낸다. 기존 사물 조사로 대화를 여는 순서는 유지한다.
- ‘생각’이 초롱 돕기→교환함으로 가기→조사→쪽지 남기기→우체국 방문에 맞게 바뀐다. 별도 진행 값을 만들지 않아 아침 복구와 저장 불러오기에도 현재 단계로 돌아온다. 새 이야기에서 혼동을 주던 ‘의문 0개’는 실제 모은 자료를 여는 행동으로 바꿨다.
- 교환함으로 가는 구간의 지도에는 ‘깊은 숲 · 교환함’을 표시한다. 지도 드래그·휠 안내와 Shift+방향키·페이지 키 탐색을 추가했다. 장소 선택과 이동 확정은 분리한다.
- 우체국 ‘대필도 합니까?’의 읽음 표시 누락을 수정한다. 저장 가져오기 성공 후 저장 목록 캐시를 비우고 메인 화면의 불러오기를 갱신한다.
- 광장·숲의 얼굴과 교환함이 고정 조작에 가려지는 배치를 정리한다. 기존 인물·사물 그림 크기를 보존하고 조사 영역을 그림과 함께 맞춘다.

## 이미 고쳐져 있던 항목과 보존 범위

지도 하단 여유 공간, 휴대폰 첫 탭, 갈색·금색 공통 UI, 이름표 배율은 0.20.14의 개선을 유지했다. 아침 복구는 기존 동작을 보존하고 취소·자료·진행 복원과 재진행을 회귀 검증한다. 증거 획득·정답·생사·결말·시간 소모는 바꾸지 않았다.
