# Room13 0.20.107 — 4~6일 주민의 행동을 이어 붙이다

2026-11-06. 소유자가 3일 피코 사건 다음 날짜로 이어가기를 요청했다. 4~6일 주민 별편 아홉 장면을 쓰고 현재 본편의 같은 순간에 짧은 행동·대사를 연결한다.

## 바뀐 내용

- 돌목은 다친 뒤에도 문을 막는 의자를 옮기려 하고, 밤이는 콩이에게 못 봤다는 말을 사람들 앞에서도 하라고 요구한다.
- 나비는 식당 일을 정리하고 직접 증언하러 나선다. 회의 승리 뒤 밤이는 보증서를 작게 접어 주머니에 보관하고, 실패 뒤에는 자신의 부인도 기록해 달라고 요구한다.
- 도토는 담요 수와 네 아이의 실제 인계를 확인한다. 보리는 화재에서 나온 셋을 안전한 쪽으로 보내고, 손을 다친 판에서는 도담에게 물잔을 들어 달라고 부탁한다. 빈 창고 판에는 다치지 않은 손과 학교의 아이들을 확인하는 별도 행동을 넣는다.
- 5일 가족 편지는 배달한 초롱이 비켜난 뒤 다돌과 다람만 읽는다. 봉투 획득·전문 청취·자료 대조의 기존 시점을 구별한다.
