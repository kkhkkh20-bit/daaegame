# 0.20.145 — 일반 주민 다섯 명의 기존 일상 대화 연결

1부에서 세 주민에게 말을 걸어도 인사나 질문을 찾지 못하고 아빠의 일반 속말로 끝나던 연결을 보완했다. 설이의 종소리 이야기, 여니의 옷 수선과 토리 이야기, 현이에게 노래를 청하는 선택을 기존 콘텐츠에서 연결한다. 바둑이에게 밤 순찰을 묻고 부엉이에게 기록 습관을 묻는 1~4일 대화도 추가 연결했다. 현재 재실·날짜·생사·부재·바쁜 상태를 검사하고, 긴장 장면과 주된 사건 대화는 우선한다. 구 캠페인의 사건·보상·증거 지급 동작은 실행하지 않는다.

현이의 노래는 기존의 겨울 구절을 사용한다. 다른 캠페인의 사건 플래그를 본편 소문으로 섞지 않는다. 읽음 표시는 남기되 같은 질문을 다시 읽을 수 있다. 새 사건이나 새 대사는 만들지 않았고 정답·생사·결말·7일 경계는 유지한다.

직전 0.20.144의 수면 확인·선택 재방문·광장 인물 위치·후속 질문 재독·생활 협업 연결도 포함한다. 모든 주민의 개인 사건이 완성됐다는 뜻은 아니다. 실제 화면과 검증 범위는 [추가 검수](../reviews/review145/검수.md)에 기록한다.
