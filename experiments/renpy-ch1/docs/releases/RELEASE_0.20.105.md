# 다람탐정 0.20.105 — 시작 부담과 예열 정리

소유자가 게임의 무거움을 지적해 원화·소리의 품질을 유지하며 첫 로딩과 불필요한 예열을 정리했다. 피코 현장조사·주민 반응은 별도 기획과 원고로 준비했고, 이번 공개의 게임 대사에는 반영하지 않았다.

- 현재 첫 화면이 쓰지 않는 이전 배경·다람 그림·버튼 판 다섯 개, 9,343,127바이트를 선로딩에서 제외했다. 원본은 원격 파일로 유지하고 실제 사용하면 기존 엔진이 받는다. 현행 표지 레이어와 필수 UI·글꼴, 실제로 연결된 대체 파일은 우선 보호한다.
- 시작 필수 게임 자료는 45,682,928 → 36,352,192바이트, 약 20.4% 감소했다. 고정 엔진 용량은 이 수치 밖이며 원격 그림 전체를 삭제한 것이 아니다.
- 예열 목록 107개는 유지하되 첫 입력 뒤 유휴 시간에 전역 한 요청씩 받는다. 날짜별 작업을 겹쳐 실행하거나 다음 날을 먼저 받지 않는다. 같은 버전 URL은 중복을 거르고, 다른 날짜로 옮기면 대기 중인 이전 날짜 파일을 비운다.
- 저장을 불러오면 그 날짜를 다시 알린다. 늦은 날짜의 공통 인물이 빠지지 않게 날짜 목록은 완전한 목록을 담고, 중복 여부는 실제 받은 URL로 판단한다. 숨긴 탭·데이터 절약 모드에서는 새 예열 요청을 시작하지 않는다. 이미 받는 한 요청은 마칠 수 있다.
- 원격 파일 디렉터리 생성의 중복 시도를 기억해 같은 부모 폴더를 수천 번 다시 만들지 않는다.
- 에셋 경로 문자열만 필요한 곳에서 명세 전체의 반복 복사를 피한다. 명세 복사 보호·연결 변경과 실패 복구·직접 경로 검증은 유지한다.

동일한 로컬 조건에서 한 번씩 측정했을 때, 메뉴 대기 10초까지 완료된 요청은 157 → 45개, 입구까지는 276 → 93개였다. 첫 메뉴 표시 시간은 24.91 → 24.72초로 비슷했다. 이 측정으로 전체 게임의 프레임 속도나 모든 기기의 체감 속도를 보장하지 않는다. CDP의 일부 큰 응답 바이트가 0으로 보고돼 그 합은 실제 전송량 비교에 쓰지 않았다.

주민 반응은 소유자가 선택한 **14일 공통 시간표 + 피코 사건 별편부터**의 범위로 [기획 묶음](../design/resident-reactions-20261105/README.md)에 정리했다. 주민 네 명·일곱 장면의 사망/보호생존/절도미수 원고와 매칭 조건, 기존 시신 컷을 쓰는 조사·가족 대화 설계, 사건 후 인사·업무·자세·재방문 반응 계약을 포함한다. 게임 미반영 기획이며 새 사인·범인·증거·생사·정답을 만들지 않는다.
