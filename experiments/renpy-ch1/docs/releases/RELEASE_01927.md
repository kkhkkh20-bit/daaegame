# 0.19.27 — 승인 조사 지도 동작 9종

승인된 GitHub 원본 `fc2a0e7cc84e0cfbce49064e44a46b6bc3e2a2fa`의 지도 동작 9종을 별도 `map9_` 키로 연결했다. 파일별 SHA256·bytes·원본 크기를 확인하고 lossless WebP로 보관한다. 실제 지도 표시는 기존 2px 격자 경로를 사용한다. 프로필과 대화 smooth 원본/registry, 대사, 일정, 사건 상태는 변경하지 않는다.

선생님 학교 오전/오후 젖은 옷 펼치기, 꽥순 강 오후 그물, 누비 여관 오전 빨래, 뭉치 가게 오후 상자, 물결 강 오전/오후 밧줄, 달그락 시장 오전/오후 냄비, 종종이 우체국 편지, 굴돌 작업실 오전/오후 돌 두드리기, 피코 11일 이후 진료소 휴식을 연결한다. 기존 일정에서 실제 등장한 인물만 바꾸고 사건 offer와 별도 사건 자세는 보존한다. 다른 장소의 일거리까지 같은 포즈로 바꾸지 않는다.

인물의 기존 발 위치와 서 있는 기준 크기에 새 stature_ratio를 적용한다. 피코는 원본→world 단일 배율 0.20625로 침대에 배치하며 지정된 이불 전경 다각형을 그림과 클릭 mask에 함께 적용한다. 굴돌은 작업대 표면에 손의 돌 접점을 맞추고 기존 작업대 가림을 적용한다.

별도 Library 원본: 현행 스킬의 공식 materialize helper로 솔방울 ZIP 전송을 1회 시도했으나 `library file transfer failed: download failed`로 종료했다. 준비 요청은 성공했지만 파일 수신은 0개, helper는 HTTP 상태를 노출하지 않았다. 이전 직접 전송의 프록시403과 같은 원인이라고 단정하지 않는다. 프록시 변경·우회·추가 전송은 하지 않았고 새15컷도 미시도 상태다. 따라서 솔방울과 대화 전용15컷은 이번 릴리스에 포함하지 않는다.

검증: 최종 0.19.27에서 단위 검사·Ren’Py lint, 배포 조각/ZIP/사전로딩 파일 SHA 확인 통과. 실제 Chromium/WASM 조사 화면 9개에서 각 동작을 검토하고 얼굴 중앙 클릭 대상이 해당 인물임을 9/9 확인했다. 피코 이불 가림점은 피코가 아닌 침대 조사 대상으로 판정됐다. 꽥순 얼굴 영역은 그물을 제외한 실제 얼굴로 보정했고, 굴돌 돌 접점은 작업대 가림에 묻히지 않게 world y454로 조정했다. 전체 캠페인 반복 QA가 아닌 지정 일정·장소 fixture 검증이다. 초기에 테스트 fixture의 입주 완료 플래그가 빠진 것은 QA만 수정했으며 일정 로직은 바꾸지 않았다.
