# 0.18.63 · 이전 정면 인터뷰 크기로 복원

소유자 피드백으로 회의 발언 인물의 확대 기준을 1200에서 840으로 되돌렸다. 0.18.61의 얼굴·상반신 구도로 복원하며, 0.18.62에서 고친 카메라의 연속 시각 기반 중앙 정착은 유지한다.

대형 원탁의 자리 간격을 반영해 여관 발언 근접 화면 전용 배경을 추가했다. 가운데 화자의 의자 한 개만 보이고 옆자리 의자는 화면 밖에 있도록 했다. 전체 안건·투표 화면은 기존 전체 원탁을 유지한다. 제단에는 의자를 추가하지 않는다.

검증: 단위 검사·Ren’Py lint·웹 빌드 및 실제 Chromium에서 여관/제단 정면 구도, 모바일과 좌우 이동 종료 후 중앙 정착 확인. 자료 제시·반론·투표 로직은 변경하지 않았다.
