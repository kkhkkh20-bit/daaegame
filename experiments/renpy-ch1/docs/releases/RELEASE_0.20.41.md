# 0.20.41 — 불타는 밤

가설·제단 회의를 모두 완전히 진 마을의 아침 경로에서, 14일 저녁 뒤 불타는 밤으로 이어진다. 12~13일에 침상 표시·잠긴 집·돌목의 기억 이상을 먼저 보여 준다.

학교 교실에서 복도·광장·산길을 거쳐 폐온실로 피한다. 현장의 물건·인물·지도 조작으로 진행하며, 다람의 열과 세 곳에서 머문 행동에 따라 가족의 세 결말이 갈린다. 별도 생사 메뉴나 생존 플래그는 추가하지 않았다. 제단 갈림길 표시와 결말 기록을 연결했다.

아빠와 다람이 서로 손을 놓지 말자며 주고받는 대화를 넣었다. 전체 대사 개작은 본편 구현 뒤 진행한다. 기존 장소 배경과 불 소리를 사용하며, 납품 배경 중 검토 후보 4장은 이번에 적용하지 않았다.
