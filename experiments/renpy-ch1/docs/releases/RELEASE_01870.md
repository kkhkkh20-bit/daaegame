# 0.18.70 · 토론을 이어 듣고 끼어드는 리듬

회의가 차분한 질문 목록처럼 끊기던 흐름을 바꿨다. 안건에 들어가면 공개된 발언과 짧은 주민 응수가 이어지고, 플레이어의 대사 넘김 속도로 진행한다. ‘되묻기’로 현재 주장을 중단해 기존 질문/확인 대사로 들어갔다가 다시 듣기로 이어진다. ‘발언 고르기’는 토론을 멈추고 기존 발언 선택 화면으로 돌아간다. 선택 화면에서 ‘토론 듣기’로 다시 시작할 수 있다.

화자가 바뀌면 이전 3인 구도와 새 3인 구도가 좌석 순서에 맞는 방향으로 0.32초 동안 좌우로 전환된다. 대사창과 입력 버튼은 고정한다. 같은 화자·아빠의 답변에서는 카메라 이동을 새로 시작하지 않는다. 그림 준비 시간에 전환이 소모되지 않게 실제 표시 시점에 시작하며, 움직임을 끄거나 건너뛰는 중이면 즉시 고정 구도로 전환한다.

되묻기/자료 제시 때 짧은 양피지 문구가 나타난다. 정오답 판정 전에 성공 연출을 띄우지 않는다. 원래 증거 판정, 증언 동의, 실제 대피 준비, 공정한 심리와 엔딩 관문은 유지한다. 이어 듣기는 숨겨진 발언을 열거나 입증하지 않는다. 중립 응수 중에는 자료 제시/되묻기가 비활성이고, 반박할 수 있는 실제 주장으로 돌아오면 다시 활성화된다.

대사 중 자료창 취소 및 자료창에서 저장한 게임을 불러올 때 원래 줄/페이지/발언 대상으로 돌아온다. 자료가 맞아 다음 대상이 갱신되어도 현재 들리는 주장에 대한 제시는 그 주장에 고정한다. 되묻기로 끊은 줄은 읽기 완료로 잘못 기록하지 않는다.

검증: 단위 테스트 176개, Ren’Py lint/웹 빌드, 실제 Chromium 회의 전체 흐름 및 토론 전용 검수(끼어들기, 듣기 재개, 제시·취소·저장/불러오기, 반박 대상 고정, 모바일, 움직임 끄기, 준비/입증 우회 방지). 명시적인 7일/14일 상태를 사용했으며 전체 14일 플레이 검사는 아니다.
