# 0.18.97 — 관계도 레퍼런스 적용·회의 공간 구분

[조사 자료와 적용 판단](../reviews/01897/RESEARCH.md)

- 관계도 기본 화면: 선택 인물을 가운데 크게 두고, 이미 알게 된 직접 관계를 주변에 배치한다. 전체 자리표 전환, 가로로 넘기는 인물 색인, 상세 목록과 읽던 선택 기억을 제공한다.
- 회의: 화자, 발언 순서, 새로 확인/다시 확인/근거 1/2/반박함 상태를 구분한다.
- 식당과 Q4 후속 회의는 기존 원탁과 앉은 배치를 쓴다. 광장·학교는 원탁 전경 마스크를 적용하지 않는다. 서 있는 인물의 발 위치도 탁자 높이에 의존하지 않는다.
- 광장 야외·학교 실내 입석·식당 원탁·제단 돌판은 머리글과 지도에 같은 도트 아이콘을 사용한다. 발견하지 않은 장소 유형은 범례에 표시하지 않는다.
- 지도에서 학교·진료실·수리점·장터 이름표의 간격을 조정하고, 이름표 클릭 영역의 겹침을 검사한다.
- ‘지금 모임이 있습니다’는 기존 회의 안내가 현재 날짜·시간·장소와 일치할 때만 표시한다. 선택만으로 이동하거나 시간을 쓰지 않는다.
- 관계·상태·발견 조건, 대사·회의 날짜·증거·지목·투표·엔딩 로직은 유지한다.

## 검증

- `dev/check.sh`: 단위 테스트·Ren’Py lint 통과. 장소 분류, Q4 원탁 복원, 현장 입석 발 위치, 이미 발생한 안내만 지도에 표시하는 회귀 테스트 4개를 추가했다.
- 실제 회의 화면 테스트 7개 통과: `relations_tab`, `ep1_meeting`, `ep3_meeting`, `ep4_after_trial`, `ep5_soup_meeting`, `ep6_cart`, `ep6_altar`. 개발 중 화면 구문을 고친 뒤 해당 테스트를 재실행해 통과했다.
- 브라우저: 26명 관계도와 실제 가로 드래그, 전체/인물 중심 전환, 선택 복귀, 큰 글씨·모바일, 두 자료·지목 취소, 네 회의 공간·야간 광장, 지도 이름표 11개의 클릭 영역 비중첩, 지도 선택 시 시간/위치 불변, 숨겨진 장소 범례 미노출을 확인했다.
- `verification.json`과 보고서 캡처는 최종 웹 빌드에서 얻었다. 전체 캠페인 완주를 뜻하지 않는다.
