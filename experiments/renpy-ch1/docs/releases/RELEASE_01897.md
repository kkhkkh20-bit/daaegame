## 기록 거름 단추
- 기록 「전체」와 보여주기 화면에 거름 단추를 넣었다: 전체 N / ● 안 읽음 N / 오늘 얻음 N / 이 사람 관련.
- 「이 사람 관련」은 보여주는 상대가 있을 때만 보이고, 보여주기를 열면 먼저 골라져 있다.
  - 그 사람 이름이 들어간 자료가 앞에 오고, 나머지는 뒤에 그대로 있다. 정답 자료를 알려 주지는 않는다.
- 자료 칸을 거름 단추 아래로 조금 내렸다.

## 다시 시작할 아침
- 하루를 처음 자유롭게 움직이는 때, 그날 아침을 숨은 저장으로 남긴다. 저장 목록에는 보이지 않는다.
- 「더보기 → 다시 시작할 아침」과 이름 판에서 지나온 아침을 골라 돌아간다. 확인창을 한 번 거친다.
- 그 뒤에 얻은 기록과 결과는 사라지고, 그날 아침의 수첩으로 다시 시작한다.
- 시안 문구 "알고 있는 것만 가지고 간다"는 실제 동작(그날 아침 상태로 복원)과 달라 고쳤다.
- 이 판본 전에 지나간 날은 "기록 없음"으로 보인다.

## 이번 겨울의 이름 판
- 결말 후일담 뒤에 먼저 나온다. 결말 화면의 「이름 판」 단추로 다시 열 수 있다.
- 보여 주는 것
  - 구한 사람: 초록 테두리
  - 잃은 사람: 회색 얼굴과 붉은 X
  - 에피소드 ①~⑥: 찾은 자료 수, 깨지 못한 말 수, 결과
- 못 찾은 자료가 무엇인지는 보여 주지 않는다.
- 단추: 새 여정 시작 / 다시 시작할 아침 / 닫기.
