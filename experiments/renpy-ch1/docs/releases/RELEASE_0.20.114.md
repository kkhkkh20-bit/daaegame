# Room13 0.20.114 — 제1부 · 화재 사건

2026-11-06. 소유자 지시에 따라 1~7일을 제1부로 묶었다. 화재의 현장·논증·학교 인수와 오후 후속 행동을 마친 뒤, 13호실의 다음 사건이 시작되기 전에 다람과 마무리한다. 메인화면 부제도 맞췄다.

현재 판의 승리·부분 성공·실패를 별도 기록으로 펼쳐 본다. 누비의 자백, 보리에게 남은 혐의, 실제 확보한 배급표, 학교 인수와 엄마의 미확인 위치를 구분한다. 사전 대피 판에서는 빈 창고 진압으로 쓴다. 기존 정답·생사·예방 행동을 보존한다.

별도 ‘1부 완료’ 저장을 자동으로 남기고 불러오기에도 연결했다. 수동 저장 여섯 칸을 유지한다. 후속판은 같은 저장에서 7일 저녁의 기존 장면부터 이어질 수 있다.

1~7일 자료 대조의 14개 문맥을 공통 읽기 화면으로 통합했다. 일반 기록도 핵심 사실을 먼저 읽는다. 제출 체크 정렬과 휴대폰 설정의 저장 그림 크기를 맞췄다. 피코의 사망 소식과 살아 있는 판의 구금 소식을 분리해, 실제로 소식을 들은 주민만 이후 반응에 사용한다. 나비에게 놓친 사망 소식은 4~7일에 대면해서 전할 수 있다.

완성 범위와 분기 기준은 [기획](../design/PART1_FIRE.md), 검증과 캡처는 [검수](../reviews/part1-fire-20261106/검수.md)에 기록한다.

전체 단위1347개, 최종 관련34개, 엔진23개 고유 시험과 lint를 통과했다. A/B/C 대사 검사0건이다. 웹 ZIP의 버전·핵심 원본·전송 조각 해시와 검수 fixture 제외를 확인했다. 첫 로딩36,386,260바이트, 전판 대비11,833바이트 증가이며, 선로딩33개·원격4626개·예열107개는 같다. 새 그림은 추가하지 않았다.

새 프로필에서 1~7일을611초 연속 자동 진행해1부 완료까지 도착했다(정답 계획·대화 건너뛰기 사용, 상태 주입 없음, 캡처161장, 페이지 오류0). 이후 완료 저장의 표식 복원을 보완하고 엔진2경로·관련 단위14개와 최종 웹 PC/휴대폰·새로고침·메인 이어하기·수동 저장을 재확인했다. 실제 초기 이용자의 난도·재미 평가는 별도다.
