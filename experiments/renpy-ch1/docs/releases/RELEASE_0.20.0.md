# 0.20.0 — 휴대폰 조작 정리, 표정 31칸, 엄마 편지의 도토리

## 휴대폰(소유자 지시: "까로 질문 중 더보기 메뉴가 뒤에 떠 저장을 누르지 못하는 문제 ... 먼저 고치고")
- 더보기 화면이 질문 화면 뒤에 뜨던 문제를 고쳤다. 앞뒤 순서를 안쪽 화면에만 적어 무시되던 것이 원인이었다.
- 아이폰 14 가로 크기·터치로 점검해, 터치 화면에서만 키웠다.
  - 대사 아래 조작 28px
  - 더보기 판 글자 26px
  - 이름표 56px
  - 질문 행 최소 64px
  - 이전/다음 질문 64px
  - 기록 창 작은 버튼 56px
  - 회의 대조 버튼 64px
  - 「일째」「전달 가능」 같은 작은 글자 16~18px
- PC 배치는 그대로다.

## 표정
- 부족하던 대사 표정 31칸을 넣었다(Codex 그림).
  - 도토·백부인 당황
  - 선생님 기쁨
  - 토실·실룩·굴돌 5칸
  - 서리 3칸(새 디자인)
  - 부엉이 4칸
  - 꼬미·판돌 3칸

## 엄마의 진짜 편지
- 소유자 지시: 도토리를 대사로 짚지 말고, 편지 끝에 작게 넣어 플레이어가 발견하게.
- 방의 메모 끝에는 삐뚤한 도토리, 엄마의 경고 편지 끝에는 보통 도토리를 그림으로 넣었다.
- 초대 편지에는 없다.

- 단위 테스트 862개와 lint 통과. 바뀐 화면 테스트 통과. 아이폰 크기 브라우저 점검 통과.
