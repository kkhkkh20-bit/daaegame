## 쉬운 말
결박·집행·원본·레버·배급·은신처·판결 같은 말은 그대로 둔다(소유자 결정).

| 원래 말 | 바꾼 말 |
|---|---|
| 치명상 | 죽게 한 상처 |
| 범행 도구 | 촛대 조각 |
| 누군가의 범행 | 누군가 하려던 일 |
| 알리바이 | 그 시간 어디 있었는지 / 함께 있었다고 말해 줄 수 있다 |
| 입증 | 밝히다 |
| 등록 안 된 | 마을 장부에 이름이 없는 |
| 이미 본 범행 | 이미 본 사건 |

'이송'은 장부에 적힌 말로 남기고, ⑤ 옛 시설 장면에서 엄마가 뜻을 한 번 풀어 준다.
