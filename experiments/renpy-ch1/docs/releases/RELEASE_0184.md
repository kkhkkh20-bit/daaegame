# 0.18.4-dev · 2026-10-14 — 선택지 화면과 대사 넘기기 (소유자 지시·플레이어 댓글)

## 선택지

소유자 지시는 세 가지였다.
- 폭을 적어도 두 배로 한다.
- 두 줄이 되지 않게 한다.
- 더 직관적으로 만든다.

| 항목 | 전 | 후 |
|---|---|---|
| 목록 폭 | 470px | 940px |
| 줄 수 | 길면 두 줄 | 한 줄. 선택지 문구를 행동 요약으로 줄였다(아래) |
| 맥락 | 화면 위에 "선택"만 있음 | 바로 앞 대사(말한 사람·내용)가 위에 남는다 |
| 고르기 | 클릭·터치 | 왼쪽 금색 칸에 번호를 붙였다. 키보드 1~9(숫자 패드 포함)로도 고른다. 터치 기기에서는 숫자 키 안내를 숨긴다 |
| 크기 | 줄 높이 42 | 줄 높이 56. 마우스를 올리면 칸 전체가 밝아진다 |

- 선택지 문구 46개를 24자 이하로 줄였다. 원래 45자 안팎이던 재판·2주차·생활 선택지가 대상이다. 선택지는 무엇을 할지만 적고, 자세한 말은 고른 뒤 대사로 나온다.
  - 예: "첫 비명 뒤에 있던 핀과, 거둬 올 때의 범행 도구를 이어서 ‘구하다가 만졌다’는 말을 뒤집는다" → "핀과 도구로 ‘구하다 만졌다’를 반박한다"
  - 새 단위 테스트 `dev/test_choice_length.py`: `game/`의 `menu` 선택지가 24자를 넘으면 실패한다.
- 같은 목록 화면을 쓰는 다른 목록(인물 없이 뜨는 질문 목록)도 940px와 번호가 적용된다.
- 마주 보고 묻는 화면(인물이 왼쪽에 서는 화면)은 바꾸지 않았다.

## 대사 넘기기 (커뮤니티 댓글)

대사 중 아래 도구 막대에 버튼 3개를 더했다. 기록·백로그·자동·옵션은 그대로 있다.

| 버튼 | 동작 |
|---|---|
| 건너뛰기 | 읽은 대사만 다음 선택지까지 빠르게 넘긴다. 처음 보는 대사가 나오면 그 자리에서 멈추고 알려 준다 |
| 빠르게 | 처음 보는 대사도 다음 선택지까지 넘긴다. 이야기보다 진행을 먼저 하려는 사람용 |
| 숨기기 | 대사창과 버튼을 숨겨 그림만 본다. 화면을 누르면 돌아온다 |

- 두 넘기기 모드는 한 번 쓰고 꺼진다. 다음 선택지, 질문 목록, 마을 화면에 닿으면 저절로 꺼진다. 켜진 동안 버튼이 금색이 된다.
- "읽은 대사"는 기존 `persistent.room13_read`(회차와 무관한 읽음 표시)를 쓴다. 게임 상태는 넘어가지 않는다.
- 예전에 읽은 대사 빠르게 넘기기를 소유자 결정으로 뺀 적이 있다. 이번 지시로 버튼 방식으로 다시 넣었다.
- 댓글 중 반영하지 않은 것
  - 전체이용가 모드: 지금 게임에는 바꿀 노출·선정 장면이 없다.
  - 설정 백과사전 링크: 참고 자료라서 기능이 아니다.
