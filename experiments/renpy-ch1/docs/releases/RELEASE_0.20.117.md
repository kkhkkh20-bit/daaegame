# Room13 0.20.117 — 화재의 근거를 직접 연결하기

2026-11-07. 소유자의 ‘해보자’ 지시로 1부 화재 추리의 관찰·질문·책임 구분을 보강한다.

자백 전의 세 보기 반복을 없애고, 이미 확인한 관찰 두 개와 누비에게 다시 물을 질문을 함께 연결한다. 닫힌 등잔과 남은 기름, 문 앞의 탄 자국과 기름 냄새 나는 천, 실제 들은 보리의 목격을 구분한다. 이 연결은 누비의 문 앞 행동을 다시 물을 근거이며, 방화·확산 방향·살해 의도를 확정하는 판정이 아니다.

자백 뒤에는 자료를 ‘불의 흔적·누비 쪽 근거·보리의 행동’으로 나누어 제출한다. 배급표를 자백으로 표시하지 않고, 실제 확보한 배급표의 대체·덧붙임 제출은 기존대로 유지한다. 사전 대피 판에는 빈 창고 진압, 구조 판에는 아빠가 목격한 구조 행동을 쓴다.

화면은 기존 종이 수첩·공통 버튼·글자 단계를 사용한다. 틀린 연결은 개별 정답을 표시하지 않고 다시 살필 범위를 알려 준다. 기존 자료 제출의 정답 묶음·기회·승리·부분 성공·실패·대승리·인물 생사는 바꾸지 않는다. 이미 첫 논증을 마친 구 저장은 같은 논증을 다시 요구하지 않는다.

검증 범위와 화면은 [검수 기록](../reviews/fire-links-20261107/검수.md)에 남긴다. 주민 반복 반응과 전체 그림 화풍 통일은 이번 변경 범위가 아니다.
