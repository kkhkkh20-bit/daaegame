# 0.20.55

대사를 「당사자끼리 주고받는 대화」로 고쳤다. 소유자 지적은 "너무 정보 전달이야", "고유 명사도 있고 티키타카가 없어", "서로 대화를 해야해 당사자라고 생각하고"였다.

역전재판 영어 원문 9화와 같은 방법으로 쟀다. 줄 길이와 화자 교대는 이미 비슷했다. 차이는 앞사람 말에 먼저 반응하며 시작하는 줄의 비율이었다(25% 대 6%). 그래서 한 줄 안의 순서를 바꿨다. 반응과 입장을 먼저, 주장은 하나만, 찌르는 말은 끝에 둔다. 한 줄에 사실을 여럿 늘어놓던 설명은 상대가 묻고 받는 2~4줄로 쪼갰다. 기준은 `docs/design/VOICE_GUIDE.md` 1-2-4에 있다.

- 고친 장면: 2·3·5·6·7·8·9·10·11·13·14일의 설명이 길던 30여 장면. 같은 장면에서 60자 넘는 줄이 69개에서 31개로 줄었다.
- 회의 긴박감: 걸린 것과 시간을 입 밖에 내게 했다. 방청의 술렁임과 그 소리가 뚝 그치는 순간, 아이가 소매를 쥐는 몸짓을 3·10·12·14일 회의에 넣었다.
- 인물 카드에 맞춰 표정 214줄을 다시 매기고, 꺼져 있던 표정 25줄을 되살렸다.
- 인물 소품표(`docs/design/CHARACTER_PROPS.md`)의 새 소품 11개를 각 인물의 첫 장면에 한 번씩 넣었다.
- 대화창 전신 그림 요청서를 새로 썼다(`docs/art-requests/대화창_전신그림_요청서.md`). 얼굴 스티커는 요청하지 않는다.
- 바로잡은 것: 말줄임표 정리 때 대본 표기 `[삭제{...}]`가 5·10일 두 줄에 섞여 10일 회의 화면이 멈추던 문제. 너울 전용 소품인 주판이 백 부인 줄 두 곳에 남아 있던 것.

사실·증거·생사·회의 정답과 진행 조건은 바꾸지 않았다. 117장면 전체를 다 고친 것은 아니며, 나머지 장면은 날짜순 통독으로 이어서 고친다.
