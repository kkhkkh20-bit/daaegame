# 0.18.54 · 2026-10-15 — 빛과 그림자가 함께 일렁인다

0.18.53 위에 쌓았다. 소유자: "게임을 돌려 보면서 인터랙티브 무빙을 체크하고, 횃불이 있으면 그림자 부분도 일렁여야 한다."

## 1. 점검 결과(이전 판)

엔진 화면을 녹화해 2초 동안 바뀌는 픽셀을 쟀다(`motion_audit` 화면 테스트 + 녹화).
- 여관 로비 저녁: 불꽃과 창밖 눈만 움직이고, 방 바닥은 거의 그대로였다(먼 바닥 밝기 변화 0, 가까운 바닥 0.8).
- 실내 등불 장면: 빛 판이 4단계로 '툭툭' 바뀌어, 일렁임보다 깜빡임에 가까웠다.
- 그림자는 어느 장면에서도 움직이지 않았다.

## 2. 바뀐 것: 조명 장치(`R13FxLightRig`)

- 빛마다 따로, 매 프레임 부드럽게 흔들린다. 불꽃은 빠르고 크게, 촛불은 그 사이, 등불은 느리고 작게.
- 가장 센 빛이 약해지면 빛에서 먼 곳이 짙어져 빛 웅덩이가 줄어들고, 세지면 넓어진다(방 전체 명암이 같이 숨쉰다).
- 여관 로비(아침·오후·저녁): 벽난로 앞 바닥에 드리운 의자·탁자 그림자가 불꽃이 커질 때 짙어지며 불 반대쪽으로 아주 조금 늘어난다.
- 적용: 여관 로비 3시간대, 저녁의 학교·수리점·진료실·창고·온실·시설·광장, 장면 그림 10장, 메인 타이틀.
- 이전 빛 판 깜빡임(`inn_glow`, `lamps`, `lamp_glow`, 장면 그림 `lamp`)을 대신한다.
- 녹화 비교(여관 로비 저녁, 2초): 바뀌는 픽셀 1.7만 → 16만, 먼 바닥 밝기 변화 0 → 19.7.

## 3. 판 만들기

- `dev/make_dot_fx.py`의 `light_rigs()`: 장면마다 빛 위치·반지름·세기·종류(fire·candle·lamp)를 적으면 어둠 판(shade), 빛 판(glow), 바닥 그림자 판(sway)을 만든다.
- 바닥 그림자 판은 원화에서 넓게 이어진 어두운 덩어리만 골라 불보다 아래쪽만 쓴다(외곽선과 작은 무늬는 빼서 그림이 지저분해지지 않게).

## 4. 성능

- 조명 장치는 초당 20번 다시 그린다. 소프트웨어 렌더러(헤드리스 크롬)에서 여관 로비 13~15fps, 효과 없는 장면 19fps. 실제 기기(GPU)에서는 더 높다. 입력 지연은 0.2초 이하.

## 5. 검사

- 단위 테스트·lint 통과. 화면 테스트 `motion_audit`(새로, 기본 묶음 밖), `dot_fx`, `title_fx` 통과. 전체 회귀는 소유자 지시로 생략했다.
