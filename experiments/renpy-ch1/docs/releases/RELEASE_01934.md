# 0.19.34 — 나비 주방 5동작과 날짜별 동선

0.19.33의 지도 26동작에 준비돼 있던 나비 당근 썰기(KI-1)와 승인 추가 4종(KI-2~5)을 기존 일과에 연결한다. 총 31개 승인 원본/동작이다.

- 첫날은 보존한다. 2~14일의 아침에만 일상 주방 준비를 한다. 당근→냄비→수프→접시 정리→쟁반 순으로 날짜에 따라 반복하며, 오후·저녁 식당 서빙은 기존 그대로다.
- 둘째 주에는 할머니 구금 시 아침 접수대, 대피소 준비 시 학교가 주방보다 우선한다. 변경은 기본 일과 두 지점에서만 이뤄져 기존 사건 고정 배치·부재 처리의 우선순위를 유지한다. 내부 ID, 세이브 키, 시간 진행을 바꾸지 않는다.
- 원본4는 art commit64264145의 ZIP/manifest/각 PNG 해시·바이트·크기를 검증하고 그대로 보관한다. 조사용 파생본만 768 높이/2px 격자/무손실 WebP로 만든다. 대화용 smooth 원본 연결을 바꾸지 않는다.
- 실제 조리대에 도마·그릇·쟁반을 맞춘다. 접시는 조리대 곁에서 닦으며 없는 싱크를 가정하지 않는다. 새 열린 냄비는 화구의 두 기존 그릇 사이 빈 면에 놓아 닫힌 뚜껑과 겹치지 않게 한다.
- 식당 활동 설명을 실제 쟁반 서빙에 맞추고, 주방의 일반적인 일과 설명을 추가한다. 새로운 사건·단서·일거리·대사는 만들지 않는다.
- 기존 2~3일 저녁 주방 사건은 `room13_episodes.rpy`의 실제 day/period/location/ep2_seen 조건으로 열린다. 아침 일과와 분리되며 W2·아이들·관계 선택을 보존한다. 비활성 옛 식사 일거리를 부활시키지 않는다.

검증: 실제 WASM에서 나비 5동작 및 식당/학교/접수대 우선 장면, 2개 저장 복원. 1~14일×3시간대×5상태×20명=4,200행 배치표에서 31동작 전부 관측, 중복/다른 장소 포즈/조건 우회/부재 재등장 오류0. 이는 명시적인 상태 fixture 검사이며 전체 캠페인 완주를 뜻하지 않는다. 단위 테스트·lint 및 빌드 part/ZIP 검사를 별도로 수행한다.

자료: `docs/reviews/nabi-kitchen-active/`, `docs/reviews/map-pixel-output/`. 후자의 실제 캡처에서는 1280×720 카메라2px 이동 시 같은 얼굴 픽셀이 유지되지만 1024×576 분수 축소에서는 표본이 달라진다. 모든 화면에서 pixel-perfect라고 주장하지 않으며 원근·배율 시스템을 새로 만들지 않았다.

별도 대기: 검사원은 설이(resident_seol)가 아니라 서리(resident_seori)다. 기존 living_notes는 자신의 기록을 보는 오른쪽 측면이며 환자 쪽 시선 변형과 구분된다. 새 승인 시선 원본은 별도 작업으로, 이 판에서 좌우반전이나 대화 정면시선 변경을 하지 않았다. 이름/직업 UI 후속 패치도 아직 포함하지 않는다.
