# 0.19.46 — 공통 UI 및 터치 조사

소유자가 검토한 공통 UI를 적용한다. 하단은 동일한5칸, 아이콘·글씨 중앙 정렬, 같은 투명도·테두리·간격으로 통일한다. 조사/대화 보기와 대상 선택 후 명시적 조사, 회의 듣기/검토 구분, 자료·기록 모달의 회의 배경 유지도 포함한다.

정본: docs/design/UI_COMPONENTS.md. 검토 캡처와 자동 검사: docs/reviews/common-ui-20261018/. 최신 main0.19.45의 그림·회의 연출·테이블 배치를 보존해 통합했다. 대사·증거 판정·일정·시간 규칙은 이 UI 릴리스에서 변경하지 않았다.

검증: dev/check.sh, 공식SDK8.5.3 웹 빌드의 compile/lint, 실제 Chromium의 PC/터치 조사·회의·취소·하단 규격 검사. 질문0/8/12개·실제 질문 재생과 복귀는 공통 UI 검토본에서도 통과했다.

플레이 리뷰의 현재 잔존 항목: 입구 질문의 ‘원본과 다시 맞춰’는 실제로 담당자 대기 확인창을 여는 행동이었다. 질문을 ‘원본 담당자를 기다리겠습니다.’로 명확히 했다. 자료 대조는 기존 자료 보여주기에 그대로 둔다. 대기 결과·진행 조건은 변경하지 않았다. 근거: 클라우드 work/player-review-log/notes.txt의0.19.13 플레이 기록과 docs/HANDOFF_20261017.md, 현재 r13_entry_dispatch의 wait 분기 대조. 최신 코덱스 리뷰 원본과 동일하다고 단정하지 않는다.
