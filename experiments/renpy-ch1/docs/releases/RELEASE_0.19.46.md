# 0.19.46 — 실제 검수된 생활 그룹 3개

공방 부리·톡, 여관 여니·토리, 학교 깜이·몽이·방울 그룹을 실제 엔진 검수 후 활성화했다. 기존 성인 출현·사건 제안·개인 대화는 보존한다. 공방은2·3일 오전/오후, 여관은2·3·6일 오후의 실제 동시 출현일만 사용한다. 학교는8·9일 오전/오후이면서 구조·소개·학교 조건이 있고 사망/사건/혼잡 조건이 없는 경우만 나온다. 시간·기록·관계·증거를 소비하거나 부여하지 않는 짧은 그룹 대화다.

새 협업3원본을 보존하고 공통 조사용 도트 파생본으로 연결했다. 부리의 목재 하나에 톡의 드라이버를 맞추고, 최신 굴돌 작업 자리와 겹치지 않도록 접점을570,425로 조정했다. 토리는 여니의 천을 보는 위치에 배치하고 앞 안락의자 가림을 적용했다. 귀를 포함한 전체 높이만으로 작아 보이지 않게 마지막 크기·발 기준을 보정했다. 제공 원화의 가방끈과 시점은 뒤집지 않았다. 학교 놀이3원본의 알파는 보존했다.

인계 패치의 `call screen ... from` 문법 오류를 바로잡았다. 그룹 대화판은 얼굴을 가리지 않도록 위쪽 빈 공간에 배치했다. 대시보드 기술ID 후속 패치 e8f6a363도 포함한다. 스크립트 내용별 버전 URL로 갱신하며 공개 문제의 원인이 캐시였다고 확정하지 않는다.
