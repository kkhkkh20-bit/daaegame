# 0.20.121 — 전체 인물 크기 기준 정리

대화 등록69종과 현장 그림68개 ID를 대조했다. 같은 현장 키인데 일반 대화가 크게 확대되거나, 전용 표정에서 커지고, 질문 그림의 발이 화면 밖으로 내려가던 표시 규격을 정리했다.

- 일반 대화69종: 현장 기본 키를 기준으로 표시 배율을 맞추고 760·840·1302 사이의 비례를 유지한다. 기존 기준과2% 안인 정상 그림은840 표시를 보존한다.
- 질문69종: 전신 전용 크기를 공통으로 선택한다. 어른·아이·어린 도담의 상대 키를 유지하고 발이708px 안에 들어오게 한다.
- 별도 문맥10종: 일반 대화와 크기를 맞춘다. 질문을 열어 마지막 문맥 그림이 남아 있어도 해당 그림의 발 기준을 사용한다.
- 세련의 앉은 자세는 유지하고 질문에서 화면 아래로 나가던 위치만 올린다. 단독 회의의 초점 인물에도 같은 표시 기준을 적용한다.
- 구 저장에서 일반 대화 그림을 다시 표시할 때 새 기준을 사용한다. 공용 인물과 일반 전신 등록이 없는 단역도 포함한다. 현장 카메라·별도 활동 자세는 보존한다.
- 도담의 추가 현장4자세를132px 기준으로 재생성하고, 작은아이보다 일반 kid_ 분류가 먼저 적용되던 생성 규칙을 고쳤다. 기본 중립 그림과 다른426개 현장 그림은 유지한다. 이4자세가 실제 플레이에서 전환돼 크기가 튀었다고 단정하지 않는다.

원화의 디자인·대사·추리 정답·생사·결말은 변경하지 않았다. 표시 크기표는 현재 원본 프로필과 일치할 때만 적용하며, 원화 재납품 도구도 크기표를 갱신한다.

전체 단위1,444개·lint와 변경 화면을 검사했다. 실제 엔진 렌더 전후 및69종 평상시→기쁨→지문, 전용 문맥과 질문, 세련 의자, 회의 화면을 확인했다. 준비된 화면의 검증이며 이야기 전편의 연속 플레이는 아니다. 최종 웹에서 질문9종·휴대폰 큰 글씨·실제 저장과 불러오기 뒤 재표시도 통과했고 브라우저 오류는 없었다. 상세 수치·웹 검증은 [전체 검수](../reviews/character-size-20261108/검수.md)에 남긴다.
