# Room13 0.20.16 — 1~14일 대사 다듬기

## 바뀐 것

소유자 지시(2026-10-23): "말투가 통일되어야 하고 주어 목적어 동사 모두 보여서 말이 직관적으로 이해가 되어야 하고. 개성이 있어야 해 각 사람마다. 대사 자체를 이해가 가는 비주얼노벨 소설처럼 잘 구성해 줘야 하고."

- 1~14일 본편 대사 약 600줄의 표현을 `docs/design/VOICE_GUIDE.md` 기준으로 고쳤다. 사실·단서·조건·결말·순서는 바꾸지 않았다.
  - 지문은 아빠 1인칭 현재형으로 통일했다(과거형이 17% 섞여 있었다).
  - 생각 대사는 행동 묘사가 아니라 속말로 바꿨다.
  - 빠진 주어·목적어를 채웠다("그럼 언제 떨어졌습니까?" → "그럼 그 핀은 언제 떨어졌습니까?").
  - 인물별 말투를 맞췄다: 돌목·너울·촌장·보리·은호·판돌은 하오체, 까로·도토·나비·세련은 해요체, 아이에게는 반말. 톡은 더듬는 말투, 부엉이 할아버지는 "~네".
  - 같은 장면의 물건·장소 이름을 통일했다(붓/펜, 진료소/진료실, 국/수프).
  - 아빠가 아직 이름을 모르는 사람은 지문에서 역할로 부른다("초소 경비", "짐꾼", "화가").
- 새 도구: `dev/dialogue_day.py`(하루치 대본 보기·대사 반영), `dev/dialogue_sweep.py`(대사 기계 검사).
