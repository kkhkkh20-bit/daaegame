# 0.19.92 — 인물 목소리와 회의의 무너짐

소유자 지시(2026-10-22): 인물의 개성을 과장해서 키운다. 말투, 말버릇, 과장된 몸짓, 아빠의 속생각은 대사판에서 맞춘다. 톤은 아주 어둡게 유지한다.

## 대사판
- 인물 목소리표(소유자 검토용 문서 「다람탐정_인물목소리_20261022」)를 기준으로 1~14일에 말버릇과 몸짓을 넣었다. 문장 교체 140, 더한 줄 140(아빠 속생각 약 40). 죽음, 고백, 이송, 아이가 위험한 장면에는 넣지 않았다.
- 같은 말버릇이 너무 자주 나오지 않게 줄였다(할머니 "아이고", 아빠 "적어 두겠습니다", 부엉이 "흠", 나비의 행주).
- 회의마다 상대가 무너지는 순간을 서술로 넣었다: 3일 실룩(웃음이 굳음), 10일 할머니("먹고 해"를 되풀이하다 목도리를 누름), 12일 선생님(손뼉이 먹히지 않음, 출석부), 13일 촌장(손바닥을 거둠)과 너울(장부를 탁 덮음, 주판알이 헛돎), 14일 촌장("불은 나눠야 따뜻하오", 무릎).
