# 0.19.22 — 승인된 특수장면 8컷

아트 커밋 `4c4978ed4d06c1e482dfb8aad9938d4e9fa8d1e1`의 원본 8개와 출석부 SVG 2개의 해시·크기를 검증했다. 초롱 부상 생존, 네로 쇠약 생존, 선생님 담요 두 분기, 보리 돌봄 두 분기·신발 한 짝·도담 손잡기를 각각 해당 대사 묶음에 전용 컷으로 연결했다. 일반 59명·354슬롯 및 조사 기본 동작은 유지한다.

선생님은 도담 한 명인 분기와 깜이·몽이·방울·도담 네 명인 분기를 분리한다. 보리의 무릎 위 인물은 상실 분기에서 깜이, 모두 생존한 분기에서 도담이다. 이름·동그라미는 승인 SVG를 지정된 원근 사각형에 합성했다. 도담만 동그라미 / 새미만 동그라미 없음이 유지된다. 합성 범위 밖 원본 픽셀 보존도 검사했다.

컷은 일반 인물 배율을 사용하지 않는다. 실제 보이는 알파 영역으로 경계를 잡고 선생님 눕기 높이는 340, 다른 컷은 400 이하로 제한했다. 바닥 접점은 y=490이며 큰 글씨 대사창 위에 남는다. 기존 배경의 바닥 쪽을 전용 카메라로 보여 주고, 일반 스프라이트와 학교 군중 오버레이를 중복 표시하지 않는다. 그림 파일이나 일반 장소 카메라 상태는 변경하지 않는다. 컷은 해당 대사 묶음 종료 시 기존 수명주기로 제거된다.

대사·분기 조건은 8개 첫 서술에 컷 메타데이터를 추가한 것 외에 원본 해시와 같다. 초롱의 강가 서술/종탑 배경 및 네로 사망 분기의 흰 늑대 서술 불일치는 요청대로 남겨 두었다. 문맥별 기존 표정 검토는 유지하고, 실제 컷이 완성된 다섯 제작 요청만 완료 상태로 갱신했다.

검증: 단위 검사 298개와 Ren’Py lint 통과. 이후 바닥 프레이밍 보정에 대해 특수장면 단위 검사를 재실행하고 최종 웹을 다시 빌드했다. 실제 Chromium에서 원래 분기의 대사 패킷을 production r13_lines에 전달하는 좁은 fixture로 8컷 표시·각 저장복원·대사 묶음 종료 후 정상 대화 복귀를 확인했다. 선생님 한 명 분기는 큰 글씨로도 검사했다. 분기 조건은 원본 보존 검사로 확인했으며 전체 에피소드를 다시 플레이한 검사는 아니다.

가독성 한계: 원근 페이지의 동그라미 배치는 확인되지만, 출석부 이름은 실제 게임 배율에서 작은 글씨여서 다섯 이름을 편히 읽을 크기는 아니다. 이름과 동그라미의 의미를 설명하는 원래 대사는 그대로 남아 있다. 별도 확대 기능은 추가하지 않았다. 공개 URL의 기존 프록시 403은 재시도하지 않았으며 GitHub Pages 배포 결과로 상태를 확인한다.
