# 0.19.36 — 인물 왼쪽 · 질문지 오른쪽

질문이 많을 때 스크롤 존재를 알아차리기 어려웠고, 자료 제시 버튼이 질문 목록과 떨어져 있었다. 소유자가 승인한 역전검사 참고 시안에 따라 대화 상대는 왼쪽, 질문은 오른쪽으로 배치했다. 검정 약53% 배경 막 위로 인물을 밝게 남기고 자료 보여주기를 오른쪽 하단에 고정했다. 돌아가기·기록은 왼쪽 하단에 있다.

일반 주민과 입구 돌목·까로·다람이 질문 화면에 적용했다. 질문 원문과 기존 요약, 읽음 표시, 숫자 키 및 입력 보호를 유지한다. 대사·해금 조건·시간·증거 로직은 바꾸지 않는다. 일반 이야기 분기 선택지는 기존 화면을 유지한다.

질문 문장의 실제 렌더링 높이에 맞춰 완전한 행을 배치한다. 짧은 행은 승인 시안대로 최소54px, 최대8개를 표시하고, 넘치는 질문은 전체 개수/현재 쪽수와 이전·다음 질문 버튼을 쓴다. 숫자 키는 현재 쪽의 보이는 번호와 일치한다. 숨겨진 스크롤은 없다. 긴 질문은 기존 요약 또는 원문을 줄바꿈한다. 검토용 임시 화면과 배치 토글은 제거했다.

검증: `dev/check.sh` 단위 검사 및 Ren'Py lint 통과, 웹 빌드 성공. 실제 Chromium PC/모바일 큰 글씨에서 빈 목록·8개·12개 배치, 페이지 왕복과 상태 불변, 실제 질문 dispatcher의 자료 제시/기록 열기·취소·복귀, 숫자 키로 대사 시작·읽음 복귀·돌아가기를 확인했다. 검증 캡처 및 결과는 `docs/reviews/side-topics-release-20261017/`.
