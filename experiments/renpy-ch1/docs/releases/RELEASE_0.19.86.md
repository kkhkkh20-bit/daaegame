# 0.19.86 — 공용 회색 담요 수선 소품 보충

소유자의 부족 리소스 보충 지시에 따라 13일 학교의 판돌 공용 담요 수선 전/후 두 그림을 제작했다. 기존 청록 담요는 스타일 참조로만 사용했고, 가족 침구와 구분하는 회색 소재·터진 끝·아래를 향한 새 무늬 천을 구현했다. 동일 구도와 주름을 유지해 수선 전후를 읽을 수 있다.

기존 학교 현장 담요 클릭·대사·컷 정리·기록 그림 경로만 사용한다. 실제 수선 이후 기록을 얻어야 완성 소품이 수첩에 보인다. 새 UI, 대사, 선택지, 진행 조건, 캐릭터 그림은 추가하지 않았다. 토리의 인물 표정/동작 작업은 보존한다.

검증: 기존 검사 794개와 Ren'Py lint 통과. 실제 13일 저장에서 현장 담요 클릭→수선 대사→기록 획득→다음 장면에서 컷 제거를 실제로 확인했다. 실제 캡처는 docs/story-v111/resources01986/. 모든 엔딩을 재실행하는 중복 검사는 하지 않는다.

공식 dev/build_web.py 빌드. 새 WebP 2종 합계 293236바이트는 후기 progressive 자산으로 전달하며 초기 다운로드에 추가하지 않는다. 초기 파일 총량은 37779586바이트(이전 대비 스크립트 약 6.5KB 증가).

남은 항목: 옷·병·철사 등 정확한 접합 확대는 원본 물체 대응 대조 후 순차 보충한다. 초소 내부/시설 공간은 후보를 먼저 검증한다. 인물 동작은 토리 작업과 중복 생성하지 않는다.
