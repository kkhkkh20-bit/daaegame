# 0.19.18 — 회의 공방 연출

정확한 발언에 근거를 내면 ‘잠깐만요!’로 공방을 끊고, 승인된 큰 고정 이미지가 뜨고, 당사자와 주변이 즉시 크게 놀란다. 카메라와 현재 주장을 고정한 채 자료를 설명한다. 상대의 재정비·역공·최종 항변과 주민의 짧은 반응에 조명·구도·배경음을 함께 연결했다. 인물 화면을 옆으로 갈아 끼우던 방식 대신, 배경·고정 좌석·탁상을 하나의 시선으로 원근 투영하는 2.5D 카메라를 사용한다. 식당 원탁, 제단 돌판, 광장·학교의 모든 기존 C/F/Q 회의에 적용한다.

맞는 자료만으로 승리를 먼저 선언하지 않는다. 기존 역질문을 통과해야 성공음·반박 완료가 나오며, 자료 부족·부분 입증·포기·집행 실패 결과는 그대로다. 새 판결·의심 수치·랜덤 패배를 추가하지 않았다. 기존 표정과 음악을 재사용했고 인물 그림은 기존 자산이고, 승인된 「잠깐만요!」 고정 이미지가 추가됐다.

구체적인 구성과 검증 범위: [회의 연출 검토](../reviews/01917/MEETING_DIRECTION.md).
