# 0.18.26 · 2026-10-15 — 석재 프레임과 간결한 날짜·대화 UI

소유자가 제공한 Chef RPG 화면의 회색 면·깎인 모서리·겹친 테두리를 참고해 직접 그리는 공통 UI를 적용했다. 타 게임의 그림이나 프레임 파일은 사용하지 않았다.

- `R13StonePanel`: 짙은 회색 면과 3단 회색 테두리. 무작위 마모, 점무늬, 질감 이미지는 없다. 옵션으로 면의 투명도만 바뀌고 테두리는 선명하게 유지된다.
- 공통 행동 버튼·지역 이동 버튼·옵션·지도 장소 목록/선택·짧은 질문 선택·타이틀 선택 테두리가 같은 재질을 사용한다.
- 날짜판은 큰 일차 숫자와 요일/시간·현재 장소를 분리한다. 원래의 날짜/시간/위치 데이터만 사용한다.
- 대화창은 중앙 1008px 폭으로 줄이고 이름표를 왼쪽 위에 둔다. 아빠 얼굴을 새로 넣지 않으며 중앙 인물 연출과 분기를 유지한다.
- 하단 조작부는 작은 표시 면과 기존 터치 영역을 유지한다. 자료/인물/증언의 의미별 색, 생각의 파란색·괄호, 백로그 원문은 클로드의 0.18.24 구현을 보존한다.
- 밝은 기록 종이 내부는 이번 범위에서 유지한다. 모든 화면의 정보 배치나 상점 시스템을 다시 설계하지 않는다.

## 병합

클로드의 0.18.24 글자 규칙·프레임 변경과 배포 파일이 겹쳤다. 원본 의미 처리 변경을 보존하고, 배포 파일은 병합한 소스에서 빌더로 다시 생성했다. 메인 배경 정리 기록은 번호 중복을 피해 RELEASE_01825.md로 옮겼다. 최종 빌드는 0.18.26이다.

- Ren'Py compile/lint 및 웹 빌드 통과.
