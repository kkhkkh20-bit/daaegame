# 0.19.29 — 외부 지도 양피지 톤 통일

숲·산길 지도만 파란 설경 그림으로 남아 마을의 양피지 지도와 재질이 달랐다. 네 목적지 이동 기능을 유지하고, 숲·산길을 밝은 종이 위 갈색 잉크 선화로 교체했다. 거친 종이 무늬와 자글거리는 질감은 제외했다.

기본 숨김 지도, 온실·제단 발견 패치, 네 장소 선택 그림과 외곽선을 함께 교체했다. 바깥 여백도 양피지색으로 맞췄다. 새 건물 외곽에 따라 클릭 영역을 조정했고, 대표 클릭점·목적지·발견 조건·대사는 유지했다. 일반 장소 선택 그림은 기본 지도에서 잘라, 선택할 때 발견 전 그림과 어긋나지 않도록 했다.

그림 원본과 제작 근거: `design/maps/20261017/mountain-parchment/`.
검증 결과: `docs/reviews/mountain-parchment-20261017/`.

검증: 최신 main(0.19.28)을 병합한 원본에서 `dev/check.sh` 통과(단위 검사·Ren'Py lint). 웹 빌드의 PC 마우스와 844×390 터치로 발견 전후 표시, 네 목적지 선택, 선택 중 전체 게임 상태 불변을 확인했다. 실제 이야기 전체를 다시 완주한 검사는 아니다.
