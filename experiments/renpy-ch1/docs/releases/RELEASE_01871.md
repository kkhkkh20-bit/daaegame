# 0.18.71 · 반복해서 듣고 모순을 찾는 회의

미해결 논점의 발언 묶음이 끝나면 첫 발언으로 돌아온다. 플레이어가 대사를 넘기는 속도로 반복하며, 듣는 도중 이전/다음 버튼이나 좌우 방향키로 발언을 바로 찾을 수 있다. 이미 반박한 발언은 순환 대상에서 빠지고, 마지막 필수 발언까지 입증하면 결론을 선택할 수 있는 발언 화면으로 돌아온다. 결론 선택과 기존 공정한 심리·증언 동의·실제 준비 관문은 그대로 적용한다.

들은 발언은 선택 화면에서 조금 옅게 표시하고 ‘들음’을 붙인다. 읽기 상태는 질문 완료·반박 완료와 별개이며, 끝까지 읽은 실제 주장만 기록한다. 발언 기록에서 언제든 다시 선택할 수 있다. 반박한 발언은 기존 체크/취소선과 다시 듣기를 유지한다.

첫 발언부터 모순 구간을 붉게 알려주던 표시를 회의 듣기·선택 화면에서 제거했다. 실제 되묻기로 열린 숨은 발언에는 처음 읽기 전까지만 ‘새 발언’을 표시한다. 반복만으로 숨은 발언이 열리거나 증명되지는 않는다. 무한 빠른 넘김으로 입력 기회를 잃지 않도록 토론 듣기 중 빠른 넘김은 끄며, 더보기에서 ‘토론 멈추기’로 발언 선택에 돌아올 수 있다. 반복 듣기의 카메라 이동은 0.18초로 짧게 하고, 첫 듣기는 기존 0.32초를 유지한다. 움직임 끄기는 즉시 전환이다.

되묻기는 원래 발언으로, 새 발언을 끌어낸 질문은 새 발언으로 돌아온다. 자료 제시 취소·실패·저장/불러오기는 원래 발언/페이지/반복 위치로 돌아온다. 맞는 자료로 반박한 발언은 이후 순환에서 빠진다.

검증: 단위 테스트 181개, Ren’Py lint 및 웹 빌드. 실제 Chromium에서 두 바퀴 순환, 좌우 이동, 들음 표시, 질문 후 복귀와 숨은 발언 공개, 자료 제시·취소·실패·성공, 자료창 저장 복귀, 마지막 입증 후 순환 종료·결론 활성화, 모바일 화면을 확인한다. 기존 회의·제단·반론·공개 의견 흐름도 별도 확인한다. 명시적 7일/14일 회의 상태를 사용하며 전체 14일 플레이 검사는 아니다.
