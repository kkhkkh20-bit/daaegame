# 0.19.69 · 새 본편 4~5일 연결

4일 솜이네 대화에서 끝나던 새 본편을 5일 밤까지 잇는다. 4일 밤의 제한된 목격과 현장 조사, 5일의 동의받은 옷 대조, 밤이 혐의 정정, 엄마의 경고와 답장, 다음 날 보호 약속 및 문 잠금 확인을 원문 ID와 효과 그대로 연결했다. 천 대조만으로 혐의를 풀거나 경고 편지만으로 초대 편지 작성자를 확정하지 않는다.

경고 문장은 표시만 첫 문장/나머지로 나눠 첫 문장이 완전히 표시되는 순간 BGM을 한 번 멈춘다. 첫 클릭 완성·현재 대화 건너뛰기·저장/불러오기도 같은 결과를 유지한다. 가족의 경고와 답장은 공개 제시 수첩에서 제외하고 가족끼리의 비교에서는 직접 고를 수 있다. 이전 검토 종료 지점은 새 4일 구간으로 이어지며, 기존 선택과 물자·증거를 다시 계산하지 않고 새 필드만 명시적으로 보완한다.

실행 데이터는 25장면·238개 진행 노드·1,035레코드(표시 대상 852개)다. 필요한 배경 3개와 교정된 가족 전용 편지 후보 1개를 더했다. DEV 소매 접합도는 적용하지 않았으며 전용 초소·골목 원화와 밤 배경은 여전히 검토가 필요하다.

검증: 전체 742개 단위 검사, 초반 회귀를 포함한 native 검사 10개, Ren'Py 8.5.3 lint. 기존 종료 지점 이어하기 1건은 최초 실행의 시간 제한에 걸려 별도로 재실행하여 통과했다. native 위치 준비 검사를 전체 연속 플레이·모바일·사람 재미 검수로 간주하지 않는다. 세부 결과는 `docs/story-ms14/CONTINUATION_01969.md`에 있다. 6~14일은 아직 실행 연결하지 않았고 공개본을 빌드하거나 배포하지 않았다.
