# 0.19.74 — PR21 통합, 시작 음향·모바일 움직임·초기 로딩 개선

최신 main 0.19.73의 짧은 하단 건너뛰기·마차 도입·페이지 스킵 수정을 보존하고 PR21 `8653d3a1`의 디자인 복구를 실제 소스에 병합했다. 기존 파일 다운로드 제한이 없는 이 작업 환경의 정상 SDK로 공개 빌드를 생성한다. 생성된 preview를 손으로 패치하거나 PR의 오래된 빌드를 덮어쓰지 않는다.

## 로딩

- 시작 전에 모든 인물 표정과 이후 장소 그림을 받던 분류를 바꿨다. 타이틀·마차·입구에 필요한 인물과 배경·글꼴·시작 음악만 필수 대상으로 삼고 나머지는 기존 Ren'Py progressive downloader가 필요할 때 받는다. 파일 품질이나 원화 해상도를 낮추지 않는다.
- 작은 후기 그림까지 핵심 zip에 넣던 문제를 함께 고쳤다. 첫 실측 빌드의 필수 게임 자료는 298,613,736 → 약 54,260,000바이트(약 82% 감소), 핵심 zip은 53.8 → 16.4MB다. 별도 renpy.js/wasm 공통 런타임은 양쪽 수치에 포함하지 않는다.
- 시작 직후 전체 후기 음악·컷신을 미리 받던 동작을 없앴다. 다음 여관의 음악·환경음 두 개만 낮은 우선순위로 준비한다.
- progressive 요청도 파일 해시를 URL에 붙여, 같은 파일명의 PR21 교체 그림이 예전 HTTP 캐시와 섞이지 않도록 했다. 저장 데이터는 삭제하지 않는다.

## 시작 음향과 움직임

- 마차 BGM과 입구 BGM·바람을 시작 전에 받아 다운로드 대체 무음으로 시작하지 않도록 했다. 메인 메뉴에서 pulse·이전 장면 효과음도 정리한다.
- 출발·바퀴·옷감 효과음을 동시에 시작하지 않는다. 저역에 치우친 원본 바퀴음(150Hz 미만 에너지 약83%)은 원본을 보존하고 180Hz high-pass와 감쇠를 적용한 `cart-roll-light.mp3` 파생본 하나로 조용히 반복한다. 일반 클릭 효과음과 별도 채널을 써서 서로 중단시키지 않는다. 마차에서는 타이핑 효과음도 억제한다.
- 휴대폰 축소 시 거의 보이지 않던 1~3px 흔들림을 가로3px·세로최대8px로 조절했다. 대화창·하단 버튼은 움직이지 않으며 기존 움직임 정지 설정을 존중한다. 정차·스킵 후 해제한다.

## 검증과 범위

757개 단위 검사, SDK 직접 lint, 마차 정상 진행/첫 페이지 스킵/분할 페이지 스킵, PR21의 피코 실제 클릭과 소파 두 자리 실제 입력을 확인했다. 새 웹 빌드에서 PC·휴대폰 크기의 실제 배경 픽셀 변화, BGM 재생 위치의 연속 증가, 비어 있는 pulse 채널, 출력 오디오 신호를 측정한다. 자연 이동으로 입구·여관·13호실의 기존 조사·기록·닫기를 추가 확인한다. 검사 결과와 실제 수행 범위는 `docs/story-ms14/validation/01974/`에 보관한다.

휴대폰 검사는 Chromium의 모바일 viewport/touch 실행이며 실물 iPhone Safari 검사라고 주장하지 않는다. 로컬 관찰 시간은 테스트의 12초 안정화 대기를 포함하고, 네트워크마다 같은 로딩 시간을 보장하지 않는다. 전체 40명 수동 시각 검수나 모든 신규 대본 완료를 의미하지 않는다. 장터 상인·지도 정밀 마스크 등 PR21의 보류 항목은 이번 통합으로 완료 처리하지 않는다.
