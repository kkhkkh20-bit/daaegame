# 0.17.19-dev · 2026-10-14

옵션 화면의 소리·화면·게임 세 탭을 유지하면서 실제 조절과 확인을 보강했다.

- 소리: 효과음과 대사 타이핑 소리를 따로 켜고 끈다. 타이핑을 꺼도 문·조사 등 효과음은 유지한다. 효과음 듣기로 설정한 음량을 확인하며, 음소거/음량 0이면 안내한다.
- 화면: 글자 크기·대사창 진하기를 바꾸면 같은 탭에서 대사 예시를 확인한다. 인물 전환 효과의 변경은 즉시 영구 저장한다.
- 게임: 기존 대사 속도·자동 진행 속도·읽은 대사 빠르게·저장 정리를 유지한다.
- 옵션 초기화: 확인/취소를 거쳐 소리·화면·읽기 옵션만 기본값으로 돌린다. 작은 기기는 큰 글씨를 기본으로 복원한다. 진행 저장·발견·읽은 대사·결말 기록·시각·돈·증거는 유지한다.
- 설정은 자동 저장되며 화면 아래에 이를 표시한다.

사용자 요청에 따라 추리 도움 옵션을 추가하지 않았다. 사건 데이터, 기존 추리 메모·도면 풀이, 정답·보상 규칙은 이번 변경에서 수정하지 않았다.

0.17.18-dev를 기반으로 빌리기·아이템 쓰기·1회차 비밀 통로 조사와 그 이전의 변경을 보존했다.

검증: 단위 검사, Ren'Py 8.5.3 compile/lint, 실제 Chromium 클릭과 844×390 터치, 큰 글씨 상태의 세 탭 배치, 설정 새로고침 유지, 초기화 취소, 실제 새 게임에서 초기화 전후의 전체 진행 상태 비교. 웹 전체 화면의 플랫폼별 지원과 각 기기의 실제 스피커 출력은 이번 검증 범위 밖이다.
