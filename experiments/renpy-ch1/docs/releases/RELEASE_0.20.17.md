# Room13 0.20.17 — 마차 편지 선택지 정리

## 바뀐 것

- 1일 마차의 「편지를 살펴볼까?」 선택지(마지막 줄을 본다 / 글씨를 살핀다 / 편지를 접는다)를 없앴다. 소유자(2026-10-23): "결과가 그냥 읽는 거라 이런 선택지는 없어도 되지 않을까?" 세 갈래가 같은 장면으로 모이고 남는 값(K01a·K01b)은 마차 안에서만 쓰였다.
- 편지 끝 「……기다릴게」 → 다람의 놀림 → 한 글자씩 다시 읽기 → 편지를 외투에 넣기 순으로 이어 읽는다. K01a·K01b는 둘 다 기록한다. 라벨은 예전 저장을 위해 남겼다.
- 화면 시험 95곳을 선택지 대신 마지막 편지 줄까지 넘기도록 바꿨다. 빨리 넘기기 시험은 첫 멈춤을 입구 초소 화면으로 본다.
- `dev/reanchor_lines.py`: 코드 줄이 밀릴 때 검토 기록(대사 목록·그림 연결)의 줄 번호만, 다른 칸이 모두 같을 때만 다시 맞춘다.
