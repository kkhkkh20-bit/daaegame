# 0.19.60 — 첫 회의의 정확한 논증과 오답 세 번

- 새 회차 Q1은 톡을 지목하는 첫 발언에 대한 반박 선택으로 물증·거래·증언 중 하나의 논증을 확정하고 끝까지 입증한다. 다른 안의 성공으로 현재 논증의 빈 단계를 대체할 수 없다. 증거 소지나 다른 논점의 자료만으로 통과하지 않는다.
- 수리 작업표와 자재 대장(L21/L22)을 추가했다. 모든 공략은 실제 반출과 수리 의뢰의 권한 범위를 따로 입증한다.
- 잘못 제시한 증거, 확정한 해석, 입증되지 않은 최종 결론은 회의 전체에서 오답을 공유한다. 세 번째에 실패하고, 같은 조사 자료로 회의 처음부터 다시 시작할 수 있다. 열람·질문·해석 확정 전 철회는 무료다.
- 기존 rules 1/2 저장과 이후 이야기의 처분 결과는 유지한다. 새 규칙은 새 게임에 적용된다.
- 0.19.59의 자료 필터 정리를 병합했다. 신규 화면 디자인은 추가하지 않았다.
