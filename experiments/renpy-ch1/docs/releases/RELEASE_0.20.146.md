# 0.20.146 — 주민 대화·작은 부탁·마을 일과

1부에서 주민을 눌러도 인사로 끝나던 대화를 개인 질문으로 확장했다. 주민의 직업·관심사와 전반/후반의 안부를 고를 수 있고, 필수 수사 질문과 함께 표시한다. 위기에는 일상 노래를 섞지 않는다. 피코 소식을 직접 들은 나비·부리와 실제 화재 결과를 아는 관계자의 후속 질문을 구분한다. 새 생활 질문이 놓친 사망 소식 전달을 막지 않도록 필수 업무 판정을 분리했다.

여니의 바느질, 설이의 종소리 안내, 부리의 예비 부품 정리를 선택 의뢰로 연결했다. 수락·거절·보류, 실제 물건 작업과 보고, 마친 뒤 기억이 이어진다. 시작은 2~5일, 수락한 일은 7일까지 마칠 수 있다. 들은 부탁은 현장의 ‘부탁’ 수첩에서 다시 본다. 완료한 도움은 현이의 노랫말에 남는다. 본편의 증거·정답·생사·시간·돈을 보상으로 바꾸지 않는다.

아홉 주민의 일과를 여러 장소로 나누고, 독립 역할이 없는 네 배역은 평상시 군중에서 뺐다. 보통 현장은 다섯 명까지 보이되, 현재 사건 인물과 수락한 의뢰 담당자는 보존한다. 구 저장에 남은 지난 대화 위치 때문에 재배치된 주민의 질문이 사라지는 문제를 함께 고쳤다. 인물 ID와 원화는 지우지 않는다.

회의·학교 인계·쪽지 전달을 마친 7일차 자유 오후를 계속 긴급 장면으로 세던 제한도 풀었다. 완료 전과 구금·후속 사건은 보호하고, 장면 번호·기록은 유지한다.

숨긴 동행 다람에게는 현장 위의 ‘다람’ 버튼으로 말을 건다. 학교·다른 보호자·구금 상태에서는 멀리 있는 다람을 부르지 않는다. 물건에 여러 행동이 있으면 공통 질문 수첩에서 선택·취소하며, 물건 이름만 아빠 대사로 읽지 않는다. 새 그림을 생성하지 않고 기존 배경·원화·UI를 사용한다.

검증 범위와 화면은 [검수 기록](../reviews/review146/검수.md)에 구분해 기록한다. 55명 카탈로그는 대사 정의 수이며 한 장면의 출현 수가 아니다. 전 주민의 모든 날짜·모든 분기를 자연 진행했다는 뜻으로 쓰지 않는다.
