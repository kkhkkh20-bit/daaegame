# 0.19.37 — 기록 고정 위치와 자료 제시 분리

대화 화면의 기록 버튼이 인물 옆 왼쪽 아래에 있어 다른 화면의 기록 위치와 달랐다. 소유자 요청으로 기록은 조사 화면과 같은 우측 하단에 고정하고, 자료 보여주기는 오른쪽 질문지 아래에서 기존보다 64px 위로 올렸다. 돌아가기는 좌측 하단을 유지한다.

질문 행과 페이지 조작이 올라간 자료 제시 버튼과 겹치지 않도록 질문 영역 높이와 페이지 버튼 위치를 조정했다. 긴 질문의 줄바꿈·명시적 페이지 이동·현재 쪽 숫자 키·읽음 표시를 유지한다. 대사·진행 조건·자료 제시 로직은 바꾸지 않는다.

검증: `dev/check.sh` 단위 검사 및 Ren'Py lint, 공식 웹 빌드. 실제 Chromium PC 1280×720와 모바일 844×390/큰 글씨에서 빈 목록·8개·12개 배치, 고정 버튼 좌표와 겹침 여부, 페이지 왕복 및 숫자 키, 실제 자료 제시/기록 열기·취소·복귀를 확인했다. 시안과 결과는 `docs/reviews/fixed-topic-tools-20261017/`.
