# 0.19.99 — 1~14일차 대사 전면 수정, 갈색 톤 UI 통일, 퍽·흔들림 연출

## 대사(소유자: "대사 훨씬 좋다. 이대로 전체적으로 수정해서 적용")
- 1~14일차 전체를 Codex가 날마다 고치고 Claude가 검수해 넣었다.
- 기준: 살아 있는 말, 처음 하는 20대가 바로 이해할 쉬운 말, 플레이어보다 먼저 정답을 말하지 않기, 줄마다 표정, 말 안 되는 제도 바로잡기.
- 사실(이름·숫자·장소·누가 무엇을 했는지)과 회의 논리는 그대로 두었다.
- 플레이어가 맞힌 뒤 아빠가 정리하는 결론 줄은 남겼다(예: 3일차 우박·초롱의 시각 정리). 엄마가 조사해 알려 주는 내용도 남겼다(11일차 "쇠는 나중에 덧붙였다", 14일차와 이어짐).

## 연출(소유자: 역전재판처럼 "퍽" 효과음과 화면 흔들림)
- 줄마다 jolt(가벼운 놀람)·shake("퍽"+흔들림)·slam(가장 센 순간)·flash(단서가 맞아떨어지는 순간의 하얀 번쩍임)를 지정할 수 있다.
- 1~14일차 전체에 지정했다. 하루 줄의 5% 안팎이고, 죽음·이송·아이 위험 장면에는 쓰지 않았다.
- 효과는 0.2~0.5초 한 번이다. 설정에서 '화면 움직임'을 끄면 소리만 나고, 건너뛰기 중에는 나지 않는다.

## UI(소유자: "갈색 톤으로 하고 ... 쭉쭉 가보자")
- 0.19.98의 새 대화창·설정창 모양은 그대로 두고 색을 갈색·베이지로 바꿨다.
- 붓 리본, 판(금 모서리 장식), 버튼은 Codex가 손으로 칠한 질감으로 바꿨다(art/ui-painted-20261022).
- 공통 버튼과 어두운 판을 같은 조각으로 바꿔서 현장 하단·질문 화면·선택지·더보기도 한 번에 같은 재질이 됐다.

## 검증
- 단위 테스트 859개와 lint 통과. 화면 테스트(새 세계 1~14일차 전체 포함) 통과. 브라우저에서 첫 화면부터 첫 현장까지 진행 확인.
