# Room13 0.20.109 — 10~12일 주민 별편과 반응

2026-11-06. 소유자의 다음 구간 요청에 따라 10~12일 별편 9장면과 본편 반응 27행을 연결했다. 시점 인물은 부리·톡·부엉이·나비·엄마·굴돌·서리·돌목 여덟 명이며 나비는 두 시점에 등장한다.

서류 설명을 반복하는 대신 사과를 받을 시기를 고르는 부리, 증거를 풀지 않고 수리를 설명하는 톡, 토실의 밥자리와 새미의 책을 맡는 나비, 약병보다 아이의 몸을 살피는 서리의 행동을 썼다. 부엉이의 오늘 인수표와 어제 확인한 서류철은 구별한다.

살인/예방, 실제 출석, 토실의 실제 인수, 가족 재회, 배식 전 중단/섭취 후 사건, 일반 승리/부분 성공/명단 칸 무효를 분리한다. 기존 자료·정답·기회·생사·구금·결말과 UI·아트는 유지한다. 상세 [원고·시간·분기 매칭](../design/resident-reactions-day101112-20261106/README.md), [검수 기록](../reviews/resident-days101112-20261106/검수.md).

이번 확장은 전체 14일 중 사흘이다. 14일 연속 플레이나 인간 초견 독자 실험을 했다고 주장하지 않는다.

전체 단위 1,306개·관련 16개, lint·A/B/C, 네이티브 고유 14개와 새 브라우저 초기 로딩 통과. 초기 로딩은 941바이트 증가한 36,369,125바이트다.
