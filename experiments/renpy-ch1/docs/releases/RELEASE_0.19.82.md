# 0.19.82 — 이른 새벽의 숲 안개와 느린 눈

사용자가 이른 새벽의 미스터리한 분위기, 숲 안개와 내리는 눈을 요청했다.0.19.81의 정돈된 형태를 유지하면서 밝은 아침을 해 뜨기 전 청회색 새벽으로 바꾼다. 먼 마을은 낮은 안개에 일부 가리고 작은 창 불빛만 남긴다.

- 안개는 그림 안의 넓고 부드러운 층으로 표현한다. 눈·숲에 잔무늬나 질감 필터를 추가하지 않는다.
- 기존 R13FxSnow를 재사용해 눈송이22개만 천천히 내린다. 마차와 카메라는 고정한다. 새 엔진·외부 영상·새 파티클 자산을 만들지 않는다.
- 이 컷의 눈 위치 격자만1px로 두어 낮은 속도에서도 큰 칸으로 뛰지 않게 한다. 다른 장소의 눈 설정은 바꾸지 않는다.
- 기존 움직임 설정을 끄면 눈은 표시하지 않는다.3.5초 자동 전환·건너뛰기·기존 주행음·내부 대화는 유지한다.
