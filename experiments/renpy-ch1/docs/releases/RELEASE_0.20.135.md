# 0.20.135 — 자체 작도 UI 축소와 납품 B 에셋 통일

공통 아이콘·버튼·자료/지도 보조 판·증거 틀을 기존 납품 B 에셋으로 맞췄다. 새로운 이미지 생성 없이 기존 파일을 재사용한다. 버튼의 상태·클릭 영역·액션과 도구함 재매칭은 유지한다. 소지 자료·정답·생사·결말은 변경하지 않는다.

전용 그림 내용이 추리 단서인 경우에는 같은 내용의 대체본 없이 범용 아이콘으로 바꾸지 않았다. 같은 규격 납품이 없는 정사각 버튼과 피코의 임시 스케치는 잔여 항목으로 기록했다. 관련 단위158개와 SDK5개를 확인했으며, 최종 웹 검증은 [화면과 검증 범위](../reviews/asset-reuse-20261109/검수.md)를 따른다.

최종 웹에서도 PC·휴대폰의 메인/질문/자료 대조/증거 알림/지도를 확인했고 새 게임에서 입구 등록까지 진행했다. 브라우저 pageerror는 없었다.
