# 0.19.75 — 마차 전체 배경·한 번의 덜컹임·로딩 음악·현장 이동

소유자의 최신 지시에 따라 좌석만 잘라 보여주던 마차 도입을 폐기하고 제공된 원본 배경을 게임 화면 전체에 표시한다. 반복 흔들림을 없애고 “아빠는 안 잡아 줘?” 직전에 0.48초의 단발 덜컹임을 붙였다. 대화창과 버튼은 고정되며, 기존 움직임 끄기 설정과 건너뛰기 경로를 존중한다. 기존 저장에서 참조할 수 있는 옛 transform 이름은 움직임 없는 상태로 유지한다.

HTML 로딩 화면이 기존 타이틀 음악을 먼저 재생한다. 브라우저가 자동 재생을 막으면 로딩 중 첫 터치/키 입력으로 시작한다. 로딩 화면 종료와 페이지 이탈 때 별도 재생을 정리하여 게임 음악과 중복되지 않게 한다. 음악 요청은 기존 필수 다운로드와 동일한 파일 해시 URL을 사용한다. iPhone의 무조작 자동 재생 제한을 해제하는 기능은 아니다.

현장의 기존 viewport·좌표계·조사 경로를 유지한다. 두 픽셀 단위 강제 이동을 풀고 한 픽셀 단위 좌표를 저장하며, 좌우 화살표의 즉시 480픽셀 이동을 0.42초 가감속 이동으로 바꾼다. 이동 중 최대 프레임 갱신을 요청하고 Ren’Py의 기존 adjustment 애니메이션을 사용한다. 또한 가장자리 안내를 확인하는 0.3초 타이머와 이동 버튼의 불필요한 전체 화면 재평가를 없앴다. 안내와 끝 지점 버튼은 이동이 끝난 뒤 달라졌을 때만 갱신한다. 실제 기기의 성능과 화면 주사율에 따라 프레임 수는 달라진다.

0.19.74의 초기 필수 자료 축소, PR21 디자인 통합, 짧은 건너뛰기 버튼과 기존 조사·수첩·증거 제시를 보존한다. 6일차 파일과 신규 스토리 범위는 변경하지 않는다.

검증: 단위 검사 760개 통과, SDK 직접 lint 종료0, 네이티브 마차 3경로 통과. 새 웹 빌드에서 일반 대화·편지·컴팩트 건너뛰기, 자연 이동으로 입구·여관·13호실의 조사/수첩/증거 제시/가족 꾸러미 획득을 확인했다. 로딩 음악은 엔진 시작을 일부러 지연한 브라우저에서 자동 재생 및 첫 터치 해제, 로딩 화면 종료 시 정지를 각각 확인했다. 프레임 검사는 소프트웨어 렌더링 Chromium의 실제 중간 좌표와 정지 복귀를 확인하는 것으로, 실물 iPhone의 60fps를 측정한 결과가 아니다. 결과는 `docs/story-ms14/validation/01975/`에 보관한다.
