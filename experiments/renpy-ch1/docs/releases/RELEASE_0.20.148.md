# 0.20.148 — 소설의 세계를 선택 조사로 연결

2026-11-10. 정본 소설과 주민 별편에 근거한 선택 조사 여섯 연쇄를 1부의 안전한 공개 방문에 연결했다. 등 관리·우편 접수·식당 자리·공구 대여·학교 돌봄·화재 뒤 장작을 관찰한 뒤 해당 주민에게 질문하고, 직접 참여하거나 이야기를 듣고, 다음 만남에서 참여 방식에 맞는 대화를 듣는다.

수락만으로 작업을 완료하지 않는다. 실제 현장 물건을 다시 눌러 확인하며 취소할 수 있다. 피코의 생사와 주민별 실제 청취, 톡 회의 결과, 화재의 실제 구조·인수 결과에 따라 대화 문맥을 나눈다. 결과는 아빠가 상대에게 먼저 전하고, 보리에게도 다른 장소에서 한 일을 직접 보고한다. 본편이 요구하는 같은 물건 조사는 우선한다.

본 것·들은 것·직접 해본 일을 독립 저장하고 기존 수첩의 ‘마을 이야기’에서 출처와 다음 행동을 읽는다. 휴대폰·큰 글씨에서는 한 장씩 넘긴다. 기존 그림·음악·공통 UI를 재사용했다. 기존 증거·예방·생사·회의 정답·인수 판정·시간·7일 1부 종료 경계를 바꾸지 않았다.

전체 단위 검사 1,773개와 실제 SDK 준비 경로 18개 및 우편 조사 화면 조작이 통과했다. 웹에서는 이전 저장 복원, 세련의 듣기와 보리의 실제 왕복 작업·보고·저장, Android 휴대폰 기록 쪽 넘김을 확인했다. 검증 범위와 화면은 [148 검수](../reviews/review148/검수.md), 원문과의 연결은 [적용 설계](../design/WORLD_INVESTIGATIONS_PART1_20261110.md)에 남긴다. 모든 주민의 날짜별 별편을 모두 구현한 판이나 1~7일 자연 완주 검증으로 보고하지 않는다.
