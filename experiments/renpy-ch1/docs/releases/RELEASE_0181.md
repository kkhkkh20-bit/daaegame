# 0.18.1-dev · 2026-10-14 — 기록·질문·조작 UI 개선

ROOM13_GUIDE.md와 RELEASE_0180.md, OVERRIDE_MAP.md를 읽고 이전 미배포 변경을 리팩토링된 일반 소스에 병합했다. 새 빌드·WebP 경로·글꼴 통일을 유지한다.

- 읽은 질문에 흐린 표시와 취소선을 함께 적용한다.
- 기록 상세의 확인한 내용을 날짜·장소보다 먼저 보여주며 긴 자료 제목의 글자 크기를 조정한다.
- 자료 획득·제시 알림을 작은 가로 카드로 정리하고 대화 중에는 좌측 상단에 표시한다. 기존 효과음은 유지한다.
- 하단 버튼의 작은 시각적 높이를 유지하면서 클릭 영역을 확대한다.
- 13호실 다람이에게 자료를 제시하면 기존 동료 대화와 연결한다. 기존 제시 처리와 개별 증거 반응은 보존한다.
- 새 제시 함수 확장에 맞춰 덮어쓰기 지도를 갱신했다.

검증 범위: 소유자 지시에 따라 개별 화면·브라우저·플레이 및 단위 테스트는 이번에 실행하지 않았다. Ren'Py 컴파일·lint와 웹 빌드만 확인하고 배포한다. 전체 플레이 검증은 후속 변경과 함께 진행한다.
