# 0.20.134 — 입구 서류 재클릭 제거와 증거 획득 알림 복원

입구 선반에서 맞는 요일의 신청서를 찾으면 그 자리에서 원본 읽기와 획득까지 이어진다. 명단을 보기 전에 선반을 눌러도 경비에게 명단을 요청하고 확인한 뒤 선반 조사를 계속한다. 장부를 먼저 읽는 경로와 편지를 보여 주는 경로는 유지한다.

증거 획득 카드는 오른쪽에 실제 자료 그림·“증거 획득”·자료 이름을 표시한다. 자료·지도·설정 화면에 가려진 동안 만료되지 않으며, 연속으로 얻은 자료를 순서대로 보여 준다. 현재 카드에 다음 자료가 추가돼도 앞 카드로 돌아가지 않는다. 자료 제시와 마차 편지의 기존 표시는 유지한다.

증거 ID·정답 조합·기회·등록 결과·생사·결말은 변경하지 않는다. 관련 단위228개와 최종 알림9개, SDK3개를 확인했다. [실제 화면과 검증 범위](../reviews/gate-evidence-20261109/검수.md)를 따른다.

PC·휴대폰 웹에서 0.20.133 저장 복원, 선반 첫 조사부터 원본 획득, 두 자료 제시와 등록 성공을 확인했다. E02·E03·E05 획득 카드를 각각 촬영했으며 브라우저 pageerror는 없었다.
