## 대사 다듬기 (소유자 지시)

- 제미나이 1번 파일: 130줄을 반영했다. 2~10번은 낱말만 기계적으로 바꿔 조사가 깨진 줄이 많아 반영하지 않았다.
- 11·12번: 소유자가 준 수정본을 먼저 썼다(119줄). 뜻이 바뀐 15줄과 도구 검사에 걸린 줄은 뺐다.
- 나머지 범위: 같은 방향(고유명사·새로 만든 말을 줄이고, 함축된 말을 풀어 씀)으로 다시 썼다.
  1. 그거·거기·그분 같은 말을 가리키는 대상으로 바꿈
  2. 잘린 대답을 뜻이 드러나게 채움
  3. 대사 속 만든 말을 일상어로 바꿈. 고정 용어 95개와 장소·물건·기록 이름은 그대로 둠
  4. 연결어(그래서, ~거든요, 먼저) 보충
  5. 장면이 뜻하는 태도를 한두 마디로 드러냄
  6. 긴 서술문을 사실 하나씩 짧게 나눔
- 결과: 내보낸 3,629줄 중 2,849줄 반영, 거절 0줄. `dev/dialogue_tool.py`가 이름 횟수·괄호 조각·길이·따옴표를 검사했다.
- 지키지 않은 것을 따로 확인: 새 사실·단서 추가, 존댓말·반말 변경, 인물 이름 추가·삭제.
