# 0.19.32 — 승인된 반투명 대화 UI와 넓은 선택지

대사창은 기본 불투명도 약85%, 선택지는 약90%(가리키면 약96%)의 짙은 갈색 재질로 바꿨다. 글자 투명도는 유지하고 테두리는 가는 선으로 정리했다. 선택 화면의 전체 암막과 하단 도구 모음의 시각적 무게도 줄였다.

선택지는 PC 최소 높이72px, 큰 글씨80px, 세로 여백17px, 항목 간격16px로 넓혔다. 실제 줄 높이·여백에 맞춰 목록 높이 계산도 조정해 화면을 넘는 항목은 스크롤로 고를 수 있다. 대화 상대가 없는 선택지도 높이72px를 사용한다.

두 차례 실제 브라우저 비교 시안을 확인한 소유자가 승인했다. 검토용 플래그는 제거하고 기본 UI로 연결했다. 기존 저장의 검토용 변수 값과 무관하게 적용된다. 대사창 진하기 설정은 연하게·기본·진하게로 구분하며, 진하게는 불투명한 창을 유지한다. 대사·선택 결과·단서·진행 조건은 변경하지 않았다.

검증: `dev/check.sh`(단위·Ren'Py lint), `dev/build_web.py --part-mb 8`, 실제 Chromium의 밝은 실외·저녁 실내·844×390 큰 글씨 화면 및 선택지 클릭 후 원본 대사 연결. 전체 이야기 완주 검사는 아니다. 결과는 `docs/reviews/translucent-ui-release-20261017/`에 기록한다.
