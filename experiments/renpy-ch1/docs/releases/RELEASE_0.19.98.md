# 0.19.98 — 대화창·설정창 새 디자인, 1일차 대사 전면 수정

## 대화창(소유자 지시: 노션 「UI 개선안」 맨 위 시안 그대로)
- 상자 없이 화면 아래쪽 얕은 남색 그늘 위에 대사를 놓는다. 이름은 버건디 붓 리본과 가는 금색 선, 대사는 한 단계 큰 따뜻한 흰 글씨.
- 오른쪽 아래는 작은 글자 조작 「▸▸ 건너뛰기 | ⚙ 더보기 ▸」. 누르는 범위는 기존 터치 높이(모바일 80)를 유지한다.
- 일반 대사의 「기록」은 더보기 안 「자료 기록」으로 옮겼다. 주민 질문 화면 하단은 기존 승인 배치를 유지한다.
- 새 세계 회의(입구·등불 등) 대사도 같은 대사창을 쓰고, 회의 무대와 쟁점 머리띠는 그대로 둔다.
- 「대사창 진하기」 설정은 그늘 진하기로 계속 적용된다.

## 설정창(소유자 시안 그대로)
- 남색 판, 가는 금 테두리와 모서리 장식, 왼쪽 탭(읽기·소리·화면)의 버건디 붓 강조.
- 선택 버튼은 금 테두리, 고른 값은 버건디 바탕에 작은 마름모. 속도 미리보기 상자, 하단 설정 초기화·메인화면·단축키 PC·닫기, 오른쪽 위 X.
- 더보기 판도 같은 재질과 버튼으로 바꿨다.

## 대사
- Codex 1일차 전면 수정본(소유자 승인)을 표정과 함께 적용했다(초소부터 첫날 밤까지 104줄).
- 겨울철 입장 규칙에서 '가족 방문'이라는 별도 입장 분류를 없앴다(소유자). 규칙은 "방문객은 묵을 곳이 확인되면 함께 온 사람까지 등록한다"이고, 신청서에는 방문 목적(아내를 만나러)만 적힌다. 입구 회의의 증거 조합(입장 명단·방문 신청서·입장 규칙)과 판정은 그대로다.
- 마차 장면 v5 대본, 앉아 있는 다람 8가지 표정, 게임 전체 대사 표정 표시 수정(0.19.97 이후 커밋).
