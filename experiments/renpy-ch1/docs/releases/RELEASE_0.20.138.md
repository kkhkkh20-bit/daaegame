# 0.20.138 — 자동 해설을 줄이고 단서를 직접 확인하는 조사

입구의 요일 맞히기를 짧은 서류 검색으로 바꾸고, 제시 전에 원본과 명단의 차이를 인물이 전부 설명하던 줄을 덜었다. 서류의 이름·인원·날짜는 그대로 읽을 수 있으며 실제 입증 뒤에 설명과 이름 정정이 이어진다. 입구는 작은 누락 확인 튜토리얼이다.

첫 방의 도토리 위치를 맞혀야 통과하던 단계를 현행 읽기에서는 요구하지 않는다. 두 글을 읽고 다람과 이야기하며, 직접 끝부분을 관찰했는지에 따라 표현을 구별한다. 도토리 없음으로 위조·작성자·작성 순서를 확정하지 않는다. 옛 관찰 도중 저장의 호출은 보존한다.

2일 초롱에게 두 글을 직접 제시한다. 메모에는 필체와 마지막 목격을 확인하고, 초대 편지에는 발송자를 모른다는 답과 우체국 장부의 단서를 듣는다. 어느 순서로든 제시할 수 있고 다른 자료·취소는 확인 완료나 실패로 처리하지 않는다. 실제 답변 뒤에만 완료를 기록한다. 두 글을 확인한 뒤 기존 교환함 경로로 이어진다. 이 대화의 자료함은 보유 자료를 한 목록에 보여 주며 문서를 자동으로 고르지 않는다.

새 진상·증거 ID·정답·기회·생사·결말·새 그림은 추가하거나 바꾸지 않았다. 검증 범위와 화면은 [검수 기록](../reviews/deduction-20261109/검수.md)에 남긴다.

관련 단위200개·생성 메타데이터36개·SDK5개 통과, 대사 A/B/C0건. 최종 로컬 웹에서 기존2일 아침 저장을 불러와 초대 먼저→메모 제시→교환함 이동까지 확인했다. 입구와 첫 방은 집중 화면 시험으로 확인했으며1~7일 전체 재완주는 하지 않았다.
