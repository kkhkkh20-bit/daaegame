# 0.19.76 — V1.1.1 첫 3일 연결

V1.1.1 원문을 기존 Room13의 대화·현장 클릭·인물 질문·지도·수첩 제시에 연결한다. 새 실행 엔진이나 별도 게임 메뉴를 켜지 않으며, 기존 자산과 PR21 디자인/0.19.75 마차·로딩·카메라 수정을 유지한다.

- 원본 82씬/3162개 레코드와 지시·감사 자료를 `docs/story-v111/source/`에 보존했다. 첫 3일의 실행 조건/선택 효과만 검토해 Ren’Py label로 연결했다.
- 초대 편지와 초소 원본/명단/규칙, 숙소 메모와 꾸러미, 봉투 기록, 등 조사, 피코 보호/네로 작업, 점검·대여·측정/운반·매입·칼 대조를 기존 입력 방식으로 진행한다.
- 반복 관찰로 선택 효과가 다시 지급되지 않는다. 침구 예약과 실제 수령, 피코의 생사와 초상의 완성 주체, 돌 반환과 실제 설치, 실룩 처우를 분리한다.
- 교환함의 실제 클릭 겹침/접지 배치, 오답 제시 후 근거 정리, 장소 이동 시 음악의 불필요한 이중 전환을 수정했다.
- 공개 범위는 3일차까지다. 그 뒤에는 기존 확인창에서 저장/메인 화면 이동을 안내한다. 4~14일을 완료한 엔딩으로 처리하지 않는다.

## 검증

- `dev/check.sh`: 단위 검사와 Ren’Py lint 통과. 보존된 구작 시작 문장에 unreachable 안내가 있으나 파싱/실행 오류는 없다.
- `v111_opening_native`: 실제 마차→편지 입력→입구 조사 통과.
- 실제 웹 피코 보호 경로: 첫날 조사/증거 제시/취침, 둘째 날 실제 식당 인계, 셋째 날 생존·완성 초상, 증거 대조, 돌 복구, 출석 의무 선택과 마지막 취침까지 진행 확인.
- 최종 빌드의 네로 경로: 피코 부재/미완성 초상→다람의 이어 그리기, 담요 예약 0장→실제 수령 2장, 돌 반환 보류, 실룩 공동작업 대기, 3일차 완료 안내까지 통과. 오답 후 재제시도 통과했다. 완료 안내의 저장 화면 열기/복귀와 메인 화면 이동을 확인했다.
- 저장·로드·스킵 기본 기능의 반복 행렬은 돌리지 않았다. 통과한 첫날은 테스트 저장에서 이어서 확인했다.
