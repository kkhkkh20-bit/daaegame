# Room13 0.20.115 — 제1부 리뷰 보완

2026-11-06. 소유자의 ‘그부분 개선해줘’ 지시로 1부 리뷰의 다섯 문제를 보완했다. 범위는 1~7일 화재 뒤 학교 인수와 1부 마무리까지다.

종료 대사를 ‘오늘 조사는 여기서 마치자’로 바꿨다. 누르면 탐색 계속/1부 마무리를 고르며, 완료 화면에서도 탐색으로 돌아갈 수 있다. 돌아갈 때는 7일 오후와 사건·증거·이미 한 행동을 유지한다. 다시 마무리하면 새 오후 행동까지 완료 저장에 갱신한다. 후속판은 기존처럼 7일 저녁부터 이어진다.

3일 칼 대조와 7일 화재 가설은 정답만 신중한 말투인 차이를 줄였다. 칼날 자국과 부러진 칼끝, 등잔·문 쪽 천·뒤창 장작을 근거로 가르도록 바꿨다. 선택 순서·반환값·정답 자료·기회·판정은 유지했고 반박도 해당 가설에 맞췄다.

4~5일에는 아빠가 먼저 관찰과 추정을 구별하고 다람은 아이의 마음과 자기 기억을 보탠다. 너울은 무작정 새 범인을 지목하기보다 기존 처분을 유지하려는 태도를 드러낸다. 6일에는 익명 물자 전달과 안전한 만남에 대한 답 확인을 아빠의 목적으로 이어 주고, 두 이송 경로 모두에서 누비가 자기 아이를 돌보는 행동을 보인다.

7일 누비가 자백한 뒤 꼬미 사망 경로에서는 이름과 결과를 직접 듣는다. 마지막 가족 대화는 꼬미 생사·보리의 혐의에 따라 달라지고, 엄마의 답장과 처음 초대 편지의 차이를 앞으로 물을 질문으로 묶는다. 편지 소지만으로 내용을 들었다고 소급하지 않는다. 과자를 남긴 다람의 말로 마무리한다.

웹 검수에서 공방의 자동 발화 합류가 학교 주민 전원의 위치까지 공방으로 바꾸던 오류를 발견했다. 자동 발화에서는 말하는 주민만 현재 장소에 합류한다. 이미 위치 표식이 잘못 저장된 경우에도, 학교 화면에서 실제 마주한 다람과는 마지막 가족 대화를 나눈다. 사망·떠남·구금 조건은 유지한다.

실제 확인 범위와 캡처는 [검수](../reviews/part1-improvements-20261106/검수.md)를 따른다. 초견 이용자의 재미·난도 평가는 자동 검증과 구분한다.
