# 0.18.13-dev · 2026-10-15 — 첫 며칠: 질문 → 자료 제시 → 새 사실 → 새 의문 (소유자 지시)

원칙: 선택지나 안내가 플레이어 대신 "누구에게 무엇을 보여 줄지" 정하지 않는다. 일반 질문은 흐린 답을 받고, 맞는 자료를 직접 제시해야 사실이 나온다.

## 안내를 의문으로
- 화면 위 목표줄(1~2일): 목적지·행동 대신 풀리지 않은 의문을 쓴다. 예: "엄마는 우리가 올 걸 알고 있었다. 그런데 왜 기다리지 않았을까?", "엄마는 정말 우체국 안에 들어갔을까? · 창구는 내일 오전에 연다". 시간·장소 같은 환경 정보는 남겼다.
- 다람이의 "어디부터 살펴볼까", 첫날 밤·2~3일 밤 대화도 같은 방식으로 바꿨다.
- 기록 비교 결과는 확인된 것과 모르는 것까지만 말하고, "보여 주고 확인해 보자" 같은 다음 행동은 뺐다.
- 조사 메모의 "막혔다면 생각 정리"는 직접 눌러야 열리므로 남겼다. 다만 사람과 자료를 둘 다 지정하지 않도록 한 단계 흐리게 썼다.
- 일자리 판의 "엄마의 메모 제시 → …" 설명을 없앴다. 하는 일만 보인다.

## 이름만 묻기 vs 자료 제시 (`systems/room13_present_flow.rpy`)
- 2~4일, 초롱·슬링·세련에게 "제 아내를 보신 적 있습니까?" 류의 질문이 생겼다. 이름만으로는 알아보지 못한다.
- 엄마 초상은 기록 **P01**이 됐다. 질문 목록에 자동으로 생기던 "엄마 초상을 보여 준다" 두 개를 없앴다. 기록에서 직접 제시해야 한다.
  - 슬링: 밤마다 편지를 부치러 왔고 초롱이 받아 갔다(J08).
  - 초롱: 얼굴을 확인했다(J07). "편지를 전달할 때 사람을 다시 찾을 필요가 없어졌다."
- 뿔이의 "돌에 긁힌 이름들을 보여 준다"도 같은 이유로 없애고, 기록 R01 제시로 바꿨다.

## 엄마 연락 날짜 (사실과 설명 맞추기)
- 예전 설명은 "답장이 이틀 빨라진다"였지만, 실제 계산은 반나절(시간 칸 2개)이었다.
- 큰 흐름(엄마와 만나는 것은 2주차)은 그대로 둔다. 초상의 보상은 신원 확인이다.
  - 초롱이 얼굴을 확인했으면, 가족이라는 다른 증거(편지+매듭)를 따로 요구하지 않는다.
  - 답장은 원래대로 "다음 날"이지만, 그날 첫 시간에 확인할 수 있다(오후에 보내면 다음 날 오후 → 다음 날 오전).

## 기록 문장
- 관찰·들은 말만 남기고 추론을 뺐다. 엄마의 두 번째 쪽지(M02)는 적힌 글 그대로, 그을음(R02)은 "여러 겹 겹쳐 있다"로.
