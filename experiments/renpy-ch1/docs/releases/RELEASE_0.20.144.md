# 0.20.144 — 잠자기 확인과 1부 재탐색·선택 대화 연결 복구

침대를 누르면 바로 다음 날로 넘어가던 동작에 ‘잠자기 / 더 둘러보기’ 확인을 넣었다. 잘 수 있는 단계에는 현장에 ‘잠자기’ 버튼도 표시한다. 취소하면 날짜·시간·자료·진행을 유지한다. 2일차 아침 약속 준비와 수면의 연쇄는 한 번 동의한 뒤에만 이어지며, 옛 저장의 자동 수면 예약은 새 동의로 간주하지 않는다. 침대를 누른 동작이 ‘아빠: (침대)’로 출력되던 경로도 막았다.

현재 사건의 선택지에 연결된 장소만 열리던 탐색 제한을 완화했다. 1~7일의 일상 조사 중에는 실제 방문한 접수대·광장·우체국·수리점·진료실·학교를 다시 방문할 수 있다. 여관 접수대·복도·13호실의 연결과 현장 길목 이동도 복구했다. 식당은 방문 후 열린다. 구금·사건 봉쇄·이동 중·회의·긴급 대응은 기존 제한을 따른다. 재탐색이 원래 임무를 완료하거나 건너뛰지는 않는다.

이미 읽은 후속 질문이 있어도 ‘할 말 없음’으로 분류되던 오류를 고쳤다. 기존 질문 31개 중 1부에 해당하는 17개의 재독 접근을 복구했다. 실제 재실·생사·날짜·보유 자료를 다시 검사한다. 본편에 연결되지 않았던 공방 협업·여관 바느질 두 생활 장면도 기존 조건이 맞을 때 선택해 들을 수 있게 했다.

광장의 인물 겹침 회피가 카메라 위치에 따라 다시 계산돼 초롱·바둑이가 다른 곳에 다시 나타나던 문제는 장면의 고정 구도를 기준으로 계산하도록 수정했다.

새 주민 사건이나 그림·음향은 추가하지 않았다. 모든 주민의 자유 대화가 충분해진 버전이라는 뜻은 아니다. 선택 대화가 원래 없는 주민의 콘텐츠는 남은 과제다. 정답·자료 획득·생사·결말·1부 7일 공개 경계는 유지한다. 검증 범위와 캡처는 [수정 검수](../reviews/review144/검수.md)에 기록한다.
