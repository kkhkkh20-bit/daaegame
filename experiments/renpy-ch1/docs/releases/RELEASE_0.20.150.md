# 0.20.150 — 마을 퍼즐의 물품 안내와 깡통 조사 위치

2026-11-10. 마을 퍼즐 검수에서 확인한 두 문제를 수정했다.

- 2일 밤 걸쇠를 관찰하고 시장 끈을 사용했지만 묶는 방법을 아직 배우지 않은 경우, “이 물건에 쓸 도구는 아니다” 대신 재료는 맞고 묶는 방법을 알아봐야 한다고 말한다. 안내만으로 끈을 소모하거나 본편 상태를 바꾸지 않는다.
- 6일 창고의 깡통 조사 영역을 천장 쪽에서 그림 속 몸통으로 내렸다. PC 기본 글씨에서는 상단 버튼과 겹치지 않으며, 844×390 터치·큰 글씨에서도 몸통 중앙 클릭으로 관찰·회수까지 확인했다.

까로에게 배우는 조건과 초롱에게 끈을 받는 기존 경로, 깡통 관찰·회수 조건, 생사·회의 정답은 유지했다. 표시 버전과 빌드 버전도 150으로 일치시켰다.

검증 범위와 화면은 [150 검수](../reviews/review150/검수.md)에 기록한다. 이번 수정에서 1~7일 전체를 새로 완주하지 않았다.
