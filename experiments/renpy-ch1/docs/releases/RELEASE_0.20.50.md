# 0.20.50 — 군중 사전 배치와 부엉이 생존 장면

공개 전 기록 읽을 자리·수레 통로와 실제 감독자를 배치하고 공개 순간 상태로 군중 결과를 정한다. 기존 7일 대승리, 인계 먼저, 감독자 다른 업무, 옛 저장 메뉴를 유지한다.

살아 있는 부엉이가 8일 기록의 빈자리와 종이 순서를 확인하도록 돕는 장면을 추가했다. 새 정답·증거는 주지 않는다. 걸쇠 새 예방은 정문 수리만으로 비밀통로를 막지 못하므로 별도 구체안 응답을 기다린다.
