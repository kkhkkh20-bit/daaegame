# 0.20.147 — 자유 방문과 2일차 주민 생활

2026-11-10. 1부 마을 생활 기획의 첫 구현이다. 2~7일의 안전한 조사 대기에서 여관·식당·광장·입구·우체국·수리점·진료소·학교·공동 창고 등 공개 공간 열한 곳을 처음부터 방문할 수 있다. 첫날 안내와 긴급 사건·회의·구금의 동선 제한은 유지한다. 방문했다고 미래 자료나 증언을 얻지는 않는다.

2일에는 우체국의 부엉이 할아버지·세련 엽서 대화와 여관의 토리·여니 소매 대화를 추가했다. 직접 참여·옆에서 보기·거절·미방문·소개만 듣고 중단을 구분하고, 저녁 이후 실제로 다시 만났을 때 다른 대화로 이어진다. 다람은 실제 동행할 때만 참여한다. 소매에서 손을 빼는 도움은 기존 수선 의뢰의 실제 작업 완료와 별개다.

아침 등 조사의 결과와 자료를 받은 뒤에는 오전을 더 둘러볼 수 있다. ‘점심 먹으러 가기’를 선택하고 확인하면 기존 오후 일정으로 이어진다. 네로에게 가는 이동과 피코를 식당에 데려가는 이동은 오후 마감을 설명하고 확인받는다. 취소는 현재 상태를 유지한다. 피코 인계의 마감이 실제 치환 대사에서 빠져 있던 부분을 보충하고, 공개 식당 이용과 새 취침자의 인계를 구분했다.

미소유 진료 기록·물자 장부는 중립적인 외관만 설명한다. 2일 학교를 미리 피난처로 단정하는 관찰도 고쳤다. 본편에서 특정 장소에 있어야 할 주민은 평상 시간표의 다른 장소에 중복 표시하지 않는다. 2일 밤 야간 배식 중인 나비는 일반 식당 주민으로 세우지 않는다.

새 그림·음악 없이 기존 배경·인물·공통 UI를 재사용했다. 3~7일 신규 방문 사건 열 개와 반복 식사·가족 휴식의 확장은 후속 작업이며 이번 판에 모두 구현됐다고 보고하지 않는다.
