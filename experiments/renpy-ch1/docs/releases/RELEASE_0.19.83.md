# 0.19.83 — 독백 하늘색·나레이션 회색

기존 화자/독백 역할 구분을 그대로 사용하면서 사용자가 요청한 색으로 공통 토큰만 조정한다.

- 독백: 연한 하늘색 #A9DDFF. 기존 괄호 표시는 유지한다.
- 나레이션·관찰문: 중립 회색 #CED1D6. 이전 녹색 기운을 뺀다.
- 대화: 기존 크림색 #F4E7C4 유지. 이름·강조·명시적 자료 이름의 기존 처리는 유지한다.
- 밝은 종이 위에서는 가독성을 위해 독백의 기존 짙은 푸른색과 중립 짙은 회색 #51565B를 사용한다.

아빠의 모든 대사를 독백으로 재분류하지 않는다. 명시적인 thought 표시와 화자 없음 상태를 사용하는 기존 방식이다. 원문 대사·조건·선택 효과·엔진·UI 배치·폰트는 바꾸지 않는다.

## 확인

- 기존 typography_roles 단위8건 통과: 역할 선택, 괄호, 기록/종이 역할 및 대비4.5 이상.
- 기존 네이티브 typography_roles 화면 검사 통과. 최신 시작 컷에서 임의 고정 시간 대신 대화 화면을 기다리도록 테스트 진입만 보정했다.
