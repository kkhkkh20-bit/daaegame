# 0.19.70 — 기존 조사 게임 복구 · 입구 대사 업데이트

기본 시작을 원래 `room13_start`로 복원했다. 별도 MS14 메뉴 진행기를 기본 게임에서 사용하지 않는다. 원래 `r13_scene → r13_lines → r13_entry/r13_hub → r13_entry_dispatch` 경로가 배경음·환경음·캐릭터·현장 사물 클릭·수첩·자료 제시를 담당한다. 신규 스토리 날짜 확대는 중단했다.

기존 마차·입구 호출의 대사와 입구 증거를 전달 원문으로 교체했다. 원래 증거 키를 유지해 `E01`은 초대 편지, `G1`은 가족 방문 신청 원본, `G2`는 겨울철 입장 규칙, `G3`는 초소 처리 명단을 담는다. 기존 단일 자료 제시와 성공/재확인 분기를 사용한다. 새 화면·메뉴·현장 좌표·인물 배치·음악 시스템을 만들지 않았다. 신청 원본만 읽어 정정하지 않도록 기존 성공 조건에 두 보조 자료의 실제 소지를 확인한다.

교체 전 문장에 붙어 있던 표정 큐는 제거하고 원문의 기본 표정을 기존 neutral 자산에 연결했다. 대사 바인딩과 정확한 원문 참조를 갱신했다. 새로운 인물·증거 이미지·컷신을 생성하지 않았다. 별도 진행기 파일은 0.19.69 저장의 참조를 보존하기 위해 남기되 새 시작에서는 실행하지 않는다.

검증: 단위 742개, SDK 직접 lint, 브라우저 자연 시작과 실제 클릭. 브라우저 검증은 음악의 재생 이름뿐 아니라 WebAudio 출력의 0이 아닌 신호를 확인한다. 화면·상태·출력 검증 기록은 `docs/story-ms14/validation/01970-existing-entry/`에 보관한다.

이번 원문 교체 검증 범위는 마차와 입구다. 그 뒤 기존 게임은 원래 시스템과 콘텐츠로 이어진다. 나머지 신규 대본의 업데이트가 끝났다는 의미가 아니다. 0.19.69 별도 진행기에서 저장한 파일은 이전 경로를 유지하므로 복원된 기본 경로 검토는 시작 화면의 ‘처음부터’로 한다.
