# 0.19.9 — 승인된 잉크 마을 지도 적용

마을 이동 지도만 갈색 잉크와 낡은 양피지 원화로 교체했다. 가장자리의 넓은 변색과 옅은 접힘 자국을 넣고, 원화의 여백을 잘라 마을을 약 8% 확대했다. 현장 배경, 숲·산길 지도, 여관의 층별 텍스트 안내, 지역 탭과 이동/복귀 버튼은 유지했다.

마을의 이동 가능한 장소에 기존 게임 글꼴로 이름을 표시한다. 건물과 이름표가 같은 목적지를 선택한다. 선택·마우스오버는 기존 잉크 패널로 나타내고 마을의 노란 다각형 외곽선은 표시하지 않는다. 새 원화에 맞춰 클릭 다각형과 이름표 위치를 다시 작성했다. 장소 목록·개방 조건·비밀 장소·이동 디스패치·시간 처리·스토리 판정은 수정하지 않았다.

다른 채팅의 0.19.8 저장 복구·이야기 검수·놀람 효과음을 병합했고, 이전 0.19.7의 입구 인물 간격·씬/대사 건너뛰기 명칭과 캐릭터 작업은 보존했다.

검수: 전체 dev/check.sh(단위·lint), Ren’Py cartography/shortcuts, 실제 Chromium에서 11개 건물과 11개 이름표 선택·상태 보존·이동 확인. 844×390 터치 반복 입력과 취소, 여관 안내 복귀, 기존 온실/제단 발견 조건과 지하 시설 위치를 확인했다. 명시적 이동 확인으로 실제 우체국 이동을 검증했다. 브라우저 검수는 상태 fixture이며 전체 시나리오 자연 진행·모바일 실기기 검수는 아니다.
