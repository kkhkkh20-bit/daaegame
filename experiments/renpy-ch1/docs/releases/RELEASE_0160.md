# 0.16.0-dev · 2026-10-14

대화/선택 UI, 생활 추리 PoC, 이동/증거 UI 및 읽기 도구를 통합한 개발 공개본.

- 인물은 중앙 고정. 질문은 실제 글줄 높이를 계산해 세로 중앙 정렬. 까로 대화는 새 전신 원본을 확대해 상반신 아래가 끊기지 않게 배치.
- 대화창 전체 폭/작은 하단 문구. 질문/대화 사이 인물 위치와 배율 유지.
- 증거/증언은 배경 위 중앙 창. 아이콘 아래 짧은 이름, 두 줄 배열, 기록 비교/관심 표시/입수 경로 유지. 소유한 자료만 제시.
- 여관 내 이동은 여관 안내도부터. 여관 밖으로를 누르면 마을 지도. 이동 자체에는 시간 비용 없음.
- 백로그: 하단 버튼 또는 H. 실제 대화 기록을 최근 순으로 표시하며 현재 진행/선택을 바꾸지 않음. 열려 있으면 자동 진행 및 타이핑 소리 대기.
- 오토플레이: 하단 자동 버튼. 옵션에서 자동 읽기 속도 설정. 선택/기록/이동/저장 화면에서는 대사를 자동으로 넘기지 않고 질문을 자동 선택하지 않음. 마차에서도 백로그/자동 버튼 사용 가능.
- 새 게임에 첫날 여관 동선과 둘째 날 일거리/숙식비/외상/상점 적용. 기존 저장에 숙식비를 소급 청구하지 않음.
