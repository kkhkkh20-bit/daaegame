# 0.19.57 — 공통 UI와 모바일 조작 정리

- 공통 버튼은 터치 기기 또는 높이600px 미만 창에서 글자 확대 설정과 별개로80px 높이를 사용한다. 마우스 화면은64px, 확대 글자는 기존80px를 유지한다. 지도 이동·복귀도 공통232px 폭과 하단 기준선을 사용한다. 여관 목록과 화면 좌우 이동 영역도 터치 시 넓어진다.
- 새 생각은 기존 생각 버튼의 짧은 표시와 미확인 점으로 알린다. 인물을 덮던 긴 자동 알림 띠를 제거했다.
- 조사 안내는 장소별 처음3초만 표시한다. 이후 장소 이름 옆 ‘주변 조사’가 현재 모드를 알린다. 돋보기 표식은 표시하지 않는다.
- 조사 모드에서 빈 배경을 누르면 짧게 원형 터치 반응만 보인다. 조사 기록·증거·시간을 만들지 않는다. 실제 물건 클릭과 스와이프 경로는 유지한다.
- 자료의 비어 있는 증언·전달 분류는 숨긴다. 터치 환경에서는 분류 버튼과 좌측 기록 메뉴·닫기를 넓히고, 자료를3열/8개씩 페이지로 나눈다. 자료 이름과 본문도 터치 환경에서 크게 표시한다.
- 핵심 확인 내용을 먼저 보여주고 출처·기록 정보는 펼쳐서 읽는다. 자료 소유·제시·보관 자료 제한은 기존 판정을 사용한다.
- 선택한 자료를 제시할 수 있을 때 ‘보여주기’를 밝은 공통 주요 행동 색으로 강조한다. 비활성 상태는 그대로 구분한다.

0.19.56의 최신 이야기·회의 흐름 변경을 병합했다. 전체 이야기 재검수는 아니며 이번 범위의 실제 브라우저 조작과 기존 검사로 검증한다. 결과와 실제 화면은 docs/reviews/ui-polish-20261018/.
