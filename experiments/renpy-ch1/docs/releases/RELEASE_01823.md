# 0.18.23 · 2026-10-15 — 실제 메인 타이틀 화면 구현

소유자가 시안 전달 대신 직접 코딩·푸시를 요청하여 0.18.22 위에 구현했다.

- 눈 덮인 여관 배경을 글자 없는 이미지로 교체했다. 제목 로고는 별도 투명 WebP이며, 모든 메뉴는 실제 Ren'Py 컨트롤이다.
- 왼쪽 메뉴는 이어하기·처음부터·설정으로 간결하게 정리했다. 불러오기는 왼쪽 아래 보조 메뉴로 유지했다. 음악 듣기·그림 수첩 외부 링크와 긴 설명은 메인에서 제거했다.
- 저장이 없으면 처음부터가 기본 선택이다. 호환되는 저장이 있으면 이어하기가 기본 선택이고 기존 호환성 검사/불러오기 동작을 사용한다. 실제 저장 메타데이터의 날짜만 표시하며 예시 날짜·장소를 표시하지 않는다.
- 선택 중인 메뉴 하나에만 반투명 녹색 면, 계단형 낡은 황동 테두리와 마름모를 그린다. 본문은 기존 Galmuri11 Regular이며 로고만 별도 타이틀 아트다.
- 로딩 화면도 같은 배경과 로고를 사용한다. 프리로딩과 PWA 무결성 목록은 기존 빌더에서 갱신한다.
- 본편 대화/추리/분기/생활 규칙은 변경하지 않았다. 제목 변경은 논의 중이므로 이번 판에는 기존 이름을 유지한다.
