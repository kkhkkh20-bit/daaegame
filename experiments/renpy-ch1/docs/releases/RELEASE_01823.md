# 0.18.23 · 2026-10-15 — 이름·대사·생각·자료 표기와 클래식 창 프레임

소유자 제공 `typography-handoff.zip`(TYPOGRAPHY_HANDOFF.md, typography-tokens.json)과 `ui-concept_1.zip`(08차 클래식 스킨)을 적용했다. 이야기, 증거 판정, 발견 조건, 시간·경제·분기는 바꾸지 않았다. 대사는 다시 쓰지 않았다.

## 1. 의미 역할과 색

- 토큰 원본을 `game/assets/room13-typography-tokens.json`으로 그대로 옮겼다.
- 연결 코드는 `systems/room13_typography_roles.rpy`에 있다.
- 대사창 글자색은 사람이 아니라 줄의 역할로 정한다.

| 역할 | 녹색 창 위 | 양피지 위 |
|---|---|---|
| 일반 대사 | `#F4E7C4` | `#39432C` |
| 아빠의 생각 | `#9DC9FF` | `#31576F` |
| 상황 묘사(화자 없음) | `#D1D6C8` | `#555943` |
| 명칭(「…」) | `#E5C58A` | `#6C512A` |
| 보조 정보 / 물어본 질문 | `#C2C9B5` | `#625738` |

- **화자 이름표**
  - 모든 인물이 같은 색(`#F6DFAC`)과 같은 위치(대사창 왼쪽 위)를 쓴다.
  - 이름표 바탕은 작은 HUD 프레임이다.
- **아빠의 생각**
  - 문장 전체가 파란색이다.
  - 괄호는 표시할 때 정확히 한 번만 붙는다. 원문에 괄호가 이미 있으면 다시 감싸지 않는다.
  - 두 줄로 나뉜 생각은 쪽마다 한 쌍씩 붙는다.
  - 생각 안의 「명칭」은 금색으로 섞지 않는다.
- **명칭**
  - 작가가 「…」로 표시한 16자 이하의 이름 한 구절만 강조색을 받는다.
  - 엄마 편지처럼 「」로 감싼 긴 인용은 본문색 그대로다.
- **옛 자동 강조 폐지**
  - 이전에는 등장인물·장소·자료 이름을 정규식으로 찾아 색과 굵게(`{b}`)를 자동으로 입혔다.
  - 지시서 금지 항목이라 이 기능을 없앴다.
  - 그래서 대사 속 인물·장소 이름은 이제 일반 본문색이다.
- 기존 공용 색 토큰(`R13_UI_COLORS`)의 본문·보조·명칭·생각·종이 글자색도 위 역할 값으로 맞췄다. 이 토큰을 쓰는 화면은 함께 바뀐다.

## 2. 굵기

- Galmuri11은 Regular 한 가지뿐이다. room13 화면의 가짜 굵게를 모두 없앴다.
  - 회의 좌석 발언 표시의 `bold True`
  - 번호 배지의 `bold=True`
  - 대사 이름표 스타일의 `bold`
- 단위 테스트가 room13 소스에 `{b}`나 `bold True`가 다시 들어오는지 검사한다.

## 3. 기록·백로그·질문

- **백로그**(녹색 바탕): 생각은 파랑, 상황 묘사는 회색, 대사는 크림색이다.
- **기록 → 대화 탭**(양피지): 같은 역할을 양피지용 색으로 보여 준다.
- **물어본 질문**: 기존 ✓와 취소선은 그대로 두고, 글자색을 보조색(`#C2C9B5`)으로 바꿨다. 다시 읽을 수 있다.
- 타이핑 효과음은 원래부터 화면에 실제로 그려진 글자 수로 센다. 색 태그는 세지 않는다. 바꾸지 않았다.

## 4. 창 프레임 위계 (ui-concept 08차)

- 프레임 4종을 `assets/room13-ui-frame-*.webp`로 옮겼다. 48×48, 9분할 12px, 무손실이다. 원본 PNG는 웹판에서 나중에 받는 파일로 분류되므로 WebP로 바꿨다.

| 쓰는 곳 | 프레임 | 안쪽 불투명도 |
|---|---|---|
| 대사창(보통) | dialogue | 88% |
| 대사창(진하게) | aged-window | 96% |
| 대사창(연하게), 날짜·장소 표시, 이름표 | hud | 86% |
| 기록 화면 전체 | aged-paper | 100% |

- 프레임 전체의 투명도를 낮추지 않는다. 금박과 글자는 흐려지지 않는다.
- 버튼은 기존 패널을 그대로 쓴다. 모든 상자에 같은 금박을 반복하지 않기 위해서다.
- 옵션의 '대사창 진하기' 미리보기도 실제 대사창 프레임으로 보인다.

## 5. 적용하지 않은 것 (남은 범위)

ui-concept의 아래 배치 변경은 이번에 하지 않았다. 각각 화면 구조를 바꾸는 작업이라 따로 진행한다.

- 질문 목록을 화면 중앙 38% 폭으로 옮기기.
- 대화와 질문 화면에서 인물 좌표 통일.
- 제시한 자료 카드를 대화 중 유지하는 기능(06차).
- 기록 탭을 증거/증언/인물 3개로 재구성.
