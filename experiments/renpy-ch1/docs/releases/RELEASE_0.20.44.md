# 0.20.44 — 폰트 규격과 회의 자료 영역 정리

- 역할별 공통 폰트 규격 R13_UI_TYPE을 추가하고 버튼·옵션 항목명·회의 제목에 연결했다. 기존 제공 Bold 폰트를 사용하며 납품되지 않은 800 글꼴을 임의 대체하지 않았다.
- 모바일 옵션 설명 폭과 문구를 줄여 조작부와 겹치는 폭을 제거했다.
- 회의 자료 목록을 공통 테두리 카드 안에 배치하고 빈 상태 안내를 넣었다. 제출은 기존 빨강 강조, 나머지는 크림을 유지한다.
- 공통 종이·라벨·수첩을 밝은 아이보리로 조정하고 기록/회의 종이에 미세한 결을 넣었다. 클릭 영역과 회의 판정은 그대로다.
- 상위 0.20.43의 숨겨진 에피소드 변경을 보존했다.

실제 게임에서 옵션·회의·기록 캡처 통과. 전체 자연 플레이와 모든 저장 상태는 이번 범위에 포함하지 않는다.
