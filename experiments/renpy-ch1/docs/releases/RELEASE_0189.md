# 0.18.9-dev · 2026-10-14 — 1주차에 한 일이 2주차 준비를 바꾼다 (소유자 지시)

코드는 `game/systems/room13_carryover.rpy`다. 2주차 첫 이동 때 한 번 정산한다(`w1_links_done`). 지난주에 한 일이 이유와 함께 대사로 나온다.

## 도움이 되는 일 → 2주차 약속이 바로 생김

| 1주차에 한 일 | 2주차에서 |
|---|---|
| 보리 누명을 벗기거나 도움(배급표·학교 장작) | 보리가 수레를 끈다 → 환자 운반 약속 |
| 백 부인 창고 공개, 은호 저울 공개, 배급소 저울 기록(H6) | 공동 장부로 식량·장작 → 식량 약속 |
| 곰 선생님 신뢰, 표 없는 아이들 끼니 해결 | 교실이 이미 비어 있다 → 쉴 곳 약속 |
| 톡 누명 벗김·증언 | 톡과 우박이 장치 교대 → 지킬 사람 약속 |
| 무쇠 할아버지에게 약을 줌 | 서리 검사원의 회복 기록 → F1(돌아오는 사람) 근거로 가는 관찰 |
| 식은 돌·등을 알아 둠(W4 또는 W6) | 측정 계획 → F2 측정을 엄마를 만나기 전에도 시작할 수 있다 |

## 해가 되는 일 → 거절과 우회로

| 1주차에 한 일 | 거절 | 우회로 |
|---|---|---|
| 배급대 앞에서 보리를 외면하거나 장작 일로 곰 선생님을 부름 | 보리가 수레를 거절 | 까로의 마차 썰매를 10냥에 빌린다 |
| 은호에게 입막음 반값을 받음 | 은호가 대피소 몫을 거절 | 백 부인 비축 장부(H1)로 백 부인에게 받는다, 또는 은호에게 15냥 |
| 나쁜 소문 2개 이상(좋은 소문 없음) | 곰 선생님이 교실을 망설임 | 보증해 줄 사람을 데려온다: 초롱·바둑이·뿔이 촌장 신뢰 또는 나비의 증언. 아무도 없으면 쉴 곳을 얻지 못한다 |

- 원래의 2주차 대화(곰 선생님·은호·보리)는 이 거절이 있으면 닫힌다.
- 이미 약속을 얻었으면 원래 대화도 닫힌다.
