# 0.18.20-dev · 2026-10-15 — 조사 경험 보강 (소유자 최종 제작 지시)

본편·증언·재판·퍼즐 정답은 그대로다. 새 증거·새 확대 화면·이전 회차 해금은 없다.

## 1. 자료 획득 시점: 반응을 읽은 뒤 (`systems/room13_grant_timing.rpy`, `room13.rpy`)
- 자료를 제시하면 기존 반응 대화가 먼저 나오고, 대화가 끝난 뒤 새 기록이 들어오며 획득 알림이 뜬다.
- 방식
  - 제시 반응을 계산하는 동안에만 `r13_grant`가 새 기록을 저장 상태의 대기 목록(`pending_grants`)에 둔다.
  - 대사가 끝나면 `r13_flush_grants()`가 지급한다.
- 적용 범위: 제시 반응에서 생기는 모든 새 기록. 엄마 초상(J07·J08), 도토(J10), 서리의 대조(H10·H11)를 포함한다.
- 유지한 것
  - NPC가 자료를 봤다는 기록, 깃발, 후속 주제는 기존 시점(반응 계산 때) 그대로다.
  - 대사·지급 자료·조건·시간 비용도 그대로다.
- 대화 중 저장·불러오기: 대기 목록이 저장 상태 안에 있어 누락되지 않는다. 지급 함수는 이미 가진 기록을 건너뛰므로 중복되지 않는다. 빠르게 넘겨도 대사가 끝나면 지급된다.
- 같은 자료를 다시 보여 줘도 획득 연출은 다시 나오지 않는다(새 화면 테스트 `grant_after_reaction`).

## 2. 연필·자는 써도 남는다 (`room13_inspection.rpy`)
- 종이: 운반표 위에 놓인 상태가 된다(기존).
- 연필: 문지른 뒤에도 아이템에 남는다.
- 자: 걸림쇠를 조작한 뒤에도 남는다.
- 돋보기: 기존대로 재사용한다.
- 이미 연 칸에 다시 자를 쓰면 "이미 열려 있다." 탁본을 다시 문지르면 "탁본은 이미 완성됐다."

## 3. 책상 퍼즐: 방법을 아는 것과 발견하는 것 분리
- 탁본 완성 여부를 검사하던 잠금을 없앴다. 열리는 조건은 실제 조작이다.
- 기존 화면의 두 대상을 그대로 쓴다. 칸막이 아래쪽 홈(`divider`)과 도구칸 판(`compartment`)이다.
  - 자를 들고 아래쪽 홈을 누른다 → "자 끝으로 아래쪽 홈을 눌렀다. 안쪽에서 걸림쇠가 조금 내려갔다."
  - 바로 이어서 판을 누른다(오른쪽으로 민다) → 열린다.
  - 다른 곳을 누르면 홈에서 손을 뗀 것이 된다.
- 잘못된 조작에는 짧은 물리 반응만 있다. 도구는 잃지 않는다.
  - 판 틈에 자를 넣으면 "판은 걸린 채 움직이지 않는다."
  - 홈을 누르지 않고 판을 누르면 "닫혀 있다. 손잡이 대신 아래쪽에 얕은 홈이 있다."
- 탁본은 방법을 발견하는 길로 남는다(그림: 아래쪽 홈을 누른 채 오른쪽으로 민다).
- 방법을 아는 플레이어는 탁본 없이 바로 열 수 있다. "이미 방법을 안다" 같은 선택지나 이전 회차 검사는 없다.
- 단순히 자를 아무 데나 쓰면 열리는 구조는 아니다.

## 5. 조사 화면 상태와 복귀 (확인 결과)
- 놓인 종이, 완성된 탁본 그림, 열린 칸, 아직 챙기지 않은 도구 표시는 원래부터 저장 상태를 따라 그려진다. 고칠 것이 없었다.
- 메모를 읽고 돌아오면 책상 화면으로 돌아오고 선택한 도구는 해제된다(메모가 책상에 있으므로 유지). 화면과 사용 중 표시는 함께 초기화돼 서로 어긋나지 않는다.
- 필기함 안에는 기록 버튼이 없어, 기록을 열었다 닫아 조사 화면이 초기화되는 경로가 없다.
- 획득 알림이 복귀 버튼을 가리는지는 브라우저에서 아직 확인하지 않았다(아래 검증 참고).
