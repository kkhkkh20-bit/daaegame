# 0.19.94 — 회의 기회 5번, 결정타 연출, 로직 검토 반영

## 회의 기회 5번
소유자 지시(2026-10-22): "에너지 총량 5개는 주자. 추리 해나가게". 회의마다 기회가 5번이다(`R13_NW_TRIES=5`). 쟁점이 여럿인 회의(3일, 7일, 11일, 12일, 13일, 14일)도 회의 전체로 센다("회의 중 기회"). 위쪽 쟁점 띠에 "남은 기회 n / 5".

## 결정타 연출(기존 회의 장면 단계)
대사판 줄의 `beat`로 기존 회의 무대의 장면 단계를 붙였다: 잠깐만요!(끼어들기, 기존 짧은 문구 컷인), 근거 제시, 동요(무대 어둡게), 상대의 반문, 마지막 항변(더 어둡고 크게). 3일 실룩, 7일 누비, 10일 할머니, 12일 선생님, 13일 바둑이·촌장·너울, 14일 촌장.

## 로직 검토(Codex 검토 → 수정 → Codex 재검토)
- 수레에 실려 떠난 사람(`departed:`)은 도착·장면 인물에서 빠진다(떠난 나비가 학교에 다시 나오던 문제). 14일 결말의 나비 줄도 나눴다.
- 13일 담요 회의 '부분'으로 가는 모든 길이 한 곳(`partial_listed13`)을 지난다. 명단으로 실린 사람들은 다른 탑승자와 함께 14일에 인계되고, 다람은 바로 내려온다.
- 10일 13호실 회의에서 지거나 부분이면 다람이 학교로 옮겨질 뿐, 할머니 자백·책임·석방 근거는 기록하지 않는다(이기면 그대로).
- 1일 입구: 신청서만 낸 반쪽 답도 기회를 쓴다. 입구 회의 결과(승/패)를 기록한다.
- 12일: 장작이 이미 왔으면 "장작이 안 왔다" 대신 도착한 뒤의 줄.
