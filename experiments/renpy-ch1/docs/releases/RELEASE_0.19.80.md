# 0.19.80 — 정지된 마차 풍경 컷

사용자가 확인한 저채도 풍경 시안을 새 게임의 외부 마차 컷에 적용한다. 마차는 눈길 속에 작고 어둡게 놓이고, 작은 산골 마을은 먼 계곡 건너에 있다. 마차·말·바퀴·카메라를 통째로 이동하거나 확대/축소하는 연출을 제거한다.

- 한 장의 완성된 풍경을1280×720 전체 화면에3.5초 표시한 뒤 기존 내부 대화로 자동 전환한다.
- 기존 공통 건너뛰기 버튼과 일반 클릭으로 외부 컷만 닫을 수 있다.
- travel BGM과 기존 주행음 채널을 이어 쓴다.0.19.79의 행동→아빠 농담→엄마 몫 대화 및 내부의 한 번 덜컹임은 유지한다.
- 원래 두 겹의 이동용 그림은 첫 다운로드 목록에서 빼고 승인된 풍경 한 장만 넣는다. 예전 자산 자체는 보존한다. 게임 자료 초기 다운로드 약36.59MB→36.26MB; 엔진 용량과 초기 실행 시간은 별도다.

## 확인

- 단위/lint 묶음 통과.
- 네이티브 기존 coach_exterior 검사만 이번 정지 컷 길이에 맞춰 확인: 자동 전환, BGM·주행음 채널 및 pulse 꺼짐7개 확인 통과.
- 공식 dev/build_web.py 빌드 통과, core8MB 분할 유지.
- 최종 웹 빌드0.19.80 실제 클릭 검사 통과: [정지 풍경](../reviews/carriage80/landscape.png) → 외부 컷 건너뛰기 → [844×390 내부 첫 행동문](../reviews/carriage80/inside-mobile.png). 내부 건너뛰기 확인창을 잘못 연 것이 아닌 것도 화면 상태로 확인했다.

첫3일 분기와 Ren'Py 기본 저장/로드 검사는 반복하지 않는다. 전용 과자·소매 잡기 동작 그림, 이후 날짜·엔딩은 기존 미완료 범위를 유지한다.
