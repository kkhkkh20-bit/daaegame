# 0.18.51 — 관심 자료 기능 제거

- 기록과 보여주기 화면에서 관심 표시/해제, 관심 자료만 필터, 카드의 별 표시를 제거했다.
- 자료 상세에서 비워진 관심 버튼 공간만큼 읽기 영역을 늘렸다.
- 예전 저장의 관심 자료 필터 값은 무시한다. 기존 관심 목록 때문에 자료가 숨거나 제시할 수 없게 되지 않는다.
- 이전에 저장된 화면 동작이 불러오기 오류를 내지 않도록 폐지된 관심 표시 동작 이름은 아무 일도 하지 않는 호환 함수로 남겼다.
- 새로 읽은 자료 표시, 획득순 정렬, 페이지 이동, 기록 비교와 현재 분류 명칭은 유지한다. 비교 기능 제거와 ‘증거/아이템’ 명칭 변경은 별도 기획 논의 중이며 이번 판에는 적용하지 않았다.

확인: 단위 검사 144개, Ren’Py compile/lint. 브라우저에서 실제 새 게임의 기록·제시 화면에 관심 관련 조작이 없고 자료가 표시되는 것을 확인했다. 예전 관심 전용 필터가 소유 자료를 숨기지 않는 호환 검사도 포함했다.
