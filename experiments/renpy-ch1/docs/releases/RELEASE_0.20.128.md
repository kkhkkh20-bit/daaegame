# 0.20.128 — 대화 인물 여섯 명의 도트 화풍 교정

소유자가 말한 ‘대화창 차이’는 대화 중 등장하는 인물 원화의 차이였다. 창·이름 리본·버튼·글꼴은 바꾸지 않고, 실제 1부 대화에서 선택되는 원화와 별도 자세를 조사했다.

피코·콩이·까로·세련·보리·우박의 일반 여섯 표정, 세련의 앉아서 읽기·듣기, 우박의 특수 불안·분노를 기존 다람·돌목의 도트 표현으로 교정했다. 작은 계단형 윤곽과 면 음영을 사용하며, 표정별 손동작·연령·의상·종·기존 표시 키를 보존한다. 피코는 성인 동물 비례와 기존 화가 도구인 붓·판자를 적용했다. 판자의 뒷면만 보여 새 초상이나 단서는 추가하지 않는다.

세련은 오후 질문에서 별도의 예전 일러스트로 바뀌던 경로도 함께 교체한다. 읽는 자세의 아래 시선과 듣는 자세의 정면 시선을 구분한다. 우박의 특정 대사에서 회중시계·초록책으로 바뀌던 소품은 본편 대사의 온도 집게·측정 종이와 일치시킨다. ‘집게를 뒤로 당기는’ 기존 행동도 유지한다.

새 원본·해시·재가져오기 도구를 보존하고 실행 파일은 품질95 WebP로 연결한다. 기존 원화는 예전 저장 호환을 위해 남긴다. 대사·판정·자료·생사·진상·결말·1부 경계는 변경하지 않는다. 이번 교정은 여섯 명과 별도 자세 네 장이며 모든 주민의 작화 통일 완료를 뜻하지 않는다.
