## 1. 대화 전신 표정 (43명 × 6표정)

- **원본:** `daram-fullbody-expressions-43-v3` 전체본 258장.
  - 패키지 manifest SHA-256을 가져올 때 모두 대조했다.
  - 도구: `dev/import_fullbody_expressions.py`
- **게임용 사본:** 절반 크기(512×768 기준) WebP q95, 알파 무손실.
  - 대화 그림은 3px 픽셀 격자로 다시 샘플링되므로 화면에서 차이가 거의 없다.
  - 첫 로딩이 111MB에서 85MB로 줄었다.
  - 원본 크기가 필요하면 `--scale 1`로 다시 만든다.
- **guard 보정:** anxious·joy 표정에서 꼬리와 외투가 만나는 부분에 배경이 비치는 반투명 구멍이 있었다.
  - 그 상자 영역만 guard/neutral의 불투명 픽셀로 채웠다(anxious 10,020px, joy 1,488px).
  - 얼굴과 그 밖의 픽셀은 바꾸지 않았다.
- **연결:** `room13_fullbody_dialogue.rpy`
  - 캐릭터마다 6표정을 모두 담는 고정 crop과 고정 scale을 쓴다. 표정이 바뀌어도 위치와 크기가 변하지 않는다(546장 캡처에서 bounds 동일).
  - bami와 doto는 큰 글씨 모드에서 얼굴이 대사창에 닿아 0.88, 0.92로 줄였다.
- **감정 키**
  - 기존 키는 neutral→neutral, thinking→neutral, distressed→anxious, expressive→joy, panic→surprise, breakdown→anxious로 잇는다.
  - 대사별 지정은 `room13-fullbody-line-emotions.json`에 있다. 54줄이며, 대사 문구가 같을 때만 적용한다.
  - 54줄 배분: 불안 40, 분노 6, 놀람 4, 당황 3, 기쁨 1.
  - 대사 패킷에 새 키를 직접 적어도 된다.
- **바꾸지 않은 것**
  - 기존 상반신 초상(`room13-portraits.json`), 프로필 아바타, 월드 스프라이트.
  - 대기소 창의 다람이 그림은 기존 상반신을 그대로 쓴다.
  - 입 모양 자동 움직임은 넣지 않았다.
- **불러오기:** 예전 저장을 불러오면 그 순간의 대화 상대만 같은 표정과 자세의 전신 그림으로 다시 그린다(`after_load`).

- 이전 커밋을 병합하지 않았다. PR의 소스 패치(`reports/worldmap-v5-20261014/source.patch`)에서 지도 부분만 최신 코드에 옮겼다.
  - 대상: `room13_navigation.rpy` 변경, `room13_worldmap_v5.rpy`, `room13-worldmap-v5.json`, 테스트.
  - 원본 그림과 SVG 레이어는 `design/maps/20261014/`에 있다.
- **목적지:** 실제 장소 8곳(입구·광장·여관·우체국·수리점·진료실·학교·공동 창고)만 이름, 다각형 클릭, 강조 표시를 가진다.
  - 신당·옛 채석장·주택·농장 등 14곳은 그림 일부일 뿐이고 클릭이나 이름이 없다.
  - 교회는 그림에 없다.

  - 목적지 8곳의 잘라낸 이미지와 외곽선을 `dev/make_worldmap_layers.py`로 미리 만든다. 이동 반응은 약 1.2초가 되었다.
  - 다각형은 손으로 지정한 외곽선이며, 건물을 픽셀 단위로 정확히 분리한 PNG 레이어가 아니다.
- **추가 규칙:** 숨은 장소(통로·폐온실·제단)는 발견 전에는 이름, 툴팁, 선택 대상으로 드러나지 않는다(`r13_map_discovered`).

## 3. 여관 로비·복도 이동 칩 (inn-navigation-v4)

- **배경:** 바꾸지 않았다(로비 파노라마, 복도 before/after).
- **좌표:** 칩 좌표는 배경과 같은 변환을 쓴다.
  - 로비: 2048×768 → 1920×720 월드.
  - 복도: 1672×941 → 1280×720.
- **목적지:** `r13_local_connections()`에서만 가져온다. 접근 조건, 시간 비용(없음), 처리 경로(`Return(("travel",key))`)는 기존 버튼과 같다.
  - 바깥으로는 기존 `outside` 처리를 그대로 쓴다(마을 지도가 열린다).
  - 임시 객실 칩은 기존 연결과 같은 조건, 즉 사건 뒤 13호실을 쓸 수 없게 된 때에만 나타난다.
  - 비밀 통로는 나오지 않는다.
- **승인 시안과 다른 배치:** 게임 화면에 이미 있는 HUD와 겹치지 않도록 바꿨다.
  - 장면 이름은 왼쪽 위 기존 상태판이 대신한다.
  - 안내도 버튼은 '지도 · 이동' 왼쪽에 둔다.
  - '2층으로' 칩은 아래쪽 가운데 도구줄 바로 위로 올렸다.

## 4. 여관 안내도

- 소유자의 최종 지시(2026-10-15)에 따라 `inn-guide-v4-base.png` 위에 `guide-labels.json` 좌표로 실제 UI 글자를 올린다.
- **라벨 표시 조건**
  - 현재 위치에는 ● 표시를 붙인다.
  - 지금 바로 갈 수 있는 곳만 눌러서 이동할 수 있고, 조건은 장면의 칩과 같다.
  - 잠긴 곳에는 '· 잠김'을 붙인다.
  - 임시 객실은 존재하게 된 뒤에만 표시한다.
  - 통로는 표시하지 않는다.
- 닫기 버튼과 Escape로 닫힌다. 지도 화면의 기존 '여관 안내도' 탭은 그대로다.
