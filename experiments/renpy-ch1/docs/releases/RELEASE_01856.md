# 0.18.56 — 원탁 공방, 화자 전환, 대사 중 제시와 공개 투표

## 장면과 UI

- 7일째는 눈 내린 여관의 나무 원탁, 14일째는 실제 제단·배관이 보이는 석판 둘레에 서서 대결한다. 두 전용 배경만 추가했다.
- 도표와 얼굴 카드 대신 기존 도트 인물을 공간에 배치했다. 전체 구도는 논점 선택·발언 선택·의견 공개에서 쓴다. 대화는 중앙 화자와 좌우 이웃만 보이는 구도로 전환한다.
- 좌석 순서는 고정이며 화자마다 이웃도 그 순서대로 보인다. 새 화자에게 0.24초 좌우 전환을 적용하고, 같은 화자나 아빠의 답변에서는 반복하지 않는다. 아빠는 그리지 않는다. 기존 인물 전환 효과 설정을 끄면 이동을 멈춘다.
- 말풍선은 사용하지 않는다. 하단 대화창과 제목·자료·선택지에 기존 양피지와 갈색 UI를 쓴다. 종이 위 대사·생각·고유 자료 표기는 읽을 수 있는 기존 종이 색상 역할을 따른다.
- 하단은 되묻기 / 보여주기 / 다음 발언 / 결론. 발언 기록은 우측 상단에서 펼쳐 재선택한다. 중단은 확인 후 처리한다. 제단의 대피 준비와 남은 사건·탈출 선택도 같은 장면 안에 정리했다. 선택 불가 사유는 남긴다.

## 플레이와 데이터

- 발언 도중에도 소유한 증거·증언을 제시할 수 있다. 같은 정본 판정 함수를 쓰고, 제시를 끝내면 원래 대화의 인덱스·페이지·읽음 ID·화자 상태를 복원한다. 중첩 제시는 막는다. 숨은 다음 주장을 직접 도입하는 대사는 원문과 정확히 일치할 때만 그 주장을 대상으로 삼는다.
- 기존 8개 논점의 진실, 증거, 증언 동의, 재반론 선택지, 실제 인력 준비, 거짓 증언·집행 관문, 구출·엔딩 판정은 유지한다. 준비형 발언에도 자료를 보여줄 수 있지만 실제 준비를 대체하지 않는다.
- 아빠가 고른 결론 뒤 주민들의 표를 장면에 공개한다. `meeting_votes[claim]`에는 선택한 결론과 당시 실제 입증·주민 입장만 저장한다. 과반수로 사건의 사실이나 기존 엔딩 조건을 덮어쓰는 새 규칙은 넣지 않았다. 반복 선택도 표·보상을 중복 생성하지 않는다.
- 기존 회의 저장에서 돌아올 수 있도록 원래 루프·호출 복귀 지점을 유지하고 장면 상태를 다시 설정한다. 새 게임과 예전 저장에 의견 기록이 없어도 동작한다.
