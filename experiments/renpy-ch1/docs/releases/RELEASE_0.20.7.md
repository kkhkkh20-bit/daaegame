# Room13 0.20.7

소유자 리뷰(첫날 플레이, 0.20.4 웹판 재현), Codex 검수 5(주민 반응·증거 화면·저장 복구), 1일 연출 제안서, 전체 플레이 점검을 반영했다.

## 진행이 막히던 문제
- 대조 화면에서 「자료 다시 보기」(옛 「다른 주장부터」)로 연 자료창의 X를 누르면 배경만 남고 멈추던 문제를 고쳤다. 불러서 연 자료창은 닫으면 항상 돌아온다.
- 「저녁 할 일」 버튼이 새 이야기에서는 아무 동작도 하지 않아 감췄다.
- 복귀 지점을 잃은 새 이야기 저장이 새 게임으로 초기화되던 복구 경로를 고쳤다. 그날 아침 저장이 이 진행과 맞으면 그 아침에서 다시 시작한다. 없으면 저장 파일은 그대로 두고 메인 화면으로 돌아간다.
- 예전 저장을 불러와 다른 선택을 한 뒤 「아침부터」를 누르면 이전 선택이 되살아나던 문제를 고쳤다. 아침 저장마다 진행 표식을 남긴다.

## 증거·추리
- 작성한 증거 요약 80여 개가 엔진 자료형 검사에서 모두 빠져 원문 앞부분이 보이던 문제를 고쳤다. 이제 작성된 관찰 사실이 나온다.
- 큰 글씨 나란히 보기에서 설명이 버튼에 가리던 문제를 고쳤다. 그림 크기를 남은 높이에 맞춘다.
- 회의 대조 화면에 남은 기회를 표시한다. 틀린 뒤에도 정답 조합에 들어가는 자료는 남겨 두고, 그때 "맞는 근거는 남겨 두었다"고 알린다. 기회와 정답 조건은 그대로다.
- 근거를 고르는 자료창의 버튼은 「근거에 추가」, 안내는 "근거로 낼 자료"로 바꿨다. 14일 기록 꺼내기는 「이 기록을 꺼낸다」다.
- 3일 첫 쟁점 제목을 "톡이 고친 뒤에 등을 본 기록을 낸다"로 바꿨다. 쟁점("등을 연 사람은 톡 하나")과 맞춘 것이다.

## 대화 흐름
- 질문·자료 보여주기·후속 질문 뒤에는 같은 사람의 질문 목록으로 돌아온다. 「돌아가기」를 누르면 대화에서 나간다. 할 말이 남지 않았거나 그 사람이 자리를 떴으면 바로 현장으로 돌아온다.
- 날짜마다 다른 주민 반응을 반응 묶음별로 읽음 처리한다. 6일 반응을 봤다고 7일의 다른 반응이 막히지 않는다.
- 관계도는 진료 확인 기록이 생긴 뒤에만 도담의 사망을 표시한다.
- 12일 준비 안내는 자리·옮길 사람 중 실제로 남은 것만 말한다.

## 장면·대사
- 1일
  - 초소에서 아빠가 아이의 자책에 먼저 답한다("아니야. 너 때문에 그런 거 아니야.").
  - 서류 대사의 "총 2명" 같은 숫자와 단위가 쪽 사이에서 떨어지지 않는다.
  - 마차에서 편지 마지막 줄을 다시 보면 다람이 "아빠, 또 ‘기다릴게’ 읽었지?"라고 한다.
  - 두 편지를 비교하는 사이 창밖이 어두워지는 지문을 넣었다.
  - "가자, 아빠." 뒤에 「할머니에게 초롱의 행방을 묻는다」(바로 이동)와 「방을 더 둘러본다」를 고를 수 있다.
  - 밤 침대 지문에서 설명 문장을 덜었다.
  - 취침 전 「다람의 이불을 여민다」 행동을 넣었다.
  - 마지막 노크는 "발소리가 멈췄다 → 종업원이었다 → 문손잡이를 놓지 못했다" 세 줄로 나눴다.
- 2일: 포대 옮기기·마른 천 빌리기 뒤에 결과 지문을 넣었다.
- 3일: 창고에 이미 있는 톡에게 바로 각인 확인을 부탁한다. 불필요한 수리점 왕복을 없앴다.
- 7일: 누비 아이 셋을 넘기는 장면에 지문을 넣었다.
