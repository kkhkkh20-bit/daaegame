# 0.17.11-dev · 2026-10-14

같은 날 main에 올라온 0.17.8~0.17.10-dev(가로 배경 5곳, 학습 부담 줄이기, 지도·이동 터치 영역, `RELEASE_0178.md`·`RELEASE_01710.md`)를 3-way로 합친 판이다. 그 변경은 모두 유지했다.

## 대화 질문 화면 (소유자 지시, 0.15 레퍼런스 배치)
- 얼굴을 마주한 질문 화면을 0.15의 배치로 되돌렸다. 인물이 왼쪽에 크게 서고, 장면은 어둡게 가라앉는다. 오른쪽에 "누비 아주머니에게 묻기" 같은 제목과 글자만 있는 선택지가 있고, 아래에 '돌아가기'가 있다.
- 선택지에는 질문 문장 대신 **요약**이 나온다(예: "저희가 묵을 방이 있습니까?" → "묵을 방이 있는지 묻는다"). 실제 질문은 고른 뒤 대사로 한다.
  - 요약은 `game/room13_question_summaries.rpy`의 `R13_QUESTION_SUMMARIES`(질문 문장 → 요약, 255개). 표에 없는 문장은 원래 문장을 보여 준다. 웹 재포장기가 공개본에 없던 .json을 새로 넣지 않으므로 .rpy로 두었다.
  - 주제 제목 185개, 날짜별 생활 질문, 첫 접근 문장, 입구·다람이 질문을 포함했다.
- 이미 물은 질문은 흐린 색과 ✓로 표시한다(0.17.2의 체크 표시 유지).
- 질문 화면 아래 도구줄은 '보여주기'와 '기록'만 남겼다. '돌아가기'는 화면의 큰 버튼과 겹쳐서 뺐고, 백로그·자동·옵션은 질문을 고를 때 쓰지 않아 뺐다. 대사 중 선택지의 도구줄은 그대로다.
- 0.17.10의 위쪽 인물 소개 문구("할머니 · 여관 주인", "질문·자료 보여주기 · 시간 소모 없음")는 유지했다.
- 남은 점: 질문이 5개면(할머니 첫날) 마지막 하나는 목록 안에서 스크롤해야 보인다. 휴대폰에서의 터치 크기(줄 높이 76)는 실물 테스트에서 확인이 필요하다.
- 검토했다가 버린 안: 아래쪽 띠, 오른쪽 열의 진한 버튼·반투명 줄, 오른쪽 인물과 왼쪽 종이 막대.
