# 0.20.81

2026-10-28. 역전재판 캡처를 레퍼런스로 한 소유자 지적 반영.

- 강조색: 이름·장소 자동 색칠을 없앴다. “인용”·"인용"·【핵심어】만 어두운 빨강(#8E2A22) 한 가지, 굵기 그대로.
  아빠 생각(파랑) 안의 인용도 빨강.
- 대사 칸: 두 줄 고정. 두 줄을 넘는 대사(전체 약 3~5%)는 문장 경계에서 두 줄씩 나눠 다음 클릭으로 넘긴다.
  글자 칸을 좌우 안쪽으로 들였다(왼쪽 120→170, 폭 1090→940).
- 대사 장면 인물: 1.55배로 키웠다. 머리끝은 인물 키(현장 도트 서 있는 높이)로 정한다 — 어른(210) 화면 위 20,
  큰 인물(230: 선생님·까로·보리·굴돌·무쇠)은 조금 잘리고, 할머니·부엉이(195)는 조금 낮고, 아이(165)는 더 낮다.
  다람은 어른의 2/3. 그림마다 캔버스 안 머리 위치가 달라 실제 그림의 윗변을 재서 맞춘다. 마차의 앉은 다람은 예전 크기.
- 남은 것: 선택지 문구 줄이기(문제없다·모순된다처럼, 소유자 결정 대기), 버튼 글자 정렬 전수 실측, 6일 장작 창고 바깥 물건 문구.
