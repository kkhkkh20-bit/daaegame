# 0.18.91 — 레퍼런스 리뷰 A·B·C 반영

사용자 ‘잘했다 우리도 적용 하자’ 요청으로 자료 제시의 맥락, 회의 전환, 후일담 가독성을 보완했다.

- A: 자료창에 상대/현재 발언을 표시하고 상대별·회의 논점/발언별 선택 자료와 페이지를 복원한다. 현재 건넬 수 있는 물건은 금색 테두리와 ‘전달 가능’ 문구로 구분한다. 실제 전달은 기존 대화 후 확인 흐름을 사용한다. 메인 메뉴와 자료창 주요 버튼은82 논리 픽셀(844×390에서 약44.4 CSSpx)로 확대했다. 승인된 배경과 로고는 유지했다.
- B: 일반 화자 전환0.22초, 끼어들기0.12초. 기존 고정 좌석, 움직임 끄기, 미해결 진술 반복, 읽음/반박 구분, 증거 판정과 투표 분리를 재검증했다. 회의 QA는 복원된 페이지에서 앞/뒤 방향을 모두 탐색한다.
- C: 기존7개 엔딩의4장 후일담을 유지하고 자막을 단일 양피지 패널로 통일했다. 이전/다음 버튼을 키우고 접힌 선이 본문을 가로지르지 않게 했다.
- 검수 중 발견한 기존 회귀: 초상화가 정확히43명일 때만 최신 저장 형식으로 인정하던 조건이 인물 추가로 새 저장의 ‘이어하기’를 막았다. 확장된 명단도 인정하도록 수정했다.

## 검증

- `dev/check.sh`: 전체 Python 단위 검사와 Ren’Py lint 통과. 자료 표식·독립 UI 기억·저장 회귀 검사 추가.
- 브라우저: `qa_title.py`, `qa_review_materials.py`, `ROOM13_MEETING_LOOP=1 qa_meeting.py`, `qa_endings.py` 통과. 실제 입력으로 메뉴/모바일, 자료 페이지 복귀, 회의 반복·오답·반박·취소·저장/로드,7엔딩28장과 이전 장면·동작 끄기 확인. 장면 검사는 명시적 상태를 설정하는 fixture이며 새 게임부터14일 전체 플레이는 아니다.
- Ren’Py 화면 검사: `fresh_run`, `trial_win`, `meeting_lap_hint`, `finale_win` 통과. 최종 회의는60초 제한 후120초 제한으로 재실행해89.243초에 통과했다. 전체167개 화면 테스트를 모두 실행하지는 않았다.
- 이야기 검토: 기존 엔딩 본문·분기 보정 문구, 증거 판정·기록 획득·시간·투표 판정 데이터 변경 없음. 아빠 새 그림 없음.
- 사람5명의 첫 플레이 수용성 검사는 미실시. 상세 스크롤 위치 복원, 신규 장소 대비 장면/음향 제작은 이번 변경 범위에 포함하지 않았다.
