# 0.20.71

소유자(2026-10-27) 플레이 지적·플레이 리뷰(74점)·UX 인계서 1차 반영.

## 자료 대조 통합 화면 (UX 인계서 D01~D06)

- 시범 3장면(1일 입구 논증, 1일 두 편지 비교, 7일 화재 첫 추궁)의 자료 대조를 한 화면으로: 상단 쟁점·남은 기회, 왼쪽 상대의 실제 발언
  (돌목·보리 인용, 들은 뒤에만), 가운데 보유 자료 전체 목록(체크로 고르기, 이번 사건·지난 사건·사람별은 보조 탭), 오른쪽 자료 상세,
  하단 고른 자료 칩과 주 행동 하나(「근거 제시」/「비교 마치기」). 두 편지는 체크 둘 → 「나란히 보기」 → 「비교 마치기」 네 번.
- 「조사 계속」으로 기회·선택을 그대로 둔 채 현장으로 돌아간다(1일 입구·7일 화재).
- 원본·규칙을 아직 읽지 않은 채 틀리면 「아직 이 창구에서 확인하지 않은 서류가 있다」로 안내한다(「근거는 다 있다」를 거짓으로 말하지 않음).
  마지막 기회도 같은 구분. 입구 서류·규칙판을 이르게 누르면 「돌목 씨에게 신청서를 찾아 달라고 먼저 부탁하자」.
- 단계 목표 한 문장(입구·7일 인수·보리 증언). 정답 자료·개수·결과는 어디에도 적지 않는다.
- 정답·대체 정답·덧붙임·기회 수·결말·생사·예방·진엔딩 조건은 바꾸지 않았다. 다른 쟁점·옛 캠페인은 기존 화면 그대로.

## 플레이어가 발견을 표현하는 순간 (D08·D09, 소유자 「둘 다 적용해」)

- 두 편지를 나란히 펼친 화면에서 「눈에 띄는 부분을 짚어 본다」: 두 문서 위 같은 모양의 구역 넷(머리글·본문·끝부분·여백). 끝부분을 짚으면
  도토리 주고받기(기존 세 줄)가 거기서 나오고, 다른 곳은 관찰 사실 한 줄만. 기회 소모 없음. 세 번 빗나가면 다람이 자리만 말한다.
  짚은 뒤 비교를 마치면 같은 세 줄을 되풀이하지 않는다.
- 7일 화재: 자료가 받아들여진 뒤 「무엇부터 물을까」(기름 흔적 / 등잔 위치 / 문 앞 목격). 누비의 첫 대답 한 줄만 다르고 자백·결과는 같다.
