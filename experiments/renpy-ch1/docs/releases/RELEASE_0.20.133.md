# 0.20.133 — 대사 대기 중 반복 처리와 정적 원화 재생성 절감

글자가 모두 나온 뒤에도 계속되던 타이핑 음향 확인 타이머를 실제 출력 중에만 사용한다. 무음·즉시표시·메뉴 상태에서도 불필요한 반복을 줄이고, 소리가 이미 나온 글자를 뒤따라 재생하지 않도록 한다.

승인 인물의 정적 원화 조립 결과를 최대48개 재사용한다. 감정·크기·좌표·배율·픽셀 설정·도구함 변경은 서로 구분하며, 반응 시계가 있는 동적 표정은 캐시하지 않는다. 원화 해상도와 표시 위치·이야기 판정은 유지한다.

전후 실측과 실제 새 게임 리뷰의 확인 범위는 검수 기록에 남긴다. 첫 로딩 용량 감소나 모든 기기의 렉 해결로 확대해 보고하지 않는다.

첫 플레이에서 돌목이 원본을 기준으로 정정하겠다고 한 뒤 다시 어느 서류가 맞는지 모른다고 하던 한 대사를 서류 확인 요청으로 연결했다. 증거·정답·기회·생사·결말은 바꾸지 않았다.

관련 단위199개, 대사 교체28개·동적연결12개, SDK핵심4개를 통과했다. [실제측정과 첫플레이검수](../reviews/performance-firstplay-20261109/검수.md)에 범위와 미확인 내용을 남긴다. 같은 .02초 타이머 복원/제거 비교에서 스크립트처리는 줄었지만 전체 브라우저작업시간을 일반적인 렉 개선률로 사용하지 않는다.
