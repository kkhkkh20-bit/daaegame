# 0.19.84 — 들어온 통합본 병합과 마차 연출 연결

`integrate/two-zone-01982`를 현재0.19.83 위에 충돌 없이 병합했다(병합 커밋 d32fd844). 조사 화면 두 지점 슬라이드·이동 중 입력 잠금·마스크를 적용한 사물 클릭 판정 및 승인된 타이틀 그림이 들어간다. 기존 하단 지도/기록 배치, 새벽 안개·눈 마차 컷, 독백 하늘색·나레이션 회색은 유지한다.

## 마차 요청

- 다람의 마차 전용 pop과 자동 몸 반응을 끄고 내부 시작부터 기존 원화로 보여준다. 다른 장면의 등장·표정 처리는 유지한다.
- 덜컹임 전에 네 줄 추가: '아빠, 숲이 아직 깜깜해.' / '조금 있으면 날이 밝을 거야.' / '엄마는 벌써 일어났을까?' / '만나면 물어보자.' 이후 과자 농담과 편지·분기는 그대로다.
- 말발굽용 전용 채널을 추가한다. 기존 source-knock.wav에서 짧은 목질 충격음을 가공해 두 쌍의 발굽 리듬으로 만든 재현 가능한 효과음이다(dev/make_carriage_hooves.py). 새 외부 음원은 사용하지 않는다. 실제 말 녹음은 아니다.
- 말발굽·바퀴 주행음은 외부→내부에 이어지고 하차/메인 화면에서 정지한다.
- 기존 조명 장치 R13FxLightRig를 사용해 실내의 은은한 따뜻한 빛과 그림자를 얹는다. 생성기의 --carriage-only로 해당 판만 생성하며 전체 재생성에도 같은 설정을 넣는다.
- 기존 창문 마스크 안에 기존 눈 연출을 연결한다. 외부 풍경과 카메라는 고정한다. 움직임 끄기는 기존 효과 설정을 따른다.
