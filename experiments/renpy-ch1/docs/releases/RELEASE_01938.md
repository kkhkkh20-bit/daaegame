# 0.19.38 — 대화 제목의 높이와 크기 정렬

왼쪽 인물 이름과 오른쪽 ‘묻고 싶은 이야기’가 서로 다른 높이와 크기로 놓여 화면이 기울어 보였다. 소유자 요청에 따라 두 제목을 같은 y=70, 같은 글자 크기30으로 맞췄다. 글꼴과 크기가 같아 글자의 기준선도 일치한다. 인물 이름의 금색은 유지한다.

질문 목록·자료 보여주기·기록·돌아가기의 위치와 동작, 이야기 대사와 조건은 유지한다.

검증: `dev/check.sh` 단위 검사 및 lint, 공식 웹 빌드, 실제 Chromium PC/모바일 큰 글씨 캡처 및 제목 정렬 확인. 캡처는 `docs/reviews/heading-balance-20261017/`.
