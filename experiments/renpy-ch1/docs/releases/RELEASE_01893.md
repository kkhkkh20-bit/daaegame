# 0.18.93 — 읽던 자료로 복귀, 장면 대비, 후일담 대사창 통일

사용자는 다른 채팅이 이야기 로직을 작업 중이므로 디자인에 집중하고, 자료창 복귀와 장면 대비를 먼저 적용하도록 요청했다. 후일담 전용 양피지는 기존 대사창으로 되돌리라는 피드백도 반영했다.

- 자료 상세 스크롤은 자료·상대/회의 발언·현재/지난 기록·글자 크기별로 분리해 숫자로 저장한다. 다른 자료를 보거나 창을 닫았다 열어도 읽던 위치로 복귀한다. 같은 위치의 viewport가 다른 자료의 상태를 이어받지 않도록 자료 키로 화면 캐시를 분리했다.
- 일반 기록창도 마지막 탭·선택 자료/인물·페이지·현재/지난 기록 선택을 복원한다. UI 기억은 새 회차 기본값으로 초기화되며, 소지 여부와 증거 판정을 바꾸지 않는다.
- 기존 사건 상태가 occurred인 여관·2층 복도·13호실에만 약한 차가운 색조와 낮은 환경음 음량을 적용한다. 기존 사건 전후 그림, 조명 효과, 인물/UI, 물건 좌표와 클릭 영역은 유지한다. 효과 캐시를 사건 상태별로 분리해 사건 전 색감이 재사용되지 않게 한다.
- 환경음 채널만 조정한다. 기존 BGM/환경음 파일 선택, 무음 장면, 효과음, 사용자 믹서 설정은 유지하고 다른 장소나 회의로 이동하면 환경음 배율을 원래대로 되돌린다.
- 후일담 하단은 공용 `r13_dialogue_frame()`과 기존 글꼴/역할 색상, 어두운 버튼으로 통일했다. 7개 엔딩의4장 구성과 대사 본문, 이전/다음 기능은 유지한다.

## 검증

- `dev/check.sh`: 전체 Python 단위 검사와 Ren’Py lint 통과. 화면 상태의 분리와 배경/환경음 처리의 읽기 전용 성질을 검사했다.
- `dev/qa_design_return.py`: 실제 휠 입력 뒤 자료 전환·닫기/재열기에서 스크롤 복원, 일반 기록창 탭/자료/페이지 복원 통과. 기존 읽음 표식 이외의 사건 상태·시간·증거 변화 없음. 3개 실내의 사건 전후 배경을 실제 렌더링해 비교했다. 이 화면들은 명시적인 장면 상태 fixture이며 전체 회차 플레이 기록은 아니다.
- `dev/qa_endings.py`: 7개 엔딩28장, 이전 장면·재생·저장/불러오기·움직임 끄기·844×390 큰 글씨 검사 통과.
- Ren’Py 화면 검사 `fresh_run`, `typography_roles` 통과. 이번 작업에서 전체 화면 테스트 묶음을 다시 실행하지는 않았다.
- 이야기 대사/증거 데이터/시간/진행 조건/회의 판정/투표 파일은 수정하지 않았다. 기존 엔딩 본문도 동일하다.
