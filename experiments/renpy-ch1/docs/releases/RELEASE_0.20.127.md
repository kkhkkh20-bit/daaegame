# 0.20.127 — 돌목·누비를 기존 도트 화풍에 맞춰 교정

0.20.126의 새 누비는 매끈한 만화선이었고, 기존 돌목은 털의 붓질이 있는 일러스트였다. 이를 기존 다람·빨래터 배경과 같은 도트 화풍이라고 판단한 것은 잘못이었다. 두 인물 각각 여섯 표정을 작은 계단형 윤곽·색 덩어리·끊어진 면 음영으로 다시 제작했다. 기존 다람과 빨래터 원화를 기준으로 삼았으며 배경·다람 원화는 교체하지 않았다.

누비의 행주 근접 컷도 같은 의상색과 도트 표현으로 교체했다. 손·행주·구도·대사 연결과 다음 발언에서 얼굴로 돌아오는 흐름을 유지한다. 돌목·누비의 정면 시선, 의상·소품·손자세·기존 표시 키·질문 발선도 유지한다. 기계적인 픽셀 필터나 낮은 해상도 확대는 적용하지 않는다.

기존 원본을 보존하고 돌목·누비별 재가져오기 명령을 제공한다. 예전 가져오기 도구가 새 도트 등록을 되돌리지 않도록 보호했다. 도구함과 요청서도 현재 납품에 맞춘다.

대사·판정·자료·생사·결말·공개 1부 경계는 변경하지 않았다. 이번 교정은 돌목·누비 12표정과 누비 행주 컷이며 전체 주민의 작화 통일 완료를 뜻하지 않는다. [전후 비교와 검증](../reviews/pixel-style-20261108/검수.md), [앞으로의 도트 참조 기준](../design/PIXEL_STYLE_REFERENCE.md)을 따른다.
