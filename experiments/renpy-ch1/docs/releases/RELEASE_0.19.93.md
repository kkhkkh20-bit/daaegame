# 0.19.93 — 새 세계관 회의를 기존 회의 무대로

소유자 결정(2026-10-22): "전부 기존 걸 쓰자". 새 세계관 회의 11개(1일 입구, 3일 3번 등, 5일 초소, 7일 창고, 10일 13호실·기록, 11일 가설 문답, 12일 수프, 13일 담요·재수사, 14일 제단)가 일반 대화 화면 대신 옛 회의의 무대에서 진행된다.

- 발언자가 가운데, 양옆에 이웃이 서고, 말하는 사람에게 카메라가 돌아간다(원탁 카메라 R13MeetingOrbit 그대로). 실내는 기존 '실내 입석', 야외는 '현장 회의', 제단은 '돌판 회의' 배치.
- 위쪽 쟁점 띠는 기존 회의 띠와 같은 부품. 둘째 줄에 남은 기회(예: 남은 기회 2 / 3)를 기존 '반박 n / m' 자리에 보여 준다.
- 대사 하단은 승인된 대화 하단(건너뛰기·기록·더보기), 더보기도 대화용 메뉴. 회의 중 선택지에도 같은 하단.
- 회의의 범위는 생성기 라벨 목록(`game/room13_v111_meeting_stage.rpy`)으로 정한다. 지도 이동·대기 중에는 무대를 내리고 같은 회의의 다음 줄에서 다시 띄운다. 회의 밖 라벨로 나가면 끝난다.
- 대사판 줄에 `beat`(기존 회의 장면 단계: interrupt, shaken, cornered 등)를 붙일 수 있게 했다. 아직 붙인 줄은 없다.
- 판정, 기회, 결과는 바뀌지 않는다.

## 협업
- 구현은 Claude, 코드 검토와 디자인 검토는 Codex. Codex 코드 검토로 5건을 고쳤다(라벨 콜백 인자, 카메라 표정, 중간에 합류하는 인물, 회의 중 선택지 하단, 더보기 메뉴).
- Codex 디자인 검토의 남은 제안(양옆 인물 얼굴 잘림, 실내 회의의 상반신 구도, 밝은 학교 배경 감광)은 기존 배치 규칙을 바꾸므로 시안을 먼저 만든다.

## 검증
- 단위 테스트 834개와 lint 통과(새 검사: 회의 라벨 존재·중복 없음, 회의 키와 규칙의 회의 일치, 참석자 이름, 콜백 인자, 옛 회의 화면 유지).
- 새 세계관 화면 테스트 39개 통과. 가설 문답 테스트는 회의 선택지 위치에 맞춰 클릭 위치를 옮겼다.
- 10일 13호실 회의를 실제 엔진에서 캡처해 확인(학교 입석 무대, 발언자 전환, 회의 뒤 허브 복귀).
