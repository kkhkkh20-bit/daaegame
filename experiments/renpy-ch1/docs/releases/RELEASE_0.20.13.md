# Room13 0.20.13

자료 화면을 휴대폰 가로 크기에서 읽고 누르기 쉽게 고쳤다. 사건의 대사·관찰 사실·정답·생사·분기는 그대로다.

- 관찰문을 모바일 기준 약 16px 이상으로 확대했다. 출처 설명과 자료 이름도 함께 조정했다.
- 비교·출처·제시·페이지 이동·닫기·탭·분류의 터치 영역을 확대했다. 844×390에서 주요 버튼 높이는 약 45.5 CSS px다.
- 한 장 보기와 두 장 비교의 읽기 영역을 분리했다. 긴 관찰문은 버튼을 가리지 않고 스크롤로 끝까지 읽을 수 있다.
- 모바일 목록은 그림 크기와 행 간격을 조정해 확대된 페이지 버튼과 겹치지 않는다.
- 큰 글씨에서 분류 버튼 다섯 개가 탭을 덮지 않도록 폭을 조정했다.
- 자료 종류 이름의 폭을 제목 배치에 반영했다. 짧은 내용에는 불필요한 스크롤바를 숨긴다.
- 화면 표시 버전과 패키지 버전을 일치시켰다.

제목·탭 겹침과 빈 상태 안내 등 앞선 버전에서 해결된 항목은 유지했다. 회의의 자동 해설·재조사 개선은 이번에 변경하지 않았다.
