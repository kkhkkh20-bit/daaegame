# 0.18.69 · 회의 조작과 연출 정리

- 발언 선택 화면도 화자와 양옆 인물이 보이는 근접 구도를 사용한다. 전체 원탁은 안건 시작과 공개 의견 확인에 사용한다.
- 되묻기/보여주기를 대사창 아래 같은 좌표로 통일한다. 대사 중 백로그는 바로 열고 자동·건너뛰기·설정·진행 저장은 더보기에서 연다.
- 대사창 위쪽의 이전/다음 화살표와 발언 순번으로 이동한다. 좌우 방향키도 지원하고, 별도 큰 다음 발언 버튼은 제거한다.
- 반박한 말은 체크·흐린 취소선으로 남기며 다시 듣기를 허용한다. 재생은 원문/되묻기 대사만 보여주고, 자료 제시·반박·공개/준비 조건을 다시 실행하지 않는다.
- 반박 성공 시 실제 제시 반응에서 나온 문장을 ‘방금 확인한 말’로 남기고 발언 기록에도 연결한다. 아직 반박하지 않은 말에는 내용을 미리 보여주지 않는다.
- 메인 화면의 반박 수 패널은 제거하고 현재 쟁점을 질문으로 표시한다. 숫자 진행은 발언 기록 안에서만 확인한다.
- 실제 입장이 바뀐 주민만 집계 전에 짧게 말한다. 이전 집계와 같으면 반응을 반복하지 않는다. 이 화면은 입증에 따른 공개 의견 확인이며, 다수결이 증거나 엔딩 조건을 대신하지 않는다.
- 반박이 받아들여지면 큰 효과 대신 현재 표정을 0.22초 유지한다. 움직임 끄기/건너뛰기에서는 생략한다.
- 여관 참석자 10명의 새 앉은 사선 자세를 원탁 전체와 양옆 인물에 적용한다. 가운데 인물은 기존 정면 표정 세트를 유지하고, 제단은 서 있는 자세를 유지한다.
