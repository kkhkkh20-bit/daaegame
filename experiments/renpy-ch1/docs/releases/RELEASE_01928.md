솔방울 친칠라 확정 원본의 대화 6표정, 프로필, 기존 fullbody/portrait fallback을 연결했다. 숲 오전·오후 약초 묶음 동작은 별도 지도 키이며 기존 2px 격자 표시를 유지한다. 프로필 승인 범위는 58명에서 솔방울을 포함한 59명이다. 대화·프로필은 smooth 원본을 사용한다.
