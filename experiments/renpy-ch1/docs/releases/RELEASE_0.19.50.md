# 0.19.50 — 현장 조작 단순화

- 기본 현장은 인물을 직접 눌러 대화한다. ‘주변 살피기’ 한 개로 인물을 숨겨 배경 조사, ‘사람 보기’로 복귀한다.
- 식당·주방·복도 등 장소 바로가기 제거. 이동은 지도에 모았다. 대화 전환·조사 지점 옵션·현장 더보기 중복 버튼도 제거했다.
- 조사 지점은 조사 중 자동 표시한다. 선택 지점 표시와 대상 이름을 유지하며 터치 영역은72px로 넓혔다.
- 카메라를 움직여 대상이 화면 밖으로 나가면 선택을 지운다. 실제 장소 변경 시 인물 기본 상태로 복귀하고 이전 선택을 지운다. 지도/기록 취소 시 카메라와 모드는 유지한다.
- 여관 내부에서 마을 지도를 열면 여관에 현재 위치가 표시된다.
- 침대의 취침과 시간 제한 할 일 등 실제 기능은 유지했다. 대사·증거·일정·회의 로직은 바꾸지 않았다.
