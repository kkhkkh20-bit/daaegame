# 0.18.76 · 엔딩 그림의 잔질감 정리

일곱 엔딩의 네 장면, 총 28장면을 깨끗한 색면 중심으로 다시 정리했다. 눈·하늘·벽·목재·옷의 미세한 점과 얼룩, 촘촘한 나무결, 잘게 흩어진 반사광을 줄이고 큰 명암 덩어리와 픽셀 윤곽을 남겼다. 캐릭터, 장면 배치, 겨울의 색감, 중요 소품은 유지한다.

그림은 imagegen으로 직접 편집했고 후처리 흐림 필터는 사용하지 않았다. 파일은 정해진 WebP 가져오기 도구로 저장하며, 네 장면의 실제 자르기 영역을 대조한다. 결말 조건·대사·보상·후일담 조작은 변경하지 않는다.

검증: 기존 엔딩 자료의 네 영역과 경계 검사, 단위 테스트 192개, Ren’Py lint, 웹 빌드 및 실제 Chromium에서 일곱 엔딩 28장면 재생을 통과했다. 이전 이동, 중간 저장·불러오기, 다시 보기의 상태 보존, 연출 끄기와 모바일 큰 글씨도 확인했다. 실제 화면은 [비교 갤러리](../../reports/ending-clean-20261016/README.md)에 정리한다. 엔딩 검사는 명시적 상태를 사용하며 전체 14일 플레이는 아니다.

0.18.75의 시장·엄마 은신처·대사 및 다람이 표정 변경을 병합했다. 버전 충돌은 0.18.76으로 정리하고 공개본을 다시 빌드했다. 병합 후 `bash -o pipefail dev/check.sh`와 실제 일곱 엔딩 재생을 다시 통과했다.
