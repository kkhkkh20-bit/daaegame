# 0.19.42 — 피코 화가복·굴돌 돌일 4동작

승인 원본 d301395b의 피코 paint_sketchboard_v2 / mix_paint_v2, 굴돌 inspect_stone_clean / sort_chisels_clean을 공통 조사용 2px export로 연결했다. 원본과 SHA/파생 과정은 art/approved-piko-guldol-four에 보존한다. 초기 피코 sketching은 사용하지 않는다.

피코는 실제 광장 출현 중 10일까지 날짜에 따라 그림판/팔레트 동작을 나눈다(1·3·5·6·7·9일 그림판, 2·4·8·10일 팔레트). 6일 오전의 기존 광장 일정도 유지한다. 진료실/환자 동작과 사건 제안은 변경하지 않는다. 굴돌은 기존 공방 돌 두드리기 자리에 끌 정리, 광장의 기본 서기에 돌결 관찰을 연결했다. 작업대 가림을 보존하며 새로 출현시키지 않는다. 피코 그림판과 종종이 얼굴이 가까워지지 않도록 피코의 발 기준을 1050,625로 조정했다.

검증: 전체 393개 단위 검사 및 SDK lint 통과. 마지막 피코 위치 조정 후 관련 3개 테스트 통과와 공식 SDK 재빌드, 실제 5장면·5클릭 재검수. 얼굴 hit 검사 누락 없음. 원본/최종 파생 hash, 7개 조각·preload hash 및 ZIP CRC 확인. 전체 캠페인 QA가 아닌 명시적 일정 fixture다. 실제 캡처는 reports/piko-guldol-01942.

굴돌 원본 미리보기의 넓은 갈색 잔광은 alpha=0 픽셀의 RGB였으며 기존 export의 완전 투명 RGB 정리 후 보이지 않는다. alpha/실루엣을 임의로 깎거나 새 원화를 생성하지 않았다.
