# 0.20.125 — 1부 회의의 인물 배치·증거 확대·문답 리듬 개선

5일차 회의에서 콩이 얼굴이 대사창 아래에 가려지던 배치를 수정했다. 정규화된 원본의 실제 발끝을 기준으로 세워 그림 크기와 주민 간 키 차이를 유지한다. 실내·현장 한 사람 회의의 배경은 실제 장소 그림 안에서만 이동해 거울처럼 반복되는 건물을 없앴다.

3일차 칼끝 대조를 고른 뒤 칼과 파편의 깨진 면을 확대한다. 자료함의 파편·대조한 칼도 같은 원화에서 보여 준다. 파편만 가진 때에는 파편만 보이며 대조 전에는 전체 결합 그림을 보여 주지 않는다. 대조 방향 선택 직후 같은 자료를 다시 고르던 중간 메뉴는 생략하고 기존 자료 제출로 바로 검증한다. 구 저장의 메뉴 라벨은 유지한다.

1·3·5·7일 회의는 제출 직후 고른 자료를 짧게 보여 주고 실제 답변으로 이어진다. 기본 발언과 설명·반문·명시된 놀람에 화면 강약과 볼륨 차이를 연결했다. 저자가 정한 표정이 우선하며 곡은 문장마다 재시작하지 않는다. 회의 종료·불러오기에는 기존 복구 처리를 쓴다.

5일차 너울의 중간 반박 뒤에 얼굴 목격·겉옷 착용·당시 위치를 직접 묻는 세 질문을 넣었다. 각 질문은 다른 답변을 받고 나비의 직접 목격으로 이어진다. 추가 기회나 자료를 요구하지 않으며 초상화 대체 정답도 유지한다. 아빠의 자동 알리바이 해설과 겉옷 설명 반복은 줄이고 밤이의 이름 확인과 종이 접기는 보존했다.

7일차 연결판은 바로 질문을 제출한다. 출처는 선택해서 읽을 수 있고 자료 변경·현장 그림·구 저장의 출처 화면도 유지한다. 방금 연결한 관찰을 대사로 다시 읽는 반복을 없앴다. 재대조할 내용이 하나면 실제 질문으로 바로 이어지고, 흔적·들은 말 두 가지가 있으면 선택을 유지한다. 누비를 추궁하는 아빠의 말에서는 질문받는 누비와 불안한 표정을 명시해, 다른 주민의 평온한 얼굴이 잡히지 않게 했다.

진상·원본 records·정답 조합·기회 총수·생사·결말은 변경하지 않았다. 검증과 실제 화면은 [적용 검수](../reviews/meeting-fixes-20261108/검수.md)에 기록한다.

전체 단위 1,474개·관련 엔진 화면 16개·웹 5항목·lint·대사 논리 A/B/C 0건을 확인했다. 웹 저장 후 새로고침·이어하기도 통과했다. 검증 범위와 제한은 위 적용 검수를 따른다.
