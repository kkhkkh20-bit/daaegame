# 0.19.33 — 승인된 지도 동작 27컷 연결 마무리

0.19.31의 8컷에 남은 승인 원본 19컷을 추가한다. 승인된 반투명 대사·선택지 UI(main b456515e, 0.19.32)를 병합해 보존한다.

- 총 27개 원본을 해시·바이트·실제 PNG 크기로 검증하고 원본 그대로 보관. 지도용 파생본만 768px 높이/2px 격자/무손실 투명 WebP로 만든다. 가로 크기가 서로 다른 원본도 각각의 변환 비율을 쓴다.
- 26개 동작은 기존 주민 일정에서만 선택한다. 현이(장터·광장·식당), 누비(여관·학교·시설)는 기존 일정에 맞게 재사용한다. 나비 KI-1은 승인 그림 등록과 미리보기 좌표까지만 준비하고 `periods=[]`로 비활성화한다. 주방 일정을 만들지 않는다.
- 너울 GA-1/FA-1 남색 겨울 외투는 입구·시설 지도 장면에 한정한다. 회의·대화 그림, 다른 인물의 프로필·표정, 세계 일정, 사망·구금 처리와 사건 동작은 바꾸지 않는다.
- 피코 CL-1은 11일 이후 살아 있는 기존 주민만 침대 가장자리에 앉힌다. 원본 엉덩이 접점을 침대에 맞추며, 이전 누운 그림의 담요 가림은 제거한다.
- 톡·달그락 수프는 의자 접점과 그릇 바닥을 한 가지 배율로 맞춘다. 시설 너울의 손, 장터 약초, 학교 책, 보따리 등은 가구 가림보다 앞에 남긴다. 그림과 클릭 판정은 같은 가림을 쓴다.
- 꽥순 낚싯대는 조사 화면의 평상 동작이다. 현재 비활성인 기존 그물 일거리 코드·대사와 대화 그림은 보존하며 일거리를 재활성화하지 않는다. 칼바람의 새 무릎 자세는 2일 이후 평상 조사에만 쓰고 첫날 밤 사건은 보존한다.
- 오전 2160px/오후·저녁 1280px 우체국은 좌표를 분리한다. 실제 화면에서 발견한 주민 겹침은 새 동작의 위치를 조정해 해결한다.

검증 결과와 실제 실행 캡처: `docs/reviews/action27-remaining/`.

남은 범위: 나비의 주방 출현 일정은 이 판에서 미구현이다. 이후 사용자 승인으로 일상 주방 슬롯과 추가 4종 연결을 후속 작업으로 진행한다. 은호/구슬 장터 동작의 창고 추가 재사용도 이번 범위에 포함하지 않는다. 기존 미제작 대화 표정·돌목 수정 동작 등의 제작 대기 상태를 이 지도 27컷 완료로 대체하지 않는다.

추가 요청인 나비 주방 4종은 이번 27컷과 별도로 `docs/reviews/nabi-kitchen-extra4/README.md`에 기존 코드 조건과 배경 접점 후보만 기록했다. 원본 미전달·미적용이다.

검증 완료: 추가 18동작을 실제 WASM 26장면에서 확인(얼굴 클릭 포함), 3개 저장 복원, 5개 사망·구금 제외 상태, 나비 비활성 미리보기. 최종 단위/접점/원본 테스트 및 lint, 빌드 part 해시·ZIP CRC 통과. 장시간 전체 캠페인 QA와 공개 URL 재시도는 하지 않았다.
