# 0.19.3 · 2026-10-17 — 마을·숲 지도와 여관 이동 정리

승인한 맵 기획을 실제 에피소드 동선에 맞춰 반영했다. 마을은 골목을 따라 집들이 모이는 겨울 마을 그림으로 교체했고, 숲·산길은 같은 화풍의 별도 지도로 만들었다.

- 별도 핀·아이콘을 없애고 건물·지형 자체를 선택한다. 마우스 초점/탭에 이름이 나오며 선택한 장소는 하단에 남는다. 반복 탭은 이동하지 않고 ‘이곳으로 이동’으로만 확정한다.
- 지도를 화면 너비로 넓혔다. 지도 위에는 작은 제목·현재 위치 표시, 하단에는 지역 전환과 이동/닫기만 둔다. 큰 우측 설명 패널과 상단을 가리던 긴 띠를 없앴다.
- 폐온실·제단은 발견 전 그림에서도 보이지 않는다. 기존 발견·접근 조건이 충족될 때 해당 영역을 표시한다. 제단 접근은 기존 이야기 진입 규칙을 유지한다.
- 여관 평면도와 큰 방 카드를 층별 글씨 목록·현장 사진으로 교체했다. 중복 ‘안내도’ 버튼은 제거했다. 이전 안내도 호출 이름은 같은 목록으로 연결하며 기존 인접 이동 검증/반환 규약을 유지한다.
- 옛 시설은 여관 아래에 남는다. 산길 동굴, 새 이동 단계, 새 시간 비용, 독립 사건 장소 버튼을 만들지 않았다. 다람의 다섯 걸음·자료 획득·사건 대사·회의 진행 로직은 유지한다.
- 회의 유형은 선택한 장소의 하단 설명에 표시한다. 지도 위에 별도 회의 배지는 없다.
- 도입부의 지도도 새 마을 그림을 사용한다. 사용하지 않는 옛 지도·평면도 그림과 생성기는 제거했다.

설계와 실행 데이터 차이, 그림 출처·좌표 생성기: `docs/design/MAP_PLAN_20261017.md`.
