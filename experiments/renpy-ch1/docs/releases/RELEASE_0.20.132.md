# 0.20.132 — 완주 검수의 추리 그림·돌봄 대사·인물 원화 교정

- 3일차 걸쇠 설명에 기존 기록의 바깥 판·안쪽 받침 구조 그림을 함께 보여 주고, 말하는 부분을 짚은 뒤 다음 쟁점 전에 내린다.
- 7일차 누비 아이들의 학교 도착과 오늘 밤 잠자리·돌봄 담당 확인을 대사에서 구분한다.
- 초롱의 일반 여섯 표정에서 입의 끈·작업 걸레를 빼고, 끈을 잡아 달라는 실제 작업 대사에만 기존 작업 원화를 사용한다.
- 백 부인·진료 담당자·누비 큰아이의 일반 표정을 주연 도트 기준에 맞추며, 기존 키·발선·의상·고유 소품은 보존한다.

정답 자료 조합·기회·증거 ID·생사·결말·공개 1부 경계는 바꾸지 않는다. 바뀐 핵심 장면의 PC·모바일 화면과 기존 1부 완료 저장을 확인한다.

관련 단위147개·SDK 핵심4개, 최종 웹 PC·휴대폰의 수정 장면과 실제 0.20.131 완료 저장 복원을 확인했다. 이번에는 수정 장면을 준비한 부분 검증이며 전체 7일 연속 완주는 반복하지 않았다. [실제 화면·검증 범위](../reviews/fixes-20261108-132/검수.md).
