# Room13 0.20.8

첫날~2일 아침 실제 플레이 리뷰(0.20.3 기준)와 2~14일 연출 제안을 0.20.7에 대조해 남은 것을 반영했다.

- 13호실에 들어가 메모나 보따리를 먼저 누르면 제목만 나오던 문제를 고쳤다. 이제 "우선 다람이 짐부터 침대에 내려놓고 방을 둘러보자"처럼 지금 할 일과 이유를 말한다.
- 방을 조사한 뒤 할머니에게 마지막으로 돌아온 날을 물으면 더 이상 "우선 방부터 봐요"라고 하지 않는다. "그건 초롱한테 물어봐요. 내일 아침이면 광장에 있을 거예요."로 이어진다.
- 편지 비교 뒤 다람의 말을 "초롱이 어디 있는지 할머니한테 물어보자. 가자, 아빠."로 바꿨다. 바로 다음 행동인 할머니에게 묻기와 맞춘 것이다.
- 7일 구조 장면에서 비명 시각을 묻는 질문을 다람을 품에 안은 직후로 옮겼다. 구조 → 아이 확인 → 조사 순서다.
- 이미 고쳐져 있던 항목도 확인했다. 수신자 '아빠' 표시, 제목·탭 겹침, 메모 그림의 도토리, 빈 질문창 안내, 질문마다 현장으로 튕기던 문제다.
