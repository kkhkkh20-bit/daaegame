# 0.19.51 — 근거를 얻은 뒤 열리는 질문과 빈 대화 진입 방지

- 날짜가 됐다는 이유로 생활·후일 질문과 첫날 밤 행적을 먼저 나열하지 않는다. 실제로 들은 말과 조사·읽은 자료를 공통 계기 조건으로 확인한다.
- 할머니의 첫 질문은 아내 찾기에 집중한다. 방을 이미 받은 경우 다시 방을 부탁하지 않는다. 아내가 나간 날짜를 묻는 답에서 손님이 늘었다는 말을 들은 뒤 손님 수 질문이 추가된다.
- 칼바람에게 아내를 찾는 질문으로 기존 첫날 밤 목격담에 자연스럽게 접근한다. 그 뒤 다른 사람에게 그 밤을 확인한다. 숲 끝이 언급된 뒤에 그곳의 길을 묻는 후속 질문도 연다. 원래 알리바이 플래그·교차 확인은 유지하며 동일 목격담 질문을 중복 추가하지 않는다.
- 미확인 질문·관련 자료·첫 대화에서 열릴 주제가 없으면 인물을 확대하지 않고 현장에서 짧게 안내한다. 이벤트·아이·그룹·새 용도가 생긴 자료 제시 경로는 유지한다.
- 이전에 읽은 질문과 실제 대화 기록을 보존한다. 단순히 옛 메뉴에서 보았거나 이전 회차에서 알았다는 이유로 해금하지 않는다.
