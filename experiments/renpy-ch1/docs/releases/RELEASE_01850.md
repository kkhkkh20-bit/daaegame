# 0.18.50 — 기록과 같은 설정창, 중앙 질문, 하나로 이어진 도구줄

## 설정·게임 진행

- 설정창을 기록과 같은 양피지 수첩 틀로 바꿨다. 왼쪽 색인은 읽기 / 소리 / 화면이며, 현재 선택값은 짙은 갈색과 하단 강조선으로 구분한다.
- 읽기: 글자 크기, 대사 표시 속도, 자동 넘김 대기. 기존 무한 대기값(0)도 ‘수동’으로 명시한다. 글자 크기 미리보기를 제공한다.
- 소리: 배경음·효과음 음량에 퍼센트를 표시하고 음소거 상태를 명시한다. 타이핑 소리는 켜기/끄기 두 선택으로 표시한다. 효과음 듣기와 음악 출처를 유지한다.
- 화면: 대사창 진하기, 화면 움직임, 전체 화면. 기존 ‘안드로이드에서 동작’ 설명을 실제 지원 여부에 맞게 ‘기기·브라우저 지원 시’로 수정한다.
- 설정은 즉시 적용된다. 저장/불러오기와 저장 정리 기능은 설정창에서 제거했다. 게임 진행은 현장 우상단 메뉴 / 대화 하단 더보기의 ‘진행 저장’, ‘진행 불러오기’로 이동했다. 저장 정리는 기존 불러오기 화면에서 가능하다.
- ‘처음 화면’을 ‘메인화면’으로 바꿨다. 누르면 ‘메인화면으로 돌아가시겠습니까?’와 미저장 진행 안내를 표시한다. 취소하면 현재 화면을 유지한다.

## 질문·현장·도구줄

- 인물이 있는 질문 목록을 화면 중앙 높이로 올렸다. 얼굴이 일부 가려지는 것은 허용하며 하단 대사 진행 위치와 거리를 둔다. 많은 질문은 제한된 높이 안에서 스크롤한다. 보여주기는 질문 아래에서 빼고 오른쪽 제시 자료 카드 자리(같은 중심·상단 기준)에 배치한다.
- 읽은 질문은 체크·낮은 명도·취소선으로 구분한다. 다시 누르면 저장된 원문 대화가 바로 재생되며 ‘전체 대화 다시 보기 / 그만 본다’ 중간 선택을 제거했다. 작은 점으로 미열람을 표시한다. 정답이나 중요한 질문을 구분하지 않는다.
- 질문 선택 후 0.35초간 대사 넘김 입력을 보호해 빠른 두 번째 탭이 첫 답변을 넘기지 않도록 한다. 기존 대사 넘김 제한과 명시적 건너뛰기는 유지한다. 타이머는 엔진 임시 상태여서 저장 파일에 시각을 남기지 않는다.
- 백로그·자동·건너뛰기·더보기·기록을 하나의 공통 바탕과 얇은 구분선으로 연결했다. 반복된 개별 테두리를 제거하고 기록의 우하단 위치는 유지했다. 선택/마우스오버 강조는 아래쪽에만 둔다.
- 짙은 조작부의 회색을 따뜻한 갈색으로 조정했다. 밝은 양피지는 정보·기록·설정에, 짙은 갈색은 대사와 조작부에 사용한다.
- 인물 이름표를 키우고 기존 얼굴/이름표 겹침 회피를 유지했다. 출구는 방향 표시가 있는 밝은 종이 모양으로 구분했다. 인물 몸 클릭과 기존 출구의 목적지·해금 조건은 유지한다.
- 생각창에는 현재 의문만 짧게 표시하고 조사 메모를 여는 버튼을 뒀다. 조사 메모 제목을 다시 길게 나열하는 중복을 제거했다.
