# 0.18.41 · 2026-10-15 — 메인 타이틀 연출, 오프닝 다시 디자인, 대화 인물 움직임 정리

0.18.40 위에 쌓았다. 소유자 요청 세 가지.
- 첫 메인 화면에도 움직임.
- 인트로를 더 디자인해서. 동작별로.
- 움직임은 조사 화면에서는 없이, 대화 화면에서만. 기본은 눈 깜빡임, 감정이 바뀌면 처음에 그 반응(놀라면 놀라는 동작)을 하고 멈춘 채 대화.

## 1. 메인 타이틀

- **첫 등장(게임을 켠 뒤 한 번):** 로고가 위에서 떨어져 3px 단위로 두 번 통통 튀며 자리 잡는다(0.6초). 이어서 메뉴가 아래에서 6px 올라오며 나타난다(0.3초).
  - 설정·불러오기에서 돌아오는 등 다시 보일 때는 바로 제자리다.
- **계속:** 기존 1~2px 눈(`R13TitleSnow`)을 게임 안과 같은 4px·8px 도트 눈 두 겹으로 바꿨다. 등불 4개, 여관 창·문, 종탑 창의 불빛이 일렁인다.
- 굴뚝 연기는 원화에 이미 그려져 있어 넣지 않았다.
- 설정의 '움직임'이 꺼져 있으면 모두 멈춘 원래 화면이다.

- 메뉴 항목·동작·기본 선택·저장 표시, 배경·로고 그림은 바꾸지 않았다.
- 파일: `systems/room13_title_fx.rpy`, `screens.rpy`의 `main_menu` 세 줄. 불빛 자리는 `make_dot_fx.py`의 `TITLE_LIGHTS`.

## 2. 오프닝 다시 디자인 (4컷, 약 17초)

1. **편지 · 4.2초:** 어둠과 눈 속에 '할머니의 초대 편지'(E01 아이콘)가 위에서 떨어져 통통 튀고 반짝인다. 편지 이름, 아빠의 독백 두 줄.
2. **지도 · 5초:** 위아래 검은 띠가 들어온다. 마을 지도 v5를 원본 픽셀 그대로 산 쪽에서 입구 쪽으로 내려다보고, 마을 밖에서 입구까지 금색 도트 점선이 이어진 뒤 '마을 입구' 핀이 꽂힌다.
3. **제목 · 4.4초:** 입구 오후 풍경을 훑고 로고와 "눈에 갇힌 마을".
4. **마차 · 3.6초:** 덜컹거리는 빈 마차 안, 창밖으로 스치는 눈. 띠가 걷히며 마차 대화로.

- 지도에서 숨은 장소는 보이지 않는다(이름·표시는 입구 하나뿐). 점선은 마을 밖에서 입구까지만 그린다.
- 화면 테스트 `opening_cut`의 캡처를 7장으로 바꿨다.

## 3. 대화 인물 움직임 정리

- **조사(현장) 화면:** 인물 움직임 없음. 0.18.37의 현장 숨쉬기를 다시 껐다(`R13_FIELD_IDLE = False`, UI 규칙 문서도 되돌림).
- **대화 화면 기본:** 눈 깜빡임만. 첫 깜빡임을 등장 0.7초 뒤 0.6~1.6초 안으로 당겼다(이전에는 4~7초 뒤라 짧은 대사에서는 보이지 않았다). 그 뒤로는 2.6~5.2초마다.
  - 마차 첫 장면의 다람이는 웃는 얼굴(joy, 원래 눈을 감은 그림)이라 깜빡이지 않는다. 웃지 않는 대사부터 깜빡인다.
- **감정이 바뀌는 순간:** 그 감정의 동작을 한 번 하고 멈춘 채 대화한다. 같은 감정이 이어지면 움직이지 않는다.
  - 놀람: 앞 표정 그대로 움찔 → 놀란 얼굴로 바뀌며 튀어오름 → 내려앉음
  - 화남: 앞 표정 그대로 움찔 → 화난 얼굴로 바뀌며 부르르
  - 기쁨: 깡총 두 번 / 불안: 움츠리며 잔떨림 / 당황: 좌우 갸웃
  - 생각(새로 추가): 한쪽으로 기울어 1초 머문 뒤 제자리. 생각 표정은 그림이 기본 표정과 같아서 동작으로만 구분된다.
