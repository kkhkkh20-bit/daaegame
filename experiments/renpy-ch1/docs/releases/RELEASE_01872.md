# 0.18.72 · 제단에서 서서 둘러서는 돌판 회의

마지막 제단 회의의 낮은 바닥 원형단을, 주민이 서서 둘러설 수 있는 큰 돌판 구도로 바꿨다. 기존 제단의 겨울 저녁 숲·산·등불·마을·밸브와 배관을 이어가는 전용 배경을 제작했다. 회의용 그림만 추가하며 탐색 제단과 장치 상호작용은 바꾸지 않는다.

돌판 뒤쪽 선은 화면 중앙 y432, 양끝 y500을 따라 그려 인물의 허리 부근을 자연스럽게 가린다. 화자는 중앙 정면에 크게, 양옆에는 서 있는 주민을 일부 보인다. 보리의 중립 그림은 얼굴 방향을 별도로 보정해 오른쪽 자리에서도 안쪽을 본다. 식당에서는 기존 앉은 그림을 그대로 사용한다.

전체 의견 확인 화면도 같은 돌판을 쓰고, 주민들의 서 있는 높이와 가림 위치를 맞췄다. 화자가 바뀌는 좌우 전환과 반복 듣기·되묻기·자료 제시·논점 판단 흐름은 그대로 적용한다. 아빠는 화면에 그리지 않는다.

검증: 단위 테스트 181개, 회의 대상 테스트 20개, Ren’Py lint·웹 빌드. 실제 Chromium에서 14일 제단 회의의 중앙·양옆 인물, 좌우 화자 전환, 모바일 자료창 취소, F1 자료 두 건과 결론 선택, 전체 회의의 공개 의견 확인, 실제 준비 관문 미변경을 검사했다. 명시적 14일 상태를 사용하며 전체 14일 플레이 검사는 아니다.
