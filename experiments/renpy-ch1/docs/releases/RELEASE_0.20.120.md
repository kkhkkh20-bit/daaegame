# 0.20.120 — 초반 대화·인물 높이와 13호실 조사 정리

## 변경

- 인물 표정 반응이 새 정면 그림에 예전 전신 틀을 적용해 아래로 밀리던 오류를 수정했다. 실제 여관의 손 감싸기 선택 뒤 지문에서 재현했고, 같은 장면으로 비교했다. 문맥 그림과 배율이 다른 머리 기준 캐시를 구분한다.
- 까로·보리의 일반 대화 확대를 약 20% 줄였다. 다람의 일반 대화 머리를 32px 높였다. 질문용 전신·착석·별도 활동 그림은 보존한다. 질문 전용 560 규격은 중간 크기 대화 컷의 비례 기준으로 쓰지 않는다.
- 마차의 과자 반 요구 중복을 줄이고 편지 반복 읽기 질문에 답하도록 했다. 엄마를 만날 기대·잠자리 장난·돌 등불 질문의 응답을 잇는다. 여관은 엄마 부재 소식을 들은 뒤 아이가 걱정하는 순서를 맞췄다.
- 대화 기록의 역순을 시간순으로 바꾸고 실제로 읽은 한 발화의 연속 페이지만 묶는다. 백로그 스크롤 위치를 기억한다. 구 기록의 출처는 추측하지 않는다.
- 책상 아래의 소품 아이콘을 방의 조명·재질을 참고한 천 보따리와 접지 그림자로 바꾸고 바닥 배치·조사 범위를 맞췄다. 가족 그림·목도리·연필을 반영했다. 기존 배경 6장과 구 저장 소품 경로는 보존한다.
- 첫 편지 대조에서 0장 상세·읽는 쌍·구 저장 모두 X·Esc·조사 계속으로 13호실에 복귀한다. 메모에서 재개하며 읽기·선택 상태를 보존한다. 취소·재열기는 시간을 소모하지 않는다.
- 나란히 읽은 두 장은 ‘이 두 장 비교’로 명시 제출한다. 잘못 고른 쌍은 기존 판정으로 보낸다. 빈쌍·중복·미소유 자료는 제출하지 않는다.
- 편지 그림 위 겹치던 빨간 구역 글자를 공유 관찰 버튼 네 개로 분리했다. 휴대폰에서 버튼을 한 줄로 묶어 원문 공간을 확보했다.
- 도토리 차이를 찾기 전 비교의 목적을 밝히고, 발견 후 글쓴이를 확정할 수 없다는 판단과 초롱에게 엄마 소식을 물을 이유를 잇는다.

정답·기회·생사·진상·결말 판정은 바꾸지 않았다.

## 검증

최종 검사·실제 웹 화면 결과는 [검수 기록](../reviews/opening-room-20261108/검수.md)에 남긴다. 이번 범위의 준비된 장면을 확인했으며 14일 전체 연속 플레이는 수행하지 않았다.
