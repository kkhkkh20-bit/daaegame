# 0.18.49 — 접어 보는 생각과 이동·기록 UX

## 화면에서 달라진 점

- 현장 상단의 상시 목표/의문 두 줄을 없애고 하단 기록 왼쪽에 ‘생각’을 둔다. 누르면 양피지 창에 현재 의문과 조사 메모 색인을 보여 준다. 새 의문은 작은 점으로만 알리며 자동으로 펼치지 않는다. 읽은 의문은 이번 플레이의 저장에만 남는다.
- 초반 여관 의문은 ‘편지는 이곳에서 왔다. 그런데 아내는 어디에 있을까.’로 표시한다. 목적지를 지시하거나 해답을 자동 선택하지 않는다.
- ‘큰 목록 보기’를 제거한다. 예전 저장의 목록 보기 설정도 무시한다. 마을은 기존 그림 지도, 여관은 기존 장소 해금 조건을 통과한 장소만 1층/2층 카드로 표시한다. 숨은 통로는 기존 발견 조건을 그대로 적용한다.
- 장소 선택은 미리보기만 바꾸며 이동 확정을 따로 누른다. 현재 위치는 이동 버튼 대신 상태로 표시한다. 지도 이름표 폭을 늘려 긴 장소명이 줄바꿈되지 않도록 한다.
- 질문 목록 바로 아래에 ‘보여주기’를 배치하고 기록은 현장/질문/대사에서 우하단 위치를 맞춘다.
- 제시 화면은 직접 자료를 선택하기 전까지 선택 표시와 확정 동작을 비활성화한다. 비교에서 제시로 넘어가면 비교한 소유 자료를 먼저 배치하되 자동 선택하지 않는다. 원래 대화의 제시 진입 동작을 사용한다.
- 달력·아이템을 기록 내부 페이지로 통일한다. 빈 아이템 가방에서 미래 퍼즐 해법/보상을 노출하지 않는다.
- 새 자료 알림은 좌상단으로 옮겨 지도 버튼을 가리지 않는다. 지도·기록·일거리 등 모달 창에서는 알림 그림을 감추되 (책상에서 획득한 메모는 기존처럼 확대 화면·아이템 가방 위에 표시), 원래 알림 수명은 유지한다.
- ‘조사’는 가짜 버튼 대신 상태 표시로, 조사 대상 도움말은 포인터 근처로 표시한다.
- 증언/대화 아이콘 실루엣을 구분한다. 생활 화면은 종이 틀로 통일하고 일거리 행의 중복 비용·시간 설명을 줄인다. 기존 작업 전 비용/시간 확인은 유지한다.

## 변경하지 않은 것

사건 조건, 날짜 진행, 경제 수치, 기존 장소 해금, 관심 표시 기능은 유지한다. 0.18.48 저장·대화 건너뛰기 개선과 0.18.47 그림책 연출 및 다른 개발자의 타이틀 작업을 병합했다.
