# Room13 0.20.6

UI 리뷰 문서(자료 화면 겹침·모바일 가독성)의 항목을 반영했다.

- 자료 화면의 첫 탭이 제목 폭 뒤에서 시작한다. 「자료 기록」「보여주기」 제목이 탭 아래로 가려지지 않는다.
- 왼쪽 자료 목록의 이름은 칸 폭에 맞춰 최대 두 줄로 나누고, 넘치면 말줄임한다. 전체 이름은 가운데 제목에 나온다.
- 자료가 하나도 없으면 "아직 모은 자료가 없습니다."만 나온다. 분류 결과만 없으면 기존 안내를 쓴다. 고를 것이 없을 때는 "자료를 선택하세요"와 빈 스크롤바를 표시하지 않는다.
- 휴대폰 자료 창의 큰 글씨 반영은 0.20.5에서 이미 적용했다. 설정창 글씨·버튼 확대는 배치가 바뀌므로 시안 승인 뒤에 적용한다.
