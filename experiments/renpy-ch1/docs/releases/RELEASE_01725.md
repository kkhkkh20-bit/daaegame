# 0.17.25-dev · 2026-10-14

0.17.24에서 '확인이 필요한 점'으로 남긴 세 가지를 확인하고 처리했다.

## 1. 마차 안 색감
- 문제: 빈 마차 그림이 가을 장면이라 실내가 주황빛이었다. 창밖 겨울 풍경과 맞지 않았다.
- 처리: 실내(창 밖 영역 제외) 색 분포를 지금 쓰는 겨울 마차 그림(room13-pixel-carriage-morning)의 나무·좌석·벽 부분에 맞췄다. 채널별 평균과 표준편차를 옮기는 방식이다. 주황기가 빠지고 기존 마차 그림과 같은 갈색 톤이 됐다.
- 재현 스크립트: `dev/make_carriage_empty_winter.py`. selected_asset_overlay.json의 해시도 갱신했다.

## 2. 다람이 '기쁨' 표정
- 원인: 다람이 대화용 정면 초상화는 기본·생각·걱정·말하기 4종뿐이다. '기쁨'은 '말하기' 초상화로 대체됐는데, 이 그림은 미간을 찌푸리고 손가락을 드는 모습이다.
- 처리: 이미 검수된 다람이 기쁨 자세(room13-pixel-world-family-extra-gray, 눈 감고 웃는 모습)의 상반신만 잘라 대화용 그림을 만들었다(`assets/room13-pixel-dialogue-daram-joy.png`). 가장자리의 반투명 어두운 번짐은 지웠다.
  - room13-portraits.json에 daram `joy`로 등록했다.
  - 영향 범위: 마차 장면 2줄과 기존 연출 지시 1곳. 다른 인물의 기쁨 처리는 그대로다.
- 재현 스크립트: `dev/make_daram_joy_bust.py`.
