# 다람탐정 0.20.104 — 자료 읽기와 결말 기록

소유자가 플레이 후기의 자료 읽기·조사·결말 표시 개선 시안을 확인하고 승인해 본편에 적용했다.

- 자료 상세의 그림을 줄이고 본문 폭을 넓혀 관찰 사실이 먼저 보이게 했다. 필요한 그림은 따로 확대한다. 체크는 선택, 이름은 읽기라는 안내를 처음 한 번 표시한다.
- PC에서 휴대폰 폭으로 바뀔 때 발언을 한 번 접어 큰 글씨의 자료 본문이 밀려나지 않게 했다. 발언은 다시 펼칠 수 있다.
- 13호실 메모·보따리 주변 클릭에 사방 10px 여유를 더했다. 기존 획득 순서와 휴대폰 메모의 최소 클릭 크기를 유지한다.
- 결말 첫 화면에는 마지막 그림과 결말 이름을 남긴다. 기존 인원 집계와 명단은 「여정의 기록 보기」로 펼친다. 저장·메인 복귀와 집계 계산은 그대로다.
- 입구 편지 추가 제출 시험이 예전 대사를 찾던 문구를 현행 원문으로 맞췄다. 수정 전에는 마지막 문구 검사만 실패하고 그 앞의 상태 검사는 통과하는 것을 재현했다.

결말·생사·정답·자료의 관찰 사실 문장은 바꾸지 않았다. 14일 전체 연속 플레이는 이번 검증 범위에 포함하지 않는다. 후반 화면은 해당 상태를 준비한 부분 시험이다.

관련 검증의 범위와 결과는 [검수 기록](../reviews/읽기개선_20261105.md)에 적었다. 시안 단계에서 단위 1,239개·lint·관련 네이티브 4개와 PC/휴대폰 실제 입력 검사를 통과했다. 승인 뒤 0.20.104 공개 묶음에서도 판 번호 일치·강화한 PC/휴대폰 화면 검사·PC/휴대폰 저장→새로고침→불러오기를 통과했다. 날짜·장소·시간대 복원 일치, 페이지 오류 0건.
