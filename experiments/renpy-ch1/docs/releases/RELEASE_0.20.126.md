# 0.20.126 — 누비 작화 통일과 행동 장면 보강

주민 작화 검수에서 누비의 큰 계단형 윤곽과 콩이·다람의 매끈한 대화 원화 사이에 차이를 확인했다. 누비의 일반 여섯 표정을 같은 원화 기준으로 다시 제작했다. 정면 시선, 노랑 코트·크림 앞치마·초록 머플러·세탁 도구, 질문 화면의 발선과 기존 대화 키를 유지한다. 원본과 감정별 파일을 보존하며 일반·질문·회의가 같은 새 표정 세트를 사용한다.

7일차 자백 직전에는 누비가 젖은 행주를 접어 쥔 손을 보여 주고 다음 발언에서 얼굴로 돌아온다. 손과 의상은 새 대화 원화와 맞췄다. 회의 무대가 이 장면 그림을 덮지 않도록 새 행동 컷에만 예외를 적용했다. 회의 정보와 대사 조작은 유지한다.

다람의 손을 떼려는 사람의 손목을 아빠가 잡는 후속 장면에도 시점 손·소매의 짧은 컷을 연결했다. 아빠의 얼굴과 몸은 그리지 않는다. 이 장면은 현재 공개 1부 종료 뒤의 S04 경로에 있으므로 1부에서 새로 볼 수 있는 장면으로 세지 않는다. 1부 종료·후속 잠금은 유지한다.

이번 작화 교체 범위는 누비 여섯 표정이다. 현장 인물 전체나 모든 주민의 작화 통일 완료를 뜻하지 않는다. 현장 도트의 배치·키·작업 자세, 기존 대사·진상·자료·판정·생사·결말은 바꾸지 않는다. 새 후기 그림은 필요할 때 받는 기존 로딩 방식을 따른다.

검증과 PC·휴대폰 화면은 [적용 검수](../reviews/visual-fixes-20261108/검수.md)를 따른다.

전체 단위1,475개·관련 엔진 경로7개·lint·대사 논리 A/B/C 0건·공개 묶음 검사를 통과했다. 웹에서는 실제 행주 컷의 PC·휴대폰 표시와 저장·새로고침·이어하기 복원을 확인했다. 첫 로딩 증가는12,436바이트이며 새 후기 그림8장은 지연 로딩을 유지한다.
