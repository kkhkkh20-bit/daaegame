# 대화 UI — 사용자 제공 역전재판 레퍼런스 적용

현재 기준은 사용자가 제공한 대화/선택 화면 이미지다.
- 대화: 중앙 인물 상반신 확대, 머리 상단 y=48. 까로는 전신 원본에서 확대하므로 하단이 중간에서 끊겨 보이지 않는다.
- 대화창: 전체 폭 1280, 기본 y=506/h=174, 큰 글자 y=454/h=226. 진한 남색 반투명. 본문 x=220. 이름은 왼쪽의 작은 청록색 표식.
- 선택: 같은 인물 위치/배율 유지. 중앙 폭 470의 파란 가로줄, 왼쪽 밝은 사선, 금색 hover 테두리. 이미 물었던 질문은 체크와 취소선.
- 조작: 대화/선택에서는 우측 하단의 작은 돌아가기/제시/기록/옵션 문구. 현장 조사에서는 기존 작은 조사/제시/기록과 우측 옵션 유지.
- 날짜/장소 HUD는 대화/선택 동안 숨기고 현장에 복귀하면 표시한다.
- 질문 목록과 대사 사이에 인물을 옆으로 움직이거나 다시 확대하지 않는다.

관련 파일: screens.rpy, room13_screens.rpy, systems/room13_reference_ui.rpy, room13_acting.rpy, room13_rules.rpy.
검증: Ren'Py lint, dev/qa_center_ui.py. 스크린샷과 결과는 qa-room13-center-ui/.

기본 전신: art/pixel-b/portraits/room13-pixel-karo-fullbody.png. 원본과 기존 마을 활동 그림을 보존했다. 현재 대화 표정들은 기본 전신 한 장을 공통 사용하며 개별 전신 표정 제작은 후속 작업.
이 UI는 로컬 후보에 반영. 공개 게임 배포는 별도 상태다.

선택지 세로 정렬: 실제 글줄 렌더 높이와 행 간격을 합산하여 하단 조작 영역을 제외한 화면 중앙에 배치한다. 최대 높이 382 안에서 스크롤.
