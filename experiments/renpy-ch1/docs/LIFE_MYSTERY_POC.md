# 생활 추리 PoC — 2026-10-13

## 검증할 재미
일을 하며 사람과 공간을 알아간다 → 직접 관찰한 사실로 질문을 만든다 → 자료를 제시해 엄마의 다음 행적을 알아낸다. 노동 완료가 정답을 자동 지급하지 않는다.

## 구현 범위
- 새 게임: 마차 → 고장 확인 → 간단한 입장 → 여관 → 13호실. 첫날 이동은 여관 접수대/복도/방으로 제한.
- 첫날: 엄마 메모(M01)와 이불(E03)을 읽고 확보한 뒤 직접 자기. 숙식 무료. 다람이와 다음 날 수소문을 약속.
- 편지는 기존 정본의 '할머니가 보낸 편지' 유지. 엄마가 돌아오지 않아 가족에게 연락했다는 이유를 첫 대화에서 밝힘. 엄마가 쓴 초대장/위조 편지는 이번 구현에 도입하지 않음.
- 둘째 날: 입구 까로에게 귀환을 질문하면 겨울 운행 중단과 일거리 안내. 첫 질문까지 까로는 입구에 있음.
- 일자리: 식사 준비 4냥 / 소포 배달 5냥 / 부품 정리 6냥. 오전·오후만 가능, 같은 일을 같은 날 반복 불가.
- 일 도중 관찰 질문을 선택하면 사건 기반 관계 기록. 일반 완료에는 돈만 지급.
- 배달 주소를 관찰하면 다음 날부터 두 건 동시 배달 10냥을 한 번 이용 가능. 끈은 구매하거나 까로에게 빌림. 구매 필수 아님.
- 숙식비: 첫날 무료, 이후 10냥. 자기 이후 날짜가 바뀌기 직전에 차감. 부족액 외상. 중복 정산 방지. 돈이 없어도 잠자기 가능.
- 상점: 구운 밤 2냥(방에서 다람이와 대화하며 소비), 묶음끈 3냥. 같은 물건 중복 구매 방지.
- 기록: 수입/구매/숙식/외상 상환을 날짜별 장부에 저장. 다음 회차에는 돈/관계 초기화.
- 엄마 메모를 할머니/나비에게 제시하면 초롱이라는 사람을 알게 됨. 기존 E03 제시 경로도 유지. 초롱의 후속 봉투는 기존 3일차 조건 유지.
- 숨은 출입구는 엔딩 이후 새 게임에서만 조사 가능. 초반 엄마 찾기와 분리.

## 모듈 경계
- `game/systems/room13_livelihood_model.rpy`: 순수 상태 전이, 일당, 구매, 외상, 일별 정산. Ren'Py UI에 의존하지 않음.
- `game/systems/room13_livelihood_flow.rpy`: 대사, 관계 분기, 다음 날 정산 연결.
- `game/systems/room13_livelihood_ui.rpy`: 일거리/상점/장부 화면.
- `game/systems/room13_first_day_flow.rpy`: 새 게임 첫날 동선, 엄마 메모, 초기 목표.
- 기존 `room13.rpy`/`room13_screens.rpy`: 진입점만 연결. 기존 캠페인 전체를 동시에 재작성하지 않음.

## 저장 정책
`room13.livelihood` 안에 지갑/장부/관계/일 기록 저장. 기존 저장에 값이 없으면 읽기 시 기본값 사용. 새 첫날 동선은 `life_poc`가 있는 새 게임만 적용. 기존 저장에는 숙식비를 소급 청구하지 않음. 일거리 안내를 받은 기존 저장은 그날부터 정산 참여.

## 밸런스 가설
4+6=10, 5+6=11, 4+5=9. 어느 날은 1냥 외상, 어느 날은 저축. 연계 배달은 +5냥의 일회성 여유를 만든다. 무한 보너스 없음. 외상으로 막히지 않지만 장기 부채가 계속 쌓이면 후속 의뢰/임금 조정이 필요하다.

## 정보 기록 연결 보강
- 식사 준비에서 그릇을 질문하면 나비의 후속 대화가 열린다. 그 대화를 끝까지 읽어야 J01 증언을 얻는다.
- M01+J01을 기록에서 선택해 비교할 수 있다. 두 자료가 모두 있어야 하며 비교 자체는 새로운 증거를 지급하지 않는다.
- J01은 나비의 증언으로 분류되고 발언자 초상이 연결된다. 초롱에게 제시하면 엄마가 남긴 글/물건을 확인해 달라는 반응을 얻는다.
- 함께한 일 탭에서 관계 변화의 원인이 된 사건들을 확인한다. 호감도 숫자는 표시하지 않는다.
- 의뢰인이 현재 캠페인 상태에서 등장할 수 없으면 일을 시작할 수 없다. 오후/저녁 및 오늘 완료 상태도 게시판에 표시한다.
- `room13_work_clues.rpy`가 증언/비교/제시와 일거리 이용 조건을 담당한다.
