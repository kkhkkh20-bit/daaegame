# 그림 제작 요청 모듈

정적 포털: `index.html`. 프로젝트 폴더에서 `python3 -m http.server 8788`을 실행하고 `http://127.0.0.1:8788/docs/art-requests/`를 연다.

- 기본 목록은 전용 그림 미납품 10건과 납품·제작 필요 확인 6건이다. 원탁 1번 묶음은 받은 ZIP을 먼저 확인하며, 같은 그림을 다시 제작하도록 지시하지 않는다.
- 납품·연결됨 3건, 납품·등록됐으나 장면 미연결 2건, 납품·검토 후보 4건, 선택 추가 3건도 별도 필터로 볼 수 있다.
- 검색, 상태/종류 필터, 개별 요청 MD·JSON 다운로드와 전체 MD·JSON·CSV 다운로드를 제공한다. 외부 송신·그림 생성·게임 연결 변경은 수행하지 않는다.
- 전체 문서는 대조 이력을 함께 담으므로, 제작자에게 전달할 때 각 항목의 상태를 먼저 읽는다. 이미 있는 그림과 정책상 빈 얼굴을 새 미납품으로 세지 않는다.

## 갱신

편집 원본은 `manifest.json`이다. 파일을 받았으면 실제 등록/장면 호출을 확인하고 status·sources·references를 갱신한 뒤 프로젝트 폴더에서 아래 명령을 실행한다.

```
python3 dev/art_requests.py
python3 dev/art_requests.py --check
```

생성기는 모든 근거 경로의 존재를 검사하고 이미지 크기·모드·투명 픽셀 유무를 실측한다. 새 파일이 존재한다고 자동으로 납품 완료나 실제 적용 완료로 바꾸지는 않는다. 적용 검수 결과는 사람이 manifest에 기록한다.

안정 ID는 납품 파일 이름과 별개다. 기존 요청의 ID를 재사용하고, 제목을 바꾸더라도 ID를 바꾸지 않는다. 납품 원본은 기존 파일을 덮어쓰지 않고 별도 폴더로 받는다. 최종 캔버스가 미확정이면 참고 원본의 실측을 확정 규격이라고 전달하지 않는다.
