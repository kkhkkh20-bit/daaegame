다람탐정 그림 제작 요청

현재 요청서와 실제 파일·연결 코드의 대조입니다. 미납품과 미연결을 구분하며, 이미 받은 그림을 다시 만들지 않습니다.

전체 JSON전체 CSV문서로 보기

전체 문서에는 납품 완료·미연결·후보 대조 이력도 포함됩니다. 개별 요청을 전달하기 전에 상태와 규격 확인 사항을 읽어 주세요. 외부 전송은 수행하지 않습니다.

편집 원본 manifest.json → python3 dev/art_requests.py 로 재생성합니다. 현행 실측은 참고 원본 크기이며, 새 시안의 최종 캔버스를 자동 확정하지 않습니다. 아빠·지문 얼굴 등 정책상 비운 슬롯은 요청에서 제외합니다.
