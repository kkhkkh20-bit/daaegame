# 그림 제작 요청서

2026-10-29 현재 파일·등록 코드 대조. 이 문서를 외부에 전달하거나 그림을 생성하지 않았다.

요청서와 현재 파일·연결 코드의 대조 스냅샷. 외부 제작 요청/그림 생성은 실행하지 않는다.

## 중복 요청 방지

- 아빠·지문의 얼굴과 중립 얼굴 등 정책상 빈 슬롯은 미납품 요청으로 세지 않는다.
- 미연결은 미납품이 아니다. 파일 존재·등록·실제 장면 호출을 구분한다.
- 이미 받은 ZIP에 원본이 있는지 확인할 항목은 확인 필요이며 중복 제작하지 않는다.
- 화면 시안과 캔버스가 불명확하면 제작 전에 적용 담당자에게 확인한다.

## 현황

- 전용 그림 미납품: 6건
- 납품·제작 필요 확인: 0건
- 납품·연결됨: 43건
- 납품·등록 / 장면 미연결: 3건
- 납품·검토 후보: 4건
- 선택 추가 / 승인 확인: 2건

기본 제작 검토 목록은 전용 그림 미납품과 납품·제작 필요 확인 항목이다. 납품된 배경/자료/인물은 아래 대조 이력에 남기며 새 제작 요청에서 제외한다.
