# 근접 대화 도트 원본 요청서 (CLOSEUP-DOT, 2026-10-27)

## 왜 필요한가

대화 근접 그림(대사창 위 상반신·전신)은 도트판 `dialogue-dot-v2`(168칸 높이)를 3~4px 칸으로 늘려 그린다. 배경은 1칸=1px 이라
인물만 3배 거친 격자로 보였다(소유자 2026-10-27 "이게 말이 되는 도트 화소니?"). 지금은 임시로 붓 원본(`dialogue-source-master-v2`)을
같은 자리에 그린다(`R13_CLOSEUP_SMOOTH`). 현장 도트(1칸=1px)와 재질을 맞추려면 근접도 1칸=1px 로 다시 찍은 도트가 필요하다.

## 규격

- **크기(2026-10-27 정정)**: **1칸 = 1px, 인물 키는 현행 760 도트판의 3배 칸 수** — 어른 630칸(210도트×3), 덩치(까로 등) 690칸, 노인 585칸, 부리 555칸, 아이(다람) 495칸, 도담 396칸. 인물별 칸 수는 답변 묶음 `04_근접_840/closeup_840_프로필_위치표_228.csv` 의 실측값을 따른다. 처음 적었던 「어른 840px·다람 714px」는 어느 파일에도 없는 값이라 폐기한다(840 은 대사창 높이 프로필 이름이다).
  세 높이(560·760·840 프로필)는 한 원본에서 정수 비율로 줄여 쓸 수 없으므로(칸이 깨짐) **위 칸 수 한 벌만** 받는다. 실행 중 840 프로필이 그리는 파일이 760 도트판이므로 그 자리를 새 그림으로 바꾼다.
- **대상**: 대화 도트판이 있는 38명 x 6감정(neutral·joy·anxious·angry·flustered·surprise_talk) = 228장. 우선 **P1 = 다람·아빠·돌목·할머니·너울·까로·나비·초롱(8명 48장)**.
- **구도·발 위치**: 현행 760 도트판(`assets/dialogue-dot-v2/<인물>/760/<감정>.webp`)과 같은 발끝 위치. 캔버스는 인물 밖 여백 4px 이내 투명이고 위치는 우리가 계산한다(파일 안 발끝 y 만 CSV 로 함께 준다). 머리 상자 확정값은 없다(bbox 위 35% 추정).
- **팔레트**: 그 인물 대화 평온 그림 48색. 외곽 두 단계(완전 불투명/투명), 흰 테두리 스티커 없음, 그림 안 글자 없음.
- **파일**: `room13-closeup-<인물id>-<감정>.png` + 대응표 CSV. 기존 파일 덮어쓰지 않는다.
