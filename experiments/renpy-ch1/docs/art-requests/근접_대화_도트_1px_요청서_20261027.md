# 근접 대화 도트 원본 요청서 (CLOSEUP-DOT, 2026-10-27)

## 왜 필요한가

대화 근접 그림(대사창 위 상반신·전신)은 도트판 `dialogue-dot-v2`(168칸 높이)를 3~4px 칸으로 늘려 그린다. 배경은 1칸=1px 이라
인물만 3배 거친 격자로 보였다(소유자 2026-10-27 "이게 말이 되는 도트 화소니?"). 지금은 임시로 붓 원본(`dialogue-source-master-v2`)을
같은 자리에 그린다(`R13_CLOSEUP_SMOOTH`). 현장 도트(1칸=1px)와 재질을 맞추려면 근접도 1칸=1px 로 다시 찍은 도트가 필요하다.

## 규격

- **크기**: 근접 그림은 화면에서 어른 키 약 840px(아이 다람 714px, 760·560 높이 판도 쓴다). **1칸 = 1px** 이므로 어른 840칸 높이 원본.
  세 높이(560·760·840)는 한 원본에서 우리가 정수 비율로 줄여 쓸 수 없으므로(칸이 깨짐) **840 한 벌만** 받고 560·760 은 붓 원본을 그대로 둔다.
- **대상**: 대화 도트판이 있는 38명 x 6감정(neutral·joy·anxious·angry·flustered·surprise_talk) = 228장. 우선 **P1 = 다람·아빠·돌목·할머니·너울·까로·나비·초롱(8명 48장)**.
- **구도·발 위치·머리 위치**: 현행 붓 원본 840 판(`assets/dialogue-source-master-v2/<인물>/840/<감정>.webp`)과 같은 캔버스·같은 발끝·같은 머리 상자. 대응표 `game/assets/room13-dialogue-talk-art.json` 의 offset·anchor 를 그대로 쓴다.
- **팔레트**: 그 인물 대화 평온 그림 48색. 외곽 두 단계(완전 불투명/투명), 흰 테두리 스티커 없음, 그림 안 글자 없음.
- **파일**: `room13-closeup-<인물id>-<감정>.png` + 대응표 CSV. 기존 파일 덮어쓰지 않는다.
