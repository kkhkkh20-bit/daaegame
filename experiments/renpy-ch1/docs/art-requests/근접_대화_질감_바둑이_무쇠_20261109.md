# 바둑이·무쇠 근접 대화 질감 확인 요청

2026-11-09, 0.20.142 실제 1부 연속 플레이의 시각 검수 후속이다. 이 문서는 기존 `CLOSEUP-DOT` 요청의 두 인물을 구체화한다. 같은 제작을 두 번 발주하는 요청이 아니다. 외부 전송·새 그림 생성·게임 그림 교체는 하지 않았다.

현재 상태는 **납품·제작 필요 확인**이다. 저장소 원본·납품 기록·에셋 도구함에서 아래 조건을 모두 만족하는 묶음을 찾지 못했다. 소유자가 따로 받은 원본 ZIP까지 모두 없다고 확인한 것은 아니므로, 받은 원본을 먼저 확인한다. 그 뒤에도 없을 때 제작 대상으로 확정한다.

## 확인한 문제

실제 같은 대화 모드에서 밤이·나비의 계단식 픽셀 윤곽과 바둑이·무쇠의 매끄러운 선이 함께 쓰인다. `dialogue-source-master-v2`라는 같은 경로 계열이라고 원화 질감까지 같은 것은 아니다.

시각 기준은 다음 보유 원본이다. 그림의 정체성과 소품은 각 인물의 현재 그림을 우선한다.

- 질감 기준: `game/assets/dialogue-source-master-v2/bami/760/neutral.webp`
- 질감 보조 기준: `game/assets/dialogue-source-master-v2/nabi/760/anxious.webp`
- 바둑이 현재 역할: `game/assets/dialogue-source-master-v2/resident_badook/840/neutral.webp`
- 무쇠의 단서·표정: `game/assets/dialogue-source-master-v2/resident_musoe/840/anxious.webp`

작업 중 실제 화면 기록은 `/workspace/work/full142/화면리뷰.json`과 `/workspace/work/fix143/그림후보.json`이다. 작업 중 절대 경로는 제작 포털의 휴대 가능한 참조로 등록하지 않는다. 포털에서는 아래 보유 원본과 연결 코드를 근거로 참조한다.

## 바둑이

안정 ID: `CLOSEUP-DOT-BADOOK-143`.

정면 대화 전신 6표정 `neutral`, `joy`, `angry`, `anxious`, `flustered`, `surprise_talk`을 같은 질감으로 맞춘다. 달마시안의 무늬·제복·모자·망토·기록판·연필을 현재 기준으로 보존한다. 양눈이 플레이어를 보고, 표정이 바뀌어도 머리·어깨·발 기준이 튀지 않아야 한다.

보유 `dialogue-dot-v2/resident_badook`은 6표정이 있지만 3px 재샘플링 파생본으로, 현재 얼굴을 더 거칠게 만들 수 있다. `canonical48-rev45`의 기본 그림은 픽셀 표현이 분명하지만 단일 표정·등불 자세이며 현재 기록판 자세와 다르다. 주변 유색 잔상도 보여 기본 그림 한 장만 즉시 대체하는 품질을 충족했다고 판단하지 않았다. 반신 4표정 시트는 전신 6표정 대체가 아니다.

## 무쇠

안정 ID: `CLOSEUP-DOT-MUSOE-143`.

정면 대화 전신 6표정을 맞추되, 5일차의 불안한 얼굴과 **‘솜이’가 적힌 손바닥**을 함께 보존한다. 이 글씨는 손녀 이름을 기억하려는 의도된 이야기 소품이다. 일반적인 ‘그림 안 글자 금지’에서 이 손글씨만 예외이며, 다른 인명·안내·정답을 추가하면 안 된다.

보유 `dialogue-dot-v2/resident_musoe/760/joy.webp`에는 손글씨가 있다. 그러나 웃는 얼굴이고, `anxious`에는 손글씨가 보이지 않는다. 따라서 웃는 그림을 불안한 대사에 붙여 해결하지 않는다. `canonical48-rev45`는 단일 기본 표정에 두루마리를 쥐고 있어 이 역할을 충족하지 못한다. 불안 표정·손글씨·현 복장·정면 시선·픽셀 질감을 동시에 만족하는 6표정 묶음의 납품 여부를 확인해야 한다.

## 납품·인수 기준

- 먼저 기존에 받은 ZIP과 대응표를 확인한다. 이미 받은 동일 역할 그림이 있으면 중복 제작하지 않는다.
- 원본 PNG, 투명 무손실 WebP, 인물·표정·파일·크기·머리/발 기준 대응표를 받는다.
- 현재 840 프로필의 인물 비율·배치·머리/발 기준을 유지한다. 파일 이름의 숫자가 원본 캔버스 높이와 같다는 가정은 하지 않는다. 현재 실측은 레퍼런스이며 최종 원본 캔버스는 연결 담당자와 확정한다.
- 픽셀을 크게 늘리거나 일괄 필터로 다시 찍은 결과를 새 도트 원본으로 납품하지 않는다. 밤이·나비 기준과 실제 표시 크기에서 윤곽·선 굵기·명암 밀도를 나란히 확인한다.
- 흰 테두리·불투명 배경·후광·유색 잔상·잘린 귀/손/꼬리/발이 없어야 한다.
- 기본 표정만 승인해 나머지 다섯 표정의 질감 차이를 남기지 않는다.
- 무쇠는 불안 표정으로 손글씨가 보이는 실제 5일차 대사를 필수 인수 장면으로 삼는다.
- 납품 후 PC·휴대폰의 일반 대화와 해당 회의, 저장 복원에서 얼굴·소품·대사판 가림을 확인한 뒤 연결한다.
- 기존 게임 파일은 덮어쓰거나 삭제하지 않는다.

현재 두 인물의 질감 통일은 **미해결**이며, 요청 등록을 게임 적용 완료로 보고하지 않는다.
