## 2일 저녁 — 피코 살리기 (설득과 제시)

살리는 건 선택지 하나가 아니다. **피코를 움직이고, 나비를 움직여야 한다.** 둘 다 증거나 관계가 필요하다.

### 광장 — 피코를 움직이기 ⏱
```
아빠: 오늘 밤은 다른 데서 자는 게 어떻겠습니까.
피코: 동정은 사양할게요. 여기가 제일 따뜻하다니까요.
```
- `▶ 제시: 톡의 등 장부` *(2일 오전 수리점에서 얻음)*
  ```
  아빠: 수리공 톡 씨 장부입니다. 이 3번 등, 요 며칠 밤마다 깜빡인답니다.
  피코: ……3번이면 내가 자는 등인데.
  피코: (등을 올려다보며) 그러고 보니 어젯밤엔 새벽에 손이 좀 시렸어요.
  피코: 알았어요. 근데 갈 데가 없어요. 방값이 없으니까.
  ```
  → 나비에게로.
- `▶ 제시: 다른 것` → 피코 "그게 뭐요? 나 그림 그려야 해요." (실패, 칸만 쓴다)
- `▶ 그냥 설득한다` → 피코 "괜찮다니까요. 등이 손을 데워 준다니까." (실패)

### 여관 식당 — 나비를 움직이기
```
나비: 그림쟁이 아저씨를 여기서요? 할머니가 아시면 큰일 나요.
```
- 조건 `nabi_helped`(2일 이전에 나비의 식사 준비를 도왔다): 
  ```
  나비: ……손님은 제 일 도와주셨으니까요. 식당 의자라도 괜찮다면요. 불 꺼진 뒤에만, 새벽엔 꼭 나가야 해요.
  ```
  `[깃발] piko_sheltered`
- 조건 `piko_portrait`(엄마 초상을 맡겼다)일 때 다른 길: `▶ 제시: 피코가 그리는 엄마 초상`
  ```
  아빠: 이 사람이 제 아내를 그려 주고 있습니다. 아내를 찾는 데 꼭 필요한 그림이에요.
  나비: ……손님 부인을요? (잠시) 오늘 하루만이에요.
  ```
  `[깃발] piko_sheltered`
- 둘 다 없으면: 나비 "죄송해요. 저도 여기서 쫓겨나면 갈 데가 없어요." (실패)

- 공략 메모: 피코를 살리려면 **2일 오전에 수리점(톡의 등 장부)** + **1~2일에 나비의 식사 준비를 돕거나 2일 오후에 초상을 맡기기**가 모두 필요하다. 2일 하루를 이 순서로 써야 한다.
