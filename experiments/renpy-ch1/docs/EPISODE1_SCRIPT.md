## 한눈에 — 무슨 일이 있었나 (정답)

1. 광장 등은 안에 든 **따뜻한 돌 조각** 덕분에 빛나고 따뜻하다.
2. 2일 밤, 진료소의 견습생 **우박**이 선생님 심부름으로 3번 등을 열어 **온도만 재고**, 조각은 제자리에 돌려놨다.
3. 같은 밤 늦게, 빚에 몰린 짐꾼 **실룩**이 3번 등을 다시 열어 **조각을 훔쳤다.** 훔친 조각은 백 부인에게 팔았다.
4. 등이 식었고, 그 밑에서 자던 그림쟁이 **피코**가 얼어 죽었다.
5. 3일 밤, 실룩은 기록실 난로의 조각도 훔쳤다. 그 방을 지키던 **사서 선생님**이 얼어 죽었다.
6. 그리고 우박이 잰 숫자는 또 하나를 말한다. **마을의 돌 자체가 식고 있다.** 그래서 조각이 비싸지고, 사람들이 훔친다.

## 2일 저녁 — 피코 살리기

피코 본인과, 재워 줄 사람(나비)을 **둘 다** 움직여야 한다.

**광장 — 피코에게** ⏱
```
피코: 동정은 사양할게요. 여기가 제일 따뜻하다니까요.
```
- `▶ 보여 준다: 톡의 등 장부`
  ```
  아빠: 수리공 톡 씨 장부입니다. 이 3번 등이 요즘 밤마다 깜빡인답니다. 오늘 밤 꺼질지도 몰라요.
  피코: ……3번이면 내가 자는 등인데. (등을 올려다본다) 그러고 보니 어젯밤 새벽에 손이 시렸어요.
  피코: 알았어요. 근데 갈 데가 없어요.
  ```
- 다른 것을 보여 주거나 그냥 말로만 하면: 피코 "괜찮다니까요." (실패)

**여관 식당 — 나비에게**
```
나비: 그림쟁이 아저씨를 여기서요? 할머니가 아시면 큰일 나요.
```
- 나비의 식사 준비를 도운 적이 있으면: 나비 "손님은 제 일 도와주셨으니까요. 불 꺼진 뒤에만요." → **피코가 산다**
- `▶ 보여 준다: 피코가 그리는 엄마 초상` → 나비 "손님 부인을요……? 오늘 하루만이에요." → **피코가 산다**
- 둘 다 없으면: 나비 "죄송해요. 저도 쫓겨나면 갈 데가 없어요." (실패)

`[단서] 빈 난로`

**(살린 경로)** 사서 "밤에 누가 창으로 들어왔어요. 장작이 있어서 버텼어요. 얼굴은 못 봤지만, 허리에 【노끈】을 감고 있었어요." `[단서] 사서의 말`

## 4일 이른 아침 — 아랫길, 실룩

```
(지문) 짐꾼 실룩이 짐을 묶고 있었다. 갈색 노끈, 한쪽 끝이 뜯겨 있었다.
실룩의 아이: 아빠가 빵 사 왔어요! 진짜 빵이에요!
```
- `▶ 노끈을 본다` → 등 뚜껑에 걸려 있던 것과 같은 끈이다. `[단서] 실룩의 짐 끈`
- `▶ 아이에게 묻는다` → 아이 "아빠가 어젯밤 늦게, 손이 꽁꽁 언 채 들어왔어요." `[단서] 아이의 말`
- `▶ 실룩에게 빚을 묻는다` → 실룩 "백 부인한테 진 빚, 다음 달까지 못 갚으면 애들을 그 집 일꾼으로 보내야 하오."

## 4일 이른 아침 — 백 부인 창고

```
(지문) 창고 안쪽 상자에서 초록빛이 새어 나왔다. 손을 대니 사람 손처럼 따뜻했다. 등 조각들이다.
백 부인: 사고판 것뿐이에요. 요즘 온기가 얼마나 귀한지 아세요?
(지문) 조각 하나를 뒤집어 보니 밑에 작은 이름표. 톡의 글씨로 '광장 3'.
아빠(생각): 톡은 고친 조각마다 이름표를 붙인다. 이건 피코가 잠든 그 등의 조각이다.
```
`[단서] 이름표 붙은 조각`

## 4일 아침 — 광장, 회의

```
(지문) 톡이 묶인 채 돌 앞에 서 있었다. 사람들 틈에 실룩의 아이 둘이 빵 봉지를 쥐고 서 있었다. 백 부인은 맨 앞줄에 앉았다.
너울: 그림쟁이가 죽었소. (사서가 죽었다면) 기록실 선생도 죽었소. 오늘 끝냅시다.
```

| # | 상대의 말 | 보여 줄 단서 | 그 뒤 |
|---|---|---|---|
| 1 | 너울 “3번 등을 연 건 【톡】이오. 등 여는 사람은 톡뿐이니까.” | 숫자 쪽지 또는 뚜껑의 노끈 | 숫자 쪽지는 측정한 흔적일 뿐 그 사람이 톡이라는 증거는 아니라는 반박. 대여 사실을 듣지 않았다면 아빠가 말하지 않는다. 탁본만으로 공구의 주인을 단정하지 않는다. |
| 2 | 너울 “온도계를 빌려 간 【검사원 조수】가 조각을 뺐소.” | 초롱의 말 | 새벽까지 따뜻했다는 목격으로 시각을 좁힌다. 우박 자신의 말만 제시하면 독립된 확인이 필요하다는 반응. |
| 3 | 백 부인 “제 창고 조각은 【정당하게 산 것】이에요.” | 이름표 붙은 조각 | ‘광장 3’이라는 이름표로 출처를 확인한다. 현장 노끈만 제시하면 창고 조각과의 연결이 없다는 반응. |
| 4 | 너울 “누가 팔았든 【이미 끝난 일】이오.” | 빈 난로 또는 사서의 말 | 다른 난로도 안전한지 확인되지 않았음을 지적한다. 아직 같은 범인이라고 단정하지 않는다. |
| 5 | 실룩 “그 노끈…… 【누구나 쓰는 끈】이오.” | 실룩의 짐 끈. 현장의 노끈을 먼저 확보해야 함 | 두 끈의 뜯긴 끝이 맞는다는 반박. 아이에게 듣지 않은 말을 아빠가 인용하지 않는다. 현장 노끈만 제시하면 실룩의 끈과 대조했는지 묻는다. |

**처절한 순간**
```
(지문) 실룩이 무릎을 꿇었다.
실룩: ……빚이 열두 냥이었소. 못 갚으면 애들을 일꾼으로 보내야 했소.
실룩: 등 하나 식는다고 사람이 죽을 줄은 몰랐소. 그림쟁이가 거기서 자는 줄은…….
실룩의 아이: 아빠, 빵…… 이거 때문에 그런 거야?
(지문) 아이가 빵 봉지를 떨어뜨렸다. 빵이 눈 위로 굴렀다.
(침묵)
백 부인: 빚은 빚이에요. 저는 아무도 죽이지 않았어요.
다람: (작게) ……아빠.
```

**정리 고르기**
- ✔ "온도를 잰 건 우박, 조각을 훔친 건 실룩, 그 조각을 산 건 백 부인이다."
- ✗ "실룩이 일부러 사람을 죽였다." → 너울 "죽이려던 건 아니라지 않소."
- ✗ "온도를 잰 검사원 탓이다." → 서리 "제가 연 등은 새벽에 따뜻했습니다."

**결정**
```
너울: 톡은 풀어 주겠소. 실룩은 내가 데려가오.
```
| 선택 | 결과 |
|---|---|
| 실룩을 데려가게 둔다 | 실룩은 빚 대신 일꾼 명단에. 아이들은 아랫길 천막으로. 나중에 수레 명단에 실룩 |
| 백 부인 창고를 열게 한다 | 조각을 등에 돌려놓고 남은 건 나눈다. 긴 밤에 덜 죽는다. 백 부인은 아빠를 미워한다 |
| 둘 다 | 가장 정의롭지만 실룩 가족이 무너진다 |
| (실룩의 빚을 알았다면) "실룩의 빚은 훔친 조각 값으로 없던 걸로 하시죠." | 백 부인이 사람들 눈앞에서 물러선다. 실룩이 아이들을 끌어안는다. 완벽한 길 |

## 회의 뒤 — 실제 결과에 따른 등과 톡

**톡을 구하지 못함**
```
(지문) 톡이 끌려간 뒤에도 3번 등은 식어 있었다. 부리가 빈 작업대를 바라보았다.
부리: 등도 그대로고, 선생님도 안 돌아왔어요.
아빠(생각): 밝힌 것과 밝히지 못한 것이 남았다. 내가 모르는 일을 안다고 말할 수는 없다.
```

**톡은 풀려났지만 조각 반환을 요구하지 않음**
```
(지문) 풀려난 톡이 3번 등의 빈 뚜껑을 닫았다.
톡: 범인은 밝혔지만, 조각은 아직 못 돌려받았어요. 이대로는 등을 데울 수 없어요.
```

**톡 석방 + 조각 반환**
```
(지문) 톡이 돌려받은 ‘광장 3’ 조각을 등에 다시 넣었다. 등이 데워졌다. 그런데 숨 몇 번 사이에 온기가 옅어졌다.
톡: 이 조각, 가을엔 밤새 따뜻했어요. 지금은…….
우박: (돌이 식는다는 사실을 알았다면) 조각을 돌려놔도 오래 따뜻하지 않아요. 돌 자체가 식고 있어요.
```

해결한 경로의 아빠 생각: “조각을 훔친 사람은 밝혔다. 하지만 이 겨울에 사람들이 온기를 잃는 일까지 끝난 것은 아니다.”

후일담 뒤 회고는 실제로 반박한 논점과 남은 논점을 따로 적는다. 전부 반박하고 결론을 말하지 않은 경우는 ‘자료 부족’으로 부르지 않는다. 정답 위치는 자동 공개하지 않는다. ‘남은 논점을 생각한다’ → ‘구체적인 조사 방향을 본다’를 골랐을 때만 장소를 알려 준다.

선택: 이 결과로 계속 / 같은 자료로 회의 재시도 / 조사 시점 재개. 마지막 두 선택은 해당 네이티브 세이브가 있을 때만 표시한다. 기존 실패는 별도로 보관하고 재시도 입장 화면에서 다시 열 수 있다.

## 4일 — 그림책, 바뀐 마지막 문장

```
(그림책) 아침이 되자, 아저씨는 엄마 코를 다 못 그린 채 잠들어 있었어요.
(피코가 살았다면) 아침이 되자, 누군가 아저씨에게 담요를 덮어 주었어요.
다람: ……아빠. 이 책, 이제 안 읽을래.
```

## 결과 정리

| 결과 | 다음에 |
|---|---|
| 피코가 산다 | 진료소에 눕는다. 초상이 완성된다. 나중에 이름 판 옆에 사람들 얼굴을 그린다 |
| 피코가 죽고 다람이 코를 그렸다 | 엄마를 만나면 엄마가 그 초상을 보고 운다 |
| 사서가 산다 | 나중에 엄마의 옛 기록을 직접 건넨다 |
| 사서가 죽는다 | 엄마 이름이 적힌 대출 카드가 엄마를 찾는 단서가 된다 |
| 톡이 풀려난다 | 13호 사건 회의에서 톡이 증언한다 |
| 서리를 믿게 됐다 | 다람 탐정단의 세 번째 길, 수프 사건에서 서리가 약장을 미리 잠근다 |
| 실룩의 빚이 없어졌다 | 수레 사건에서 실룩이 수레를 늦게 끈다 |
| 창고를 열었다 | 긴 밤에 덜 죽는다 |
| 회의에서 졌다 | 톡이 광장에 세워진다. 등을 고치는 성공 장면은 나오지 않는다. 이후 톡 증언을 얻지 못하는 불이익은 유지한다 |
