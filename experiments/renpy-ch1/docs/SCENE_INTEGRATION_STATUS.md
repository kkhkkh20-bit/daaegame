# 실제 경로와 검증 범위

제목 화면에 추천 검증판을 명시적으로 추가한다. 기존 ‘처음부터’와 기존 저장을 교체하지 않는다. 첫 진입은 현재 미검수 범위를 설정 패널로 안내한 뒤 1일 마차 도착과 입구 조사를 시작한다.

기본 플레이는 장소 이동 화면 → 현장 인물/물체 클릭 → 기존 공용 질문 UI → 실제 대사/전용 조사 화면 → 획득 카드 → 공개 회의이다. 단순 전역 행동 목록은 관리자 상태검증 허브에만 남긴다. 현장 인물은 기존 r13_staged_visible_art와 r13_actor_hit_mask를, 질문/프로필은 기존 대사·초상 표시기를 재사용한다. 위치별 실제 목표는 추천 상태의 가용성만 사용하고 기존 사건·NPC 행동 목록을 호출하지 않는다.

물체 버튼은 현재 현장용 표지로 연결되어 있다. 64/240 물증 그림과 인물 프로필을 실제 연결했으며, 기존 배경 물체의 정밀 클릭 영역과 새 도식 결합은 네이티브 화면 검수가 남았다. 이 구현을 전 회차 배경 미술 검수 완료 또는 기존 메인 교체 완료라고 부르지 않는다.

엄마: 초롱이 가족 도착을 처음 확인한 뒤 전달 지점에 간다. 장화 말리기 생활 행동이 실제 전달 시간이다. 자료 비교를 전수 완료해야 응답/재회하는 구조는 아니다. 밤 방 비교와 실제 숙박은 별도 저녁 행동이다.

피코: 첫 만남에 이미 알고 있는 엄마 행적을 공유하고 초상을 약속한다. 3일 생존/사망 양쪽에서 같은 초상을 받는다. 생존판은 피코 자신의 설명을 유지한다. 사망판은 발견·도움 요청·서리 확인·다람 반응 후 개인적 조사 동기가 이어진다. 촌장이 다음 날 공개 회의를 알린다.

실제 아트 기준은 게시판 옆 벤치 위 매달린 황동등이다. 초기 통형 단면은 미검수 구상으로 폐기 대상이며 생산 자산에 포함하지 않는다. 추천판 근접안은 등 내려놓기→뚜껑 열기→천으로 작은 돌 들기→남은 천 끝/테두리 나사 접촉이다. 최종 exact 원화는 정적 검수를 통과했고 실제 조사 화면에 연결했다. native 렌더·클릭 검증 전에는 일반 플레이의 직접 반출 결론 게이트를 열지 않는다.

현재 검사: pure Python 상태/소스/교차 회차 테스트. 실제 클릭 fixture는 제공되지만 공식 RenPy CI 실행 전이다. 시각 배치, 넘침, 터치 입력, 저장 복귀, 자동 대사 아트 결합은 엔진 결과로 따로 판정한다.
