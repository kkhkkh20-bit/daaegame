# 토리 작업과 중복하지 않을 부족 항목

0.19.85까지 새 리소스는 생성하지 않았다. 기존 40명 승인 표정(6슬롯·3출력 크기)은 PR21 통합본을 우선 사용한다. ZIP의 G03은 통합 이전 인벤토리 기준이므로 파일 부족으로 단정해 다시 만들지 않는다.

1~3일에서 확인할 항목:
- 다람이 과자 봉지를 당기기·소매 붙잡기·하차 부축: 맞는 동작이 없으면 동일 인물 정지 초상, 숨은 행동을 새 자막으로 만들지 않는다.
- 초롱의 등 덮개 지지 끈, 받침 청소와 파편 채취: 현재 장소와 기존 초상으로 진행. 동작 그림·정확한 등 내부 대조 이미지가 부족하다.
- 식당 포대 이동·마른 천 빌리기·피코 실제 착석, 네로와 건조 처마의 세 단계 작업: 기존 현장/기존 확인 입력을 사용한다. 처마 배경·일치 동작은 토리에게 필요한 항목으로 남긴다.
- 3번 등 돌 있음/없음/복구 상태의 일치 오버레이와 파편·칼의 접합 면: 기본 배경에 정답을 임의로 그리지 않는다. 서류/수첩의 관찰 기록과 실제 비교 입력은 연결하되 맞는 확대 그림은 확인 필요하다.
- 북쪽 교환함은 기존 `assets/ms14/box.png`를 사용한다. 토리의 신규 교환함 제작 여부와 배치/문 구조를 중복하지 않도록 확인해야 한다.
- 초소 내부 전용 배경은 확정하지 않았다. 기존 초소 현장을 사용하며 보호시설 후보를 초소 내부로 재명명하지 않는다.

후반은 RESOURCE_STATUS.json의 G01~G07과 후보 16종을 유지한다. 후보 파일의 존재와 공간·작동 일치 검증을 구분한다. D11 재회 전용 새 CG, 잡기·바느질·인계 동작, D12/D14 과자·컵 컷의 장소 연속성은 후속 화면 검증 대상이다.

## 4~14일 연결 후 남은 시각·청음 확인

아래는 자동 신규 제작 주문이 아니다. 기존 후보와 토리의 진행 자산을 먼저 대조한다. 이름이 비슷한 파일이 있다는 사실과 대본 공간/물체가 일치한다는 사실을 구분한다.

- 솜이네 내부는 기존 `assets/ms14/somi_inside.webp`를 사용했다. 골목은 기존 `winter` 현장이다. 골목 전용 공간 일치는 남아 있다.
- `assets/ms14/guardroom.webp`는 실제로 `ready-facility0177-morning.webp`에서 온 시설 후보다. 초소 내부라고 이름만 바꾸어 채택하지 않았다. G01의 초소·면회 공간 일치 확인이 남아 있다.
- 옷의 찢어진 끝/울타리 천, 구리선/핀 끝, 병 입구/파편/개봉 봉인의 **정확한 대응 확대**는 텍스트 관찰과 실제 조사·제시에 연결했다. 일반 아이콘을 정확한 접합 그림으로 주장하지 않는다. 특히 `PROP_BOTTLE_SHARD`, `PROP_BOTTLE_BROKEN`, `PROP_POTS`의 후보를 대조해야 한다.
- 13일 판돌의 회색 수선 담요(`PROP_BLANKET_BEFORE/AFTER`)는 가족 소유 담요와 다른 물건이다. 가족의 청록/황토 담요 파일을 회색 증거로 재명명하지 않는다. 0.19.86에서 별도 전후 그림을 제작하고 학교 현장·수선 대사·획득 기록에 연결했다.
- 11일 옷 말리기/바느질, 13일 부축·인수, 14일 고정부 분리의 일치 동작과 `CS_EMPTY_ALTAR` 연속성은 확인이 남아 있다. 기존 같은 인물 표정·공간을 사용하고 손/몸을 합성하지 않았다.
- 이름 없는 순찰대원 등은 원문 역할/이름창과 위치 상태만 유지한다. 개별 몸 그림이 등록되지 않은 역할에 다른 인물 얼굴을 복제하지 않는다. 필수 질문은 기존 돌목 등 실제 인물에게 연결했다.
- 원문 BGM/환경음 연결과 UI음은 유지한다. 모든 미세 효과음의 청음·자세별 동작 일치까지 완료했다고 표시하지 않는다(G05/G07).

## 0.19.86 부족 소품 보충

2026-10-21 소유자의 “부족한 리소스는 톤을 맞춰가면서 채워” 지시에 따라 판돌 공용 회색 담요의 수선 전/후 2종을 제작했다. 기존 청록 가족 담요를 스타일 참조로만 사용하고 별도 회색 물건으로 구분했다. 같은 구도·주름·위치에서 오른쪽 터진 끝만 새 무늬 천으로 바뀐다. 새 부리는 화면 아래를 향해 원문 대사와 맞춘다.

- 현장: 학교의 기존 담요 조사 대상에 수선 전 소품을 연결.
- 대화: 기존 컷 레이어와 종료 정리 경로로 수선 전/후 표시. 새 화면·선택지 없음.
- 기록: 실제 수선으로 E13_MENDING을 얻은 뒤에만 완성 그림 표시.
- 나머지 공간/접합 물체는 기존 후보를 우선 대조한다. 토리의 인물 표정·동작은 계속 별도 작업으로 유지한다.
