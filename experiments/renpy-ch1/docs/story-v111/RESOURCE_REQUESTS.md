# 토리 작업과 중복하지 않을 부족 항목

새 리소스는 생성하지 않았다. 기존 40명 승인 표정(6슬롯·3출력 크기)은 PR21 통합본을 우선 사용한다. ZIP의 G03은 통합 이전 인벤토리 기준이므로 파일 부족으로 단정해 다시 만들지 않는다.

1~3일에서 확인할 항목:
- 다람이 과자 봉지를 당기기·소매 붙잡기·하차 부축: 맞는 동작이 없으면 동일 인물 정지 초상, 숨은 행동을 새 자막으로 만들지 않는다.
- 초롱의 등 덮개 지지 끈, 받침 청소와 파편 채취: 현재 장소와 기존 초상으로 진행. 동작 그림·정확한 등 내부 대조 이미지가 부족하다.
- 식당 포대 이동·마른 천 빌리기·피코 실제 착석, 네로와 건조 처마의 세 단계 작업: 기존 현장/기존 확인 입력을 사용한다. 처마 배경·일치 동작은 토리에게 필요한 항목으로 남긴다.
- 3번 등 돌 있음/없음/복구 상태의 일치 오버레이와 파편·칼의 접합 면: 기본 배경에 정답을 임의로 그리지 않는다. 서류/수첩의 관찰 기록과 실제 비교 입력은 연결하되 맞는 확대 그림은 확인 필요하다.
- 북쪽 교환함은 기존 `assets/ms14/box.png`를 사용한다. 토리의 신규 교환함 제작 여부와 배치/문 구조를 중복하지 않도록 확인해야 한다.
- 초소 내부 전용 배경은 확정하지 않았다. 기존 초소 현장을 사용하며 보호시설 후보를 초소 내부로 재명명하지 않는다.

후반은 RESOURCE_STATUS.json의 G01~G07과 후보 16종을 유지한다. 후보 파일의 존재와 공간·작동 일치 검증을 구분한다. D11 재회 전용 새 CG, 잡기·바느질·인계 동작, D12/D14 과자·컵 컷의 장소 연속성은 후속 화면 검증 대상이다.
