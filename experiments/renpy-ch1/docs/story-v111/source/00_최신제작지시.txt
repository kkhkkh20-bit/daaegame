최신 제작 지시 · 2026-10-20 18:26 KST

V1.1.1 기준본은 보존하고 기존 Ren’Py 시스템에서 구현·실행 검증을 진행한다. 새 장문 기획이나 전체 대본 재작성은 하지 않는다. 기존 Codex의 최신 변경을 먼저 확인하고 중복 적용하지 않는다.

1. 리소스 제작: 사용자 최신 승인으로 기존 82씬에 필요한 부족 배경·표정·행동 컷·소품 제작은 허용된다. 이 묶음의 과거 리소스 제작 보류 문구는 해당 범위에서 대체된다. 기존 자산 재사용·2×2 도트·동일 인물/소품·실제 출력 해상도를 유지한다. 새 시스템·새 UI 기능·스토리/결말 변경·추가 유료 결제는 이 승인에 포함되지 않는다.
2. 감사의 D10_S04 촛대 추리 표기는 D10_S03으로 정정한다. D10_S02는 관련 준비 맥락이며 D10_S04는 벤치 후속 대화다.
3. 분기 감사21건은 모두 실제 게임 버그라는 뜻이 아니다. 문서모순/연결공백/실행위험을 구별하고 최신 코드에서 이미 해결된 항목은 재수정하지 않는다. requires113개와 선택effects66개 읽기본 표시는 V1.1.1에 정정됐다.
4. 조건 미충족 인물의 대사를 숨긴 뒤 앞뒤 대화 연결, 필수정보 전달, 역할의 실제 인수까지 확인한다. 부재 인물의 일을 다른 사람이 자동으로 한 것으로 처리하지 않는다.
5. 기존 실행 처리부터 확인하고 1~3일 실제 플레이, 7일 사건/예방·10일 추리·13일 담요, 11일 재회·14일 결말, 전체 주요 분기, 모바일·음향·저장/로드/스킵 순으로 검증한다. 새 실행 엔진을 만드는 지시가 아니다.
6. 각 완료에는 변경 파일/커밋·실행 경로·실제 화면·사용 자산/음원·남은 문제를 기록한다. 문서상 설계와 실제 게임 검증은 별개다.
