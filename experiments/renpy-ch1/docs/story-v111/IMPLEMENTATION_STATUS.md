# V1.1.1 연결 작업 현황

기준: main `75890596` / 공개 0.19.75. 첫 3일 검증 소스는 0.19.76이다. 실제 실행 자료는 `verification/`에 보존한다.

## 적용 범위

- 원본 82씬·3162개 레코드와 V1.1.1 지시/감사 파일은 `source/`에 그대로 보존했다.
- 첫 3일은 기존 Room13 현장, 인물, 지도, 기록/제시, 대사와 Ren’Py label/jump로 연결한다. 비활성 MS14 실행 컨트롤러를 새 게임으로 켜지 않는다.
- 기존 증거와 이름이 충돌하지 않도록 내부 ID만 `V111:` 접두어로 분리한다. 플레이어에게 보이는 명칭과 원문은 보존한다.
- 선택 효과는 실제 입력 후 적용한다. 침구 예약과 수령, 피코 생존과 초상 완성, 돌 반환과 실제 설치, 실룩 처우를 구분한다.
- 후반의 자연어 조건을 임의로 true 처리하지 않는다. 첫 3일에는 개별 requires가 없으며 후반 연결은 아직 하지 않았다.
- 4일 진입은 현재 개발 검증 경계다. 기존 확인창으로 3일차 공개 범위를 안내하고 저장/메인 화면 이동을 제공한다. 4~14일이나 주요 엔딩을 완료했다고 표시하지 않는다.

## 실행 확인 상태

- 원문 보존/효과/선행 조건 등 변경 관련 단위 검사 10건 통과.
- 기준 760건과 변경 관련 10건을 포함한 `dev/check.sh` 통과. 이후 연결 순서 수정은 관련 지도 검사 3건만 다시 확인해 통과했다.
- 네이티브 실제 마차 시작→편지 입력→입구 조사 진입 통과.
- 실제 웹: 첫날 현장 조사, 입구 자료 3개 제시, 숙소 메모·꾸러미, 편지 비교, 취침까지 진행 확인.
- 실제 웹: 둘째 날 밧줄·교환함 조사, 우편소 이동, 세련 대화와 봉투 확인 통과. 화면 밖 인물 접근은 자동 플레이의 카메라 조작 누락이었으며 게임 대화 로직은 재작성하지 않았다. 이후 검증 진행 중.
- 교환함 클릭 영역이 초롱과 겹치는 문제를 수정했고, 화면에서 떠 있는 배치를 추가 조정했다. 수정 후 빌드에서 실제 진행 통과.
- 두 오후 경로 모두 3일차 끝까지 통과했다. 피코 보호는 생존/완성 초상/담요 0장/돌 복구/실룩 출석 의무, 네로 작업은 피코 부재/다람이 이어 그린 초상/실제 담요 2장/돌 반환 보류/실룩 공동작업 대기로 이어졌다. 오답 제시 후 선택 자료가 정리되고 정답으로 다시 진행되는 것도 실제 확인했다. 마지막 취침→4일 진입 경계→완료 안내, 저장 화면 열기/복귀, 메인 화면 이동을 확인했다.

저장·로드·스킵 기본 기능을 중복 검사하는 별도 행렬은 만들지 않는다. 실제 진행 중 막히는 연결, 선택 효과, 대사 정합성에 집중한다. 테스트 저장은 이미 통과한 구간을 반복하지 않기 위한 재개 지점이다.

## 감사와 리소스

감사 21건은 `AUDIT_21_STATUS.csv`에 원문 문제와 현재 코드 상태를 구분했다. 읽기본 113개 조건 표시는 이미 정정되어 재수정하지 않았다. 후반 원문이 기존 게임에 연결되지 않은 상태를 해결 완료로 세지 않는다.

사용 자산/부족 항목은 `RESOURCE_STATUS.json`, `RESOURCE_REQUESTS.md`에 있다. 기존 승인 초상/표정과 교환함·초상화·꾸러미 및 원본 음원을 우선 사용한다. 신규 그림이나 음원은 생성하지 않았다. 토리가 제작 중인 동작/표정과 중복 작업하지 않는다.
