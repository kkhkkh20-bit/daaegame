## 확인한 결과

- E21과 E24.partial의 누락된 지급 지점을 연결한 뒤 4~5일이 실제로 진행된다.
- 대피한 빈 창고 진압과 세 아이 구조는 서로 다른 자료다. 같은 증거 이름으로 피해 결과를 숨기지 않는다.
- 10일 석방 후 다람이 보호실로 되돌아가지 않는다. 사망한 꼬미·부엉이·네로·도담은 이후 생존 대사/이동으로 되살리지 않는다.
- 명부에 적힌 교사와 수레에서 실제 본 교사를 구분한다. 실제 인수된 뒤에는 `handed_over`로 바뀌고 그 장소에 남는다.
- 수레 정지만으로 전원 구조가 되지 않는다. 부분 결말은 한 명의 실제 학교 위치와 나머지 사람들의 광장 대기를 구분한다.
- 예방 성공만으로 미연결 학교 등을 켜지 않는다. 실제 인수·연결/사용 상태와 카드 소유는 별개다.
- 부리가 직접 운반하지 않은 상자를 자기가 날랐다고 말하지 않는다. 없는 참관자에게 응답하는 대사도 제외한다.
- 가족 대피에서 아빠는 대사대로 광장에 남고 까로의 실제 귀환 뒤 다른 운반을 맡긴다. 단순 진행용 단일 선택창은 만들지 않는다.

## 검사와 스크린샷

변경 조건/원문 보존 검사, 필수 `dev/check.sh`(전체 단위+Ren'Py lint), 공식 SDK 웹 빌드와 실제 Chromium 클릭 진행을 수행했다. 최종 검사: 전체 793개 통과, Ren'Py lint 통과, 공식 웹 빌드 완료. 최종 엔진에서 0.19.85를 읽고, 준비 완료 뒤 불필요한 단일 선택창 없이 13일로 진행하며, 가족 결말의 14일 저녁 입구 숙소까지 재확인했다. 상세는 `RESULTS.json`에 있다. 스크린샷은 시안·합성 그림이 아니라 실제 게임 화면이다.

긴 앞부분의 반복을 줄이려고 실제 진행 저장을 재사용했다. 저장/로드/스킵 기본 기능의 별도 중복 행렬은 만들지 않았다. 검사 도구의 선택창 렌더 대기/화면 좌표 문제와 게임 오류는 구분했다.

## 검수 중 고친 실행 문제

- 새 장소를 기존 cartography의 경계/그림에 연결하지 않아 생긴 지도 KeyError.
- 주민 수가 기존 바닥 슬롯보다 많을 때의 `min(empty)` 및 직전 장소 주민 전원이 다음 장소로 따라오던 문제.
- 취침 물건이 다른 장소를 가리키던 연결.
- 새 관찰 자료의 분류명이 기존 수첩 분류에 없어서 생긴 획득 화면 오류.
- 주방의 기존 `rear_after` 표면이 새 대본의 `rear` 클릭을 가로채던 문제.
- 부분 인수에서 환자 실제 위치가 빠져 있던 연결, 탑승 관찰/인수 후 이송 상태, 감독 역할 중복.
- 엄마가 학교에서 보호하는 다람이 아빠의 다음 조사 이동에 자동으로 따라오던 조건.
- 군중을 저지한 뒤 조사로 돌아올 때의 씬/음악 문맥과 동일한 군중 공개를 반복할 수 있던 문제.

## 남은 범위

- 재고 0/1장으로 11일을 시작하는 변형, 두 보조 통로 힌트 자체 클릭, 네로가 현장에 실제 동석한 에스코트 등 모든 교차 조합을 전체 재생하지는 않았다. 원문·명시적 조건은 보존한다.
- 실패한 직접 저지의 대체 대사는 보존했지만 원문에 없는 확률/시간 실패 시스템을 새로 만들지 않았다. 현재 직접 저지·감독자 보호·비개입은 연결돼 있다. 실패 판정을 위한 별도 입력 계약은 추가 확정 대상이다.
- 공간/접합 확대/동작/CG의 일치 확인은 `../RESOURCE_REQUESTS.md`에 남겼다. 토리의 기존 작업과 중복 생성하지 않는다. 새 이미지·음원 생성 0건.
- 공개 반영은 Pages가 해당 커밋을 빌드했는지 별도로 확인한다. 로컬 브라우저 진행을 공개 서버 직접 접속 검사로 바꾸어 적지 않는다.
