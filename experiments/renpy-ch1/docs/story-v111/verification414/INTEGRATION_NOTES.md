# V1.1.1 4–14일 기존 시스템 연결

실행은 기존 Room13 조사·인물 질문·지도·기록/제시 화면과 보통 Ren'Py label/if/jump/call을 사용한다. 새 런타임 해석기나 별도 저장 상태는 없다. `dev/build_v111_days1114.py`는 원문 ID를 유지한 `.rpy`를 작성하는 오프라인 제작 도구이며 4–5/6–10 도구도 함께 실행한다. 1–3일 파일은 재생성하지 않는다.

원본 82씬/3162레코드와 113개 개별 requires는 보존한다. 자연어 조건을 eval하지 않는다. 씬·블록은 native 분기, 개별 requires는 닫힌 명시적 콜백으로 연결한다. 같은 문구를 읽거나 수첩을 다시 여는 것으로 효과를 지급하지 않는다. 배경의 구작 관찰은 보존하되 구작 사건의 증거·래치를 지급하지 않는다.

## 실제 입력과 상태

- 4–5일: E21은 밤이의 밤 목격 완료, E24.partial은 네로의 회색 외투 진술 완료에 연결한다. 옷 주인 허락, 접합 면 조사, 네 근거 제시, 편지 비교/답장 인계, 잠금 확인은 기존 현장 입력이다.
- 6–10일: 학교 낮 자리와 네 아이의 실제 야간 인수는 구분한다. 대피 후 빈 창고 진압과 세 아이 구조 목격은 다른 자료다. 꼬미의 도토리는 실제 회수 입력 뒤에만 가져온 것으로 말한다. 7일 A/B 예방과 C 사건 발생을 구분하고, 사건 경로의 8–9일 필수 조사를 건너뛰어 10일로 가지 않는다. 톡의 작업장 출석과 심리 출석은 서로 다른 조건이며 수선 사본은 별도 자료다. 석방은 실제 10일 대결 결론 뒤에만 기존 `daram_state`에도 반영한다.
- 11일: 토실의 나비 인수를 확인해야 온실로 출발한다. 미도착 시 먼저 함께 기다린다. 가족 담요 0/1/2장 및 마지막 한 장 증여를 구분한다. 물자 인수는 연결·사용과 다르다. 아랫길의 실제 학교 인수 또는 상실 결과를 다음 날에 유지한다.
- 12일: 조기 예방/섭취 전 발견/뒤늦은 발견은 별도 native 경로다. 마지막 경로에서만 의료 확인된 도담 사망·새미 생존을 기록한다. 점등은 실제 연결 상태로 따로 판정한다.
- 13일: 이름이 명부에 있는 것과 수레에서 실제 관찰된 것을 구분한다. 교사·실룩의 추가 탑승 관찰 문장은 기존 `systems/room13_ep6_cart.rpy:254–255`를 재사용한다. 일반 환자와 분리 감독 대상의 실제 인수 목적지는 다르다. 마지막 인수 전에 전원 구조를 지급하지 않는다. 명령 전체 중지·운반 거부·빈 수레 반환·명령 사본 직접 전달이 완료돼야 현재 이송 사슬이 중지된다.
- 14일: 실제 구조 기록 또는 실제 연결·사용한 학교 물자 기록만 장치 분리에 제시한다. 미제시는 조사로 돌아간다. 감독 중인 돌목이 학교에 가려면 현장 교대를 확인하며 교사 감독과 실룩 감독에 같은 인물을 동시에 배정하지 않는다. 부분 구조의 새 침상 한 자리는 한 명만 인수하며 다른 사람을 전원 구조로 만들지 않는다. 가족 거래는 입구 숙소, 다른 경로는 실제 학교 이동 뒤 숙소를 기록한다.

## 원문 보존과 최소 연결 보완

원본 JSON을 고치지 않고 다음 연결만 런타임에 보완한다.

1. 6일 학교의 낮 동안 앉을 자리 허락을 한 문장으로 명시한다. 야간 네 아이 인수의 대체가 아니다.
2. 꼬미에게 도토리를 실제로 받아 오는 입력과 짧은 행동 서술을 추가하고 6일 회상을 “다람이 도토리는 내가 꺼내 왔어”로 맞춘다.
3. 7일 아빠의 선행 지식은 실제 보리의 문 앞 목격 질문을 먼저 거쳐 확보한다.
4. 예방 경로에서 초대 전달자를 묻는 부엉이 질문을 실제 입력으로 둔다.
5. 13일 교사/실룩 수레 관찰은 기존 게임의 원문을 재사용한다. 13일 마지막 위협의 “내일” 지시 대상을 명확히 한다.
6. 부리는 13일 공구 인수 때 직접 동행 요청을 수락한 경우에만 14일 현장에 온다(14일 S02 L29 지시의 연결). 미참여 물자 운반을 했다고 말하지 않으며 해당 경로는 기존 비참여 작업 반응을 사용한다. 부리의 공구 수락 행동 한 문장 외에 새 사건·대본을 만들지 않는다.
7. 아빠가 광장에 남겠다는 가족 대피 대사를 지킨다. 까로가 학교 인계를 마치고 혼자 돌아오는 관찰 서술만 최소 보완하고, 아빠 화면을 학교로 이동시키지 않는다.
8. 백 부인의 참관 수락은 원문 S02 L29의 인용을 실제 12일 질문에 연결한다. 미참관 상태에는 그 질문의 엄마 응답도 재생하지 않는다.
9. 이름 없는 순찰대원 등은 원문 화자/역할을 유지하되, 제공된 CAST에 몸 그림이 없으면 화면 밖 역할로 둔다. 존재하지 않는 스프라이트를 그리거나 다른 인물 얼굴을 복제하지 않는다. 질문 대상인 기존 돌목은 그대로 표시한다.

## 검증 범위의 구분

정적 레코드 보존, 조건 단위 검사, Ren'Py lint와 실제 클릭 진행은 서로 다르다. 실제 확인 결과는 `PLAY_REPORT.md`와 감사 CSV에 적고, 미실행 분기를 정적 검사 통과만으로 완료 처리하지 않는다. 기본 저장/로드/스킵은 이번에 반복 회귀하지 않는다. 실제 진행 저장은 긴 앞부분을 반복하지 않기 위한 검수 재개 지점으로 사용하며, 이야기 상태를 주입하지 않는다.
