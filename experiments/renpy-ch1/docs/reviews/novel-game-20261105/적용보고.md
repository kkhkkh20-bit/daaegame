# 『기다린다던 방』 소설 개정안의 본편 적용

2026-11-05 · 0.20.97. 소유자의 ‘이제 게임에 적용해보자’ 요청에 따라 14장 퇴고 원고와 게임 적용 메모를 기존 본편에 대조했다. 소설의 한 성공 경로를 공통 진행으로 강제하지 않고, 게임에서 실제로 고른 행동과 겪은 사건에 맞는 대사로 옮겼다.

## 달라진 흐름

| 구간 | 바뀐 점 |
|---|---|
| 1~3일 | 엄마의 부재에 놀라고 매달리는 다람, 기다림에 대한 이견, 피코와의 내일 약속과 시신 앞 반응을 보강했다. 도착 쪽지에는 초대 편지를 받고 왔다는 근거와 13호실·회신 경로를 한 번만 적는다. 새 게임에서는 미완성 코를 엄마에게 먼저 보여 주기로 한다. |
| 4~5일 | 아빠가 그림자와 옷 주인만으로 성급히 결론을 내리는 것을 다람이 되짚는다. 나비에게 식당에서 실제 확인하고 초소 증언으로 잇는다. 첫 답장으로 엄마가 첫날 마차를 봤지만 연락에 실패한 이유를 읽는다. |
| 6~7일 | 오늘 아이들을 옮기기로 한 뒤 학교 담요를 실제로 빌리고 수량을 기록한다. 수레 도착과 네 아이 인수는 남는다. 아픈 다람을 실제 복도로 옮겨 도토에게 맡기고 아빠가 도움을 구한다. 기본 인계와 사전 예방 행동은 구별한다. |
| 8~10일 | 복도 인계판에서만 재입실 이유를 듣는다. 촛대를 놓쳤다가 아랫조각을 다시 쥔 순서와 보지 못한 두 번째 소리를 구별한다. 책장판의 수동 출구와 별도의 판자문을 구별하고 실제 안전 왕복을 유지한다. 엄마의 6일 경고를 8일 받고, 구금 면회 때 아이에게 읽는다. 초롱의 구두 전언으로 연락이 이어진다. |
| 11~14일 | 실제로 읽은 편지·전언에 맞춰 재회 때 원망과 판단 실패를 다룬다. 겪지 않은 질병을 회상하지 않는다. 배식 중단과 자료 제출은 플레이어 행동으로 남긴다. 할머니 진술의 의도·불·진입·살해·구조 뒤 누명 순서를 맞춘다. 학교 일반 결말에서 빈 코와 가족의 다음 연락 약속을 회수한다. |

세부 항목별 적용: [1~3일](01_03_적용.md), [4~5일](04_05_적용.md), [6~10일](06_10_적용.md), [11~14일](11_14_적용.md). 설계 원문은 [원고적용설계.json](원고적용설계.json), 별도 검토는 [독립검수.md](독립검수.md)다.

## 기존 저장과 다른 경로

- `mother_first_contact_read5`는 새 첫 답장 전문을 실제로 읽은 뒤만 켠다. E27을 가지고 있다는 이유만으로 새 사실을 들었다고 하지 않는다.
- `corridor_handover7`은 복도 이동과 인계 대사를 보인 뒤 켠다. 그 전 장면을 지난 저장은 기존 방 안 인계의 회고·귀환을 유지한다. 도토 다짐이나 톡의 예방 행동을 자동으로 얻지 않는다.
- `mother_contact_relay10`은 초롱의 전언을 실제로 들은 뒤 켠다. 재회는 5일·10일 상태의 교차 조합을 구별한다.
- `portrait_waiting_for_mom`이 있는 새 미완성 그림만 14일 엄마 앞에서 완성한다. 기존 `child_completed` 그림은 다시 그리지 않는다. 피코 생존판과 가족 우선·다른 결말은 별도로 유지한다.
- 원본 `v111/records.json`, 기존 자료 ID, 회의 정답·기회 수·승패·주요 생사·결말 종류 판정은 유지했다. 새 UI 디자인과 그림은 추가하지 않았다.

## 통합 검수

- 전체 단위시험 1,220개와 Ren’Py lint 통과. 대사 자동 검사 A/B/C 각 0건.
- 신규 8개를 포함한 관련 화면시험 23개 최종 통과. 편지 청취·기존 저장·예방 귀환·실제 학교 차용과 지도 왕복·구금·인수·배식·피코 생존·결말을 확인했다.
- 독립 검수에서 나온 인물 위치, 정보 되감기, 예방판의 잘못된 회고를 수정했다. 별도 자료 요약도 맞췄으며, 문에 실제 갇혔는지와 수동 출구 기능의 증언 출처를 구별했다.
- 자료 자리표와 대사·에셋 출처의 줄 번호를 갱신했다. 전체 단위 첫 실행의 자리표 불일치는 재생성 후 해소했다.
- 신규 화면시험의 행 식별자·선행 상태와 기존 시험의 새 지도 동선 가정을 실제 실행에 맞춰 고친 뒤 재실행했다.

웹 표시·저장 복원·공개 확인은 릴리스 노트와 [통합검수_기록.json](통합검수_기록.json)에 최종 기록한다. 이번 검증은 변경 구간의 상태를 준비한 부분 화면 시험이며, 14일 전체 자연 주행·전체 화면 회귀·초견 독자의 재미 시험은 실행하지 않았다.
