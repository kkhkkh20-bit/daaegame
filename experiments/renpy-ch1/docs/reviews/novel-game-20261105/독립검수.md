# 소설 개정안 본편 적용 독립 검수

2026-11-05. 최신 퇴고 원고와 게임 적용 메모를 기준으로, 구현 담당자와 별도로 소스 차이를 확인한다. 화면 시험·빌드·공개 검증은 메인 담당의 통합 결과와 구분한다.

## 확인 범위와 기준

- 소설의 한 경로를 생존·예방·패배 경로에 공통 회상으로 복사하지 않는다.
- 아빠·다람이 실제 들은 정보와 새 읽음 상태를 구분한다. 옛 저장의 자료 보유를 새 문구 청취로 소급하지 않는다.
- 7일 복도 인계는 실제 이동·배우 위치·8일 진술과 맞추며, 별도 도토 다짐과 톡 예방 행동은 유지한다.
- 9일 책장판의 수동 출구와 별도 판자문을 구분한다.
- 13일 질문은 제출 전에 가능하나 모순의 결론은 제출 성공 뒤에 둔다.
- 14일 일반 학교 결말과 가족 우선 결말, 손실 결말을 구분한다.
- 원본 records.json, 정답 자료 묶음, 생사·승패 판정을 변경하지 않는다.

## 구현 중 발견해 수정한 항목

### 5일 나비의 증언 도착

식당에서 나비에게 초소 증언을 직접 부탁하는 새 동선을 넣은 뒤에도, 성공 대사에 남아 있던 기존 지문은 나비가 우연히 콩이를 데리러 온 듯했다. 또한 location:nabi가 식당에 남을 수 있었다. 담당자에게 전달했고, 약속대로 왔다는 지문과 증언 직전 r13_v111_join(['nabi'])로 동작·위치를 맞췄다. 관련 대사는 nabi_hearing5 블록으로 분리했다.

### 6일 도토의 실제 수레 도착

학교에서 담요를 싣고 출발한 도토의 위치가 학교에 남은 채 창고의 운반 대사가 나올 수 있었다. 담당자는 창고 수레 도착 지문과 L0011 직전 합류를 추가해 실제 위치를 일치시켰다.

### 9일 장치 조작과 단독 왕복

레버를 올리는 동작 뒤 책장판이 바로 열리는 듯한 문장이 있었다. 통로 쪽 수동 손잡이를 실제 밀어 여는 동작으로 고쳤다. 예방판의 ‘저희 둘이 돌아온 뒤’도 ‘제가 돌아온 뒤, 따닥 씨는 안전줄’로 맞춘 것을 확인했다. E09_PASSAGE는 같은 자료 ID의 설명 오버레이로 책장판과 별도 판자문을 구분하며 원본 기록은 유지한다.

### 10일 초롱 전언 직후의 되감기

새 전언에서 ‘통은 엄마가 있는 곳이 아니라 위치 쪽지를 둔 곳’이라고 확인한 직후, 기존 L0017~18이 같은 질문과 ‘답이 와 있을지도 모른다’로 되돌아갔다. 새 전언을 실제 들은 상태에서만 ‘쪽지도 함께 읽겠다’는 가족 문답으로 바꾼 것을 확인했다. 전언을 듣지 않은 이전 경로는 유지한다.

### 11일 겪지 않은 질병 회상

돌 예방판에서는 7일 아이가 악화되는 대사를 건너뛰는데, 온기 회상 블록의 새 질문은 아이가 방에서 아팠다고 했다. 담당자는 실제 악화 뒤 설정되는 기존 D07_S03_medical_request_completed가 있을 때만 질병 대비 질문을 쓰고, 그 외에는 받침의 온기 관찰만 묻도록 분리했다. 3일에 실제 느꼈다는 stone_warm_felt3와 가족 동석 조건도 유지했다.

### 자료 대조 화면의 별도 요약

대사와 긴 자료 설명을 고쳐도 v111/evidence-facts.json의 별도 요약이 먼저 표시된다. E09_PASSAGE에는 ‘안쪽 손잡이는 없다’, E08_RECENT_LETTER에는 ‘아이를 여관으로 데려오지 마요’라는 옛 문구가 남아 있었다. 메인이 두 요약과 E27의 요약을 같은 정본으로 동기화한 것을 확인했다. 새 자료 ID나 정답을 만드는 작업은 아니다.

## 보존 확인

검수 시점의 game/v111/records.json은 HEAD와 바이트 단위로 동일하다. 날짜별 newworld JSON의 새 자료 ID 집합도 동일하다. 다섯 실행 파일(days123, days45, days610, days1114, owl_prevent)의 기존 r13_v111_proof 호출과 정답 인자, r13_nw_meeting_end·r13_fork_set_fate·주요 생사 및 ending14 설정 호출을 HEAD와 대조했고 변경을 찾지 못했다. 새 그림·UI 디자인 변경도 없다. 7일 인계는 원본 operation을 복사해 DOTO_location만 실제 복도로 적용하며 다른 guardian·출발·완료 효과는 보존한다.

실행 대사와 분기 변경에서 해결되지 않은 필수 수정 항목은 찾지 못했다. 마지막 자료 요약에서는 판자문을 과거에 따닥이 갇혔던 문으로 단정하지 않도록 하고, 레버를 끈 상태의 수동 손잡이 기능은 실제 실험 결과와 따닥의 증언을 구별하도록 메인에게 문구 조정을 전달했다. 이는 소스와 대사 연결의 독립 검토 결과다. 통합 단위·lint·실제 화면 시험·웹 빌드·공개 결과는 메인 보고에 따르며, 이 검수자가 전체 자연 플레이나 실제 초견 독자의 재미 시험을 실행했다는 뜻은 아니다.
