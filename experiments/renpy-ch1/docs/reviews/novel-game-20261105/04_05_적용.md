# 소설 퇴고판의 본편 4~5일 적용

기준: `outputs/daram-full-novel-polished-20261105/게임적용대사안_전체.json`의 B01~B07·C01~C05와 5일 구조·연락 배분 항목, 같은 폴더의 4~5장 원고. 소설 한 경로를 본편 분기 전체에 덮어쓰지 않았다.

## 적용

| 항목 | 현재 코드 대조와 반영 |
| --- | --- |
| B01~B02 | 다람이 콩이에게 직접 목격 여부를 묻는 장면, 실룩 감독조건 석방의 불리한 후속과 `bami_cold4` 시작 비용은 이미 있어 유지했다. |
| B03 | 밤이가 구부린 사람을 봤고 키는 모른다고 답한 뒤, 아빠의 ‘작은 그림자’ 요약을 다람이 교정한다. 부녀 세 줄 모두 기존 `daram_ready` 조건을 붙였다. 목격 E21은 원래의 L0018 커밋에서만 얻는다. |
| B04~B07 | 세 현장 물건 직접 관찰, 바둑이 입회 수거, 나비의 독립 목격, 살아 있는 피코의 그림과 대체 정답을 유지했다. |
| C01 | 회색 옷의 소유자를 묻는 문답 → 두 사람이 번갈아 입음 → 아빠의 성급한 이름 지목 → 다람의 착용자 질문 순서로 바꿨다. 솜이가 어젯밤 무쇠가 입었다고 답하므로 실제 대조 이전에 필요한 사실이 사라지지 않는다. 네로를 붙잡거나 판정하지 않는다. |
| 5일 구조 | 다람이 전날 들은 나비의 목격을 상기하고 재확인을 제안한다. 진료소 인계 후 식당으로 실제 이동해 나비에게 그 시각을 묻고, 사람들 앞에서 말해 달라고 부탁한다. 나비가 승낙하며 새 증거를 자동 지급하지 않는다. 기존 회의의 나비 증언도 이 부탁을 받고 온 것으로 맞췄다. 성공 발표에서 `r13_v111_join(['nabi'])`를 증언 블록 앞에 명시했다. |
| C02 | 솜이의 허락, 겉옷 현물 대조, E23 취득과 귀환 증언 E24 취득을 원래 순서에 남겼다. |
| C03 | 자료 제출 성공 뒤에만 다람이 ‘거기 있었다’와 ‘물었다’의 차이를 자기 말로 확인한다. 성공 판정·정답 조합은 바꾸지 않았다. |
| C04 | 재시도 가능한 `wrong5` 분기에만 아빠의 성급함을 인정하는 한 줄을 넣었다. 최종 실패의 명단·밤이 상태·기회 수는 유지했다. |
| C05 | 승리/패배별 솜이·밤이·무쇠의 후속과 감정 차이는 기존대로 남겼다. |
| 5일 첫 엄마 답장 | 기존 봉투 획득 후 실제 읽는 전문을 `warning_first5`/`warning_rest5` 블록으로 옮겼다. 초대장 부인에 이어 첫날 마차 목격, 입구의 여관 연락 지시, 초롱 길목에서 돌아선 이유, 교환함 접근이 늦어진 이유가 나온다. 주소나 7일 이후 사건은 없다. E27 설명도 같은 전문으로 맞췄다. |
| 가족 반응 | 다람은 첫날 엄마가 봤다는 말을 되묻고, 자신도 엄마를 보러 마차에 탔다고 말한다. 아빠는 방금 처음 알았다고 답한다. 뒤의 입구 지시 회상은 엄마와 가족이 같은 말을 들었다는 범위이고, 편지 작성자를 자동 확정하지 않는다. |

## 상태와 저장

- `MS14_D05_S04_L0005` 커밋의 E27 획득과 `mother_warning_received`는 원래 시점이다.
- 새 전문을 실제로 끝까지 읽은 직후 `mother_first_contact_read5=True`를 설정한다. 기존 저장에서 E27을 보유하거나 봉투를 열었다는 이유로 이 새 설명을 들었다고 소급하지 않는다. 후반 가족 대사의 청취 분기에는 이 상태를 쓴다.
- `mother_denies_invitation`은 기존 두 편지의 플레이어 대조를 통과한 L0014 커밋에서만 생긴다.
- `records.json`, 증거 ID, 정답 조합, 생사, 회의 기회, 취소·회수·오답 후 재시도는 변경하지 않았다.
- 소설의 첫 답장(5일 수신)과 별도 경고(6일 작성·8일 수신)를 합치지 않았다.
- 5일의 기존 직접 작성 편지 두 줄을 블록으로 옮겼으므로 통합 담당자가 literal inventory와 bindings를 갱신해야 한다.

- `python -m unittest discover -s dev -p 'test_novel_game_days45.py'`: 4개 통과. 표시 전문/E27의 동일성, 봉투 보유·전문 청취·자료 대조의 구별, 다람 부재 시 부녀 교정 묶음 숨김, 재시도 감정 줄의 비변경성을 확인했다.
- `python -m unittest discover -s dev -p 'test_newworld_text.py'`: 28개 통과. 전체 overlay 유효성과 기존 소스 불변성·생사 분기 등을 확인했다.
- 소유 파일 `git diff --check`: 오류 없음.
- SDK lint·화면·웹 빌드·전체 검사·공개는 병렬 충돌을 피하기 위해 통합 담당자가 실행한다. 우선 확인할 화면 경로는 `v111_nw_d05_half_then_lost`, `v111_nw_d05_extra_e21_wins` 및 새 편지 전문이다.
