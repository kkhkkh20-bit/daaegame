# 8일 — Claude 직접 검수 (2026-10-24)

## 통과
- 보호실: 아빠가 다람 말을 끊었다가 「이번엔 아빠가 안 끊을게」로 다시 듣는다. 다람의 증언이 문답으로 한 줄씩 쌓인다.
- 도토가 물수건 거짓말을 스스로 무너뜨리는 과정(마른 물수건 → 아빠 질문 → 고백)이 아빠가 본 것에서 출발한다.
- 부리 「할아버지가 예전에 쓰던 수첩」으로 부엉이와 부리의 관계가 풀린다(7일 「부리야」 복선 해소).
- 6일자 엄마 편지 「아이를 여관으로 데려오지 마요」 → 「6일. 오늘은 8일이다」 → 「늦었군요」. 늦게 닿은 경고가 대화로 아프게 읽힌다.
- 예방 경로 갈래(a/b)마다 서리·너울 대사가 그 경로의 사실(돌을 묻었는지/난로에 남았는지)에 맞는다.
