소유자 지시: "너 스스로 대사 검수를 해서 처음부터 말이 되는지". 기준은 CLAUDE.md 「Claude의 핵심 임무」 ① 분기 논리 ② 분기별 인물 맞춤 ③ 아빠 입장에서 처음 하는 플레이어가 이해.
방법: `dialogue_day.py show N`으로 날마다 처음부터 끝까지 읽고, 경로가 의심되는 줄은 rpy 호출과 조건으로 실제로 어느 판에서 나오는지 확인했다(경로가 맞아서 문제가 아닌 것도 날짜별 문서에 적었다).

- 3일 실룩 「죽을 줄은 몰랐어요」는 피코 사망 경로에서만, 11일 「부엉이 어르신한테도 물었어」는 부엉이 생존·증언 판에서만, 12일 「약을 넣은 건 선생님이야」는 국 회의 승리 뒤에만 나온다.
