# 5일 — Claude 직접 검수 (2026-10-24)

## 통과
- 「명단」이 여기서 처음 대화로 풀린다: 솜이 「말하면 명단에 적어서 데려가」 → 아빠 「무슨 명단이니?」 → 네로 「보호시설로 보낼 사람들 이름이요. 간 사람은…… 안 돌아와요」(NW_D05_S01_A05~A07). 묻고 답하는 모범.
  - 다만 3일 패배 경로의 너울 「보호시설 명단에도 올리시오」가 이보다 먼저 나온다 → 3일 고칠 것 2로 보완.
- 네로의 알리바이를 네로가 숨기고(「그건 왜요」) 나비가 대신 대는 흐름이 인물 처지에 맞다.
- 엄마의 경고 편지: 도토리 그림 → 다람 「……엄마잖아」 → 아빠 「응. 엄마가 보낸 것 같아」. 1일 고칠 것 1(편지엔 도토리가 없다)을 넣으면 1일과 5일이 같은 단서로 이어진다.
- 「누가 엄마 이름으로 우릴 불렀는지 모른다」(S05_L0056)로 아빠의 의심이 대화로 정리된다.
