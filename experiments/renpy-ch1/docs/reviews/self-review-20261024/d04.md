# 4일 — Claude 직접 검수 (2026-10-24)

## 통과
- 네로 장면은 2일에 만났는지(`nero_met_day2`)로 갈린다. 만난 판은 「아, 다돌 씨랑 따님이네요」, 안 만난 판은 아빠가 처음 자기를 소개한다 — 인물이 아는 것과 말이 맞다.
- 솜이 「할아버지는 천막에 있어」 → 문 안 기침 소리 → 밤 다람 「여긴 솜이네 집이 더 가까워」로 거짓말이 대화로 드러난다.
- 밤이 혐의: 다람이 「큰 사람」을 지우고 아빠도 따라 고치는 장면(S04_L0056~L0059)이 「본 것과 짐작한 것을 나눈다」를 플레이어에게 대화로 가르친다.
- 동기 줄(NW_MV_D04_01~04)이 들어가 아빠가 밤이를 지키는 까닭(엄마를 본 아이)이 선다.
- 피코 스케치 블록: 다람이 성급하게 결론 내자 아빠가 「그림엔 얼굴이 없어」로 막는다 — 정답을 미리 주지 않는다.
