# 선택지 위아래 여백 확대 시안

대사창은 승인된 직전 시안 그대로 유지했다. 선택지 기본 높이는 PC 56→72px, 큰 글씨 64→80px. 세로 안쪽 여백은 9→17px, 항목 간격은 12→16px. 텍스트는 세로 가운데 정렬했다. 화면 내 목록 높이 계산도 같이 맞췄다.

실제 게임 원본 배경·인물·대사를 사용하는 로컬 Chromium 화면 fixture로 직전 시안과 비교했다. 1280×720 화면 및 844×390 큰 글씨 화면에서 확인했다. Ren'Py lint와 웹 빌드 통과. 전체 이야기 진행 검사는 아니다.

height-comparison.jpg는 왼쪽 직전 시안, 오른쪽 높이를 늘린 시안이다. 공개본에는 적용하지 않은 디자인 검토 브랜치다.
