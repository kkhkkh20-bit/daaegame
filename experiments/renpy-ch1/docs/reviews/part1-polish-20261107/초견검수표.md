# 1부 초견 이용자 검수표

이 표는 실제 이용자의 이해·조작·재미를 확인하기 위한 양식이다. 0.20.119 개발 자동화 결과를 초견 이용자 평가로 대신 기록하지 않는다. 이번 작업에서 외부 이용자에게 연락하거나 평가를 받지는 않았다.

게임을 처음 보는 이용자가 설명이나 정답을 받지 않고 1부를 진행하게 한다. 모르는 부분은 이용자가 직접 자료를 다시 읽게 하고, 진행자가 해결 방법을 먼저 알려 주지 않는다.

| 물을 시점 | 이용자에게 묻는 말 | 기록 |
|---|---|---|
| 입구 사건 뒤 | 왜 들어갈 수 없었고 무엇을 밝혀 해결했나요? | 자기 말로 설명한 내용·다시 읽은 자료 |
| 3일 아침 사건 뒤 | 어제 한 행동과 오늘 상황은 어떻게 이어졌나요? | 실제 경로의 사건·인물 반응 이해 |
| 3일 추리 뒤 | 확인한 사실과 아직 모르는 것은 무엇인가요? | 관찰·추정 구별, 막혔던 제출/선택 |
| 화재 논증 뒤 | 불이 난 원인, 길이 막힌 일, 구조한 일을 각각 어떻게 판단했나요? | 실제 본 자료와 진술로 설명하는지 |
| 1부 마무리 뒤 | 엄마에 대해 어디까지 알았고 다음에 무엇이 궁금한가요? | 이어서 플레이할 이유, 이해 안 된 대사 |

조작이 막힌 위치는 장소·화면·누르려 한 대상·실제 반응·회복 방법을 적는다. 재미 평가는 몰입이 끊긴 장면과 더 보고 싶었던 장면을 이용자의 표현 그대로 남긴다. 평가 인원이나 점수만으로 판매 가능 판정을 자동으로 내리지 않는다.
