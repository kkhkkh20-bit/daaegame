# 신규 버튼 20종 독립 검수

2026-10-25. 제작·적용 담당과 별도로 검사했다. 차단 결함 없음. 게임 코드와 에셋은 검수 담당이 수정하지 않았다.

- 요청 ZIP의 CSV와 최종 PNG 20장·SVG 20장·manifest를 대조했다. 캔버스, crop, 실제 알파 경계, 중앙 안전영역, SHA-256 일치.
- 5계열의 기본·누름·선택 상태는 불투명 영역의 형태가 동일하다. 비활성은 같은 외곽에 45% 알파이며 가장자리 양자화 오차는 1/255 이내다. 캔버스와 알파 경계는 네 상태 모두 같다.
- 그림의 위치 이동은 0px, 런타임 글자·아이콘 눌림은 2px다. SVG와 제작 시트를 직접 확인했으며 이미지에 문자나 아이콘을 합성하지 않았다.
- 기존 에셋 3,149개 SHA-256 불변. 기존 상태 12종을 변형하거나 덮어쓰지 않았다.
- 실제 Ren’Py 메인·광장·질문 화면을 적용 전후 각각 격리 복사에서 캡처했다. 메인 누름/해제, 질문 선택, 터치 질문 페이지 전환, 돌아가기 검증 통과. 적용 전 3개, 적용 후 4개 assertions 통과. 실행마다 잔류 자식 프로세스 0개.
- 실제 폰트 렌더 13항목 실측: 기존 메인 28px와 질문 22/24px 문구 12항목은 축소 없이 안전영역 내 배치된다. 별도 긴 문구 `자료 보여주기` 24px는 내용 162px를 130px에 균일 축소(0.80247)한다. 모든 항목은 2px 눌림을 포함해 세로 안전영역 안이다.
- 최종 실제 캡처에서 메인과 질문 종이 높이 개선, 글자·아이콘의 충분한 여백, 광장 메뉴 버튼 정렬을 확인했다. 크림·빨강 종이색과 갈색 윤곽을 유지하며 이전보다 곡선이 정돈된 재질이다. 새 프레임/겹침/잘림은 발견하지 못했다. 기존 클릭 슬롯·액션은 유지된다.
