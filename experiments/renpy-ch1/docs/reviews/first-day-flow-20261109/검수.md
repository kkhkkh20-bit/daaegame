# 첫날 조사 순서와 시간 연결 — 0.20.137

사용자가 공감한 재검토의 다섯 문제를 첫날 범위에서 수정했다. 새 추리 사건을 추가하지 않았으며 정답·기회·등록 결과·증거 획득 효과·생사·결말은 유지한다.

| 재검토 항목 | 적용 |
|---|---|
| 메모는 초롱을 찾으라는데 지도에는 방만 보임 | 메모와 그림을 읽은 뒤 지도에 접수대를 함께 열고, 비교 전에도 할머니에게 질문할 수 있다. 문의 먼저/비교 먼저 두 순서를 지원한다. |
| 비교 버튼 직후 오전에서 저녁으로 바뀜 | 비교에서 시간 변경을 제거했다. 실제 문의 후 돌아오는 엄마를 놓칠까 걱정하는 다람에게 답하고, 접수대를 오가며 귀환을 확인하는 낮의 행동을 보여 준 뒤 저녁으로 잇는다. |
| 비교 결과가 기존 이동 지시로 되돌아감 | 작성자는 아직 단정할 수 없다는 판단은 보존한다. 초롱에게 엄마의 행방과 초대 편지 작성자를 함께 물으려는 의문으로 잇는다. 2일차 L0024~25의 실제 후속 질문을 확인했다. |
| 설명 반복 | 입구의 중복 수정 요청 두 줄과 도토리 습관 재설명을 덜었다. 다람의 자기 이름 확인과 첫 습관 설명은 보존한다. 먼저 문의한 사실도 이후 대사에 반영한다. |
| 가족 그림 가림·과자 행동/그림 불일치·자료 본문 공간 | 큰 메모/가족 그림을 읽는 동안 획득 알림과 만료를 대기한다. 과자 행동 지문에만 대화 인물을 숨긴다. 문서는 원문을 먼저 읽고 중복 요약은 출처에서 펼친다. 상단 안내 중복을 줄인다. |

## 검증

관련 단위194개와 생성 메타데이터36개 통과. 대사 검사 A/B/C 각각0건. SDK 화면 시험5개 통과: 먼저 문의한 뒤 비교와 낮/저녁 전환, 비교 취소·재개, 휴대폰 끝부분 직접 관찰, 가족 확대, 5일차 문서 공통 화면. 각 결과 파일을 함께 보관한다. 이번 범위는 긴 1~7일 전체 회귀가 아니다.

초기 단위 검사에서는 바뀐 문장을 옛 문자열로 찾던 검사가 실패해 새 질문의 의미에 맞췄다. 새 화면 시험 초기 조건은 마차에서 이미 관찰한 K01a를 미획득이라고 가정하고 추가 블록에 없는 line_id를 기다려 실패했다. 실제 대사와 proof_given 상태를 확인하도록 시험을 수정해 통과했다. 이 실패들을 게임 진행 불능으로 보고하지 않는다.

대사 문맥 검토에서는 기존 before의 위치 질문 중복, after의 난로 화제가 문의를 끊는 문제, 먼저 문의한 경로의 다람 걱정에 답이 빠진 문제를 발견했다. 중복 제거·난로 문답 이동·아빠 답변 추가 후 두 경로를 재검토했다. slop-rewrite는 프로젝트 설정인 가이드 없음으로 사용했으며 자동 통과를 재미나 문맥의 보증으로 쓰지 않았다. 비공개 취향·원문 bundle은 공개 기록에 넣지 않는다.

## 범위와 남은 한계

실무 의견으로는, 단서를 따라 먼저 물어볼 수 있고 기다리는 이유를 확인한다는 점에서 기존보다 납득되는 흐름이다. 첫날 후반이 여전히 방과 접수대를 오가며 기다리는 구조이며, 새 장소의 능동 탐문이나 새 사건까지 구현한 것은 아니다. 도토리 차이만으로 편지 작성자를 확정하지 않는다. 모든 인물의 그림체/비율 통일이나 전 구간 재완주를 완료했다고 보고하지 않는다.
