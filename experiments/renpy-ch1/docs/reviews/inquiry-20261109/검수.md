# 증거를 보여 준 뒤 상대에게 다시 묻는 조사 — 0.20.139

입구와 첫 방의 추리가 형식적인 자료 고르기에 머문다는 피드백을 이어서 반영했다. 이번 변경은 입구의 직접 제시와2일차 초롱의 후속 질문이다. 골목 사건 전체나1~7일 전체를 새로 설계·재완주한 것으로 기록하지 않는다.

## 바뀐 흐름

- 방문 신청 원본을 돌목에게 직접 제시한다. 실제 답을 다 들은 뒤 `gate_application_acknowledged`가 기록된다. 돌목이 신청서의 동행인을 인정한 발언은 근거 대조 화면에도 펼쳐진다. 기재를 인정하는 것과 등록을 고치는 것은 구분되며, 기존 명단+신청서의 최종 근거 제시가 남는다.
- 돌목에게 초대 편지·명단·규칙을 보여 주면 그 자료로 무엇을 확인할 수 있는지 짧게 답한다. 이미 인정한 신청서를 다시 처음 보는 것처럼 반응하지 않는다.
- 초롱에게 두 글을 제시한 뒤 ‘왜 여기서 펴면 안 되죠?’와 ‘두 글 모두 아내 글씨입니까?’를 선택해 묻는다. 필체 인정은 방 메모에 한정된다. 편지를 피하는 이유는 답하지 않으며 회피 이유를 새 설정으로 채우지 않는다.
- 질문을 다 골라야 교환함에 가는 것은 아니다. 이동은 처음부터 남고, 실제 답변 뒤 각 질문만 목록에서 빠진다. 두 자료를 확인하지 않은 옛 저장에는 후속 질문을 먼저 내보내지 않는다.
- 다른 자료·재제시 반응은 현재 상대와 이미 들은 답에 맞춘다. 반응 선택 함수는 조사 상태를 바꾸지 않는다. 실제 보유 여부와 첫 자료 응답은 기존 제시 판정을 먼저 거친다.

새 증거 ID·그림·정답 조합·회의 기회·생사·결말은 바꾸지 않았다. 돌목의 원본 인정 단계를 건너뛰고 기존 최종 근거를 바로 내는 경로도 남는다. 대조 화면의 발언 변경은 들은 상태에만 적용하고 공통 문맥 표를 변경하지 않아 새 게임으로 새지 않는다.

## 문안과 상태 검토

slop-rewrite는 프로젝트 설정인 가이드 없음으로 문안을 검토했다. 검출0건을 재미 판정으로 쓰지 않는다. 독립 문맥 검토에서 초롱의 재제시 답변이 실제로 발송자를 모른다고 단정하는 표현을 발견해, 우체국 장부 확인을 권하는 말만 남겼다. 원래 회피보다 인물의 지식 범위를 더 좁히지 않았다.

관련 단위113개와 생성 메타데이터24개가 통과했다. 대사 논리 검사 A/B/C0건. SDK 집중 화면 시험5개가 통과했다. 입구는 새 게임에서 실제 그림의 서류 조사→다른 자료 제시→원본 제시→발언 반영→명단+신청서로 등록까지 확인했다. 초롱의 후속 질문 시험은 두 자료를 확인한2일차 상태를 준비했고, 기존 두 제시 순서·취소·다른 자료와 첫 방 자유 읽기도 별도 확인했다.

초기 화면 시험 실패는 시험에서 한글 화자명과 내부 인물 키를 혼동한 것, 응답 뒤 질문 목록으로 이어지는 실제 흐름을 현장 복귀로 잘못 기다린 것에서 발생했다. 실제 대화 흐름을 기준으로 시험을 고친 뒤 통과했다. 최종 입구 시험은 빈 자동 선택·기회 소모 없이 기존 두 자료로 등록이 완료됨을 확인한다.

## 화면과 확인 범위

최종0.20.139 로컬 웹을 새 게임부터 마차·입구까지 실제 입력으로 진행했다. 그림의 서류에서 자료를 얻은 뒤 초대 편지 제시→돌목의 자료 범위 답변→방문 신청 원본 제시→기재 인정→근거 대조의 변경 발언 펼침을 확인했다. 발언은 바뀌지만 등록값은 아직 완료가 아니고 제출 자료도 자동으로 선택되지 않는다.1~7일 전체 재완주가 아니다.

PC1280×720과 가로 휴대폰 크기844×390에서 최종 웹의 발언과 자료 목록을 확인했다. 휴대폰 크기에서는 발언이 두 줄로 들어가고 자료 목록은 두 쪽으로 나뉜다. 두 글 확인 뒤 초롱에게 묻는 화면은 SDK 준비 상태 시험 캡처다.

## 평가

실무 의견으로는, 이번 변경은 자료 선택의 결과를 상대의 발언 변화로 보여 주고 의문을 실제 질문으로 받을 수 있게 한다. 입구는 여전히 작은 누락 확인 사건이고 초롱의 회피는 아직 미해결 단서다. 전체 추리 난도나 재미가 완성됐다고 판정하지 않는다.
