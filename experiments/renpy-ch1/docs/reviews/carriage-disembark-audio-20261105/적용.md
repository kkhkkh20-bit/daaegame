# 마차 하차 효과음 제거

2026-11-05 소유자 요청: “다람이 내릴때 나는 효과음 같은거 다빼줘. 이상하다.”

## 원인과 변경

- 하차 첫 대사 `MS14_D01_S02_L0002`에는 `fx=jolt`가 있었다. 이는 `r13_ep_line_art` → `r13_impact`에서 `sfx-present.wav`를 `scene_fx` 채널에 직접 재생하므로 `source_fx`의 옛 정차음 차단과 별개였다. 이 한 줄의 fx를 제거했다. 같은 fx가 담당하던 화면 흔들림도 함께 없어진다.
- `r13_carriage_finish`는 별도 정차음을 이미 재생하지 않았지만 바퀴·말발굽을 0.35초에 걸쳐 끊었다. 하차 때 두 채널과 직전 효과음 채널 `scene_fx`·`sound`를 즉시 정지하도록 했다.
- 일반 대사 타이핑, 배경음·환경음, 다른 장면의 효과음은 유지했다. 대사·기록·증거·생사·진행 분기는 바꾸지 않았다.

## 확인한 다른 경로

- `r13_sound_move`는 마차 → 입구 전환에 이동 효과음을 반환하지 않는다. 입구가 다시 잡혀도 같은 배경이면 효과음이 없다.
- 실제 마차 끝·입구 도착 줄의 before/after/replace를 모두 거쳐도 문·발걸음 sfx는 없다.
- 표정 반응 함수 `r13_react`는 이미 소유자 결정으로 반응음을 재생하지 않는다. 하차 소리는 표정 자체가 아니라 위 jolt 지시에서 났다.
- 원래 장면 시작에서 pulse·타이핑·scene_fx를 정지하는 흐름은 유지했다.

## 검증

`PYTHONPATH=dev python3 -m unittest test_carriage_disembark_audio test_carriage_seat_art`: 9개 통과.

신규 3개 시험은 즉시 정지 채널, 실제 마차 끝·입구 출력 줄을 원래 ep_art/impact 함수에 통과시킨 재생 0회, 다른 장면 jolt와 장소 이동음 보존을 확인한다. 담당 파일 diff 검사를 통과했다. 전체 검사·화면·공개는 메인 통합 단계에서 진행한다.
