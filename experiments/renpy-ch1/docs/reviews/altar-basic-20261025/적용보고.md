# 제단 기본자료 경로 보완

0.20.35: 14일 학교에서 4년 전 집별 배급표 사본을 확인해 별도 기록으로 얻는다. 내용은 기존 제단 완승 대사가 이미 사용하던 촌장 집의 최다 돌 배급과 같은 해 장작 한 달분 잔량이다. 벽의 이름과 이 기록으로 마지막 쟁점을 입증한다. 기존 너울 장부 정답과 진엔딩 장부 소지 요건은 유지한다. 두 출처를 모두 제출하면 장부 대사만 한 번 나온다.

단위 1,016개 통과. 대사 논리 A/B/C 0건. 관련 단위 60개와 네이티브 3개 통과. 새 조사→실제 마지막 쟁점 UI 제출→완승 43.061초, 기존 장부 경로 19.661초, 자료 없는 합성 경로 11.571초. 새 조사 시험의 앞선 1~3 쟁점은 상태 주입이므로 전체 자연 완주로 주장하지 않는다. 장부 미소지 진엔딩 불가와 장부 추가 후 가능도 확인했다.

기본 자료는 기존 배급표 그림을 그대로 재사용한다. 전체 자연 플레이와 모바일 실기기 검증은 미실행. 웹 빌드·브라우저 결과는 릴리스 기록을 따른다.
