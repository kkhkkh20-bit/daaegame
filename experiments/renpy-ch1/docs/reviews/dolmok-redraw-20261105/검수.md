# 돌목 대화 원화 검수

기본·웃음·화남·걱정·당황·놀람 6표정을 새로 제작하고 같은 승인 묶음으로 연결했다. 외형·표정 연출 변경이며 대사·분기·정답·생사는 바꾸지 않았다.

- 오소리 성인 경비, 장부·붓·청록 외투·빨간 목도리·부츠를 원화 기준으로 유지했다. 6원본 PNG와 해시, 세 크기의 18프레임 배율·좌표를 보존한다.
- 일반 대화·질문·근접 회의의 직접 정면 요청이 새 묶음을 쓴다. 비회의의 돌목 표정 연출도 같은 묶음을 고른다. 다른 인물과 비초점 회의 경계는 유지한다.
- 관련 정면 원화 단위 15개, 전체 단위 1,239개, lint 통과.
- 실제 새 게임의 첫 돌목 대사에서 기본 그림을 확인했다. 같은 장면에서 나머지 5표정과 실제 질문 부모 화면을 fixture로 렌더했다. 정확 560/760/840 크기의 알파 경계도 확인했다. 네이티브 시험 `guard_redraw_gate` 통과.
- 픽셀 좌표를 float로 저장하면 Ren’Py가 상대 비율로 해석해 정확 크기에서 그림이 화면 밖으로 나갔다. 정수 좌표로 고쳤으며 18프레임의 가운데·발선·범위와 실제 세 크기의 표시 검사를 추가했다.
- 놀람 원화 슬롯명은 `surprise_talk`, 실제 일반 대화 포즈는 기존처럼 `surprise`다. 그 별칭으로 전환해 별도 놀람 표정이 표시되는 것을 확인했다.
- 질문에서 돌목만 560 프로필로 표시해 얼굴과 수첩이 겹치지 않고 양쪽 부츠가 화면 안에 들어온다.
- 독립 검수에서 원화 해시·소품·의상·정면 시선·6표정의 같은 발 기준 및 질문·놀람 실제 캡처를 대조했다. 추가 필수 문제 없음.
- 전체 14일 자연 완주는 실행하지 않았다. 구버전 바이너리 저장 검사는 실행하지 않았으며 현재 판의 실제 저장 복원을 별도로 확인한다.

- 실제 Chromium 웹 새 게임에서 돌목의 첫 대사·PC 1280×720·휴대폰 844×390 표시를 확인했다. 현재 판에서 UI로 저장·불러온 뒤 대사·인물·포즈가 일치했다. 같은 장면의 5표정과 질문 화면을 fixture로 캡처했고 브라우저 오류는 0건이다.
- 웹 빌드·공개 묶음 검사 통과. SHA-256: `ed1c78c59ca94d2e50a67bd52040c97db7fc66cec918726bdb00246be34b4a6a`. 공개 URL 직접 열기는 네트워크 정책으로 제한되어 로컬 웹 실행·원격 해시·Pages 배포 성공을 대조한다.
