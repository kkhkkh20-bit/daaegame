# 브라우저에서 관찰한 대사 원문

자동화가 대사 대기 루프에서 읽은 화면 텍스트를 순서대로 보존했다. 줄바꿈과 반복을 유지했고 화자 이름을 추측해 덧붙이지 않았다. 시작 준비와 일부 회의 진입 클릭 구간은 이 루프 밖이므로 게임 전체 대본의 완전한 전사는 아니다. 원본은 [dialogue.json](browser/dialogue.json)이다.
