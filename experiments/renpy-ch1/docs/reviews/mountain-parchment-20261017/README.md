# 외부 지도 톤 검수

- 원인: 마을 지도만 양피지 선화이고 산 지도는 파란 설경 그림이었다.
- 결정: 산 지도는 고유한 네 목적지 이동에 필요하므로 유지하고 밝은 양피지·갈색 잉크로 통일.
- `mountain-hidden.png`: 온실·제단이 발견 전에는 일반 숲으로 가려짐.
- `discovered-altar.png`: 후반 조건에서 네 목적지가 모두 나타남. 기존 발견 조건 사용.
- `village-match.png`: 기존 마을 지도와 실제 브라우저에서 비교.
- `mountain-mobile.png`: 844×390 실제 터치 화면.
- `result.json`: 브라우저에서 실제 마우스·터치로 네 목적지 선택과 상태 불변을 검사. 전체 이야기 완주가 아닌 상태 주입 화면 검수.

반투명 경계에 숨김 나무가 비치는 것을 확인해 발견 패치는 불투명하게 변경했다. 기존 패치 검사는 투명 채널을 요구했으므로 새 불투명 재질에 맞춰 RGB도 허용했다. 발견 분리·이미지 크기·경로·선택 마스크 검사는 유지했다.

검수 도중 초반 시설을 클릭하려던 fixture가 날짜에 따른 실제 이동 제한에 걸렸다. 초반에는 열린 장소만 검사하고 후반에는 네 장소를 모두 검사하도록 바로잡았다. 게임의 이동 조건은 변경하지 않았다.
