## 바뀐 비용과 지킨 것

- 호환 그림 5개 자체의 합은 9,343,127 B다. 새 코드의 코어 증가를 합산한 시작 묶음의 순감소가 위 표의 9.33MB다. 원본 파일은 남고 원격 목록에 들어간다. 현행 포스터·표지·글꼴·마차 8표정은 보존한다.
- 107개 예열 **목록의 개수는 유지**했다. 시작 전 실행을 막고 첫 입력 뒤 800ms 유휴 시간부터 전역 한 요청씩 받는다. 전경 파일 요청은 이 제한의 대상이 아니다. 숨긴 탭·절약 모드는 새 예열 요청을 멈추며 이미 받는 한 파일은 끝날 수 있다.
- 다음 날 예열을 없앴다. 날짜가 바뀌면 대기 중인 이전 파일을 버린다. 뒤 날짜 저장을 바로 열어도 공통 인물이 목록에서 빠지지 않게 완전한 날짜 목록과 전역 URL 중복 제거를 조합했다.
- 같은 경로 목록에 기존 디렉터리 알고리즘을 대입하면 mkdir 시도 17,839회다. 부모 폴더를 기억하면 고유 692개 수준으로 제한된다. 이는 경로 목록에서 계산한 호출 수이며 절약된 시작 시간을 실측한 숫자가 아니다.
- `Registry.resolve_path`는 불변 경로 문자열만 공유한다. `resolve`의 가변 명세 복사, 연결 변경·태그 변경의 캐시 무효화와 실패 복구, 직접 경로의 안전성 검증을 유지한다.

## 독립 검토에서 고친 것

처음 수정은 목록이 없는 날짜에 이전 예열 대기열을 남겼다. 1일은 첫날 목록을 사용하고 빈 날짜도 이전 대기열을 교체하게 고쳤다. `7→1→99` 전환과 중복 URL을 Node 실제 비동기 요청 모형으로 검사했다. 저장의 예열 표시를 초기화하고 실제 날짜를 다시 알리는 단위 검사도 추가했다.
