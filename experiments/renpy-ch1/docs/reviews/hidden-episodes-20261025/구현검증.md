# 숨겨진 에피소드 구현·검증

2026-10-25. 소유자가 시안의 새 가족 신원과 장치 원리를 승인한 뒤 구현했다. 버전 0.20.43.

## 적용

- 판돌의 누나: 6일 숟가락 관찰·소개, 7일 버려진 핀을 허락받아 수리하고 집 발견, 11일 가설 승리와 학교 장작 실제 인수 뒤 남는 몫을 허락받아 난방 교체, 13일 나비에게 실제 인계.
- 모과를 누나로 바꾸지 않으며 기존 명단·탑승·생사·회의 결과를 수정하지 않는다. 인계자가 이송·명단·사망 상태면 완료하지 않는다. 즉시 완치 대사도 없다.
- 먼저 만난 판돌은 11일 재회 대사를 사용한다. 6일 선택 대화에서는 기존 장면 인원을 유지한다.
- 고대 기지: 1일 종이·7일 판·11일 표시를 모은 진엔딩 판만 14일 선택 방문. 틀린 방향은 소모·사망 없이 재시도. 구조·사고·수첩을 조사하고 위치·시각·인물·기존 진행을 복구한다.
- 새 장소에서 일반 주민 일정·일상 자료 반응이 끼어들지 않게 했다. 명시 선택 번호를 유지하여 기존 선택지를 밀지 않는다.
- 전용 배경·인물 그림은 미납품. 기존 집/옛 시설 배경을 임시 재사용하고 누나에게 다른 인물 그림을 붙이지 않았다. 그림 요청서를 다른 채팅에 보내지는 않았다.

## 검증 범위

- 전체 자동 검사 1,066개와 Ren’Py lint 통과. 원본 줄 위치에 따른 자료표를 갱신했다.

- 대사 A/B/C 검사 각 0건. 6·7·11·13·14일 정적 분기 분석은 미해석 조건과 의심 9건을 보고했다. 전부 실오류가 없다는 판정으로 사용하지 않는다. 자세한 원출력은 `branch-audit.txt`.

- 전체 1~14일 자연 플레이 및 전체 대사 개작은 이번 범위에 포함하지 않는다.

- 네이티브 화면 시험 4개 최종 통과: 단서 부족, 방문 거절, 문 방향 오답·정답/자료/귀환, 난방 교체/인계자 부재/정상 인계. 문 선택 페이지와 인물 대화 닫기까지 시험에 반영했다.
