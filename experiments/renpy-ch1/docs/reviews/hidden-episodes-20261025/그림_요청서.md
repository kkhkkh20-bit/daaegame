# 숨겨진 에피소드 그림 요청 초안

상태: 설계 검토용. 외부 디자인 채팅으로 보내거나 제작을 실행하지 않았다. 가족 신원·기지 원리 확정 뒤 아래 항목만 요청한다. 기존 UI·글꼴·그림 비율을 따른다. 배경에는 아빠를 그리지 않으며 문자는 게임에서 얹는다. 확정 전 이름·기계 원리를 그림 안에 새기지 않는다.

## 판돌 가족

| 번호 | 그림 | 반드시 보여 줄 것 | 피할 것 |
|---|---|---|---|
| P1 | 판돌 집 문간 배경 | 수리 쟁반, 식기 보따리, 여닫는 문, 가족이 설 자리. 새 조사지점이 인물에 가려지지 않을 공간 | 모과의 귀환을 암시하는 얼굴·붉은 목도리 |
| P2 | 집 안 배경과 상태 차분 | 앉는 자리, 난로, 돌 바구니, 장작 상자, 돌을 식힐 보관함. 교체 전/후는 같은 구도 | 난로만 끄면 따뜻한 방이 되는 연출, 잠금장치가 정답처럼 빛남 |
| P3 | 판돌 누나 인물 시안 | 기존 판돌과 가족으로 읽히는 노년 인물, 중립·경계·피곤한 표정. 이름을 아직 잃지 않은 증상 단계 | 괴물화·광기 과장, 모과 초상과 동일인처럼 보이는 디자인 |
| P4 | 생활 물건 묶음 | 두꺼운 숟가락 손잡이, 빠진 고정핀, 수리 전후의 같은 물건 | 반짝이는 열쇠처럼 그리기, 기존 회의 증거를 대체하는 문양 |

P1·P2를 한 장으로 합칠 수 있는지 먼저 시안을 비교한다. 실내 전체를 미리 보여 숨긴 가족의 존재를 누설하지 않게 문간과 안쪽 시야를 구분한다.

## 고대 기지

| 번호 | 그림 | 반드시 보여 줄 것 | 피할 것 |
|---|---|---|---|
| A1 | 기존 시설에 이어지는 정비실 문 | 종이 자국, 홈과 손잡이, 금속판의 앞뒤를 구분할 실물 차이 | 알파벳 비밀번호, 정답 순서 표시, 다른 마을 지도 |
| A2 | 정비실 내부 배경 | 단면판 자리, 점검표 선반, 엄마 수첩 자리. 조작 가능한 손잡이와 통로 | 시체·새 제단·새로운 범인 초상, 바깥 문명의 결말을 정하는 폐허 |
| A3 | 세 조각 | 본뜬 종이, 세 구멍 금속판, 방향 표시를 옮겨 적은 종이. 서로 겹쳐지는 크기·방향 일치 | 기존 11일 돌판/14일 밑돌과 혼동되는 외형, 완성 경고문을 미리 노출 |
| A4 | 단면판·점검표 자료 | 승인된 구조가 읽히는 그림 칸과 짧은 글의 빈자리. 전후 상태는 동일 장치로 비교 가능 | 현대 의학 용어·수치, 사람을 태워 작동하는 구조 |
| A5 | 엄마 현장 수첩 | 현장에서 본 스케치·덜 끝난 기록, 기존 엄마 물건과 일관된 재질 | 엄마가 목격하지 못한 범행 장면, 「재」의 정답 |

## 공통 납품·검수

- 배경 원본, 인물 투명 원본, 물건 분리 원본, 상태별 목록을 함께 받는다. 확장자는 저장소 아트 반입 규칙으로 변환한다.
- 세계 좌표와 조사지점은 시안 확정 후 잡는다. 기존 1280×720 표시와 넓은 배경 방식에 맞춰 PC·모바일에서 실제 클릭 영역을 확인한다.
- 단서의 유무·앞뒤·구멍 간격은 대사와 대조한다. 판이 바뀌었는데 그림 속 돌·장작이 이전 상태로 남지 않아야 한다.
- 제작 순서: P1/P2·A1/A2 구도 시안 → 신원 승인 후 P3 → 퍼즐 규격 확정 후 P4·A3 → 진상 문구 확정 후 A4/A5.
