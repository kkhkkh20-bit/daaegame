# Font comparison — actual game captures

Proposal only, no production deployment. All three options use regular weight 400, with identical sizes, colour, layout and authored dialogue.

- A / galmuri: Galmuri11 Regular throughout.
- B / pretendard: Pretendard Regular throughout.
- C / serif: Noto Serif CJK KR Regular for the question screen's character name and heading; Pretendard Regular for dialogue, questions and controls. Its dialogue capture is intentionally identical to B.

Each prefix has dialogue.png, questions.png and mobile-questions.png. Captured using real Chromium RenPy web runtime, not a painted mockup.

Font sources: https://github.com/quiple/galmuri · https://github.com/orioncactus/pretendard · https://github.com/notofonts/noto-cjk
