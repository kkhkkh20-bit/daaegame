# 등록 뒤 너울 등장 연결

2026-11-05. 소유자 보고: 돌목에게 자료를 낸 뒤 여관으로 가려는데 인사 없이 너울이 갑자기 말을 걸어 오류처럼 보인다.

## 원인

`registered_menu`에서 여관 출발을 고르면 `registered_depart`로 이어진다. `d01.json`에는 너울의 진입을 알리는 지문이 있었지만, 인사와 자기소개 대신 곧바로 장부 규칙을 말하도록 쓰여 있었다. 이름과 역할을 앞서 질문하지 않은 경로에서는 누구인지 더 불분명했다. 또한 지도에서 먼저 여관을 고른 경우 초소로 배경만 되돌리는 보정 함수는 있었지만, 현재 배우 목록과 실제 위치를 다시 맞추지 않았다.

## 적용

- 출발 직전 까로에게 짐을 받으려는 아빠 앞에 장부를 낀 사람이 초소 안쪽에서 다가오도록 지문을 바꿨다.
- 돌목이 “너울 씨, 이 두 분도 방금 등록했소”라고 먼저 부른다. 이름 정정에 성공한 판과 ‘외 한 명’ 판 모두 실제로 두 사람이 등록됐다는 범위만 말한다.
- 너울이 직접 인사하고 마을 장부 담당임을 밝힌 뒤 여관으로 가는지 묻는다. 아빠는 아내의 편지를 받고 13호실로 가려 한다는 현재 알고 있는 방문 목적을 답한다.
- 이 문답 뒤에 기존 숙소 변경 신고 규칙이 나온다. 아빠의 답을 적은 너울이 돌목 쪽으로 돌아서는 지문을 넣어, 이후 “부인이 나타나면 여관에 먼저…”의 실제 수신자가 돌목이며 아빠도 곁에서 듣는 상황을 명시했다.
- `r13_v111_depart_from_booth()`는 정상 출발과 지도 출발 모두 초소의 돌목·다람·까로·다가온 너울을 현재 배우로 등록한다. 지도로 여관을 먼저 골랐다면 위치를 초소로 되돌린 뒤 배우 위치를 맞추고 초소를 다시 그린다. 이미 고른 여관 출발은 기존 `v111_depart_direct`로 이어져 재선택을 요구하지 않는다.

## 보존

기존 등록 성공/실패, 원본 records, 증거, 정답, 엄마 관련 지시의 완료 commit과 `heard_inn_order1`은 바꾸지 않았다. 아빠가 누가 부탁했는지와 왜 아내를 찾는지 되묻는 기존 문답, 다람의 불안과 여관에서 직접 묻겠다는 답도 그대로다. 아직 확인하지 않은 엄마의 부재·행선지나 부탁한 사람의 정체를 추가로 알려 주지 않는다. 5일 엄마의 편지에서 처음 드러나는 내용도 앞당기지 않았다.

## 검증

`PYTHONPATH=dev python3 -m unittest test_opening_departure test_newworld_text test_novel_game_early test_v111_early_topic_flow` 39개 통과.

새 시험은 정상/지도 출발 × 이름 정정 성공/실패 네 상태에서 실제 초소 위치·배우 위치·바로 이동 상태와 증거/등록 결과 보존을 확인했다. 인사·자기소개·아빠 답변 뒤에 규칙을 말하는 순서, 돌목을 향해 돌아선 뒤 지시하는 순서, 정정한 표/정정하지 않은 표의 갈림도 확인했다. 별도 공통 when 추가는 없다.

전체 검사·화면·생성 갱신·웹 빌드·커밋은 메인 통합에서 실행한다. 하차 효과음 수정은 다른 담당이며, 이 작업에서는 오디오 코드를 수정하지 않았다.
