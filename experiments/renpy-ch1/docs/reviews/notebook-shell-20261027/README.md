## 바뀐 점

- 틀 한 벌 `game/systems/room13_notebook_shell.rpy` — `screen r13_notebook_shell(title, subtitle, close_action, tabs, current, note, stamp, rule_y)`.
  배경은 갈림길·설정창과 같은 `b_opt_panel.png` 를 (-4,-4) 에 그대로 깐다(1288x728, 화면에 온전히 들어옴).
  제목 (114,64)·부제 (114,112)·회차 표기 (1150 오른쪽 끝, 78)·닫기 X (1176,60 / 휴대폰 1170,52) 는 갈림길 좌표 그대로.
- 안쪽 영역 `R13_NB_INNER=(132,140,1074,544)` → x 132~1206, y 140~684. 왼쪽 132 는 고리(x 90~127) 오른쪽, 아래 684 는 갈림길 하단 버튼 줄.
  종이(크림)는 y 646 에서 끝나므로 맨글씨·목록·뷰포트는 `R13_NB_TEXT_BOTTOM=640` 위에서 끝낸다.
- 기록 화면의 모든 탭(자료·사람·대화·메모·달력·소지품)이 같은 판·같은 상단 탭 줄(자료 사람 대화 메모 갈림길)을 쓴다.
  사람·대화·메모 탭의 왼쪽 세로 메뉴와 옛 종이 틀(`R13TravelSheet`)은 지웠다. 자료 탭의 `R13DiaryPanel`(고리가 판 밖으로 잘리던 것)도 이 판으로 바뀌었다.
- 하단 버튼 줄: 오른쪽 아래 한 줄, 공통 부품(`R13_CONTROL`) 높이 64 / 큰 글씨 80 / 휴대폰 88, 폭 136(갈림길 「닫기」와 같다).
  닫기가 맨 오른쪽, 그 왼쪽에 탭별 버튼(달력 › / ‹ 메모 · 지난 주 · 다음 주 / 전체 관계도·인물 중심 / 출처 펼치기·나란히 놓기).
  자료 탭의 쪽 넘김·출처·나란히 놓기 버튼도 같은 높이로 맞췄다(전에는 48/56/88).
- 글자 크기는 `r13_type` 단계만 쓴다: 제목 hero, 묶음 제목 subtitle, 본문 body/emphasis, 보조 small. 하드코딩 크기는 없앴다.
- 모든 글에 xsize 를 주어 넘치면 줄바꿈된다. 안내 글(사람·메모 탭)은 하단 줄이 아니라 제목 오른쪽(종이 안)에 둔다.
- 갈림길: 판·제목·부제·회차·닫기 X 를 공통 틀로 그리고, 하단 버튼의 오른쪽 끝을 1206 에 맞췄다. 나머지는 그대로.
