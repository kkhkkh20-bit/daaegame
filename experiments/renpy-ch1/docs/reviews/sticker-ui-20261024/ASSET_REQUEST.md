# 선택창 수정 시안 원본 확인 요청

최신 기준은 채팅에 첨부한 **「선택창 · 수정 시안」**이다. 다람이가 자기 수첩을 화려하고 펑키하게 꾸민 느낌, 굵은 고딕체, 흰 스티커 외곽, 진한 갈색 선을 유지한다. 시안을 재해석하지 않는다.

현재 저장소에는 이전 B안 부품과 구형 도트 다람이가 있다. 최신 시안의 아래 분리 원본은 찾지 못했다. 먼저 원본 폴더나 ZIP 위치를 확인한다. 임시 제작품을 최종 원본으로 취급하거나 공개하지 않는다.

표시 크기는 구현 기준이며, 고해상 원본을 같은 종횡비로 내려 쓴다. 캔버스 여백과 실제 그림 경계가 다르면 둘을 메타데이터로 구분한다. 가로·세로를 따로 늘리지 않는다. 늘어나는 부품은 원본에 명시한 중앙 영역만 늘리고 모서리·선 두께는 보존한다.

## 먼저 고정한 배치

- 제목: x240,y180,w520,h112. Pretendard Bold 36, 큰 글씨38.
- 선택 카드: x220,y320/432/544,w560,h96. 간격16. 세 카드의 크기는 동일하다.
- 숫자칸: 카드 기준 x60,54×54. 본문 x160,32/34px.
- 긴 문구: 가장 긴 문구에 맞춰 모든 카드 높이를 함께 늘리고 페이지를 나눈다.
- 빨간 테두리와 도토리는 포커스 표시이며, 정답이나 사건 결과를 암시하지 않는다.

## 검토 상태

실제 Ren'Py 렌더러로 동일한 마차/다람/편지 문구를 캡처한다. QA 장면은 이야기·보상·해금 데이터에 들어가지 않는다. 현재 비교본은 구형 원본 캐릭터와 제작 중 부품이 섞인 **미완성 작업본**이다. 최신 분리 원본 수령 후 선택창을 먼저 맞추고, 그 다음 화면으로 진행한다.
