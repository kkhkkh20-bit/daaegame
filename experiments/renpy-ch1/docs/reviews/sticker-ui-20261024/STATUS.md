# 동화 스티커 UI 작업 상태

공개판은 0.20.28을 유지한다. 소스의 0.20.29는 개발 중이며 커밋·push하지 않았다. 먼저 만들었던 미완성 웹 빌드는 공개 폴더에서 되돌리고 `/tmp/r13-notebook-unpublished-web`에 보관했다.

## 최신 기준

모든 UI가 다람이의 화려하고 펑키한 수첩이다. 실제 Bold 고딕, 흰 스티커 테두리, 진한 윤곽, 동일한 버튼 규격을 공유한다. 시안의 화면 배치와 비율을 구현하고, 선택창부터 한 화면씩 비교한다. 원본 부품이 없으면 유사 제작물을 최종으로 간주하지 않는다.

## 완료한 개발 작업

- Pretendard Bold 1.3.9를 공식 저장소에서 추가하고 OFL/출처 정보를 기록했다.
- 선택창 1280×720 좌표·카드 간격·동일 행 높이·번호/문구/테이프 영역을 분리했다.
- 질문용 수첩, 실제 글꼴을 반영한 페이지 측정, 동일 폭 하단 버튼, 읽은 질문 재선택을 구현했다.
- 선택 도중 원래 무대 캐릭터를 보관하고 저장·복원 후 같은 객체로 되돌린다.
- 생성 부품은 원본과 런타임을 분리해 보관했다. 최종 채택 전 작업본이다.
- 메인/조사/지도 및 공통 부품의 1차 변경은 소스에 남아 있으나, 선택창 원본 대조가 끝날 때까지 후속 화면 작업·공개를 보류한다.

## 비교본

`choice-side-by-side.png`는 저장소의 최초 B안 원본과 현재 실제 Ren'Py 화면을 각각1280×720으로 나란히 표시한 브라우저 캡처다. 채팅에 나중에 첨부한 「선택창·수정시안」의 원본 파일과 분리 PNG는 아직 작업 디렉터리에 없다. 따라서 이 비교를 최신 수정안에 일치했다는 증거로 쓰지 않는다.

남은 차이: 배경 원화의 화풍, 다람이 원화·포즈·흰 외곽, 제목 종이 외곽, 선택 카드 원본, 무늬 테이프, 도토리·열매 장식. 필요한 파일과 표시 규격은 `ASSET_REQUEST.md`, 고정 좌표는 `choice-layout.json`에 기록했다.

## 검증

- 최신 네이티브: `b_choice_reference`, `b_notebook_questions`, `b_notebook_choices` 통과. 포커스/터치/질문 페이지/읽은 질문 클릭/선택 저장·불러오기 확인.
- 앞선 관련 회귀: `long_topic_list`, `b_dialogue_stickers`, `gate_zoom`, `b_map_touch` 통과.
- 전체980개 단위 실행에서 공통표면 교체에 따른 기존 테스트2개 수정 필요를 확인했다. 나머지978개는 통과했다. `test_visual_correction`의 렌더링 mock과 정렬 검사식을 갱신한 뒤 해당 모듈5개 전부 재통과했다.
- 최종 웹 공개 검증·push는 진행하지 않았다. 원본 부품 확인 및 화면 대조가 먼저다.
