# 현장 조작 단순화 — 0.19.50

소유자 지시에 따라 인물을 기본으로 표시하고 대화는 인물을 직접 눌러 시작한다. 주변 살피기는 인물을 숨겨 조사 지점을 표시하는 한 개의 전환 버튼이다. 별도 사람과 대화·조사 지점·현장 더보기와 장소 바로가기는 제거했다. 지도와 상단 메뉴, 기록의 역할은 유지했다.

조사 대상 선택은 사실·시간을 바꾸지 않으며 ‘살펴보기’를 눌러야 실제 조사로 이어진다. 조사 중 자동 지점 표시, 선택 대상 이름, 선택 지점의 강조로 호버 없이 조작할 수 있다. 같은 공통 부품과 기록 우측 하단 정렬을 유지했다. 빈 칸에 행동을 추가하지 않는다.

## 검증

`dev/check.sh`: 단위 테스트410개 및 Ren’Py lint 통과. 공식 빌더로 생성한 웹판을 Chromium에서 실행했다. PC1280×720 및 터치844×390(큰 글씨)의 제한된 UI fixture 검증이며 전체 이야기 플레이 리뷰나 실제 휴대폰 하드웨어 검증은 아니다.

- 인물 기본 표시와 배경 조사 전환, 중복 버튼 제거.
- 기존 바로가기 버튼에 가려졌던 열쇠 중심 좌표 클릭이 열쇠를 선택하며 지도를 열지 않는다.
- 실제 지도 이동, 장소 변경 시 인물 모드와 빈 선택 상태.
- 코트 선택 후 카메라 이동 시 화면 밖 대상 선택 해제.
- 지도 취소 시 전체 게임 상태·카메라·모드 보존.
- 터치로13호실→학교→13호실 이동, 카메라는 복원하고 과거 선택은 복원하지 않는다.
- 기록 복귀 시 읽음 표시(record_ui) 외 이야기 상태 보존.
- 주민을 직접 눌러 첫 대면 말 걸기 선택을 거쳐 질문 화면 진입 및 현장 복귀.

실행 스크립트: `dev/qa_field_simplification.py`. 결과는 `report.json`, 아래 PNG는 생성 이미지가 아닌 실제 브라우저 캡처다. 기존 조사 증거는 `../investigation-usability-20261018/`에 남겨 두었다.
