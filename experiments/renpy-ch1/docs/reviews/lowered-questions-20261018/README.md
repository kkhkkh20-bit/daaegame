# 0.19.53 질문 영역 하단 조정

소유자 지시: 칼바람과 대화할 때 제목과 짧은 질문 목록이 너무 상단에 있으므로 우선 아래로 내린다.

인물 이름과 ‘묻고 싶은 이야기’를 y70→150으로 함께80px 내렸다. 질문 목록은112→192이며 질문 수 표기도 함께 이동한다. 인물 그림, 하단 명령 버튼, 자료 보여주기 위치와 질문 해금 로직은 유지한다. 공통 `R13_SIDE_QUESTION_TOP` 하나가 제목·이름·목록 시작점과 가용 높이를 함께 결정한다.

질문이 많을 때는 새 높이에서 각 행을 측정해 명시적인 페이지로 나눈다. PC/터치의1·2·8·12개 목록에서 질문 행이 페이지 조작·자료 보여주기·하단 명령과 겹치지 않는지 확인했다. 8/12개 예시는 부리의 여러 이야기 단계 제목을 섞은 시각 fixture이며 동시에 열리는 실제 질문 수를 의미하지 않는다.

칼바람 캡처는 실제 대화 디스패처에서 아내를 묻는 질문을 선택하고, 기존 목격담 대사를 진행해 질문1개→2개가 되는 화면이다. PC1280×720, 터치844×390/큰 글씨를 사용했다. 이름과 제목 기준선을 실제 캡처에서도 확인했다. 전체 이야기 플레이 또는 실제 휴대폰 하드웨어 검증은 아니다.

`dev/check.sh`(단위+Ren’Py lint)와 `dev/qa_lowered_questions.py`를 통과했다. PNG는 실제 브라우저 캡처다. 결과는 `report.json`.
