# 불타는 밤 구현 검증

## 반영

- 승인 근거: `docs/design/WILD_NIGHT_DESIGN.md` 6장. 가설·제단 모두 완패한 아침 줄기에서만 저녁 뒤 진입한다.
- 12일 학교 침상 목록, 13일 까로의 큰 집 소식과 초소 돌목의 기억 이상을 조건부로 연결했다.
- 학교 교실·복도·광장·산길 어귀·첫 굽이·폐온실을 연결했다. 기존 현장 조사·인물 질문·지도 이동을 쓴다.
- 열 없음/있음 × 지체 0~3의 결과를 `wild_family`로 기록한다. 별도 가족 생존 플래그는 쓰지 않는다.
- 제단 회의에 갈림길 표시, 불타는 밤 결말 기록을 추가했다.
- 열이 있는 판의 업기·안기 표현 불일치를 정리했다. 다람과 아빠가 서로 손을 놓지 않겠다고 주고받는 대사를 추가했다.
- 밤에는 일정표의 평상시 주민을 더 세우지 않는다. 곁에 있는 가족을 누르면 탈출 상황에 맞게 답하고, 주변 사물의 평시 설명도 나오지 않는다.

## 검사 범위

- 단위: 진입 128조합, 열×지체 8조합, 미기록 지체 기본값. 전체 1,054개 실행 뒤 후속 블록 위치 검사 실패를 고쳤고, 최종 관련 73개를 통과했다. 밤 인물 배치 회귀 시험도 추가했다.
- 대사 검사 A/B/C 0건. 14일 분기 검사에서 신규 의심 줄 없음. 기존 부리의 받침 대사 유사성 1건은 그대로다. 정적 분석기가 계산하지 못한 조건은 실제 결과 화면 시험으로 별도 확인한다.
- 네이티브: 결말 진입, 가족 4조합(엄마를 잃는 두 원인 별도), 부분 승리 제외 2개, 현장 연속 진행 2개. 9개 모두 통과. 마지막 산길의 돌목도 화면을 옆으로 움직여 실제로 누르고 질문을 선택했다.
- 화면 시험은 14일 준비 상태에서 시작한다. 현장 연속 시험은 판정값을 중간에 덮어쓰지 않고 실제 대기 라벨과 행동 처리를 거친다. 지도 목적지 선택 일부는 화면 반환 계약으로 전달한다.
- 전체 처음부터 자연 플레이·모든 이전 분기와의 조합 재생은 이번에 반복하지 않았다.

## 그림

기존 장소 배경과 불 소리로 구현했다. 신규 배경 6장은 등록 상태이며, 검토 후보 4장을 자연 장면에 적용하지 않았다. 이번 작업에 새 UI 디자인은 없다.
