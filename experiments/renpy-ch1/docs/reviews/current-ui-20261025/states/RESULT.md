# 지도 상태 스티커·기존 버튼 상태 세트 적용

## 적용
- 납품 지도 상태96px 원본4종 보존. 현재 위치/선택/잠금은 기존 공개 지도 행에만 연결한다. 잠금은 현재 장소가 아닌 기존 shown/locked 행이며 새 해금 조건은 추가하지 않는다.
- 새 대화는 지도용 기존 판정이 확인되지 않아 보관만 하고 표시하지 않는다. 숨은 통로/지하/온실/제단은 기존 공개 조건을 유지한다.
- 버튼 12종은 메인, 지도, 조사 조작, 질문 하단에 연결. 넓은 선택은 조사 버튼에 재사용하며 질문 카드 디자인은 변경하지 않는다. 설정 전용 버튼·정사각 아이콘 버튼·대사 이름 리본은 원래 계열 유지.
- 같은 계열4상태를 동일한 공통 알파 영역(primary/standard136×40, wide232×52)으로 잘라 투명 여백만 제거. 9-slice나 가로세로 개별 늘림 없이 균일 배율로 고정 클릭영역 안에 가운데 정렬한다.
- 상태 우선순위: 비활성→누름→선택→기본. 누름 그림·글자·아이콘2px 이동도 같은 배율로 적용. Button의 기존 액션·클릭·드래그 판정은 유지한다.
- 웹 초기 다운로드 목록에 작은 버튼/상태 PNG를 포함했다. 공개 웹 빌드/배포는 이번에 하지 않았다.

## 검증
- current_ui_capture 통과(메인/설정/조사/대사/질문/선택/여관/숲).
- b_ui_button_states 통과: 실제 마우스 누름 그림 상태, 떼면 동작1회, 비활성 클릭 무효, 선택버튼 동작.
- b_map_status_early 통과: 1일차 잠금·현재·선택/선택해도 이동하지 않음/미발견 장소 비공개. 초기 시험의 비공개 숲탭 클릭을 제거해 실제 초반 UI 조건에 맞춰 재검증했다.
- b_map_village_delivery 통과: 드래그 상태 불변/스크롤/학교·진료실·장터/구역전환/숨은장소/모바일캡처/취소/광장 실제이동.
- b_map_inn_forest 통과(19개 검증), 관련 단위12개 통과, 독립 코드 검수에서 차단 결함 없음.
- 모바일 실기기/브라우저 pointercancel과 전체 회귀는 수행하지 않았다. 모든 캡처는 개발본이다.
