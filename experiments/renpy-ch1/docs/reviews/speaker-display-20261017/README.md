## WASM 검수 증거

전달 검수 ZIP에 원본 PNG와 결과 요약을 보관한다. 배경/인물은 기존 게임 자산을 그대로 쓰는 검수 상태이며, 자연 진행 캡처와 구분한다.

- 전후: 밝은 눈밭(누비), 어두운 실내(모모), 긴 이름(부엉이 할아버지), `???`, `누비 · 모모`, 844×390 기본/큰 글씨.
- 전후 픽셀 차이 경계: 누비 `(254,500,398,541)`, 모모 `(254,500,362,541)`, 긴 이름 `(254,500,479,541)`. 모두 이름표 영역 안이며 대사창·인물·배경은 동일하다.
- 첫 대화 화면/누비 인물 상세/회의 이름표 확인. 인물 목록에 만나지 않은 사자 선생님이 나타나지 않음.
- 자연 새 게임의 이름 있는 대사 진입. 오프닝은 저장 도구를 숨기므로 저장 검수에 한해 `place` 표시값으로 일반 대사 도구 모음을 노출한 fixture를 사용한다. 실제 저장/불러오기 버튼을 클릭하고 원래 packet이 유지되는지 비교한다. 이후 반복 클릭 8회를 확인한다.
- 전체 게임 완주/모든 분기/이전 배포 저장의 버전 간 이행 검사는 하지 않았다. 이름표 변화와 관련 화면에 한정한 검수다.

최종 소스에는 이름이 포함되지 않은 익명 질문 제목에서 역할 줄을 숨기는 조건을 추가했다. 이 마지막 표시 조건은 캡처 이후 추가했으므로 `room13_screens.rpy`의 최종 해시와 WASM 결과의 소스 해시만 다르다. 알려진 이름의 비교 시안에는 영향이 없으며, 최종 파일의 정식 빌드/화면 검수는 통합 담당에게 남긴다. 질문 관련 단위 검사 7개와 diff 검사 통과.

최종 캡처 육안 검사에서 모모/부리 인물 상세 캡처는 검수 overlay의 선택 상태가 누비에 남아 있음을 발견했다. 이 두 PNG는 전달 ZIP에서 제외했다. 3개 표시 예시는 코드/metadata 기준이며, 상세 화면의 모모·부리 전환은 통합 환경에서 재확인해야 한다. QA 도구는 실제 인물 선택 버튼을 누르도록 수정했으며 이 도구의 마지막 수정은 재실행하지 않았다.
