## 날짜·시간·상태 검사

`runtime.json`, `schedule.csv`, `schedule-summary.json`, `nabi-schedule.md`를 참조한다.

실제 WASM의 최종 r13_where/r13_stage_people로 1~14일, 아침/오후/저녁, 5가지 상태(routine/offers/losses/shelter/case_prevented)를 계산했다. 관련 20명×210상태=4,200행이다. 31개 승인 동작 모두 한 번 이상 선택됐으며 다음 오류는0이었다.

- 같은 상태에서 식당·주방 등 두 장소에 동시 등장
- 일정 장소와 실제 등장 장소 불일치, 예정된 조사 주민 누락
- 다른 장소의 지도 동작 잔류
- 날짜/시간대/행사/배경 폭 가드 우회
- 사망·구금으로 제외된 주민의 재등장

어린이 피난, 누비 보호, 환자 이동, 할머니 구금, 사망·구금 깃발 및 사건 미발생 상태를 구분했다. 새로운 일과는 나비의 기본 아침 슬롯에만 적용된다. 기존 이야기의 모든 선택 조합을 완주한 검사는 아니며, 검사에 사용한 구체적인 상태와 결과를 JSON에 남겼다.

나비5종의 실제 얼굴 클릭, 2종 저장 복원, 실제 지도 메뉴의 주방→식당→주방 왕복을 확인했다. 아침 식당에는 나비가 없고 돌아오면 같은 주방 동작으로 복원된다. 시간이 흐르지 않았다. 추가18동작의 가구 접점/누비3장소/현이3장소 실화면은 `../action27-remaining/`의 검수와 동일한 좌표다.

## 그리기·접점과 보존 범위

- 신규 원본4는 승인 ZIP/manifest와 각 PNG 해시/크기가 일치하며 `art/approved-nabi-kitchen-extra4/`에 그대로 보관했다. 기존 KI-1은 덮어쓰지 않았다.
- 새 열린 냄비는 기존 닫힌 냄비/주전자와 다른 화구 빈 면에 둔다. 앞 조리대는 실제 상판 접점에 도마·그릇·쟁반을 맞춘다. 접시는 조리대 옆에서 닦는다. 없는 싱크/수도꼭지는 만들지 않았다.
- 지도용만768 높이·2px 격자다. 원근과 작은 뷰포트에서의 표본 손실은 `../map-pixel-output/`에 기록했고, 최종 화면 전체를 pixel-perfect로 주장하지 않는다.
- 대화 원본·표정·배경·내부 ID·저장 키·사건 조건·보상·단서는 보존했다. 활동 설명만 식당의 실제 쟁반 동작에 맞췄다.
- 전체 단위+lint 검사를 통과했다. 첫 검사에서 새 함수 삽입으로 기존 대화 감사 줄번호가 밀리는 것을 발견해 함수를 파일 끝으로 옮겼다. 대화 감사 레지스트리를 다시 쓰거나 대사를 바꾸지 않았다.
