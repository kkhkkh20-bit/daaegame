## 변경

- 27개 원본 파일은 GitHub 도구로 확정 커밋에서 읽었고 모든 Git blob SHA를 검증했다. 25 PNG의 manifest SHA-256도 일치한다. Library 재시도 없음.
- 실제 원본 판·선택 버튼·미리보기와 전체 25 PNG 모음 그림을 열어 확인했다. 이는 게임 화면 검수가 아니다.
- `screens.rpy`의 옵션 스타일·pause_menu만 변경. 판은 원래 캔버스 1288×728을 (-4,-4)에 얹어 실제 그림 (12,12,1256,696)을 유지. 고리 포함 판은 늘리지 않는다. 기술판(64 inset)은 원본 보관만 한다.
- 선택 버튼은 16px 투명 여백을 제거한 뒤 24/16 모서리를 고정한다. 탭은 32/20 모서리 고정. 고리와 겹치지 않도록 왼쪽 탭은 x96, 폭200으로 조정하고 기존 PC76/터치88 높이는 유지한다.
- 음량 막대는 그림 높이20, 손잡이36을 유지한다. thumb_offset=0으로 손잡이가 막대 밖 백분율 글자를 가리지 않게 한다. 두 볼륨 줄 외 기존 타이핑 소리·효과음 듣기·음악 출처도 유지한다. 임의 설정 추가 없음.
- 미리보기는 860×110 원래 그림 크기. `room13_typing_preview.rpy`는 글자색만 갈색으로 변경했다. 샘플 문구·타이핑 동작 불변.
- 하단 버튼은 기존 B 메인 버튼을 재사용하고 닫기를 강조한다. 기존 하단 좌표·폭·터치 높이 유지.
- 초기화·홈·단축키·저장·음소거 아이콘과 선택 장식은 글자/터치 공간 검수가 끝나기 전 보관만 한다. 새 컨트롤을 만들지 않았다.
- 대사·사건·생존·분기·조사·회의 로직 변경 없음. 옵션 action 목록 비교 동일, 옵션 구간 밖 screens 내용은 기존 PR head와 동일.

## 검증과 제한

- 전체 Python 단위 검사 971개 통과. 초기 2개 실패(주석의 size 문자열 오인, 이전 손잡이 offset 기대값)는 주석 정리 및 새 손잡이 간격 검증으로 해결 후 전체 재실행 통과.
- 옵션 동작 6개, 시각 프레임 5개, 글자/터치 배치 7개 단위 검사 통과.
- 기존 시각 테스트의 납품 파일명 기대값을 B 자산으로 갱신하고 동일 crop/모서리 검사를 추가했다. 음량 검사는 새 손잡이 크기와 0 offset, 백분율 간격을 검증한다. 테스트 삭제·약화 없음.
- CI 기존 진단 목록 앞에 settings_volume_endpoint, settings_typography, settings_touch, title_fx를 추가했다. 기존 조사/회의 검사·실패 처리·권한은 그대로다.
- 로컬 SDK 다운로드의 기존 CONNECT 403은 재시도/우회하지 않았다. 로컬 Ren'Py lint, PC/모바일 실행, 실제 스크린샷은 미실행이다. 정적 좌표·원본 픽셀 확인만으로 실제 화면 통과를 주장하지 않는다.
- 기존 head CI는 resource-index 성공, verify-build는 단위/lint 후 조사 6개 실패. main에는 비교 가능한 verify-build 실행이 없어 선행 실패인지 미확정이다. 이번 head의 CI 결과는 PR에서 별도로 확인해야 한다. 안전한 병합 조건 충족 전 draft 유지, 병합/배포 금지.
