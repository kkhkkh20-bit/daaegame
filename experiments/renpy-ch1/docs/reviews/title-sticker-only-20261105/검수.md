# 메인·로딩 캐릭터 스티커 적용

요청: 왼쪽 마을 그림을 빼고 오른쪽 캐릭터 스티커만 남긴다. 기존 로고와 게임 메뉴의 위치·기능은 유지한다.

- 실제 Ren’Py `title_sticker_capture` 화면 시험 통과. 마을이 없는 남색 바탕과 로고·캐릭터·메뉴를 확인했다.
- 로딩 관련 단위 시험 3개 통과. 메인·로딩의 바탕·레이어·좌표, 로딩 파일 복사와 내용 해시 주소, 음악 안내 조건을 검사했다.
- 독립 검수에서 HTML 루트 로딩 파일 복사, 생성기와 실제 합성 파일, 브라우저 캐시와 letterbox 색을 대조했다.
- 새 그림을 제작하지 않고 메인의 마을 배경층을 제거했다. 로딩 그림은 기존 생성기로 메인과 같은 구성으로 합성했다.
- 전체 게임 자연 완주 검사는 실행하지 않았다.

- 전체 단위 시험 1,234개와 Ren’Py lint 통과.
- Chromium 실제 웹 로딩을 지연시켜 PC 1280×720·휴대폰 844×390의 로딩 화면을 캡처한 뒤, 같은 세션의 메인과 설정 열기·닫기·터치를 확인했다. 브라우저 오류 0건.
