# 본편 4~6일차 논리 검수 · 0.20.91

소유자가 1~3일차 검수 뒤 ‘6일까지 달려보자’고 요청한 범위다. 기존 실제 3일차 저장에서 이어 4~6일차를 진행하고, 대사·기록·판정·인물 위치를 대조했다. 새 판 v2와 7일 이후 전체 주행은 이번 범위가 아니다.

| 6일 구조 준비 | 학교에 보낸 다람을 기본 동행 처리로 다시 화재에 데려옴 | 복귀 이동에 빈 동행 목록을 명시해 다람을 학교에 남김 |

E23은 실제로 수거한 천을 무쇠가 벗어 둔 옷과 맞댄 기록이다. 자연 경로에서는 E22 수거 뒤에만 얻는다. 따라서 E23을 제출했을 때 수거 기록을 다시 안 냈다는 이유로 현장 연결을 부정하지 않는다. 피코 그림은 기존대로 그날 밤 차림을 보강하며, 물린 순간을 찍은 기록으로 바꾸지 않는다. 현장 연결·최초 목격·착용자 가운데 빠진 축은 여전히 부족한 제출로 처리한다.

보리의 장작 절취와 화재 책임을 섞는 너울의 주장은 사건 속에서 반박할 주장이다. 이를 서술자의 확정 사실로 고치지 않았다. 학교의 허락과 실제 네 아이 인계도 구별하며, 생사·부상·결말·회의 기회는 유지했다.

## 검증

- 전체 단위 검사 1,169개, Ren’Py lint 통과.
- 대사 자동 검사 A 소개 전 이름, B 사망 가능 화자 무조건 대사, C 결과 지문 중복 모두 0건.
- 관련 화면 시험 7개 통과: 식당 대화 위치와 세 인물, 학교 허락과 다람 반응·꼬미 부재, 실제 학교 왕복 뒤 다람 잔류, 6일 오늘 인계·내일 약속 분기, 5일 승리·패배.
- 증거 판정 회귀 검사에서 기존 네 장·기존 그림 세트·새 대체 두 세트·관련 보강을 허용하고, 핵심 축이 빠지면 거부하며 적절한 반박으로 이어짐을 확인했다.
- 이름표 회귀 검사는 실제 이름표 계산 함수를 종업원·진료 담당자에 적용해 중단이 재발하지 않는지 확인한다.

브라우저 진행은 실제 현장·지도·대화·자료 버튼을 누르는 자동화다. 각 대사 쪽을 넘기며 기록한다. 선택에는 실제 실행 코드의 정답 목록과 경로 도우미를 사용하므로 처음 보는 사람의 눈가림 시험과 구별한다. 글자 속도·조회·검사 저장 외에 줄거리 값이나 보유 자료를 주입하지 않았다. 네이티브 화면 시험은 장면 직전 상태를 준비한 회귀 검사로, 전체 자연 주행과 구별한다.

수정 전 실제 주행은 5일 회관의 이름표 오류에서 중단됐다. 이를 자동화의 입력 실패로 분류하지 않았다. 수정 후 브라우저 결과·선택·제출 자료·저장 복원·공개 묶음 해시는 `검증결과.json`에 기록한다.

모든 조작 순열과 7~14일 전체 주행은 미실행이다. 공개 도메인은 환경의 네트워크 정책으로 직접 접속할 수 없어, 로컬 공개 묶음을 브라우저에서 확인하고 원격 파일 해시·Pages 작업으로 배포를 확인한다.


## 실제 진행 결과와 화면

실제 0.20.90의 3일차 저장을 0.20.91에서 이어 6일차 취침 전까지 도달했다. 5일 증명에는 E20·E23·E24 세 자료를 실제 UI로 제출했다. 네 아이를 오늘 인계한 경로와 실제 6일차 오후 저장에서 내일 약속을 선택한 구조 경로를 각각 끝까지 확인했다. 두 경로 모두 기존 결과가 유지됐고, 구조 복귀 뒤 다람 위치는 학교였다. 브라우저 페이지 오류는 모두 0건이다. PC·휴대폰에서 실제 저장 메뉴로 저장한 뒤 새로고침·불러오기를 했으며, 6일차 위치·자료·진행 값이 같았다.
