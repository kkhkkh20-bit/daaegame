# 책 표지 메인 검수

소유자 「안보이는데 해봐」로 시안 적용을 승인해, 실제 메인과 웹 로딩을 같은 배치로 구현했다.

- 로고·6인 스티커 원본의 SHA-256이 이전 판과 동일하다. 생성한 장식 배경만 새 파일로 추가했다.
- 전체 단위 1,234개 통과. 최종 Ren’Py lint를 단독 실행해 완료했다. 기존 미도달 지문 안내 외 파싱·누락 파일 오류는 없다.
- 실제 엔진 화면 시험 3개 통과: 저장 없음 메인, 키보드로 비활성 행을 지나 설정 열기, 실제 새 게임을 저장하고 메인 복귀→불러오기→돌아가기→이어하기.
- Chromium에서 PC 1280×720·휴대폰 844×390 로딩·메인 캡처, 세로 메뉴 정렬, 키보드 설정 진입, 터치 설정 열기·닫기를 확인했다. 브라우저 오류 0건.
- 메인과 로딩은 같은 배치 JSON을 읽으며 새 장식 배경·기존 로고·포스터가 모두 첫 화면 필수 로딩에 포함되는 것을 확인했다.
- 시안에 그려진 글씨·캐릭터를 통째로 버튼 이미지로 쓰지 않았다. 텍스트·버튼·저장 상태는 실제 UI이고 인물은 기존 승인 원본이다.
- 초기 병행 검사의 lint 프로세스가 화면 시험 실행기에 의해 종료되어 단독 재실행했다. 저장 후 키보드 검사는 남은 마우스 위치의 영향을 없애도록 시작 행을 지정한 뒤 통과했다. 이전 별도 작업의 소스 없는 actor_layout.rpyc가 네이티브에 남아 있어 해당 산출물만 /tmp로 격리했다. 웹 빌드는 기존부터 rpyc를 제외하므로 영향 없다.
- 전체 게임 자연 완주는 실행하지 않았다. 공개 URL 직접 접속은 네트워크 정책으로 제한되어 로컬 웹 실행·원격 묶음 해시·Pages 배포 성공으로 확인한다.
