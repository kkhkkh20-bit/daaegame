# 다람탐정 UI 통일성 검토 — 0.20.40

## 판정

아직 통일되지 않았다. 남색 수첩·크림 종이·빨간 강조색은 공유하지만, 실제 부품은 링 수첩, 갈색 서류판, 다중 테두리 장식판, 새 스티커 버튼으로 나뉜다. 공통 색만으로는 같은 UI처럼 보이지 않는다.

## 화면별 관찰과 우선순위

| 화면 | 관찰 | 제안 |
|---|---|---|
| 옵션 | 수첩 외곽·도토리 슬라이더·작은 장식은 컨셉에 맞음. 탭/제목은 본문 버튼보다 가늘고, 선택색은 남색·빨강이 혼용됨. 읽기/화면 탭의 미리보기 아래가 현재 뷰포트에서 잘림 | 선택 상태와 강조 행동의 색 의미를 정하고, 미리보기가 한눈에 들어오도록 높이 조정 |
| 회의 자료 대조 | 작은 상단 제목이 테두리에 걸쳐 보임. 갈색 서류판과 길고 얇은 다중 테두리 버튼이 수첩 UI와 다름 | 1순위. 기능/판정 유지, 수첩 패널과 단순 스티커 버튼 적용 |
| 회의 대사 | 수첩 대사창은 맞지만 인물은 도트 윤곽으로, 질문창의 흰 스티커 외곽과 다름 | 캐릭터 표현 규칙을 대화/질문과 함께 정리 |
| 회의 재시도 | 바깥 수첩은 맞지만 버튼이 큰 클래식 다각형 장식판 | 1순위. 버튼 윤곽·테두리를 통일. 중요도는 크기와 빨강으로 구분 |
| 기록 | 링 없는 갈색 서류판, 테두리 굵기/색이 질문 수첩과 다름 | 1순위. 질문/옵션과 같은 수첩 계열로 연결 |
| 대사 | 수첩·흰 테두리 캐릭터·이름 리본이 일관됨 | 유지. 건너뛰기/더보기의 리본 형식은 다른 보조 버튼과 역할별 기준 정리 |
| 질문 | 수첩·캐릭터 스티커가 맞음. 하단 버튼은 얇은 갈색 테두리라 조사 버튼과 다름 | 2순위. 하단 도구 버튼의 재질·윤곽 통일 |
| 선택 | 캐릭터가 도트 그림이며 흰 스티커 외곽이 없음. 제목은 단정한 직사각 판, 선택지마다 같은 위치에 테이프 반복 | 2순위. 승인 캐릭터 스티커 연결, 제목/선택지의 장식 밀도 정리 |
| 메인 | 로고·인물 묶음은 스티커 컨셉이 명확함. 하단 버튼은 다른 화면보다 평평하고 작게 보임 | 3순위. 현재 배치 유지, 버튼 계열만 맞춤. 이어하기/불러오기 회색은 새 저장 프로필의 비활성 상태로 정상 |
| 조사 | 공통 스티커 종이와 방향표시는 맞춰짐. 장식 반복도 장소명 한 곳으로 줄임 | 새 기준 부품으로 사용. 다른 화면까지 통일됐다는 의미는 아님 |
| 지도 | 마을은 수첩 안에 하단 조작부가 있고, 여관/숲은 수첩 밖 별도 바를 사용함. 버튼 형태와 제목 위치도 다름 | 2순위. 지도 3종의 외곽·헤더·하단 구조 통일 |
| 갈림길 | 외곽은 수첩이지만 현재 위치 배지·이전/다음·닫기가 클래식 다각형 | 1순위. 방향표시와 보조 버튼부터 교체 |

## 공통 기준

- 같은 역할의 부품은 같은 윤곽·테두리 굵기·폰트 굵기·상태 표현을 사용한다.
- 작은 컨트롤마다 테이프를 붙이지 않는다. 장식은 화면의 대표 위치에만 제한한다.
- 크림 종이/남색 수첩/흰 스티커 외곽을 공통으로 하되, 큰 수첩 패널과 작은 라벨까지 똑같은 모양으로 만들지는 않는다.
- 빨강은 주요 행동/강조, 남색은 글자·외곽 중심으로 역할을 정리한다. 현재 상태색 정리는 별도 적용 검토 대상이다.

## 캡처 범위와 한계

현재 소스0.20.40의 Ren’Py 화면을1280×720로 렌더했다. 실제 사용자의 저장은 변경하지 않고 격리 복사본을 사용했다. 질문/선택 문구·갈림길 진행은 QA fixture이며 UI는 실제 공통 컴포넌트다. 회의는10일차 상태를 주입해 실제 라벨로 진입한 예시이고, 재시도 화면은 디자인 확인을 위해 별도로 표시했다. 자연 플레이 전체/모든 회의 분기 검증은 아니다.

초기 일괄 캡처는 구형 QA roam이 v111 상태를 지워 갈림길 진입에서 실패했고, 상태를 보존해 앞부분11장을 다시 촬영했다. 회의는 장면 선행 조건을 갖춘 별도 fixture로 분리했다. 이 캡처 준비 문제를 게임 UI 결함으로 집계하지 않았다.

게임 디자인/대사/분기는 이번 검토에서 수정하지 않았다. 검토용 스크립트와 캡처만 추가했다.
