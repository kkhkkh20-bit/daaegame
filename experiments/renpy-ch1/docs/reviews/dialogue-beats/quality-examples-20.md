# 대사 감정 명세 품질 표본 (20개)

이 문서는 이미지 승인서가 아니다. 모든 신규 리소스는 HOLD이며 활성 등록부는 비어 있다.

## 작성 방식과 숫자의 의미

- 정적 1,808행: 1,422행은 장면별 문맥 검토 후 감정을 지정했다. 같은 장면에 공통 이유를 쓴 행이 있으며 1,422개의 독립적인 서술형 판정문을 작성했다는 뜻은 아니다. 나머지 386행은 원본 대사 묶음이 완전히 같은 레거시 재독 별칭을 기계적으로 복사했고 놀람 동작을 껐다.
- 동적 리터럴 972행: 소스와 인접 대화를 읽고 묶음별 기본 감정(대부분 neutral)을 수동 지정한 뒤 인덱스별 예외를 수정했다. 972행 전부에 별도의 상세 이유를 쓴 것은 아니다. 행 추출·SHA 계산·JSON 작성은 자동화했으며 키워드로 감정을 추론하지 않았다.
- 달력·추가 명세도 문맥별 기본값과 행별 예외 방식이다. 실행 감사에서 확장 JSON 누락과 나비의 기본/동행 분기 간 모순을 발견해 이번에 보완했다. 따라서 과거 “리터럴 미검토 0”을 런타임 전체 검토 완료와 같다고 볼 수 없다.
- 아래 예시는 이번에 앞뒤 대사까지 다시 읽고 이유를 개별 작성했다. 회의와 조사 동작은 별도 렌더러로 유지된다.
