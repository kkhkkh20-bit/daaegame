# B안 옵션(설정)창 — 에셋 요청서 (2026-10-24)

소유자 지시: "옵션창도 에셋 요청서 만들어".

기준 화면: 지금 게임의 설정창(`game/screens.rpy` `screen pause_menu`, 1280×720). 구성과 기능은 그대로 두고 겉모습만 B안(크림 종이·갈색 손그림 선·흰 테두리 스티커·네이비/코랄 포인트)으로 바꾼다. 아래 "보이는 크기"는 1280 기준, 투명 여백을 뺀 실제 그림 크기다. 캔버스는 사방 16px 투명 여백을 더한다. 공통: 투명 배경 PNG, **그림에 글자 없음**(글자는 게임이 쓴다), 정면, 기존 B안 납품(`b-ui`, `b-ui-question-v2`)과 같은 선 굵기·색.

## 지킬 것

- 글자는 그림에 넣지 않는다. 버튼 글자 크기가 「크게」(글자 크기 설정)일 때 버튼 높이가 88까지 늘어나므로, 버튼·탭은 세로로도 9-slice 가 되게 그린다.
- 다크 모드가 따로 있으면 같은 이름 뒤에 `_dark` 를 붙인 판(종이색을 짙은 갈색으로)도 함께 받는다. 지금 게임 설정창은 밤 잉크(짙은 갈색) 하나뿐이다 — 다크판을 둘지는 소유자가 정한다.
