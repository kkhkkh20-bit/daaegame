# B안 UI 에셋 요청서 (GPT 이미지 생성용)

목적: 다람탐정(Ren'Py, 1280×720 화면) B안 수첩 스타일 UI를 실제 게임에 넣을 **부품 그림**. 첨부한 B안 시안 6장의 스타일을 그대로 따른다.

## 공통 규칙 (모든 요청에 붙인다)

```
스타일: 첨부한 B안 시안과 같은 손그림 동화풍. 크림색 종이(#F7EEDA 근처), 따뜻한 갈색 테두리,
빨간 리본(#C44038 근처), 마스킹테이프, 도토리 장식. 부드러운 종이 질감과 얕은 그림자.
배경: 완전 투명(PNG 알파). 배경색·바닥·그림자 판을 깔지 말 것.
글자: 그림 안에 어떤 글자도 넣지 말 것(한글·영어·숫자 모두). 글자는 게임이 따로 쓴다.
구도: 정면, 기울이지 않음, 원근 없음. 잘리지 않게 사방에 여백 16px.
한 장에 부품 하나만.
```

## 받은 뒤 제가 하는 일

1. 크기·투명도·가운데 비움을 확인하고, 모자라면 다시 요청할 목록을 드린다.
2. 판은 9-slice로 잘라 Ren'Py `Frame`으로 늘려 쓰고, 글자는 Pretendard 고딕체로 게임이 쓴다.
3. 같은 장면으로 시안 캡처를 다시 만들어 보여 드린다 → 승인 → 적용.

주의: 그림에 정답·범인을 암시하는 물건이나 강조를 넣지 않는다. 선택 강조(빨간 테두리)는 "지금 고르는 중" 표시일 뿐이다.
