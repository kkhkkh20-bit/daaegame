## 배치

- 수첩 틀(1280×720)을 **0.86 배**로 줄여 (90,2)에 둠. 아래 조작 줄(y602~712, 승인된 공통 부품)과 겹치지 않으면서 틀 아래 띠가 보이는 가장 큰 배율이다. 지도 창은 화면 기준 (166,52) 977×490.
- 틀 아래 띠(원래 캡션 자리)에 왼쪽은 구역 이름·현재 위치, 오른쪽은 안내 또는 「○○ · 지금은 이곳으로 갈 수 없습니다.」 알림을 씀. 그래서 예전 여관 머리판과 숲 안내 줄은 B 탭에서 없앰.
- 탭·이동·현장으로 버튼은 아래 조작 줄에 그대로 있어 수첩 틀과 겹치지 않음. 탭 위치·크기는 바꾸지 않음.
- 스티커는 납품 상자 안에 그림 비율대로 가운데 맞춤. 이름표는 게임이 그림(여관 이동 칩과 같은 크림 판). 현재 위치는 이름표 앞에 「현재 · 」를 붙임.
- 떠오름: 고르거나 마우스를 올리면 기존 마을 지도와 같은 `r13_map_pop`(1.05배, 위로 5px), 원래 자리에 옅은 그림자, 이름표도 5px 함께 올라감. 떠오른 스티커는 이웃 그림에 가리지 않게 맨 나중에 그림. 터치는 올림 단계를 쓰지 않음(기존과 같음).
- 누를 자리: 스티커가 실제로 보이는 곳 + 이름표(`focus_mask`). 버튼 id 는 기존 그대로 여관 `map_room_*`, 숲 `map_building_*`, 갈 수 없는 공개 장소 `map_locked_*`.
- 「이곳으로 이동」 판정(`can_travel`), 여관 안내(`r13_inn_guide` = 지역 연결만 이동), 탭 전환, Esc 닫기, 키보드 포커스는 바꾸지 않음.

## 스포일러 처리 확인

- 화면은 `r13_bmap_places`(= `r13_map_nodes` + 숲의 `r13_map_locked_nodes`)가 돌려준 장소만 그린다. 새 공개 조건은 만들지 않았다. `r13_map_locked_nodes` 는 원래 폐온실·제단을 빼므로 공개 전에는 흐린 그림도 나오지 않는다.
- 숨은 장소는 스티커·이름표·버튼·툴팁·접근성 이름(alt)이 모두 없다. 화면 시험이 해당 id 의 위젯이 없음을 확인한다(`r13_qa_bmap_hidden_absent`).
- 숲: 폐온실·제단이 지도에 없으면 그 자리에 가림판만 그린다. 가림판은 버튼이 아니고 떠오르지 않는다. 판정은 예전 `r13_cart_cover_visible` 과 같다(지도에 나오면 가림판을 치움).
- 여관 숨은 통로는 가림판이 없어 공개 전에는 아무것도 그리지 않는다(빈 바탕만).
- 단위 시험: 숨은 곳이 판정 목록에 없으면 결과에 없음, 화면이 배치표를 직접 돌지 않고 판정 목록만 돈다는 점을 고정.

## 부족한 부품 / 임시 처리

- **옛 시설(ancient, 지하)**: 납품에 그림이 없다. 지금 코드에서는 `passage_open` + `ancient_found`(2주차 13호 뒤 통로의 갈라진 벽) 뒤에 지도에 나와야 하고, 그곳에 있을 때 지도를 열면 여관 탭에서 현재 위치로 고른다. 예전 목록에는 「지하」 줄이 있었다. 임시로 **사각형 그림을 만들지 않고 다른 장소와 같은 이름표 한 장만** 지면 오른쪽 아래(지도 안 1078,548)에 둔다. 이름표를 누르면 고르고 이동할 수 있다. 화면 시험 `b_map_revealed` 가 이 상태를 찍었다(`captures/bmap-pc-inn-ancient-label-only.webp`). 필요한 부품: 지하 옛 시설 스티커(투명 PNG)와 놓을 자리. 여관 바탕에 지하층이 없으므로 바탕 아래쪽에 지하 단면을 더하거나, 숨은 통로 아래에 놓을 작은 계단 스티커가 필요하다.
- 임시 객실은 숙박·사건 조건 전에는 자리가 비어 보인다(기존 목록에서도 나오지 않던 곳). 숨김 그림이 아니라 그냥 빈 칸이다.
- 다크/라이트 구분은 이 게임에 없다(밤 잉크 UI 하나).

## 마을 탭과 다른 점(그대로 둠)

- 마을: 옛 손그림 지도, 끌어서 둘러보는 넓은 화면, 왼쪽 위 이름판과 위쪽 안내 줄, 장소 윤곽선(이동 가능 표시), 글씨가 그림에 박힌 이름. B 탭: 수첩 틀, 고정 화면, 아래 띠 안내, 흐림(갈 수 없음)/선명(갈 수 있음), 게임이 그리는 이름표.
- 탭을 오가면 테두리·색조가 확 달라진다. 마을 v2 가 오면 같은 `r13_map_b` 로 옮길 수 있게 배치표 구조를 지역별로 짜 두었다.
