# 납품 UI 도구함 등록 대조 (2026-10-25)

## 확인 결과

`game/assets` 이미지·글꼴·소리 3,101개는 모두 도구함에 등록돼 있었다. 부족한 것은 파일 등록이 아니라 화면 용도를 알 수 있는 의미 역할이었다. 기존 18개에 34개를 추가해 총52개로 정리한다.

추가 범위: 메인 배경, 질문 수첩·제목·이름표·아이콘·선화, 조사 수첩·마스코트·위치/더보기, 대사 이름표, 설정 미리보기·장식6종, 마을/여관/숲 수첩과 바탕·마스코트, 새 대화 지도표시 원본, 종이 효과음3종.

의미 역할은 기존 `file:assets/...`와 같은 group·match·캔버스·media를 공유한다. 파일 별칭 전파가 이미 연결된 화면에 적용되며, 현재 선택된 그림·효과음·표시 조건은 바꾸지 않는다. `new_dialogue`는 원본을 찾는 역할만 추가한다. 새 대화의 판정·발생 조건을 새로 만들지 않는다.

정적 역할은 재시작 대상으로 명시한다. 기존 live 지도 아이콘3개는 live 속성을 유지한다. 스캔을 다시 해도 사용자가 정한 연결·태그·렌더 정보·한국어 이름을 보존한다.

## 보류·제작 요청

- 신규 정사각 버튼4장, 메인8장, 질문도구8장: 원본 미납품. 기존그림 늘리기·유사그림 대체를 하지 않았다.
- 정확한 요청 묶음: `design/requests/pending-ui-buttons-20261025.zip`. 정본요청서/CSV20행/기존승인원본/비교캡처/원본경로와 SHA-256 포함.
- 기존 자료 후보인 돌아온그릇·돌목무효그림과 청음 보류 후보01은 기존 결정을 유지한다. 새로운 자료ID·이야기·실패/재시도 조건을 추가하지 않는다.

## 검증

임시 프로젝트에서 새 스캔 실행 후 기존3,104개 역할의 모든 상태에 대해 최종 파일 경로가 변하지 않았음을 확인했다. 새 효과음 역할의 audio 종류와 질문 수첩 의미역할/파일역할의 동일 group을 확인했다. 병렬 실제 캡처 종료 후 최종 catalog/bindings에 저장했다. 최종 등록3,101개·전체역할3,138개(의미역할52개). `asset_toolbox.py validate` 통과, `test_asset_toolbox.py` 15개 통과.
