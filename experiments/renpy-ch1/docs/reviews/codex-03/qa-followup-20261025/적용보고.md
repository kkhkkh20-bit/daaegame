# 병합 뒤 화면 시험 4개 수정 (2026-10-25)

게임 로직과 디자인을 바꾸지 않고 시험을 현재 수첩 UI에 맞췄다.

- 군중 선택지는 긴 제목·카드 높이에 따라 페이지가 나뉜다. 첫 페이지에서 다음 항목을 기다리던 시험을 실제 「다음 →」 버튼으로 이동하도록 수정했다. 세 페이지 캡처로 각 항목과 탐색 버튼을 확인했다.
- 촌장 거래는 조건 대화 뒤 첫 항목이 보일 때까지 진행하고, 다음 페이지에서 수락 항목을 확인한다.
- 질문 하단 버튼은 「자료 제시」다. 기존 「자료 보여주기」 탐색을 고쳤다. 다람에게 편지를 제시하고 돌목의 자료 창을 열고 닫는 기존 흐름이 끝까지 통과했다.
