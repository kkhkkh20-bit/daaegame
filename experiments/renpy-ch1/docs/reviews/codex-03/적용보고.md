# 디자인 인계 10묶음 적용 보고 — 0.20.32 검수본

최신 이야기 브랜치 `claude/cool-gates-s9msjz`의 `726b1294`에 기존 다람이 수첩 UI 작업을 3-way 통합했다. 이전 `/workspace/daaegame` 작업본은 보존했고 현재 작업본은 `/workspace/daaegame-apply`이다. 소유자가 제작은 다른 채팅, 디자인 적용·검수는 이 Codex가 맡아 알아서 진행하도록 승인한 범위다. 첨부 지시서03에 따라 main·Pages에는 직접 반영하지 않는다.

## 적용한 것

- 아랫길 노인: 전용 전신·기본 얼굴을 기존 `v111_lowerroad_elder`에 연결. 공유 `elder`와 생사·표정 분기는 유지. 일반/큰 글씨·터치 화면 확인.
- 배급표: 기존 `NW_NUBI_TICKET` 그림만 새 납품 WebP로 교체. 이전 파일은 art/batch02-elder-ticket-20261025에 보존. 자료 화면의 작은 탭·자료 종류·그림 상자는 기존 B 부품으로 정돈하고 제목 띠와 목표 글자 대비를 보완했다.
- 효과음: 수첩 열기02/종이 버튼03/자료 다루기04를 기존 소리 이벤트에 낮은 음량으로 연결. CC0 출처 기록 보존. 디코딩·길이는 확인했으며, 직접 청음 완료로 주장하지 않는다. 피크0dB인01은 적용하지 않았다.
- 갈림길: 추천 A안. 미확인 결과는 개수만 표시하고 대승리 이름·조건·방법·배지는 미리 드러내지 않는다. 기존 grand:fire/soup 확정 이벤트로 회상 기록을 승격하고 같은 실행의 이김 중복 수집을 막는다. 이전 실행의 실제 이김 기록은 복원한다. 카드175×116 유지, 네 결과는 열별 스크롤, 결과명·회차 두 줄 분리와 얇은 B 윤곽. 읽기 화면은 기록을 쓰지 않는다.
- 지도 시험: 새 B 지도13곳·뷰포트·배율에 맞춰 QA helper를 갱신했다. 강가·숲·시장·여관 복도는 실제 버튼을 누르며 선택/이동을 검증한다. 플레이 상태로 선택 값을 주입하지 않는다.
- 기존 UI 통합: 굵은 고딕, 메인 A안 포스터, 다이어리 옵션, 대사·질문·선택·지도·버튼 상태를 유지. 실제 큰 글씨/터치 대사와 컨트롤 입력영역의 비중첩을 확인했다.

## 표시 준비까지 완료한 것

- 회의 재시도: PC·터치 화면과 실제 accept/retry 반환 계약을 구현하고 상태 불변을 검증했다. `call r13_meeting_retry_prompt`의 `_return`이 `accept`면 기존 결과, `retry`면 이야기 담당의 회의 초기화 루틴으로 연결하면 된다. 이번에는 회의 첫 진입·기회·proof_kept 복원이나 실패 라벨을 임의로 수정하지 않았다. 160px 시안 버튼을 확대하지 않고 기존 승인 고해상 공통 확인 부품을 재사용했다.
- 밤 배경6장: 납품 PNG와 RGBA 픽셀이 같은 무손실 WebP 등록, `r13_background("wild_school_classroom")` 등6키 제공. 실제 엔진으로 렌더 검수했으나 불타는 밤 사건 런타임이 아직 없어 자연 플레이에는 연결하지 않았다. 학교 복도·산길 어귀·온실의 새 문·새벽 시점은 검토 후보임을 유지한다. 기존 낮/밤 장소의 기본 배경을 덮지 않는다.

## 보완·미납품

1. 첨부1은 요청서와 참고 캡처뿐이다. 정사각4장·메인/질문 크기 보완16장의 실제 PNG는 아직 없다. 기존 버튼 상태12종을 유지한다.
2. `NW_RETURNED_BOWL`: 납품에 이야기의 핵심 대조 단서인 바닥 표시가 없다. 기존 그림 유지, 새 후보 보관. 정식 학교 그릇 바닥 표식과 같은 표시가 보이는 대조컷이 필요하다. 임의 문양을 발명하지 않았다.
3. `REWARD_DOLMOK_VOID_MARK`: 납품 제안ID이며 현재 자료ID가 없다. 후보 보관, 새 아이템·보상을 만들지 않았다. 이야기 담당이 실제 표시 지점/ID를 정하면 연결한다.
4. 원탁 입석1차5인 부리·도토·할머니·나비·보리는 이번 첨부에 없다. 예전 그림을 임의 새 자세로 대체하지 않았다.
