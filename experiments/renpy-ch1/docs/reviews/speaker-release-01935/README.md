# 이름 표시 통합 0.19.35

31개 승인 맵 동작 적용 main `6700c5ed` 위에 `fix/speaker-display-20261017` (`532d9101`)을 병합했다. 기존 맵/그림/대사 본문/저장 키는 바꾸지 않았다. 사자 선생님·부엉이 할아버지의 미확정 고유 이름은 현 호칭 그대로다.

정식 SDK lint와 전체 단위 검사 통과. build_web.py 정식 빌드 후 실제 Chromium/WASM `config.version=0.19.35`에서 검사했다. 런타임 소스 overlay는 사용하지 않았다. 1280×720 / 844×390 기본·큰 글씨, 밝은/어두운 배경, 긴 이름, 익명 ???, 복수 화자, 회의 이름표, 첫 대화 화면을 확인했다. 모모→부리→누비의 실제 선택 버튼 클릭 후 선택 ID와 이름·역할을 검증하고 화면을 저장했다. 미소개 사자 선생님은 목록에 노출되지 않는다.

새 게임 자연 진행 대사에서 기존 저장/불러오기 UI로 왕복해 packet 동일성을 확인했고 8회 후속 클릭에서 예외가 없었다. 오프닝의 저장 도구만 검수 fixture로 노출했다. 전체 캠페인 및 모든 기존 저장 버전의 이행 검사는 범위 밖이다.

`transport.json`: 7개 part 크기/해시, 합친 아카이브 SHA256, ZIP CRC 통과. `runtime.json`은 화면/선택/저장 결과다. 이전 전달 브랜치의 overlay 검수와 구분한다.

함께 포함한 나비 일정 CSV 변경은 CRLF→LF 정규화뿐이며 일정 데이터는 동일하다. QA writer에도 LF를 명시했다.

미완료: 서리 검사원의 새 3/4 정면 시선 원화 승인, 광장 공간/깊이 배치안 후속 검토. 미승인 옆모습과 임의 좌우 반전은 적용하지 않았다. 기존 미제작 아트 목록을 이번 UI 변경으로 완료 처리하지 않는다.
