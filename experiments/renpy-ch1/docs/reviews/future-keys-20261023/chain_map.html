사건이 사건을 구한다 — 연쇄 지도

앞에서 살린 사람 · 사건 전에 확보한 물건 · 미리 산 물건이 뒤 사건의 열쇠가 된다. (설계 제안)
살린 사람결정적 물건상점(다른 길)
P1 피코 → 4일 밤 그림자 스케치 → 밤이 회의 근거
P2 톡 → 13호 빗장을 고쳐 둠 → 부엉이
P3 톡 → 수레 바퀴 → 네로
P4 밤이 → 7일 밤 거짓 호출 목격 → 부엉이
P5 꼬미 → 비밀 문 → 통로 조사
P6 꼬미 → "선생님만 작은 냄비" → 도담
P7 보리 손 무사 → 수레를 끔 → 네로
P8 보리 무죄 → 공개 때 너울 앞에 섬
P9 부엉이 → 약장 열쇠 위치 → 도담
P10 네로 → 가족 호송·이름표 → 전원 인계
P11 도담 → 담요의 새 무늬 → 담요 회의
P12 나비 → 학교에서 사람을 받음
P13 굴돌 → 제단 돌판 해독
O1 3번 등 돌 → 가설 회의
O2 엄마의 기록 사본을 먼저 맡음 → 부엉이
O4 약병 회수 → 도담
O5 너울 장부 → 진엔딩
모든 예방에는 물건의 길(상점)과 사람의 길(앞에서 살린 사람)이 함께 있다. 돈으로는 다 살 수 없어, 진엔딩에는 사람의 끈이 반드시 필요하다.
