링크: https://kkhkkh20-bit.github.io/daaegame/preview/room13-dev/ (예전 화면이면 새로고침)

처음 하는 사람의 눈으로 본다. 걸리는 곳은 「며칠·어디·무슨 화면·무엇이 이상한지」 한 줄씩 적어 주면 된다.

## 1. 이해 (가장 중요)

- [ ] 1일 마차~입구: 아빠가 왜 이 마을에 왔는지, 누구를 찾는지 알겠는가
- [ ] 2~3일: 피코가 왜 위험한지, 등 돌이 왜 중요한지 대화만으로 알겠는가
- [ ] 회의마다: 무엇을 다투는지, 어떤 자료를 내야 하는지 감이 오는가(틀렸을 때 힌트가 도움이 되는가)
- [ ] 7일 불 회의 뒤: 너울이 왜 창고 몫을 누비네에 주겠다고 했는지 납득되는가(이번에 넣은 줄)
- [ ] 13일 수레: 실룩 실토(두 배 값·나머지 두 돌), 판돌·모모가 왜 명단에 있는지 납득되는가(이번에 넣은 줄)
- [ ] 결말: 왜 이 결말이 나왔는지 아빠 입장에서 이해되는가

## 2. 재미·감정

- [ ] 다람·아빠 주고받기(조사 반응 37곳)가 귀찮지 않고 정이 가는가, 너무 잦지 않은가
- [ ] 죽은 사람·살린 사람에게 마음이 쓰이는가(부엉이·꼬미·네로·도담·피코)
- [ ] 미래를 알고 다시 할 때 「이걸 바꿔 볼까」가 떠오르는가(돌 바꾸기, 빨래터, 수레 그릇)

## 3. 화면

- [ ] 대화창 인물 도트가 고르게 보이는가(아이 크기 적당한가)
- [ ] 이름·장소·자료 글씨 색이 읽기 편한가, 과하지 않은가
- [ ] 보조 버튼(지도·기록·생각)이 눈에 편한가
- [ ] 휴대폰 가로: 현장 이름표, 지도 아래 버튼이 너무 작지 않은가(캡처 `phone-landscape-844x390.png`, 자동 점검에선 작게 보였다)
