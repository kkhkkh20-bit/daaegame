## 기준과 한계

- 먼저 저장소 루트 `ROOM13_GUIDE.md`를 읽었다. 로컬 원본만 정적으로 읽었으며 게임 파일 수정·시험·lint·빌드·서버 실행·커밋은 하지 않았다. 읽기에는 관리 환경 runtime 스킬의 비밀정보 비노출 규칙을 적용했다. 해당 환경 상태 도구는 이 세션의 도구 목록에 없으며 네트워크 작업은 필요 없었다.
- 검토 원문: `docs/reviews/REVIEW_20261021_전체사건진상.txt`. 사건 01~12의 개선/취약점, 06-추가의 작가 진상·진행①~⑨·결정사항·동시수정 항목, 공통 1~8, 우선 A~D를 아래 주표에 대응했다. 보존 요구도 필요한 곳은 독립 행으로 판정했다.
- **반영됨**은 실행 호출·자료/조건을 함께 찾은 경우, **일부 반영**은 구성 요소 일부만 존재하거나 자동 문답/선조사로 남은 경우다. **미반영**은 제안한 입력·전환이 실제 연쇄에 없거나 기존 구조가 명백히 남은 경우다. **판단 불가**는 채택되지 않은 대안/조건부 제안의 확정 자체를 알 수 없는 경우다. ‘일부 반영’의 감정·설득력 평가는 충분성까지 입증했다는 뜻이 아니다.
- ‘영향’은 앞으로 고칠 경우의 범위 추정이다. 실제 판정을 바꿨다는 뜻이 아니다. 크기: 작음=한 장면 문구/관문, 중간=한 사건의 다단계 질문/획득 연결, 큼=여러 날짜의 알리바이·예방·최종 판정 재정합. 새 UI 없이 가능한 작업을 우선 적었다. 새 그림 필요 여부는 새 장치/발견 구도 확정 뒤 재평가해야 한다.
- 줄 번호는 감사 당시 작업 트리 기준이며 동시 작업으로 이동할 수 있다. JSON은 줄 번호보다 **정확한 ID/키**를 근거로 썼다. `Dxx_...`는 `MS14_Dxx_...`, `days123/45/610/1114`는 `game/room13_v111_days*.rpy`, `dxx.json`은 `game/v111/newworld/dxx.json`을 뜻한다. 별도 표기 없는 대사 ID의 기본값은 `game/v111/records.json`이다.
- 원문 레코드의 존재만으로 화면 출력을 인정하지 않았다. `game/room13_v111_newworld_text.rpy:258`의 교체, `:287`의 before/after/drop, `:301`의 조건부 블록과 실제 days 호출을 함께 읽었다. 실제 그림 픽셀/체감 난도/모든 저장 경로의 자연스러움은 이번 읽기 전용 감사로 검증하지 않았다.

## 원검토서와 현재 원본 사이의 주의할 차이

1. **보고서의 ‘야생화 표현을 원문에서 못 찾았다’는 과거 관찰은 현재에 그대로 적용되지 않는다.** d11.json NW_H_OPEN_04는 명칭·증상을 말하고 가설 회의가 돌과 노출을 대조한다. d08은 원인 확정을 유보하며 d14의 구매 장부·시설 발언이 할머니의 지식을 잇는다. 그렇다고 새 밀실/살인 계획 전체가 확정됐다는 뜻은 아니다.
2. **보미 이름 공개 순서가 바뀌었다.** 원검토서는 D11_S01에서 가족 관계와 이름을 처음 듣는다고 했지만 d11.json은 D11_S01_L0027을 ‘네 엄마 이름은 뭐니?’로 바꾸고 토실의 이름 발언을 지연시키는 흐름을 둔다. 벽 이름과 D14 고백을 함께 봐야 하며 원문 설명만으로 플레이어의 보미 지식을 앞당기지 않아야 한다. 이번 감사의 ‘보미 결말 D14 유지’ 판정은 이름과 사망 확정을 구별한 것이다.
3. **달래 선행 공개 경로는 현재 확인 가능하다.** D11 `heat_seen11`의 이름 조사/NW_NAMES, D13 새 장부 획득, D14 넷째 논점 성공·플래그·조건 호출이 연결된다. 원검토서의 ‘획득 경로를 확정하지 못했다’는 문제를 현재도 미해결이라고 쓰지 않았다.
4. **D13 군중 실패는 데이터가 있지만 정상 진입이 없다.** 존재하는 대사를 실제 가능한 결과로 세지 않는다. 또한 현재 새 세계의 ending14에는 left_name/frozen 경로도 있으므로 원검토서의 전원/부분/가족/폭력 네 범주만으로 결말 영향을 다 설명할 수 없다.
5. **기록 생사와 현재 회의 성패를 분리해야 한다.** `room13_v111_newworld_rules.rpy:144` 이후는 다섯 인물 생존·이송·부상과 회의 성패를 후반 결말에 연결한다. 대사만 다듬는 작업은 이 값을 바꿀 필요가 없지만, 정답/실패 관문을 새로 연결하면 명단과 진결말에 간접 영향이 생긴다.
