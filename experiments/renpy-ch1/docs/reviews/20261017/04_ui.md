## 문제없음으로 확인한 것
- `r13_confirm`·`r13_records`·`r13_book`·`r13_more_tools`·`r13_backlog`·`r13_morning_pick`·`r13_save_review/cleanup`·`r13_shortcut_help`·`r13_debate_board`·`r13_winter_board`·`r13_shop`·`r13_work_board`는 Esc로 닫히거나 돌아갑니다.
- 숫자 키(질문 목록·회의 선택지)는 각 화면이 `ready` 뒤에만 받습니다. 위에 모달(기록, 더보기)이 뜨면 아래 화면 키가 막힙니다. 서로 겹치는 숫자 키는 찾지 못했습니다.
- 반복 타이머: `r13_world_camera_controls`의 `timer .3 repeat`는 상태를 바꾸지 않고 다시 그리기만 합니다. `r13_material_detail`의 읽음 표시 타이머는 한 번만 돕니다. 이름 판(`r13_winter_board`)은 큰 글씨에서도 틀 안에 들어갑니다(`winter_board_large.png`).
- 자료 넘김: 걸러서 개수가 줄어도 `r13_record_page`가 쪽 번호를 맞춥니다(큰 글씨 8개/쪽, 보통 12개/쪽).
