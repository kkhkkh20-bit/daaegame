## 확인했지만 문제 없던 것 (참고)
- 점프·호출 대상: 정적 수집 결과 없는 label이 없었다. `R13_EVENT_OFFERS`·`R13_TOPIC_LABELS`·`R13_GIMMICK_LABELS`의 label도 실행 중 `renpy.get_all_labels()`와 대조해서 모두 있었다.
- 0.19.3 지도: `room13-cartography.json`의 그림·외곽선·발견 패치 파일은 모두 있다. 옛 v5·안내도 이름을 참조하는 곳은 남아 있지 않다. `r13_inn_guide` 계열은 이제 부르는 곳이 없는 죽은 코드다.
- 회의 두 자료 엮기(Q4 s3, Q5 s3, Q5A s2): 두 자료는 늘 한 번에 지급된다. Q4는 `ttadak_dead`·`nt_ttadak_half`에서만 열리고, 두 경로 모두 N07+N09를 준다.
- 「지난 사건」 묶음: 각 묶음 표식(lt_done·kd_done·wf_done·ws_done·week2_started)은 해당 회의가 끝난 뒤에 세워진다. 회의 중에는 자료가 빠지지 않는다.
- 새 store 변수(`r13_scene_bg`, `r13_records_view`, `r13_book_views`, `r13_fast_*`, `persistent.r13_mornings` 등)에는 모두 `default`가 있다.
- 0.19.5 마차 대사의 `no_lead`·`sfx: comic`, 엄마 "?" 얼굴, 도착 장면 `r13_here_scene`(광장·입구·창고·초롱)에서는 문제를 찾지 못했다.
