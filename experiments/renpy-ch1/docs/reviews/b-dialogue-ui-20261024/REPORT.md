## 연결과 보존

특수 행동 `room13-dialogue-pose-source-art.json`이 우선하며 그대로다. 기존 `room13-dialogue-talk-art.json`도 원문 그대로 유지했다. 기본 감정의 일반 대화 렌더링에서만 별도 B 프로필을 선택한다. 회의 중에는 원래 프로필을 선택한다. surprise_react→surprise_talk의 기존 타이밍/키, 대사 조건, 반응 플래그, 저장 후 정착 동작은 그대로다. neutral과 보류4개는 기존 프레임을 유지한다.

각 신규 몸체는 납품 WebP 원본 바이트 그대로 복사했다. 50몸체/50얼굴의 SHA를 납품 JSON과 대조하고 실제 몸체50개 픽셀을 모음 그림으로 확인했다. 기존 실제 알파 높이·중심·하단에 맞춰 균일배율을 계산하고 캔버스는 유지했다. offset은 Ren'Py 상대좌표로 해석되지 않도록 정수 픽셀이다. 중심/발 오차는 반올림0.5px 이내다. 새 B 그림만 중간 pixel_grid 재표본화를 생략해 원본 윤곽을 유지하며 기존 neutral/특수 그림은 기존 처리를 쓴다.

조사 그림 등록·발/조사 클릭·회의 방향·본문 대사·분기·사건·상태·선택 action은 수정하지 않았다. 질문 카드도 기존 행 기하·페이지·키보드·읽음 판정을 그대로 둔다.
