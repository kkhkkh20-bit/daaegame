# 전체 스토리 검수 — 2026-10-25

0.20.33을 기준으로 5명이 1~5일, 6~10일, 11~14일, 날짜를 넘는 분기, 대사 이해도를 병렬 검수했다. 실제 라벨·자료 획득·조건부 대사·결말 값을 설계와 대조했고, 자동 검사 의심을 실제 오류와 구분했다. 모든 경로의 자연 플레이 전수검사가 아니다.

## 우선 해결이 필요한 정책 충돌

**제단 마지막 쟁점은 장부 없는 판에서 완승 불가.** 13일 피코 회의 패배 및 불 대승리 장부 경로 미완료 → 14일 아침 → 제단1~3 정답 → 제단4는 소지 검사에서 자동 lost, 전체 partial이 상한이다. 제단1 대체정답 추가만으로 회의 전체의 기본자료 완승은 충족되지 않는다.

기존 부분 결과 설계와 최신 ‘기본 증거만으로 언제나 완승’ 원칙이 충돌한다. 탄 쪽지만으로 장부의 4년 전 배급량 사실까지 증명할 수 있다고 임의로 정하지 않았다. 권고는 **제단 진입 전 기본 조사 경로에서 해당 연도의 집별 배급 사실을 확보하도록 보완**하는 것이다. 기존 장부의 입증 사실과 정답 판정을 유지할 수 있다. 확보 장소·행동·관련 대사의 구체 설계는 다음 수정에서 먼저 정해야 한다. 기존 부분결과를 유지하려면 최신 회의 원칙의 명시적 예외가 필요하다.

## 수정한 문제

- 부분 정답 알림이 정확한 자료 조합을 열거하던 문제: 옛 note 알림을 제거하고 일반 보존 상태 안내만 사용한다. 단계별 생각 줄과 정답 판정은 유지.
- 도토 다짐의 ‘누가 불러도 가지 말라/얼굴 보고 부르는 사람만’ 혼선: 문간에서 대답만 하고 다람 곁을 비우지 않도록 명시.
- 가설 패배 후에도 제단 패배 지문이 ‘다음 겨울 다시 돌’이라고 말하던 연속성: 가설 결과에 따라 현재도 푸른 불을 쓰는 지문으로 나눈다.
- 문서: 회의 기회 수, 겉옷 공동 착용 현행, 부엉이 예방 현행, 대승리·재시도 현행, 제단1 대체정답, 채워진 오답 생각 줄 설명을 갱신.

## 확인한 주요 연결

1~5일 필수 자료·사망/생존 초상·실룩 처분·밤이 기회 차감, 6~10일 부엉이 두 예방 경로·화재 대승리·13호와 기록 회의의 자료 전달, 11~14일 수프 보상·수레 하차·군중 개입·제단 부분 결과·진엔딩을 대조했다. 이번 범위에서 추가로 확정한 생사 부활·필수 자료 미획득 진행 차단은 없었다. 미확인 조합의 무결함을 보증하는 의미는 아니다.
