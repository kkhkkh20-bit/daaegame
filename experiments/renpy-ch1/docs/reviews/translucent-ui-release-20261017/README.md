# 반투명 대화 UI 공개 검수 — 0.19.32

소유자가 승인한 대사창·선택지 시안을 기본 UI로 반영했다. 최신 main의 0.19.31 맵 동작 그림도 합친 뒤 검사했다.

- `capture-report.json`: 실제 Chromium의 제작 배경·인물·원본 대사 화면 fixture. 승인 시안용 플래그를 켜지 않고 기본 재질이 d9·가는 테두리인지 검사했다.
- PC 1280×720: 밝은 눈밭의 마을 입구, 저녁 여관 실내에서 대사·선택지 확인.
- 모바일 844×390 및 큰 글씨: 대사·선택지 확인.
- 실제 높이72px인 선택지 버튼을 마우스로 눌러 `life:resident_nubi:work` 원본 대사로 연결되는지 검사했다.
- 대사창 진하기 설정: 연하게 c9, 기본 d9, 진하게 ff·dark 확인.
- `check.log`: 병합한 원본에서 dev/check.sh(단위·Ren'Py lint) 통과.
- `build.log`: 최종 웹 빌드 해시. capture-report.json의 archive_sha256과 같다.

스크린샷 파일의 `preview`는 시안 비교 도구에서 이어진 이름이다. 이 폴더는 0.19.32 공개용 빌드의 기본 UI 캡처다. 상태 주입을 사용한 화면·버튼 연결 검사이며, 전체 이야기 완주 검사는 아니다. 대사·선택 결과·단서·진행 조건은 바꾸지 않았다.
