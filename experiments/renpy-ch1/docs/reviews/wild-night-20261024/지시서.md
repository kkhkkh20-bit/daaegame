## 9. 소유자에게 확인할 것

1. **결말 판정 자리**: 설계안의 「남겨진 이름 다음, 얼어붙은 마을 앞」은 구조상 불가하다. 「마을의 아침 줄기 안, 제단 회의 진 뒤」로 바꿔도 되는가(사실대조 0장 1번).
2. **밤 장면 안 행동을 판정에 넣을지**: 시안은 「다람의 열(앞 행동) × 그 밤에 남을 도운 횟수」다. 앞 행동 값만 쓰라는 뜻이면 지체 칸을 빼고 「열 없음 → 셋 / 열 있음 → 엄마를 잃음」 두 갈래가 되며, 둘 다 잃는 끝은 따로 값이 필요하다.
3. **숨을 곳**: 고개 대신 폐온실(엄마가 숨던 곳)로 바꿔도 되는가. 13호실은 여관 안쪽 돌 때문에 시안에서 뺐다.
4. **제단 회의에 갈림길 「?」를 붙일지**: 불타는 밤에서 마을 사람이 죽는다. 붙이면 `R13_FORK_FATE`에 `altar`를 더하고 `dev/test_fork_screen.py` 재도출 규칙도 맞춘다. 시안은 생존 값을 쓰지 않아 지금은 붙지 않는다.
5. **결말 이름**: 「불타는 밤」(가칭) 확정 여부.
6. **새 사실**: 「큰 집 난로가 넘어져 불이 났다」, 「학교도 탔다」, 「도토가 야생화가 왔다」, 「돌목이 이름을 잊어 간다」는 게임에 없던 사실이다. 11·13일 다른 판 대사와 부딪치지 않는 것은 확인했다(전부 `wild_omen`·밤 장면 안에만 있음).
