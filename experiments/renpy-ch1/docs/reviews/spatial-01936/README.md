# 공간 접점 수정 검증

- 나비 주방 5원화: 같은 앞 조리대에서 머리 높이 120px, 뒤 화덕에서는 94px. 각 원화 머리 메타데이터로 개별 크기를 계산하고 손/그릇 접점과 가구 마스크를 보존했다. 기존 원본을 변형하지 않았다. 8 실제 동작·장소 상태, 2 저장/복원 확인.
- 다람: 침대 이불 앞쪽으로 내려간 좌석을 매트리스 표면으로 이동하고 바닥 그림/조사 동작을 하단 안내 위로 옮겼다. “두 침대 사이 끼임” 자체는 재현되지 않았다. 사건 대기 중 휴식은 승인된 앉기 원화로 연결했다.
- 광장: 기존 슬링/설이의 단차를 실제 발 접점과 지면 깊이로 분리했다. 기존 벤치/수레/게시판 인물은 변경하지 않았다.
- 서리: 승인된 앞쪽 3/4 시선 원화를 원본 SHA 확인 후 진료실의 기존 서류 동작에만 연결했다. 오전/저녁 조건은 해당 인물이 실제로 진료실에 있을 때만 적용된다. 12일 오후 창고·저녁 학교의 기존 동작은 유지했다.
- 실제 얼굴 클릭 8회 및 런타임 449 인물 레코드에서 인물 추가/삭제, 이벤트 이동, 기존 stage 자료 변경이 없음을 확인했다.
- before/after는 12장씩 실제 SDK 빌드. clicks와 nabi는 그 후 서리까지 반영한 빌드다. 이후 표정과 승인 질문 UI 통합은 공간 소스를 변경하지 않았다.
- 장소별 66장/118 인물·동작·장소 조합의 검수 결과 및 남은 겹침/소품 비율은 [보고서](../../../../../reports/place-balance-01936/README.md)에 명시했다. 모든 사건 분기를 통과했다고 주장하지 않는다.
