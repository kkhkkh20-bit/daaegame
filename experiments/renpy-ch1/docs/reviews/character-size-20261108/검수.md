## 확인 범위

- 입력 원화817파일과 일반 등록 프로필·문맥을 정적 대조했다. 화면에 드러나는 값은 별도 엔진으로 다시 측정했다.
- 본편69종의 일반 여섯 표정·질문 여섯 표정을 전후 측정했다. 수정 뒤 질문 발끝은 모든 표정에서710px 이내다(원본 알파40 수학 기준708, 실제 리샘플 경계 오차2px 포함).
- 실제 대화 UI69종의 중립→기쁨→지문207장을 캡처했다. 화자 유지138단언이 통과했다.
- 전용 문맥10종의 실제 선택과 대화→질문을 검증했다. PC와 대표 휴대폰, 세련 우체국 오후의 실제 chair_listen을 포함해11단언이 통과했다.
- 단독 회의 돌목·꽥순·꼬미·너울과 휴대폰을 확인했다. 초점 전환3단언이 통과했다.
- 현장430개 파일의 크기와 알파, 등록된 생활 배치를 대조했다. 도담4자세만 변경됐고 중립 및 다른426파일은 보존했다.
- 독립 검수자가 전후 갤러리 각6장을 모두 열어69종을 비교하고, 대표 실제 대화·질문·회의를 확인했다. 개별 UI207장을 전부 독립 열람한 것은 아니다.
- 첫 단위 실행에서 도담4파일의 도구상자 canvas_size 제약이 옛 크기여서 실패했다. 카탈로그와 제약을 함께 갱신한 뒤 전체1,444개 재검사와lint가 통과했다.
- 임시 시험의 인덱스 초기화·대량 측정 timeout은 시험 준비를 고쳐 재실행했다. 제품 진행 오류로 기록하지 않았다.

별도 활동·앉음·무릎 자세를 같은 전신 높이로 강제하지 않았다. 실제 스토리 전편 연속 진행은 이번 범위가 아니다. 최종 웹 검증은 아래에 기록한다.


## 최종 웹 확인

최종 빌드0.20.121을 Chromium에서 실행했다. 실제 새 게임 건너뛰기로 시작해 질문9종의 PC 화면과 대표3종의 휴대폰 큰 글씨, 세련의 앉은 자세, 돌목의 실제 일반 대사를 확인했다. 브라우저 pageerror는 없었다.

같은 빌드에서 옛 표시 크기 객체를 준비해 실제 저장 메뉴로 저장하고 불러왔다. 돌목 그림의 불투명 높이가1349px에서976px로 재표시됐다. 구 버전에서 생성한 별도 실제 저장 파일의 이관 시험은 아니다. [웹 검증 결과](웹검증.json)

최초 내려받는 묶음은36,561,380바이트로 이전보다58,794바이트 늘었다. 크기표를 더한 결과이며 원화 묶음의 일괄 선탑재를 추가하지 않았다.
