# 1부 UI·대화·실제 화면 검수

2026-11-08 · 0.20.122. 소유자 요청: UI 개선, 플레이 중 스크린샷, 앞말과 뒷말이 실제 대화로 이어지는지 확인한다. 1부(1~7일)를 대상으로 한다.

## 검수 방법

- 최종 대사 공급 경로를 실행 라벨 순서와 대조한다. 편집 도구의 ID 순서를 재생 순서로 간주하지 않는다.
- 새 게임부터 실제 현장·질문·자료·지도 버튼을 누르며 화면을 캡처한다. 정답을 아는 모델의 개발 검수이며 초견 인간 플레이 실험은 아니다.
- 장면별 준비 시험과 새 게임 실제 진행을 구분한다. 모든 분기나 모든 캡처를 수작업으로 보았다고 계산하지 않는다.
- 이야기의 사실·자료·정답·생사·결말을 유지한다. 고유한 회피·농담과 응답 누락을 구분한다.

## 유지한 정상 연결

[최종 웹의 마차·초소 실제 대화 전문](마차·초소-실제대화.md)을 다시 읽었다. 마차의 과자 나눠 먹기→엄마 몫→봉지 접기, 편지를 자꾸 읽는 이유, 돌 난로 질문의 답변은 이미 이어져 있었다. 여관에서 엄마가 없다는 반응→아빠의 인정→마지막 목격을 묻는 순서, 13호실에서 다람을 안아 준 뒤 함께 메모를 보는 순서도 유지했다. 주민의 의도적인 회피와 방어를 모두 친절한 설명으로 바꾸지 않았다.

## 검사 결과

- 전체 단위 1,444개와 lint 통과. 대사 점검 A/B/C 각 0건이다. 기계 점검이 모든 문장의 자연스러움을 보장한다는 뜻은 아니다.
- 최종 코드의 질문 PC·휴대폰·큰 글씨와 페이지/읽음 표시/자료/기록/더보기 복귀, 편지 관찰, 화재 자료 읽기 세 시험이 24단언을 통과했다. 질문 시험은 임시 격리본에서 더보기의 새 닫기 버튼 실제 클릭까지 확장했다.
- 수정 대사 9개 지점은 본편의 최종 공급 함수를 부르는 준비 장면으로 표시하고, 화면을 캡처했다. 이는 자연 진행과 구분한다.
- 독립 검수자가 질문·더보기·편지 관찰 캡처 6장을 직접 열어 텍스트·쪽 넘김·도구의 가림과 잘림을 확인했다. 자동 읽기 토글 동작은 이 정지 이미지 검수와 별도로 웹에서 실행했다.
- 최종 웹 0.20.122의 PC/휴대폰 큰 글씨, 질문 행·더보기 열기/닫기, 실제 자동 읽기 켜기/끄기와 대화 복귀를 확인했다. pageerror 0건. [웹 결과](최종웹UI검증.json)
- 최종 비교 안내 문구가 들어간 웹에서도 새 게임 마차·백로그 62개 발화 순서, 비교 안내 펼침/접기, 0장 상세 종료·시간/자료 보존·현장 복귀와 재개, PC/휴대폰 편지 관찰과 다음 질문으로의 연결을 확인했다. pageerror 0건. [웹 자료 검증](최종웹자료검증.json)
- 피코 후속 질문은 야외 잠자리와 식당 인계 뒤 두 준비 상태에서 실제 질문을 골라 세 문답과 복귀를 확인했다. 두 상태의 장소·인계 값은 유지됐고 pageerror는 없었다. [최종 피코 검증](최종웹피코검증.json) · [야외 질문](화면/피코-야외잠자리-질문.png) · [실내 인계 뒤 답변](화면/피코-실내이동뒤-답변.png)

## 실제 진행 범위

1~3일은 공개 0.20.121을 새 빈 프로필에서 시작했고, 피코 현장 자동화 처리 보완 뒤 같은 실행의 복구 저장으로 이어 3일 취침 직전까지 진행했다. 그 저장을 0.20.122 검수 빌드에서 불러와 4~7일을 이어 확인했다. 마지막 비교 안내 문구는 별도의 최종 웹 시험으로 재확인했다. 연속 버튼 진행과 최종판 변경 구간 재검사를 조합한 검수이며, 최종 배포본 한 버전으로 모든 분기를 무중단 완주한 시험은 아니다.

캡처는 대사 출력·등장 연출 중의 프레임도 포함한다. 정지 화면 한 장만으로 문장 전체와 동작이 모두 검증됐다고 판단하지 않고, 최종 공급 대본·순서와 준비 장면, 실제 입력 결과를 함께 대조했다.

같은 새 게임에서 이어 온 저장으로 7일차 ‘1부 마무리’를 선택해 완료 화면과 결과 기록까지 도달했다. 피코 사망, 화재 대피 성공·꼬미 생존 경로다. 실제 3일 발견 현장의 세 문답, 입구·3일·화재의 자료 제출, 4~5일 문답과 인계·6일 물자/화재/아이들 인계·7일 현장 논증과 이름 확인을 포함했다. pageerror 0건. [1~3일 기록](실제진행1~3.json) · [4~7일 기록](실제진행4~7.json)

## 표시·대화 검수의 결론

실무 의견으로는, 마차는 이제 과자 장난→엄마 몫→편지와 방 번호→함께 잘 자리→돌을 조사하러 온 엄마라는 연관을 따라 읽을 수 있다. 고친 것은 주로 정보를 더 설명하는 문장보다 상대의 질문을 먼저 받는 문장이다. 주민의 회피와 각자 사정은 유지했다.

질문과 자료 화면은 기존 수첩·크림 종이·남색 잉크를 유지하면서 눌리는 행과 복귀 동작을 더 명확히 했다. 새 원화나 선탑재 묶음을 추가하지 않았다. 전체 대사의 재미와 판매 적합성을 기계 검사 숫자로 단정하지 않는다.
