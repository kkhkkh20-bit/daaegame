# 조사·회의 UI 검토안 — 2026-10-17

검토 브랜치 `design/investigation-meeting-ui`. 기준 main d681b9a9 (0.19.39). 공개 배포 전 시각 검토용이며 버전을 올리거나 main에 병합하지 않았다.

## 레퍼런스와 적용 판단

- [역전검사 DS 공개 체험기](https://www.nintendoworldreport.com/hands-on-preview/20880/ace-attorney-investigations-miles-edgeworth-nintendo-ds): 대상 근처에서 Examine 버튼이 나타나고 상세 조사를 연다. NPC를 모두 숨기는 방식이라는 뜻은 아니다. 정적인 배경을 사용하는 우리 게임에는 조사/대화 전환과 대상 선택 → 명시적 조사로 응용했다.
- [역전검사 컬렉션 공식 개발자 글](https://news.capcomusa.com/2024/09/30/directors-testimony-behind-the-scenes/): 조사 여부 표시와 조건 변화에 따른 표시 갱신을 설명한다. 완료 표시는 실제 상태에 근거해야 한다.
- [고스트 트릭 공식 소개](https://news.capcomusa.com/lets/browse/ghost-trick-phantom-detective-reawakens-in-summer-2023): 터치 조작을 지원한다. 대상이 드러나는 전용 상호작용 상태와 선택 후 행동이라는 원칙을 참고했다. 그림의 발광 효과는 차용하지 않았다.
- [Tangle Tower 공개 리뷰](https://www.nintendolife.com/reviews/switch-eshop/tangle_tower): 휴대 모드의 터치 조사 사례. 인물·질문·자료가 나뉘는 화면은 [공개 화면](https://buried-treasure.org/wp-content/uploads/2019/12/06_tangletower.jpg)도 참고했다.

다른 게임을 직접 플레이한 리뷰가 아니라 공개 자료를 조사한 결과다.

## 수정

### 조사

- `주변 살피기`: 배경 물건을 조사하며 인물과 이름표를 숨긴다.
- `사람과 대화`: 기존 등장 인물과 이름표를 보여준다. 기존 등장 조건과 시간표는 유지한다. 현재 대화 이벤트가 있으면 탭에 !를 표시한다.
- 물건을 누르면 이름이 나타나며 `살펴보기`를 눌러 실제 조사한다. 선택만으로 시간·증거·대사가 진행되지 않는다.
- `조사 지점 표시`를 제공한다. 호버 없이도 누를 곳을 확인할 수 있다. 배경의 기존 조사 영역도 계속 누를 수 있다.
- 기록은 우측 하단, 생각은 그 위에 두고 화면 이동 안내가 하단 조작과 겹치지 않게 이동했다.

### 회의

- 듣는 화면: 반투명 먹색 대사창, 상단 `발언 듣는 중`과 순서·이전/다음.
- 검토 화면: 종이 인용 카드, 상단 `발언 검토`. 말 듣기와 자료 대조를 색과 형태로 구분한다.
- `이 발언에 자료 보여주기`를 넓은 금색 주 행동으로 강조한다. 발언 선택/다시 듣기·되묻기는 보조 행동으로 구분한다.
- 기록은 공통 우측 하단, 회의 중단/더보기는 좌측에 둔다.
- **버그 수정:** 자료 또는 기록 창을 열 때 일반 식당 조사 배경으로 바뀌던 현상. 모달 뒤에도 회의 좌석 장면을 유지한다.
- 대사, 증거 판정, 해금, 시간 흐름은 수정하지 않았다.

## 검증 범위

Ren’Py SDK 8.5.3 공식 웹 빌드와 Chromium WASM 실행. 기존 dev/check.sh 및 lint 통과. 데스크톱 1280×720, 터치 844×390 + 큰 글씨 설정을 확인한다.

스크린샷은 실제 렌더링이다. 도입부 조사와 10일차 회의 C2를 지정한 제한적인 UI fixture로 확인했다. 회의는 보유 증거 11개만 지정했으며 전 증거 지급이나 전체 스토리 플레이가 아니다. 자동 검사 상세는 report.json에 기록한다. 기록 열람 시 읽음 표시는 정상적으로 변경될 수 있다.

기존 도토 좌석 그림의 스타일 불일치는 이번 UI 수정 범위에서 고치지 않았다. 새 그림이 필요하다.

검증 재현: 레포 루트에서 HTTP 서버를 열고 프로젝트 디렉터리에서 `python3 dev/qa_investigation_meeting_ui.py`를 실행한다. 기본 URL은 8776번 포트이며 `ROOM13_UI_QA_URL`, `ROOM13_UI_QA_OUT`으로 변경할 수 있다.
