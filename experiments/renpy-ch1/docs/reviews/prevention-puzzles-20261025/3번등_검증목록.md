# 승인된 절도 미수판 — 통합 확인 목록

2026-10-25 소유자 승인. 구현 완료 보고가 아닌 검증 기준이다.

- 끈만/조사만/묶기까지 완료를 구분한다. 이전 회차 플래그를 읽어 행동을 해금하지 않는다.
- 식당 숙박과 광장 생존을 다른 상태로 유지한다. 광장 예방판에 식당에서 잤다는 대사를 내보내지 않는다.
- 미수판에서는 3번 돌이 계속 현장에 있고 백 부인 창고에서 인수하지 않는다. 기존 E15/E16을 허위 획득하지 않는다.
- 칼끝은 실제 현장 조사를 해야 얻는다. 칼과 조각을 맞추는 동의를 유지한다.
- 미수판 정답은 그 판에서 실제 얻는 기본 자료만으로 모두 충족된다. 도난판 전용 자료를 요구하거나 받아들이지 않는다.
- 회의 기회 소진의 성공·부분·패배와 명단 후속을 유지한다. 미수판에서 다시를 고르면 미수판 시작으로 돌아간다.
- 회의 재시도는 미리 한 덮개 준비·피코 생존·자료를 없애지 않는다.
- 피코 초상 수령 장소, 4일 5번 등, 13일 실룩 자백에서 도난 성공 전제 문장을 분기한다.
- 네로 담요와 피코 광장 생존이 함께 가능하며 진엔딩 집계가 숙박 여부 대신 실제 생존을 본다.
- 기존 도난판과 기존 저장의 조사·회의 경로를 유지한다.
