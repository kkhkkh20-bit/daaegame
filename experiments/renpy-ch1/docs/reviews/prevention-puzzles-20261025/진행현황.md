# 예방 작업 진행 현황

완료는 코드·관련 검사·화면 확인·main 반영까지 끝낸 묶음만 뜻한다. 작은 보완을 사건 전체 완성으로 세지 않는다.

| 묶음 | 상태 | 남은 경계 |
|---|---|---|
| 피코 3번 등 절도 미수판 | 완료 0.20.47 | 전체 자연 플레이 마지막 회귀에서 재확인 |
| 꼬미 깡통 독립 준비 | 완료 0.20.45 | 별도 뒤창 대안은 후속 선택 경로 |
| 네로 수레·운반·인계 | 완료 0.20.48 | 준비 조합·인계 연결 완료. 새 지팡이/등 고정 대안은 범위 밖 |
| 수프 사전 개입 | 완료 0.20.49 | 현장 관찰·실제 개입으로 자동 예방 제거 |
| 군중 사전 배치 | 완료 0.20.50 | 공개 전 실제 배치·감독자 부재·기록 대승리 보존 |

위 묶음 이후: 부엉이 2단계 → 감정선 빈 곳 → 전체 대사 검수. 전용 그림 적용은 납품된 자산부터 진행한다. 대사는 아빠가 이해하고 묻는 순서·다람과 아빠의 유쾌함·주민별 정가는 개성을 기준으로 본다.
