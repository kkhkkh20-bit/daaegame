# 톡 수리 보호 경로 — 0.20.51

소유자가 추천 구체안을 승인했다. 7일 빗장 조사·톡의 동의·실제 작업 확인으로 보호 준비를 기록한다. 무죄로 풀려나 살아 있고 명단·이송·다른 임무가 없는 톡만 가능하다. 밤에 톡이 방 안에 남아 다람과 부엉이를 혼자 두지 않는다. 정문 수리로 비밀통로가 막힌다고 설명하지 않는다.

돌 제거·도토 약속은 기존대로 우선한다. 중복 준비와 밤 결과 뒤에는 톡의 자기 예약만 해제한다. repair 결과와 갈림길 「곁에 남은 수리공」을 분리했다. 도토가 약속을 지켰다는 거짓 대사가 나오지 않으며, 다음 날 서리가 돌을 꺼내는 공통 경로를 유지한다.

관련 자동 31개와 실제 준비→동의→작업→진료소 지도→밤 결과 화면 시험 통과. 전체 자동 1,091개 실행에서 새 테스트의 상태 추출 오류 3개를 수정한 뒤 관련 검사를 재실행했다. 화면 일부 선택은 시험용 Return 버튼을 사용했고, 전체 1~14일 자연 플레이는 반복하지 않았다. 화면용 Xvfb 종료는 재시작해 해결했다.

최종 관련 자동 38개 통과. 웹 빌드·qa_carriage 통과, 페이지 오류 0건.
