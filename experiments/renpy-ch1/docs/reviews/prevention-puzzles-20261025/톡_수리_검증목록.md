# 톡 수리 경로 검증 기준

2026-10-25 소유자가 추천 구체안 승인. 정문이 비밀통로를 막는 설정은 만들지 않는다.

- 걸쇠 조사만/부탁만/실제 작업 연결까지 완료를 구분한다.
- 톡이 무죄로 풀려나 실제 가능할 때만 부탁·작업이 성립한다. 사망·이송·다른 임무 상태를 무시해 옮기지 않는다.
- 작업자는 방 안에 남는다. 아빠가 서리를 부르고 도토가 거짓 부름에 나가도 아이와 노인을 혼자 두지 않는다.
- 돌을 치운 판, 도토 약속과 겹친 판의 우선순위를 정하고 톡의 임시 배치·예약을 정리한다.
- 새 경로가 8일에 도토가 약속을 지켰다고 말하지 않는다. 돌을 그대로 둔 경우 무너짐·서리의 사후 돌 처리 전제는 유지한다.
- 8일 생존 기록읽기, 10일 기록 회의, 11일 가설, 갈림길 지도에서 실제 사건과 맞는다.
- 이전 돌/약속/살인판과 기존 저장을 유지한다.
