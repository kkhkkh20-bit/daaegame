## 실행 검증 장애 / 남은 일

- 이 소비 환경에서 Ren'Py SDK를 찾지 못해 저장소의 공식 setup_sdk.sh로 `/workspace/renpy-sdk`에 설치를 시도했다. 공식 다운로드 요청이 `curl: (56) CONNECT tunnel failed, response 403`으로 실패했다. 재시도/다른 URL/프록시 우회는 하지 않았다. 자동 승인 심사 거절이 아니라 네트워크 응답 오류다.
- 따라서 Ren'Py lint, 실제 게임 실행, PC/모바일 저장 있음/없음 메뉴, 키보드 이동·설정 왕복·불러오기·새 게임, 실제 게임 스크린샷은 **미검증**이다. 단위 검사 통과가 이를 대신하지 않는다.
- 별도 HTML 배치 미리보기 캡처도 Chromium 기본 사용자 경로 생성 오류 후 쓰기 가능한 /tmp 프로필·캐시로 실행했으나 20초 내 완료되지 않았다. 캡처 산출물은 없다. 합성 이미지를 게임 실행 캡처로 제출하지 않는다.
- 실행 가능한 환경 또는 PR CI에서 lint/build/관련 화면을 확인하기 전 병합·배포하지 않는다. 이 보고서는 검증 완료·출시 승인 문서가 아니다.
