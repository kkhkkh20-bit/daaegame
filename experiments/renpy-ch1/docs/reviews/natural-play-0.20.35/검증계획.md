# 기존 본편 자연 진행 확인

대상 빌드 0.20.35. 새 에피소드 구현을 늘리지 않고 기존 진행의 연결을 확인한다.

- 새 게임→1~3일: 자료를 실제 조사하고 회의 UI로 제출, 3일차 실제 저장 생성.
- 해당 저장→4~14일: 기본 조사를 따라 정상 진행, 회의는 소지한 기본 정답을 우선 사용한다.
- 실제 갈림길 저장을 재사용하여 필요한 실패·예방 경로만 확인한다. 이미 검증한 UI/조건을 이유 없이 반복하지 않는다.

시험 도구 수정은 버튼명·자료 서랍·선택지 페이지·지도 조작에 한정한다. 자료 지급, 날짜 이동, 이야기 깃발 수정, 라벨 jump로 자연 진행을 대신하지 않는다. 화면·스토리 조회와 실제 저장은 허용한다. 진행 결과와 중단 지점을 완료 보고서에서 구분한다.
