# 인물 이름과 질문지 제목의 정렬

왼쪽 ‘부리’는 y92/38px, 오른쪽 ‘묻고 싶은 이야기’는 y76/26px여서 높이와 시각적 무게가 달랐다. 소유자 지시로 두 제목 모두 y70/30px로 맞췄다. 같은 글꼴과 크기를 사용해 기준선을 일치시켰으며, 인물 이름은 금색으로 유지한다. 질문 목록과 고정 도구의 위치·행동 및 이야기 내용은 바꾸지 않았다.

[PC 캡처](pc-actual-topics.png) · [모바일 가로/큰 글씨 캡처](mobile-actual-topics.png) · [캡처 결과](report.json)

실제 Chromium에서 주입한 3일째 오전 수리점 상태의 주민 질문 화면을 캡처했다. 전체 플레이 검증이 아니라 제목 정렬과 화면 겹침을 보는 시각 검토다. `dev/check.sh` 단위 검사와 Ren'Py lint, 공식 웹 빌드를 통과했다.
