# 1~7일 전체 대사 검수

2026-10-25. 최신 VOICE_GUIDE의 대화로 이해시키기·유쾌한 부녀·주민별 생활 고집을 기준으로 검수했다.

## 범위

- `dev/dialogue_day.py show 1`부터 `show 7`까지 실제 원문과 날짜별 replace/before/after/blocks를 합친 대본 전체를 플레이 순서로 읽었다. 조건별 변형과 별도 블록도 포함했다. 도난판·예방판·기록/반박 변형은 서로 연속 재생되는 줄로 오인하지 않았다.
- 수정 파일은 d01~d07 JSON뿐이다. 원본 records, 실행 rpy, 퍼즐 조건·생사·정답·자료 획득·인물 신원·새 설정은 바꾸지 않았다. 별도 hidden_pandol/hidden_base/lamp_attempt JSON은 이 담당 범위 밖이다.
- 이미 다듬어진 부녀 농담과 피해·상실 장면은 유지했다. 농담 수를 늘리는 식의 전체 개작은 하지 않았다.
