# 인물 왼쪽 · 질문지 오른쪽 시안

사용자 요청에 따른 역전검사 참고 배치 검토. 공개 화면에는 연결하지 않았다.

- 배경 전체에 검정 53% 막을 얹고 인물은 그 위에 밝게 표시한다.
- 왼쪽에는 인물과 이름, 오른쪽에는 질문 8개를 세로로 표시한다.
- 질문 제목은 레이아웃 검토용 짧은 주제로 바꿨다. 이야기 대사나 실제 질문 조건은 수정하지 않았다. 서로 다른 단계의 부리 질문을 함께 배치한 테스트이며 동시 해금 상태가 아니다.
- 자료 보여주기는 오른쪽 질문지 아래에 고정한다.
- 돌아가기와 기록은 왼쪽 하단에 둔다.

[PC 실제 웹 캡처](pc-side.png) · [모바일 가로/큰 글씨 실제 웹 캡처](mobile-side.png)

Ren'Py lint와 웹 빌드 확인. 실제 Chromium에서 두 화면 크기로 캡처하고 예외 화면이 없는 것을 확인했다. 선택 버튼은 배치 검토용 NullAction이며 실제 이야기 진행 검증을 의미하지 않는다. [결과](report.json)

8개를 동시에 표시하기 위해 행 높이 54px를 사용한 비교 시안이다. 기존 승인한 여유 있는 72/80px 행보다 촘촘하다. 8개보다 많거나 제목이 길 때의 처리는 별도 설계가 필요하다. 메인 머지 및 공개 배포 없음.
