# 기록 우측 하단 고정 · 자료 보여주기 위로

소유자가 시안 캡처와 적용을 함께 요청한 배치. 기록은 조사 화면과 동일한 우측 하단에 고정하고, 자료 보여주기는 오른쪽 질문지 아래에서 한 단 위에 둔다. 인물 왼쪽·질문지 오른쪽·검정 반투명 배경 및 좌측 하단 돌아가기는 유지한다.

- 자료 보여주기: `(640,572,592,72)`, 기존보다 64px 위.
- 기록: 일반 글씨 `(1168,664,112,56)`, 큰 글씨 `(1148,650,132,70)`.
- 자료 제시 버튼과 기록 버튼이 겹치지 않는다. 질문 및 페이지 버튼은 자료 제시 버튼 위에서 끝난다.
- 질문이 넘치면 쪽수와 이전/다음 버튼을 사용한다. 대사나 질문 해금 조건은 변경하지 않는다.
