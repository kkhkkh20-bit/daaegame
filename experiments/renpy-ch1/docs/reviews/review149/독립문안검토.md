# 149 독립 문안 검토

1~2일, 3~5일, 6~7일을 나눠 작성하고 별도 담당이 사실·시점·지식·표정·후속 대사의 연결을 대조했다. 작성자는 제품 파일을 고치지 않고 실제 ID별 수정안을 냈으며 메인 담당이 반영했다.

| 검토 | 발견 | 최종 처리 |
|---|---|---|
| 7일 학교 인수 뒤 문답 | 누비가 이미 학교에 간 아이들이 현재 말을 듣는다고 함 | 학교에서도 알게 될 두려움만 남김 |

slop-rewrite는 원문을 보존한 별도 작업본과 검사 기록을 남기는 절차로 사용했다. 고정된 새 사실·정답·조건·자료 효과를 교체하지 않았다. 자동 PASS와 사람의 자연스러움·감정 판단은 구분했다.

1~2일 작업본에는 수치 0·인용 1·부정 7이 빠졌다는 비교 안내가 있었다. 문장을 합치거나 부모의 실제 대답으로 고치면서 생긴 차이이며, 자료의 인용 원문과 판정 효과는 그대로 두었다. 6~7일은 누비의 말이 끊기는 줄표 한 곳의 AT-18 S2가 남아 자동 FAIL이다. 게임에서 의도한 중단 발화를 지우지 않았다. 이 잔여를 전체 자동 통과로 보고하지 않는다.

전용 미수판 19블록·67행도 별도로 읽었고 9행을 수정했다. 자동 발견은 없었으며, 칼의 기존 주장·부분 성공 범위·초상 인수·좌우 기록법의 후속 회수를 직접 대조했다.
