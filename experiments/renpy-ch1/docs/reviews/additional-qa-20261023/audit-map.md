# 추가 QA 지도 검토 — A03·A05

## 기준선 대조

원 보고서는 0.20.11의 실제 플레이를 기록했다. 수정 기준 0.20.14에서는 이미 갈색·금색 주변 UI, 제목/상태판 글자 잘림, 터치 버튼 88px, 지도 하단 여유 184px, 실제 드래그 후 첫 탭 누락을 고쳤다. 이 항목을 추가 QA의 신규 수정으로 세지 않는다.

A03의 ‘교환함’과 지도 ‘깊은 숲’ 연결 표시는 없었고, A05의 드래그 안내 및 PageUp/Down 지도 이동은 없었다. 원 보고서는 휠·드래그를 실행하지 못했으므로 ‘우체국 이동 불능’의 재현 증거가 아니다.

## 적용

- `r13_map_label()`은 2일차 `go_box`, 또는 같은 첫 장면 `MS14_D02_S01`의 `travel`→`forest` 및 교환함 미조사 조건에서만 ‘깊은 숲 · 교환함’을 표시한다. 기존 이동 목록에 숲이 들어 있어야 표시한다. 선택 정보, 건물 접근성 이름, 산길 hover 표시가 같은 함수를 사용한다.
- 지도 원화의 이름이나 이야기의 고정 장소명은 바꾸지 않는다. `box_inspect`, `box_note`, 우체국, 다른 날짜/장면, 아침 복귀 이전 단계에는 기본 장소명으로 돌아온다. 저장 데이터에 별도 안내 플래그를 남기지 않는다.
- 마을 지도 안내띠에 PC 드래그·휠·Shift+방향키·PgUp/PgDn, 터치 손가락 드래그 방법을 표시한다. 고정 크기 산길에는 기존 선택·확정 안내를 유지한다.
- Shift+방향키는 지도 viewport를 160px씩 옮기고 PageUp/Down은 화면 단위로 옮긴다. 기본 방향키는 기존 버튼 포커스 이동에 남겨 두었다. 이 입력은 장소 선택값이나 세계 상태를 변경하거나 여행을 확정하지 않는다.

## 지킨 범위

이동 가능 조건, 발견되지 않은 장소의 비밀, 별칭 장소 배제, 잠김 안내, 선택 후 이동 버튼으로 확정하는 구조는 유지한다. A01·A02 목표/대사와 A04 인물 배치 파일은 수정하지 않았다.

## 파일

- `game/room13_navigation.rpy`: 단계별 보조 장소명 및 조작 안내.
- `game/room13_worldmap_v5.rpy`: 지도 키보드 이동 및 보조명 연결.
- `dev/test_map_additional_qa.py`: 단계·완료·복구·이동가능 경계 및 상태 불변 시험.
- `dev/qa_map_additional.py`: 새 빌드에서 실제 휠·드래그·키보드·터치 검사 및 화면 캡처.

## 검증

`PYTHONPATH=dev python -m unittest test_map_additional_qa test_map_affordance test_worldmap_v5 test_inn_navigation_v4`: 24개 통과(신규 5개, 기존 19개). 브라우저 스크립트 `py_compile` 통과.

새 빌드의 네이티브 실행과 브라우저 실물 검증은 통합 빌드 뒤 진행한다. 아직 실행하지 않은 화면 시험은 통과로 기록하지 않는다. 브라우저 스크립트는 새 게임 입구 이후 day2 및 공개 장소 fixture를 사용하며 실제 이야기 완주 검증으로 세지 않는다.

## 마무리 보완

0.20.14 안내띠 아래 빨래터 이름 rect [495,565,100,42]는 첫 클릭 때 선택 유지, 같은 지점 두 번째 클릭 때 laundry 선택으로 바뀌었다. 안내띠 뒤 입력 통과가 확인되어 최종 viewport의 높이를548로 제한해 그림과 입력을 함께 자른다. 사용자의 추가 실측은 휠·드래그와 우체국 진입 정상이며 이동 불능으로 분류하지 않는다. 장시간 다중 기기 검증은 즉시 마무리 지시에 따라 이번 판에서 생략한다.
