# 추가 QA 반영 — 0.20.15

2026-10-23 전달된 [원문](SOURCE.md)을 공개 0.20.14(`9d895f36`)와 대조했다. 보고서의 플레이 버전은 0.20.11, 당시 소스 검토 버전은 0.20.12다. 구현·지도·현장 배치·아침 복구·독립 검수를 다섯 담당으로 나눴다.

| 항목 | 현재판 대조 | 반영 내용과 확인 기준 |
| --- | --- | --- |
| A01 초롱 이후 필수 조작 | 반복 응답이 지지 끈으로 이어지지 않음 | 해당 단계의 초롱 응답과 등불 이름에 조작 대상을 명시. 원래 등불 클릭으로 진행하며 반복 안내 자체는 자료·시간·진행을 바꾸지 않음. |
| A02 현재 행동과 생각 | 장면 단위 목표가 남고 의문 0개가 혼동을 줌 | 기존 gate·scene·travel_to로 현재 행동 계산. 자료 보기로 연결. 복구 시 저장된 단계에서 자동 재계산. |
| A03 숲/교환함 목적지 | 대사와 지도 이름 연결 부족 | 교환함으로 가는 단계에서만 ‘깊은 숲 · 교환함’ 표시. 원래 이동 허용 조건과 선택→이동 유지. |
| A04 고정 UI 가림 | 이름표 보정과 별개로 배우·교환함 확인 필요 | 광장·숲의 얼굴과 필수 사물 배치를 계측해 보정. 좌우 카메라, 보통·큰 글씨, PC·가로 휴대폰을 확인. |
| A05 지도 탐색 | 기존 휠·드래그와 하단 여유 공간은 유지 | 입력 방법 안내, Shift+방향키·페이지 키 탐색 추가. 드래그 자체가 이동을 확정하지 않는지 확인. |
| 아침 복구 | 원문에서는 취소·2일 아침 복귀 정상 | 복구 로직을 유지하고 실제 새 게임에서 취소, 자료 보존, 진행 복원, 복귀 후 재진행, 수동 저장과의 구분을 검증. |

추가 인계의 ‘대필도 합니까?’는 읽음 표시 설정 누락을 보완한다. 저장 가져오기 성공 후 저장 캐시를 비우고 화면을 갱신한다. 지도 휠·드래그와 우체국 진입은 추가 실측에서 정상으로 정정되었으며 이동 불능 결함으로 분류하지 않는다. 소유자의 즉시 마무리 지시에 따라 장시간 자연 플레이와 전체 회귀는 이번 판에서 생략하며, 실제 완료된 확인만 검증 기록에 남긴다.

판정·증거 획득 시점·조건·시간 소모·생사·결말을 변경하지 않는다. 교환함에서 직접 관찰한 사실과 범인에 대한 추측을 구분하는 원문도 보존한다. 보고서의 미검증 항목을 확인된 버그나 통과 결과로 취급하지 않는다.

최종 시험 결과와 검증 한계는 [VALIDATION.md](VALIDATION.md)에 기록한다. 담당별 근거는 [안내](audit-guidance.md), [지도](audit-map.md), [배치](audit-layout.md), [복구](audit-recovery.md), [독립 검수](audit-integration.md)로 나눈다.
