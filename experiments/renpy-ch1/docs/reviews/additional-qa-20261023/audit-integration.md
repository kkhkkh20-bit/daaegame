## 최종 배치 및 저장 가져오기 보완

- 교환함은 x880/y500의 단일 rect에서 그림 위치·크기와 클릭 영역을 함께 만든다. D2 및 D11 `pump_open11`이 같은 물건을 쓰며 D11 진행 라벨과 행동 조건은 변경하지 않았다. 왼쪽 화면에서는 최소 140×116의 식별 가능한 부분, 오른쪽 화면에서는 전체 그림이 UI 밖에 남는다.
- 광장/숲은 현재 배율 1.0, 높이720이고 카메라가 좌우 끝으로 정착한다. 새 HUD 회피가 사용하는 월드좌표와 UI좌표가 이 두 장소에서는 일치한다. 인물 번역은 x/y/rect/depth 및 들고 있는 소품 keepout을 같이 옮기며 인물 크기·표정은 유지한다. 고정 의자/가구 접촉 인물은 이동하지 않는다.
- 새 후보 점수는 UI 얼굴 가림, 중요 물건 가림, 다른 얼굴 가림 순이다. 측정된 D2 fixture를 실제 일반/큰 글씨/터치 높이64·80·88의 UI 사각형에 각각 대조해 얼굴 교차0을 확인했다. 이 짧은 순수 함수 계측은 새 실행 화면 시험을 대신하지 않는다. 최대 터치 생각버튼 영역만으로 일반 버튼의 y600~616을 모두 포함하지는 않아 담당에게 전달했다. 현재 fixture에서는 이 틈의 충돌도 없었다. D11 실제 화면은 담당 최종 통합 검사 범위다.
- 추가 사용자 제보인 저장 파일 가져오기 성공 후 메인 불러오기 비활성은 기존 runtime이 `location.scan()`만 호출하는 경로와 맞는다. 부모 요청으로 읽기전용 역할을 이 부분에 한해 해제하고 `dev/build_web.py`의 loader 설치에서 성공 후 scan 다음 `renpy.loadsave.clear_cache()`를 호출하도록 수정했다. 해당 엔진 함수는 슬롯/최신슬롯 캐시를 지우고 화면 interaction도 재시작한다. 파일 sync 성공 뒤 기존 성공 메시지 전에 실행하며 저장 내용·현재 진행을 변경하지 않는다.
- 저장 가져오기 수정은 임시 runtime 사본에 적용해 멱등성, sync 이후 호출 순서, Node JS 문법을 확인했고 관련 저장 UI 단위8개가 통과했다. 공개 runtime은 부모의 새 빌드에서 생성된다. 긴 검증은 사용자의 빠른 마무리 요청에 따라 추가하지 않았다.
