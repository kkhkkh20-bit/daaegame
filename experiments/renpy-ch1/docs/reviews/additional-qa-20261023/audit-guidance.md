# 추가 QA A01·A02 — 2일차 행동 안내

기준: 0.20.14, `9d895f36`. 보고서 원문 `SOURCE.md`는 0.20.11 실제 화면 검토이므로 현재 코드와 대조했다.

| 항목 | 현재 확인 | 반영 |
|---|---|---|
| A01 초롱 재클릭 | `lamp_rope`는 등불 object만 연결되어 있고, 초롱에게 하는 필수 질문은 없다. 일반 인사/빈 대화 경로가 점검 요청을 복기하지 않음 | 현재 단계가 `lamp_rope`이고 2일차 광장일 때 초롱이 덮개 지지 끈을 먼저 잡아 달라고 짧게 안내. 첫 클릭·재클릭 모두 같고 획득이나 진행 실행 없음. 등불의 기존 호버/접근성 이름도 `등불 · 덮개 지지 끈`으로 표시 |
| A02 현재 생각 | 2일차 광장·교환함이 같은 장면 ID라 장면 기본 의문 `오늘 마을을 떠날 길이 있을까?`를 공유 | `lamp_rope`, `go_box`, `box_inspect`, `box_note`, `envelope_show`, `post_menu`별 생각. 이동 중에는 실제 저장된 `gate=travel`, 장면, `travel_to`로 입구·광장·숲·우체국 목표 선택 |
| A02 의문 0개 | V111에서 notes를 항상 빈 배열로 만들어 구형 조사 메모 개수 0이 표시됨 | V111 생각창은 `모은 자료 보기`로 실제 자료 탭을 열도록 연결. 구형 캠페인의 조사 메모와 개수 표시는 유지 |

생각은 장기 목적(아내 소식·편지 발신인)과 지금 할 일(끈 잡기·지도 이동·교환함 조사·쪽지 넣기·봉투 제시)을 연결한다. `go_box` 이후 초롱 재클릭도 그 단계의 생각으로 돌아간다. 다른 날짜·장소·인물·단계는 기존 인사·생각으로 위임한다. 후일 숲 재방문에 2일차 안내가 남지 않는다.

소유자 추가 QA 적용 지시가 해당 조작·목적지 안내를 허용하므로 기존 일반적인 목적지 안내 제한의 예외로 적용했다. 수사 정답·숨은 단서·범인·다음 결과를 미리 알리지 않는다. 새 반짝임·돋보기·화살표는 추가하지 않았다.

- `game/systems/room13_day2_guidance.rpy`: 조회 전용 단계별 문구, 초롱 재클릭, 등불명 표시.
- `game/systems/room13_v111_goal.rpy`: 기존 생각 계산 함수에서 2일차 안내를 우선 사용.

`field-bindings.json`, `room13_v111_days123.rpy`, `d02.json`은 수정하지 않았다. action index/guard, 자료 획득 commit L0033·L0039, 이동과 조사 시간, 정답·결말·생사 값은 그대로다. 안내를 읽는 것으로 점검이나 교환함 조사가 실행되지 않는다. 새 진행 값을 저장하지 않아 아침 상태를 복구하면 안내도 복구된 단계에서 다시 계산된다.

## 검사

순수 단위: 신규 7개, v111 32개, newworld 27개 통과. 조회 전후 상태 전체 비교와 반복 클릭 3회, 2일 아침→교환함 진행→아침 상태 복원 시 안내 복원을 확인했다. 실제 네이티브 화면·브라우저·아침 UI 복구는 통합 검수에서 별도 실행해야 한다. 여기서 실제 플레이 완료로 주장하지 않는다.

실제 화면 검수용 `dev/qa_day2_guidance.py`를 준비하고 Python 문법 검사를 통과했다. 날짜·장소·단계·등장인물·기존 만남을 명시적으로 설정한 뒤 실제 버튼으로 생각, 자료 탭, 초롱 반복 대화를 검사한다. PC와 740×360 큰 글씨 캡처, 생각 본문 높이, 등불 접근성 이름·호버, 자료 탭 연결, 전후 `room13` 전체 불변을 확인하도록 작성했다. 현재 단계는 새 웹 빌드 대기이며 실행 통과를 주장하지 않는다.
