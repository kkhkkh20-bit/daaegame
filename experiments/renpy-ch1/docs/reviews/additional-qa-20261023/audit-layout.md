# A04 · 광장과 숲의 고정 메뉴 가림

기준은 실제0.20.14 웹판이다. 기존 보고서0.20.11의 증상을 그대로 결함으로 옮기지 않고 날짜2·광장 lamp_rope·숲 box_inspect 화면 fixture로 재현했다. 날짜·장소·장면·라벨을 검수용으로 준비했으며 자연 진행 완주로 주장하지 않는다. 기존판 캡처와 배우/머리/사물 좌표는 `/workspace/work/daram-additional-qa/layout-baseline/`에 있다.

## 확인한 원인

기본 입석 후보는 UI를 피하지만 이후 고정 작업 동작과 필수 물건 회피 단계에서 위치가 다시 바뀐다. 마지막 단계에서는 UI를 다시 검사하지 않았다. 큰 글씨에서 광장 다람, 숲 왼쪽 초롱, 숲 오른쪽 다람의 얼굴과 생각 버튼이 겹치는 것을 실제 좌표와 캡처에서 확인했다. 숲 교환함은 월드 `[1150,548,220,152]`라 왼쪽 화면에서 보이는 부분이 대부분 생각/기록 영역 뒤로 들어갔다.

## 반영

- 최종 물건 회피 이후 **광장·숲에만** 얼굴과 하단 고정 메뉴를 재검사한다. 겹친 인물만 같은 그림·가로세로 크기를 유지해 평행 이동한다. 필수 물건, 주변 얼굴, 앞뒤 깊이를 함께 비교한다. 실제 그림과 클릭 마스크에 이미 쓰는 `r13_balance_translate`를 재사용하며 들고 있는 물건의 마스크도 같이 옮긴다. 가구에 앉거나 매달린 인물은 이동시키지 않는다.
- 같은 장면에서 카메라를 움직일 때 배우가 갑자기 달아나지 않도록 좌우 끝 카메라를 함께 검사한다. 이 두 장면의 월드 배율은1.0이다. 공통터치 최대 크기의 하단 좌표 `(772,616,480,88)`, 생각 `(1020,512,232,88)`를 양쪽에 예약한다. 이는 기존 UI의 가장 큰 높이를 보수적으로 예약한 값이며 새로운 UI 배치가 아니다. 공통 UI 규격이 바뀌면 이 예약값도 함께 확인해야 한다.
- 교환함은 크기220×152를 유지해 `[880,500,220,152]`로 옮겼다. 좌우 화면 공통 구간이며, 가장 큰 하단 UI에서도 왼쪽 위140×116 영역을 가리지 않는다. 740×360에서 해당 식별 영역은70×58 CSSpx다. 그림이 클릭 rect를 직접 읽도록 묶어2일차와11일차 MS14_D11_S00 양쪽에서 같은 위치를 쓰게 했다.
- 0.75배율 입구를 포함한 다른 장소에는 새 배치 보정이 호출되지 않는다. 공통 카메라, 이름표, UI, 그림 크기, 사건·획득 조건은 변경하지 않았다. 인물의 몸 전체가 항상 UI와 떨어진다는 주장은 하지 않으며 완료 기준은 얼굴과 필수 사물 식별 영역의 노출이다.

## 단위 검증

기존판의 실제 배우/머리 좌표를 작은 fixture로 저장했다(`dev/fixtures/additional-field-layout014.json`). `dev/test_additional_field_layout.py`는 양쪽 카메라의 최대 터치 메뉴와 얼굴 겹침 없음, 원래 배우 배열 불변·그림/크기 보존, 이동한 배우가 주요 조사 물건을 덮지 않음, 교환함의 그림/클릭 영역 공유·연속 식별 영역 확보, 이동 마스크 일치를 확인한다.

관련 단위시험 **30개 통과**:

`PYTHONPATH=dev python -m unittest test_additional_field_layout test_play_review_field test_settings_type_scale test_visual_correction test_presentation_loading test_choice_length test_topic_footer test_room13_question_layout`

## 최종 빌드에서 확인할 것

`dev/qa_additional_field_layout.py`로 PC1280×720 /844×390 /740×360, 보통·큰 글씨, 좌우 카메라를 확인한다. 메뉴 클릭이 뒤의 사물 행동을 실행하는지는 가림과 별도로 실제 입력으로 확인한다. 교환함의 새 위치가 지면에서 자연스러운지, 최종 재배치된 배우가 교환함을 덮지 않는지,11일차 교환함 재방문은 최종 캡처 및 실제 입력 확인 전까지 미검증이다. 네이티브·웹 빌드는 부모 담당이다.

## 최종 보완

생각 버튼 예약은 PC·터치의 합집합 y512~624, 높이112로 확대했다. 해당 범위의 측정 fixture 단위 검사를 함께 갱신했다. 최종 배포에서 모든 기기·11일차를 실제로 확인한 것으로 간주하지 않는다.
