## 검증 한계

첫 입구까지는 실제 새 게임으로 진행했다. 자료 전체 보유·후반 장소·질문30개와 일부 제출 경로는 명시적인 검수용 상태를 사용했다. 후반부를 자연 플레이로 모두 완주했다는 뜻은 아니다. 전체14일 수동 플레이, 실물 휴대폰의 터치 오조작률, 실제 사용자 참여 시험은 실행하지 않았다.

PC 마우스의 위치 순간이동과 누름을0ms에 합성하면 호버 갱신과 경합하는 경우는 남아 있다. 실제 포인터 접근을 모사해 이동 후180ms 호버→첫 클릭한 조건과 구분하며, 실제 터치 드래그의 첫 탭 누락은 수정 후 재시도 없이 통과했다.

공개 사이트 도메인은 실행 환경의 네트워크 정책으로 직접 접속할 수 없다. 동일 산출물의 로컬 브라우저 실행과 GitHub Pages 빌드 상태를 별도로 확인한다.
