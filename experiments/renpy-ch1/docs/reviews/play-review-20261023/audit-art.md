# 자료 그림 인수 검토 · 2026-10-23

요청: 자료마다 맞는 아이콘을 배치하고, 다른 Codex 채팅에서 받은 자산도 원본과 실제 표시를 대조한다.

## 결과

현재 V1.1.1 정본과 새 세계관 덮어쓰기를 합치면 자료는 80종이다. 기존 제작 자산을 조사한 결과 새로 생성해야 할 그림은 없다. 전용 자료 그림 68종, 상태별 그림 3종, 실제 발언자 얼굴을 쓰는 증언 9종으로 모두 연결할 수 있다. `assets/evidence/`의 나머지 두 그림(D01_FAMILY_DRAWING, D01_SNACK_BAG)은 장면용이므로 자료 수에 넣지 않았다.

| 구분 | 수 | 조치 |
| --- | ---: | --- |
| 자료 전용 그림 | 68 | 기존 `assets/evidence/<key>.webp`를 목록에도 연결한다. 큰 상세 그림과 같은 물건을 보여 준다. 부모 작업의 evidence_view 수정 대상이다. |
| 상태·내용별 그림 | 3 | E09 초상(미완성·완성·다람 완성), E30 보따리, E13_MENDING 수선 담요는 기존 연결을 유지한다. |

기존 목록은 V111 자료에 옛 캠페인의 두루마리·일반 종이를 재사용했다. 그림 파일의 부재보다 목록과 전용 원화가 연결되지 않은 것이 주원인이다. 기존 원화는 `art/evidence-art-20261022/`에 원본과 제작 기록이 있으며, 별도의 새 생성으로 교체하지 않았다.

## 그림 검토

`evidence-contact-0.jpg`부터 `evidence-contact-2.jpg`까지 기존 70장을 한눈에 확인했다. 따뜻한 갈색 종이·목재·금속 색과 투명 배경이 기존 자료 화면에 맞는다. 반쯤 탄 수첩 장은 실제로 오른쪽이 탄 종이이고, 장부·쇠고리·돌판·목도리·겉옷·유리 파편은 자료명에 해당하는 서로 다른 형태다. 문서의 글은 읽을 수 없는 필기선이며 별도의 정답 문구나 강조 표시를 추가하지 않았다. 기존 방 메모·경고 편지의 작은 그림은 보존한다.

상태별 원화와 얼굴을 포함한 파일별 크기·알파 범위·SHA-256·화자·자료명은 `evidence-art-manifest.json`에 기록했다. 이는 원본 자산 검토이며, 목록 축소 크기에서의 식별성과 잘림은 통합 브라우저 캡처로 별도 확인해야 한다.

## 다른 채팅에서 자산을 받을 때

1. 자료 ID와 현재 본문을 함께 받는다. 옛 캠페인의 같은 숫자 ID를 현재 자료로 오인하지 않는다.
2. 상태가 다른 자료는 상태 키와 각각의 그림을 명시한다. 미완성 초상을 완성 그림으로 바꾸지 않는다.
3. 증언은 주제 인물이 아닌 실제 발언자와 대조한다.
4. 원본 파일·생성 기록·게임용 파일의 경로와 해시를 기록한다. 기존 자산이 맞으면 중복 생성하지 않는다.
5. 알파·크기·클리핑을 확인하고, 기존 화면 바탕 위에서 목록과 큰 상세를 둘 다 캡처한다.
6. 정답의 의미를 새 그림에 임의로 추가하지 않는다. 자료 획득 조건·판정은 별도 코드 검증을 거친다.

## 검사

`python -m unittest dev/test_evidence_assets.py -v`: 3개 통과. 전체 80종의 그림 커버리지, 9종 증언의 본문 화자와 얼굴 파일, 초상 3개 상태·보따리·수선 담요 파일 존재를 검증했다. 새 그림 생성 수는 0이며 기존 80종 연결 완성이 목표다.
