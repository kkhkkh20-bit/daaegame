# 1〜2일 대사 후속 검수 (0.20.53)

전체 개작 완료가 아니라 날짜순 후속 검수 첫 묶음이다. 1〜2일 합본의 조건별 변형을 대조하고 27개 문장을 수정했다. 수정한 줄만 reviewed로 기록하며, 다른 줄은 일괄 완료 처리하지 않는다.

- 초소 미등록판: 아빠의 질문에 작업표의 동행인 기입 방식을 답한다. 아이를 들여보냈지만 이름은 없는 결과를 유지한다.
- 초롱: 누구냐는 질문에 다돌이 이름과 메모를 보여 주는 이유를 답한다. 식량을 놓은 함과 거주지를 구별한다.
- 우체국: 가져온 사람과 쓴 사람을 구분하고 아빠가 확인된 범위를 되묻는다.
- 초상 의뢰: 피코는 처음엔 앞에 온 부녀를 그려 달라는 부탁으로 받아들였다가, 없는 엄마를 찾는다는 말에 반응한다.
- 까로의 마차 걱정, 피코의 그림과 잠자리 고집, 아빠와 다람의 가족 그림 이야기를 생활 대화로 보강한다.
- 교환함 쪽지를 엄마가 반드시 읽는다고 단정하지 않는다. 네로가 본 일을 확인하는 범위는 그대로다.

조건·증거 문구·획득·생사·회의 정답·장면 순서는 변경하지 않았다. 전후 문장은 apply-report.json, 재사용 가능한 원본 편집 묶음은 edits.json에 보존한다. 원본 반영 뒤 소스 지문이 달라졌으므로 이 묶음을 재적용하면 이전 버전 검사에 걸리는 것이 정상이다.
