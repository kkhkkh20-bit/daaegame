# 0.20.129 — 진행 중 지연 검수

2026-11-08. 이전128 검수는 첫 로딩 바이트·원화 표시·부분 경로 위주였고 진행 중 지연 측정이 부족했다. 이번에는 숨은 회의 인물의 생성·예측, 중복 자동 예열, 인물 점진 로딩 경로를 조사했다.

## 수정 근거

- 단독 회의에서도 모든 회의 주민의 원화를 만들고 `visit()`에 넣고 있었다. 실제 화면에는 현재 화자만 그린다. 같은 좌석 명단을 보존하면서 생성·예측할 원화는 현재 화자만 고른다.
- 완료된 놀람의 전용 반응 그림을 다시 만들고 예측하던 비용을 제거한다. 반응 진행 중에는 두 그림을 유지한다.
- 여러 시기의 인물 등록표를 모두 순회해 옛 그림·전체 감정·특수 자세를 함께 예열하던 방식을 현재 중립 대화·현재 현장 중립으로 제한한다. 실제 표시할 다른 표정·자료·특수 장면 파일은 점진 제공을 유지한다.
- 현행 `dialogue-player-facing`, `dialogue-size-fit`, `field-dot-v2` 등록표가 인물 분류에서 빠져 일부 새 원화는 작은 유색 축소본으로 대체됐다. 이들을 인물로 분류해 같은 크기의 투명 대체 그림을 사용한다. 이미지 원본이나 표시 크기를 줄이지 않는다.


## 측정 방식과 범위

같은 로컬 Chromium·1280×720·소프트웨어 그래픽 환경에서 준비한5일 회의 진입과12회 화면 클릭을 비교한다. Python profiler를 켠 결과는 웹 Asyncify 대기 시간이 일부 내장 함수에 부정확하게 귀속돼 개선률 근거에서 제외한다. 별도 일반 실행에서 대화 원화 생성 함수 호출 수와 브라우저 작업 시간·실제 이미지 캐시 크기를 기록한다. 캐시 크기는 해당 시점의 값이며 최대 메모리나 휴대폰 실기기의 값이 아니다.

기준128 일반 실행은 약16.15초 구간에서 원화 생성168회(회의6명 각28회), 브라우저 작업 시간 약9.44초였다. 준비한 상태의 짧은 비교이며7일 전체 연속완주 결과는 아니다. 

예열 표는 파일 목록의 전송 예산이다. `fetch.blob()` 예열은 모든 그림의 즉시 디코드를 뜻하지 않으며, 전체 목록의RGBA 환산치를 실제 메모리 측정으로 보고하지 않는다. 처음 게임을 열기 전 필수 로딩과 게임 시작 뒤 예열도 구분한다.

소유자가 마지막으로 렉만 먼저 고치도록 범위를 좁혀, 대사·일반소품 클릭 방식·아빠 초상·엄마방 그림 작업은 이번 공개에서 제외했다.

## 자동 예열 예산

실제 공개 transport.prefetch 목록 기준으로128의108개·24,937,584바이트를129의12개·1,030,362바이트로 줄였다(약95.9% 감소). 이는 시작 후 예열 목록의 예산이며 첫 필수 로딩 전체가96% 줄었다는 뜻이 아니다. 음악8,013,108바이트는 실제 장소에서 재생할 때 기존 점진 로더로 받는다. 타이틀·마차의 필수 음악·효과음은 유지한다. [실제 목록 예산](warm-budget.json), [날짜별 인물 후보 예산](character-prefetch-budget.json)을 구분한다. 날짜별 후보 표의1일130개·17,181,074바이트는 음악과 최종 remote필터 전 값으로, 실제 자동예열량으로 사용하지 않는다.

## 수정 뒤 단기 비교

[기준](before.json)·[수정 뒤](after.json)의 같은 회의 진입과12클릭에서 원화 생성은168회→28회로 줄었다. 보이지 않는 다섯 사람의 준비가 제거된 결과다. 이미지 캐시는 관찰 시점70개·33,039,199픽셀→30개·19,160,530픽셀이었지만 앞선 화면 이력이 달라 전체 메모리 개선률로 사용하지 않는다.

브라우저 작업 시간은9.440초→9.416초로 큰 차이가 없었다. 따라서 이 짧은 로컬 검사만으로 클릭 지연이나 전체 렉이 해결됐다고 판단하지 않는다. 이번의 확정 개선은 자동 전송량·숨은 초상 준비·불필요한 이미지 예측 감소다. 이미 로딩된 장면의 처리 비용은 남아 있다.

[예측·연출·글자 출력 비교](prediction-ab.json)에서도 화면 예측을 실제 등록 객체에서 끄거나 문장 예측을0으로 줄이는 방법에 일관된 처리 시간 개선이 없었다. 이 실험 설정은 제품에 적용하지 않고 SDK의 기존 기본값·사용자 연출·타자 설정을 유지한다. 전체7일 연속완주·사용자의 실제 기기에서의 프레임 측정은 이번 범위가 아니다.
