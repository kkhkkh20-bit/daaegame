# B 마을 지도 적용

- 전달된 배경·수첩·버튼·다람 스티커와 1280×720 좌표를 적용했다. 테두리는 Frame으로 모서리를 보존한다.
- 그림에 없는 여관/학교/진료실 등 공개 목적지는 다른 장소 목록으로 유지했다. 공개·잠김·시간·이동 판정은 기존 함수를 공유한다.
- 하단 버튼·추가 목록·닫기 모바일 터치영역 88px. 기존 여관/숲 지도는 유지한다.
- native b_map_village_delivery 통과: 지도 선택은 이동하지 않음, 추가목록, 구역 전환, 모바일, 닫기, 광장 실제 이동.
- 관련 단위 시험 12개 통과. 개발본 캡처이며 공개 사이트 반영은 이 묶음에 포함하지 않았다.
