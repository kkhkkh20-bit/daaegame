8/12개 배치는 서로 다른 진행 단계의 부리 질문을 모으고, 12개는 일부를 반복한 레이아웃 테스트다. 실제 동시 해금 상태라는 뜻은 아니다. PC 1280×720 및 모바일 844×390/큰 글씨에서 실제 Chromium 마우스·터치로 조작했다.

페이지 왕복은 전체 게임 상태를 바꾸지 않으며, 2쪽에서 숫자 키 1이 그 쪽 첫 질문의 action을 가리키는 것도 확인했다. 실제 dispatcher에서 자료 제시·취소와 기록 열기·닫기, 질문 선택·대사·읽음 복귀 및 호출 흐름으로 돌아가기를 검사했다. [검증 결과](report.json).

`dev/check.sh`와 최종 Ren'Py lint, 공식 웹 빌드도 통과했다. 공개 빌드에는 검토 전용 화면이나 디자인 토글을 남기지 않았다.
