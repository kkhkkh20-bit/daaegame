# 도구함 검토·납품 기능 및 회의 UI 보완

실제 Ren’Py 회의 캡처, 이전/현재 비교, 마지막 캡처 재표시, 역할 제작 요청 ZIP, 직전 변경 되돌리기를 구현했다. ZIP에는 그룹의 모든 상태 원본·규격·태그·사용처·마지막 캡처가 들어간다. 사용처는 원래 파일과 그룹도 추적하며 동적 경로 누락 가능성을 표시한다.

제작용 회의 fixture라 테스트 종료 버튼이 포함되며 저장된 연결을 사용한다. 렌더 완료까지 기다려야 한다. 임시 프로젝트와 별도 저장에서 실행하며 분리된 자식 프로세스 종료·무관한 프로세스 보존을 검증했다.

의미 역할은 18→52개. 기존 3,104개 역할 연결은 유지했다. 회의 상단·이름·본문과 수첩 링 겹침은 기존 납품 패널로 수정했다. 대사·판정 로직은 유지했다.

관련 단위 97건, Ren’Py lint 통과. 실제 캡처 및 브라우저 캡처 버튼→비교→ZIP 다운로드 검증 통과, JS 오류 0. 모바일 별도 화면과 전체 회귀는 이번에 재실행하지 않았다.
