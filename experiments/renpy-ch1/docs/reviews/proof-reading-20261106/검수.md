# 증거 읽기 UI 본편 적용 검수 · 0.20.113

2026-11-06. 소유자 지시로 별도 시안 승인 규칙을 삭제하고 0.20.112의 PC·휴대폰 읽기 방향을 본편에 적용했다. CLAUDE.md·AGENTS.md·CODEX_OPERATING_GUIDE.md의 현재 적용 문구를 함께 정리했다. 예전 릴리스나 원고에 남은 당시 승인 이력은 작업 기록으로 보존한다.

## 동작과 정보 경계

- 목록은 이번 회차에 보유하고 기존 제시 적격인 자료만 보여 준다. 기존 분류와 획득 순서 정렬을 유지한다.
- 이름을 눌러 한 장을 읽거나 두 비교 자리를 채워도 제출 묶음은 바뀌지 않는다. 체크만 제출 선택을 바꾼다. 빈 제출은 비활성이다.
- 두 장 읽기의 자료 제목에서 그 자리를 변경할 수 있다. 다른 자리와 같은 자료를 고르면 중복 자리를 비운다. 제출 묶음과는 독립이다.
- 실제 발언은 상단에서 펼친다. 자료의 현재 변형·상태별 기존 사실은 작은 그림보다 먼저 읽힌다. 전체 내용·출처는 따로 펼친다.
- E11의 청소·조각 없음 진술은 `after.MS14_D03_S02_L0023`의 추가 문답 NW_D03_S02_T22/T23에 실제로 있다. 현재 UI는 문서 두 줄을 먼저 보이고 이 진술은 전체 내용·출처에 남긴다.
- E13은 우박의 실제 시간 답변 뒤 측정지를 받아 보유한다. 기존 facts의 마지막 보고된 진술만 ‘함께 들은 말’로 나눈다. 기록 종류라는 이유로 다른 자료를 전부 문서라고 재분류하지 않는다.
- 두 편지 원문과 구역 짚기, 세 번째 비교 자료 교체 확인, 기존 재조사·되묻기 반환과 정답 판정은 유지한다.

## 웹 검증

새 Chromium에서 버전0.20.113·전송 조각 두 개 HTTP200·메인화면·페이지 오류0을 확인했다. [새 브라우저](새브라우저.json). [웹 묶음](웹묶음검사.json)은 모든 조각 크기/해시와 합친 ZIP 해시를 맞췄고 실행 UI 원본과 일치, qa_tests 제외를 확인했다.

기존 실제 `br-piko_lost-day3`를 화면 클릭으로 이어 약39초 만에 진료소 자료 대조에 도착했다. 이 상태를 실제 저장한 뒤 PC1280×720으로 복원하고 두 자료를 이름으로 골라 읽었다. 선택0·기회 불변을 확인했다. 이어 같은 브라우저를844×390으로 바꿔 실제 터치 UI를 검사했다. 두 기기 모두 두 열의 스크롤 범위0으로 E11/E13 핵심 사실이 전부 첫 화면에 보였다. 출처·모드 전환 뒤에도 제출 선택E11 한 장과 기회가 유지됐으며 페이지 오류0이다. ## 추가 연속 검수에서 정정한 기록

이전 검수는 replace의 L0023만 보고 after 문답을 놓쳐 ‘실제 대화에서 빠졌다’고 잘못 적었다. 0.20.113을 새 게임부터 화면으로 이어 다람의 “반짝이는 거, 그때도 있었어요?”와 초롱의 “없었어요! 돌을 잠깐 들고 받침 가루까지 털었는걸요”가 실제로 나옴을 확인했다. 이후 L9103의 ‘초롱이 따로 한 말’은 출처가 있는 요약이다. 이 항목은 게임 오류로 세지 않는다. 검수자의 설명을 정정하며 실행 코드와 웹 묶음은 유지한다.
