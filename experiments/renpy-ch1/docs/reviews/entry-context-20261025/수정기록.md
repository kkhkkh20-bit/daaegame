# 초소 대화 맥락과 4일 조사 연결

소유자 지적: 방문객인 아빠에게 일꾼·아이 제한부터 말하면 아빠 입장에서도 맥락이 없다. 상대가 이름과 방문 목적을 확인하는 과정이 먼저 필요하다.

1일: 이름 질문→다돌 답변→돌목이 명부에서 이름을 찾음→일꾼으로 기재된 사실→아빠의 방문 목적 확인→기재 내용과 신청 원본 대조로 이어지도록 수정했다. 장작 운반을 이미 들은 뒤 다시 처음 듣는 것처럼 묻던 후속 대사도 바꿨다. 판정·자료 내용은 유지했다.

4일: 실제 저장에서 look_gate4의 조사 대상 booth가 새 gate_documents 영역 뒤에 겹쳐 일반 서류 반응만 반복되는 것을 확인했다. 기본 조사 대상을 화면 위에 있는 gate_documents로 바꾸고 반환 index는 그대로 유지한다. 동일 조사 뒤 기존 물림 장면으로 이어진다.

단위: 대사층27개·후반 연결16개 통과, 대사 논리 A/B/C 0건. 실제 화면 검증 결과는 릴리스0.20.36과 후속 로그를 따른다.
