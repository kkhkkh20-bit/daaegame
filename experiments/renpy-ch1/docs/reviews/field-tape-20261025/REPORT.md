# 빨간 테이프 반복 제거

소유자 지적: 모든 부품 오른쪽 위에 같은 테이프가 반복되어 복사한 느낌이 난다.

공통 paper 기본/hover에서 테이프를 제거하고 place 기본/hover 두 자산만 장식을 유지한다. r13_field_paper(tape=True)를 장소명 한 곳에서만 사용한다. 나머지는 동일한 종이색·남색 테두리를 공유한다. SVG 생성기와 에셋 도구함을 함께 갱신했다.

실제 조사 화면 gate-clear-touch.png 및 capture.log에 사물·기록·생각·인물 클릭 확인을 기록한다.

검사: 전체1051개와 lint 통과. 실제 화면4개 assertion 통과. 첫 자동 검사는 상태에 따라 달라지는 “새 생각” 문구 탐색에서 시간초과하여, 같은 버튼의 좌표로 눌러 재검증했다.
