# 에피소드별 후일담 컷신

기준: `16a9cf44`까지의 main에 있는 대사와 결과 플래그. 게임 전체 엔딩 E0–E6의 기존 28개 장면은 유지하고, 여섯 사건의 마무리에 별도 후일담을 연결했다.

새 그림 28컷(에피소드별 24컷과 보조 결말 4컷), 승인된 장면 그림 4개, 기존 초상화 컷과 승인 캐릭터 원화를 조합한 장면으로 53개 후일담 프레임을 구성한다. 하나의 결말마다 모든 그림을 재생하지 않는다. 독립적인 결과를 조합해 해당 플레이에서 일어난 장면만 보여 준다.

| 에피소드 | 후일담에 반영하는 결과 |
|---|---|
| ① 조각 도난 | 피코 생존/사망, 톡 석방/구금, 실룩 인계/빚 면제, 백 부인 창고 개방 |
| ② 아이들의 회의 | 강가에서의 작별/신발만 남음/진료소, 밤이 귀환/연행, 솜이의 침묵, 이틀 뒤 빈 침상 |
| ③ 창고 화재 | 꼬미 생존/도토리 매장, 회의에 불참한 결과, 보리의 구금/세 아이를 돌봄, 누비 연행 뒤 남은 아이들/학교에 맡긴 아이들/나비가 돌보는 아이들 |
| ④ 13호의 밤 | 초롱 생존/부상/사망, 따닥 무사/동상/사망, 할머니와 토실의 작별, 부리의 모자 |

| ⑥ 수레 | 수레 정지/출발/가족만 탈출/명단 공개 뒤 소요, 바둑이 무사/부상/사망, 판돌의 탈출, 명령서 책임을 다음 날 묻는 선택, 광장에 가지 않은 밤 |

## 인물과 상황을 지키는 조건

- 아빠는 카메라다. 그림에 아빠를 추가하지 않는다.
- 다람이가 보호실에 있거나 잃어버린 상태면 다람이가 함께 있는 그림을 쓰지 않는다.
- 수레를 멈춘 결과와 바둑이의 생존은 별개다. 바둑이가 죽은 판에는 굴돌 단독 장면과 뜯긴 완장만 보여 준다.
- 꼬미 사망 장면에 살아 있는 꼬미를, 도담 사망 장면에 네 아이를 넣지 않는다.
- 따닥이 무사한 판에는 동상 붕대 그림을 쓰지 않는다. 초롱 부상은 사망과도 무사 귀환과도 구분한다.
- 무쇠의 강가 신발은 어른 신발이다. 피코의 초상화는 뒷면으로 보여 아직 그리지 못한 코를 완성해 버리지 않는다.
- 대사와 증거, 회의, 날짜, 생사 결과는 바꾸지 않는다. 컷신 선택과 재생은 현재 결과를 읽고 UI 진행 위치만 저장한다.
