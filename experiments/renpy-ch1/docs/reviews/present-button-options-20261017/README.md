# 보여주기 버튼 위치 — 검토용 A/B

소유자 요청: 핵심 기능인 보여주기가 오른쪽 위에 혼자 떠 있어 대화 UI와 연결되지 않는 인상을 개선할 시안 비교.

- A: 질문 목록 아래 오른쪽 끝에 정렬. 가로332×세로72px(큰 글씨80px), 봉투 아이콘·자료 보여주기·얇은 금빛 밑줄. 질문이 많을 때는 목록에 스크롤 공간을 확보하고 버튼과 겹치지 않게 한다.
- B: 돌아가기·자료 보여주기·기록을 하단 반투명 행동 바로 묶는다. 위치가 고정되고 모바일에서 큰 글씨 버튼 높이80px를 확보한다.
- 대사창·선택지의 승인된 반투명 재질과 높이는 유지했다. 실제 자료 제시 명령도 기존 명령을 그대로 사용한다.

실제 Chromium 캡처: 마을 입구·저녁 여관, 1280×720 및 844×390 큰 글씨. A는 실제 PC 클릭, B는 실제 모바일 터치로 원래 자료 목록(r13_book)이 열리고 그만두기로 대화 목록에 돌아오는 동작을 확인했다. Ren'Py lint·웹 빌드 통과. 상태 주입을 사용한 화면 fixture이며 전체 이야기 완주 검사는 아니다.

공개본에는 적용하지 않은 검토용 브랜치다. r13_present_design 기본값 current, 비교용 값 attached(A)·dock(B). A를 추천하지만 소유자가 시안을 확인한 뒤 공개 적용한다.
