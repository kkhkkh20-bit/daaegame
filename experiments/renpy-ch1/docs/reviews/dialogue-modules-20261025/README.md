# 분기별 대사·그림 작업 도구 검증

게임 런타임·대사 원문을 바꾸지 않고 편집/요청 도구를 추가했다.

- 백엔드 12개: 원문→실제 날짜 패치 반영, 조건변형과 fallback 동시 편집, stale/중복/메타변경 거부, 검수상태 보존, 부분 쓰기 차단·실패 rollback, 문자열 escape·보간/태그 제한, HTML JSON 왕복, 날짜 합본 UTF-8/편집 링크.
- 브라우저: 날짜/분기 선택, 수정과 상태, JSON/CSV/MD 다운로드, 새로고침 임시저장, JSON 재가져오기, 메타 조작 거부, 390px 표시. 웹에서 받은 424줄 파일을 실제 CLI로 검사해 변경 1개를 확인했다.
- 전체 웹 다운로드 19,466행을 CLI로 재검사해 변경 0개로 확인했다. 실제 문장 편집 가능 7,539개와 미확정/대체/삭제 원문 등 읽기 전용 11,927개를 구분한다. 연결 추출 항목 수이며 서로 다른 대사 수와 같다고 주장하지 않는다.
- 순서 대본 읽기와 날짜·검색 링크, 읽기 전용 표시, 통합 작업실 링크를 확인했다. 페이지 오류 0건.
- 그림 요청 포털의 검사·브라우저 결과는 ../art-requests-20261025/에 있다. 미납품10/납품확인6을 기본 제작 검토 대상으로 구분했다.

한계: 정적 대사 조건·호출 위치 묶음이며, 게임 상태 전체를 시뮬레이션해 모든 실행 경로를 생성한 것은 아니다. 동적·미확정 Python/Ren’Py 문자열은 임의 자동 편집하지 않는다. 사용자 편집의 문체·사실·분기 타당성은 게임 반영 전 별도 검수한다.
