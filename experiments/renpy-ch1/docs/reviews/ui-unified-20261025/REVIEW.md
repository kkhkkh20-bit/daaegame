# UI 통일 적용 검토 · 0.20.42

소유자의 “그러면 맞춰줘” 승인에 따라 적용했다.

- 공통 버튼: 크림/남색 테두리, 빨강 강조, 굵은 Pretendard. 눌림·선택·비활성에서도 동일한 영역을 유지한다.
- 옵션: 같은 버튼 표면을 사용하고 미리보기·행 간격을 다이어리 안에 정리했다.
- 회의 자료 대조·기록: 남색 표지와 크림 종이·링의 공통 수첩 패널로 변경했다.
- 선택: 항목마다 반복되던 테이프를 없애고 번호·문구 간격과 인물 스티커 외곽을 정리했다.
- 지도: 여관·숲에도 공통 외곽 수첩과 하단 조작을 사용한다. 제목 공간을 확보했다.
- 메인·질문: 공통 버튼 배경을 사용한다. 질문의 원래 책 그림과 대사창 배치는 유지했다.

## 자체 검토
색·글꼴·버튼 상태·책의 기본 구조를 맞췄다. 옵션과 질문은 제공된 질감 원화, 자료 대조와 기록은 늘어나는 공통 패널이므로 종이 질감까지 같지는 않다. 테이프는 제목·위치 등 일부 포인트에만 남겼다. 대사·분기·판정·장소 공개 조건은 변경하지 않았다.

## 캡처 범위
17개 실제 실행 화면. 질문·선택·갈림길에는 검토용 진행 상태/문구를 주입했고, 회의는 실제 10일차 라벨에 진입했다. 재시도는 화면을 단독 표시했다. 전체 자연 플레이 검증을 의미하지 않는다.
