# 반투명 대화 UI 검토용 시안

사용자 요청에 따라 로컬 Ren'Py 웹 실행 화면을 캡처했다. 공개본에는 적용하지 않았다.

- 비교 그림은 왼쪽 기존·오른쪽 시안, 위 밝은 실외·아래 저녁 실내다.
- 대사창 불투명도 d9(약85%), 선택지 e6(약90%), hover f5(약96%), 하단 도구 모음 b8(약72%). 글자에는 투명도를 적용하지 않는다.
- 테두리는 한 줄로 줄이고, 선택 화면 전체 암막은 80에서30으로 낮췄다.
- 모바일 캡처는 844×390 및 큰 글씨 설정이다.
- 실제 제작된 배경·인물과 원본 대사를 사용한 화면 fixture다. 전체 이야기 플레이 검사는 아니다. 대사·일정·선택 결과는 바꾸지 않았다.
- dev/build_web.py 빌드·Ren'Py lint 및 실제 Chromium 렌더링 통과.

시안은 r13_ui_preview=True일 때만 켜진다. 기본값은 False이며 해당 브랜치는 디자인 검토용이다.
