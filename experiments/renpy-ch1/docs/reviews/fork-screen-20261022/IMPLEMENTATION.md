# 갈림길 구현 인계

기준: 소유자가 승인한 approved_A.png / approved_A.html. 상세 패널 B는 구현하지 않는다.

- 진입: 새 세계관의 기록 화면 왼쪽 `갈림길`. 기존 수첩 위에 읽기 전용 화면을 연다. 자동 표시·이동·되돌리기는 없다.
- 화면: 공통 R13PaperFrame / R13PaperPanel / r13_control / R13AntiqueIcon. 한 페이지 최대 여섯 열, 항상 보이는 좌우 버튼 및 방향키. 최초 페이지는 현재 회의를 포함한다.
- 현재: 활성 NW 회의 무대가 우선, 아니면 마지막으로 결정된 회의 다음 칸. 열 순서는 실제 11개 회의 키에 대응한다. 미래는 전체를 한 칸으로 감춘다.
- 저장: `room13['v111']['fork_run']`은 세이브에, 총 시작 횟수·결과별 최신 PNG·결말별 PNG는 persistent의 `r13_fork_runs/seen/endings`에 저장한다. 이번 경로는 항상 현재 세이브의 meeting 값을 읽는다. 불러오기/화면 열기는 회차를 늘리지 않는다. 기존 세이브의 미기록 회차 번호는 1로 표시하며 과거 횟수는 복원할 수 없다.
- 캡처: 첫 회의 결정 시 320×180 PNG. 실패한 결과도 발견으로 저장하고 해당 장소 배경을 표시한다. 과거 플레이에서 촬영하지 않은 스크린샷은 소급 복원하지 않는다.
- 공통 부품 확장: PaperPanel의 remembered 점선 옵션(기본 외형 유지), 기존 팔레트의 lock 아이콘.
- 단위: `python3 -m unittest discover -s dev -p test_fork_screen.py` 9개 통과. 전체 검사 최초 849개 중 시작 파일 줄 이동에 따른 검수표 비교 2개 실패 후 줄 이동 제거, 해당 검사 재확인(대사 18개·자료 5개 모두 통과).
- 엔진 인계: 사용자의 지시대로 Ren'Py 실행·lint·실제 캡처·모바일 검수·웹 빌드는 수행하지 않았다. `dev/run_renpy_tests.sh v111_fork_screen`으로 fork_a.png 생성 후 승인 A와 비교할 것. 특히 글자 세로 공간, 터치 탭/닫기 겹침, 실제 캡처 시점과 웹 persistent PNG 저장을 확인할 것.

커밋/푸시 없음. 승인 시안 파일은 작업 시작부터 있던 미추적 자료다.
