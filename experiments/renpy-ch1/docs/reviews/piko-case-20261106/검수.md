# 피코 사건 편집 검수 · 0.20.112

2026-11-06. 승인 범위는 3일차 피코 사건의 관찰·추론·사후 반응 연결이다. 14일 전체 소설 재집필이나 새 사건 추가가 아니다. [수정 장면 일부](../../design/piko-case-20261106/수정장면.md)를 실제 JSON/반응 함수에서 추려 두었다.

## 바뀐 흐름

1. 사망 현장을 보고 다람·그림에 관해 이야기한다. ‘아빠는 여기서 자지 마’는 밖에서 밤을 보낸 피코를 본 직후의 불안이다. 초상은 미완성 상태와 기존 소지 여부를 지킨다.
2. 공구 시연 때 바깥 걸쇠·안쪽 틈·들어 올리는 방향을 도면에 남긴다. 이전에는 이 관찰 지문이 원본에만 있고 실제 라벨에서 호출되지 않았다. 자료 설명은 관찰만 남겨 뒤 반박을 선행하지 않는다.
3. 회의에서는 실룩의 ‘걸쇠를 닫다 부러졌다’는 설명에 대해 플레이어가 확인할 축을 고른다. 칼 식별/시간 범위와 실제 사용 수단을 구별한다. 기존 증거 세 장 제출 뒤 도면에 기초해 위치 모순을 설명한다. 흠집을 안다는 말만으로 유죄를 단정하지 않는다.
4. 수리 미완료는 톡의 책임으로 남지만 절도와 구분한다. 실룩 처리 뒤 부리가 직접 소식을 듣고 현재 아이들 곁을 맡는다. 미래의 귀환 시각·급식·실제 인계는 확정하지 않는다.

## 검증한 것과 한계

전체 단위 1,324개, 최종 관련 43개, lint, 대사 A/B/C 0. [엔진 11개 사례](화면시험.json)는 새 가설 오답 2개·기존 자료 오답·재시도·정답, 부리 부재, 보고/대기소 처리, 실제 시신 조사와 저장복원, 예방 생존판, 기존 실패/부분/완승, 생존 도난 미수판을 포함한다. 새 가설은 기회를 쓰지 않고 기존 자료 오답만 1회를 쓰는 것도 검사했다.

처리 갈래 첫 테스트는 직전 돌 반환 선택을 준비 상태에 빠뜨려 다음 장면으로 잘못 진입했다. 그 상태만 보완한 뒤 두 갈래를 다시 통과했다. 제품 버그라고 보고하지 않는다. 엔진 사례는 준비한 상태에서 실제 라벨/버튼을 실행하는 회귀이며 초면 인간 재미 검증이 아니다.

[원본 보존 대조](원본보존.json): 원본 records·rules·미수판·evidence-facts·field-bindings가 동일하고 정답 조합 7개, commit 51개·선택 처리 20개·명단 호출 2개의 순서를 보존한다. 새 증거 ID·생사·사인·결말 판정은 바꾸지 않았다.
