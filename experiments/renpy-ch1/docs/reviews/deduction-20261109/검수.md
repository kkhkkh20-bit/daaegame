# 추리의 행위를 돌려주는 첫 구간 수정 — 0.20.138

사용자는 입구와 엄마 방의 도토리가 추리 퀴즈로서 맛이 없다고 지적했다. 이번 범위는 돌목의 입구와 첫 방에서2일차 초롱에게 이어지는 조사다. 별도 솜이네 골목 사건까지 검토·수정 완료한 것으로 기록하지 않는다.

## 구조와 적용

| 구간 | 기존 문제 | 변경 |
|---|---|---|
| 입구 선반 | 화면 날짜를 보며 어제/오늘/내일을 고르는 검색이 별도 퀴즈였다. | 오늘 신청서를 바로 꺼내 원본 읽기·획득으로 잇는다. 요일 메뉴의 옛 저장 진입과 재선택 라벨은 남긴다. |
| 입구 입증 | 원본을 읽으면 아빠·다람이 차이를 해설하고, 선택형 문답도 제출 조합을 미리 말했다. | 원본 사실은 그대로 보여 주고 제시 전 해설6줄을 덜었다. 제대로 제시한 뒤 누락을 설명하고 이름을 고친다. 정답 묶음·대체 묶음·기회·등록 결과는 유지한다. |
| 첫 방 | 끝부분 위치를 누르면 차이를 자동으로 설명하고 통과했다. | 현행 읽기에서는 특정 위치를 맞혀야 하는 합격 조건을 요구하지 않는다. 직접 문서를 짚는 관찰은 선택으로 남는다. 읽은 뒤 다람과 이야기한다. |
| 도토리의 의미 | 그림 없음만으로 작성자를 가를 근거는 없었다. | 관찰했다면 다른 작성자라고 단정할 수 없다고 말한다. 미관찰이면 차이를 봤다고 하지 않는다. 엄마가 보낸 편지라고 믿고 온 가족의 의문으로 잇는다. |
| 초롱에게 확인 | 두 글의 필체·발송자 문답이 한꺼번에 자동으로 흘렀다. | 두 글을 직접 제시한다. 메모는 필체와 마지막 목격을, 초대는 발송자 미확인과 우체국 장부를 확인한다. 어느 순서도 유효하다. 실제 답변 뒤에만 각 완료값을 기록한다. |

초롱이 메모는 알아보는데 가족을 부른 편지의 발송자는 모른다는 비대칭은 기존 사실이다. 새 반전이나 위조 정답을 만들지 않았다. 두 글을 확인하면 기존 교환함 경로로 이어지고, 이후 우체국에서 발송 기록을 확인하는 동선은 보존한다. 보유 문서를 자동으로 선택하거나 증거를 지급하지 않는다.

새 그림·새 사건·새 증거 ID·정답·기회·생사·결말은 바꾸지 않았다. 첫 방의 진행 중인 옛 관찰 호출은 호환을 위해 남겨 둔다. 새 읽기 모드 진입은 그 절차를 필수로 요구하지 않는다.

## 검증

관련 단위200개·생성 메타데이터36개 통과. 대사 A/B/C0건, 최종 빌드 lint와 공개 묶음 검사 통과. SDK5개 통과: 위치 퀴즈 없는 읽기, 초롱에게 초대 먼저/메모 먼저, 취소·다른 자료, 입구 실제 장부/선반 조사, 옛 요일 메뉴 복귀. 초롱 시험은 시험용 간이 자료 선택기를 실제 제품 자료함으로 바꿔 선택·닫기를 확인했다. 각 결과 파일을 보관한다.

초기 실패는2일차 준비 상태에서 누락한 실제 첫날 취침 표식, 시험용 자료 선택기와 실제 UI의 버튼 차이, 삭제한 해설을 계속 찾던 문구/그림 검사에서 발생했다. 준비 상태와 시험을 실제 바뀐 경로에 맞춘 뒤 통과했다. 빌드 임시 저장공간 부족은 이전 작업의 재생성 가능한 임시본을 정리한 뒤 해결했다.

문장 검토는 프로젝트의 slop-rewrite 가이드 없음 설정으로 수행했다. 구조 검토에서 찾은2일 첫 인사의 선행 메모 제시는 방문 목적 질문으로 바꿨다. 자동 검사 통과를 추리의 재미 보증으로 쓰지 않는다.

## 실제 웹 범위

0.20.137에서 실제 플레이로 남긴2일 아침 저장을 최종0.20.138에서 불러와, 귀환 문의→광장→등 작업 돕기→초대 편지 먼저 제시→메모 제시→교환함 이동 대기까지 실제 입력으로 진행했다. 새 게임 전체 재완주가 아니며 입구·첫 방의 새 경로는 집중 SDK 시험으로 검증했다. 불러오기 진단 명령이 제어권 전환 중 응답을 돌려주지 않아 자동화 명령 큐를 복구했다. 실제 게임의 불러온 진행은 유지했고 이야기값이나 자료를 직접 지급하지 않았다.

## 남은 한계

실무 의견으로는, 자동 해설과 형식적인 통과 절차를 줄이고 관찰을 외부 확인으로 연결했다. 입구 자체는 여전히 작은 누락 확인 튜토리얼이고, 첫 방은 미해결 단서다. 새 사건의 반전이나 다단계 범인 입증을 만든 것은 아니다. 이 변경만으로 전체 게임의 추리 재미가 완성됐다고 평가하지 않는다.
