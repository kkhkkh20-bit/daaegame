# 0.20.130 — 첫 방 조사와 클릭 반응

## 확인한 문제와 변경

| 제보 | 원인과 수정 |
|---|---|
| 클릭 반응과 마우스 오버 이름이 어색하다 | 커서를 따라다니는 큰 이름 카드를 제거했다. 물건에는 얇은 모서리 표시, 누른 자리에는 작은 원만 표시한다. 확장된 조사 범위 가장자리를 눌렀을 때 표시가 물건 중심으로 튀던 좌표도 고쳤다. 주민의 고정 이름표와 접근성 이름은 유지한다. |
| 엄마 방에서 메모를 봤는데 진행이 안 된다 | 기존에는 메모 뒤 보따리를 별도로 찾아 눌러야 했다. 책상 메모를 펼친 한 동작에서 밑의 가족 그림까지 확인하고, 이미 가진 초대 편지와 메모를 함께 펼친다. 제출 체크와 정답 판정은 자동으로 하지 않는다. |
| 도토리가 안 보인다 | 기존 원문 끝의 32px 도토리가 글 사이에서 작게 보였다. 같은 그림을 원문 아래 48px 공간에 별도로 표시한다. 초대 편지에는 끝그림이 없다는 기존 사실을 유지한다. |
| 주머니가 배경과 어울리지 않는다 | 떠 있던 별도 주머니 레이어와 그 클릭 영역을 제거했다. 배경에 이미 그려진 책상 종이를 조사 대상으로 쓴다. 가족 자료의 그림도 기존 가족 그림으로 맞춘다. |
| 다음에 뭘 해야 하는지 모르겠다 | 책상에서 읽기 → 명시 비교 → 할머니에게 초롱의 행방 묻기 → 취침 → 2일차로 이어지는 기존 목적을 한 동선에서 확인했다. |

## 검증 범위

- 관련 단위 검사 108개 통과. [출력](unit.txt).
- SDK 화면 시험 6개 통과: 첫 방 조사 범위·가족 자료 획득, 선택 없는 읽기 취소와 재개, 틀린 두 글의 기존 판정, 문서 짚기, PC·터치 두 자료 선택. [결과](native-results.json).
- 실제 입력: 같은 지점을 0.14초 안에 다시 눌러도 다른 조사가 시작되지 않았고, 커서를 새 물건으로 옮긴 경우 약 0.41초에 조사 입력이 열렸다. 새 지점 마우스 클릭 한 번, 휴대폰 실제 터치 한 번으로 메모가 열림을 확인했다. 이 수치는 해당 실행의 입력 보호 동작이며 게임 전체 성능 측정은 아니다. [입력 상태](input-results.json), [휴대폰 터치](after-touch.png).
- SDK lint: 새 구문 오류 없음. 기존 도달 불가 문장 경고는 남는다. [출력](lint.txt).
- 웹 1280×720, 844×390에서 실제 클릭과 화면을 확인했다. 첫 방 조사 직전의 상태를 준비해 메모 클릭부터 대조·취소·재개·끝그림 관찰·비교·할머니 질문·취침·지도 이동·2일차 입구 대화까지 연속으로 진행했다. 새 게임 전체 완주에 해당하지 않는다.
- 0.20.129에서 메모 뒤 보따리 대기 지점을 실제 저장하고, 0.20.130에서 불러와 가족 그림·두 글 읽기로 이어짐을 확인했다. 자료 자동 제출 없음. [상태](legacy-save.json).
- 0.20.130에서 휴대폰으로 수동 저장 → 브라우저 새로고침 → 불러오기 → 책상에서 같은 두 글 재개를 확인했다. PC 전환 뒤에도 내용과 미선택 상태가 유지됐다. [저장 결과](save-results.json). 입력 시각 기록용 임시 함수가 남은 측정 세션은 저장 검수에서 제외하고, 새로고침 후 원래 함수만 있는 세션으로 검증했다.
- 대사에 남아 있던 ‘책상 아래’와 자료 요약의 위치도 ‘메모 밑·책상’으로 맞췄다. 새로운 추리 사실을 추가하지 않는다.
- 선택형 서랍 종이는 취침 전에도 남기며, 옛 보따리 대기 라벨과 자료 ID·획득 효과는 보존한다. 숨은 종이 경로의 전체 주행은 이번 브라우저 검수에 포함하지 않는다.
- 결말·생사·정답·1부 경계는 변경하지 않는다. 전체 회귀와 14일 자연 플레이는 수행하지 않았다.

이번 수정은 첫 방과 현장 입력의 확인된 문제에 한정한다. 게임 전체의 지연 해소나 전체 조사 시스템의 완성도를 판정한 결과는 아니다.
