# 1부 주민에게 말을 걸 가치가 부족한 부분

2026-11-09. 2일차 광장 캡처에 나온 8명을 대상으로 1~7일 소스를 확인했다. 모든 날짜에 각 주민을 직접 눌러 본 플레이 검수는 아니다. 표의 145 항목은 추가 소스 연결을 뜻하며, 실제 화면 검증 결과는 root의 별도 기록을 따른다.

주민의 직업과 대화 원문이 있어도 본편 질문 목록으로 들어가는 경로가 빠진 경우가 있다. 144에서는 읽은 후속 질문의 재독과 생활 협업 2장면을 복구했다. 145 소스에는 설이·현이·여니·바둑이·부엉이의 기존 일상 대화를 추가 연결했다. 이것만으로 주민마다 도움을 청하고, 플레이어의 행동을 기억하고, 사건 뒤 달라지는 생활이 모두 구현된 것은 아니다.

설이·현이·여니는 144 시점에 `greetings.json`과 `reactions.json`의 해당 대화가 없고 본편 발화자 매핑도 빠져 있었다. 실제 일반 일상 대화는 `ROOM13.topics`에 별도로 있었으나, 본편은 현재 사건 선택지와 후속 질문만 읽었다. 이 때문에 아빠의 일반 속말로 끝날 수 있었다. 145 연결은 이 접근 문제를 고치는 범위다.

표의 이름은 설이(`resident_seol`), 현이(`resident_hyeoni`), 여니(`resident_yeoni`)로 소스에서 확인했다. 캡처의 ‘혀이’로 보이는 이름은 소스상 ‘현이’다. 부엉이 할아버지와 뿔이 촌장은 본편 발화에서 각각 ‘부엉이’, ‘촌장’으로도 표기한다.

대표 근거:

- `game/v111/newworld/reactions.json`: 현재 자료 기반 후속 질문과 날짜 조건.
- `game/v111/field-bindings.json`, `game/room13_v111_idle.rpy`: 본편 선택 질문과 인사·속말 전환.
- `game/systems/room13_v111_resident_talk.rpy`: 145의 다섯 주민 연결 목록과 안전 조건.
- `game/room13_conversations.rpy`, `game/room13-content.json`: 직업·걱정에 관한 기존 일상 원문.
- `game/systems/room13_new_cast.rpy`: 현이의 표기와 기존 노래.
- `game/assets/room13-life-groups.json`: 바느질·부품 손질의 기존 협업 원문과 시간표.
- `game/room13_v111_owl_prevent.rpy`, `game/room13_v111_days610.rpy`: 도토의 약속과 부엉이 관련 분기.
- `game/v111/newworld/d02.json`, `d03.json`, `d05.json`: 촌장의 의식 발화와 부엉이의 앞선 대화.
