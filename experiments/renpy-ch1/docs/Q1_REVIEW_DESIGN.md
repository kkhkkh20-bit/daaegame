# 첫 사건 조사·회의·실패 개선

2026-10-18 사용자 승인 기획의 구현 범위. 첫 사건 Q1에 적용한다.

## 의도

실패를 없애지 않는다. 무엇이 미입증인지 이해하고 실패한 경로로 계속하거나, 반복 피로를 줄여 다시 시도할 수 있게 한다. 회의 입장에 완전 조사 조건을 추가하지 않는다.

## 조사와 회의

- 추리 메모는 획득한 자료와 본 사건에 따라서만 질문을 생성한다. 미발견 증거 개수나 범인 이름을 미리 노출하지 않는다.
- 목표 줄에는 4일 오전~오후라는 실제 회의 시간과 조사 마감을 표시한다. 반박 가능 개수는 조사 완료율처럼 표시하지 않는다.
- 입장 전 ‘회의에 들어간다 / 조사를 더 한다’. 취소는 시간을 쓰거나 결과를 확정하지 않는다.
- 노끈 제출의 반응은 현장 물증, 소유자 연결, 조각 출처를 구분한다. 현장 끈 없이 실룩 끈만 가지고 범행을 입증하지 않는다.
- 탁본은 비교하지 않은 공구의 소유자를 증명하지 못한다. 숫자 쪽지만 제출한 아빠는 온도계 대여 사실을 말하지 않는다.
- 회의 종료 확인의 취소는 ‘회의에서 더 생각한다’. 현장으로 나간다는 오해를 없앤다.

## 실패 회고

실제로 반박한 논점 / 입증하지 못한 논점 / 톡의 결과를 남긴다. 자료를 갖고도 반박하지 못한 경우와 자료 연결이 부족한 경우를 구분한다. 전부 반박하고 결론을 확정하지 않은 경우, 기한을 놓친 경우도 별도 문장이다.

기본 회고에는 정답 자료·장소가 없다. 질문과 사고 방향은 선택해서 보고, 구체적인 장소는 한 번 더 선택해야 공개한다. 이미 끝난 회의는 다람이의 ‘광장 회의를 돌아볼까?’에서 다시 읽을 수 있다. 옛 저장도 없는 재시도 시점을 만들어내지 않는다.

## 재시도 계약

- 조사: 3일 새벽 장면 직후 저장, 4일 기록실 결과를 본 뒤 더 가까운 지점으로 갱신. 피코·사서를 살리는 선택은 이 재시도보다 앞선 일이므로 되돌려 살려 주지 않는다.
- 회의: 입장 직전. 증거·돈·시간·인물 상태·호출 스택 전체를 Ren'Py 저장으로 복원한다.
- 결과: 후일담 직후 별도 슬롯에 보관한다. 재시도 중 입장 화면에서 이전 결과를 불러올 수 있다.
- 임의의 수동/자동 저장을 덮지 않는 고유 슬롯. 회차 토큰으로 이전 결과를 구분하며 새 게임에는 해금·보상·증거가 이어지지 않는다.
- 저장 실패 시 알림을 내고, 실제로 불러올 수 있는 선택지만 제공한다. 회고/힌트는 무상태 읽기다.
- 재시도에 추가 보상을 주지 않는다. 회의 직전의 지갑을 복원하므로 성공 보상은 해당 분기에서 한 번만 얻는다.
- 기존 읽은 대사 넘기기를 사용할 수 있다. 4일 재조사는 새벽 사망 장면을 반복하지 않고 끝난 지점에서 이어진다.

## 후일담

톡 구금 / 톡 석방 및 조각 미반환 / 톡 석방 및 조각 반환의 대사를 나눈다. 범인을 못 밝힌 아빠는 실룩을 범인으로 단정하지 않는다. 피코와 사서의 생사, 이후 톡 증언 조건은 유지한다.
