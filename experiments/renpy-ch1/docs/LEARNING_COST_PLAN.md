# 세계관 학습 비용 개선 — 0.17.9

## 목적

눈에 갇힌 마을에서 딸과 아내의 행적을 추적하는 생활 추리게임이다.
관찰 → 질문 → 읽고 기록 → 비교/보여주기 → 새로운 의문을 반복한다.
각 설정은 다음 행동의 이유 또는 마을에서 살아가는 느낌을 돌려주어야 한다.
이 문서는 기획 의도와 이번 구현 범위를 구분한다. 재미가 검증됐다는 보고서가 아니다.

## 학습 순서

| 시점 | 플레이어의 의문 | 처음 배우는 것 | 곧바로 사용하는 곳 |
|---|---|---|---|
| 마차 도착 | 엄마는 어디에 있나? | 편지가 가족을 불렀음, 마차 축에 문제가 있음 | 경비에게 방문 이유 설명 |
| 초소 | 왜 아빠 한 명으로 적혔나? | 원본과 옮긴 기록은 다를 수 있음 | 두 종이를 읽고 다람이와 비교, 경비에게 제시 |
| 광장→여관 | 편지를 보낸 사람은 무엇을 아나? | 주민의 역할, 말을 걸지 직접 선택 | 할머니의 첫 인사와 질문 |
| 13호실 | 엄마가 남긴 것이 있나? | 확대 조사, 읽은 후 획득, 기록의 출처 | 메모와 바느질 관찰, 다람이와 정리 |
| 첫날 밤 | 내일 누구부터 만나나? | 모르는 것과 아는 것의 구분, 잠자기가 날짜를 바꿈 | 알려진 단서에 따른 부녀 대화, 직접 자기 |
| 둘째 날 | 돌아갈 수 있나? 어떻게 머무나? | 정기 마차 운행 제한, 한나절 노동과 숙식 정산 | 까로 질문, 일 선택 전에 시간·정산 확인 |
| 수소문 | 누가 엄마를 직접 봤나? | 직접 본 방향과 확인된 방문의 차이 | 초롱·세련의 후속 질문과 기록 비교 |
| 사건 이후 | 그 주장이 사실인가? | 자료의 범위, 증언자의 허락, 실제 작동 확인 | 해당 주장에 자료로 반박 |
| 후반 | 다른 생존 방법이 있나? | 남은 힘, 이동·소모·손실, 환자의 회복 | 관찰 자료와 주장을 연결 |

다람이의 추리를 건너뛰거나 자동으로 여관/객실로 이동하지 않는다.
처음 만난 주민은 활동 관찰 → 부녀 반응 → 말을 걸지 선택 → 인사 → 질문을 유지한다.
숨은 통로의 초회차/재플레이 해금은 기존 규칙을 유지한다.

## 이번에 구현한 조치

1. 인물의 선택 화면과 인물 기록에 이름·공개 역할을 함께 쓴다.
   - 예: 까로 · 마부 / 초롱 · 등불 돌보기 / 나비 · 여관 식사 준비.
   - 역할은 공개 행동만 담는다. 내부 프로필의 ‘비밀 식량 전달’ 등은 사용하지 않는다.
   - 현장 이름표는 기존 크기를 유지하고 툴팁에 역할을 넣는다.
2. 질문/자료 보여주기/일반 이동에는 시간 소모가 없음을 짧게 표시한다.
   - 시간을 쓰는 활동에는 한나절과 도착할 시간대를 표시한다.
   - 무료 탈출 선택은 ‘이번 여정이 끝날 수 있음’을 별도로 쓴다.
   - 모든 시간 결과를 하나의 함수에서 만든다. 실제 비용은 기존 활동 규칙을 따른다.
3. 일 선택 전에 임금·한나절·밤 정산을 표시한다.
   - 지금 돈과 기본 일당을 기준으로 납부/남는 돈/새 외상을 예상한다.
   - 이미 알아낸 후속 질문과 묶음 배달 방법만 표시한다. 모르는 보상을 정답처럼 나열하지 않는다.
   - 묶음 배달은 일 도중 10냥 선택지가 따로 표시된다. 사전 기본 일당 예상은 5냥이다.
   - 임금, 숙식비, 외상, 일자리 해금/주민 부재 규칙은 변경하지 않는다.
4. 잠자기 확인에 다음 날 전환과 예상 정산을 넣는다.
   - 낮에 자면 남은 낮 시간을 사용하지 않음을 알린다.
   - 4일째 기존 저녁 사건 경로는 ‘저녁을 맞는다’고 표시해 다음 날로 건너뛴다고 약속하지 않는다.
   - 부족액은 외상이며 잠을 막지 않는다. 기존 정산 완료일은 두 번 청구하지 않는다.
5. 기록의 탭은 ‘찾은 것 / 들은 말 / 인물 / 대화’로 정리한다.
   - 물건·문서·관찰기록의 내부 분류는 유지한다.
   - 자료 상세에 직접 조사/발언자/증언 사용 허락 상태를 표시한다.
   - ‘관찰 메모’와 ‘추리 메모’ 진입점을 ‘조사 메모’ 하나로 합친다.
   - 조사 메모에서 ‘지금 궁금한 것 / 자세히 본 것 / 알게 된 세계’를 읽는다.
   - 알려진 사실과 모르는 것을 분리하고, 행동 힌트는 눌러 펼친다.
6. ‘지난 플레이’는 이전 기록이 있을 때만 표시한다.
   - 새 게임 시작 시 이전에 모은 기록을 저장 상태 안에 별도로 기억한다.
   - 첫 플레이에서 지금 모은 자료를 과거 플레이 자료로 표시하지 않는다.
   - 과거 자료는 현재 인벤토리에 추가되거나 제시 가능해지지 않는다.
   - 이전 저장은 기존 정보에서 현재 소유하지 않은 자료만 읽기 전용으로 표시한다.
7. 세계 설명은 현재 여정에서 관련 자료를 얻은 뒤에만 선택해서 읽는다.
   - 힘이 줄어드는 기록 → 돌에 남은 힘.
   - 실제 힘을 옮긴 기록 → 총량이 늘지 않음.
   - 저녁 관찰 → 소모량과 지속 시간.
   - 회복 관찰 → ‘야생화’와 일부 회복의 범위.
   - 추출 시설 원본 → 희생의 의미.
   - 엄마의 연구 → 룬을 옛 문자와 병기.
   - 메뉴 열기는 새로운 증거·깃발·시간·정답을 지급하지 않는다.
8. 회의의 여론 숫자 대신 ‘참석자 반응 · 결정은 확인한 근거로’를 쓴다.
   - 자리와 반응 색은 유지한다. 표를 모으면 판결이 바뀐다는 잘못된 기대를 줄인다.
   - 실제 판결은 기존 논점 입증 규칙 그대로다.
9. 마차 운행 불가와 이후 다른 길 조사 사이의 범위를 명시한다.
   - 까로가 모는 정기 마차/고개 운행에 대한 설명이다.
   - 다른 길 사정은 지금 조사해야 하며 안전하다고 미리 알려주지 않는다.
10. 가족 편지와 메모의 연결은 재회 대화에서 확인한다.
    - 초반 할머니의 설명은 할머니의 주장이다.
    - 엄마는 가족에게 연락한다는 말을 듣고 도착할 경우를 위한 메모를 남겼다.
    - 실제 편지의 내용은 재회 때 읽으며, 할머니가 숨긴 정보와 유인 의도는 기존 반전으로 남긴다.
    - 엄마가 초대 편지를 썼거나 위조했다는 설정을 새로 추가하지 않는다.
    - 0.18.56 소유자 결정: 가족은 엄마가 보낸 편지인 줄 알고 온다. 실제로는 할머니가 엄마 이름으로 쓴 편지다(도토리 표시가 없음). 여관에서는 '엄마가 며칠째 안 보인다'고 듣는다. 엄마가 쓴 경고(E18)는 '오라는 편지를 쓴 적 없다'고 말한다.

## 보존할 것

중앙 상대 이미지, 읽은 질문 재방문, 인물 접근 선택, 제시 후 후속 질문을 읽어야 기록되는 경계,
손으로 조사하는 확대 화면, 드래그 지도, 첫날 숙식 무료, 낮 두 번 노동, 명시적 잠자기,
0.17.8 넓어진 생활 공간과 입구 파노라마·저장 페이지·회의 자리 및 발언 선택, 기존 공개 회의와 캠페인 결말.
기존 화면 이름과 대사 복귀 라벨은 저장 호환을 위해 삭제하지 않는다.
새 모듈은 읽기 정책과 선택 UI를 담당하며 기존 경제/조사 모듈의 상태 전이는 유지한다.

## 다음 플레이 테스트

5명에게 첫날과 둘째 날 일부를 직접 플레이하게 한다. 답을 알려주지 않는다.

- 첫날 종료 후: 알아낸 것 / 아직 모르는 것 / 다음에 보여줄 자료와 상대를 말하게 한다.
- 일 선택 직전: 고른 이유, 시간이 얼마나 흐르는지, 오늘 밤 돈이 모자라면 어떻게 되는지 묻는다.
- 증언 제시 직전: 직접 본 것과 들은 것의 차이를 설명할 수 있는지 본다.
- 후반 자료: 옮긴 힘의 총량이 늘었는지, 낮 결과만으로 밤을 보장할 수 있는지 묻는다.
- 기록 탐색: 이미 획득한 자료를 다시 찾는 시간과 ‘지난 플레이’ 오제시 시도를 기록한다.

목표: 5명 중 4명이 초반 세 질문과 시간/외상 규칙을 도움 없이 설명한다.
‘모두 클릭해 봤다’만 나오면 새로운 설정 추가보다 단서→질문 연결을 수정한다.
테스트 결과가 없으므로 재미나 이해도 개선을 확정적으로 주장하지 않는다.

## 후속 기획 — 이번에는 적용하지 않은 것

- 14일 전체 일감·임금·외상·사건 일정 밸런스: 하루별 자연 플레이 후 조정.
- 질문 선택의 손익이나 정보 경로 배타성: 현재 항상 질문하는 선택이 유리하므로 별도 재미 검증.
- 주민 일정 예고: 약속·직접 들은 일정만 기록하는 방향으로 설계. 전 주민 위치를 처음부터 공개하지 않음.
- 여론을 판결에 반영하는 규칙: 추리의 근거와 인기 투표가 혼동되지 않게 별도 검토.
- 새 종족 능력, 룬 해독 퍼즐, 세계 백과사전, 새 아트: 이번 학습 개선에 필요하지 않음.
