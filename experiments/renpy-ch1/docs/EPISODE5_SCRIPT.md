## 한눈에 — 무슨 일이 있었나 (정답)

1. 엄마는 숲 뿌리 밑에 숨어 있다가, 들킨 걸 알고 **폐온실 아래**로 옮겼다. 할머니는 손녀 **토실**에게 아빠 뒤를 밟게 했다.
2. 여관 아래 **옛 시설**의 유리관에는 아직 식지 않은 돌 조각이 남아 있다. 조각을 모아 광장의 큰 돌을 데우면 **사람을 바치지 않아도 된다.** 다만 준비에 꼬박 하루가 걸린다.
3. 11일 밤, 돌이 크게 식는 **긴 밤**. 아랫길 천막의 등록 안 된 사람들이 서로 기대 앉은 채 얼어 죽는다.
4. 대피소의 **사자 선생님**은 대피 명단에서 표 없는 아이들 이름이 빠진 걸 보고 믿었다. "이 아이들은 얼어 죽거나, 수레에 실려 간다."
5. 12일 저녁, 선생님은 진료소에서 훔친 **잠드는 약**을 **아이들 냄비**에만 넣었다. 아이들과 수프 노래를 부르면서. 아이 넷이 깨어나지 않는다. 수프를 남긴 새미만 산다.
6. 그날 밤, 엄마의 방법이 통해 광장 등이 밝아진다. **구원은 몇 시간 늦게 왔다.** 선생님이 틀렸다는 걸 증명하는 건 그 늦은 불빛뿐이다.

## 0. 그림책 — 잠자는 숲속의 공주 (10일 밤, 임시 객실)

- ④의 「10일 밤 — 그림책」(빨간 모자의 바뀐 문장)을 덮은 뒤, 다람이 다음 책을 꺼낸다.

```
다람: 아빠, 이거 읽어 줘. 갇혀 있을 때 맨날 생각했어. 나가면 아빠가 읽어 줄 거라고.
(그림책) 공주는 물레 바늘에 찔려 깊은 잠에 빠졌어요.
(그림책) 성 안의 사람들도 모두 함께 잠들었어요. 가시덤불이 성을 감쌌어요.
(그림책) 백 년이 지나, 왕자가 와서 공주를 깨웠어요.
다람: 다 같이 자면 안 무섭겠다. 그치?
아빠: ……그런가.
다람: 근데 왕자가 안 오면 어떡해?
아빠: 오지. 동화니까.
```
- (다람이 갇혀 있다면) 아빠가 보호실 창문 아래에서 소리 내어 읽는다. 창살 너머로 다람 "……왕자가 안 오면 어떡해?"

```
(지문) 창살 사이로 작은 손이 나왔다. 아빠가 그 손을 잡았다.
```

```
(지문) 종이에는 아내의 글씨로 짧게. 「여기는 들켰다」.
아빠(생각): 들켰다. 누군가 이 굴을 찾아냈다. 아내는 더 깊은 데로 옮겼다.
```

## 10일 저녁 — 폐온실 길, 작은 발소리 ⏱

```
(지문) 폐온실로 가는 숲길. 눈 밟는 소리가 하나 더 있었다. 멈추면 그것도 멈췄다.
다람: (작게) 아빠. 누가 따라와.
아빠: 거기 누구야. 나와.
(지문) 나무 뒤에서 작은 아이가 나왔다. 털모자를 눈썹까지 눌러쓴 토실이었다.
토실: ……미안해. 미안해, 다람아.
```
**토실의 고백**
```
토실: 할머니가…… 아저씨 따라가 보라고 했어. 어디 가는지만 보고 오라고.
다람: 왜? 우리 엄마 찾는 건데 왜?
토실: 몰라. 할머니가 무서워. 할머니 눈이 요즘 이상해.
토실: ……근데, 그거 알아? 할머니가 우리 엄마도 보호소에 보냈어.
토실: 우리 엄마는 산 너머에서 일한다고 했는데, 아니야. 보호소에 갔대. 나 문 뒤에서 들었어.
토실: 우리 엄마는 안 돌아왔어.
(침묵)
다람: ……우리 엄마는 찾을 거야. 너도 같이 가.
```
`[단서] 토실의 말`
- (④에서 할머니를 붙잡아 두었다면) 토실 "할머니가 갇히기 전에 시킨 거야. 안 하면 혼날 것 같아서……. 이제 혼낼 사람도 없는데." 같은 단서.

- `▶ 토실을 감싼다: "같이 가자. 할머니한테는 길을 잃었다고 하자."` → 토실이 아빠 소매를 잡는다. (결과 정리: 제단 뒤 토실 엄마 이름 적기)
- `▶ 토실을 여관으로 돌려보낸다` → 토실 "……응." 밤에 할머니가 폐온실 쪽 길을 안다. 12일 낮 폐온실 문이 부서져 있다(엄마는 이미 옛 시설로 옮겨 있어 무사. 찝찝함).
- `▶ 토실에게 묻는다: "네 엄마 이름은?"` → 토실 "……나도 잘 몰라. 할머니가 엄마 이름 말하면 화내." (⑥ 명단 원본으로 이어지는 떡밥)

## 11일 새벽 — 폐온실, 재회

```

(지문) 바닥 판자 하나가 들려 있었다. 그 아래에서 등잔 불빛.
(지문) 누군가 사다리를 올라왔다. 목도리에 반쯤 가린 얼굴. 코를 찡그렸다. 눈부셔서.

(지문) 다람이 달렸다. 눈 위에서 한 번 미끄러지고, 그대로 엄마 품으로.

다람: 엄마 왜 안 왔어! 왜 편지만 썼어! 나 엄청, 엄청 기다렸어!

엄마: ……응. 그래도 왔어야 했어.
(침묵)
엄마: (아빠를 보며) 당신도. 미안해. 그 편지, 내가 쓴 게 아니야.
```

  ```
  (지문) 선생님이 냄비를 비웠다. 아이들 옆에 눕고, 담요를 끌어 덮었다.
  사자 선생님: 깜이, 몽이, 방울, 도담. 선생님 왔어요.
  (침묵)
  (지문) 머리맡에 출석부가 남았다. 다섯째 줄, 새미의 이름에만 동그라미가 없었다.
  ```
  → 선생님이 죽는다. 이름 판에 다섯 이름이 한꺼번에 오른다.

## 12일 밤 늦게 — 임시 객실, 남은 것들

**위로 — 엄마와 초상** (①에서 피코가 죽고 다람이 코를 그려 넣었다면)
```
(지문) 다람이 판자 하나를 엄마 앞에 내밀었다. 엄마 얼굴. 코만 크레용으로 삐뚤빼뚤.
다람: 그림쟁이 아저씨가 그린 거야. 코는 내가 그렸어. 아저씨가 못 그려서. 약속했거든.
엄마: (판자를 받아 들고, 한참 보다가) ……코를, 찡그렸네.
다람: 엄마 웃을 때 그렇게 하잖아.
(지문) 엄마가 판자를 끌어안고 울었다. 웃으면서. 코를 찡그리며.
```
- (피코가 살았다면) 피코가 진료소에서 마무리한 초상을 직접 건넨다. 피코 "코, 다람이가 알려 준 대로 그렸어요."

**위로 — 보리**
- (엄마가 깜이·몽이·방울을 깨운 경로, 또는 ③에서 보리를 지켰고 그 아이들이 살았다)
  ```
  (지문) 보리가 대피소 구석에 앉아 있었다. 무릎에 깜이, 양옆에 몽이와 방울이 잠들어 있었다.
  보리: 내 애 하나 잃고…… 셋 얻었다.
  보리: (화상 자국이 있는 손으로 깜이 머리를 쓸며) 이번엔 안 놓친다.
  ```
- (넷 다 잃은 경로)
  ```
  (지문) 보리는 아무 말도 하지 않았다. 도담의 작은 신발 한 짝을 손에 쥐고, 밤새 난로 옆에 앉아 있었다.
  아빠(생각): 그날부터 보리는 말을 잃었다.
  ```

**위로 — 새미의 노래** (어느 경로든)
```
(지문) 모두 잠든 밤. 교실 구석에서 작은 목소리.
새미: (노래) 휘휘 저어라 겨울 수프, 감자 하나 당근 하나.
새미: (노래) 다 같이 먹으면 따뜻해……
(지문) 노래가 거기서 멈췄다. 한참 뒤에, 아주 작게.
새미: (노래) ……내일도 같이 먹자.
```
- (선생님을 막았다면) 다음 날부터 선생님이 새미 하나에게 글을 가르친다. 결말에서 새미가 이름 판 앞에서 이 노래를 끝까지 혼자 부른다.

## 결과 정리

**수프 — 누가 사나**

| 조건 | 결과 |
|---|---|
| 아무것도 못 했다(⑤를 고르지 않음 포함) | 깜이·몽이·방울·도담이 깨어나지 않는다. 새미만 산다. 엄마와의 재회는 12일 밤으로 늦어진다 |
| 엄마와 재회했지만 설득은 못 했다 | 엄마가 약을 알아보고 조각으로 아이들을 데운다. 깜이·몽이·방울이 깨어난다. **도담만** 죽는다 |
| 설득 성공(엄마 + 두 증거), 약장은 열려 있었다 | 선생님이 냄비를 쏟는다. 아무도 안 죽는다. 도담이 이틀 앓는다 |
| 설득 성공 + 서리가 약장을 잠갔다(①) | 약이 선생님 손에 들어가지 않는다. 아무도 잠들지 않는다. **완벽한 길** |
| 서리가 약장을 잠갔지만 설득은 못 했다 | 선생님이 약장 유리를 깨고 꺼낸다. 비극은 그대로. 회의에서 깨진 유리와 선생님 손의 베인 자국이 더해진다 |

**긴 밤 — 아랫길**

| 조건 | 결과 |
|---|---|
| 아무것도 안 했다 | 네로와 천막 사람 다섯이 죽는다. 이름 판에 '아랫길 사람들 (이름 모름)' |
| ① 창고 조각 나눔 / ③ 장작 나눔 | 그만큼 덜 죽는다(둘 / 하나~둘) |
| ② 네로를 만났다 + 11일 오후 네로와 선생님을 움직였다 | 대부분 학교로. 네로와 노부부만 남는다 |
| 위의 셋 모두 | 노부부 둘만 죽는다(최소). 네로가 살아 ⑥에서 수레 길을 알려 준다 |
| 네로의 이름표가 있다 | 다람이 천막 사람들 이름을 이름 판에 옮겨 적는다 |

**그 밖**

| 결과 | 다음에 |
|---|---|
| 엄마와 재회했다 | ⑥ 회의에서 엄마가 말한다. 제단에서 엄마의 방법을 고를 수 있다 |
| 옛 시설 실험을 했다 | ⑥ 촌장의 "돌은 희생으로만 버틴다"를 「밝아진 등」으로 깬다 |
| 토실을 감쌌다 | 제단 뒤, 다람과 토실이 이름 판에 토실 엄마 이름을 같이 적는다 |
| 토실을 여관으로 돌려보냈다 | 할머니가 폐온실을 찾아낸다. ⑥에서 할머니가 한 걸음 앞서 있다 |
| 수레의 진실을 대피소에 밝혔다 | ⑥에서 주민들이 수레 앞을 막아선다 |
| 선생님을 너울에게 넘겼다 | 선생님이 수레에 실린다. ⑥에서 수레를 멈추면 선생님도 산다 |
| 선생님을 막았다 | 선생님이 새미에게 끝까지 글을 가르친다. 결말에서 새미가 수프 노래를 혼자 부른다 |
| 선생님을 막지 않았다 | 이름 판에 다섯 이름. 출석부는 다람이 갖는다. 결말에서 다람이 출석부의 이름을 부른다 |
| 솜이를 옛 시설에 데려갔다 | 솜이가 할아버지 목소리를 듣는다(설명하지 않음) |
| 피코의 초상이 있다 | 엄마가 초상을 안고 운다. 결말에서 초상이 이름 판 옆에 걸린다 |
| 마을 | 대피소에 빈 그릇이 남는다(죽은 수만큼). 보리가 말을 잃거나(넷 다 잃음), 아이 셋을 거둔다 |
