# 자료 정체성과 수첩 폴더

현재 등록된 관찰 fact ID는 59개다. 이것은 물증 59개를 수집한다는 뜻이 아니다. UI는 이를 26명 인물 프로필, 16개 물건 묶음, 3개 현장으로 묶는다. 동일 인물/물건의 다른 날짜 관찰은 새 카드 복제품이 아니라 해당 프로필의 이력이다. 사실 ID는 회의의 입증 범위를 구분하기 위해 내부적으로 유지한다.

물건 묶음 16개: 방문 신청 원본, 초소의 방문 목록, 관측 장부, 엄마 연구 원본, 피코의 초상, 광장 3번 등, 17번 돌, 배식 용기와 천, 수레와 담요·두 고정끈, 빨래터 통과 주둥이 조각, 벌림 도구, 13호 개폐 장치, 두 냄비와 뚜껑, 반출 약통, 배분판, 출발 명단.

일상적 개별 부품까지 세면 이 16묶음은 적어도 23개 구성물에 해당한다. 예: 냄비2+뚜껑2=4, 수레+담요+끈2=4, 용기+천=2. 개폐장치의 판자/레버 같은 구조 부품까지 모두 세면 더 늘어난다. 따라서 '물증이 16개뿐'이라는 수치로 축소해 표현하지 않는다. 모든 것이 휴대 수집품도 아니다. 등·수레·개폐 장치·배분판은 현장에서 확인하는 고정 대상이다.

현장 3개: 장부에 나온 방, 장작창고, 학교의 실제 자리. 인물 발언을 위해 가짜 증언 종이 아이콘을 새로 만들지 않는다.

수첩 및 회의는 메인/사건1~6 폴더와 자료·현장/인물 탭을 사용한다. 현재 사건이 기본 열림이다. 다른 폴더와 관련 과거 사실은 직접 접근 가능하며 오답 후보도 숨기지 않는다. 같은 인물이 현재 폴더에 등장하면, 프로필 안에서 이미 획득한 다른 회차의 사실도 연결된다. 아직 획득하지 않은 사실은 보이지 않는다.

실물 그림은 별도 registry로 연결한다. 등록 키/종류/중복은 test_recommended_catalog.py에서 검사한다. native UI 실행과 실제 해상도 시각 검수는 아직 진행 전이다.
