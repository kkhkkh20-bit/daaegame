연결할 때 반드시 지킬 것
1. 원본 ui-button-states는 덮어쓰지 말고 새 폴더로 추가한다.
2. button.standard와 button.primary는 질문/지도뿐 아니라 메인·현장에서도 공유한다. 전역 역할에 곧바로 일괄 연결하면 보호 대상 화면도 바뀐다. 이번 허용 대상은 질문창 도구와 지도 하단 버튼이다. 적용 담당자는 공유 소비자 영향을 먼저 확인하고 범위를 제한할 수 있을 때만 연결한다.
3. 현행 역할은 Frame 금지다. 임의 9-slice/가로세로 개별 늘림이나 crop 추가를 하지 않는다. 실제 표시 크기·균일 배율은 기존 화면에서 확인한다.
4. hover는 기존 fallback basic을 따른다. 기본/누름/선택/비활성 네 상태를 모두 연결한다.
5. 일반 버튼의 선택 상태는 옅은 청색이므로 기존 짙은 글씨를 유지한다. 주요 버튼은 기존 밝은 글씨를 유지한다. 비활성 상태의 기존 입력 금지도 유지한다.
6. scan → validate → 4상태 실제 화면 캡처 → 이전/현재 비교. PC/모바일, 긴 글자·아이콘·터치영역·선택/비활성 구분을 검수한다.
7. 기존 레이아웃·대사·분기·판정·표정·클릭 영역은 수정하지 않는다. 얼굴 아이콘은 제작하지 않았다. 조사 캐릭터의 도트/스티커 방향도 변경하지 않았다.
