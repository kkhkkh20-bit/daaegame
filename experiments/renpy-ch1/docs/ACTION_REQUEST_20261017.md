# 동작 요청서 — 장소별 인물 배치·원근 (2026-10-17)

- 소유자 요청(2026-10-17): 장사하는 주민은 매대 뒤, 우체국 직원은 창구 뒤. 원근에 맞춰 멀면 작게, 가까우면 크게. "이 맵에 누가 이 동작으로" 요청서를 만들어 GPT로 그림을 받는다.
- **시안 단계다.** 게임 파일은 아직 고치지 않았다. 시안 그림: `docs/placement_mockups/<장소>.png` (21장), 다시 만들기: `python3 docs/placement_mockups/make_mockups.py`.
- 시안 그림 읽는 법: 이름표 금색 = 매대·창구·책상 뒤(하반신 가림), 하늘색 = 제자리 작업, 연두 = 앉음, 흰색 = 손님. **주황 점선 + "새 동작 XX-n"** = 지금은 기존 그림을 임시로 둔 자리, 아래 표의 그림이 필요하다. 왼쪽 빨간 막대 3개 = 발 y 520/610/700에서의 어른 키.
- 한 장에 그 장소의 일정상 인물을 **모두** 지정 자리에 세웠다(실제로 동시에 다 있지는 않다. 최대 동시 인원: 장터 8, 광장 8, 창고 8, 수리점 9, 우체국 6, 여관 6, 식당 6, 입구 6).

## 0. GPT에 넣을 공통 지시문 (모든 요청 앞에 그대로 붙인다)

```
[스타일 고정 — 반드시 지킬 것]
1. 첨부한 "기존 인물 그림"과 같은 캐릭터다. 얼굴·털색·무늬·옷 색·소품은 그대로 두고 자세만 바꾼다. 새 옷, 새 소품, 새 색을 더하지 않는다(요청에 적힌 손 소품만 예외).
2. 기존 시트와 같은 픽셀 아트: 같은 픽셀 크기(도트 한 칸 크기), 같은 진한 갈색/검정 1px 외곽선, 같은 팔레트와 명암 단계(셀 셰이딩 2~3단), 안티앨리어싱·흐림·그라데이션·광택 없음.
3. 배경은 완전 투명(PNG 알파). 바닥 그림자, 바닥 타일, 배경 소품을 그리지 않는다(매대·책상은 게임 배경에 이미 있다).
4. 캔버스: 세로 768px, 인물 한 명. 서 있는 자세는 머리 꼭대기~발바닥이 기존 그림과 같은 비율(머리:몸 = 기존 neutral 그림과 동일). 위아래 여백 4px 이내.
5. 발 기준선: 서 있는 그림은 두 발바닥이 캔버스 맨 아래에서 4px 위 한 줄에 닿는다. 상반신만 보이는 "매대 뒤" 그림도 다리까지 다 그린다(게임에서 매대가 가린다). 앉은 그림은 의자/통을 함께 그리고 의자 다리 끝이 그 기준선에 닿는다.
6. 방향: 별도 표시가 없으면 3/4 정면(몸은 화면 쪽, 얼굴은 살짝 옆). 손님 쪽(화면 아래)을 본다.
7. 결과는 그림 1장 = 동작 1개. 파일 이름: room13-action-<인물id>-<동작id>.png
```

## 1. 깊이(원근) 규칙

모든 장소에 같은 식을 쓴다. 발 y(화면 720 높이 기준)에서 **서 있는 어른 키**

`h(y) = H700 × (y − yv) / (700 − yv)`

- `yv` = 키가 0이 되는 가상의 높이(바닥이 멀어지는 정도), `H700` = 화면 아래쪽(y=700) 어른 키.
- 인물 키 = h(y) × 체격: 아이 0.76, 청소년 0.90, 어른 1.00, 노년 0.95 (보리 1.06, 톡·사자 선생님 1.04, 뭉치 0.96).
- 앉음·웅크림 그림은 지금 게임과 같이 `stature_ratio`(있으면) 또는 머리 크기 기준으로 줄인다.

## 4. 구현할 때 바꿀 데이터 (승인 뒤, `game/assets/room13-world-layout.json`)
- `perspective`: 위 표의 규칙을 `[a, b]`(h = a·y + b, a = H700/(700−yv), b = −a·yv)로 모든 장소에 넣는다. 지금은 wide 장소만 있고 inn·school·workshop·square·gate·clinic·store·greenhouse·facility·altar는 없다(각 slot의 세 번째 값이 손으로 정한 키라 장소 안에서 원근이 들쭉날쭉, clinic은 앞뒤가 거꾸로).
- `slots`의 세 번째 값(키)을 perspective로 다시 계산하거나, 코드에서 slot 키 대신 perspective를 쓰게 한다(`r13_stage_people`의 `floors[index]` → `display_height`).
- 매대·창구 뒤 자리: `positions`(인물별 고정 자리 [x, 발y, 키]) + 새 칸(예: `staff_occlusion: {인물: 다각형}`)이 필요하다. 지금 `occlusion`은 장소 하나에 하나뿐이고 손 위치(`work`)+`hand`가 있는 포즈에만 적용된다. 시안의 가림 다각형 좌표는 `make_mockups.py`의 `OCC`에 있다(장터 4개, 우체국·여관·창고·광장·수리점·진료실·학교·접견실·식당·주방).
- `market.occlusion`, `post.occlusion`이 지금 비어 있다 → 위 다각형을 넣는다. `post`의 `slots`는 전부 창구 앞 "waiting"이라 창구 뒤 자리(세련 (1270,503), 슬링 (1460,499))를 추가해야 한다. 코드의 `if location=="post" and person!="seryeon":pose="neutral"` 규칙도 슬링은 예외로 바꾼다.
- `poses`/`slot_actions`: 새 그림이 들어오면 인물별 포즈 이름을 지정(예: market `resident_eunho: "stall_prices"`). `room13-pixel-acting.json`에 새 포즈 항목(file, crop, foot, head, contact `"behind_counter"`, `stature_ratio`)을 추가하고 `R13_LIVING_ALLOWED`에 장소를 더한다.
- `capacity`: 장터 4 → 8, 우체국 6 유지 + 창구 뒤 2.
- 진료실 `floors`의 키(262/244/234)는 앞쪽이 더 작게 적혀 있어 규칙과 반대다.
