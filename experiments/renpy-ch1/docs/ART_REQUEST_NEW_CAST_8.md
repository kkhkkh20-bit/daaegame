## 공통 규격 (기존 주민과 같게)

- 그림체: 기존 주민과 같은 동물 의인화 픽셀아트, 겨울옷.
  - 참조 파일: `game/assets/room13-fullbody-daram-*.webp`, `room13-fullbody-*-neutral.webp`
- 대화용 전신 6장: neutral, joy, anxious, surprise, angry, flustered.
  - 기존 전신 파일과 같은 캔버스 크기, 같은 발 위치, 같은 머리 높이 비율.
  - 파일 이름: `room13-fullbody-<코드>-<표정>.png`
- 눈 깜빡임: 표정마다 반쯤 감은 눈(half)과 감은 눈(closed). 같은 캔버스에 눈만 바뀐다.
- 현장용 서 있는 자세 1장과, 아래 표의 활동 자세 1~2장. 투명 배경, 발이 바닥에 닿은 전신.
- 얼굴 아이콘 1장(정사각형, 대화 기록과 이름표용).
- 넣지 않는 것: 글자, UI, 다른 캐릭터, 배경.
