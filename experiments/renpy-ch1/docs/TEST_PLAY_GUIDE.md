# 테스트 플레이 안내 (0.18.22)

소유자가 직접 확인할 때 쓰는 안내. 재미 검증 문서가 아니다.

## 1. 관리자 도구

**켜는 법** (둘 중 하나)

- 주소 뒤에 `?admin=1`을 붙여 연다. 예: `.../preview/room13-dev/?admin=1`
- 게임 필드 화면에서 `Shift + A`를 누른다. 다시 누르면 꺼진다.

켜면 필드 위쪽 가운데에 빨간 **관리자** 버튼이 생긴다. 일반 플레이어 화면에는 보이지 않는다.

**탭별 기능**

| 탭 | 하는 일 |
|---|---|
| 다음 진행 조건 | 오늘 진행에 필요한 것(완료/필요), 잘 수 있는지와 그 이유, 이 방에서 누를 수 있는 것과 아직 안 본 것, 이곳 사람과 활동, 일반 사건 표시, 돈·물건·자료 |
| 이동·시점 | 시작 지점 6곳(새 회차 상태로), 하루 앞/뒤, 아침·오후·저녁, 장소 바로 이동(조건 무시) |
| 돈·물건·자료 | 돈 +10/+50, 일자리 열기, 상점·대여 물건 받기, 자료(증거) 하나씩 받기 |
| 클릭 영역 보기 | 방 안에서 누를 수 있는 모든 물건을 빨간 테두리와 이름으로 표시 |

**주의**

- 이동·시점과 자료 받기는 정상 진행을 건너뛴다. 이후 대사나 분기가 실제 플레이와 다를 수 있다.
- 버그를 재현할 때는 "어느 버튼으로 왔는지"를 같이 알려 주면 된다.

## 2. 첫날 (1일째)

1. **마을 입구**
   - 돌목에게 "신청한 것과 이름 목록이 다른 이유"를 물으면 그가 명단을 보여 준다(G3).
   - 초소 선반의 서류 묶음을 누르면 우리 예약 원본(G1)이 나온다.
   - 까로나 다람이에게 묻거나, 원본을 돌목에게 보여 주면 동행 등록이 바로잡힌다.
2. **광장 → 여관**: 할머니에게 말을 걸어 방을 부탁하면 13호를 받는다.
3. **13호실**
   - **책상 위 접힌 종이**를 누른다. 찻잔 왼쪽에 있는 흰 종이다. 엄마의 메모(M01)를 얻는다.
   - **침대(이불)**를 누른다. 붉은 매듭을 보고 엄마의 바느질(E03)을 얻는다.
   - 둘 다 끝나면 침대를 누르거나 오른쪽 아래 **자기** 버튼을 눌러 잔다. 둘 중 하나가 빠졌으면 침대 메뉴에 무엇이 남았는지 나온다.
4. 선택: 메모를 할머니에게 보여 주면 '등불을 돌보는 사람'이 초롱이라는 것을 알게 된다.

## 3. 둘째 날 이후 (요약)

| 날 | 할 수 있는 것 |
|---|---|
| 2일 | 까로가 일자리(배달·주방·수리)를 제안한다. 메모를 초롱에게 보여 주면 J02, 우체국 세련에게 J02와 가족 자료를 보여 주면 J03을 얻는다. 여관 현관 문틈(낮, 할머니가 있을 때)도 2일째부터 열린다. |
| 3~4일 | 일반 사건이 장소에 '!' 표시로 뜬다. 눌러야 들어가고, 지나치면 결과만 나중에 듣는다. 부엉이 할아버지 장면, 저울·탁본·손등불 같은 물건 조사가 이때 가능하다. |
| 4일 저녁 | 13호 사건. 그 전에 주방 레버를 올려 두거나 책장 판을 쐐기로 막아 두면 할머니가 계획을 멈춘다(예방 분기). |
| 5~6일 | 사건 뒤 현장 재조사, 증언 범위 확인(도토 시야 등), 포장 자루 조사(5일부터). |
| 7일 | 식당 회의(첫 재판) 또는 청문. |
| 8~14일 | 둘째 주 위기와 결말. |

필요한 장면으로 바로 가려면 관리자 도구의 시작 지점을 쓴다(1일 13호, 2일 아침, 3일 아침, 4일 저녁, 5일 사건 뒤, 8일 둘째 주).

## 4. 새 확대 조사 화면 확인 위치

| 화면 | 가는 법 |
|---|---|
| 배달 짐 묶기 | 일거리 → 배달. 끈은 상점 '질긴 묶음끈'이나 까로의 허락으로 얻는다. |
| 여관 문틈 | 2일째 이후 낮, 여관 접수대에서 현관 문을 누른다. |
| 식당 배식 | 회차의 첫 주방 일을 할 때 |
| 포장 자루 | 5일째부터 잡화점 포장천 자루. 부리의 작업칼이 필요하다. |
| 손등불 | 주방 뒷문. 초롱의 손등불이 필요하다. |
| 저울 | 잡화점 저울. 표준 저울추가 필요하다. |
| 침대 밑 판자 | 13호 침대 밑. 작업칼이 필요하다. |
| 돌 탁본 | 광장 돌. 탁본 종이와 숯이 필요하다. |

물건은 관리자 도구 → 돈·물건·자료에서 받을 수 있다.
