# 회의 규칙 2판 — 「회의는 전투」 (2026-10-24, 설계)

소유자(2026-10-24):
- "알피지 게임이라고 쳐. 회의는 전투고. 위쳐 같은 게임 보면 퀘스트 실패할 수 있지만 전투는 죽으면 끝이지, 죽는다고 선택지가 달라지지 않잖아."
- "어떤 상황에서든 회의가 시작되면 깰 수는 있는데, 얻는 증거에 따라 대승리 분기도 있고, 보너스 증거를 얻으면 보다 조금은 쉽게 회의가 풀리게 하는 정도야. 물론 실패 분기도 가능은 하고."
- "진엔딩을 위한 하나의 수준으로 놓고, 이왕이면 해당 증거로 승리할 수 있게 하자. 한두 에피소드는 대승리를 해야. 진엔딩 조건의 하나로 뭔가를 얻어 다음에 미래에 도움이 되게끔."
- 앞서: "시간의 개념이 생기면 조사에 제약이 있고 오히려 스트레스가 될 거야." → 시간 제한은 넣지 않는다.

## 1. 원칙

1. **조사는 자유, 시간 제한 없음.** 정해진 행동을 하면 회의에 필요한 기본 증거는 반드시 손에 들어온다(지금 구조: 현장 행동 132곳 중 117곳이 단일 행동, `field-bindings.json`).
2. **회의는 언제나 깰 수 있다.** 기본 증거만으로 모든 쟁점에 정답이 있다. 플레이어와의 약속: 「회의에 필요한 증거는 언제나 자료함에 있다.」 막히면 증거가 없어서가 아니라 추리가 아직 안 맞아서다.
3. **보너스 증거는 조금 쉽게 해 준다.** 퍼즐(조사·대화·아이템 조합)로 얻은 보너스 증거는 그 쟁점의 **또 하나의 정답**이다 — 기본 증거 조합보다 짧거나 덜 헷갈리는 길. 이미 있는 장치 `R13_PROOF_ALTERNATES`(`room13_v111_newworld_rules.rpy:81`)를 쓴다(예: 5일 피코 그림이 겉옷 대조·귀가 진술을 대신하는 P1).
4. **대승리는 한두 회의에만, 진엔딩 조건으로.** 대승리 회의에서는 보너스 증거로 쟁점을 이기면 「대승리」가 되고, 무언가를 손에 넣어 뒤 사건에서 미래를 바꾼다.
5. **실패 분기는 남는다.** 기회 5번을 다 쓰면 지금처럼 부분·짐 결과로 이어진다. 전투에서 지는 것과 같다 — 진 결과가 이야기의 다음 갈래가 된다(「결과를 받아들인다」가 기본). 다시 하기 선택을 줄지는 아래 4장.

## 2. 지금 회의 로직과 맞춰 보기 (코드 확인)

- 쟁점마다 정답 증거 조합이 있고, 틀리면 기회 1번을 쓴다(`R13_NW_TRIES=5`, `r13_nw_retry`, `:186`). 맞는 근거는 남겨 두는 힌트가 있다(`r13_v111_proof_kept`).
- 정답 판정 `r13_v111_proof_accepts`(`:119`)는 기본 정답과 `R13_PROOF_ALTERNATES`의 대체 조합 가운데 하나를 받는다. 덧붙임 `R13_PROOF_EXTRAS`는 정답에 더 얹어도 되는 자료.
- 결과는 회의 11개 가운데 8개가 이김·부분·짐, 3개(1일 입구·5일 초소·13일 피코)가 이김·짐(`docs/reviews/branch-review-20261024/사실조사.md`).
- 대승리 단계는 지금 없다.

그래서 1~3·5번 원칙은 **지금 로직 그대로** 된다. 새로 할 일은 (가) 퍼즐로 얻는 보너스 증거를 각 쟁점의 대체 정답에 등록하는 것, (나) 대승리 회의 두 곳에 「보너스 증거로 이겼는가」를 기록해 결과를 가르는 것뿐이다.

## 3. 대승리 회의 후보 (추천, 소유자 확인 전)

지금 「이겨도 값만 적고 아무 데도 안 쓰는」 두 회의를 살린다(새 사실을 지어내지 않는다).

| 회의 | 지금 이기면 | 대승리로 얻는 것 | 뒤에서 바뀌는 것 |
|---|---|---|---|
| 7일 불 | `fire_neoul_promise_recorded` 값만(읽는 곳은 시험 파일뿐) | 누비에게 한 너울의 약속을 증언으로 확보 | 13일 공개 때 군중이 너울을 겨누는 까닭을 풀어 폭력을 막는 근거, 14일 장부 대면 |
| 12일 수프 | `transfer_list_secured` 값만(읽는 곳 없음) | 명단 원본을 손에 쥠 | 13일 담요·수레에서 명단 사람 전원을 내리는 근거 |

진엔딩 조건: 지금(사망 0 + 장부 + 기록·가설·담요·제단 이김)에 「불·수프 대승리」를 더한다.

## 4. 정할 것

1. 대승리 회의 두 곳(7일 불, 12일 수프) — 추천.
2. 각 대승리의 보너스 증거를 어느 앞 에피소드의 어떤 퍼즐로 얻게 할지 — 3일·6일 등에서 후보를 뽑아 시안으로.
3. 기회 5번을 다 썼을 때 「결과를 받아들인다 / 회의를 처음부터 다시」를 고르게 할지(전투 패배 뒤 다시 하기). 화면이 바뀌므로 이미지 시안 먼저.
