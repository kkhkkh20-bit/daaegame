# 13~14일 주민 별편과 본편 연결

2026-11-06. 마지막 이틀의 주민 여섯 명, 별편 여섯 장면을 쓰고 본편 반응 18행을 연결했다. [합본](주민_반응별편.md)과 [시간·분기·지식 매칭](reaction-map.json)에 원고 전문과 게임 발췌를 구별한다. 본편은 기존 14일이며 새 하루나 결말을 만들지 않았다.

| 날짜 | 시점 | 행동과 자기 목적 | 실제 앵커 |
|---|---|---|---|
| 13일 | 판돌 | 한 장을 다 덮지 못하고 옆 사람 몫을 남기려 함 | blanket_mended13, S01_L0017 뒤 |
| 13일 | 나비 | 학교 담요를 안으로 옮기게 하고 문 앞을 비움 | 실제 beds_ready13 블록 |
| 13일 | 까로 | 빈 수레 고삐를 은호 손에 직접 주려 함 | cart_return13, S04_L0085 뒤 |
| 14일 | 토실 | 자기가 쓴 엄마 이름의 잉크가 마를 때까지 기다림 | 실제 이름 쓰기 선택, S04_L0007 뒤 |
| 14일 | 백 부인 | 오늘 받은 몫과 아직 없는 내일 몫을 중복 계산하지 못하게 확인 | 실제 참관, S04_L0022 기존 MB01 뒤 |
| 14일 | 초롱 | 등을 줄이면서도 학교 문과 사람의 신호가 보이는지 확인 | 실제 초롱 출석, S04_L0029 뒤 |

## 시점과 갈래

- 판돌의 한 장을 반 접는 양보가 담요 수량 증가·기부·새 인수 효과가 되지 않는다. 가족 거래·담요 회의 전의 공통 장면이다.
- 나비의 자리를 준비하는 일은 개별 하차·학교 인수를 끝낸 일이 아니다. 기존 실제 출석 및 reader_nabi로 세 행 전체를 보호한다. 까로도 기존 karo_ready를 묶음 전체에 쓰며 반환 외의 명령·호송·중계 완료를 새로 주장하지 않는다.
- 가족 우선은 가족 셋의 자리이며 마을 구원이 아니다. 수레를 세움, 하차, 학교 인수, 연결 중지, 이미 떠난 사람은 각기 다르다.
- 14일 세 장면은 실제 아침 줄기다. 일반 아침은 무사망·진엔딩·희생 운영 완전 종료와 같지 않다. 다른 결말의 주민을 이 줄기로 옮기지 않는다.
- 토실의 이름 쓰기는 안/밖 문답 청취와 별개다. 밖에 있던 아이가 못 들은 자백을 인용하지 않는다. 지금 이름을 쓰지 않는 선택에서는 이 별편을 제외한다.
- 백 부인은 오늘 학교 물자의 소유자·기부자가 아니라 실제 인수표를 확인하는 참관자다. 엄마의 실제 학교 인수와 구별하며 새 장작 거래·기부·내일 약속을 만들지 않는다.
- 초롱 부재 시 기존 엄마 대체를 유지한다. 등 관리와 이송 연결·장치 공동통제·물자 실인수를 같은 일로 축약하지 않는다.

## 읽기 파일

기본은 실제 수레 반환·토실 이름 쓰기·아침 줄기의 여섯 장면이다. 이름 쓰기를 미룬 경로 다섯 장면, 개별 인수 후 이송 중지 절차를 마치지 않은 아침 경로 다섯 장면, 가족 우선 경로의 공통 장면 한 편을 따로 제공한다. 가족 우선 파일은 새 결말 전문이 아니라 거래 전 판돌 장면만 담는다. 전체 비교본은 여섯 장면이며 본편의 모든 결말을 새로 소설화한 파일이 아니다.

`python3 dev/export_resident_days.py --source docs/design/resident-reactions-day1314-20261106 --out /workspace/outputs/resident-days1314-20261106`

네 경로와 비교본의 PDF·Word·HTML 장면 순서·장 번호를 검사한다. 검증 범위·캡처는 [검수 기록](../../reviews/resident-days1314-20261106/검수.md), 이전 구간을 찾는 순서는 [읽기 안내](../../../../../docs/reading/README.md)를 따른다.

14일 시간표를 기준으로 피코 사건부터 마지막날까지 선택한 주민 별편의 구간 확장을 마쳤다. 다음 신규 날짜는 없다.
