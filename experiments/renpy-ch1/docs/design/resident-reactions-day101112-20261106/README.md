## 지식과 결과의 경계

- 다람이 학교에 나오는 것과 무혐의는 다르다. 살인회의 실패는 명단·감시가 남는다. 부분 성공은 할머니의 구금·위조 인정이 아니다. 최종 승리도 계획성·고의 타격까지 확정하지 않는다.
- 부리의 회의 전 별편은 할아버지의 사망을 다루며 다람의 혐의 해제·최종 진상을 선공개하지 않는다. 톡은 출처 대조 뒤 실제 출석한 때만 등장한다. 없으면 기존 사본 대체를 쓴다.
- 살아 있는 부엉이의 인수표와 기존 서류철을 구별한다. 종이 인수는 문서회의 승리·부분 성공에서 실제 선택해 건넨 뒤다. 치료 생존과 돌 제거 예방의 과거를 같게 회상하지 않는다.
- 나비의 실제 토실 인수와 부녀의 온실 이동을 구별한다. 온실 재회는 가족만이며 엄마의 앞선 편지·구금 소식 인지 여부를 새로 소급하지 않는다.
- 담요 0/1/2장, 토실에게 실제로 준 한 장, 가족 자리·공급·구조 준비·학교의 실제 구조 인수는 유지한다. 굴돌의 시설 출석과 이후 명단도 그대로다.
- 서리와 나비의 12일 별편은 먹기 전 중단판이다. 의료진 실제 귀환·약병 확인 뒤에 서리가 말한다. 장부 밖 약 고백과 투약 확정을 앞당기지 않는다. 나비의 책 장면은 자백 뒤 일반 승리·부분 성공·대승리에 공통이다.
- 돌목의 명단 칸 무효는 돌아온 그릇으로 대승리한 뒤 실제 돌목이 입회한 경우만이다. 먹은 뒤 사건도 해당하지만 이미 생긴 피해나 이송된 사람을 되돌리지 않는다. 선생님 감독 선택은 별도로 남는다.
