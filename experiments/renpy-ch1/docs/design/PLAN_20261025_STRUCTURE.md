# 구성안: 조사 짜임 반복과 중후반 웃음 공백 (2026-10-25, 소유자 확인 전)

대사만 고쳐서는 풀리지 않는 두 문제를 장면 구성으로 푸는 안이다. 소유자 확인 뒤에 적용한다.
사실·증거·생사·회의 정답은 바꾸지 않는다.

## 2. 안 A — 다람이 갇힌 동안의 임시 짝 (구조 변경, 확인 필요)

역전재판도 마요이가 없을 때 하루미·미츠루기·이토노코가 짝을 대신한다. 짝이 바뀌면 조사 짜임도 바뀐다.

- 후보 1 **부리**(추천): 부엉이의 손녀. 할아버지 일을 밝히려는 당사자이고, 말을 곧이곧대로 받는다
  ("'빌려줌'. '훔치게 해 줌' 말고요"). 8일 13호에 수첩을 들고 이미 나온다. 9일 공방은 부리 일터다.
  아빠의 짐작을 부리가 글자 그대로 받아 고치는 짝이 된다. 다람과 다른 웃음(곧이곧대로의 웃음)이다.
- 후보 2 **도토**: 아이를 두고 내려간 죄책감으로 따라다닌다. "정확히는"이 아빠의 짐작을 고친다. 단 8일에 거짓말이 드러나므로 함께 다니면 긴장이 생긴다.
- 해야 할 일: 8-2(13호)·9-1(주방)·9-2(공방)·9-3(식당)에 그 인물을 세운다(`r13_v111_arrive`). 장면마다 2~4줄 주고받기를 넣는다.

## 3. 안 B — 조사 장면의 들어가는 방식 바꾸기 (대사 위주, 바로 가능)

8~9일 여덟 장면이 모두 「아빠가 다가가 묻는다」로 시작한다. 들어가는 방식을 섞는다.

- 이미 벌어진 일 한가운데서 시작: 9-2 공방은 톡이 누군가와 값 때문에 다투는 데서 연다.
- 상대가 먼저 찾아온다: 9-3 식당은 나비가 먼저 "또 답부터 정해 놓고 묻지는 마세요"로 막아선다(이 줄은 이미 있다. 장면 첫 줄로 올린다).
- 아빠가 퍼즐을 맞추는 짧은 정리: 9일 끝에 아빠 속말 세 줄로 「아는 것 / 모르는 것 / 내일 물을 것」을 정리한다. 판을 넘는 추리의 쾌감을 준다(정답은 말하지 않는다).

## 4. 안 C — 무거운 날의 숨구멍 (대사, 바로 가능)

- 갇힌 다람의 대장 놀이: 면회 때마다 아빠가 보고하고 다람이 명령한다. 8·9일에 넣었다. 10일 대기실에 한 번 더 넣으면 반복 웃음이 완성된다.
- 13일(수레): 돌목의 귀찮음과 까로의 투덜이 이미 마른 웃음을 준다. 수레가 멎은 뒤 다람·아빠 한 마디("바늘보다 수레가 더 느려" 같은 13일 바느질 장면 되받기)를 넣는다.
- 10일 회관: 회의 사이 쉬는 틈에 톡의 "값은 아직이지만요" 같은 자기 손해 농담을 한 번 더 둔다.
