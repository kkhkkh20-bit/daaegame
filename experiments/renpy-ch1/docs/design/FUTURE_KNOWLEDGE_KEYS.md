# 미래 지식 열쇠표 (다회차 추리 설계도)

소유자 결정(2026-10-23):
- "잔혹 동화가 기본이고, 진엔딩 조건은 어려워야 하고, 다회차 유도용 분기 이미지를 보고 다음에 미래를 아는 사람이 맞추는 수준으로. 이것을 찾는 것 자체가 다회차 추리물. 게임 포가튼 시티를 참고. 기본은 대부분 죽는 엔딩."
- "진엔딩 보려면 어차피 처음부터 해야 할걸." → 회차마다 처음부터(날짜 이어하기 없음). 반복 피로는 읽은 대사 건너뛰기로 줄인다.

근거: 소유자 설계안 「분기별 사전 대비 설계안」(0.20.15), 0.20.16 소스. 사건 태그는 `docs/design/EVENT_TAGS.md`.
이 표는 설계다. 게임은 아직 바꾸지 않았다.

## 원칙

1. **비극이 기본값이다.** 아무것도 모르고 성실히 하면 피코·꼬미·부엉이·네로·도담 대부분이 죽고 14일은 「얼어붙은 마을」(사망 4명 이상)로 끝난다.
2. **열쇠는 비극 뒤에만 보인다.** 각 비극에는 원인이 드러나는 뒤 장면이 있고, 그 지식이 있어야 앞 장면의 평범한 행동이 열쇠로 읽힌다(포가튼 시티의 방식: 회차를 넘어 남는 것은 사실뿐).
3. **회차 해금 없음.** 대비 행동은 첫 판에도 할 수 있다. 다만 첫 판에는 생활 행동으로만 보이고, 아무도 권하지 않는다. 이전 회차 기록으로 선택지를 열지 않는다.
4. **운명 선택지를 없앤다.** 「오늘 옮긴다/내일 데려온다」, 「A/B/C」처럼 위기 직전에 결과를 고르는 메뉴 대신, 앞선 장면의 실제 행동이 판정 시점에 결과를 정한다.
5. **판정은 이야기의 전환점에서.** 식당 폐점, 저녁 점호, 서류 열람, 수레 출발. 읽는 시간·클릭 수로 판정하지 않는다.
6. **갈림길 지도가 다음 회차를 부른다.** 결말 뒤 지도는 판정 시점마다 「?」와 안 본 결과 개수만 보인다. 무엇을 해야 하는지, 누가 사는지는 감춘다.
7. **진엔딩은 어렵다.** 아래 「진엔딩 조건 제안」.

## 진엔딩 조건 제안

현행: 아침 경로 + 사망 0 + 너울 장부 + records·hypothesis·blanket·altar 모두 승리.
제안(어렵게): 현행에 두 가지를 더한다.
- 13일 명단 인원 전원 실제 인계(`outcome13=all_rescued`)
- 운송 고리 중단(`current_transport_chain_stopped`)

뜻: 모두 살리고, 모두 데려오고, 다시는 같은 일이 없게 한다. 첫 판에 우연히 볼 수 없고, K1~K5와 K11~K13을 다 알아야 닿는다.

## 구현 순서

1. 갈림길 지도 시안(이미지) → 승인
2. K1 피코 시범: 정답 메뉴를 걷고 식당 행동 판정으로 → 첫 판(모름)과 둘째 판(앎)을 실제로 플레이해 확인
3. K2 꼬미 → K4·K5 단서 정리 → K3 부엉이 → K13 공개 순서
4. 진엔딩 조건 강화는 1~3이 끝난 뒤 적용(먼저 바꾸면 시험할 길이 없다)

## 열어 둔 질문

- K3 부엉이: 설계안의 추가 선택안(도토와 "급한 호출은 확인한다" 합의로 C에서도 막기)을 넣을지. 열쇠표 취지(8일에 알게 된 거짓 호출을 7일에 쓴다)와 가장 잘 맞는 안이라 실무 의견으로는 권한다.
- K5 도담: 약병만 회수하고 난방이 없는 중간 상태를 둘지(설계안의 별도 승인안).
