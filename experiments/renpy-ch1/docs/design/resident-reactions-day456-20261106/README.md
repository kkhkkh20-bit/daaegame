# 4~6일 주민 별편과 본편 연결

2026-11-06. 소유자의 다음 날짜 진행 요청에 따라 3일 피코 사건에 이어 4~6일을 작업했다. 본편 사건·진상·정답·생사 결과는 현재 실행 소스를 기준으로 유지한다.

읽기 원고는 [주민 반응별편](주민_반응별편.md), 장면의 시각·당사자가 아는 범위·실행 앵커는 [통합 매칭표](reaction-map.json)를 따른다. 날짜별 원고와 매칭 파일도 함께 보존한다. 이전 3일 별편은 별도 폴더에 유지한다.

| 날짜 | 시점 인물과 장면 | 본편 반응 연결 |
|---|---|---|
| 4일 | 돌목: 다친 채로도 문을 비우라고 고집 | 의자를 옮기고 앉는 짧은 행동 |
| 4일 | 밤이: 콩이의 정정을 자기 앞에서만 끝내지 못하게 요구 | 공개 정정 요구·콩이 답변 |
| 5일 | 나비: 일을 정리하고 직접 증언하러 출발 | 물통 정리·앞치마 벗기·당사자의 답 |
| 5일 승리 | 밤이: 보증 내용을 읽고 접어 보관 | 접을 크기를 직접 정하고 종이를 챙김 |
| 5일 실패 | 밤이: 자신이 아니라고 한 말도 기록하라고 요구 | 기존 실패 대사 보강, 명단 등록 결과 유지 |
| 6일 사전 인계 | 도토: 담요를 빌리고 실제 입실·수량을 확인 | 네 아이와 담요 확인 후 수레를 뺌 |
| 6일 아이 잔류 | 보리: 구조한 셋을 안전한 쪽으로 돌리고 창고를 다시 봄 | 구조 직후 행동과 지시 |
| 6일 꼬미 상실 | 보리: 다친 손으로 도담의 물잔을 받지 못함 | 도담에게 도움을 요청하고 세 아이를 바라봄 |
| 6일 빈 창고 | 보리: 다치지 않은 손과 학교의 네 아이를 확인 | 물잔·화상 장면과 분리한 행동 |

별편은 주민 1인칭 전문이고, 게임은 다돌이 직접 보는 짧은 대사·행동만 사용한다. 각 장면에는 독자용 시간·갈래 표기를 넣었다. 승리/실패와 사전 인계/화재 상실을 조합한 네 읽기 경로는 각각 여섯 장면이며, 전체 비교본 아홉 장면은 한 판의 연속 사건이 아니다. 피코의 생사·선택적 스케치는 이 별편들에서 확정하지 않는다.

## 정보와 결과의 경계

- 밤이는 얼굴·키·나이를 못 봤다. 낮에 봤다는 콩이의 말은 범행 목격이 아니다.
- 나비의 출발 약속은 공통, 실제 초소 증언은 기존 승리 장면에서 합류한 뒤에만 나온다.
- 5일 엄마 편지는 초롱이 비켜난 뒤 가족만 읽는다. 전문 청취 표시와 봉투 획득은 구분한다.
- 학교의 허락, 담요 차용, 네 아이의 실제 인계를 구별한다. 네 아이를 인계해야 빈 창고 경로가 된다.
- 아이들이 남은 화재에서 세 아이는 구조되지만 꼬미는 사망한다. 이를 꼬미 생존 분기로 부르지 않는다.
- 도담은 보리의 아이이며 꼬미와 다르다. 장작 절도 인정은 방화 인정이 아니다. 방화범에 관한 7일 진술을 6일로 당기지 않는다.

## 재생성·검증

`python3 dev/export_resident_days.py`는 통합 매칭표와 합본에서 HTML·경로별 PDF·Word를 만든다. HTML의 각 경로에서 장면 수와 순서를 실제 브라우저로 검사한다. 본편 단위·화면 검사와 공개 상태는 [0.20.107 릴리스](../../releases/RELEASE_0.20.107.md)와 해당 검수 기록에 따로 기록한다. 소설이 재미있다는 인간 초견 독자 검증을 통과했다고 주장하지 않는다.
