# 대사 시안 — 1일 입구 (MS14_D01_S02, 줄 28개)

2026-10-28 소유자: 「대사 이런 식으로 만들어 줄 수 있나? “……네?” “그, 그건” “뭐?” “또 너니? 로잘린?” …… 우리 대사들은 와닿지 않아」
「하아아암 같은 것도 넣어야 하는 듯」(웹소설·대화형 캡처 다섯 장).

레퍼런스에서 가져온 것(문장은 옮기지 않고 기법만):
1. **반응 먼저.** 할 말보다 놀람·되물음이 먼저 튀어나온다 — 「……네?」「뭐?」「일꾼이요?」.
2. **말이 걸리고 끊긴다.** 당황하면 첫 음절을 반복하거나(「그, 그건」) 말을 못 맺는다(「……」).
3. **소리·몸의 말.** 하품(「하아아암」), 한숨, 헛기침(「흠흠」), 얼버무림(「으음……」).
4. **상대를 부르며 몰아붙인다.** 이름을 부르고, 남과 비교하고, 혼잣말처럼 깎아내린다 — 사람마다 말버릇이 다르다.
5. **지문은 감정의 결과를 짧게.** 「지목당한 로잘린이 당황하며」처럼 누가 어떤 기분으로 말했는지를 한 줄.
6. **설명은 쪼개 주고받는다.** 한 사람이 다 말하지 않고, 듣는 쪽이 「무슨 뜻이에요?」로 끊는다.

지키는 것: 사실·순서·누가 무엇을 아는지는 그대로다. 줄 번호(기록 ID)를 그대로 쓰므로 선택지·회의 연결이 깨지지 않는다.

## 적용 방법(승인 뒤)

- 날짜 순서대로 하루씩 바꾼다(`dev/dialogue_day.py show N` → 수정 JSON → `apply N`). 하루마다 `dev/dialogue_logic_check.py`(A/B/C 0)와 단위 시험.
- 인물마다 반응 버릇을 정해 VOICE_GUIDE 에 적는다(돌목 「흠흠」「……」, 까로 「어이쿠」, 다람 「아빠……」 끝을 흐림, 아빠 당황 시 첫 음절 반복 등).
- 회의(정답 판정)와 이어진 줄은 사실·단서 낱말을 바꾸지 않는다.
