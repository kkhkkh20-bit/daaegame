# 다람탐정 공통 UI 규격

2026-10-17. 정본은 `game/room13_typography.rpy`의 `R13_CONTROL`과 `game/room13_controls.rpy`다. 화면마다 새 버튼 외형이나 정렬 수치를 만들지 않는다.

## 조작 부품

| 부품 | 크기·배치 | 사용 |
|---|---|---|
| 하단 행동 버튼 | 너비232, 높이64 / 큰 글씨80, 간격16 | 조사·대사·회의·대화의 공통 하단 |
| 상단 보조 행동 | 같은 재질·내용 정렬, 높이64 | 지도, 조사 지점 표시 |
| 메뉴 행 | 너비328, 높이64 / 큰 글씨80, 2열 | 더보기 팝업; 작은 터치 행으로 압축하지 않음 |
| 질문 행 | 내용 너비592, 최소54, 긴 문장은 측정해 증가 | 대화 질문, 명시적 페이지 |
| 선택지 행 | 기존72 / 큰 글씨80 최소 높이 | 이야기 분기 선택 |
| 종이 탭 | 종이 재질, 가운데 정렬, 선택 시 공통 먹색 표면 | 자료 분류·필터 |
| 현장 지점 | 위치를 표시하는 작은 돋보기 | 물건의 기존 넓은 터치 영역을 함께 유지 |

같은 역할의 부품은 같은 크기를 쓴다. 긴 문구 때문에 한 버튼만 늘리지 않는다. 안내와 버튼을 합친 이중 네모도 만들지 않는다.

하단 다섯 칸의 x는 28, 276, 524, 772, 1020. 모든 네모의 밑변은704이며 화면 아래 여백은16이다. 보통 y640, 큰 글씨 y624. `r13_footer_control()`로만 배치한다. 두 번째 줄은 `r13_control_upper_y()`를 사용한다.

- **조사:** 주변 살피기 / 사람과 대화 / 살펴보기 / 더보기 / 기록.
- **대사:** 백로그 / 자동 / 대사 건너뛰기 / 더보기 / 기록(일부 컷신은 설정).
- **회의:** 더보기 또는 중단 / 발언 선택 또는 토론 듣기 / 되묻기 / 자료 보여주기 / 기록.
- **대화 질문:** 돌아가기는 첫 칸, 더보기·기록은 마지막 두 칸. 자료 보여주기는 기록 바로 위 같은 크기의 칸. 빈 칸은 채우기 위해 행동을 추가하지 않는다.

## 내용 정렬

- 아이콘28×28, 글씨22 / 큰 글씨24, 아이콘-글씨 간격10, 좌우 안전 여백16.
- 아이콘과 글씨를 하나의 hbox로 묶고 두 축 모두 중앙 정렬한다. 버튼 내부에 별도 y좌표나 .75 정렬을 주지 않는다.
- 아이콘이 없는 버튼도 글씨를 수직 중앙에 둔다. 긴 질문 행은 번호와 여러 줄 본문을 같은 수직 중앙에 둔다.
- 장식 아이콘은 기존 `R13AntiqueIcon`의 금색·가죽·종이 팔레트를 쓴다. 이모지나 다른 아이콘 세트를 섞지 않는다.

## 표면과 상태

명령 버튼은 `R13ControlSurface` 하나로 그린다. 잘린 모서리5px, 2px 테두리, 먹갈색 면, 불투명도90%(e6)를 공유한다. hover도 투명도를 바꾸지 않는다.

| 상태 | 표현 |
|---|---|
| 기본 | 먹갈색 면·황갈색 테두리·밝은 글씨 |
| 주요 행동 | 같은 크기·불투명도에 금색 테두리·따뜻한 면 |
| 선택 | 같은 금색 강조, 상태를 유지 |
| 호버 | 같은 면적·불투명도에서 면과 테두리 색만 변경 |
| 비활성 | 같은 면적·불투명도, 회갈색 테두리·낮은 내용 대비, 입력 차단 |

호버는 보조 신호다. 모바일에서는 탭의 선택 상태, 대상 이름, 활성화된 조사 버튼만으로 조작이 가능해야 한다.

대사는 기존 승인된85%(d9), 조작 버튼은90%(e6), 자료·발언 카드는 불투명 종이다. 이것은 역할별 구분이며 버튼마다 임의로 투명도를 다르게 주지 않는다. 읽기 패널은 `R13InkPanel` / `R13PaperFrame`, 클릭 가능한 조작은 `R13ControlSurface`를 쓴다.

## 화면 간격

대사·회의 발언 카드는 하단 버튼 위16px에서 끝난다. 큰 글씨일 때도 이 간격을 유지한다. 질문의 실제 글자 높이를 측정하고 자료 보여주기 윗줄과 페이지 이동 공간을 뺀 뒤 페이지로 나눈다. 숨은 질문 스크롤을 추가하지 않는다.

## 개발·검토

- 새 행동은 `use r13_control(...)`, 하단 행동은 `use r13_footer_control(column,...)`.
- 기존 `r13_antique_button`과 `r13_strip_button`은 같은 공통 부품으로 위임한다. 새 렌더러를 추가하지 않는다.
- 기존 `r13_action_button` 스타일도 같은 표면·중앙 정렬을 상속한다. 저장 파일 호환용 옛 Displayable 이름은 남기되 새 사용처를 만들지 않는다.
- `r13_control_specimen`은 실제 엔진의 부품표다. 기본·선택·주요·비활성 및 하단을 한 화면에서 본다.
- `dev/qa_investigation_meeting_ui.py`: PC/터치에서 하단 너비·높이·밑변·겹침 및 실제 조사·회의 취소 흐름.
- `dev/qa_side_questions.py`: 0/8/12개 질문, 페이지 이동·숫자키·자료/기록 취소·실제 대사 복귀.

공통 스타일 변경은 화면 캡처까지 확인한다. 엔진 컴파일 성공만으로 시각 검수가 끝났다고 판단하지 않는다.
