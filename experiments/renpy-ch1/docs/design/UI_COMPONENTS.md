- **현장(0.19.55):** 인물이 기본이며 직접 눌러 대화. 첫 칸은 주변 살피기 ↔ 사람 보기 전환 하나. 배경 물건은 직접 누르면 조사한다. 중간 선택·별도 살펴보기 버튼·돋보기 표식은 없다. 기록은 마지막 칸. 별도 대화·지점 표시·더보기·장소 바로가기는 없다. 이동은 지도에 모은다.
- **대사(0.19.62):** 현재 대화 건너뛰기 / 기록 / 더보기. 백로그·자동은 더보기 안. 건너뛰기는 확인 후 진행. 공통 도크 `r13_concept_dock()`를 사용한다.
- **회의:** 더보기 또는 중단 / 발언 선택 또는 토론 듣기 / 되묻기 / 자료 보여주기 / 기록.
- **대화 질문(0.19.62):** 돌아가기는 왼쪽. 오른쪽 한 줄에 자료 보여주기 / 기록 / 더보기. 기록·더보기 폭160, 제시256, 건너뛰기304. 시각 높이56·아이콘20·글씨22·간격16을 공유하고 모바일 터치영역80은 유지한다. 도크 오른쪽과 대화 날짜 패널 오른쪽은1232(여백48)로 맞춘다. 현장 날짜는 옵션 버튼과 겹치지 않게 기존 배치를 유지한다.

## 폰트 승인(0.20.27, 2026-10-24 소유자 정정)

B안 요청서와 소유자 정정에 따라 Pretendard 고딕 일반체(`assets/Pretendard-Regular.otf`)와 `r13_ui_font()`를 공통 사용한다. 메인 메뉴·옵션·대사·질문·공통 UI에 적용하며 기존 색상·크기·일반체·이름 외곽선은 유지한다. 이전 갈무리·메인 명조 지정보다 이 결정이 우선한다.

## 내용 정렬

- 현장·회의는 아이콘28×28, 글씨22 / 큰 글씨24, 아이콘-글씨 간격10, 좌우 안전 여백16. 대사·질문 도크는 위 승인 규격(아이콘20·글씨22·간격8)으로 중앙 정렬한다.
- 아이콘과 글씨를 하나의 hbox로 묶고 두 축 모두 중앙 정렬한다. 버튼 내부에 별도 y좌표나 .75 정렬을 주지 않는다.
- 아이콘이 없는 버튼도 글씨를 수직 중앙에 둔다. 긴 질문 행은 번호와 여러 줄 본문을 같은 수직 중앙에 둔다.
- 장식 아이콘은 기존 `R13AntiqueIcon`의 금색·가죽·종이 팔레트를 쓴다. 이모지나 다른 아이콘 세트를 섞지 않는다.

## 표면과 상태

명령 버튼은 `R13ControlSurface` 하나로 그린다. 잘린 모서리5px, 2px 테두리, 먹갈색 면, 불투명도90%(e6)를 공유한다. hover도 투명도를 바꾸지 않는다.

| 상태 | 표현 |
|---|---|
| 기본 | 먹갈색 면·황갈색 테두리·밝은 글씨 |
| 주요 행동 | 같은 크기·불투명도에 금색 테두리·따뜻한 면 |
| 선택 | 같은 금색 강조, 상태를 유지 |
| 호버 | 같은 면적·불투명도에서 면과 테두리 색만 변경 |
| 비활성 | 같은 면적·불투명도, 회갈색 테두리·낮은 내용 대비, 입력 차단 |

호버는 보조 신호다. 모바일에서는 탭의 선택 상태, 대상 이름, 활성화된 조사 버튼만으로 조작이 가능해야 한다.

대사는 기존 승인된85%(d9), 조작 버튼은90%(e6), 자료·발언 카드는 불투명 종이다. 이것은 역할별 구분이며 버튼마다 임의로 투명도를 다르게 주지 않는다. 읽기 패널은 `R13InkPanel` / `R13PaperFrame`, 클릭 가능한 조작은 `R13ControlSurface`를 쓴다.

## 화면 간격

대사·회의 발언 카드는 하단 버튼 위16px에서 끝난다. 큰 글씨일 때도 이 간격을 유지한다. 질문의 실제 글자 높이를 측정하고 자료 보여주기 윗줄과 페이지 이동 공간을 뺀 뒤 페이지로 나눈다. 숨은 질문 스크롤을 추가하지 않는다.

## 개발·검토

- 새 행동은 `use r13_control(...)`, 하단 행동은 `use r13_footer_control(column,...)`.
- 기존 `r13_antique_button`과 `r13_strip_button`은 같은 공통 부품으로 위임한다. 새 렌더러를 추가하지 않는다.
- 기존 `r13_action_button` 스타일도 같은 표면·중앙 정렬을 상속한다. 저장 파일 호환용 옛 Displayable 이름은 남기되 새 사용처를 만들지 않는다.
- `r13_control_specimen`은 실제 엔진의 부품표다. 기본·선택·주요·비활성 및 하단을 한 화면에서 본다.
- `dev/qa_investigation_meeting_ui.py`: PC/터치에서 하단 너비·높이·밑변·겹침 및 실제 조사·회의 취소 흐름.
- `dev/qa_side_questions.py`: 0/8/12개 질문, 페이지 이동·숫자키·자료/기록 취소·실제 대사 복귀.

공통 스타일 변경은 화면 캡처까지 확인한다. 엔진 컴파일 성공만으로 시각 검수가 끝났다고 판단하지 않는다.

## 질문 영역 기준선 (0.19.53)

`systems/room13_side_questions.rpy`의 `R13_SIDE_QUESTION_TOP=150`을 인물 이름과 질문 제목이 함께 쓴다. 목록은 그보다42px 아래에서 시작한다. 이전 기준선70에서80px 내렸다. 질문 수가 적다고 상단에 붙지 않도록 하며, 질문이 많을 때는 현재 시작점과 자료 보여주기 사이 높이를 측정해 페이지로 나눈다. 하단 명령 부품과 인물 그림의 위치·크기는 유지한다.

## 0.19.57 모바일·자료 화면 기준

공통 버튼의 모바일 판정은 r13_touch_ui() 한 곳에서 관리한다. 터치 기기이거나 물리 창 높이가600px 미만이면 높이80, 그 외64이며 사용자 글자 확대는 계속80을 사용한다. 지도 이동·복귀는 현장과 같은 공통 footer_control을 쓴다. 지역 탭과 자료 분류는 별도 의미를 유지하면서 모바일 높이80과 최소 너비80을 사용한다.

주요 행동 색은 R13ControlSurface(primary=True)에서 관리한다. 활성 제시와 이동에 사용하고 비활성 상태는 같은 geometry에서 낮은 대비로 구별한다.

조사 힌트는 장소별3초 후 접고 모드 이름은 장소명에 남긴다. 새 생각 알림은 기존 생각 버튼 안에서 처리한다. 빈 배경 입력의 반응은 UI 화면만 사용하며 게임 상태를 수정하지 않는다. 자료 출처 펼침도 화면 내부 상태다.

## 공통 확인창 (0.19.61 승인)

`r13_confirm`은 `r13_confirmation_card`를 사용한다. 기존 `R13PaperFrame`을 본체와 버튼에 재사용하며, `R13ConfirmPaper`는 얕은 그림자만 더한다. `R13ConfirmSeal`은 날짜창의 `R13TimeDial` 둘레를 감싸는 작은 돌출 장식이다. 모서리 밖에 걸치되 본문·버튼을 가리지 않는다.

본문에 맞춰 높이가 정해지고 화면 중앙에 놓인다. 큰 글씨·터치에서 공통 조작 높이를 적용한다. 장식은 입력·진행 상태를 만들지 않는다. 잠자기·일·회의 등 같은 확인창을 쓰는 곳에 공통 적용하며 별도의 화면별 장식을 추가하지 않는다. [승인 시안과 실제 검수](../reviews/confirmation-card-20261018/README.md).
