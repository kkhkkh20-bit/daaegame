- 요청받은 디자인 채팅: 아래 부족 원화의 기존 자산 대조·제작·전후 일치 검수. 이야기 효과·정답·선택지·UI·엔진은 변경하지 않는다.
- 토리의 진행 중 인물 표정/동작과 중복 제작 금지. 먼저 기존/진행 자산 목록을 확인한다.
- 이미 완성: 다람 신규 동작 10종, 꼬미/도담/새미/우박 추가 표정, 공용 회색 담요 전후 2종. 이를 다시 만들지 않는다.

## 최우선: 화면으로 비교할 단서 3세트

### C01 — 회색 겉옷과 울타리 천: 찢어진 선 + 두 줄 수선실

참조: game/v111/records.json 의 MS14_D05_S02_L0016, L9101. 허락 후 벗은 겉옷과 보관한 울타리 천을 나란히 관찰한다. 날카로운 못에 뜯긴 지그재그 선과 두 줄 수선실이 이어진다.

납품: C01_coat_master, C01_fence_piece, C01_comparison. 같은 한 장의 원본을 실제로 분리해 만든 형상이어야 한다. 독립적으로 생성한 비슷한 두 천은 불가. 비교 그림은 두 조각 사이에 여백을 두고 같은 배율/방향으로 놓는다. 수선실의 두 줄이 양쪽 끝에서 정확히 이어져야 한다. 원형·화살표·정답 체크·피/이빨 자국 추가 금지. 이 자료는 이동 경로의 근거이며 물림 장면을 증명하는 그림이 아니다.

### C02 — 핀 뒤 구리선과 분리 보관한 조각: 두 번 꺾인 선 + 파단 경계

참조: MS14_D08_S03_L0007, L0016, L0020. 촛대 장식 고리에 접힌 천이 핀으로 잠겨 있고 핀 뒤 구리선 일부가 비어 있다. 천/핀을 처음 상태대로 둔다.

납품: C02_pin_wire_master, C02_wire_fragment, C02_comparison. 동일 원본 형상에서 분리하고, 두 번 꺾인 선·끊긴 굴곡이 이어져야 한다. 색이 비슷한 것만으로 맞는 그림 불가. 상처 속 조각은 별도 종이 받침 위 보존 상태로 표현한다. 천/핀을 뽑거나 피 묻은 손으로 맞추는 새 행동을 그리지 않는다.

### C03 — 병 입구와 파편: 비대칭 경계 2개 + 제조 이음선 + 봉인 전후

참조: MS14_D12_S02_L0011 / D12_S03_L0020 / D12_S04_L0014, L0021.

납품: C03_bottle_intact_sealed, C03_bottle_missing_piece, C03_fragment, C03_comparison, C03_seal_closeup. 병 입구와 파편은 동일 원본에서 분리하고 비대칭 경계 두 곳과 제조 이음선을 함께 연결한다. 조각을 돌려도 임의의 방향에서는 맞지 않아야 한다. 준비 때 병 입구/마개/목의 개봉 봉인은 온전하다. 병 표기만으로 내용물을 확정하는 도상, 독약 마크, 범인 강조, 의미심장한 광채 금지. 도구로 보존한 관찰 상태이며 맨손 접합 장면 불가.

## 톤과 파일 규격

- 기존 겨울 마을의 그림책/도트 톤, 절제된 채도와 따뜻한 암색 윤곽, 읽히는 큰 픽셀 덩어리. 얼룩·반복 패턴·과한 미세 입자·실사 질감 금지.
- 배경과 단서 소품은 기존 그림을 참조한다. 두께·크기·광원·재질을 세트 내에서 고정한다.
- 소품은 투명 RGBA PNG 원본, 기준 1024×1024 이내. 동일 세트는 캔버스/원점/배율 동일. 관찰용 비교 패널은 1280×720 또는 960×540, 제목/라벨/UI 글자를 이미지에 굽지 않는다.
- 폰에서 작은 디테일이 사라지지 않도록 실제 1280×720 게임 화면을 가로폭 약 640/390으로 줄여도 접합 단서를 구분할 수 있는 확대 시안을 포함한다.
- 자르기/분리 과정의 공통 원본, 마스크/좌표와 회전 기준점을 함께 납품한다. 동일 원본에서 나왔다는 것을 코드 담당이 확인할 수 있어야 한다.
- 완성 원본과 런타임용 파생본을 구분한다. 원본 변경 없이 코드 담당이 dev/import_art.py로 WebP를 만든다. 원본 파일을 덮어쓰지 않는다.

## 납품 검수표

1. 기존 파일/토리 작업과 중복 여부, 실제 확인한 경로.
2. 원문 ID → 자산 파일명 → 표시 전제(조사 전/획득 후/제시 중)의 매핑.
3. before/after 및 조각/본체를 같은 배율로 겹친 검수 캡처.
4. 형태 2개 이상의 대응 지점 표시가 들어간 제작 검수용 이미지. 게임용 이미지에서는 표식을 제거한다.
5. 일반 화면과 휴대폰 축소 화면의 가독성 캡처.
6. 파일별 크기/해상도/투명도, SHA256, 공통 원본 경로, 제작/재사용 출처.
7. 불확실한 부분은 미완료로 적고 임의 설정으로 메우지 않는다.

먼저 C01~C03의 소규모 시안을 보여 주고 형상 일치와 기존 톤을 확인한 뒤 세트로 완성한다. 대사나 사건 논리는 고치지 말고 코드 담당에게 그림과 매핑을 넘긴다.
