# 미연결 분기·대사 목록

정상 진행에서 들어오는 길이 없는 분기와 대사를 모은다. 여기 있는 항목은 구현된 분기 수에 세지 않는다. 연결하려면 이야기상 계기가 먼저 정해져야 하고, 결말 판정에 미치는 영향을 함께 확인한다.

## 13일 군중 장면 — 막으려 했지만 못 막음

- 라벨: `r13_v111_crowd_failed13` (`game/room13_v111_days1114.rpy`)
- 대사: `MS14_D13_C_L0021`("밀지 마요. 아이도 있어요."), `MS14_D13_C_L0022`("비켜.")
- 설정 값: `crowd_injury=True`, `crowd_intervention="failed"`, `outcome13="crowd_violence"`
- 14일 후일담: `r13_v111_crowd_failed14`(`MS14_D14_END_VIOLENCE_L0017`·`L0018`, "막으려고 갔어. 그런데…… 못 막았어.")가 이 값을 읽는다.
- 현재 상태: 군중 선택지는 「너울 앞을 막는다」(성공), 「현장 감독자에게 보호를 맡긴다」(성공), 「막지 않는다」(`none`) 셋뿐이다. 어느 선택도 이 라벨로 오지 않는다.
- 결정(2026-10-23 소유자 "추천안 대로"): 결말 판정을 바꾸지 않고 미연결로 분리한다. 「막는다」를 무작위 실패로 바꾸지 않는다(소스 검토 0.20.4 연결 확인 2의 권고).
- 연결 조건 후보(채택하지 않음, 다시 검토할 때 참고): 감독자가 다른 곳에서 감독 중이고(`busy:guard`) 가족이 광장에 있을 때 아빠가 다람을 붙든 채 막으러 가는 경우. 이 경우 플레이어가 그 위험을 선택 전에 알 수 있어야 한다.
