# 첫 회의: 대체 논증의 난도와 오답 예산 (0.19.60)

사용자 결정: 회의가 핵심이다. 대체 공략도 어려워야 하며, 원래 조사 경로를 놓쳤을 때 다른 정확한 논증으로 돌파하는 길이어야 한다. 회의마다 하나의 논증을 확정하고 그 논증의 고리를 끝까지 입증한다. 같은 시도 안에서 A/B/C를 바꿔 끼우지 않는다. 오답은 회의 전체에서 세 번. 실패하면 같은 자료로 회의 처음부터 재도전할 수 있다. 실패 결과로 이후 이야기를 계속하는 선택도 유지한다.

## 분기가 열리는 정확한 지점

너울의 첫 발언 “등을 돌보는 톡이 조각을 가져간 것 아니오?”에 대한 반박 선택으로 분기한다. “남은 끈의 주인부터 따지겠습니다”, “팔린 조각의 행방부터 따지겠습니다”, “두 사람이 본 작업부터 맞춰보겠습니다”가 각각 A/B/C 논증의 출발이다. 선택 뒤에는 해당 논증의 첫 반론으로 이어진다. 플레이어가 끈의 사용 경로(A), 거래와 취득 경위(B), 두 목격의 연결(C) 중 내세울 논증을 말하고 확정한다. 확정 전에는 기록을 읽고 생각을 바꿀 수 있다. 확정한 뒤에는 해당 논증의 발언과 공통 권한 쟁점으로 회의가 진행된다. 소지한 자료, 확정한 발언, 그 발언에 대한 정확한 제시가 다음 논점을 연다. 자료 소지만으로 입증되거나, 다른 논점에 맞는 자료를 냈다는 이유로 통과하지 않는다.

| 논증 | 단계와 필수 자료 | 틀리면 넘지 못하는 구분 |
|---|---|---|
| 물증 | `v_trace`: L04 현장 끈 + L07 실룩 끈 → `v_recent`: L15 첫 순찰 → `v_user` 실제 사용자 질문 → `v_action`: L16 반출 관찰 | 같은 색/절단면 일치, 과거 흔적/첫 순찰 이후, 잔열/조각 존재, 사용자/반출 행위 |
| 거래 | `v_origin`: L09 광장 이름표 → `v_trade`: L18 원장 + L19 대금 쪽지 → `v_own`: L19 소유 조건 → `v_where` 취득 경위 질문 → `v_slip`: L20 상충하는 두 설명 | 같은 금액/동일 거래, 대금 수령/자기 물건 판매, 판매자/직접 반출자 |
| 증언 | `v_identity`: L17 부리의 얼굴·연속 관찰 → `v_action`: L16 초롱의 반출 관찰 → `v_link`: L16 + L17 | 얼굴/손 안의 물건, 같은 장소/같은 사건, 사건 일치/작업자의 연속성 |
| 공통 최종 방어 | 반출 입증 뒤 `h_work`: 서명된 수리 작업표 제시 → `h_scope`: L21 작업표 + L22 자재 대장 → `v_permission` 별도 허락 확인 | 수리 의뢰/개인 처분 권한, 기록 부재/행위자 입증, 반출/무단 반출 |

거래 경로의 자백은 판매 조건과 취득 설명의 모순을 플레이어가 확정한 뒤 나온다. 증언 경로는 두 증언을 모았다는 이유만으로 연결하지 않는다. 같은 수레 도움 사건을 기준으로 삼고 작업자가 바뀌지 않았다는 관찰까지 답해야 한다. 모든 경로가 수리 권한 해명을 넘어야 한다.

L21: 톡이 2일 낮 의뢰한 3번 등 덮개 점검. 지급 나사 두 개, 조각 교체·회수 예정 수량 0. L22: 광장 3 조각은 사용 중인 마을 자재, 덮개 부품과 별도 항목, 폐기·양도 기록 없음. 이 두 문서는 범인이나 시각을 단독 증명하지 않는다. 톡의 수리 의뢰 사실과 무단 반출 피해 사실은 양립한다.

## 논증의 일관성

A안을 골랐다면 `v_trace → v_recent → v_user → v_action` 전체가 필요하다. C안에서 얻은 인물 확인을 A안의 사용자 설명 대신 쓰거나, B안의 자백으로 A안의 남은 단계를 생략하지 않는다. B/C도 각자 명시된 전체 연쇄가 필요하다. 공통 수리 권한 쟁점은 선택한 연쇄를 모두 입증한 뒤 열린다.

자료는 모두 열람할 수 있다. 다른 경로의 사실을 거짓이라고 바꾸지 않는다. 그 자료로 다른 주장을 시작하려 하면 처음 내세운 논증의 어느 고리를 잇는지 묻고, 현재 연결을 입증하지 못한 제시는 오답으로 센다. 비활성 경로의 발언을 내부 호출로 제시해도 판정 단계에서 거부한다. 이전/다른 경로의 입증 상태가 섞여도 승리 조건은 현재 선택의 전체 연쇄만 본다.

논증 확정과 정식 반박 확정은 되감기 경계로 남긴다. 틀린 반박만 되감아 지우거나 같은 회의에서 논증 선택으로 되돌아가는 대신 회고의 재도전을 사용한다. 일반 저장·불러오기는 유지한다.

## 세 번의 오답

- 자료 열람, 질문, 증거창에서 취소: 무료.
- 짝 자료의 첫 유효 제시, 같은 첫 자료를 다시 확인: 아직 논증이 완성되지 않았으므로 무료. 같은 자료 두 번으로 짝이 완성되지는 않는다.
- 현재 발언에 맞지 않는 증거를 근거로 제시: 1회. 다른 발언에 유효한 증거라도 현재 발언에 틀리면 센다.
- 유효한 증거 뒤 해석 선택: 확정 전 철회 가능. 두 단계 논증도 답을 모두 선택한 다음 한 번 확정한다. 중간에 정오답을 알려 주지 않는다.
- 확정한 해석이 틀림: 논증 전체 실패, 오답 1회. 어느 단계가 성립하지 않는지 상대가 반박한다. 다른 단계의 부분 입증은 주지 않는다.
- 근거 없는 최종 결론이나 살해 의도 단정: 같은 예산에서 1회. 맞는 결론과 충분한 입증이 함께 있을 때만 승리한다.
- 세 번째 오답 즉시 이번 회의 종료. 성공 반박을 하나 해도 횟수는 줄지 않는다. 선택한 논증은 도중에 바꾸지 못한다.
- 이미 입증된 발언이나 답을 들어야 하는 질문에 자료를 보인 행동은 새 반박으로 취급하지 않는다.

재도전은 기존 Ren'Py 회의 직전 저장을 불러온다. 조사 자료, 돈, 이전 선택은 그때 상태로 돌아오고 선택한 논증, 회의 중 입증, 새 작업 문서, 오답, 결론 결과는 남지 않는다. 다시 시작하면 다른 논증을 선택할 수 있다. 결과 유지와 조사 보완 선택도 기존 회고에서 제공한다. 처음부터 조사하도록 강제하지 않는다.

## 밸런스 판단과 한계

정답 하나를 더 고르게 만드는 것만으로 난도가 보장되지는 않는다. 현재의 최소 장벽은 정확한 발언-자료 대응, 복합 논증의 동시 성립, 공통 권한 반박, 공유 오답 예산이다. 선택지는 모두 기존 부품의 24자 이내 요약으로 쓴다. 긴 정답만 찾는 방식과 자동 자백을 줄인다.

세 경로는 같은 사실 기준으로 무단 반출을 입증한다. 경로에 따라 판결의 사실을 바꾸지 않는다. 판결 뒤 처분 요구와 이후 결과는 기존 이야기 규칙으로 이어진다. Q1 실패가 톡의 이후 증언과 진엔딩을 막는 정본의 의도도 유지한다. 재도전은 그 실패를 취소하는 플레이 선택이다.

실제 초회 난도가 같다고 검증된 것은 아니다. 제작자가 정답을 아는 기능 검수로 확인할 수 있는 것은 통과 조건과 실패·복원 동작이다. 블라인드 플레이에서 경로별 첫 시도 성공률, 틀린 논점, 재도전 횟수, 포기 지점을 수집한 뒤 문구와 증거 간 거리를 조정해야 한다. 특정 경로가 쉬우면 오답 한도를 줄이기보다 그 경로의 관찰 연결을 보강한다.

구현: `game/systems/room13_q1_difficulty.rpy`, rules 3. 이미 rules 1/2로 진행하던 저장은 기존 규칙을 유지한다. 새 게임에서 활성화된다. 자유문장 의미 판정기가 아니라 작가가 설계한 발언·증거·해석 조합의 판정이다.
