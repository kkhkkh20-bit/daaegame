# 첫 사건의 여러 승리 논증 설계

후속 난도 규칙과 정확한 분기 조건은 [0.19.60 설계](Q1_HARD_ARGUMENTS.md)를 따른다. 기존 rules 2 저장에는 아래 규칙을 유지한다.

2026년 10월 18일 설계. 설계 기준 실행본은 main d87aea1b, 0.19.57이다. 0.19.58 구현은 `game/systems/room13_q1_arguments.rpy`에 있다. 아래는 의도와 제작 명세이며, 실제 관찰·검증 결과는 해당 판의 검수 기록으로 구분한다.

구현 자료 ID는 L15(첫 순찰), L16(반출 관찰), L17(부리 목격), L18(원장), L19(대금 쪽지), L20(회의의 정정 전 설명)이다. 초롱의 두 관찰은 서로 다른 질문과 자료로 분리했다. 세 논증은 같은 회의에서 조합할 수 있고, 사용하지 않은 경로의 반박 완료를 요구하지 않는다.

이번 구현은 Q1의 작가가 정한 발언·자료 조합을 판정한다. 아래 자료 구조는 설계 개념이며 범용 자유문장 판정기나 증언 수정 시 모든 의존성을 자동 재계산하는 엔진까지 만든 것은 아니다. 현재는 관찰 범위와 해명 변경을 명시적인 논점으로 관리한다. 회의 도중 재반박을 틀려도 이미 입증한 사실은 남지만, 최종 결론을 확정하면 해당 시도의 결과가 정해진다. 실제 검증 범위는 [0.19.58 검수 기록](../reviews/q1-multiple-arguments-20261018/README.md)에 남긴다.

첫 사건 「등 도둑」에서 다른 자료와 논리로 같은 승리를 얻는다. 현장 물증, 거래 추적, 교차 증언 중 하나의 완성된 논증으로 톡의 누명을 벗기고 실룩의 절도를 밝힌다. 모든 자료를 모으거나 세 경로를 모두 수행할 필요는 없다. 조사 부족을 낮은 등급의 결말로 보상하는 구조는 이번 설계에서 쓰지 않는다.

## 1. 승리와 진실

작가의 진실은 고정한다. 우박은 측정 후 조각을 돌려놓았고, 실룩은 이후 광장 조각을 훔쳐 백 부인에게 팔았다. 다음 밤 기록실에서도 절도가 발생한다. 피코와 사서의 생사는 앞선 행동에 따른다. 회의가 이미 발생한 손실을 지우지는 않는다.

각 경로의 공통 승리는 다음과 같다.

- 톡은 완전히 석방되고 Q1 해결로 기록된다. 승리 방식에 따른 보상 차등이나 숨은 정답 경로를 두지 않는다.
- 실룩이 광장 조각을 무단으로 가져갔다는 사실을 확정한다. 살해 의도까지 입증했다고 쓰지 않는다.
- 실룩을 넘기기, 조각 반환 요구, 둘 다 요구하기라는 기존 후속 선택에 동일하게 도달한다.
- 빚의 조건을 확인했다면 어느 경로에서도 빚 정리를 요구할 수 있다. 기존처럼 이를 별도 조사 조건으로 유지하되 회의 중 실룩의 빚 진술에서도 조건을 확인할 기회를 준다.
- 톡의 후속 증언을 부탁할 자격도 같다. 승리 즉시 `witness:tok`를 자동 지급하지는 않는다.

범인 지목에 필요한 입증과 승리 뒤 처분 선택을 분리한다. 서로 다른 공략이라는 이유로 창고 반환 선택을 숨기지 않는다. 창고를 미리 조사하지 않은 경로는 범행 확인 후 실룩의 판매처 진술과 공개 현물 확인으로 같은 선택에 도달한다. 이 확인은 승리에 따른 장면이며, 다시 지도를 돌며 필수 물건을 수집하는 과제가 아니다.

플레이어가 처음에 우박을 의심했어도 나중에 근거를 정리하면 승리할 수 있다. 과거의 잘못된 가설은 영구 오답 깃발이 아니다. 그러나 무관한 사실을 많이 제출하거나 목소리를 높였다는 이유로 승리하지는 않는다.

## 2. 기존 구조에서 바꿀 부분

개정 전 Q1은 필수 진술 다섯 개의 반박 완료와 결론을 요구한다. s4의 기록실 피해까지 광장 사건의 필수 조건이고, s5는 L04와 L07의 끈 대조에 의존한다. 이미 복수 허용 자료, 일부 근거에 대한 응답, 두 자료 연결과 되묻기 기능은 있으므로 이를 확장한다.

| 현재 조건 | 새 조건 |
|---|---|
| 모든 필수 진술 반박 | 제출한 결론에 필요한 사실과 관련 반론 해결 |
| 특정 증거로 지정된 문장을 반박 | 같은 사실을 뒷받침하는 서로 다른 근거를 인정 |
| 다섯 항목을 모두 처리해야 결론 | 완성된 논증이 있으면 결론, 다른 논점은 선택적으로 계속 |
| 자료가 충분한가를 내부 정답 목록으로 판단 | 자료의 출처, 관찰 범위, 사건 시점, 주장 범위를 판정 |
| 두 번 틀리면 자동 힌트 | 상대의 구체적인 반론은 기본, 조사 힌트는 선택 |

두 가지 기존 표현도 함께 정비한다.

1. L06의 ‘미지근했다’만으로 조각의 존재나 절도 시각을 확정하지 않는다. 잔열일 수 있다. 새 증언에서 직접 본 내용을 구분해 얻는다.
2. 4일 아침 L08의 ‘어젯밤’은 3일 밤이다. 광장 절도가 일어난 2일 밤의 알리바이나 결정적 증거로 사용하지 않는다. 기록실 사건에 관한 질문과 동기 이해에는 남긴다.

기존의 탁본 L14는 너울의 단정에 이의를 제기하는 근거로 유지한다. 탁본만으로 범인의 신원이나 범행 시각을 만들어 내지 않는다. L10/L11의 기록실 피해는 수사 확대와 예방·책임 논점으로 남기되 광장 절도의 해결에 반드시 요구하지 않는다.

## 3. 새 사실의 시간표

아래 시간표와 목격은 이번 설계가 추가하는 작가용 설정이다. 기존 대본에서 이미 확인된 사실과 구분한다. 화면에 분 단위 시각을 새로 도입하지 않고 관찰 순서로 비교한다.

| 구간 | 고정할 사건 |
|---|---|
| 2일 밤 | 우박이 측정하고 조각을 돌려놓는다. |
| 그 뒤 밤 첫 순찰 | 초롱이 흔들리는 받침을 바로잡으려고 뚜껑을 열어 조각의 존재를 직접 확인한다. 뚜껑 틈에는 끈이 없다. |
| 2일 늦은 밤 | 실룩의 작은 짐수레 바퀴가 광장 턱에 걸린다. 부리가 풀어 주며 얼굴을 확인한다. 이 만남은 두 목격의 공통 사건 표지가 된다. |
| 직후 | 실룩이 3번 등에서 조각을 꺼낸다. 초롱은 반대쪽에서 빛나는 조각이 들려 나오는 동작과 등이 꺼지는 것을 본다. 얼굴은 보지 못한다. 부리는 실룩이 그 자리에 서서 작업하는 전후를 보지만 뚜껑과 몸에 가려 손 안 물건은 보지 못한다. |
| 3일 동튼 뒤 | 초롱은 다음 순찰에서 등을 확인해 조각이 없음을 보고 피코를 발견한다. 밤에는 수리 작업인 줄 알고 지나쳤다. 반출 목격과 발견 사이에 추위에 노출된 시간이 있으며, 발견 후 구조를 늦추지 않는다. |
| 3일 해 질 녘 | 실룩이 광장 조각을 백 부인에게 판다. 기존 ‘해 질 녘’ 진술을 날짜까지 명확히 한다. 그날 밤 기록실 절도와 구분한다. |
| 3일 밤 | 기록실 절도. 기존 사서 분기와 L08의 귀가 진술은 이 밤에 속한다. |
| 4일 오전과 오후 | 현재 회의 가능 시간 안에 조사와 회의가 진행된다. |

초롱의 목격은 구조를 외면하는 장시간 방관으로 만들지 않는다. 부리는 2일 밤 수리점 공구를 치우고 돌아가는 길에 수레를 도왔다. 두 사람의 실제 시야는 대사 배치와 배경으로 검수한다. 서로 다른 사람을 같은 사람으로 오인할 공백이 있으면 C 경로의 결정적 증언으로 채택하지 않는다.

## 4. 추가 자료와 얻는 과정

아래 Q1N 코드는 설계용이다. 구현 때 사용하지 않는 정식 ID를 배정한다. 새로운 인물은 필요 없다.

| 자료 | 획득 계기와 내용 | 증명하지 못하는 것 |
|---|---|---|
| Q1N1 초롱의 순찰 상세 | L06을 들은 뒤 ‘안도 보셨습니까?’를 물어 첫 순찰의 조각과 빈 뚜껑 틈, 이후 조각이 꺼내진 모습과 빈 등을 구분해 기록. 플레이어가 질문해야 획득 | 범인의 얼굴, 빌린 끈의 사용자, 살해 의도 |
| Q1N2 부리의 밤 목격 | 수리점에서 그날 밤 일을 묻거나 수레 이야기를 제시. 바퀴를 풀어 준 상대의 얼굴, 실룩이 등 앞에서 작업한 전후, 현장에 다른 사람이 없었던 관찰 범위 | 가려진 손 안의 물건, 창고 판매 |
| Q1N3 백 부인의 매입 원장 | L09를 직접 제시해 취득 근거를 요구하면 부인이 ‘정당한 매입’을 입증하려 내놓음. 3일 해 질 녘, 조각 한 점, 대금, 거래번호, 수령 표시 | 수령 표시만으로 판매자 신원, 직접 절도 |
| Q1N4 실룩의 대금 쪽지 | 돈·빵·빚의 실제 대화 계기로 실룩에게 정산 내역을 요청. 별도 동의를 받아 확인. 원장과 같은 거래번호·금액, ‘자기 소유 조각’으로 판다는 거래 조건 | 원장과 대조하지 않은 물건 동일성, 그 조건이 사실이라는 보장 |
| Q1N5 회의에서 정정된 실룩의 진술 | 플레이어가 실제 반박으로 설명의 모순을 드러낸 뒤에만 발생. 현장 작업 또는 거래를 인정하는 말과 최종 반출 자백을 별개 항목으로 보존 | 일부 인정만으로 절도나 살해 의도를 확정하는 것 |

Q1N1은 한 자료에 관찰 단위를 나눠 담는다. 처음에는 순찰 확인만 듣고, 재질문하면 반출 동작을 듣는다. 파일 하나를 가졌다고 모든 관찰을 자동 사용하지 않는다. Q1N2도 ‘얼굴을 직접 봤는가’, ‘같은 순간인가’, ‘자리를 비웠는가’를 직접 물어 확인해야 완성된다.

새 질문은 사건·자료에서 생긴 의문으로 연다. 처음부터 ‘범인의 목격자를 찾는다’ 같은 정답 안내를 붙이지 않는다. Q1N3은 부인이 이름을 몰랐다는 기존 진술과 양립하도록 기명 장부가 아닌 거래번호와 수령 표시다. Q1N4의 존재와 조회 기회는 빵 봉지·빚 이야기에서 자연스럽게 드러내고, 주머니 수색이나 아이 협박을 요구하지 않는다.

두 회계 문서의 번호가 같다고 독립된 두 증인의 신뢰로 계산하지 않는다. 같은 거래를 연결하는 자료다. 백 부인 혼자 쓴 원장과 실룩이 보관하는 대금 쪽지의 대조는 사후 말 바꾸기를 제한하지만, 물건 출처는 별도로 확인해야 한다.

## 5. 세 가지 완성 가능한 논증

경로 이름은 작가용이다. 게임에서 A/B/C를 고르거나 직업처럼 잠그지 않는다. 플레이어는 지금 공격할 발언과 주장할 내용을 고른다.

### A 현장 흔적에서 실룩의 행동으로

준비 예시: L04, L07, Q1N1의 첫 순찰과 반출 관찰. 창고 조각이나 거래 원장은 없어도 된다.

1. ‘누구나 쓰는 끈’에 두 뜯긴 끝의 대조를 제시한다. 성립하는 사실은 동일한 끈에서 나왔다는 것까지다.
2. 실룩은 ‘전에 수리를 도왔을 때 남았겠지’라고 반박한다. Q1N1의 첫 순찰에서 틈이 비어 있었다는 관찰로 사건 전 흔적이라는 설명을 무너뜨린다.
3. ‘끈을 빌려 썼을 수도 있다’는 너울의 반론에는 실룩에게 당시 사용자를 묻는다. 실룩은 부리가 수레를 도운 사실을 알고 있어 자신이 현장에 있었다는 사실까지 부인하지 않고 ‘내가 올라갔소. 느슨한 뚜껑을 고쳐 줬을 뿐이오’로 범위를 좁힌다. 이것은 현장 작업 인정이며 절도 자백은 아니다. Q1N2를 이미 얻었다면 목격으로도 같은 사실을 입증할 수 있다.
4. Q1N1의 반출 관찰과 동튼 뒤 확인한 빈 등을 연결해 ‘뚜껑만 고쳤다’를 반박한다. 여기서 관찰한 사람이 누구인지 연결하는 책임은 1~3단계가 담당한다.
5. 실룩은 자신이 조각을 꺼냈음을 인정한다. 공공 등에서 가져갈 권한이나 반환 계획이 없었다는 확인 뒤 범행을 확정한다.

끈을 안 빌렸다는 사실을 보이지 않는 정답으로 취급하지 않는다. 본인의 사용 인정도 없고 Q1N2도 없다면 ‘실룩의 끈’에서 ‘실룩의 행동’으로 진행할 수 없다. 재질문으로 얻는 인정의 발동 조건과 대사는 고정하며, 인벤토리를 읽고 더 강한 거짓말을 새로 만들어 내지 않는다.

### B 거래를 추적해 거짓 설명을 무너뜨리기

준비 예시: L09, Q1N3, Q1N4. 현장 끈과 두 목격은 없어도 된다.

1. L09로 창고 물건이 광장 조각임을 밝힌다. 이름표 하나가 낡았을 가능성을 따지면 톡이 실제 관리 장부와 대조해 현재 설치 물건임을 확인한다. 회의 출석자인 톡의 대답이며 갖고 있지 않은 L01을 소지한 것으로 만들지 않는다.
2. 백 부인은 ‘얼굴은 모르지만 값을 치렀다’고 말한다. 두 정산 기록을 대조해 판매자가 실룩임을 확인한다. 부인의 얼굴 기억을 갑자기 선명하게 바꾸지 않는다.
3. 실룩은 ‘돈을 대신 받아 줬소’라고 반박한다. 쪽지의 자기 소유 확인 문구를 제시하면 판매를 인정하지만 ‘톡에게 버리는 조각이라고 받았다’고 설명한다.
4. 플레이어는 ‘훔친 사람이군요’와 ‘어디서 받았습니까?’를 구별해 선택한다. 앞의 단정은 아직 성립하지 않는다. 뒤의 질문에는 ‘수리점에서 건네받았다’는 답이 고정된다.
5. 톡에게 해당 날짜의 반출·폐기 처리를 묻는다. 현재 장착 중인 조각을 폐기한 적이 없다는 답과 실룩이 스스로 말한 등 내부의 반출 과정이 충돌한다. 여기서 실룩의 말실수 대사를 사용한다: ‘받침에 걸려서 끄집어내느라…’. 이것만으로 절도를 확정하지 않는다.
6. 아빠가 ‘수리점에서 받았다면서, 왜 등에서 꺼낸 이야기를 하십니까?’라고 모순을 지적한다. 실룩이 해당 조각을 직접 꺼내 팔았다고 정정한다. 광장 조각의 현물과 양쪽 거래 기록이 자백의 외부 근거가 된다.

이 경로는 증거만으로 직접 절도를 연역하는 경로가 아니라, 검증된 거래 사실로 거짓 설명을 추궁해 새로운 증언을 얻는 경로다. 원장만 제출하면 자동 자백하는 방식은 금지한다. 3~6의 범위 구분과 모순 지적을 플레이어가 수행해야 한다. 자백 전에 ‘판매자이므로 도둑’이라고 최종 확정하면 반격받는다.

### C 서로 다른 시야의 증언 연결하기

준비 예시: Q1N1과 Q1N2의 상세 진술. 두 끈, 창고 조각, 거래 기록 없이 가능하다.

1. 초롱은 ‘꺼내는 건 봤지만 얼굴은 못 봤다’고 말한다. 이 증언만으로 실룩을 지목하면 실패한다.
2. 부리는 ‘실룩 씨 얼굴을 봤지만 손 안은 못 봤다’고 말한다. 이것만으로 절도를 주장해도 실패한다.
3. 두 사람이 같은 상황을 봤는지 수레 바퀴가 걸린 순간과 부리가 도운 전후로 연결한다. 단순히 ‘둘 다 밤’이라는 이유로 합치지 않는다.
4. 너울이 ‘도중에 다른 사람이 올라갔을 수 있지’라고 반박한다. 부리에게 관찰 중 끊긴 구간을 묻는다. 얼굴 확인부터 실룩이 내려올 때까지 위치를 지켜봤으며 몸에 가려진 것은 손 안 물건이라는 범위를 확인한다.
5. 초롱의 반출 동작·동튼 뒤 빈 등과 부리의 인물·관찰 연속성을 결합해 실룩의 반출을 확정한다. 실룩은 ‘식은 조각인 줄 알았다’고 변명한다. 그 말은 물건을 가져갈 권한도, 의도적 살해의 증거도 아니다.

증언 두 개라는 숫자가 승리를 만드는 것이 아니다. 같은 사건, 신원, 행동, 관찰 공백이라는 서로 다른 문제를 모두 해결해야 한다. 부리의 증언은 아빠나 초롱에게 들은 말을 반복하는 내용이면 안 된다. 두 증언의 시간과 장소가 연결되지 않았으면 결론은 아직 미완성이다.

## 6. 섞어서 싸워도 인정하기

경로 전체를 외운 순서로 수행했는지 검사하지 않는다. 예를 들어 A로 시작해 끈 대조와 첫 순찰로 최근 현장 접촉을 입증한 뒤, C의 부리 목격으로 끈을 빌렸을 가능성을 해소하고 초롱의 반출 관찰을 붙이면 성공한다. 실룩에게 현장 사용 인정을 반드시 다시 받아야 할 이유가 없다.

B를 진행하다 정산 쪽지를 못 얻었어도 부리와 초롱의 진술을 완성하면 그 근거로 범행을 확정한다. 이미 밝힌 창고 출처는 공통 후속 장면에서 그대로 인정한다. 반대로 ‘갈색 끈’, ‘늦은 귀가’, ‘빚이 있다’를 섞어도 신원과 행동의 연결이 없으므로 성공하지 않는다.

한 주장을 철회해도 다른 논점에서 성립한 사실을 지우지 않는다. ‘실룩이 죽이려 했다’를 철회하면 절도 입증은 남는다. 근거였던 증언 자체가 정정됐다면 그 증언에 의존하는 추론만 다시 계산한다.

## 7. 회의의 실제 대화 예시

아래는 B 경로 중 일부의 신규 대사 초안이다. 선택지는 아빠가 할 말로 쓴다.

> 실룩: 돈을 받아 왔다고, 그 물건까지 내 것이 되오?
>
> 선택: ‘이 쪽지에도 그렇게 썼습니까?’ / ‘그러니 훔친 사람이군요.’ / ‘그 부분은 다시 보겠습니다.’
>
> 아빠: 부인의 원장과 번호가 같습니다. 여기에는 자기 조각을 판다고 적혀 있고요. 누구의 심부름이었습니까?
>
> 실룩: …톡이 버린다는 걸 받았소.
>
> 선택: ‘어디에서 받으셨습니까?’ / ‘톡 씨, 폐기한 조각입니까?’
>
> 실룩: 수리점에서. 손에 쥐여 줬소.
>
> 톡: 그 조각은 3번 등에 넣어 둔 거예요. 버린 적 없어요.
>
> 실룩: 버릴 거랬잖소. 받침에 걸려서 끄집어내느라 손이…
>
> 선택: ‘수리점에서 받으셨다면서요.’
>
> 실룩: …
>
> 아빠: 직접 등을 열고 꺼냈습니까?
>
> 실룩: …내가 꺼냈소. 그걸 팔았소.

‘그러니 훔친 사람이군요’를 고르면 실룩은 ‘팔러 갔다는 것과 등을 열었다는 건 다르오’라고 반박한다. 최종 확정이 아니라면 한 번의 과장으로 회의를 즉시 끝내지 않는다. 원래 문제로 돌아가 연결을 보완할 수 있다.

질문을 고르는 것만으로 답의 진위를 게임이 인증하지 않는다. ‘톡에게 받았다’는 주장도 다른 주장과 동일하게 자료·증언으로 검토한다. 말실수 장면은 논리로 획득한 진전이며 임의 확률이나 친밀도 수치로 열지 않는다.

## 8. 판정 로직

핵심 자료 구조는 자료, 관찰 사실, 플레이어 주장, 반론, 공개된 진술 이력이다. 모든 상태는 현재 회차와 시도에 속한다. 작가용 진실 데이터는 대사 일관성 검사용이며 플레이어 주장의 자동 채점 근거로 직접 읽지 않는다.

```text
Evidence: id, source, event, observed_facts, acquired_parts
Testimony: speaker, statement_id, event, firsthand, observation_gap
Argument: claim, submitted_supports, established_facts, unresolved_challenges
Rule: prerequisites, establishes, challenges, dialogue
```

같은 증언을 복사한 기록은 같은 출처다. 인물의 평판 점수로 물증의 결손을 대신하지 않는다. 신규 규칙은 Q1에만 적용하고 다른 회의의 기존 판정은 유지한다.

작가용 논증 규칙의 핵심은 다음과 같다.

```text
same_rope := L04 + L07의 실제 대조
recent_trace := same_rope + Q1N1의 첫 순찰 확인
actor_at_lamp := Q1N2의 신원·연속성 확인 OR 실룩의 현장 사용 인정
removal_seen := Q1N1의 반출·동튼 뒤 빈 등 확인
same_event := 두 관찰의 공통 사건 표지와 순서 연결
sale_link := L09 출처 확인 + Q1N3/Q1N4 거래 대조

observed_removal := actor_at_lamp AND removal_seen AND same_event
corroborated_admission := 반출 자백 AND (recent_trace OR sale_link)
siluk_removed := observed_removal OR corroborated_admission

case_ready := siluk_removed AND 무단 반출 확인
             AND 톡에게서 정당하게 받았다는 반론 해결
win := case_ready AND 플레이어의 적정 범위 결론 확정
```

A에서 현장 사용 인정을 받을 때는 작업 시각까지 물어 같은 반출 사건과 연결해야 한다. ‘언젠가 올라갔다’는 말로 `same_event`를 만들지 않는다. B에서는 반출 자백과 현물·거래의 교차 확인이 이를 대신한다. C에서는 두 목격의 사건 표지를 플레이어가 연결한다.

무단 반출 확인은 ‘톡이 아니라면 불법’이라는 숨은 세계 규칙이 아니다. 회의에서 유지보수 책임자인 톡에게 현재 설치 상태와 교체·폐기 지시를 확인하고, 실룩에게 받은 허락·반환 여부를 질문한다. C에서 아직 판매 사실을 모르면 범행 확인 뒤 판매처를 따로 묻는다. 공개된 반론에 답할 자료나 진술이 없으면 미해결로 남긴다.

출력은 다음 네 종류로 구분한다.

| 판정 | 게임의 반응 |
|---|---|
| 관련 없음 | 무엇을 따지는 중인지 상대가 짧게 응답 |
| 일부 성립 | 인정한 사실을 보존하고 남은 반론을 말함 |
| 논증 성립 | 상대가 해당 주장을 철회하거나 제한된 다음 설명으로 이동 |
| 결론의 범위 초과 | 입증한 사실은 보존하고 의도·다른 사건까지 확장한 부분만 반박 |

결론 준비는 보유 자료만으로 자동 켜지지 않는다. 플레이어가 실제로 연결한 논증을 평가한다. 인벤토리에 정답 재료가 있다는 이유로 아빠가 대신 추리하거나 조사하지 않은 목격을 인용하면 안 된다.

기존 `r13_debate_ready`, 결론 지목, `r13_debate_answerable`과 막힘 판단은 Q1에서 같은 판정기를 읽는다. 투표·반응·복기도 그 결과를 읽으며 각각 별도의 정답 목록을 유지하지 않는다. 복수 근거가 있으면 가장 먼저 들어온 증거 ID 하나가 아니라 검증된 근거 묶음을 저장한다. 순환 논증으로 새 사실을 만들지 않는다.

## 9. 긴장과 반복 플레이

회의 입장을 조사량으로 막지 않는다. 입장 전에 보여 줄 것은 톡에게 제기된 혐의, 예정된 처분, 현재 기한이다. 준비도 백분율, 남은 증거 수, ‘이 경로면 승리 가능’ 표시는 없다.

되묻기와 자료를 펼쳐 보는 행동은 무료다. 대화 중 근거를 제시했다가 반박받으면 계속 보완할 수 있다. 별도의 ‘이 결론으로 회의를 마치겠습니다’를 확정하면 그때의 논증으로 성공·실패를 결정한다. 확정 전에는 회의로 돌아갈 수 있지만, 확인 문구가 정답 여부를 알려 주지는 않는다. 새로운 신뢰도 체력이나 오답 횟수 제한은 이번 안에 넣지 않는다. 같은 오답 반복으로 힌트가 자동 해금되거나 유리한 진술이 누적되지는 않는다.

새로운 친밀도 게이지, 무작위 설득, 모든 대화의 시간 비용은 추가하지 않는다. 이번 1차 설계가 만드는 전략은 공격할 주장, 근거의 연결, 주장의 범위, 반론에 대응하는 순서다. 자료를 전부 수집하는 플레이는 여전히 가능하다. 이를 제한하는 자원 배분 전략까지 완성했다고 부르지는 않는다.

후속 확장으로 동시 사건을 넣는다면 반드시 게임 안에서 사전에 시간을 알리고, 먼저 간 쪽이 무엇을 놓치는지 납득할 수 있어야 한다. Q1의 새 논증이 재미있는지 확인하기 전에 증인을 임의로 사라지게 하거나 정답 자료를 파괴하지 않는다.

패배 후 기본 복기는 ‘실룩의 거래는 확인했지만 직접 가져갔다는 설명은 확정하지 못했다’처럼 해당 시도에서 실제로 남긴 논점을 쓴다. 다른 승리 경로 전체와 증거 위치는 공개하지 않는다. 선택적 힌트와 현재의 조사/회의/결과 저장 복원은 유지한다.

## 11. 구현 단위와 검수 기준

1. 위 시간표를 실행 대본에 반영하고 Q1N1~4의 획득 장면·부분 관찰·질문 해금을 만든다. 초롱의 시야와 부리의 연속 관찰을 대사와 장면에서 먼저 검수한다.
2. Q1 한정 논증 판정기를 순수 함수로 만든다. 기존 `pair`, `soft`, `press`를 연결하고 실행 순서·오버라이드 지도를 확인한다.
3. A와 B의 반박·재반박을 먼저 실제 플레이 가능한 길로 완성한다. C는 두 증언의 교차 검수 후 추가한다. 설계의 목표는 세 길이며 첫 구현을 두 길로 나눠 검증하는 순서다.
4. 공통 결론, 창고 확인, 처분 선택, 회고, 증언 부탁을 연결한다. 복기에서 미사용 경로를 미해결 필수 항목으로 표시하지 않는다.
5. 각 경로와 혼합 경로를 실제 입력으로 플레이하고 대사 전문·스크린샷·도달 상태를 저장한다. UI 외형은 기존 공통 부품을 사용한다.

필수 수용 사례:

- L04 또는 L07이 없어도 B와 C로 같은 승리에 도달한다.
- L09나 거래 서류가 없어도 A와 C로 같은 승리와 반환 선택에 도달한다.
- 피코와 사서가 모두 사망한 상태에서도 세 경로의 조사와 회의가 가능하다. 사서 구조가 승리의 우회 필수가 되지 않는다.
- 초롱의 잔열 진술만으로 절도 시각을 확정할 수 없다.
- 부리의 얼굴 확인만으로 절도를 확정할 수 없다.
- 두 목격이 동일 사건이라는 연결 없이 C가 완성되지 않는다.
- 거래만 입증한 상태에서 범인 지목은 기각되지만 그 거래 사실은 보존된다.
- A의 현장 사용 인정 대신 부리의 확인을 사용해도 통과한다. 제시 순서 때문에 같은 논증이 다르게 채점되지 않는다.
- 빚·늦은 귀가·흔한 끈만 모은 조합, 반복 제시, 정정 전 증언과 정정 후 증언의 이중 계산은 실패한다.
- 실룩의 절도를 입증한 뒤 살해 의도 주장을 철회해도 기존 입증은 남는다.
- 완성 논증 한 개로 결론을 확정하면 다른 경로 미진행 때문에 패배하지 않는다.
- 어느 승리 경로든 동일한 후속 선택에는 동일한 보상·톡 증언 자격·수레/긴 밤 결과가 나온다.
- 회의 재시도와 새 회차에서 이전 주장·보상·획득 관찰이 누적되지 않는다.
