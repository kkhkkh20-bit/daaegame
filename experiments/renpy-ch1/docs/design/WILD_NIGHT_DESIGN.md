# 불타는 밤 — 집단 야생화 설계안 (2026-10-24, 시안)

소유자 지시(2026-10-24): "그 시나리오 중에 주민 대부분이 야생화가 되어서 서로 죽고 죽이는 상황도 나왔으면 해", "야생화 되어서 집들이 불타고 좀비마을처럼 공포에 떠는 그 상황을 만들고 싶어". 앞서 "무서운 결과는 최악까지 허용".
상태: 소유자 결정 완료(2026-10-24, 세 항목 모두 추천안). 사실 대조 뒤 지시서로 만든다.

결정: (1) 가설 회의와 제단 회의를 둘 다 졌을 때만 터진다. (2) 12~13일 전조 대화 + 14일 밤 탈출 장면 + 결말. (3) 앞 행동이 다 빠지면 다람·엄마도 죽을 수 있다.

## 1. 게임에 이미 있는 사실 (새로 지어내지 않는 부분)

| 사실 | 근거 |
|---|---|
| 꺼낸 아르카 곁에 오래 있던 사람부터 날짜·이름을 잊는다(야생화) | `D11 NW_H0_W_01`, 가설 회의 정답 「꺼낸 아르카 곁에 오래 있던 사람부터 무너진다」(`room13_v111_days1114.rpy:545`) |
| 증상: 말이 거칠어짐, 가족을 못 알아봄, 밤에 이상하게 돌아다님 | `room13_episodes.rpy:156` 너울 |
| 야생화가 온 사람이 사람을 문다 | 4~5일 무쇠가 돌목을 묾(`D05 S03_L0016`) |
| 요즘 캐는 안쪽 돌이 더 세다 | `EPISODES.md` 사실 요약 |
| 밤새 아르카등을 켜 두는 큰 집 아이들에게만 표시가 있다 | `D11` 학교 침상 목록 |
| 등을 끈 사흘 동안 새로 앓은 사람이 없다(너울의 숫자) | `D11` 가설 회의 근거 줄 |
| 시설 기록: 「꺼내어 불을 켜지 말라. 곁의 말이 무너진다」 | `D14 NW_A2_W02` |
| 장작 창고가 탔다 — 여관 장작은 이틀 치 | 7일 아침(0.20.24 동기 줄) |

즉 「돌을 더 태우면 더 많이, 더 빨리 무너진다」는 이미 게임의 규칙이다. 집단 야생화는 그 규칙을 끝까지 밀어붙인 판이다.

## 2. 왜 그 판에서만 터지는가 (인과)

1. **11일 가설 회의에서 진다** → 마을은 「옮는 병」·「아르카가 부른다」 같은 틀린 결론을 쥔다. 등을 끄지 않는다.
2. **장작이 없다**(6~7일 창고 불) → 집마다 난로까지 아르카로 땐다. 무서우니 밤새 등을 더 켠다. 「옮는 병」이라 믿으면 앓는 사람을 집 안에 가두고 문을 잠근다 — 돌 곁에 더 오래 둔다.
3. (선택, 새 설정) **13일 수레가 떠난 뒤** → 마을이 믿던 「한 사람이 열흘을 산다」가 무너졌다고 느낀 사람들이 남은 돌을 한꺼번에 꺼내 땐다.
4. **14일 제단 회의에서도 진다** → 마지막으로 등을 끌 기회가 사라진다. 그날 밤 터진다.

실무 의견으로는 1과 4 둘 다 졌을 때만 터지게 하는 것이 맞다. 하나만 져도 터지면, 첫 판 대부분이 이 결말로 가서 「얼어붙은 마을」·「남은 사람들」 같은 다른 결말을 볼 일이 거의 없어진다.

## 3. 장면 — 「불타는 밤」

좀비 공포의 문법(조용한 이상 → 소리 → 아는 얼굴이 낯설어짐 → 갇힘 → 탈출)을 따르되, 이 마을의 말과 물건으로만 그린다.

**전조(12~13일, 가설 회의 진 판에만, 아빠가 묻고 상대가 답하는 짧은 대화)**
- 12일 학교: 침상 표시가 늘었다. 아빠가 「어제보다 많습니까?」 → 선생님 「큰 집에서 셋이 더 왔어요. 등을 끄라니까 다들 무서워서 못 꺼요.」
- 13일 아침 여관: 밤새 복도를 걷는 발소리. 나비 「옆방 손님이 제 이름을 몰라요. 사흘 묵은 분인데.」
- 13일 광장: 굴뚝마다 푸른 아르카 불빛. 판돌 「장작이 없으니 다 돌을 때지. 돌이라도 있어야 겨울을 나오.」 아빠(생각): 가설 회의에서 말하려던 것이 저거였다.

**밤(14일 제단 회의에도 진 판)**
1. 여관 방. 다람이 깬다. 창밖 큰 집 쪽이 붉다. 아르카 난로가 넘어져 불이 붙었다.
2. 복도. 아는 얼굴(예: 도토, 나비)이 아빠를 못 알아본다. 이름을 불러도 늦게 돌아본다(11일 선생님 말과 같은 증상).
3. 광장. 불 끄러 나온 사람과 야생화가 온 사람이 뒤엉킨다. 서로 문다. 누가 누구를 쳤는지 아무도 모른다(13일 군중 장면의 말투를 잇는다).
4. 탈출. 아빠의 목표 「셋이 나간다」가 그대로 행동이 된다 — 엄마가 어디 있는지, 마차(까로·톡의 축)가 굴러가는지, 다람의 손을 놓지 않는지.

**결말 「불타는 밤」(가칭)** — 판정 순서는 「남겨진 이름」 바로 다음, 「얼어붙은 마을」 앞.
- 가족이 어떻게 되는지는 앞의 행동으로 정한다(새 메뉴로 고르지 않는다 — 분기표 「메뉴 → 행동 판정」 방향과 같게).
  - 톡이 살아 축이 고쳐졌고 엄마와 합류했다 → 셋이 불타는 마을을 뒤로 하고 고개로(그래도 마을은 잃음).
  - 둘 중 하나가 빠졌다 → 한 사람을 두고 나가거나, 셋이 13호실에 숨어 날이 밝기를 기다린다.
  - 둘 다 없다 → 최악. (잔혹도는 소유자 결정, 아래 4.)

## 4. 소유자가 정할 것

1. **터지는 조건**: (추천) 가설 회의와 제단 회의를 둘 다 졌을 때 / 가설 회의만 져도.
2. **장면의 크기**: (추천) 14일 밤 짧은 탈출 장면(조사·이동 몇 번) + 결말 / 결말 화면 글만.
3. **가족 최악의 끝**: 다람이나 엄마가 죽을 수 있다 / 가족은 살고 마을만 무너진다.

## 5. 넣기 전에 확인할 것 (사실 대조)

- 7일 장작이 탔다는 사실이 모든 경로에서 같은지(꼬미 생존 판 포함).
- 가설 회의 진 판의 12~14일 기존 대사 가운데 「등을 껐다」·「새로 앓은 사람 없다」처럼 전조와 부딪치는 줄이 있는지.
- 이미 죽거나 수레로 떠난 인물을 밤 장면에 세우지 않기(`departed:`, `r13_nw_dead()`).
- 진엔딩 조건(가설·제단 승리)과 겹치지 않음 — 이 판은 정의상 진엔딩이 불가능하다.
