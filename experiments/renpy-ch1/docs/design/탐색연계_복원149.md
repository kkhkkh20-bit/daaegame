# 1부 탐색 연계 복원 149

2026-11-10. [원안 전 항목 대조](기존기획_복원대조_20261110.md)를 바탕으로 시장의 물건과 주민에게 배운 방법을 다른 현장에서 사용하는 첫 연결을 구현한다. 기존 주민 생활 연쇄는 유지한다.

## 이번 실행 경로

| 시작 | 플레이어가 직접 하는 일 | 다른 곳에 남는 쓰임 |
|---|---|---|
| 2~7일 안전한 자유 방문의 장터·물자 가게 | 실제 있는 은호에게 사용 허락을 구한다. 남은 끈은 받고, 표준추는 빌려 쓴 뒤 돌려줄 수 있다. | 기존 저장의 물품 소유권을 이어 쓴다. 돈·가격·수고비는 사용하지 않는다. 현장의 ‘물품’에서 고르고 사용할 곳을 누른다. |

| 가게 저울 | 빌린 표준추를 올리고 접시·조정부를 살핀다. 가게 밖으로 나갈 때 자기 추를 회수한다. | 실제 은호에게 다시 재 달라고 해야 눈금 정정과 영점을 확인하는 방법이 남는다. 표준추는 재사용한다. |

‘관찰한 기억’과 ‘실제로 준비한 물건’을 구분한다. 매듭 방법만 알거나 끈만 가지고 있어서는 새 등 고정 경로가 열리지 않는다. 초롱에게 남은 끈을 얻어 고정하던 기존 무료 경로도 유지한다. 물품을 선택한 상태로 필수 대화·필수 물건·침대를 눌러도 기존 본편 진행을 막지 않는다.

수고비·사례금·감사 할인은 지급하지 않는다. 물품은 실제 주민에게 받거나 빌리며, 도움의 결과는 배운 방법·관계·현장의 변화로 남긴다.

관찰은 범인 지목을 대신하지 않는다. 접시 높이 차이와 나사 자국만으로 추의 정확한 질량·손댄 사람·고의 조작을 확정하지 않는다. 은호의 재계량은 현행 우박의 온도 측정이나 백 부인의 장부 수사를 대체하지 않는다. 구 `scale_rigged`, `shop_discount`, 옛 증거 번호를 활성화하지 않는다.

## 보존할 연결

피코의 실제 식당 입실과 초상, 깡통·학교 자리·아이들 실제 인수, 판돌의 숟가락→문고리 핀→부리의 손질→집 수리, 집게 대여→13호 돌 처리, 톡의 빗장 수리는 이미 현행에 연결되어 있다. 같은 기능을 새 의뢰로 겹쳐 만들지 않는다. 7일 낮의 준비와 1부 이후의 결과를 구분한다.

## 다음 복원 순서

1. **학교·식당의 대체 조달과 부탁 회수.** 나비·도토의 실제 자리와 운반, 보리의 화재 뒤 행동을 연결한다. 누구에게 부탁만 했다고 아이들이 이동하거나 인수가 끝나지 않도록 한다.
2. **공구의 재사용과 물건 기록 통합.** 현재 대여·반납과 새 물품 사용을 같은 소유권 기록에서 읽게 한다. 첫날에 이미 없앤 필기함 강제 퍼즐은 다시 요구하지 않는다.
3. **후속 사건의 수레·보온·인수.** 톡·보리의 도움을 현재 11일의 수레·운전·등·학교 인수와 대조해 붙인다. 옛 계획의 도움 플래그 하나로 구조 완료를 찍지 않는다.
4. **약장·담요·돌판의 사람 연결.** 기존 12~14일 실제 증언과 물건 사용 시점을 유지하면서, 앞서 받은 도움을 대화와 대체 준비에 회수한다.

각 연쇄는 도입→관찰→플레이어 선택→실제 행동→다른 장소의 사용→사건 결과 반응을 하나의 단위로 검수한다. 새 정답이나 생사 판정을 원안 문서만 근거로 추가하지 않는다. 후속 작업은 공개 1부의 완성으로 세지 않는다.

## 화면·검증 계약

보유한 배달 전후 그림·저울 그림·물품 아이콘과 공통 수첩·버튼·글꼴을 재사용한다. 새 그림·음악은 추가하지 않는다. 배운 방법은 ‘물품 → 알게 된 방법’에서 다시 읽는다. 자세한 실행 결과와 실제 화면은 149 검수 보고서에 따로 남긴다. 준비 상태 시험을 1~7일 연속 자연 플레이로 보고하지 않는다.
