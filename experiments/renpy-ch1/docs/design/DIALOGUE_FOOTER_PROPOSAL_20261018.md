# 대화 하단 UI 제안 — 검토용 시안

소유자 요청: 백로그·자동은 더보기에 모으고 더보기를 가장 오른쪽에 둔다. 대사 건너뛰기 오조작을 막고 기록·제시는 주 행동으로 강조하되 하단 아이콘이 대사보다 커 보이지 않게 한다.

## 추천 배치

- 대사: 오른쪽에 기록 → 더보기. 대사창은1072px 폭으로 정리하고 본문은PC26px/모바일29px. 상시 백로그·자동·건너뛰기 버튼은 제거한다.
- 질문: 자료 보여주기 → 기록 → 더보기를 같은 하단 줄에 놓는다. 제시는 금색 채움으로 강조한다. 돌아가기는 왼쪽에 둔다.
- 도구 버튼의 보이는 높이는56, 아이콘20, 글자22, 간격16. 모바일 누르는 영역은80을 유지하고 시각 부품을 가운데 정렬한다.
- 더보기: 대화 기록, 자동 읽기, 읽은 대사 빠르게, 현재 대화 건너뛰기, 저장·불러오기, 설정. 자동 중에는 별도의 정지 표시가 대사 화면에만 나온다.
- 현재 대화 건너뛰기는 처음 보는 대사도 지나간다는 확인창을 거친다. 계속 읽기를 기본 강조한다. 취소하면 같은 대사로 돌아간다.

## 범위

실제 게임 코드로 렌더링한 별도 design/dialogue-footer-concept-20261018 브랜치다. main/배포본은 변경하지 않는다. 전체 회의 화면과 기존 아침 재시작·메인화면 항목의 하위 메뉴 연결은 본 적용 시 통합 검증할 범위이며 이 시안의 검증 대상은 일반 대화·인물 질문·자료 제시·백로그·확인창이다.

공식 빌더로 만든 검토용 로컬 웹 빌드를 사용한다. 생성한 preview 산출물은 이 시안 브랜치에 커밋하지 않으며, 실제 캡처와 결과는 docs/reviews/dialogue-footer-concept-20261018/에 보관한다.
