# 7~9일 주민 별편과 본편 연결

2026-11-06. 4~6일에 이어 7~9일의 주민 9명, 별편 9장면을 썼다. 현재 본편 실행과 그 순간에 당사자가 아는 정보를 우선한다. [합본](주민_반응별편.md), [시간·정보·분기 매칭](reaction-map.json)과 날짜별 원고·매칭을 함께 둔다.

| 날짜 | 시점 | 행동과 목적 | 본편 앵커 |
|---|---|---|---|
| 7일 | 사자 선생님 | 막내의 직접 대답을 기다리면서 잡은 손은 떼지 않음 | 실제 세 아이 인수 블록 |
| 7일 | 누비 | 자백이 어디까지 적혔는지 자기 눈으로 보려 함 | 자백 전용 L0044 뒤 |
| 7일 | 보리 | 밥과 일을 맞바꾸지 않으면서 빈 그릇부터 맡김 | 꼬미 생존 전용 L0036 뒤 |
| 8일 | 서리 | 아빠의 다음 질문보다 아이가 소매를 정리할 시간을 먼저 확보 | 살인·구금 L0015 뒤 |
| 8일 | 부엉이 | 종이를 자기 손에 들고 다람이 옆으로 오게 함 | 치료 생존 care8 L0014 뒤 |
| 8일 | 초롱 | 비밀 내용을 듣지 않고 봉투가 누구 손에 갔는지만 확인 | 공개 길 동행 선택 후 L0032 앞 |
| 9일 | 부리 | 자기 할아버지에 대한 질문을 아빠의 딸 구하기에 종속시키지 않음 | 살인판 주방 L0005 뒤 |
| 9일 | 톡 | 사람을 쳐다보는 시선을 수리한 물건으로 돌려놓음 | 실제 공방 출석 L0007 뒤 |
| 9일 | 세련 | ‘맡긴 사람’과 ‘쓴 사람’을 한 이름으로 묶지 못하게 함 | 공통 우체국 L0009 뒤 |

게임에는 주민 속마음을 넣지 않고 아빠가 직접 보고 듣는 추가 27행과 기존 인수 지문 1행 개정을 연결했다. 기존 생존 when을 새 발췌 묶음에도 명시하여 사망 상태에서 인접한 아이의 응답만 남지 않게 했다. 새 조건·자료·그림·음원·화면이나 판정은 만들지 않았다.

## 분기와 지식 경계

- 누비 자백은 보리의 실제 문 앞 목격과 첫 자료 대조 뒤다. 살의는 입증되지 않았다. 너울의 약속을 들었다는 누비 주장과 대승리의 독립 자료 입증은 구별한다.
- 화재 회의의 패배·부분 성공·일반 승리·대승리는 기존 결과를 유지한다. 회의가 꼬미의 생사를 되돌리지 않는다.
- 부엉이 사망과 다람 구금, 돌을 치워 쓰러지지 않은 경우, 쓰러진 뒤 의료진으로 살아난 경우를 구별한다. 치료 생존 별편을 돌 예방에 붙이지 않는다.
- 초롱은 봉투와 공개 길 동행을 안다. 엄마의 편지 전문·은신처는 알지 못한다. 현장에 없는 다람의 응답을 추가하지 않는다.
- 톡의 공방 출석과 나중 회의 출석은 독립이다. 부재하면 기존 부리·세련의 사본으로 같은 수리 기록을 얻는다. 수리·소유 확인은 사용·살해 목격이 아니다.
- 부리와 할머니의 갈등을 10일 전 범행 확정으로 쓰지 않는다. 세련의 접수표는 맡긴 사람을 보이며 작성자를 확정하지 않는다.

## 읽기 파일

사망·꼬미 상실·톡 출석을 기본으로, 꼬미 생존, 수리 사본, 의료진의 치료 생존, 돌 제거 예방을 나눈 다섯 경로를 제공한다. 기본 경로는 앞 4~6일의 꼬미 상실 별편과 이어 읽을 수 있다. 돌 예방의 8일에는 공통 초롱 별편만 포함하며 치료 생존 장면을 대신 넣지 않는다.

읽기 경로는 사건 전체를 다시 쓴 본편 소설이 아니라 해당 시간의 주민 별편을 연결한 것이다. 경로마다 장 번호를 다시 매겨 끊기지 않게 했고, 개발 매칭은 원본 RR ID·제목으로 유지한다. 전체 비교본 9장면은 한 판의 연속 사건이 아니다.

`python3 dev/export_resident_days.py --source docs/design/resident-reactions-day789-20261106 --out <출력폴더>`로 HTML·PDF·Word를 생성한다. 화면에서 각 경로의 장면 순서·표시 수·장 번호를 검사한다. 공개 다운로드는 루트 `docs/reading/resident-days789-20261106`에 둔다.

## 독립 읽기 검수

누비·부리·세련의 기록 요구는 각각 자기 의도 방어, 유족의 질문 유지, 접수 업무의 정확성으로 구별된다는 검토를 받았다. 처음 읽는 독자를 위해 7일 제목에 시점 이름을 붙였다. 톡의 구리선은 상자 속 증거와 다른 작업대의 선으로 옛 수리 방법을 보여 주는 것임을 밝혔고, 근거 없는 감는 횟수는 뺐다. 누비가 말하는 몫의 약속도 자기 주장과 별도 확인을 구별해 설명했다.

검사·공개·화면의 실제 범위는 [0.20.108 릴리스](../../releases/RELEASE_0.20.108.md)와 검수 기록을 따른다. 인간 초견 독자가 재미있게 읽었다는 실험 결과로 세지 않는다.
