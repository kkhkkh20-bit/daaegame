# 주민 반응 별편 — 공통 시간표와 반응 규칙

2026-11-05 · 기준 본편 0.20.104 · **별도 기획. 게임 대사·상태·정답에 미반영.**

이 표는 한 번의 완주 결과를 정본으로 만들지 않는다. 같은 날의 사건 자리와 갈림을 고정하고, 각 주민이 실제로 본 것과 전해 들은 것을 그 위에 얹는다. 분 단위 시각은 만들지 않는다. ‘이후’는 장면의 진행 순서이며 모든 장소의 정확한 동시 시각을 뜻하지 않는다.

## 기준 자료와 우선순위

1. 현행 `game/room13_v111_days123.rpy`, `days45.rpy`, `days610.rpy`, `days1114.rpy`의 실제 이동·합류·재생 순서와 `game/room13_lamp_attempt.rpy`의 별도 경로.
2. `game/v111/newworld/dNN.json`의 개정 대사와 `game/room13_v111_newworld_text.rpy`의 조건. `game/v111/records.json`의 원행은 개정 적용 뒤의 문장과 구별한다.
3. `game/v111/field-bindings.json`의 현장 인물·조사 대상, 실제 line ID/블록을 읽은 시점. 소지품만으로 새 대사를 들었다고 간주하지 않는다.
4. `docs/reviews/novel-game-20261105/적용보고.md` 및 날짜별 적용 기록. 최신 소설은 `/workspace/outputs/daram-full-novel-polished-20261105/chapters/`의 14장 퇴고 원고.
5. `docs/design/story_master.md`, `EPISODES.md`, `VOICE_GUIDE.md`는 사실·관계·문체 확인에 쓴다. 오래된 ‘설계/미구현’ 표기는 현행 코드와 다시 대조한다.

0.20.104는 읽기 UI·결말 표시·조사 클릭 여유를 바꾼 판이며 사건·생사·관찰 사실은 바꾸지 않았다(`docs/releases/RELEASE_0.20.104.md`).

## 별편의 반응 규칙

- 각 장면에는 **직접 봄 / 직접 들음 / 전달받음 / 아직 모름**을 붙인다. 주변 주민의 이동이나 전언은 시간표에 없는 한 자동 생성하지 않는다.
- 정보 조건과 감정 조건은 다르다. 시신을 본 뒤 손을 못 놓는 행동은 가능하지만, 추리 자료를 읽기 전 사인·도구·실행자를 알아맞히는 독백은 금지한다.
- 새 별편은 새 증거·새 알리바이·신규 목격자가 되지 않는다. 단서의 획득·입증을 앞당기는 설명 대신, 손을 멈춤·그릇을 치우지 못함·말을 끝내지 못함·아이 가까이 섬 같은 현재 행동을 쓴다.
- 감정은 다음 방문에 남긴다. 3일의 충격 뒤 4일에도 무표정으로 평소 농담을 반복하지 않는다. 다만 죽음을 모르는 주민에게 추모를 강요하지 않는다.
- 범인의 머릿속을 빌려 수수께끼를 푸는 별편은 이번 범위에서 제외한다. 너울·실룩·할머니의 숨은 지시를 ‘의미심장한 독백’으로 먼저 흘리는 것도 제외한다.
- 같은 구간 재방문은 새 장문을 반복하지 않는다. 최초 1회 선택 열람 원고 뒤, 상태에 맞는 1~2줄 잔향을 별도로 설계한다. 의무 대사나 새 회의 단계는 늘리지 않는다.
- `반응을 읽음`이 `자료를 읽음/선택함/입증함`을 대체하지 않는다. 장치별 열람 여부를 저장할지, 판별로 저장할지는 구현 승인 때 정한다.
- 피코 별편의 게임용 공개 시점은 사건 해당 줄을 본 뒤다. 별도 소설 모음에서는 각 편 머리에 날짜·장소·대응 흐름을 표시하고, 사망판에서 생존판으로 이어 읽는 오류를 막는다.

## 기존 문서와 충돌·미확정

1. `docs/SCHEDULE_14D.md`는 구 `r13_where`의 기본 일과표다. 너울 1~4일 부재·나비 전일 식당·돌목 전일 입구라는 칸은 현재 첫날 초소 너울 소개·5일 나비 초소 합류와 다르다. 별편의 실제 출석 근거로 쓰지 않는다.
2. 퇴고 소설 3장은 피코 사망을 겪는 한 경로다. 그 시신·미완성 초상·후회 장면을 보호생존/절도미수판에 옮기지 않는다. 미수판은 `lamp_bound2`가 우선이며 초상이 완성되어 있다.
