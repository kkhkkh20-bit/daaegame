# 다람탐정: 경량화와 주민 반응 기획

2026-11-05. 소유자는 게임 경량화, 피코 시신 앞의 대화·조사, 사건에 따른 주민의 행동·대사, 같은 시간축의 주민별 별편을 요청했다. 후속 선택으로 **‘14일 전체 시간표 + 피코 사건 별편부터’**를 확정했다.

성능 수정과 서사 기획의 적용 상태를 구분한다. 성능 수정은 0.20.105 공개 대상으로 검증한다. 아래 원고와 서사 설계는 **게임 미반영 기획**이다. 생사·사인·추리 정답을 새로 정하지 않았다.

## 읽는 순서

1. [주민 반응 별편](주민_반응별편.md): 주민 네 명의 일곱 장면. 사망·도난, 보호생존·도난, 생존·절도미수의 서로 다른 아침을 나누어 읽는다.
2. [14일 공통 시간표와 반응 규칙](공통시간표와_반응규칙.md): 같은 날의 사건 자리·분기·정보 공개 순서를 맞춘다. 14일 주민 전원의 대사를 완성했다는 뜻은 아니다.
3. [피코 현장조사 기획·대사](피코_현장조사_기획.md): 이미 있는 시신 컷을 다시 보며 머물고, 묻고, 초상과 다람을 살피고, 떠나는 흐름이다.
4. [사건 후 주민 행동 시스템](사건후_주민행동시스템_기획.md): 평상 인사·업무·현장 자세·재방문까지 같은 사건 상태를 참조하는 계약이다. 아직 소식을 모르는 주민에게 아빠가 화면에서 전하는 신규 장면 제안도 분리했다.
5. [장면 매칭 데이터](reaction-map.json): 각 별편의 인물·분기·원문 출처·공개 하한·유효기간·재방문 잔향을 담았다. 실행 코드나 이미 있는 읽음 플래그 목록이 아니다.

독자용 PDF·Word·텍스트와 분기별 읽기 HTML은 `dev/export_resident_reactions.py`로 만든다. 코드 ID·작가용 표는 독자용 본문 뒤에 섞지 않았다.

읽기본: [분기별 HTML](읽기본/주민별편.html), [15쪽 별편 PDF](읽기본/주민별편.pdf), [별편 Word](읽기본/주민별편.docx), [기획서 Word](읽기본/주민반응기획서.docx).

## 핵심 변경 방향

- 피코 현장은 현재 컷과 자동 문답 뒤 등 조사로 넘어간다. 기존 E09 인수 뒤에 선택 흐름을 두어 직접 대화할 시간을 만든다. 시신을 누르는 것을 새 정답 조건으로 삼지 않는다.
- 사망·보호생존·미수에 같은 인사와 표정을 덮지 않는다. 사망을 보았거나 들은 사람만 그 사실에 반응한다. 각 주민이 아는 범위를 넘어 사인·범인을 말하지 않는다.
- 별편만 추가하고 현장 인사는 그대로 두는 식으로 끝내지 않는다. 최초 대면·질문 응답·업무 태도·표정·재방문의 짧은 반응까지 연결한다.
- 가족의 흔적과 ‘사람을 구하려는 증명이 다른 사람을 위험하게 함’이라는 기존 사건의 결과를 보존한다. 뒤 날짜에서 밝혀질 지시를 주민 독백으로 먼저 공개하지 않는다.

## 검토 중 바로잡은 점

처음에는 보호생존판 초롱이 피코의 현재 위치를 모르고 나비도 도난을 아직 모른다고 잘못 정리했다. 현행 `piko_alive3`의 L0028과 L0033을 대조해, **초롱이 식당에서 살아 있는 피코를 보고 도난을 발표하며 나비도 그 말을 듣는 시점**으로 원고·조건·정보표를 수정했다. 본문 문학 편집과 정보 시점 검토를 따로 한 이유다.

정확한 사망 시각·새 진료자 이름·의학적 직접 사인·화면 밖 전령은 새로 만들지 않았다. 부리의 현행 별편은 사망 미인지 상태로 남기고, 아빠가 소식을 전한 뒤의 반응은 별도 신규 기획으로 구분했다.

## 다음 적용 단위

첫 적용 단위는 피코 현장 선택 흐름과 주민 네 명의 최초 반응·재방문 잔향이다. 기존 컷·질문 부품을 쓰는 화면 시안, 세 사건 흐름의 실제 입력, 저장 복원과 미인지 주민 검증을 마친 뒤 본편에 붙인다. 이번 경량화 공개에 아직 검토 중인 서사 UI를 함께 넣지 않는다.
