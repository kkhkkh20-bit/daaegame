# 사건 이후 주민의 행동과 말

2026-11-05 · 소유자 요청 범위: 14일 공통 시간표 + 피코 사건 별편부터. **게임 미반영 기획**이다. 기존 사건의 생사·사인·범인·정답을 바꾸는 문서가 아니다.

## 목표

주민은 사건이 일어난 뒤에도 똑같이 인사하고 질문을 받는 안내판으로 남지 않는다. 무엇을 하다가 그 소식을 접했는지, 지금 무엇을 하려는지, 누구 앞에서 말하는지에 따라 몸짓과 말이 함께 바뀐다. 별편은 그 행동을 읽는 원고이고, 게임에서는 같은 장면을 짧은 대화와 작업 변화로 옮긴다.

단, 마을에 사건이 생겼다는 사실과 모든 주민이 그 사건을 안다는 사실은 다르다. 공통 시간표의 실제 출석·청취 근거가 없는 인물은 아직 모른다. 해당 분기의 플레이어가 모르는 사실을 별편이 대신 알려 주지도 않는다.

## 한 장면을 두 번 쓰는 방법

1. 공통 사건 자리: 실제 라벨·자료 획득·대화 완료를 기준으로 시간축을 잡는다.
2. 주민 원고: 자기 일과 욕구를 가진 주민 시점에서 그 사건을 쓴다. 다른 장소의 범행이나 남의 속마음은 쓰지 않는다.
3. 게임 발췌: 원고에서 눈앞의 행동 한 가지, 직접 건네는 말 두세 줄, 다시 만났을 때의 짧은 반응을 고른다. 원고 전체를 강제 대사로 만들지 않는다.
4. 동일성 검사: 원고와 게임의 물건 위치·인물·알고 있는 사실이 같은지 비교한다. 새 자료·알리바이가 생기면 이 반응 기획에서 분리한다.

## 주민별 반응 상태

아래 항목은 앞으로 구현할 데이터 계약이다. 현재 같은 이름의 플래그가 존재한다는 뜻은 아니다.

| 항목 | 기록할 것 | 금지할 추정 |
| --- | --- | --- |
| 사건과 분기 | 실제 사건 ID, 사망/보호생존/미수, 회의 결과 | 생존을 사망 장면으로 재생 |
| 접한 경로 | 직접 봄 / 현장에서 직접 들음 / 명시된 전달 / 아직 모름 | 같은 마을이니 알고 있음 |
| 내용의 범위 | 죽음 확인 / 도난 발표 / 혐의 / 입증된 내용 등 개별 사실 | 죽음을 알면 사인·범인도 앎 |
| 현재 단계 | 충격 직후 / 조사 중 / 회의 직후 / 당일 저녁 / 후일의 흔적 | 아침·저녁을 분 단위로 임의 고정 |
| 자기 상태 | 현재 위치·담당 일·구금/부재·동행자 | 말할 수 없는 사람이 나타남 |
| 표현과 기간 | 첫 대면·질문 응답·업무 반응·재방문 잔향 | 접속할 때마다 같은 충격 장문 반복 |

별편을 읽었다는 표시와 사건 정보를 들었다는 표시는 분리한다. 읽음 표시를 얻었다고 자료나 추리 성공을 주지 않는다. 사건 청취와 주민 상태를 바꾸는 쓰기는 실제 장면 재생 완료 시점에만 한다. 메뉴를 그리거나 미리 예측하거나 마우스를 올리는 것만으로는 바꾸지 않는다.

## 어떤 반응이 먼저 나오는가

1. 사망·구금·퇴장으로 현재 만날 수 없는 인물은 일반 반응보다 먼저 제외한다.
2. 진행 중인 구조·자기 가족의 위기 등 해당 인물의 당면 행동을 먼저 보인다.
3. 자신이 목격하거나 들은 사건의 직후 반응을 그다음에 둔다.
4. 회의에서 실제 들은 결과와 그날 저녁의 반응을 둔다. 혐의가 벗겨진 것과 범인이 확정된 것을 구별한다.
5. 다음 날부터는 생활 속의 짧은 잔향으로 줄인다. 원래 일을 다시 하는 것과 사건을 잊는 것을 같게 쓰지 않는다.
6. 해당 정보가 없거나 유효한 사건 반응이 없을 때 평상 인사·작업 대화로 돌아간다.

동일 사건의 충격 문장을 날짜가 지날 때마다 새로 초기화하지 않는다. 뒤에 더 큰 사건이 생겼다고 앞의 기억을 지우지도 않는다. 화면에 모든 기억을 한꺼번에 출력하는 대신 현재 행동과 가장 관련 있는 반응 하나를 고른다.

## 실제 게임에서 바뀌어야 할 표면

| 표면 | 반영 방식 | 피코 사건 예 |
| --- | --- | --- |
| 첫 대면 | 일반 인사 대신 지금 하는 행동부터 시작 | 초롱은 시신 쪽을 보다가 부녀가 함께 설 자리를 비킨다 |
| 질문 제목 | 상대에게 건네는 짧은 질문 | 「발견했을 때도 이 자세였습니까?」 |
| 대답 | 이미 아는 사실에 한정하고 호흡·행동을 달리 | 죽음 확인과 정확한 사망 시각을 구분한다 |
| 일·부탁 | 무조건 밝은 거래 인사 대신 현재 일의 맥락 | 톡은 공구를 쥐면서도 자기 수리를 설명하는 말이 막힌다 |
| 현장 모습 | 기존 위치·검증된 표정·작업 자세 안에서 선택 | 새 인물 이동이나 새 목격은 만들지 않는다 |
| 재방문 | 최초 반응 뒤 한두 줄의 잔향 | 원고 매칭표의 인물별 잔향을 사용한다 |
| 별편 열람 | 현재 분기와 공개 시점을 모두 만족할 때만 | 사망판에서 보호생존 별편을 현재 사건처럼 열지 않는다 |

이 변경은 별편을 메뉴에 넣는 것만으로 끝나지 않는다. **일상 인사·질문 후속·업무 응답·현장 자세가 같은 상태를 참조해야 한다.** 상세한 열람 UI와 시신 조사 화면의 배치는 별도 시안 대상이다. 이번 성능 수정 공개에는 이 미승인 서사 UI를 섞지 않는다.

## 아직 모르는 주민에게 소식이 닿는 장면

위 표의 ‘아직 모름’을 영구 상태로 방치하지 않는다. 다음은 **새로 붙일 화면 안 전달 장면의 편집 제안**이다. 현행 대본에 이미 있는 일이라고 기록하지 않는다. 전령을 새로 만들거나 화면 밖 소문으로 처리하지 않고 아빠가 실제 방문했을 때 말한다.

- 나비: 사망 현장을 본 뒤 식당에서 실제 대면했을 때, 사망 확인만 전달한다. 원인·실행자·시신 이동 장소는 전달하지 않는다. 나비가 현재 만날 수 없는 구간이면 이 장면도 재생하지 않는다.
- 부리: 사망판의 공방 집게 문의 첫머리에 짧게 전달할 수 있다. 기존 대여 증언과 자료 획득을 앞당기거나 대체하지 않는다. 이 안을 채택하면 현재 별편 07의 ‘사망 미인지’ 버전과 구분된 원고를 따로 써야 한다. 본 기획의 기존 07은 현행 본편에 맞춘 미인지 버전이다.
- 돌목: 광장을 직접 봤다고 소급하지 않는다. 사망 현장 뒤 초소에서 실제 대면했을 때 아빠가 알리는 후보로 남긴다. 최초 청취 장면을 확정한 뒤에야 돌목 별편을 쓴다.

### 나비에게 전하는 짧은 원고

아빠: 「피코 씨가 오늘 아침 광장에서 숨진 채 발견됐습니다.」

나비: 「……그 사람을 어디로 옮겼대요?」

아빠: 「그건 아직 듣지 못했습니다.」

지문: 「나비가 들고 있던 그릇을 탁자에 내려놓는다. 빈자리를 한번 보고, 다람에게 눈을 돌린다.」

나비: 「거기 앉아 있어도 돼.」

지문: 「다람이 내 손을 놓지 않자 나비는 의자를 더 당기지 않는다.」

이후 나비가 평소 조리 업무를 재개해도 밝은 첫 인사를 다시 시작하지 않는다. 다음 대면에는 그릇을 놓고 먼저 아이가 곁에 있는지 확인하는 정도로 줄인다. 미확정인 시신 이동에 답을 지어 넣지 않는다.

### 부리에게 전하는 짧은 원고

아빠: 「피코 씨 일로 등을 살피고 있습니다. 아침에 숨진 채 발견됐어요.」

부리: 「……피코요?」

지문: 「부리의 시선이 내 얼굴에서 다람에게 내려간다. 하려던 말을 멈춘다.」

아빠: 「톡 씨가 쓰던 집게를 찾으러 왔습니다.」

부리: 「집게요? 잠깐만요.」

지문: 「공구가 걸리는 빈 칸을 본 뒤 부리가 다시 입을 연다.」

여기서 기존 집게 대여 문답으로 이어 간다. 전달의 유무를 공구 증언의 정답 조건으로 만들지 않는다. 별편을 먼저 읽어서 이 전달이 실행된 것으로 취급하지 않는다.

## 구현 순서와 합격 기준

1. 피코 사망 현장에 머물기·묻기·초상 보기·다람에게 말하기·떠나기를 연결한다. 기존 자료를 다시 주거나 클릭을 정답 조건으로 만들지 않는다.
2. 초롱·나비·톡·부리 네 명의 첫 반응과 재방문 잔향을 붙인다. 현행 단서를 설명하는 말을 줄이지 않는다.
3. 보호생존·결박 미수·사망의 세 흐름을 각각 열어 다른 흐름의 시신·완성 초상·도난 진술이 섞이지 않는지 검사한다.
4. 14일 시간표에 따라 다음 사건으로 확대한다. 인물이 현장에 없을 때 전달받는 장면을 먼저 확정한다.

검사에는 미인지 주민, 같은 사건 재방문, 회의 실패·부분 성공, 부재/구금, 저장 복원, 다음 날 전환이 포함된다. 소설 원고만 읽고 ‘전체 게임 반응 구현 완료’로 세지 않는다.
