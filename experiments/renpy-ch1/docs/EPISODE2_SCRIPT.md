## 한눈에 — 무슨 일이 있었나 (정답)

1. 마을의 돌이 식으면서, 어떤 사람들은 **자기 이름과 가족을 잊어 간다.** 마을 사람들은 이걸 '야생화'라고 부르고, 그런 사람을 '보호소'로 보낸다.
2. 솜이의 할아버지, **무쇠 할아버지**가 잊어 가고 있다. 솜이는 할아버지가 보호소로 끌려갈까 봐 **아무에게도 말하지 않고**, 밤마다 아랫길의 네로 아저씨 천막에 할아버지를 숨겼다.
3. 4일 밤, 할아버지는 천막을 빠져나와 집을 찾아 헤매다가, 자기를 붙잡는 경비 **돌목**을 무서워서 **물었다.**
4. 너울은 처마 밑에 사는 아이 **밤이**가 물었다며 보호소로 보내려 한다.
5. 다람과 친구들이 진짜 일을 밝혀낸다. 그날 밤, 정신이 맑아진 할아버지는 **솜이를 못 알아보는 날이 오기 전에** 스스로 얼음 강으로 걸어간다.

## 결과 정리

| 결과 | 다음에 |
|---|---|
| 회의 승리 → 밤이 무죄, "친구" | ④ 13호 사건에서 밤이가 증언한다(침대 밑에서 본 것) |
| 탐정단 결성 | ④ 갇힌 다람에게 쪽지를 나른다 · ⑥ 수레 앞에서 돕는다 |
| 할아버지 이름을 말함 | 솜이가 하루 동안 탐정단을 떠났다 돌아온다 |
| 감쌈 | 솜이가 다람 곁에 남지만, 너울이 밤이를 계속 감시한다 |
| 강가의 작별을 봄 | ⑤ 옛 시설에서 솜이가 할아버지 목소리로 자기 이름이 불리는 걸 듣는다(위로) |
| 회의를 못 함·짐 | 밤이가 보호소로 끌려간다(→ 제단 명단에 밤이). 탐정단은 생기지 않는다 |
| 네로를 만남 | 네로가 이름표 하나를 준다 → 긴 밤의 위로 |
