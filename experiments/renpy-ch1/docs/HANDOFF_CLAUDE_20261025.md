## 소유자가 가장 중요하게 보는 기준

- **맥락 누락에 따른 논리 비약**을 없앤다. 초소 예: 이름 확인 → 명부에 아빠가 일꾼으로 적혔다고 설명 → 아빠가 아내 만나러 왔다고 정정 → 실제 신청과 대조. 아이를 일꾼으로 못 받는다는 제한부터 꺼내면 방문한 아빠도 플레이어도 이해할 수 없다.
- 아빠가 아는 만큼 묻고, 상대가 그 질문에 답한다. 작가만 아는 정보로 다음 대사를 건너뛰지 않는다. 확인하지 못한 이름·장소·생사·약속은 단정하지 않는다.
- 다람은 당차고 유쾌한 아이이며, 아빠도 생존 판단과 생활 익살을 함께 가진다. 주민은 자기 고집·버릇·일하는 방식으로 특이하고 정이 가야 한다. 모든 인물을 같은 재치나 의미심장한 단문으로 만들지 않는다.
- 위기·죽음·아이 상실에 농담을 얹지 않는다. 이미 자연스러운 짧은 대사는 보존한다. 수정 건수를 늘리는 것이 목표가 아니다.
- 회의가 본 게임, 예방은 플레이어의 다음 판 지식으로 푸는 물건 퍼즐이다. 아빠는 회차 기억이 없다. 문장으로 예방 정답을 미리 알려 주지 않는다.
- 생사·진상·결말·회의 정답·UI 디자인은 승인 없이 변경하지 않는다. 이번에는 기존 사건/조건을 유지하며 문장과 저작 도구만 손봤다.

## 도구에서 고친 것과 주의점

- 날짜별 읽기에는 본편 합본 뒤에 **날짜가 확인된 별도 JSON 분기 부록**을 붙인다. 숨겨진 가족/기지·등 미수판이 본편 날짜 파일에 없어서 빠지던 것을 보완했다. 부록 순서는 실제 재생 순서가 아니며, 호출 조건에 따라 개별 재생한다.
- 직접 rpy 문자열의 위치ID `파일:줄:열` 끝자리(예: 열38)를 8일로 오인하던 날짜 추정을 수정했다. 실제 라벨의 날짜를 쓰고, 라벨이 바뀌면 이전 scene을 이어받지 않는다. 날짜가 불명확한 공용 줄은 공용/전체에서 찾는다.
- `renpy.display_menu` 문자열은 선택지로 분류한다. 읽기 전용 동적 문자열·옛 캠페인·미사용 원문도 inventory에 있으므로 전체 행 수를 현재 본편 고유 대사 수라고 부르지 않는다.
- 검수 상태는 이번에 수정한 행만 reviewed로 저장했다. 읽어 보고 보존한 줄을 일괄 완료 처리하지 않았다. 통독 범위는 날짜별 보고서로 확인한다.
- 생성 도구 수정으로 분기 메타데이터가 바뀌었다. **옛 내려받기 JSON은 다시 가져오지 말고 최신 작업실에서 재출력**한다. 충돌/원본 해시 오류를 지우고 억지 적용하지 않는다.

## 수정·다운로드 방법

다운로드 묶음: `docs/story-workbench/claude-handoff-20261025.zip` (인계서·1~14일 TXT·편집 JSON·그림 요청서). 다시 만들기: `python3 dev/build_story_handoff.py`. 묶음 안의 `dialogue-edit-all.json`이 생성 시점의 편집용 파일이며 검수 폴더 edits.json은 적용 전 기록이다.

공개 작업실: https://kkhkkh20-bit.github.io/daaegame/experiments/renpy-ch1/docs/story-workbench/

로컬 명령은 프로젝트 폴더 `experiments/renpy-ch1/`에서 실행한다.

```bash
python3 dev/dialogue_modules.py build
python3 -m http.server 8788
# http://127.0.0.1:8788/docs/story-workbench/
python3 dev/dialogue_modules.py check 수정본.json
python3 dev/dialogue_modules.py apply 수정본.json          # 쓰지 않고 검사
python3 dev/dialogue_modules.py apply 수정본.json --write  # 실제 반영
```

조건·ID·화자·해시는 보존하고 text/review_status만 고친다. 브라우저 임시 저장은 게임 원본을 바꾸지 않으므로 JSON을 보관해야 한다. CSV/Markdown은 읽기·비교용이고 자동 반영은 JSON이다. 이번 옛 패킷은 적용 전 기준의 증거로만 남겼다. 최신 문장은 작업실/원본을 기준으로 삼는다.
