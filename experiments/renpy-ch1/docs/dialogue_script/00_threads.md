# 단서 줄기 단계


## mom
| 단계 | 확인한 사실 | 다음 의문 |
|---|---|---|
| 1 memo | 엄마가 13호 책상에 메모를 남겼다. | 메모에 적힌 ‘등불을 돌보는 사람’은 누구일까? |
| 2 named | 등불을 돌보는 사람은 초롱이다. | 초롱도 엄마를 만났을까? |
| 3 recognized | 초롱은 엄마의 글씨와 얼굴을 알아봤다. | 언제 어디서 만났고, 엄마는 무엇을 맡겼을까? |
| 4 promised | 엄마가 초롱에게 가족 앞으로 봉투를 맡겼다. | 봉투에는 무엇이 적혀 있고, 언제 받을 수 있을까? |
| 5 received | 엄마가 맡긴 봉투를 읽었다. 엄마는 오라는 편지를 쓴 적이 없다고 했다. | 그럼 우리를 부른 초대 편지는 누가 썼을까? |
| 6 letter | 초롱이 끝까지 지니고 있던 엄마의 편지를 읽었다. 엄마는 살아 있고, 다람에게 직접 썼다. | 엄마는 지금 어디에 숨어 있을까? |
| 7 hideout | 숲 뿌리 밑 은신처는 들켰고, 엄마는 더 깊은 곳으로 옮겼다. | 엄마는 어디로 옮겼을까? |
| 8 reunited | 엄마를 다시 만났다. | 엄마가 연구해 온 것으로 마을을 구할 수 있을까? |
