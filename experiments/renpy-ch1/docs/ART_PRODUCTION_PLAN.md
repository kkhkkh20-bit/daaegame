# 그림 제작 기획표 (GPT 병렬 작업용, 2026-10-16)

- 목적: 코드와 그림을 동시에 진행한다. 이 표의 순서대로 GPT에게 한 장씩 맡기고, 받은 그림은 `art/incoming/`에 넣는다.
- 내용의 근거(무엇을 그릴지)는 `docs/ART_REQUEST_EPISODES.md`에 있다. 이 문서는 그중 **무엇부터, 어떻게 요청하고, 어떻게 검수하는지**만 적는다.
- 검수는 다른 채팅이나 사람이 해도 된다. 4절 「검수표」만 보면 된다.

## 2. GPT에 붙여 넣는 공통 앞말

모든 요청의 맨 앞에 그대로 붙인다.

```
픽셀아트 게임 배경/캐릭터를 그려 줘. 눈 덮인 그림책 같은 겨울 마을이다.
그림체: 큰 색면, 계단형 외곽선, 단순한 명암. 따뜻한 주황 등불과 차가운 푸른 눈빛의 대비.
인물은 귀여운 동물이다. 분위기는 잔혹동화지만 무서움은 조용함과 남은 물건으로만 보여 준다.
피, 상처, 시신은 그리지 않는다. 글자·숫자·간판 문구·UI는 넣지 않는다(글자가 필요한 물건은 읽을 수 없는 선으로).
마을의 따뜻한 돌 조각은 초록빛으로 숨 쉬듯 은은하게 빛난다(등불의 주황과 구별).
배경 그림에는 사람을 넣지 않는다.
첨부한 참고 그림과 같은 그림체·색감으로 맞춰 줘.
```

- 참고 그림으로 함께 첨부할 것:
  - 배경: `game/assets/room13-pixel-panorama-square-*.webp`, `room13-pixel-panorama-school-*.webp`, `room13-pixel-wide-kitchen-*.webp`
  - 인물: `room13-fullbody-*-neutral.webp` 두세 장(다람, 나비, 보리)
  - 아이콘: `room13-pixel-material-icons079-objects.webp`

## 3. 한 장씩 붙이는 개별 요청 (A·B·C·D 묶음)

> 형식: 공통 앞말 + 아래 한 줄 + 크기. 한 번에 한 장만 요청한다. 같은 장소의 다른 시간대는 **같은 그림을 첨부하고 "조명만 바꿔 줘"**라고 한다.

**A. 장소**
- P03 지붕 위: "여관 눈 지붕 위에서 마을을 내려다보는 가로로 긴 장면. 굴뚝, 눈 덮인 기와, 멀리 광장 등불과 학교 지붕, 반대쪽 멀리 얼음 강. 아래쪽 3분의 1은 평평한 지붕 바닥으로 비워 둔다. 저녁. 2048×768."
  - 밤판: "같은 구도, 밤. 멀리 강 쪽에 작은 등불 하나, 반대쪽 학교 뒤에서 붉은 불빛이 피어오른다."
- P05 솜이네 집: "작고 추운 오두막 실내. 꺼져 가는 난로, 낡은 의자 둘, 창가 의자 하나(빈자리), 벽에 아이 그림, 문 옆에 큰 털신 한 켤레. 오후의 흐린 빛. 2172×724."
- P06 장작 창고 바깥: "학교 건물 뒷마당 끝, 지붕이 내려앉은 낡은 나무 창고. 장작이 벽처럼 쌓였다. 오후. 2048×768."
  - 불판: "같은 구도, 밤. 창고 문 쪽이 통째로 불타고, 뒷벽 판자 하나가 뜯겨 있다. 사람은 넣지 않는다."
  - 터판: "같은 구도, 아침. 검은 기둥 몇 개만 남고 녹은 눈에 시커먼 물이 고였다."
- P07 꼬미의 아지트: "창고 안쪽. 장작을 쌓아 만든 벽, 그 안에 담요 넷이 나란히, 구석에 작은 여관 등잔, 벽에 아이들 크레용 낙서(그림만), 깨진 그릇. 생각보다 아늑하다. 등잔 빛. 2172×724."
- P08 빨래터: "여관 뒤 마당. 큰 무쇠 솥 밑에 약한 불, 솥 옆 등유 통, 빨랫줄에 언 이불, 빨래판, 물통, 빨랫줄 너머로 이어지는 길. 김이 피어오른다. 오후. 2048×768." (저녁판은 조명만)
- P09 종탑 아래: "광장 동쪽 끝 종탑의 돌계단 아래. 종탑 문, 위로 오르는 좁은 계단, 꺼진 등 셋. 밤. 2048×768."
- P10 처마 밑: "여관 옆벽의 깊은 처마 밑. 짚더미, 낡은 망토가 걸린 못, 처마 끝 고드름, 2층 창. 오후. 2048×768."
- P12 회관 앞: "회관 정문 계단과 문 옆 장작더미 그늘. 게시판 자리. 오후. 2048×768."

**B. 인물** — "전신, 정면에 가깝게, 투명 배경. 기존 캐릭터와 같은 머리·몸 비율(아이는 다람과 같은 키 기준)." + 표의 설명 + 표정 이름.

**D. 그림책** — "오래된 그림책 삽화 느낌의 픽셀아트, 종이 질감, 색은 바랜 수채 톤. 900×600." + 표의 장면.

## 4. 검수표 (검수하는 사람이 보는 것)

| 볼 것 | 통과 기준 |
|---|---|
| 크기 | 표의 크기와 정확히 같다 |
| 그림체 | 첨부한 기존 그림과 나란히 놓았을 때 튀지 않는다(외곽선 굵기, 명암 단계, 채도) |
| 바닥 자리 | 바깥 장면은 아래 3분의 1이 평평하게 비어 주민이 설 수 있다 |
| 금지 | 피·상처·시신·읽을 수 있는 글자·UI가 없다. 배경에 사람이 없다 |
| 시간대 | 같은 장소의 시간대 그림은 구도가 같고 조명만 다르다 |
| 이야기 | 표에 없는 수상한 물건(새 단서처럼 보이는 것)이 없다 |
| 돌 조각 | 초록빛이고, 등불 주황과 구별된다 |
| 인물 | 동물 종류가 표와 같다. 다람과 키 비율이 맞다. 투명 배경 |

- 검수에서 걸린 그림은 같은 요청에 "○○을 고쳐 줘"만 덧붙여 다시 받는다.

## 5. 받은 뒤 (코드 쪽에서 할 일)

- `art/incoming/`에 PNG를 넣으면 이야기 담당 채팅이 `dev/import_art.py`로 무손실 WebP로 바꾸고, 임시 그림 자리에 연결한다.
- 연결할 곳: 장소는 `r13_scene(...)`의 배경 키, 인물은 `assets/cast.json`, 아이콘은 증거 그림 매핑.
- ⑤⑥·제단 그림(F 묶음)은 코드가 들어간 뒤 이 표에 같은 형식으로 더한다.
