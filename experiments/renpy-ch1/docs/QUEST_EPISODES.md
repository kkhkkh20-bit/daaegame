# 의뢰 에피소드: 의뢰 하나 = 한 판 (2026-10-16, 설계 초안)

- 소유자: "의뢰마다 스케일을 크고 복잡하게 만들어 놓으면 좋다. 이 의뢰가 한 에피소드다. 한 게임 한판이다." "살아가는 주민에게 의뢰받고 처리하고, 엄마 정보를 얻어도 좋고, 마을의 변화가 된다. 돌아다니며 의뢰를 하다 보면 재판까지 자연스럽게 흘러가야 한다."
- `QUEST_PLAN.md`의 작은 의뢰 19개 표를 **큰 의뢰 6개**로 묶는다. 작은 사건(A~W)은 각 의뢰의 단계가 된다.
- 레퍼런스: 위쳐 3의 큰 곁가지 의뢰처럼 "받기 → 조사 여러 단계 → 뒤집힘 → 회색 결정 → 나중에 돌아오는 결과".

## 전체 구조

```
본편 줄기: 가짜 편지 → 엄마의 흔적 → 4일 저녁 사건 → 7일 회의 → 2주 차 재회·결말
                 ↑            ↑              ↑            ↑
의뢰 6개:  엄마의 편지 · 처마 밑의 밤이 · 나비의 빚 · 톡의 공방 · 창고의 밤 · 광장의 돌
```

- 의뢰를 하다 보면 회의 증인·증거·집행 조건이 모인다. 회의는 따로 준비하는 게 아니라 의뢰들의 결과로 열린다.
- 한 회차에 6개를 다 끝내기 어렵게 한다(기간이 겹친다). 무엇을 고르느냐가 그 회차의 이야기가 된다.

## 의뢰 하나의 틀

| 칸 | 내용 |
|---|---|
| 의뢰 | 누가, 왜, 얼마에 |
| 기간 | 열리는 날 ~ 닫히는 날. 그동안 의뢰인은 그 자리에 있다 |
| 단계 | 조사 2~4단계. 단계마다 장소·사람·물건이 다르다 |
| 뒤집힘 | 처음 보인 것과 실제가 다르다 |
| 결정 | 회색 선택 3~4개 |
| 여파 | 바로: 돈·물건·관계 / 나중: 큰 마디(회의·엄마·2주 차)와 결말 |
| 엄마 조각 | 의뢰마다 엄마에 관한 조각 하나(선택) |
| 마을 변화 | 의뢰 뒤 마을에서 눈에 보이는 변화 하나 |

## 의뢰 6개

### 1. 엄마의 편지 (본편과 가장 가까운 의뢰)

- 의뢰: 까로가 "반송된 소포 배달을 도와주면 품삯 7냥".
- 기간: 1~4일.
- 단계
  1. 소포 배달(기존 배달 일). 받는 집이 비어 있고 소포가 반송된다 → 세련이 엄마의 반송 소포를 기억한다.
  2. 우체국에서 슬링이 봉투를 김에 쐬는 것을 엿본다(기존 L).
  3. 피코에게 엄마 초상을 맡겨, 초상을 보여 주며 엄마를 본 사람을 찾는다(기존 G).
  4. 초롱의 점검함에서 엄마의 경고를 받는다(기존 warning).
- 뒤집힘: 초대 편지는 엄마가 쓴 것이 아니다.
- 결정: 슬링을 모른 척 / 슬링을 회유 / 가짜 편지를 흘려 할머니를 속인다.
- 여파: 회의의 편지 증거(H9 등), 할머니의 4일 저녁 계획에 틈, 엄마 연락이 빨라짐.
- 마을 변화: 우체국 화덕의 김 쐬기가 멈춘다.

### 2. 처마 밑의 밤이 (큰 사건 1 확장)

- 의뢰: 바둑이가 "처마 밑 아이가 검사로 끌려가지 않게 도와 달라". 보수 없음, 대신 순찰대의 신뢰.
- 기간: 2~4일.
- 단계: 싼 방의 함정(누비 역할은 백 부인, 기존 Q) → 서리의 건강 확인서 → 네로가 밤이를 숨겨 줄 곳 → 4일 저녁까지 밤이를 처마에 남긴다.
- 뒤집힘: 격리 방은 너울의 지시였다.
- 결정: 밤이를 숨긴다 / 검사를 받게 하되 서리가 맡는다 / 너울 편.
- 여파: 회의 E10(밤이 증언), 바둑이·너울 관계.
- 엄마 조각: 밤이는 밤에 숲 끝의 망토 그림자를 보았다.
- 마을 변화: 처마 밑에 담요와 등이 생긴다 / 처마가 빈다.

### 3. 나비의 빚 (큰 사건 2 확장)

- 의뢰: 나비가 "식사 준비를 거들어 주면 6냥"(기존 식사 준비 일).
- 기간: 2~5일.
- 단계: 따로 놓인 그릇 → 주방 뒷문의 아이들 → 학교 뒤 장작 창고의 아이 다섯 → 장작이 사라지는 밤(보리, 기존 O) → 아이들 끼니 구하기.
- 뒤집힘: 장작 도둑 보리는 아픈 아이 때문이었다. 나비의 품삯은 할머니가 깎고 있다.
- 결정: 할머니에게 알린다 / 비밀을 지킨다 / 보리에게 장작을 사 준다 / 은호에게 싸게 식량을 얻는다.
- 여파: 회의에서 나비가 할머니 앞에서도 본 대로 증언(E12·E15), 보리의 아이.
- 마을 변화: 장작 창고 아이들이 학교 안에서 잔다 / 아이가 감기에 걸린다.

### 4. 톡의 공방 (큰 사건 4 확장)

- 의뢰: 부리가 "부품 정리를 도와주면 8냥"(기존 부품 정리 일).
- 기간: 3~5일.
- 단계: 맞지 않는 수량 → 너울이 톡을 몰아세움 → 광장 등의 계측 집게 자국 → 우박의 자백 → 여관 뒷벽 보수 중 옛 통로(따닥 역할은 톡, 기존 I).
- 뒤집힘: 범인은 도둑이 아니라 몰래 잰 견습생이었다. 돌이 식고 있다.
- 결정: 우박을 너울에게 / 서리와 함께 해명 / 조각만 돌려놓기 / 이름 빼고 사실만.
- 여파: 회의 E13(톡 증언), C1 대체 근거, 2주 차 부리의 도구(W).
- 마을 변화: 수리점 판자가 떼어진다 / 수리점이 닫힌다.

### 5. 창고의 밤 (조연 의뢰의 큰 판)

- 의뢰: 광장 게시판 "창고 일꾼 구함, 하루 15냥 — 백 부인".
- 기간: 2~3일(3일 저녁 실행).
- 단계
  1. 일을 받는다. 3일 저녁 창고로 간다.
  2. 문이 잠긴다(감금). 그 사이 누군가 13호를 뒤진다. 쐐기·다람이 방 지킴으로 막을 수 있다(기존 C).
  3. 창고 안에서 비축 장부를 찾는다.
  4. 같은 밤 솜이가 약초를 훔쳐 폐광 쪽으로 달아난다(기존 B).
  5. 사라진 물건이 은호 노점으로 흘러든다(기존 N, 여니 역할은 은호).
- 뒤집힘: 15냥은 미끼였다. 백 부인은 마을 배급 곡식과 약을 쌓아 두고 있다.
- 결정: 장부를 서리에게 / 백 부인과 거래 / 은호에게 판다 / 솜이에게 약을 준다.
- 여파: 2주 차 비축 나눔(V), 무쇠가 폐광 길을 알려 줌, 실룩의 빚(의뢰 6과 연결).
- 마을 변화: 배급대 줄이 짧아진다 / 백 부인 창고에 자물쇠가 늘어난다.

### 6. 광장의 돌 (큰 사건 3 확장, 2주 차까지)

- 의뢰: 초롱이 "등이 자꾸 깜빡인다, 같이 봐 달라". 보수 4냥.
- 기간: 5~6일, 이어서 2주 차.
- 단계: 배급표 다툼(도토, 기존 E) → 등이 꺼지는 밤 경고 종(초롱이 종지기, 기존 K) → 촌장의 계측 숫자(우박, 기존 P) → 실룩의 증언 팔기(기존 T)와 빠른 길 사기(기존 A)는 촌장 쪽 돈줄로 이어진다.
- 뒤집힘: 돌은 회복되지 않고, 촌장은 숫자를 조작해 희생을 정해 왔다.
- 결정: 종을 친다 / 지도부 편 / 숫자를 증거로 확보 / 실룩의 빚을 짚어 내 편으로.
- 여파: 촌장의 "증거대로 집행" 약속(회의 결과가 실제로 집행되는지), 2주 차 대피와 결말.
- 마을 변화: 종이 울린 뒤 사람들이 광장에 모인다 / 아무도 모르고 지나간다.
