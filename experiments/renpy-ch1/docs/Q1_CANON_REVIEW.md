# 첫 사건 개선의 전체 서사 대조

> 후속 변경: 0.19.58은 사용자가 승인한 [여러 승리 논증](design/Q1_MULTIPLE_ARGUMENTS.md)을 적용한다. 아래 ‘전부 반박해야 성공’은 0.19.54 당시 판단 기록이며 새 회의의 성공 조건은 아니다. Q1 패배로 톡 증언 기회를 잃는 후속 인과는 유지한다.

2026-10-18. 사용자의 “전체 대사본과 기획서를 가지고 의도인지 오류인지 크게 보면서 진행” 요청에 따른 변경 판단 기록. 첫 사건을 쉽게 만드는 것과, 실패를 이해할 수 있게 만드는 것을 구분한다.

## 어떤 문서를 기준으로 삼았나

`story-room13/MAIN_STORY.txt`, `docs/STORY_EPISODES_FULL.md`, `docs/EPISODES_5_PLAN.md`, 에피소드 1~6 개별 대본을 대조했다. 이 문서들은 서로 다른 시기의 집필안이다. 문서에 장면이 있다는 이유만으로 현재 게임에 다시 넣지 않는다.

최신 결정은 `story-room13/CURRENT_STORY_DECISIONS.txt`와 `story-room13/CASE13_CANON_SYNC.md`를 우선한다. 날짜는 `game/systems/room13_timeline.rpy`, 현재 동작은 `game/`에서 확인한다. `ROOM13_GUIDE.md`의 관찰과 추론 구분, 질문으로 안내하기, 현재 회차 증거만 사용하기도 함께 따른다.

구체적인 개정 차이:

- 초기 5개 에피소드안은 우박이 조각을 가져간 사건이었다. 뒤의 전체·개별 대본은 우박의 측정과 실룩의 절도를 나눈다. 옛 우박 처벌/조각 반환 경로를 복구하지 않는다.
- ④ 대본에는 톡 대신 토실에게 핀을 증언시키는 안이 있다. 그러나 0.19.14 소유자 결정은 Q1 실패 → 톡 증언 없음 → C4와 진엔딩 차단을 명시한다. 토실 우회로를 추가하지 않는다.
- 옛 전체 줄거리의 사건 4일/재판 7일은 현재의 사건 7일/재판 10일과 다르다. 첫 사건 Q1은 4일 오전~오후다.
- ④ 대본의 두 문 혼동, ⑤·제단 대본의 손으로 돌을 충전하는 설명은 최신 정본과 다르다. 현재의 두 단계 통로, 고대 기기를 통한 잔여 에너지 이동 규칙을 이번 개선으로 되돌리지 않는다.

## 판단과 실제 수정

| 현상 | 판단 | 조치 |
|---|---|---|
| 덜 조사해도 회의에 들어가고 질 수 있음 | 의도된 선택·실패 | 완전 조사 입장 조건을 추가하지 않음 |
| 반박해도 진실을 모두 밝히지 못하면 톡 구출 실패 | 현재 기획 | 일부 반박 성공과 남은 의심을 함께 기록. 부분 승리로 석방시키지 않음 |
| 톡이 끌려간 직후 톡이 등을 고침 | 결과와 장면의 모순 | 구금 / 석방·미반환 / 석방·반환 후일담 분리 |
| 반환하지 않은 조각을 등에 다시 넣음 | 결과와 장면의 모순 | 실제 반환 선택을 확인 |
| 숫자 쪽지만 가진 아빠가 온도계 대여 사실까지 인용 | 획득 정보와 대사의 불일치 | 쪽지로 확인한 측정 흔적만 근거로 말함 |
| 아이에게 묻지 않아도 아이의 말을 회의에서 인용 | 획득 정보와 대사의 불일치 | 두 노끈의 대조에 한정 |
| 탁본 반박 경로 | 기획에 명시된 우회 방법 | 처음 수정에서 제외했던 것을 복원. 공구 주인을 단정하지 않는 반박으로 변경 |
| 현장 끈 없이 실룩의 끈만으로 두 끝이 일치한다고 함 | 관찰하지 않은 대조를 생략한 판정 | 양쪽 기록 필요. 획득 순서는 제한하지 않음. 플레이 조건 변화로 명시하며 단순 문구 수정으로 취급하지 않음 |
| 노끈을 다른 주장에 냈을 때 막연한 오답 | 전달 부족 | 출처 확인과 끈 주인 대조가 왜 다른지 해당 인물이 반응 |
| 전부 반박했지만 결론을 내지 않은 실패 | 자료 부족과 다른 상태 | 결론 미확정으로 표시 |
| 정답을 바로 알려 주거나 다음 사건의 피해를 예고 | 추리·뒤늦은 결과의 매력 훼손 | 기본 회고에는 실제 논점만. 조사 방향은 사용자가 두 단계로 선택했을 때만 |

백 부인의 판매자 방문 시각도 재검토했다. 절도 시각과 판매 시각은 같을 필요가 없고, 현재 대본만으로 해 질 녘 판매가 오류라고 확정할 수 없다. 처음 수정했던 새벽 방문 표현은 원래의 해 질 녘으로 되돌렸다.

## 이번 요청으로 추가하는 기획

회고와 재시도는 기존 결함의 자동 정답 처리와 다르다. 사용자가 승인한 반복 피로 개선으로 추가한다. 회의 직전/조사 시점/기존 결과를 Ren'Py 저장으로 보관한다. 새 회차의 인물이 실패를 기억하거나 증거를 물려받지 않는다. 중간 저장을 허용한 `MAIN_STORY.txt`의 원칙과도 구분해 적용한다.

구체적인 장소 힌트는 기존의 질문 중심 기본 안내에 대한 선택적 도움이다. 자동으로 열지 않고, 플레이어가 명시적으로 고른 뒤에만 보여 준다. 기본 회고로 미래의 증인·진엔딩 조건을 설명하지 않는다.

전체 대본에는 아직 개정 전 문장이 남아 있다. 이번 작업은 위 인과관계를 검토해 Q1 개선 범위를 정한 것이며, 여섯 사건 전체의 대사를 최신 정본으로 전면 재작성했다는 뜻은 아니다.
