# 다음 세션에 필요한 최소 맥락

현재 목표: 생활이 추리의 접근 경로가 되는 PoC. 그래픽 확대 제작보다 첫날~셋째 날 선택/경제/정보 흐름 검증을 우선한다.
정본/범위: LIFE_MYSTERY_POC.md 참조. 새 모듈은 game/systems/. 테스트 결과는 dev/reports/와 qa-room13-life-poc/.
공개 배포: 이번 생활 PoC는 로컬 후보이며 공개판과 다름. 공개 배포 성공으로 보고하지 말 것.
자원: 원본 art/는 보존. 실제 참조는 파일명뿐 아니라 JSON manifest와 코드 동적 경로를 확인. 용량만 보고 삭제 금지.
사용 한도: 사용자가 ChatGPT/Codex 주간 한도 절약을 요청. 필요한 코드 범위만 읽고 이미 통과한 검사를 이유 없이 반복하지 않기. 이미지 생성/추가 에이전트/전체 재빌드는 필요성이 있을 때만.
추가 기획 시: 기능/대사/시간표 결정부터 문서에 고정하고 구현. 회차 지식과 아빠가 현재 알 수 있는 사실을 구분.
