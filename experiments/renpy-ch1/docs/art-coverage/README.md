# 아트 현황 원장

현재 상태는 [SUMMARY.md](SUMMARY.md), 전체 항목은 [coverage.csv](coverage.csv) / [coverage.json](coverage.json), 첫 제작 요청은 [BATCH_01.md](BATCH_01.md) / [batch-01.json](batch-01.json)을 사용한다. 과거 `ART_PRODUCTION_PLAN.md`나 요청 CSV는 근거 자료이며 현재 완료 목록이 아니다.

화질 자료: [꽥순 원본·렌더 진단](PIXEL_DIAGNOSIS_KKWAK.md), [표시 계산 CSV](display-metrics.csv), [표시 계산 JSON](display-metrics.json). `python3 dev/art_display_metrics.py`로 재생성한다. 이는 브라우저 실측이 아니며 전역 픽셀 규칙을 바꾸지 않는다.

후보 제작·수신·승인 진행 상태의 단일 기록은 [첫 제작 묶음 현재 현황](BATCH_01.md#현재-제작수신-현황--2026-10-17)과 그 기계용 원본 `batch-01.json`이다. `coverage.json/csv`와 `SUMMARY.md`는 현재 저장소에 실제 연결된 자산 기준이며, 미수신 후보의 제작 보고를 파일 존재나 완료로 집계하지 않는다.

## 갱신

`python3 dev/art_coverage.py`가 최신 게임의 캐릭터, 주요 채널, 장소 시간/사건 상태, 이벤트 배경·겹침, 지도 공개 상태, 대화 지시, 기존 제작 요청을 읽어 원장을 다시 만든다. `python3 dev/art_coverage.py --check`는 생성 결과가 현재 코드와 같은지 확인한다.

확정 명단은 48명이다. 런타임에는 추가/기존 보조 15명도 남아 있으므로 별도로 추적한다. 보조 인물 전체가 새 제작 대상이거나 현재 장면에서 쓰인다고 단정하지 않는다. 아빠는 1인칭 시점이며 화면에 그리지 않는다.

행의 종류를 구분한다. `character/...`는 채널 자산, `usage/...`와 `dialogue-cue/...`는 사용 요구, `request/...`는 과거 제작 요구, `map/...`는 장소·시간·조건별 연결이다. 총 행 수를 필요한 그림 수로 합산하지 않는다. 기존 요청의 상태 문구는 보존하되 완료 판단에는 사용하지 않는다.

## 상태 의미

|차원|예시|뜻|
|---|---|---|
|제작|available_unreviewed|현재 파일이 있음. 승인·화면 합격을 의미하지 않음|
|제작|not_produced|독립 표정/동작 없음, 중립 대체 또는 미연결|
|제작|needs_correction|기존 그림에 승인 수정 반영이 필요함|
|제작|candidate_held|후보·승인 보류, 자동 연결 금지|
|제작|needs_reconciliation|과거 요청·동적 코드 요구를 현재 제작물과 추가 대조해야 함|
|연결|linked / neutral_fallback / legacy_atlas|직접 연결 / 중립 대체 / 의도된 기존 atlas 사용|
|연결|broken_path / requires_resolution|없는 파일 / 동적 요구의 해석 필요|
|화면|not_run / passed|현재 증거가 없음 / 정확한 자산·조건에 대한 실제 검수 증거가 있음|

`reviews.json`은 사람이 수행한 실제 검수만 기록한다. ID별 `status: passed`, `evidence`(캡처/실행 기록), `asset_hashes`(파일→SHA-256), `context_sha256`(원장의 현재 값)을 남긴다. 그림이나 장면 조건이 달라지면 이전 합격은 자동으로 무효화된다. 과거 캡처나 파일 존재 확인만으로 합격을 넣지 않는다.

## 범위 한계와 다음 작업

정적 분석은 모든 실행 경로/상황 조합을 증명하지 않는다. `script_pose_cue`는 원문과 위치를 남기며 인물·조건을 추측하지 않는다. 제한 표정 세트인 추가 아이들은 기존 웃음/울음 연결을 유지하고, 없는 나머지 감정이 실제 장면에 필요한지 먼저 확인한다. 저장·불러오기, 겹침·접점, 카메라 좌우, 모바일 화면은 장면별 실행 검수가 필요하다.

P0는 이미 보이는 승인 불일치 수정과 주요 장면 대체 해소, P1은 반복 등장 표정/행동과 승인된 겨울옷 요청, P2는 현재 연결의 화면 확인이다. 첫 16장 이후 너울 5표정, 돌목 조사 동작 입 수정, 중립 대체 23명 표정, 장소별 미제작 행동 순으로 진행한다. 맵 시간대 재사용은 즉시 새 그림 대상으로 판정하지 않고 의도와 실제 장면을 확인한다.

현재 승인 조사 registry 21건은 16건 연결, 4건 철회, 1건 후보 보류다. 새로 연결할 승인 누락은 없다. 후보인 실룩 바퀴 눈 털기를 임의 승인하거나 철회된 네로/부리/피코/뭉치 옛 디자인을 되살리지 않는다.
