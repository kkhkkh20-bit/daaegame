겨울의 두 주 — 구현 기준 / 2026-10-12

상태
14일 전체를 통과하는 첫 시나리오 개발판. 기존 1장 대본과 상태는 legacy_start로 보존한다.
루트 공개 게임과 HTML v2는 수정하지 않는다. 새 게임은 겨울 시나리오, 이전 1장은 메뉴에서 선택한다.
완성품 분량의 주민 이벤트/전용 미술/음성으로 오인하지 않도록 게임 결말에도 개발판 범위를 표시한다.

확정 세계관
- 겨울에 마차가 끊긴 마을. 부녀의 목표는 엄마를 찾아 함께 탈출하는 것.
- 돌은 고대 문명이 동물들의 언어를 가능하게 한 선물. 현재 주민들은 원리를 잊고 열과 빛을 사용한다.
- 노후화와 난방 과사용으로 조절 기능이 손상된다. 밤의 언어 손상과 충동 조절 저하는 가동 부하에 연관된다.
- 강제 추출이 완료되면 대상은 사망한다. 야생화한 주민을 죽은 희생자의 귀환으로 설명하지 않는다.
- 공모자는 일시적인 출력 회복을 위해 희생한다. 이것은 수리가 아니다.
- 엄마는 원리를 알지만 개별 범죄의 행적·책임은 부녀가 조사한다.
- 마법적 독심, 죽은 자의 부활, 실제 시간회귀는 추가하지 않는다.

실행 규칙
winter-story.json: 장소, 조사 대사, 증거, 발생 기간, 선행 조건, 심의 주장과 복수 입증 경로.
winter_rules.rpy: 부작용 없는 copy-on-write 상태 함수. 화면이 직접 날짜·증거를 변경하지 않는다.
winter.rpy: 원자적인 장면 교체(효과음 정리→암전→새 BGM→장면)와 대사, 날짜 이벤트, 심의 진행.
winter_screens.rpy: 수첩, 선택·확인, 이동, 주장과 두 증거 비교, 결말 회고.
Ren'Py의 저장/불러오기/rollback 사용. 중복 조사 행동은 다시 과금하지 않는다.
오전·오후·저녁의 큰 활동만 시간 진행. 새 질문, 이동, 관찰, 기록 재열람, 주장 되묻기는 무료. 진행 확정 전에 비용을 표시한다.
3일 할머니 심의, 6일 이송 자료 심의, 14일 최종 심의. 조사 부족이어도 14일째 결말까지 간다.
시간은 대사를 읽는 현실 시간과 무관하다. 이른 취침은 남은 행동을 잃는다고 확인한다.

현재 주민 분기
누비: 3~5일 목격 → 이름을 담당자에게 공개하면 조기 구금.
이름을 숨기고 가족을 옮기면 피신/공개 증언 허락.
보호하지 않으면 6일 구금, 6~7일 원본 지시+숙박 보증으로 구출 가능, 놓치면 8일 강제 추출 사망.
플레이어에게 사망은 추출 기록을 직접 확보했을 때만 알려준다.
토리: 화요일 낮 광장 방문 중 도면 만남은 2일만 열린다. 9일 재방문에는 반복되지 않는다. 놓쳐도 5일 이후 수리점 대체 경로가 있다.
엄마: 도면+목격 모순→지하 경로 가설→현장 검증→12일까지 접촉 가능.
교대 시간 없이 접촉하면 추적됨. 별도 행동으로 은신처를 옮겨야 안전해진다.
현재 11명에 주간 동선을 적용했다. 주민 35명 전체를 새 일정으로 이식한 것은 아니다. 기존 캐릭터 원본 자산은 보존.

입증
할머니: 침구/제작 기록 + 유예금 영수증.
이송 자료: 목적지 지시 + 운행 기록 또는 내부 바퀴 자국.
최종: 선정 선행 + 실행 지시 / 외부 운행 불가 + 내부 목적지 / 의식 입력과 출력 차이 / 강제 추출 원리 + 대상 사망 기록.
현재 회차에 확보한 두 자료만 사용. 순서는 무관. 되묻기로 필요한 연결을 이해할 수 있다.
세 번의 오답/보류로 해당 심의 발언을 마친다. 이전에 입증한 내용은 유지한다.

결말
진실: 11일 이내 엄마 접촉, 은신처 보호, 누비 보호와 증언 허락, 비상 운용·연료·탈출로,
      최종 네 주장 직접 입증. 누적 호감도나 이전 회차 체크로 자동 승리하지 않는다.
가족: 엄마+보호+탈출로. 마을의 구조는 남는다.
불완전한 폭로: 조작과 거짓 이송을 입증. 완전한 구조 규명에는 실패.
부녀 탈출: 탈출로만 확보. 엄마를 데려오지 못함.
분리: 위 조건에 도달하지 못함.
영구 저장은 본 결말 목록뿐. 증거와 행동 상태는 매 회차 새로 시작한다.
2회차 필수 잠금은 없다. 일찍 알기 어려운 경로와 시간 배분으로 재도전을 유도한다.

후속 제작
- 새 줄거리 전용 장소별 겨울 배경과 중앙 시설, 엄마/촌장/경비의 승인된 인물 그림.
- 지금의 접수실·수리점·통로는 기존 배경 재사용으로 최종 미술이 아니다.
- 원탁 다인 반응 연출, 전용 BGM/녹음 음성, 야간 탐험의 독립적 조작 구간.
- 주민 전체를 새 사건의 생활 일정과 연결, 첫/중간 심의 결과의 장기적 파장 확대.
- 공개 배포용 완성도를 위한 실제 사용자 난이도·읽기 시간 검사.
- 2편은 임시 안정 이후 정비 기록의 조작과 외부 공급망 조사. 1편 범죄의 책임은 유지.
