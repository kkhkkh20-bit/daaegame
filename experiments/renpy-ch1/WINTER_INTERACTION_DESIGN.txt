겨울의 열흘 — 현장 조사 복구 / 2026-10-12

이번 수정의 목적
행동 목록을 고르는 시나리오 프로토타입에서, 장면을 보고 주민과 물건을 누르는
비주얼 추리게임으로 되돌린다. 시간·증거·회의·결말 규칙은 유지한다.

실행 경계
winter-story.json : 사건 대사, 날짜, 증거, 행동 비용, 회의 반박 조건.
winter-world.json : 배경과 대응하는 조사 사물 영역, 짧은 관찰, 질문 소유자, 인사.
winter_rules.rpy : 복사 후 갱신하는 시간·지식·증인·결말 규칙.
winter_world.rpy : 주민 출현, 질문 조건, 관찰 기억, 현재 목적, 현장 대화 흐름.
winter_screens.rpy : 클릭 입력과 표시만 담당. 증거/행동 비용을 화면에서 직접 변경하지 않음.
winter_scene : 장소 이동 때만 암전 → 음원 변경 → 배경. 대화 재개에 불필요한 암전 없음.
winter_lines : 대사와 해당 인물/프사를 함께 변경. 현장과 인터뷰 그림을 동시에 띄우지 않음.

조작 규칙
- 물건 클릭: 관찰은 무료. 자세한 조사에 비용이 있으면 질문 창과 확인 창을 거친다.
- 주민 클릭: 인사와 질문 창. 들은 질문에는 가로줄. 재확인은 무료이며 증거 재지급 없음.
- 배경 빈 곳 클릭: 짧은 관찰 응답 + 해당 위치 확인 표시. 기존 표시를 지우지 않는다.
- 이동/수첩/저장 무료. 장소 이동 버튼은 계속 같은 위치.
- 새 정보/날짜/증인 상태를 사용해 질문을 다시 계산한다. 미래의 사건 질문을 미리 표시하지 않는다.
- 클릭 조사 화면과 질문 화면은 진입 후 0.4초 입력 유예. 대화 넘기기가 조사로 관통하지 않는다.
- 확인 표시는 winter.checks, 인사는 winter.seen. 둘 다 세이브와 롤백 대상.

첫 플레이
마차 도착 → 눈밭에 내림 → 초소 경비의 분리 요구 → 아빠의 대응 선택 → 여관 도착.
여관에서는 접수대 할머니를 직접 눌러 방과 엄마의 숙박 사실을 확인한다.
목표 안내는 숙박 등록 → 명부 → 마지막 목격 → 운송 기록으로 현재 지식에 맞게 바뀐다.
본조사 3회가 끝나도 자유 관찰과 안부, 기록 재확인은 가능하다.

장소별 물리 조사
여관: 접수대/빗장/젖은 바닥. 할머니 접수대 뒤, 나비 식당 입구.
입구: 초소/고갯길/여관 불빛. 돌목 검문, 까로 운행 대기, 누비 구금 때 너울 등장.
광장: 돌/난방관/수레 자국. 도토 기록, 2일째 토리 연습.
우편실: 분류함/우편 자루/접수 장부. 세련 접수대 뒤, 5일째부터 도토 기록 확인.
수리점: 출력계/옛 도면/바퀴/장작. 부리 작업대 곁.
열세 번째 침대: 기운 이불/창/빈 상자/침대 밑. 클릭해서 침구 증거를 확인.
점검 통로: 안쪽 문/번호 기록/기계. 발견 전 엄마 이름이나 인물이 지도에 노출되지 않음.
총 23개 물건 영역, 기존 본조사 28개 전부 연결.

인물 제작 규격
필수: 현장 전신(소품과 자세), 정면 인터뷰 전신, 얼굴 전용 크롭.
몸 그림은 contain 배치, 얼굴은 별도 크롭. 인터뷰 중 현장 인물 화면을 닫는다.
신규 경비 돌목: 오소리, 짙은 녹색 외투/붉은 목도리/장부.
상급 명령과 민원 사이에 낀 하급 경비. 규정의 목소리처럼 말하지만 이름을 밝히며
자신의 책임을 회피하지 못하는 성격. 너울과 역할/복장/실루엣을 구분.
현장: 장부 확인. 인터뷰: 정면으로 멈춤 손짓. 동물의 둥근 앞발, 전신과 신발 포함.
현재 한 인터뷰 표정만 제작됨. thinking/distressed 등의 키는 호환용 같은 그림이다.
다수 표정이 제작되었다고 취급하지 않는다.
기존 41인 CAST는 유지하고 돌목을 추가. 엄마/촌장 전용 표정은 아직 미제작.
엄마는 발견한 안쪽 문을 다시 눌러 대화하며, 다른 주민 그림을 대역으로 쓰지 않는다.

아트 및 배포
image_gen 원본 PNG 보존. WebP는 배포용 인코딩. 4장 겨울 장소는 한 시트의
정해진 사분면을 런타임 크롭한다. 사물 영역도 해당 구도를 기준으로 작성했다.
현재 겨울 시나리오 그림과 음악은 처음 받는 game.zip에 포함한다.
이전 가을 시험판의 야외 배경만 Ren'Py 공식 점진 다운로드 사용.
기존 root 공개 게임과 HTML/v2 소스는 변경하지 않는다.

후속 제작 범위
모든 인물의 생활 자세·표정 추가, 엄마/촌장 전용 디자인, 더 세밀한 하루 시간표,
소품 움직임·음성·다국면 퍼즐은 별도 제작 대상이다. 이번 복구에 포함됐다고 주장하지 않는다.
