# 비밀통로 중간 계단 — 요청한 가로 맵 원본

원본 2048×768, 광장과 같은 비율. 게임 월드 기준 1920×720. 인물·UI 없는 도트 배경이다. 왼쪽 서비스 문, 중앙 나선형 돌계단과 층계참, 오른쪽 아래 계단·서비스 문으로 구성했다. 어둡고 퀴퀴하지만 계단과 조사할 벽면은 식별 가능하게 했다.

현재 게임 배경·이동 노드·증거 좌표를 바꾸지 않은 별도 제작 자산이다. 연결할 때는 기존 주방 스위치 → 객실 책장 아래 책의 두 단계 해제와 실제 통로 확인 증거를 유지해야 한다. 그림에 있는 문이나 물건만으로 새 이동·증거·범행 사실을 자동 확정하지 않는다. 실제 지점과 관찰문을 맞춘 뒤 기존 passage의 중간 구간으로 적용한다.
