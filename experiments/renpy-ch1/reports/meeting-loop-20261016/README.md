# 반복 속에서 모순을 찾는 회의 · 0.18.71

실제 Ren’Py 웹 빌드를 Chromium에서 검토했다. 플레이어가 넘기는 속도로 같은 논점을 반복해서 듣고, 이전·다음 발언으로 이동하거나 질문·자료 제시로 끼어든다. 명시적 7일/14일 회의 상태를 사용했으며 전체 14일 플레이 검사는 아니다.

![들은 발언을 다시 선택](heard-history.png)

![질문으로 열린 새 발언](new-statement.png)

![모바일](mobile.png)

- 반복만으로 질문 완료·반박·숨은 발언 공개가 발생하지 않는다.
- 들은 발언과 실제로 반박한 발언을 구분한다. 반박한 발언만 순환에서 제외한다.
- 틀린 자료·취소·저장 복귀는 같은 발언으로 돌아온다.
- 필요한 모순을 모두 입증하면 순환을 끝내고 결론을 고를 수 있다.
- 토론 중 빠른 넘김은 끄고, ‘토론 멈추기’로 발언 선택 화면에 돌아온다.

loop-result.json: 실제 두 바퀴 순환·발언 이동·들음 표시·질문 후 복귀·자료 제시/실패/취소/저장 복귀·숨은 발언 공개·순환 종료·모바일 검수.

flow-result.json: 기존 회의·반론 선택·공개 의견·제단 준비 관문 회귀 검수.
