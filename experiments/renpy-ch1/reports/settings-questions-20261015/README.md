# 설정·질문 UI — 0.18.50

적용 위치와 이유는 `../../docs/releases/RELEASE_01850.md`에 정리했다.

- `settings.png`: 실제 새 게임에서 연 설정. 기록과 같은 종이 틀을 사용하고 진행 저장·불러오기는 별도 메뉴로 분리했다.
- `questions-and-present.png`: 실제 입구 대화. 질문을 중앙으로 올리고 보여주기를 오른쪽 자료 카드 위치로 옮겼다.
- `mobile-dialogue.png`: 844×390 대화 화면. 하단 도구줄은 하나의 바탕과 구분선으로 연결한다.
- `read-topic.png`: 2일차와 읽은 원문 기록을 준비한 별도 검토 상태. 체크·흐린 글씨·취소선으로 읽음을 표시한다. 선택 후 원문이 바로 재생되고 중간 선택 없이 질문으로 복귀하는 것을 확인했다.

단위 검사 144개, Ren’Py compile/lint와 관련 브라우저 조작을 확인했다. 전체 14일 회귀는 이번 범위에 포함하지 않았다.
