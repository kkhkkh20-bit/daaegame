# 0.18.55 브라우저 확인

실제 웹 게임과 원래 Ren’Py 레이블을 사용했다. 새 게임의 입장 서류 획득·원본 제시를 거친 뒤, 상점/회의별 날짜·소유 자료·대상 상태를 명시적으로 준비하여 해당 동작을 검사했다. 장면을 빠르게 열기 위한 검토용 이동 버튼은 임시 브라우저 코드에만 있고 배포본에는 없다. 전체 14일 동선 완주 결과가 아니다.

- 새 게임: 실제 예약 원본 선택·제시로 입장 기록 수정.
- 자료: 증언·연필·종이·상점 물건·대여 물건이 같은 자료창에 표시. 별도 증거/증언/아이템/기록 비교/정렬 조작 없음.
- 초롱: 기름 보여주기 후 거절은 현재 회차 상태 불변. 수락은 1개 소모·도움 1회·시간 불변. 연필 보여주기는 보유 유지.
- 서리: 약초 보여주기만 하면 E20 없음. 건네기를 선택하고 반응을 읽은 뒤 기존 E20 지급 및 약초 소모.
- 부리: 빌린 칼 보여주기 거절은 보증금 불변. 반납은 칼 제거와 5냥 환급.
- 이동: 여관의 연결 장소가 상단 목록에 표시되고 문 위 중복 이동 화면은 호출하지 않음.
- 회의: 실제 7일째 회의 진입과 현재 주장 선택. 되묻기 후 숨은 다음 발언 공개. 보여주기로 E05를 골라 실제 반박 처리. 중단 확인에서 ‘더 찾아본다’는 회의를 닫지 않음.
- 회의 제출 자료는 실제 증거·증언에 한정. UI용 tool:/bag: 키가 판정에 들어가지 않음.
- 1280×720 및 모바일 가로 844×390 화면 확인.

단위 검사 151개 통과. 웹 빌드 compile/lint 통과. 0.18.53의 별도 주민 이벤트 변경을 병합한 빌드에서 확인했다.
