## 0.18.75의 처리

- 렌더러가 없으면 첫 오류에서 게임을 그 자리에 세운다.
  - 이야기·기록·시간이 진행되지 않고, 자동 저장도 하지 않는다.
  - 화면에 이유를 보여 주고 버튼 두 개를 둔다: '다시 시도'(새로 고침), '실행 기록 받기'.
  - 자동 재시도는 하지 않는다. 계정 데이터, 브라우저 보안, GPU 설정은 건드리지 않는다.
- 입구·현장 화면이 `(종류, 값)` 짝이 아닌 결과를 돌려주면 같은 화면을 다시 띄운다.
  - 입구로 무조건 돌려보내지 않는다(현장은 현장, 질문 목록은 질문 목록).
  - 세 번 연속 그러면 보이는 오류를 낸다.
- 렌더러가 정상인 경우에는 Ren'Py 자체 오류 화면이 그대로 처리한다.
