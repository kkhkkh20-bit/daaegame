실제 연결표 기준 · ‘연결됨’은 파일 연결 상태이며 화면 검증 완료와는 다릅니다.

연동 방식: 게임 연결표를 읽어 생성한 현황입니다. 웹에서 파일을 바꿔도 게임에 즉시 적용되지 않습니다. 제작 → 납품 명세 검사 → 일괄 연결 → 실제 화면 검증 → 공개 배포 순서로 진행합니다.

이미지와 함께 이 명세를 작성해 전달하세요. 기준 파일 해시로 충돌을 확인합니다. 빈 슬롯은 제작 승인 대상과 다릅니다.

표는 좌우로 밀어 볼 수 있습니다. 이미지를 누르면 확대됩니다. 의도적 공백은 제작 전 인계 지침을 확인하세요.
