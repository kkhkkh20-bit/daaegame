다람탐정 대사 작업실

분기를 골라 읽고, 원문과 비교하며 수정하고, 검수한 묶음을 내려받으세요.

작업 순서와 반영 범위
  1. 날짜·장면·조건을 골라 대사를 읽습니다. 조건이 다른 줄은 연속 대사가 아닙니다.
  2. 수정본을 쓰고 검수 상태를 표시합니다. 브라우저 안의 임시 저장이며 다른 기기와 공유되지 않습니다.
  3. 편집 JSON을 내려받습니다. CSV와 검토 문서는 읽고 비교하기 위한 파일입니다.
  4. 저장소에서 python3 dev/dialogue_modules.py check 수정본.json으로 충돌을 검사합니다.
  5. 검사 후 python3 dev/dialogue_modules.py apply 수정본.json --write로 게임 원본에 반영합니다. 이 페이지는 게임 파일을 직접 바꾸지 않습니다.

행의 출처와 조건은 편집하지 않습니다. 읽기 전용 행은 문장 교체가 지원되지 않는 출처이며 검수 상태만 남길 수 있습니다. 최신 소스로 다시 생성하면 변경된 원문은 새 기준으로 표시됩니다.

‘현재 분기’ 다운로드에는 검색·검수 필터 결과도 반영됩니다. 전체 다운로드는 모든 대사를 포함합니다.

전체 0줄현재 선택 0줄수정 0줄검수 완료 0줄
분기 묶음은 실제 조건·호출 위치를 기준으로 나눕니다. 모든 조합을 자연 플레이한 기록은 아닙니다.
