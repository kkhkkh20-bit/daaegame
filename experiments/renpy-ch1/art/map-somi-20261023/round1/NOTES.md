# 솜이네 지도 확장 검토 시안 — 2026-10-23

## 상태

요청한 파일 형식과 좌표, 미리보기까지 작성했다. **원화 접합과 길 연결에 보완이 남은 검토 시안**이다. 원본 픽셀 보존은 검증했지만, 화풍·질감·접합이 완전히 일치하는 승인용 완성 원화라고 판단하지 않는다.

## 배치와 그림

- 지도 크기: **2304×1344**. 기존 1672×941 대비 가로 약 1.378배, 세로 약 1.428배다.
- 기존 원화 위치: **base_offset = [0, 0]**. 원본을 늘이거나 다시 그리지 않고 왼쪽 위에 그대로 합성했다. 기존 장소 좌표에 더할 값은 [0, 0]이다.
- 오른쪽 632px와 아래쪽 403px에 양피지색 눈밭, 나무, 강 하류를 추가했다. 기존 나무와 건물은 하나도 옮기지 않았다.
- 솜이네는 기존 강보다 아래쪽인 새 땅에 놓았다. 굴뚝, 눈 덮인 지붕, 문, 작은 창 두 개, 낮은 울타리를 그렸다. 집은 추가 수정으로 줄여 우체국보다 작은 규모로 맞췄다.
- 「솜이네」는 생성된 손글씨이며 글자 뒤 바탕 상자는 없다. 기존 글씨를 복제한 것은 아니므로 세부 붓결에는 차이가 있다.
- 생성 그림은 내장 imagegen으로 만들었다. 결과물 조각의 크기 정리, 원본 복원 합성, 알파 마스크·윤곽선 추출, 미리보기 출력에는 ImageMagick을 사용했다. CLI 이미지 생성 API는 사용하지 않았다.

## 좌표와 영역

`cartography_somi.json`의 좌표는 새 2304×1344 원화 기준이다.

- bounds: [1270, 1140, 205, 145]
- point: [1370, 1205]
- label_point: [1365, 1256]
- label_bounds: [1326, 1240, 82, 31]
- art_key: ms14_somi

영역 그림과 윤곽선 그림은 모두 **205×145 RGBA WebP**다. 영역 그림은 집·울타리·작은 마당·이름을 포함하는 다각형 안만 불투명하며 바깥은 투명하다. 지붕 위 연기는 선택 영역에서 제외했다. 윤곽선은 기존 자산처럼 연한 색의 약 2px 선으로 저장해 런타임에서 갈색으로 물들일 수 있도록 했다. 솜이네 골목과 솜이네 방은 이 하나의 art_key와 좌표를 함께 쓰면 된다. shared_by는 장소 이름 기록이며 게임 내부 ID를 추정해 넣지 않았다.

강 선택선을 포함하지 않는다. 선택 bounds의 최상단 y=1140은 기존 원화 끝 y=940보다 아래여서 기존 강 영역과 겹치지 않는다.

## 미리보기

- preview_full.png: 1536×896. 점선은 원본이 보존된 [0,0,1672,941] 사각형을 표시한다. 점선은 원화 파일에 들어 있지 않다.
- preview_view_village.png: 1280×720. 약 0.746411배, 화면 offset [16,-24]. 기존 마을 화면 구도를 따른다.
- preview_view_somi.png: 1280×720. 같은 축척, offset [-440,-283]. 솜이네 영역만 RGB 밝기 +0.09, 윤곽선 #694425로 표시했다.
- 화면 높이는 원화 비율에 따라 반올림했다. 게임과 같은 최근접 보간을 사용했다. 하단 장소 판과 버튼은 생략했다.
- Ren'Py에서 실제 드래그나 focus_mask 동작을 실행한 결과는 아니다. 게임 적용과 이동 조작은 포함하지 않았다.

## 확인한 점

1. 최종 WebP에서 [0,0,1672,941]을 잘라 원본과 비교: ImageMagick AE **0**. 디코딩한 RGB 픽셀이 모두 같다. 최종 WebP는 무손실 저장했다.
2. 영역·윤곽선의 크기가 bounds의 205×145와 일치한다.
3. 두 영역 파일에 실제 알파 채널이 있고 바깥이 투명하다.
4. 선택 미리보기의 강조 위치는 솜이네이며 강 전체에 별도 선택선을 그리지 않았다.
5. 기존 game/ 자산·JSON·Ren'Py 코드의 tracked diff가 없다. 결과물은 요청한 art 폴더 안에만 작성했다.

## 남은 보완점

- **하단 y=941 접합부에 양피지색과 질감 차이가 가로 띠처럼 남는다.** 오른쪽 강 접합부도 확대하면 원본과 새 선의 차이가 보인다. 원본 보존과 자연스러운 접합을 동시에 완수하지 못했다.
- **다리 끝에서 새 길 시작까지 원본 안의 빈 강변 구간이 남는다.** 원본을 한 픽셀도 바꾸지 않는 조건 때문에 기존 빈 땅에 새 길을 덧그리지는 않았다. 새 땅의 길은 그 아래에서 솜이네로 이어지며, 길선이 다리까지 연속해서 닿지는 않는다.
- 강 하류는 오른쪽 가장자리로 빠지지만, 우하단에서 아래쪽 확장부로 넘어가는 끝부분의 연속성은 추가 정리가 필요하다.
- 새 집은 원본보다 정면에 가깝고 눈 지붕·벽 질감이 더 세밀하다. 기존 건물의 직선적인 지붕과 완전히 같은 화풍은 아니다. 손글씨 크기와 붓결도 육안 확인이 필요하다.
- 생성 조각을 목표 크기에 맞춰 리샘플링했다. 기존 원본 픽셀 밀도는 그대로지만, 확장부의 세부 선명도가 완전히 같다고 보장하지 않는다.

## 최종 생성 지시 기록

최종 채택 부분은 오른쪽 확장 조각, 아래 확장 조각, 작은 집 수정 조각이다. 전체 지도 생성 시도는 기존 마을을 재해석해 채택하지 않았다. 아래는 최종 사용한 프롬프트의 한국어 기록이다.

### 오른쪽 확장

832×941 캔버스의 왼쪽 기존 지도 200px를 위치와 크기 그대로 보존하고 오른쪽 빈 영역만 확장한다. 위쪽과 아래쪽에서 들어오는 강안을 이어 동쪽·남쪽으로 굽이치는 하류를 만든다. 기존과 같은 얇은 갈색 잉크선과 양피지색, 눈 덮인 땅, 드문 침엽수와 앙상한 나무를 사용한다. 집·글씨·UI는 추가하지 않는다.

### 아래 확장

2304×500 지도 조각의 위쪽 기존 그림 145px는 그대로 두고 아래 빈 부분만 그린다. 양피지 바탕의 넓은 눈밭과 드문 나무를 추가한다. 다리 아래에서 내려온 좁은 길이 작은 집으로 이어지게 한다. 작은 집에는 굴뚝·눈 지붕·문·창 두 개·낮은 울타리를 넣고, 아래에 상자 없이 손글씨 「솜이네」를 쓴다. 다른 장소 이름이나 UI를 넣지 않는다.

### 집 크기 수정

집과 울타리만 기존 시안의 65% 정도로 줄이고 중심 위치를 유지한다. 주변 나무와 진입로를 보존한다. 기존 지도와 같은 얇은 세피아 잉크선, 작은 눈 지붕과 굴뚝·문·창 두 개를 사용한다. 벽돌 질감과 울퉁불퉁한 눈 처마를 줄이고, 손글씨 「솜이네」와 상자 없는 이름 배치를 유지한다. 확대·크롭·새 사물 추가는 하지 않는다.
