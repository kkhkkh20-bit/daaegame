# 초롱의 평상시 대화 원화 교정

2026-11-08 소유자의 완주 검수 수정 승인으로 제작했다. `resident_lamplighter`의 일반 여섯 표정을 같은 평상 자세로 맞춘다.

입에 문 끈과 손에 든 닦는 천을 제거한다. 한 손은 가방끈에 편안히 두고 다른 손은 기존 등불을 든다. 원래 털·긴 귀·주황 목도리·녹색 외투·크림 조끼·보라 회색 바지·갈색 구두·도구 가방과 정면 시선을 보존한다. 기존 다람·너울의 작은 도트 계단 윤곽과 큰 색면을 기준으로 썼다.

- 생성 원본 PNG 바이트는 그대로 보관했다.
- 게임용 WebP는 표준 `import_art.encode`의 q95/무손실 알파 압축이다.
- `source-gallery.png`는 검수용 미리보기이며 게임 원화가 아니다.
- 일반840 가시높이 `528.584071`, 질문 높이 `560`은 기존 계약을 계승한다.
- 과거 광장 작업 원화 `art/dialogue-gaze-20261107/resident_lamplighter/`와 별도8일 `guarded_relief`는 삭제하지 않는다.
- 광장 청소에만 기존 작업 원화를 고르는 문맥 연결은 메인 담당자가 관리한다.

`python3 dev/import_chorong_calm132.py`는 납품 파일과 프로필만 검사한다. `--apply`는 메인 담당자가 통합 시 실행한다. 전역 확대 필터·정답·대사·자료·관계 값을 바꾸지 않는다.

## 광장 작업 연결 계약

`manifest.json`의 `work_pose`에는 교체 전의 `gaze116` 당황 표정 프로필을 동결했다. `lamp_work132`는 `MS14_D02_S01_L0011`의 “이 끈 좀 잡아 주세요” 대사(자동 분할 포함)에만 선택된다. 새 평상 그림을 적용한 뒤 importer를 재실행해도 작업 그림이 평상 그림으로 덮이지 않는다. 일반 표정과 별도 작업 표정의 표시 높이는 같은 기존 계약을 따른다.

관련 순수 검사: `PYTHONPATH=dev python3 -m unittest test_chorong_calm132` — 원본·알파 여백·표정 고유성, 프로필 키/발선, 동결 작업 참조, 한 대사 선택 범위를 확인한다. SDK/웹 실제 화면 검사는 메인 통합 담당자가 실행한다.
