# 다람탐정 UI 조각

생성 이미지의 붓 결·안료 질감을 PIL로 크기, 색, 알파 보정한 PNG입니다. UI 조각에는 글자가 없습니다. 좌표와 모서리 값의 단위는 px이며 순서는 **(left, top, right, bottom)** 입니다.

| 파일 | 크기 | 9조각 모서리 | 용도 |
|---|---|---|---|
| name_ribbon.png | 440×100 | (88, 0, 88, 0) | 양 끝 20% 보존, 가운데 60%만 가로 확장 |
| opt_tab.png | 400×128 | (80, 0, 80, 0) | 양 끝 20% 보존, 가운데 60%만 가로 확장 |
| panel.png | 256×256 | (48, 48, 48, 48) | 금색 모서리 장식 보존 |
| btn_idle.png | 96×88 | (16, 16, 16, 16) | 기본 |
| btn_hover.png | 96×88 | (16, 16, 16, 16) | 밝은 갈색·금선 |
| btn_selected.png | 96×88 | (16, 16, 16, 16) | 버건디, 마름모 없음 |
| btn_insensitive.png | 96×88 | (16, 16, 16, 16) | 회갈색·낮은 대비 |
| say_shade.png | 8×320 | (0, 0, 0, 0) | 9조각 불필요, 가로 확장; 위 α=0, 아래 α=240/255 |
| contact.png | 1600×1120 | 해당 없음 | 불투명 확인 시트, 어두운/밝은 배경과 확장 예시 |

리본의 top/bottom=0은 세로 크기를 유지하는 가로 3조각 사용을 뜻합니다. panel과 버튼은 RGBA이며 외부가 완전히 투명합니다. 판의 바탕 알파는 약 94%, 금선은 더 선명하게 유지합니다. 금선과 붓 가장자리에는 부드러운 안티앨리어싱이 있습니다. say_shade는 RGB #231712, alpha=round(240×(y/319)^2.4)이며 위쪽 30%의 알파는 최대 약 5%입니다.

contact.png의 글자는 파일 식별용이며 게임에 넣는 조각에는 포함되지 않습니다. 확인 시트의 판은 452×256, 버튼은 174×60으로 9조각 확장했습니다.

## 제작

내장 image_gen 사용. 생성된 리본 2개, 판 1개, 버튼 상태 4개의 질감을 PIL로 정리했습니다. 버튼 테두리 형태는 idle을 기준으로 통일했습니다. 그늘은 요청대로 PIL에서 매끈한 그라데이션으로 제작했습니다. 사용한 프롬프트 세트는 PROMPTS.md에 기록했습니다.
