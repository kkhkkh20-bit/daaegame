## 제작 방법과 직접 검수

내장 이미지 생성 도구로 초상 내부와 유리 세트를 재작화하고, Python PIL로 합성·회색 변환·분리·가장자리 마감·배치·축소·무손실 WebP 저장을 수행했다. 원본을 이용한 합성은 4배 해상도에서 처리한 뒤 LANCZOS로 축소했다. 지난 `PROPOSAL.md`와 `assets_draft/`는 구조 제안의 참고로 읽었고, 거친 초안을 납품 그림으로 사용하지 않았다.

완성된 `검수_전체.png`와 짝별 비교본을 직접 열어 확인했다. 첫 유리 합성은 냄비 잘림과 질감 문제가 있어 버렸고, 구리선도 평평한 선 묘사를 버리고 원본의 금속 질감으로 교체했다. 최종본에서 세 짝의 대응 요소, 초상의 두 손·목도리·수레, 받침의 둥근 자국과 직선 자국을 확인했다.

파일 검사에서 8장 모두 384×384 RGBA이고 알파 최솟값 0·최댓값 255임을 확인했다. 파일별 SHA256은 `검수_파일.json`에 남겼다. 원본 게임에는 반영하지 않았으며 Ren'Py 실행 화면에서의 축소 표시·증거 공개 시점·비교 화면 동작은 검증 범위에 포함하지 않았다.

## 생성 지시문 요지와 재현 자료

생성 도구는 내장 도구를 사용했으며 별도 API나 CLI 호출은 사용하지 않았다. 실제 지시의 한국어 요지는 다음과 같다.

1. 초상: 원본 종이·먹선 테두리·질감·왼쪽 위 조명을 유지하고, 중앙 아래의 들뜬 연한 덧칠 아래에 수레·앞에서 묶인 두 손·붉은 목도리의 익명 인물을 그림책 화풍으로 표현한다. 이름·글자·화살표·피·범인 암시는 배제한다. 종이 밖은 투명하게 만든다.
2. 유리 파편: 원본 냄비는 왼쪽에 완전히 보존하고 오른쪽에 기준 병과 맞는 두꺼운 입술·짧은 목의 따뜻한 투명 갈색 유리를 표현한다. 갈고리형과 계단형의 비대칭 경계 두 곳, 이어지는 세로 제조선을 보인다. 떨어진 조각과 깨진 입구를 함께 보여 주고, 글자·표식·독약·피는 배제한다.
3. 봉인병: 원본 병의 몸체·마개·이어진 빈 종이 봉인을 유지하고, 유리 파편 참조원화의 입술 두께·목·제조선에 맞는 파손 전 상태를 그린다. 봉인이나 유리는 깨지지 않았으며, 제조선은 종이 옆에 보이게 한다. 추가 물건·글자·표식·독약 암시는 넣지 않는다.

선택한 고해상도 생성 원화는 `제작자료/`에 보관했다. `make_assets.py`는 이 자료와 읽기 전용 게임 원본을 이용해 최종 크기 파일과 비교본을 다시 만든다. 생성 도구를 다시 호출하지 않는다.
