# 48px 자료 아이콘의 기준

사용자는 고선명 AI 아이템처럼 보이는 광택과 장식이 게임 몰입을 깨므로, 이전 64px 아이콘보다 단순한 도트를 요청했다. 이번 결과는 자료·물건 82종의 그림을 직접 다시 그리고 실행 기준도 48×48로 통일한 것이다.

금속은 차분한 황토색, 가죽은 낮은 채도의 버건디·청록·갈색, 종이는 크림색으로 둔다. 재질별 명암은 2~3단계의 큰 픽셀 면으로 구성하고 작은 반사광·금장·잔선·디더링·종이결은 덜어낸다. 외곽선은 뚜렷하게, 실제 자료를 구분하는 봉인색·매듭·핀·중요 도형은 남긴다. 인물 초상과 P01은 이번 작업에서 제외한다.

imagegen으로 각 시트를 편집했다. 표준 `dev/import_art.py --lossless`로 도트와 투명도를 보존해 가져왔다. PNG를 필터로 처리하거나 Python으로 그림을 다시 그리지 않았다. 알파 영역을 읽어 각 그림의 표시 좌표만 확인했고, 촛대 두 조각처럼 한 자료에 속한 부분은 함께 표시한다. 게임에서는 nearest 방식으로 확대한다.

이전 그림은 Git 커밋 `8947812f317b8c257684775decca170ee149fe3c`에 남아 있다. 새 그림의 프롬프트와 전후 해시는 `sources.json`, 실제 적용 좌표는 `game/assets/room13-material-icons079.json`이다.
