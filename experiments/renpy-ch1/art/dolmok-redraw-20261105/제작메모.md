# 돌목 대화 원화

소유자 요청: 「돌목캐릭터 대화 모습이 너무 못생기고 이상한데 이쁘게 다시 만들어 주라」.

기존 돌목과 메인 6인 스티커를 기준으로 기본 원화를 imagegen으로 다시 그린 뒤 동일 몸·소품의 얼굴 표정만 바꿔 6장을 제작했다. 원본 PNG와 SHA-256을 보존한다. 크림 털과 회색 눈가 무늬의 오소리 성인 경비, 청록 외투·빨간 목도리·장부·붓·갈색 부츠를 유지한다.

`dev/import_dolmok_redraw.py`가 원본을 품질95 WebP로 가져오고 세 크기의 배율·가운데·발 기준을 등록한다. 마스터를 크기별로 다시 축소 저장하지 않는다. `manifest.json`과 `room13-dialogue-player-facing.json`에서 18프레임의 출처·배율·좌표를 확인할 수 있다. Ren’Py의 float 위치는 상대 좌표이므로 픽셀 위치는 정수로 저장한다.
