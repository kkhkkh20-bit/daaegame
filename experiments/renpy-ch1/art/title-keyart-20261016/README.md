# 겨울 동화 타이틀 원화와 로고

imagegen으로 전용 원화와 투명 로고를 각각 생성하고 `dev/import_art.py`로 넣었다. 배경에 버튼·제목을 구워 넣지 않아 실제 텍스트·포커스·터치 영역은 Ren'Py UI로 동작한다.

- 원화: `game/assets/room13-title-fairytale084.webp`. 기존 `room13-fullbody-daram-neutral.webp`를 인물 참조로 사용했다. 붉은 베레모·남색 옷·크림색 꼬리·책의 정체성을 유지한다. 왼쪽 다람이와 편지, 가운데 눈 덮인 마을과 다리, 오른쪽의 메뉴용 안개 여백을 함께 그렸다.
- 로고: `game/assets/room13-title-logo.webp`. 이름 ‘다람탐정’의 아이보리 책 글씨, 눈·마른 가지·작은 붉은 봉인. 도토리는 넣지 않았다. 도트 윤곽을 보존하려고 무손실로 가져왔다.
- 스타일: 조용한 남색·청록 숲, 아이보리 눈, 따뜻한 창, 작은 붉은색. 굵고 명확한 색 덩어리와 계단형 윤곽. 사진 같은 표면, 번쩍이는 입체 금장, 무작위 노이즈·그레인은 요청하지 않았다.

생성 결과와 가져온 파일의 해시는 [sources.json](sources.json)에 남겼다. 단일 인물은 기존 디자인을 참조한 표지 일러스트이며 새 대화 초상화 제작은 별도다. 아빠는 그리지 않았다.

조명은 `dev/make_dot_fx.py --title-only`로 재생성한다. 새 원화를 1280×720으로 표시했을 때 확인한 마을 창과 다리 등불 위치를 사용한다. 타이틀만 재생성해 다른 장면의 프레임을 바꾸지 않는다.
