# 너울 도트 화풍 교정 원본

2026-11-08 소유자의 실 플레이 검수 수정 승인 범위다. 요청 `FIX131-NEOUL`을 따른다.

- 여섯 기본 표정: neutral, joy, angry, anxious, flustered, surprise_talk.
- 생성: image_gen.imagegen. 중립을 다람·돌목 도트 기준으로 교정하고 같은 중립을 공통 기준으로 다섯 표정을 만들었다.
- 원본은 각 1024×1536 RGBA 생성 바이트 그대로 보존했다. `manifest.json`에 생성 경로, SHA-256, 알파 경계, 대응 런타임 파일을 기록했다.
- 금빛 털, 안경, 크림 코트, 청록 목도리, 적갈색 조끼, 회갈색 바지, 갈색 부츠, 옷깃을 잡은 손, 반대쪽 내린 손, 정면 시선을 유지한다.
- 기존 너울의 840 프로필 표시 키 848과 질문 표시 키 560, 실제 알파 발선을 보존한다. 다른 캐릭터의 키와 전역 필터는 바꾸지 않는다.
- 현재 문맥 등록과 별도 원본 동작 등록에 너울 전용 별도 프로필은 없다. 일반 대화·질문·단독 회의의 여섯 기본 표정 대상이다. 현장 그림 등록은 변경하지 않는다.

`source-gallery.png`는 제작 원본의 비교 시각화다. 실제 플레이 캡처가 아니다.

## 연결

메인 담당자가 다음 명령을 실행한다.

```bash
python3 dev/import_neoul_pixel131.py --apply
```

기본 실행은 검증만 한다. `--apply`는 `room13-dialogue-player-facing.json`의 너울 항목과 크기 맞춤표만 갱신한다. 다른 인물·문맥·동작 등록은 건드리지 않는다.

## 인수 검사

`python3 -m unittest discover -s dev -p 'test_neoul_pixel131.py'` 2개를 통과했다. 여섯 표정의 원본/런타임 해시, 투명 모서리, 잘림 없음, 원래 표시 키와 발선이 검증된다. 외부 알파 최대값은 전부1이어서 몸 바깥에 보이는 배경이나 그림자 덩어리가 없다.

여섯 표정과 원본 비교표를 직접 확인했다. 실무 의견으로는 기존의 가는 윤곽과 잔명암보다 다람·돌목의 계단 윤곽과 큰 색면에 가깝다. SDK·웹·일반 대화/질문/회의의 실제 화면 인수는 통합 담당자가 수행한다.
