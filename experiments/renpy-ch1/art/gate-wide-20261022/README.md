# 마을 입구 오전 확장 배경

- 완성본: `gate-wide-morning.png`, RGB PNG, 2560×960, 월드 좌표 1배.
- 미리보기: `preview-75.png`, 1920×720. 분홍 테두리는 왼쪽 끝 카메라(x=0~1279), 청록 테두리는 오른쪽 끝 카메라(x=640~1919). 두 화면 모두 높이 720.
- 원본: `../../game/assets/room13-pixel-ready-gate0173-morning.webp`, 2048×768.
- 원본을 Pillow 최근접 이웃으로 1920×720으로 축소하여 (320,200)에 배치했다. 보존 범위는 x=320~2239, y=200~919이다.
- 최종 합성 후 해당 영역의 모든 RGB 픽셀이 원본 축소본과 동일한지 검사하여 통과했다. 원본 영역 안쪽은 경계를 포함해 변경하지 않았다.

## 도구와 처리

내장 `image_gen`으로 외곽 확장을 생성했다. Pillow와 NumPy로 크기 조정, 외곽 도트 정리, 경계 보정, 원본 복원 및 미리보기를 처리했다.

`expansion-input.png`는 지정 위치에 원본을 놓고 외곽을 자홍색으로 표시한 편집 입력이다. `generated-outpaint.png`는 내장 도구가 반환한 2048×768 생성 원본이다. 생성 결과를 Lanczos로 2560×960으로 맞춘 다음, 1280×480 BOX 축소와 최근접 이웃 확대를 적용해 외곽을 2px 격자로 정리했다. 이후 중앙 원본을 다시 덮었다.

손본 경계는 원본 직사각형 바깥쪽 6px이다. 생성 그림과 원본 가장자리의 색상 차이를 바깥쪽으로 점차 줄이는 방식으로 보정했다. 중앙 원본에는 이 보정을 적용하지 않았다. 모서리 바깥 영역은 생성 결과를 유지했다.

`finalize.py`는 후처리와 픽셀 검증을 재현하는 스크립트다. 이 디렉터리에서 `python finalize.py generated-outpaint.png`로 실행할 수 있다. 현재 작업 공간의 절대 경로를 사용한다.

## 생성 프롬프트의 한국어 기록

도구에 전달한 영어 원문은 `prompt.txt`에 보존했다. 아래는 같은 내용의 한국어 기록이다.

용도: 합성. 편집 대상은 2560×960 캔버스이며 겨울 도트 마을 그림이 x=320~2239, y=200~919에 있다. 자홍색 영역만 확장 생성한다. 중앙 그림의 크기, 배치, 구조, 사물, 색상을 보존한다. 출력은 2560×960이며 확대나 구도 변경을 하지 않는다.

위 200px에는 푸른 오전 하늘, 먼 설산, 잘린 지붕 꼭대기, 굴뚝 연기와 침엽수 꼭대기를 잇는다. 왼쪽 320px에는 기존 왼쪽 집, 돌담, 나무 울타리, 눈 덮인 땅과 침엽수를 잇는다. 오른쪽 320px에는 기존 집의 지붕과 벽, 돌담, 나무 울타리, 눈과 침엽수를 잇는다. 아래 40px에는 눈밭과 푸른 그림자를 잇는다.

원본의 2~3px 도트 덩어리, 선명한 계단형 경계, 파란 하늘·흰 눈·따뜻한 목재의 겨울 오전 팔레트, 원근과 빛 방향을 맞춘다. 건축선, 울타리 가로대, 나뭇가지와 눈 그림자가 경계에서 정확히 이어져야 한다. 자홍색은 남기지 않는다. 새 사람, 동물, 상자, 짐, 종이, 표지판, 글자, 로고, 워터마크와 눈에 띄는 조사 단서를 만들지 않는다. 배경 확장만 한다. 중앙은 그대로 둔다.

## 육안 점검과 한계

집 지붕, 울타리와 눈밭의 큰 형태는 이어진다. 다만 생성 외곽은 중앙보다 도트가 약간 부드럽고, x=320·2240 부근의 돌담·수목 및 y=920 부근의 눈 그림자는 확대해서 보면 미세한 질감·윤곽 차이가 남는다. 완전한 수작업 도트 접합과 동일한 수준으로 보장하지 않는다.

게임 코드 및 설정은 수정하지 않았고, git 명령과 Ren'Py 실행은 사용하지 않았다.
