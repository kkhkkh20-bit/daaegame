# 대화 인물 도트 교정 원본

2026-11-08. 소유자의 ‘대화할 때 나오는 인물 그림 차이’ 교정 요청으로 제작했다. 창·버튼·리본은 수정하지 않는다.

피코·콩이·까로·세련·보리·우박 각6표정과 세련 앉은2자세, 우박 특수2감정 총40 PNG다. 각 인물의 manifest는 원본 SHA·투명 경계와 실행 경로를 기록한다. 생성 원본은 수정하거나 기계적으로 픽셀화하지 않았다. 스타일 기준은 기존 다람과127돌목이다. 의상·연령·감정별 의미 있는 손동작을 유지한다.

피코의 붓·초상 판자와 우박의 온도 집게·측정 종이는 대본 및 승인 현장 도구에 맞춘다. 새 초상·단서·기록 숫자는 추가하지 않는다. 자세의 다름은 연기로 유지하며, 인물 정체성과 그림체를 맞춘다.

`python3 dev/import_dialogue_cast128.py --apply`로 q95 WebP와 프로필·크기표를 다시 만든다. `runtime-fit-targets.json`은 교정 직전 최종 표시 높이를 보관한다. 콩이의 질문용 아동 크기373.333px도 보존한다. 세련 앉은 자세는 기존 visible 높이/가운데/발선/캔버스를 따른다. 옛 납품 원본과 실행 파일은 예전 저장 참조용으로 남긴다.

[검수 보고](../../docs/reviews/dialogue-cast-20261108/검수.md)의 합성 비교와 실제 게임 화면을 구분한다. 이번6명 교정은 전체 주민 화풍 통일 완료를 뜻하지 않는다.
