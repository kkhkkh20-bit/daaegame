# 자료·물건 아이콘

사용자 요청: 여러 증거와 아이템을 예쁜 앤틱 아이콘으로 만들되, 촘촘한 잔점·거친 질감은 줄인다. 새 인물 초상화는 인물 재구성 이후로 미룬다.

기본 데이터뿐 아니라 실제 실행 중 추가되는 자료까지 확인했다. `catalog.json`은 제작 당시의 전체 자료·상점·대여·필기함 목록이다. 증언과 P01 초상은 제외하고 기록 62종과 물건 20종을 제작했다. 소지품을 자료에 통합해 보여주는 기존 정책을 유지한다.

아이콘 5개 시트를 imagegen으로 제작하고, 표면 질감·가장자리·초상 제외를 다시 편집했다. 배경은 투명하다. 표준 `dev/import_art.py`로 WebP를 가져온 뒤 실제 시트 크기와 각 아이콘의 개별 범위를 기준으로 JSON 좌표를 작성한다. 서로 떨어져 있는 촛대 두 조각처럼 하나의 자료인 부분은 같은 영역에 포함한다. 이미지에 필터를 덧씌우거나 수동으로 배경을 지우지 않는다. 제작 프롬프트와 해시는 `sources.json`에 기록한다.

도트 표현은 필수다. 최종 그림은 기존 픽셀 아이콘을 스타일 참고로 다시 제작하며, 윤곽·명암을 분명한 픽셀 덩어리로 구성한다. 실행 시 64×64 논리 크기와 nearest 샘플링을 사용해 목록과 상세에서 도트 크기를 일관되게 유지한다.
