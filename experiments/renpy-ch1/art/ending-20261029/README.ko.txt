파일 받기
- runtime ZIP 01~06은 실제 연결용입니다. source ZIP 01~05는 원본 보관용입니다.
- 모든 ZIP은 독립 압축 파일이며 각각 10,000,000바이트 미만입니다. 바이너리 분할 파일이 아닙니다.
- 원하는 ZIP들을 같은 폴더에 풀면 daram-ending-art-20261029 아래로 합쳐집니다. 공통 CSV와 이 안내문은 동일한 중복 파일입니다.
- package-index.csv는 각 ZIP의 수록 ID, asset-correspondence.csv는 이미지·원본·크기·레이어 관계를 정리한 대응표입니다.

규격
- END-01~10 장면 및 그 투명판: 1280×720.
- 추모 소품: 720×720.
- END-11: 기존 WILD-DAWN 배경의 1672×941를 유지하며 인물 투명판 3개도 같은 크기입니다. 기존 배경 크기 예외입니다.
- 승인받은 규격 축소·투명판 정렬본을 runtime에 넣었고 원본 PNG는 변경하지 않았습니다. 엄격한 원생 1px 도트 인증을 의미하지 않습니다.

레이어 사용법
- END-02-base 위에 END-02-portrait-piko 또는 END-02-portrait-mom-childnose 하나만 선택해 (0,0)에 겹칩니다.
  두 판 모두 엄마의 초상입니다. piko는 초상의 인물이 아니라 피코가 완성한 버전을 뜻합니다. 다른 판은 코만 아이 솜씨로 약간 삐뚤어진 버전입니다.
- END-04-base만 쓰거나 END-04-blanket을 (0,0)에 겹칩니다. 기본판에는 가족 셋이 이미 있습니다.
- END-11-base-reused 위에 END-11-three / END-11-father-child / END-11-father-alone 중 하나만 (0,0)에 겹칩니다.
- 투명판을 따로 자동 자르기하거나 각자 확대·축소하지 마세요. 배경과 같은 캔버스·원점을 유지해야 합니다.
- WILD-ENDING-PROPS-a는 요청서 (가), WILD-ENDING-PROPS-b는 (나)에 대응합니다. 모모는 별도 소품 없이 END-08을 재사용합니다.

확인 범위
- 모든 PNG/WebP 쌍의 크기 및 디코딩 RGBA 픽셀 일치를 검사했습니다. WebP는 무손실입니다.
- 투명판 6개는 배경과 같은 캔버스이며 아래 200px가 완전히 투명함을 검사했습니다.
- 제작 단계에서 내용·인물 수·물건·읽히는 글자 여부와 정지 합성 화면을 육안 확인했습니다.
- ZIP CRC와 이미지 SHA-256을 검사했습니다. checksums.sha256은 압축 해제 후 이미지·CSV를 검증할 때 사용합니다.
- 게임 저장소 연결, manifest.json 반영, 실제 대사창을 띄운 PC·모바일 화면 검수, 배포는 수행하지 않았습니다.
  최종 게임 화면에서 대사창 가림과 기존 대화 도트의 얼굴·옷·색 일치 여부는 게임 담당 검수가 필요합니다.
