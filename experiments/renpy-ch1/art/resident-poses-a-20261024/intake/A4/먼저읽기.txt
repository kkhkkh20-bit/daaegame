주민 생활 동작 A안 4차 묶음

흰 테두리 스티커 스타일. 기존 조사/생활 동작 원화에서 변환한 정지 이미지.
게임 미적용. 코드, 등장 조건, 대사, 사건, UI 기능 변경 없음.
원본은 originals, 투명 PNG와 동일 픽셀 lossless WebP는 runtime, 출처/검수 정보는 provenance.
PNG/WebP 둘 다 불러올 필요 없음. 같은 그림의 대체 포맷이다.
런타임용에는 그림 픽셀 크기를 바꾸지 않고 사방 32px 투명 여백만 추가했다.
그림 캔버스 크기는 실제 게임 표시 크기가 아니다. 기존 주민의 발 위치, 가구 대비 크기를 기준으로 배치해야 한다.
사물과 손이 함께 그려진 동작의 클릭 영역을 전체 직사각형으로 잡지 말 것. 조사 증거, 이동 버튼 가림을 확인할 것.
배경에 이미 있는 가구/등/작업대와 소품이 겹치면 중복 배치하지 말 것.
생활 동작 중 시선은 기존 작업 원화를 따르며 대화 시에는 정면 대화 에셋으로 전환하는 기존 연결을 유지할 것.
생존/사망/사건 발생 전후 조건은 기존 규칙을 그대로 유지. 사망 인물을 생활 이미지로 다시 등장시키지 말 것.
원화 참조 커밋은 1a0fc74775514efb353b844e102034600389b6f2. 최신 코드의 파일 연결과 위치는 별도 확인 필요.
미리보기는 납품 에셋을 모은 목록이며 실제 게임 화면이 아니다.
생성: built-in image_gen. 여백/포맷/목록 미리보기: ImageMagick.

너울은 기존 생활 동작 원화의 네이비 외투와 빨간 완장을 유지했다. 이전 대화용 B 기본 그림의 흰 외투와 다르므로 동일 장면 연결 전 복장 연속성을 확인해야 한다.
