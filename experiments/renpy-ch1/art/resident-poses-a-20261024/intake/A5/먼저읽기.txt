주민 생활/장면 동작 A안 5차 묶음

흰 테두리 스티커 스타일, 기존 동작 원화에서 변환한 정지 이미지.
게임 미적용. 코드, 등장 조건, 대사, 사건, UI 기능 변경 없음.
원본은 originals, 투명 PNG와 동일 픽셀 lossless WebP는 runtime, 출처/검수 정보는 provenance.
PNG/WebP는 같은 그림의 대체 포맷이다. 둘을 함께 로드하지 않는다.
런타임용에는 원본 그림 픽셀 크기를 바꾸지 않고 사방 32px 투명 여백만 추가했다.
캔버스 크기는 실제 게임 표시 크기가 아니다. 기존 주민의 발 위치와 가구 대비 크기에 맞춰 연결한다.
행동용 소품, 의자, 가구가 배경과 중복되는지 확인하고 증거/이동 버튼의 클릭 영역을 가리지 않는다.
생활 동작 중 시선은 작업 원화를 따른다. 대화 시에는 기존 정면 대화 에셋을 사용한다.
생존/사망/사건 전후 조건은 기존 규칙을 유지한다. 특정 장면용 동작을 평소 마을에 상시 배치하지 않는다.
원화 참조 커밋 1a0fc74775514efb353b844e102034600389b6f2. 최신 코드의 파일 연결/좌표는 미검증이다.
미리보기는 납품 에셋 목록이며 실제 게임 화면이 아니다.
생성: built-in image_gen. 여백/포맷/목록 미리보기: ImageMagick.

엄마의 조각 보여주기와 판돌의 이름 가리키기는 장면 맥락 전용이다. 그림만으로 증거 의미나 정답을 확정하지 않는다. 조각의 정확한 증거 대응은 별도 검수 필요. 다람 착석은 기존 장면용이며 임의 이동/수레 상황을 새로 부여하지 않는다.
