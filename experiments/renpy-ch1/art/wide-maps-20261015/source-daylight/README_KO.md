# 우체국·주방·식당·통로 시간대 배경 8장

2026-10-15 제작. 아침 원본을 imagegen lighting-weather 편집으로 낮(afternoon)·밤(evening)으로 파생했다. 원본 아침은 상위 폴더에 보존했다. 이 패키지는 코드 변경·게임 적용·배포를 포함하지 않는다.

## 검수와 제한
- 8장 전부 원본과 직접 시각 대조했다. 문·창·가구·주 조사물의 누락은 보이지 않는다. 주방은 테이블 자루 1개, 바닥 자루 없음, 왼쪽 문과 찬장 아래 홈을 유지한다. 식당은 솥·빵·담요·천장 장갑, 통로는 하강계단·레버·린넨·바구니·걸레를 유지한다.
- 주방·식당·통로: 5개 표본 영역별 에지 비교의 최적 이동은 0~1 px다. 조명에 따라 에지 검출이 달라지는 추정값이며 모든 픽셀·모든 물체의 동일성을 증명하지 않는다. 게임 클릭/가림/카메라 QA는 남았다.
- 통로 저녁은 2171×724로 아침 2172×724보다 폭 1 px가 작다. 임의 리사이즈·크롭으로 숨기지 않았다. 동일 가상 월드 전체 비율 배치 시 최소 차이를 확인해야 한다.
- 우체국 두 장은 엄격한 동일 좌표 검수 보류다. 낮은 공고(-5,+8), 난로(-5,0), 소포(-3,0) 정도, 밤은 공고(-12,+1), 난로(-8,-1), 소포(-7,-1) 정도 표본 드리프트가 있다. 목도리 표본은 상관도가 낮아 수치가 신뢰할 만하지 않다. 밤은 2159×728로 아침2160×728보다 폭1px가 작다. 우체국만 기존 아침 rect를 그대로 확정하지 말고 시간대별 재측정 또는 원본 픽셀을 보존하는 조명 보정이 필요하다.
- 초기 우체국 밤 시안의 닫힌 난로가 유리/불꽃 문으로 바뀐 문제를 발견하여 제외했다. 포함한 최종 밤 시안은 원래 불투명 금속문을 유지하며 난로 불꽃을 추가하지 않았다.
- imagegen 재시도에서도 완전한 좌표 고정은 보장되지 않았다. 완성 자산 8장/픽셀 동일 검수 통과라고 보고하면 안 된다. 제작 산출물 8장, 6장 근접 정합, 우체국2장 엄격 정합 보류로 구분한다.

## 파일
각 장소의 {장소}-afternoon-wide.png, {장소}-evening-wide.png. geometry-qa.json에 크기·SHA256·5개 국소 에지 검사의 이동/상관도를 기록했다. check_geometry.py는 읽기 전용 검수 스크립트이며 이미지 픽셀을 수정하지 않는다. prompts.json은 제작 요청을 기록한다.

공통 프롬프트: lighting-weather; 기존 원본을 편집 대상으로 사용; 시간대 조명만 변경; 카메라·문·창·가구·조사물·모든 실루엣과 픽셀 크기 보존; 인물/텍스트/새 소품 금지. 낮은 중성 겨울 낮빛, 밤은 파란 주변광과 기존 등·화덕 조명. 우체국 마지막 재시도는 난로 금속문 유지와 불꽃/유리창 추가 금지를 강조했다.
