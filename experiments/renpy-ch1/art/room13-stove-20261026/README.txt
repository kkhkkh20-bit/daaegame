별도 overlay: 같은 색/원형 도장의 배급 돌 윗부분과 소량 재. 알파0/255.
원본 생성 크기의 투명 PNG이며 visible_bounds와 배치 제안을 manifest에 적었습니다.
재받이 돌은 stove13_7 상태와 독립적으로 표시합니다. pocket_ration7로 돌을 챙긴 뒤에는 별도 조각을 숨깁니다. 이미 난로를 교체한 세이브에서 중복 표시되지 않도록 기존 상태 로직을 함께 확인하십시오.
배경/난로/재받이 구도는 기존 납품 기준입니다. 생성형 편집이므로 배경 전체 픽셀 동일성 보장은 아니며, 실제 좌표와 클릭 영역은 연결 담당자가 검증해야 합니다.
게임/저장소에는 적용하지 않았습니다. 이전 납품은 덮어쓰지 않았습니다.
