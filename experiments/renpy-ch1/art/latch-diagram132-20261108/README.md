# 3일 걸쇠 위치 스케치

2026-11-08 소유자가 승인한 완주 검수 P1 교정이다. E17의 바깥 걸쇠 진술과 E32의 안쪽 받침 파편 위치를, 성공 설명의 말이 가리키는 그림으로 보여 준다. 새 자료나 정답, 동기, 작동 부품을 추가하지 않는다.

- 원본 `source.png`: image_gen 생성 결과를 그대로 보관.
- 런타임 `game/assets/room13-latch-diagram132.webp`: 동일 원본의 무손실 WebP.
- 점선은 이미 비어 있는 돌 자리다. 창고의 특정 돌 상태를 새로 묘사하지 않는다.
- 외부의 단순 닫는 탭·바깥 판·뒤의 받침·파편 틈만 그린 개략 단면이며 실제 치수 도면이 아니다.
- 한국어 부품명과 강조 테두리는 게임의 타이포그래피 단계로 붙인다. 원화에 글자를 굽지 않는다.
- `MS14_D03_S05_L0021` 바깥 판 강조, `L0023` 안쪽 파편 위치 강조, `L0025`에서 명시적으로 내린다. 대사 블록 종료도 같은 화면을 정리한다.

첫 생성은 도구 출력 안전 분류(violence)로 실패해 파일이 없었다. 인물·위험 장면 없이 기계 부품의 위치만 보여 주는 요청으로 다시 생성했다. 첫 실패를 납품으로 세지 않았다.

실제 화면 시험은 메인 담당자가 SDK·웹 빌드와 순차 실행한다. 이 디렉터리 원본만으로 PC/휴대폰 화면 검증 완료를 주장하지 않는다.

옛 저장 호환은 해당 네 대사 ID의 표시용 복사본만 보완한다. 이미 계산된 옛 후속 대사도 바깥→안쪽→다음 쟁점 정리로 이어지며 원 packet·증거·기회는 쓰지 않는다. after_load는 효과음/기존 연출을 재실행하지 않고 현재 도식만 복원한다.
