# 엔딩 그림의 색면 기준

2026-10-16 사용자는 촘촘한 잔점과 거친 질감을 싫어하며, 픽셀 윤곽과 큰 명암 덩어리가 남는 깨끗한 표현을 요청했다. 엔딩 E0~E6의 네 장면을 이 기준으로 imagegen에서 직접 편집했다.

- 눈·하늘·벽·옷·목재는 넓고 조용한 색면으로 읽히게 한다.
- 무작위 점, 디더링, 종이결, 촘촘한 나무결, 자잘한 반사광을 덜어낸다.
- 눈·표정·중요 소품·등불에만 필요한 작은 디테일을 남긴다.
- 흐림 필터로 윤곽을 뭉개지 않는다. 겨울의 온도와 기존 인물·소품·장면 의미를 유지한다.

실행 자산은 기존 `room13-pixel-cinematic-ending-E*074.webp` 경로에 교체했다. 크기 1672×941과 네 장면의 자르기 좌표는 모두 같다. 원본 그림은 Git 커밋 `000840985356c84f016271089c687147e97ab174` 및 이전 검수 갤러리에 남아 있다. 편집 프롬프트와 전후 해시는 `sources.json`에 기록했다.
