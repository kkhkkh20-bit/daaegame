# 자료 그림

각 그림은 512×512 RGBA PNG이며, 투명 배경과 약 8% 여백으로 정리했습니다. 내장 이미지 생성 도구로 개별 생성하고 PIL로 크기와 배치를 정리했습니다. 생성 프롬프트는 `generation_prompts.json`에 기록했습니다.

- `E03` — 방문 신청 원본 종이
- `E06` — 낡은 종이의 방 메모
- `E31` — 공급 경로 진술 기록지
- `E11` — 작은 점검장
- `E14` — 운반표
- `E17` — 걸쇠 관련 진술 기록지
- `E18` — 이야기를 적은 기록지
- `E23` — 찢어진 자리와 두 줄 수선실이 있는 겉옷
- `E28` — 엄마에게 쓰는 답장
- `E06_EMPTY` — 빈 창고와 인계를 적은 관찰 기록지
- `E08_CHILD_ACCOUNT` — 손목과 진술을 적은 기록지
- `E08_RECENT_LETTER` — 짧은 엄마의 편지
- `E08_TOOL` — 접힌 천과 닫힌 핀이 남은 부러진 촛대
- `E09_PASSAGE` — 안쪽 손잡이가 없는 통로 문
- `E09_PIN_TIME` — 핀을 다시 채운 때의 진술 기록지
- `E12_FRAGMENT` — 작은 냄비의 파편과 병 입구
- `E13_HANDOVER` — 학교 인수 기록지
- `NW_BURNT_PAGE` — 반쯤 탄 수첩 장
- `NW_KEEPER_DATE` — 창고 구석의 빈 침상
- `NW_NEOUL_LEDGER` — 상자에 담긴 장부
- `NW_SICK_BEDS` — 작은 꽃 표시가 있는 침상 목록
- `NW_TABLET_B` — 희미한 글자가 새겨진 제단 밑돌
