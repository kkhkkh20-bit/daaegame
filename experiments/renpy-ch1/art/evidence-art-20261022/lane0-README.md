# 다람탐정 자료 그림

생성 프롬프트와 원본 경로: `generation_manifest.json`

- `E01` — 접힌 초대 편지와 읽히지 않는 필기선.
- `E04` — 겨울철 입장 규칙을 적은 종이 문서.
- `E07` — 초대 봉투 접수 내역을 적은 펼친 장부.
- `E35` — 가족 침구 예약 내용을 적은 종이.
- `E12` — 공구 대여 내용을 적은 작은 접힌 쪽지.
- `E15` — 작은 각인과 방향 홈이 있는 회갈색 창고 돌.
- `E32` — 수거한 금속 칼끝 파편.
- `E22` — 울타리에서 수거한 회색 천 조각.
- `E26` — 혐의 정정 내용을 적은 기록지.
- `E29` — 다음 날 아침 보호 약속을 적은 종이.
- `E06_FIRE` — 뚜껑이 닫히고 기름이 남아 있는 등잔.
- `E08_CHILD_POSITION` — 두 손과 위치를 확인한 내용을 적은 관찰 기록지.
- `E08_ROOM` — 방의 현장 관찰 내용을 적은 메모.
- `E08_WOUND_WIRE` — 끊긴 굴곡이 있는 짧은 구리선 조각.
- `E09_PIN_HANDOVER_TIME` — 계단참의 핀을 확인한 시점에 관한 기록지.
- `E09_SCARF` — 끝이 찢어져 올이 풀린 버건디 목도리.
- `E12_HANDLING` — 작은 냄비의 인계와 관찰 구간에 관한 기록지.
- `E13_ORDER` — 이송 명령 중지 사본 문서.
- `NW_HALL_WINDOW` — 인물 없이 가까이 본 회관 나무 창틀과 어두운 유리.
- `NW_MADAM_DAY7` — 특정 행을 강조하지 않은 펼친 창고 장부.
- `NW_PIKO_PAINTING` — 대부분 덧칠로 덮이고 작은 틈만 남은 그림 표면.
- `NW_STONE` — 각인이 없는 검푸르게 탄 돌.
- `NW_TRANSFER_LIST` — 이름이 읽히지 않는 표 형태의 학교 대피 명단.
